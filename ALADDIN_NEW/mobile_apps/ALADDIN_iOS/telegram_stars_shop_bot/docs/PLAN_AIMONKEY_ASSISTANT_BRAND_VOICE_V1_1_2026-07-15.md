**Дата:** 2026-07-15

**SSOT трекер:** `AIMONKEY_ASSISTANT_BRAND_VOICE_V1_1_TODO_TRACKER.md` (ids `as-bv-*`)

**Продукт:** `telegram_stars_shop_bot` → already shipped AI Помощник v1  

---

## 0. Вердикт (одна страница)

**Цель v1.1:** помощник звучит как AiMonkey — коротко, по-русски, по делу, без воды и без «я нейросеть на 15 абзацев» — **без** переобучения модели.

**Как:** tone guide + 30–50 золотых ответов + вшивка в system/KB + месяц метрик CSAT/тем.  
**Факты** по-прежнему только из KB SSOT + tools (`shop.db` / VPN).  
**LoRA / fine-tune** — **out of scope v1.1**; gate только после ≥500 чистых пар и доказанной боли тона.

---

## 1. Принципы (лучшие практики — обязательно)

1. **Факты ≠ тон.** Гайды/заказы = KB+tools. Тон = prompt + эталоны.  
2. **Не стартовать с fine-tune** для support-бота.  
3. **Эталоны не дублируют** длинные шаги Happ — только стиль + ссылка на KB / краткий каркас.  
4. **Красные линии v1** не ослаблять: бонус≠Stars, без `/sub/` в тексте, возврат→человек, no write-tools.  
5. **Privacy:** в датасет v1.1 — только вымышленные/обезличенные примеры; сырые логи с ПДн не класть в эталоны.  
6. **Измеримость:** до/после — CSAT 👍/👎, доля эскалаций, ручная выборка 20 диалогов.  
7. **Kill-switch** бренд-пакета: флаг или откат system prompt к короткому v1.

## 3. Tone guide — что зафиксировать (содержание)

Обязательные блоки в `AIMONKEY_ASSISTANT_BRAND_VOICE.md`:

1. **Кто мы:** AiMonkey — магазин Stars/Premium + VPN Happ; помощник поддержки, не психолог.  
2. **Тон:** спокойный, уверенный, короткий; «на ты» допустимо; без сленга и без канцелярита.  
3. **Длина:** обычно 3–8 коротких строк / шаги списком; не эссе.  
4. **Структура ответа:** суть → шаги (если how-to) → что нажать в боте → если не вышло — «Человек».  
5. **Запреты формулировок:** «как ИИ-модель…», «безусловно!», вода, обещание возврата/сроков, Stars с бонуса.  
6. **Обязательные формулы:** «смотрю ваш заказ в базе», «бонус только на VPN», «ссылка — кнопкой».  
7. **Эмодзи:** умеренно (как в боте), не кластер стикеров.  
8. **Язык:** только русский в v1/v1.1.

## 4. 10 тем для золотых ответов (минимум покрыть)

На каждую тему — **3–5** эталонов (в сумме 30–50).

| # | Тема | Что показать в эталоне |
|---|------|------------------------|
| T1 | Happ Android — старт | Кратко + «полная инструкция в гайде» / citation |
| T2 | Happ iOS | Аналогично |
| T3 | Статус своего заказа | «Из базы: #N — status» без угадываний |
| T4 | Чужой / нет заказа | Честно «не вижу» без утечек |
| T5 | Stars с бонуса? | Чёткий отказ, только VPN |
| T6 | Рефералка «как работает» | Коротко + куда в меню |
| T7 | Капча / оплата зависла | Не ломать checkout; что делать юзеру |
| T8 | VPN не коннектится | Чеклист + escalate при failed |
| T9 | Возврат денег | Без обещаний + человек + policy blurb |
| T10 | Jailbreak / «давай admin» | Отказ + помощь по продукту |

Дополнительно по желанию (в лимит 50): Premium gift, пополнение баланса, «где ссылка VPN».

**Формат эталона (обязательный):**

```text
id: gold.t5.bonus_stars_01
topic: ref_bonus
user: Можно купить Stars с бонусного баланса?
assistant_html: <короткий эталон, Telegram-safe HTML>
must_include: ["только на VPN", "основной баланс"]
must_not_include: ["можно оплатить Stars бонусом"]
kb_hints: ["kb.ref"]
escalate: false
```

## 5. Как вшить в продукт (техника)

1. **Tone guide** — документ для людей + сжатые 8–12 правил в `SYSTEM_PROMPT`.  
2. **Золотые ответы** — модуль с списком dict; юнит-тест: must_include / must_not.  
3. **Orchestrator:** при `topic_guess` подмешивать **≤2** эталона (≤400 символов каждый) в system context; общий бюджет токенов не взрывать (учитывать OpenRouter free limits).  
4. **KB `kb.brand`:** опционально plain-text tone rules для retrieve по «как говорить».  
5. **Не** копировать полные Happ-шаги в золотые — SSOT остаётся `ha-*` / `vpn_happ_*`.  
6. **Флаг:** `ASSISTANT_BRAND_VOICE_ENABLED=true` (default true после smoke) — быстрый откат.

## 8. Критерии приёмки (DoD v1.1)

Обязательно:

1. [ ] Tone guide утверждён OWNER (1 страница смысла)  
2. [ ] ≥30 золотых ответов по T1–T10  
3. [ ] SYSTEM_PROMPT обновлён, не длиннее ~1.5–2× текущего  
4. [ ] Few-shot wire + unit на must_include/must_not  
5. [ ] Регресс assistant tests зелёный  
6. [ ] Contabo: flag ON, kill-switch проверен OFF→ON  
7. [ ] Baseline метрик зафиксирован (неделя)  

Успех через 30 дней (мягкие цели, без понтов):

- CSAT 👍 доля не хуже baseline (или +5 п.п. если база низкая)  
- Ручная выборка 20 диалогов: ≥15 «тон ок»  
- Нет всплеска ложных обещаний возврата / Stars с бонуса

## 9. Когда НЕ делать LoRA (и когда да)

**Не делать в v1.1**, пока не выполнены все:

1. v1.1 бренд-пакет в проде ≥30 дней  
2. Есть ≥500 **чистых** пар (редактор + лучшие CSAT), без ПДн  
3. Проблема именно **тон/формат**, не «устарел гайд»  
4. Есть кто поддерживает переобучение раз в квартал  

Если gate пройден — отдельный план `as-lora-v2` (не этот документ).
