Заполните и отправьте в поддержку / ML при проблемах с VPN.

---

## Happ client checklist (P1 — перед тестом)

1. **HWID** — включить **до** импорта подписки (Happ → Настройки → HWID).
2. **DoH** — отключить; использовать системный DNS (Happ часто ставит Cloudflare DoH и игнорирует DNS из bundle).
3. **Обновление подписки** — только при **выключенном** VPN (иначе таймаут UPDATING).
4. **Профиль:** Wi‑Fi → 🇪🇺 Авто WiFi ⚡; 4G → 🇪🇺 Авто 4G 📶; не работает → 🇪🇺 Запасной (xhttp) или **Мобильный мост** (если в подписке).
5. Ссылка подписки: `https://aladdin-ai.ru/sub/<token>` (не `vpn.aladdin-ai.ru`).

---

## Что скопировать из Happ

1. **Настройки → О приложении** — версия Happ
2. **Профиль → ⋮ → Поделиться конфигом** — только имя профиля (без UUID в публичный чат)
3. **Логи / tunnel.log** — последние **200–500 строк** вокруг момента сбоя
4. **access.log** (если есть в Happ) — фрагмент с ошибкой TLS/Reality
5. Скрин: переключатель VPN + выбранный профиль
