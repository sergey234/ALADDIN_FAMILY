## Инструкция на сайте простым языком (обязательный UX)

Цель: любой человек после оплаты **сам** понимает, что делать — без поддержки и без жаргона.

### Где показывать

| Место | Что видит пользователь |
|-------|------------------------|
| Главная (гость) | Коротко: «1. Выберите срок → 2. Оплатите → 3. Откройте ссылку в Happ» |
| Перед оплатой | Ник + согласие + одна фраза «после оплаты получите ссылку для Happ» |
| Страница заказа `/o/…` (после оплаты) | **Главная инструкция** (шаги ниже) + кнопка Happ + QR |
| Вкладка «Подписки» | Та же инструкция, если VPN уже активен |
| Вкладка «Устройства» | «Один телефон = одна ссылка. Второй телефон — новое устройство / слот» |
| Вкладка «Профиль» | «Как войти снова» (сессия / ник+код / Telegram) — **без слова пароль** |
| Ошибка / нет ссылки | Честно: «ссылка готовится…» / «напишите в поддержку» — **не** показывать «готовую», пока peer-up не успешен |

### Текст инструкции (канон копирайта — внедрить в SPA)

**Заголовок:** Как включить VPN за 4 шага

1. **Скачайте Happ** — бесплатное приложение (кнопки App Store / Google Play).  
2. **Скопируйте вашу ссылку** или нажмите «Открыть в Happ» (или отсканируйте QR).  
3. **В Happ:** «+» → добавить подписку → вставить ссылку. На iPhone включите **HWID** в настройках Happ, если попросит.  
4. **Включите VPN** в Happ. Готово.

**Важно (короткие предупреждения):**

- Ссылка **личная** — не пересылайте друзьям.  
- Открывать нужно **в приложении Happ**, не просто в браузере Safari/Chrome.  
- Тот же браузер на сайте помнит кабинет сам. Другой телефон → **ник + код доступа** (код показали один раз при создании ника).  
- Пароль от почты **не нужен** — мы его не выдаём и email не просим.

### Вкладка «Подписки»
- Активна до …  
- Кнопка оплатить / продлить

### Вкладка «Бонусы» (сердце рефки на сайте)
- Большая карточка уровня: **Старт / Бронза / Серебро / Золото** + прогресс «ещё N друзей с VPN≥30д»

- Счётчики: приглашено / купили / VPN≥30д  
- Балансы (если привязан TG или после web-начислений): основной / реферальный — **коротко**, без финансового жаргона  

### Вкладка «Профиль»

Доказательство в логе worker (Contabo):

```text
Jul 29 18:11:38 … xray-peer-up: invalid telegram_user_id
Jul 29 18:11:38 … job 57 done (provision)
```

Корень: web-аккаунты используют **отрицательный** `telegram_user_id` (канон в `schemas.py`), а shell `xray-peer-up.sh` / `xray-peer-down.sh` / `wg-peer-*` принимают только `^[0-9]+$`. Provision помечается `done`, хотя peer-up упал → ссылка «живая» в API, но **в Xray клиента нет**.

Дополнительно (не корень, но в план):

- В браузере без HWID `/sub/` отдаёт заглушку «App not supported / Включите HWID» — это норма для curl, не баг Happ.
- В `env` строка с `🇷🇺 Вход` без кавычек → `Вход: command not found` при source env (починить кавычки).
- Сайт показывает plain `https://…/sub/…`; бот ещё даёт UX `happ://add/…` — после фикса peer-up добавить тот же one-tap на сайте.
