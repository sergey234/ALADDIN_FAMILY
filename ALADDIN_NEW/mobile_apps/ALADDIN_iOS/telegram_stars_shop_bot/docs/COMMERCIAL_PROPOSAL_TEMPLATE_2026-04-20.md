# Коммерческое предложение

**Проект:** Telegram Stars Shop Bot + Partner API  
**Версия:** 1.0  
**Дата:** 20.04.2026

## 1. Титульный лист
- Название проекта.
- Логотип/бренд заказчика.
- Краткий слоган: "Единый Telegram-бот с партнерским API для продаж Stars/Premium".
- Контакты исполнителя.

## 2. Executive Summary (1 страница)
- Цель проекта: запуск и масштабирование продаж через Telegram и партнерские интеграции.
- Ключевая архитектура: один бот + один API-шлюз + API-ключ = партнер.
- Что уже реализовано: бот, API, webhooks, тесты, CI, документация.
- Бизнес-эффект: быстрый запуск, снижение операционных рисков, готовность к росту.

## 3. Бизнес-задачи и эффект
- Прием заказов Stars/Premium.
- Администрирование и обработка заявок.
- Работа с реферальной моделью.
- Подключение партнеров без форков бота.
- KPI/эффекты: сокращение ручной рутины, ускорение обработки заказов, рост каналов продаж через API-интеграторов.

## 4. Область поставки (Scope)
- Telegram-бот (клиентский и админский контур).
- Partner API v1.
- Входящий payment webhook.
- Исходящие partner webhooks.
- Тесты + CI + эксплуатационная документация.
- Ограничения v1 (что осознанно не включено).

## 5. Функциональные возможности (по модулям)
### 5.1 Клиентский Telegram-контур
- Каталог, оформление заказа, профиль, поддержка.
- Баланс и частичная/полная оплата.
- Sell flow (выкуп Stars), история с пагинацией.
- Privacy screen.

### 5.2 Админский контур
- Изменение статусов заказов.
- Подтверждение пополнений.
- Обработка sell-заявок.
- Уведомления пользователям.

### 5.3 Partner API
- Аутентификация X-API-KEY.
- Orders / Topups / Profile.
- Идемпотентность заказов.

### 5.4 Webhooks
- Входящий webhook оплаты (mark_paid).
- Исходящие события order.status_changed с подписью.

## 6. Техническая архитектура
- Компоненты: Bot Runtime, API Runtime, SQLite.
- Модель данных: orders, api_clients, ledger, topup_requests, sell_requests.
- Безопасность: hash API-ключей, HMAC-подписи webhook, rate limit, фильтрация секретов в Sentry.
- Наблюдаемость и эксплуатация.
