# VPN UX — ручной smoke (6 путей)

После деплоя проверить в Telegram на прод-боте.

1. Hub → **🌐 VPN** → **⚡ Скорость** → **✅ Понятно** → снова приветствие (не тарифы 290 ₽).
2. **🟢 Оплата** → галочки → **Назад** → приветствие → снова **Оплата** → обе галочки → **Продолжить** → тарифы.
3. **📖 Помощь** → «Как импортировать файл» → **К меню помощи** → **К подключению** → пульт.
4. **🔀 Запасные способы** → OpenVPN → **К запасным** → **К подключению**.
5. Поддержка → **Политика Stars / Premium** — текст про отличие от VPN; кнопка **Документы AiMonkeyVPN** (если VPN включён).
6. `/vpn` без галочек — одно сообщение (витрина); с галочками — одно (пульт).

Автотесты: `pytest tests/test_vpn_screen_nav.py tests/test_vpn_navigation_matrix.py`
