# План: объединение «Заказы» + «Выданные» (только UI)

Дата: 2026-07-15  
Область: Telegram Stars Shop Bot  
Ограничение ТЗ: **не** трогать бизнес-логику заказов, выдачу, оплату, статусы в БД/API, обработчики fulfillment.

## Цель

Одна кнопка **📦 Заказы** вместо пары «📜 Заказы» + «🧾 Выданные». Внутри — все заказы пользователя карточками, новые сверху.

## Текущее состояние (код)

| Элемент | Где | Сейчас |
|--------|-----|--------|
| Кнопка заказов | `shop_kb.hub_menu_kb` | `📜 Заказы` → `nav:orders:0` |
| Кнопка выданных | там же + `ui_show_receipts` | `🧾 Выданные` → `nav:receipts` |
| Список заказов | `hub.nav_orders` + `_orders_page_html` | пагинация, кнопки `#id · сумма` |
| Выданные | `hub.nav_receipts` | только `status='completed'`, до 12 шт. |
| Карточка | `hub.order_detail` (`ord:{id}`) | уже открывает деталь — **оставить** |

## Шаги реализации

1. **Хаб-кнопки** — убрать `🧾 Выданные`; переименовать в `📦 Заказы` (callback `nav:orders:0` без смены).
2. **Список** — `_orders_page_html`: карточки по ТЗ (рамка, emoji товара, №, сумма, дата, статус с эмодзи); сортировка `ORDER BY id DESC` (уже есть) — проверить.
3. **Маппинг статусов UI** (только отображение, значения в БД не менять):
   - `completed` → 🟢 Выполнен
   - `processing` / paid-like → 🟡 В обработке (уточнить по фактическим `status` в `orders`)
   - `pending_payment` → 🔵 Ожидает оплаты
   - `cancelled` / `canceled` → 🔴 Отменён
   - ожидание выдачи (если отдельный статус) → ⏳ Ожидает выдачи
4. **Кнопки под списком** — оставить пагинацию + открытие `ord:{id}` (логика детали без изменений).
5. **Legacy** — `nav:receipts`: редирект на `nav:orders:0` (старые сообщения в чате) или тихий fallback; флаг `UI_SHOW_RECEIPTS` можно игнорировать в хабе.
6. **Тесты** — snapshot/строковые проверки хаб-кнопок и HTML карточки статуса; smoke: completed всё ещё открывается.
7. **Деплой** — `scripts/deploy_prod.sh`.

## Вне скоупа

- Изменение payment / provision / Partner API
- Изменение enum статусов в БД
- PDF-чеки (если были только в «Выданные» — ссылка из карточки `ord:` если уже есть)

## Критерий готовности

- В хабе одна кнопка заказов.
- В списке видны pending / processing / completed / cancelled.
- Новый заказ первым.
- Тап по выполненному → прежняя карточка с данными Stars/Premium/VPN.
