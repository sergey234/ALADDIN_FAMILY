## Язык для людей (без слова «слот»)

| Внутри кода (ок) | На экране пользователю |
|------------------|------------------------|
| slot / device_slot | **устройство** |
| free slot | **свободное место** / «можно добавить ещё» |
| buy slot | **«+ Новое устройство — N ₽»** |
| slot opened | **«Устройство добавлено»** / «Можно подключать» |
| slot limit | **«Все места заняты»** |
| revoke slot | **«Отвязать устройство»** |

Имена («Телефон жены», «Рабочий Mac») — **редактируемые** на get. и в боте (FSM «введите имя»). Автоимя после первого коннекта (iPhone / Android / …).

## 0. Продуктовые правила (d01 ✅)

1. База = **1 устройство** в подписке. `paid_device_capacity` стартует с 1.  
2. Каждое доп. = отдельная покупка (`VPN_EXTRA_DEVICE_PRICE_RUB`, старт 99 ₽).  
3. Потолок = `min(paid_device_capacity, device_limit)`, `device_limit` до **5**.  
4. Оплата → +ёмкость → своя `/sub/…` + «Ожидает подключения».  
5. Отвязка → ссылка мертва; **ёмкость не уменьшается**.  
6. В UI нет слова «слот».  
7. «В сети» = `last_seen` &lt; 5 мин (env), без фейкового realtime.  
8. Старый техтекст в разделе устройств убрать; тексты — ТЗ Миши §3.

## Анализ: шесть шляп (зафиксировано в плане)

### 🤍 Белая
Без Mini App в TG: HTML, inline-кнопки, фото/QR, пагинация, URL в браузер.  
Нельзя в чате: CSS-сетка, inline-форма rename, анимации.  
Сервер устройств + API + короткий экран бота — уже на Contabo; вкладка get. — нет.

### ❤️ Красная
Нужен «гараж гаджетов», не лог. Тизер-список слаб. Сайт должен совпасть с ТЗ. Кнопка «открыть в браузере» ок, если крупная и ясная.

### 🖤 Чёрная
Простыня текстом; спам сообщениями; PNG-карточки тяжелы; «+» без оплаты путает; rename FSM не «вау», но рабочий. Только сайт + убогий бот = снова претензии.

### 💛 Жёлтая
Сайт = 100% ТЗ. Бот = карточный пульт + QR + copy. URL на get. = полный UI без Mini App. Один API.

### 💚 Зелёная
Бот: шапка + карточка 1/N + ‹ › + Copy/QR/Rename/Отвязать + «+ N ₽» + «Панель в браузере».  
Сайт: сетка §3. Потом Mini App = тот же UI.

### 💙 Синяя
1) Панель get. 2) Карточный бот 3) Оплата d06 4) Пуш d10 5) Mini App — позже.

## 3. Панель на get. (d07–d08 ⏳) — эталон красоты

### 3.1
Вкладка **«Устройства»** / `#devices` при session + активной подписке.

### 3.2 Верх
«**N из M**» + бар (зелёный / жёлтый при 1 свободном / красный при 0) + **«+ Добавить устройство»**.

### 3.3 Сетка
Mobile 1 · tablet 2 · desktop 2–3.  
Карточка + аккордеон: ссылка, QR, copy, rename на месте, отвязка.  
Статусы и дата — дословно ТЗ.  
Confirm: *«Вы точно хотите отвязать это устройство? Ссылка станет недействительной»*.

### 3.4 Добавление
Модалка: ссылка + Скопировать + QR + «Ожидает подключения». Без старого техтекста.

### 3.5
Адаптив Samsung / iPhone / Mac / планшет; те же API, что бот.

## 4. Бот — карточный пульт (d09b–d09c ⏳), не «бедный тизер»

Заменяет ощущение «технический список». **Максимум красоты без Mini App.**

### 4.1 Шапка (одно сообщение)
```
🏠 Мои устройства
Занято 3 из 5
████████  🟢 / 🟡 / 🔴
```

### 4.2 Карточка устройства (одно сообщение, листание)
```
📱 Телефон жены
🟢 В сети сейчас
Подключен 12 июня 2026
Устройство 2 из 3

[ ‹ ]  [ › ]
[ Скопировать ссылку Happ ]
[ Показать QR ]
[ Переименовать ]
[ Отвязать ]
```

Rename: FSM «Введите новое имя» → обновление карточки.  
Отвязка: confirm из ТЗ → ссылка мертва.

### 4.3 Действия общие
```
[ + Новое устройство — 99 ₽ ]   ← d06
[ 🌐 Полная панель в браузере ] ← get./devices (url)
[ ⬅️ К VPN ]
```

### 4.4 После add / оплаты
```
✨ Устройство добавлено
⚪️ Ожидает подключения
[ Скопировать ] [ QR ] [ К карточке ]
```

### 4.5 Пуш (d10)
`🔔 Новое устройство подключилось: iPhone 15 Pro`

### 4.6 Админка (d11)
Список устройств в support; точечный revoke; `/admin_vpn_device_reset` = сброс всех с понятным текстом.

**Запрещено в боте v1:** простыня всех устройств одним длинным текстом; сетка «как сайт» из emoji-таблиц.
