# Ручной чеклист приёмки (перед продом)

Сопоставление с **ID из плана** (44 строки §3.0): `docs/ACCEPTANCE_CHECKLIST_BY_ID.md`.

Отметьте пункты после проверки в стейджинге / препроде.

## Онбординг и меню

1. [ ] `/start` — первый экран, кнопка «Далее», второй экран с 10 кнопками хаба.
2. [ ] `/menu` — снова экран 2 + хаб.
3. [ ] Команда `/my` — профиль и клавиатура хаба.

## Каталог и пустые разделы

4. [ ] **Купить Stars** — список товаров или явное сообщение о пустом `products.yaml`.
5. [ ] **Premium / Подарки** — при отсутствии позиций — понятное сообщение и выход в меню.

## Заказ (основной сценарий)

6. [ ] Выбор товара → способ оплаты → ввод `@username` → подтверждение → заказ создан, админу уведомление.
7. [ ] **Мои заказы** — список, пагинация, открытие деталки, кнопка поддержки.

## Баланс

8. [ ] **Пополнить баланс** — пресеты и своя сумма, заявка админу, зачисление через админ-кнопку.
9. [ ] Оплата заказа **с баланса** (полностью) и **частично** (mix) — суммы в деталке заказа сходятся.

## Профиль, рефералка, данные

10. [ ] Профиль — балансы, ссылка, FAQ рефералки (без «Продать Stars» / выкупа).
11. [ ] **Данные и политика** — экран открывается, возврат в профиль.

## API и ключи

12. [ ] **Наш API** — выпуск Partner API ключа (при заданном `API_KEY_PEPPER`), ключ показывается один раз.
13. [ ] `GET /health`, `GET /v1/user/profile` с `X-API-KEY`, `POST /v1/orders/create` с `Idempotency-Key` (повтор — тот же заказ).

## Поддержка и админка

14. [ ] Поддержка — с URL / с шаблонами FAQ без URL.
15. [ ] `/admin` — смена статусов заказа, пополнения (под админским ID).

## Регресс

16. [ ] `/cancel` в процессе checkout сбрасывает сценарий.
17. [ ] Чеки — список завершённых заказов открывает карточку заказа.

## Sentry и автоплатежи / вебхуки

18. [ ] При заданном `SENTRY_DSN` ошибки в боте и Partner API попадают в проект Sentry (smoke: искусственная ошибка на стейджинге).
19. [ ] `POST /v1/payments/provider-webhook` с валидным `X-Payment-Signature` переводит API-заказ из `pending_payment` в `paid`; повтор с тем же `idempotency_key` — без дубликата.
20. [ ] `PUT /v1/webhooks/subscription` задаёт HTTPS URL; при смене статуса API-заказа партнёр получает `POST` с `X-Partner-Signature` (см. `RUNBOOK` раздел 10).

## VPN / Happ

23. [ ] iPhone: Happ + `/sub/…` + профиль 🇷🇺 Вход RU.
24. [ ] **Android:** Google Play Happ → HWID → `/sub/…` → 🇷🇺 Вход RU (см. `docs/VPN_HAPP_ANDROID_CONNECT_GUIDE.md`).
