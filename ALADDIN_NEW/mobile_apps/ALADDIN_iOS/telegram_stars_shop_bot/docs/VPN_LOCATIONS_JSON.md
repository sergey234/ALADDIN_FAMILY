# VPN_LOCATIONS_JSON — список локаций в боте

Переменная окружения **`VPN_LOCATIONS_JSON`** задаёт строки для экрана «🌏 Локации (обзор)»: свёрнутый вид — первые `VPN_LOCATIONS_PREVIEW_N` строк (по умолчанию 3), развёрнутый — все строки плюс служебная строка про «белые списки» (если её ещё нет в списке).

## Формат 1 — массив строк

```json
["🇪🇺 Автовыбор", "🇫🇷 Франция", "🇩🇪 Германия", "🇳🇱 Нидерланды"]
```

## Формат 2 — объект с полем `lines`

```json
{
  "preview_n": 3,
  "lines": [
    "🇪🇺 Автовыбор",
    "🇫🇷 Франция",
    "🇩🇪 Германия",
    "🇳🇱 Нидерланды"
  ]
}
```

- **`preview_n`** (опционально): сколько строк в свёрнутом виде; иначе используется **`VPN_LOCATIONS_PREVIEW_N`** из `.env`.
- Пустой или невалидный JSON → в боте остаётся встроенный MVP-список, в лог пишется предупреждение.

## Лимиты

- Итоговый текст сообщения ≤ 4096 символов (Telegram); при длинном списке сократите строки или разбейте контент на внешний хаб (`VPN_INSTRUCTIONS_URL`).

## Связка с продуктом

Список **информативный** до интеграции с VPN API: фактический endpoint/peer по-прежнему выдаётся после оплаты по правилам SKU. Задача **`vpn-37-locations-api`** — подтягивать строки из API/БД нод и связать с выбором peer.
