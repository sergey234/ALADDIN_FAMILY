# Happ — видео для бота

Канонические файлы:

```
happ_appstore_region_guide.mp4   — видео (смена региона)
happ_app_icon.png                — иконка Happ («H» на чёрном), к альбому с видео
```

Исходник от дизайнера: `Смена ГЕО.mp4` → переименовать в имя выше.

Путь в репозитории: `assets/vpn/happ_appstore_region_guide.mp4`

На проде бот берёт файл отсюда, если в `.env` пусто `VPN_HAPP_REGION_VIDEO_FILE_ID`.
После первой успешной отправки в Telegram можно сохранить `file_id` в env — тогда
загрузка с диска не нужна.

Экран в боте: **🟢 Оплата** → кнопка **🎬 Видео: скачать Happ в РФ**.
