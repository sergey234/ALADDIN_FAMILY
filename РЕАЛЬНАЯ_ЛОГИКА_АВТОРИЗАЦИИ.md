## 🔐 РЕАЛЬНАЯ ЛОГИКА АВТОРИЗАЦИИ

### **1. РЕГИСТРАЦИЯ УСТРОЙСТВА (АНОНИМНО)**

**Что происходит:**
- 📱 При **первом запуске** приложения
- 📱 Приложение **автоматически регистрирует устройство** на сервере
- 📱 Используется **только deviceId** (UUID устройства)
- ✅ **БЕЗ email, password, телефона** - полностью анонимно!

**Endpoint:**
```
POST /api/auth/register-device
{
    "deviceId": "UUID устройства",
    "deviceType": "ios"
}
```

**Ответ:**
```json
{
    "token": "JWT токен",
    "deviceId": "UUID устройства",
    "subscription": {
        "level": "trial",
        "trialInfo": {
            "isActive": true,
            "daysRemaining": 14
        }
    }
}
```

**Код (iOS):**
```swift

    let deviceId = UIDevice.current.identifierForVendor?.uuidString ?? UUID().uuidString

    // ✅ Вызов API БЕЗ авторизации (requiresAuth: false)
    APIService.shared.registerDeviceAnonymously(request: request) { result in
        // Получаем JWT токен с TRIAL подпиской
    }
}
```

**Код (Server):**
```python
# api_gateway.py или device_endpoints.py
@app.post("/api/auth/register-device")
async def register_device(data: Dict[str, Any]):
    device_id = data.get("deviceId", str(uuid.uuid4())[:8])
    
    # ✅ Создаем токен БЕЗ персональных данных
    token = jwt.encode({
        "sub": device_id,
        "exp": datetime.utcnow() + timedelta(days=14)
    }, SECRET_KEY, algorithm=ALGORITHM)
    
    return {
        "token": token,
        "deviceId": device_id,
        "subscription": {
            "level": "trial",
            "trialInfo": {"isActive": True, "daysRemaining": 14}
        }
    }
```

### **2. АКТИВАЦИЯ TRIAL ПЕРИОДА**

**Что происходит:**
- ✅ При регистрации устройства **автоматически активируется TRIAL**
- ✅ Пользователь получает **14 дней бесплатного доступа**
- ✅ Токен содержит информацию о TRIAL периоде
- ✅ Все функции работают как в платном тарифе

**Код:**
```swift
// Core/Managers/SubscriptionManager.swift (строки 492-548)
func activateTrialIfNeeded() async {
    // Calculate trial dates
    let startDate = Date()
    let endDate = Calendar.current.date(byAdding: .day, value: 14, to: startDate)!
    
    let trialInfo = TrialInfo(
        startDate: startDate,
        endDate: endDate,
        durationDays: 14
    )
    
    // Register device and activate trial
    try await registerDeviceAnonymously()
    await updateTrialStatus(trialInfo)
}
```

### **3. ПОСЛЕ ИСТЕЧЕНИЯ TRIAL (14 ДНЕЙ)**

**Что происходит:**
- ⚠️ **TRIAL истекает** - функции перестают работать
- ✅ **Нужно оплатить тариф** (Basic/Premium/Family) для продолжения работы
- ✅ ИЛИ остаться на **Free тарифе** (ограниченные функции)

**Код:**
```swift
// Core/Managers/SubscriptionManager.swift (строки 1042-1078)
if !trial.isActive {
    logger.business("🎁 Trial expired - switching to free tier")
    
    // Переход на Free тариф с ограниченными функциями
    let freeSubscription = SubscriptionStatus(
        level: .free,
        isActive: true,
        expiresAt: nil,
        trialInfo: nil,
        limits: SubscriptionLimits.freeLimits,
        components: [],
        lastUpdated: Date()
    )
    
    await updateSubscriptionStatus(freeSubscription)
}
```

## 🔄 РЕАЛЬНЫЙ ПОТОК РАБОТЫ

### **Сценарий 1: Первый запуск приложения**

```
1. Пользователь открывает приложение
   ↓
2. SubscriptionManager.initializeOnAppStart()
   ↓
3. Проверка токена:
   - Токена нет → registerDeviceAnonymously()
   ↓
4. POST /api/auth/register-device
   {
       "deviceId": "UUID устройства",
       "deviceType": "ios"
   }
   ↓
5. Сервер создает токен БЕЗ персональных данных
   ↓
6. Ответ с токеном и TRIAL подпиской:
   {
       "token": "JWT токен",
       "subscription": {
           "level": "trial",
           "trialInfo": {"isActive": true, "daysRemaining": 14}
       }
   }
   ↓
7. Токен сохраняется в Keychain
   ↓
8. TRIAL активируется автоматически (14 дней)
   ↓
9. Все функции работают как в платном тарифе
```

---

### **Сценарий 2: После истечения TRIAL**

```
1. TRIAL истекает (14 дней прошло)
   ↓
2. checkTrialExpiration() обнаруживает истечение
   ↓
3. Переход на Free тариф (ограниченные функции)
   ↓
4. Пользователь видит предложение оплатить тариф
   ↓
5. Пользователь оплачивает тариф (App Store или QR)
   ↓
6. После оплаты:
   - Сервер обновляет подписку
   - Выдается новый JWT токен с платными правами
   - Все функции снова работают
```
