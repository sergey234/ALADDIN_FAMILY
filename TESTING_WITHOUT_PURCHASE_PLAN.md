### **Текущая система:**

#### **1. Регистрация/Авторизация**
```
POST /api/auth/login
{
    "email": "user@example.com",
    "password": "password123"
}

Ответ:
{
    "access_token": "JWT токен",
    "refresh_token": "JWT refresh токен"
}
```

#### **2. Сохранение токенов**
- ✅ Токены сохраняются в **Keychain** (безопасное хранилище)
- ✅ Используются для всех последующих API запросов
- ✅ Автоматически обновляются при истечении

#### **3. Проверка тарифа**
```swift
// Порядок проверки:

3. Если нет бесплатного → активировать автоматически
```
