## ✅ ВЫПОЛНЕННЫЕ ДЕЙСТВИЯ

### 1. Исправлены 2 ошибки в коде

#### Ошибка #1: Избыточный Task { @MainActor in } внутри .task {}
**Проблема:**
```swift
// ❌ БЫЛО:
.task {
    let currentExpiresAt = subscriptionExpiresAtIso
    Task { @MainActor in  // ← Избыточно!
        await updateExpirationTextCache(from: currentExpiresAt)
        debugLog.append("✅ cachedExpirationText инициализирован")
    }
}
```

**Исправление:**
```swift
// ✅ СТАЛО:
.task {
    let currentExpiresAt = subscriptionExpiresAtIso
    await updateExpirationTextCache(from: currentExpiresAt)  // ← Убран избыточный Task
    debugLog.append("✅ cachedExpirationText инициализирован")
}
```

**Причина:** `.task {}` уже выполняется в async контексте на MainActor, поэтому дополнительный `Task { @MainActor in }` избыточен.

---

#### Ошибка #2: debugLog.append внутри Task
**Проблема:** `debugLog.append` вызывался внутри Task, но debugLog мог быть уже захвачен.

**Исправление:** Вынесен за пределы Task, так как теперь нет вложенного Task.
