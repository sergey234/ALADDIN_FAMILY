## ❓ ВОПРОС 1: Автоматическое обновление токена

**Вопрос:** "Если токена нет, обе операции завершаются ошибкой - у нас же автоматическое автообновление токена везде?"

### ✅ ОТВЕТ:

**Да, автоматическое обновление токена реализовано:**

**Где работает:**
- ✅ `NetworkManager.get()` - вызывает `refreshTokenIfNeeded()` перед каждым GET запросом (строка 231)
- ✅ `NetworkManager.post()` - вызывает `refreshTokenIfNeeded()` перед каждым POST запросом (строка 279)
- ✅ `NetworkManager.put()`, `patch()`, `delete()` - также вызывают `refreshTokenIfNeeded()`

**Как работает:**
```swift
// Core/Network/NetworkManager.swift (строки 229-231)
func get(...) {
    Task {
        _ = await JWTTokenManager.shared.refreshTokenIfNeeded()  // ✅ Автоматическое обновление
        // ... далее проверка токена
    }
}
```

**НО есть нюанс:**

1. ✅ **Если токен истек:** `refreshTokenIfNeeded()` обновит его автоматически
2. ❌ **Если токена нет вообще:** `refreshTokenIfNeeded()` вернет `false` и проверка `AppConfig.authToken` все равно вернет `nil`

**Проблема:**
- Если пользователь не авторизован (токена нет в Keychain), автоматическое обновление не поможет
- Нужна авторизация пользователя

**Решение:**
- Обработать ошибку `unauthorized` как требование авторизации, а не как ошибку данных
- Показать понятное сообщение или перенаправить на экран авторизации

## ❓ ВОПРОС 2: Где сохраняются отчеты и как их посмотреть?

**Вопрос:** "Куда сохраняется этот отчет и как его можно увидеть - где посмотреть?"

### ✅ ОТВЕТ:

**Отчеты НЕ сохраняются локально на устройстве:**

1. **Хранение:**
   - ✅ Отчеты хранятся на сервере (база данных PostgreSQL)
   - ✅ Загружаются с сервера каждый раз при открытии модального окна
   - ✅ НЕ кэшируются локально (кроме временного хранения в памяти ViewModel)

2. **Что сохраняется локально:**
   - ✅ Выбранный пользователь: `@AppStorage("driving_reports_selected_user_id")`
   - ✅ Выбранный период: `@AppStorage("driving_reports_period")`
   - ❌ Отчеты НЕ сохраняются локально

3. **Где посмотреть отчеты:**

   **Экран:** `DrivingReportsModal` (модальное окно)
   
   **Как открыть:**
   - Главная → Аналитика → Компоненты защиты → Отчеты о вождении (карточка)
   - Или: Аналитика → Компоненты защиты → 🚗 Отчеты о вождении
   
   **Что отображается:**
   - ✅ **Статистика** (если есть `stats`):
     - Количество поездок
     - Балл безопасности
     - Количество нарушений
   
   - ✅ **История поездок** (если есть `reports`):
     - Список всех поездок за выбранный период
     - Для каждой поездки:
       - Откуда → Куда
       - Время в пути
       - Расстояние
       - Балл безопасности
       - Нарушения (если есть)
       - Система позиционирования (GPS/ГЛОНАСС)
   
   - ✅ **Пустое состояние** (если нет данных):
     - "Нет данных о поездках"

**Код отображения:**
```swift
// Shared/Components/Modals/DrivingReportsModal.swift

// Статистика (строки 81-84):
if let stats = viewModel.stats {
    statsSection(stats: stats)
}

// История поездок (строки 91-97):
if !viewModel.reports.isEmpty {
    tripsHistorySection  // ✅ ЗДЕСЬ ОТОБРАЖАЮТСЯ ОТЧЕТЫ
} else if !viewModel.isLoading {
    emptyStateView  // "Нет данных о поездках"
}
```

**API endpoints:**
- `GET /api/reports/driving/stats?userId={userId}&period={period}` - статистика
- `GET /api/reports/driving?userId={userId}&period={period}` - список отчетов
