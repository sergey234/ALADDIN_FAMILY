## 🔍 ПРИЧИНА ОШИБКИ "ОШИБКА ЗАГРУЗКИ"

### **Проблема:**
Когда токена нет, устанавливался `dataSource = .error`, что показывало индикатор "Ошибка загрузки" в UI, даже когда была кнопка "Войти".

### **Исправление:**
1. ✅ Изменено `dataSource = .error` → `dataSource = .empty` при отсутствии токена
2. ✅ Индикатор источника данных скрывается, когда есть кнопка "Войти"
3. ✅ Показывается только errorBanner с понятным сообщением

### **Результат:**
Теперь при отсутствии токена:
- ✅ Показывается кнопка "Войти" (красивая карточка)
- ✅ Показывается errorBanner с сообщением
- ✅ НЕ показывается индикатор "Ошибка загрузки" (избыточно)
- ✅ Пробуются загрузить кэшированные данные
