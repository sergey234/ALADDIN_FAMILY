### ШАГ 2: Обновить ElderlySettingsModal

1. Добавить `@EnvironmentObject private var localizationManager: LocalizationManager`
2. Заменить все hardcoded тексты на `localizationManager.localized()`
3. Использовать `String(format:)` для текстов с форматированием

**Примеры замен:**
```swift
// Было:
Text("⚙️ Настройки интерфейса")

// Стало:
Text(localizationManager.localized("elderly_settings_title"))
```

```swift
// Было:
Text("Текущий размер: \(Int(fontSize))")

// Стало:
Text(String(format: localizationManager.localized("elderly_settings_font_size_current"), Int(fontSize)))
```
