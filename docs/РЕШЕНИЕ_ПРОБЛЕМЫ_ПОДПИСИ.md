# 🔧 РЕШЕНИЕ ПРОБЛЕМЫ ПОДПИСИ

## ❌ ПРОБЛЕМА #1: Профили в GitHub Secrets старые

**Симптомы:**
- UUID профилей: `de134a6b-7135-4f75-bc3b-4a68fd753f7c` и `c0a22622-4b23-4be3-b18d-b744dbf8e6ce`
- Профили определяются как Development/Ad Hoc (есть ProvisionedDevices)
- Xcode не может использовать их для App Store

**Причина:**
В GitHub Secrets все еще старые профили (Development/Ad Hoc), хотя правильные файлы (App Store Distribution) уже подготовлены.

**РЕШЕНИЕ:**

### ШАГ 1: Обновите PROVISIONING_PROFILE_APP

1. Откройте файл: `~/Desktop/ALADDIN_Profiles/app_profile_appstore_base64_CORRECT.txt`
2. Выделите ВСЁ содержимое (Cmd+A)
3. Скопируйте (Cmd+C)
4. Откройте: https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions
5. Найдите `PROVISIONING_PROFILE_APP` → нажмите `Update`
6. Вставьте содержимое (Cmd+V)
7. Нажмите `Update secret`

### ШАГ 2: Обновите PROVISIONING_PROFILE_EXTENSION

1. Откройте файл: `~/Desktop/ALADDIN_Profiles/extension_profile_appstore_base64_CORRECT.txt`
2. Выделите ВСЁ содержимое (Cmd+A)
3. Скопируйте (Cmd+C)
4. На той же странице GitHub Secrets
5. Найдите `PROVISIONING_PROFILE_EXTENSION` → нажмите `Update`
6. Вставьте содержимое (Cmd+V)
7. Нажмите `Update secret`

## ❌ ПРОБЛЕМА #2: Проект настроен на Automatic signing

**Симптомы:**
- В `ALADDIN.xcodeproj/project.pbxproj` все таргеты имеют `CODE_SIGN_STYLE = Automatic`
- Параметры командной строки `CODE_SIGN_STYLE=Manual` игнорируются
- Xcode пытается использовать Automatic signing, но не может (нет аккаунта в CI)

**Причина:**
Xcode приоритизирует настройки проекта над параметрами командной строки.

**РЕШЕНИЕ:**

### Вариант 1: Использовать xcconfig файл (рекомендуется)

Создать временный xcconfig файл, который переопределит настройки проекта для Release конфигурации.

### Вариант 2: Изменить проект на Manual signing

Изменить `CODE_SIGN_STYLE = Manual` в проекте для Release конфигурации.

### Вариант 3: Использовать exportOptionsPlist

Использовать `exportOptionsPlist` с явным указанием профилей при экспорте IPA.

## ✅ РЕКОМЕНДУЕМОЕ РЕШЕНИЕ

1. **Сначала обновите GitHub Secrets** (ШАГ 1 и ШАГ 2 выше)
2. **Затем обновите workflow** для использования xcconfig файла

После обновления GitHub Secrets workflow будет использовать правильные App Store Distribution профили, и архив должен собраться.

---

## 🔍 ПРОВЕРКА

После обновления GitHub Secrets проверьте в логах workflow:

```
✅ App Profile: App Store Distribution (нет ProvisionedDevices)
✅ Extension Profile: App Store Distribution (нет ProvisionedDevices)
```

Если все еще видите:
```
⚠️  App Profile: Development/Ad Hoc (есть ProvisionedDevices)
```

Это означает, что GitHub Secrets НЕ обновлены!
