## ❌ ЧТО РЕАЛЬНО НЕ РАБОТАЕТ

### Проблема 1: Нет восстановления токена ПЕРЕД запросом

**Текущий код:**
```swift
// Core/Network/NetworkManager.swift:247
if requiresAuth {
    guard let token = AppConfig.authToken else {
        completion(.failure(NetworkError.unauthorized("Токен отсутствует")))
        return  // ❌ Сразу ошибка, не пытается восстановить
    }
}
```

**Проблема:**
- Если токен отсутствует в AppConfig → сразу ошибка
- НЕ проверяет SubscriptionManager
- НЕ пытается восстановить токен

**Решение:**
```swift
if requiresAuth {
    // ✅ ДОБАВИТЬ: Восстановление токена перед проверкой
    if AppConfig.authToken == nil {
        if let token = SubscriptionManager.shared.currentToken {
            AppConfig.authToken = token.token
            logger.business("✅ Токен восстановлен из SubscriptionManager")
        }
    }
    
    guard let token = AppConfig.authToken else {
        completion(.failure(NetworkError.unauthorized("Токен отсутствует")))
        return
    }
}
```

### Проблема 2: Нет автоматической перерегистрации при 403

**Текущий код:**
```swift
// Core/Managers/JWTErrorRecovery.swift:102
case 403:
    return .userNotification  // ❌ Только уведомление, нет перерегистрации
```

**Проблема:**
- При 403 ошибке только уведомление пользователю
- НЕТ автоматической перерегистрации устройства
- НЕТ попытки получить новый токен

**Решение:**
```swift
case 403:
    // ✅ ДОБАВИТЬ: Перерегистрация устройства при 403
    logger.business("🔄 403 Forbidden - пытаемся перерегистрировать устройство")
    Task {
        await SubscriptionManager.shared.performDeviceRegistration()
    }
    return .silentRetry  // Повторяем запрос после перерегистрации
```

### Проблема 3: Нет проверки токена при инициализации

**Текущий код:**
```swift
// Core/Managers/SubscriptionManager.swift:165
func initializeOnAppStart() async {
    loadPersistedData()  // Загружает токен
    // ❌ НЕТ проверки что токен синхронизирован с AppConfig
}
```

**Проблема:**
- После загрузки токена нет проверки синхронизации
- Если синхронизация не сработала → токен может отсутствовать в AppConfig

**Решение:**
```swift
func initializeOnAppStart() async {
    loadPersistedData()
    
    // ✅ ДОБАВИТЬ: Проверка синхронизации
    if let token = currentToken, AppConfig.authToken == nil {
        AppConfig.authToken = token.token
        logger.business("✅ Токен синхронизирован с AppConfig при инициализации")
    }
}
```

## 🎯 УТОЧНЕННОЕ РЕШЕНИЕ

### Решение 1: Восстановление токена перед запросами (КРИТИЧНО)

**Где:** `Core/Network/NetworkManager.swift`

**Что делаем:**
- Перед проверкой токена пытаемся восстановить из SubscriptionManager
- Только если токена нет нигде → возвращаем ошибку

**Код:**
```swift
// В методах get(), post(), put(), patch(), delete()
if requiresAuth {
    // ✅ ВОССТАНОВЛЕНИЕ: Пытаемся восстановить токен из SubscriptionManager
    if AppConfig.authToken == nil {
        if let token = SubscriptionManager.shared.currentToken {
            AppConfig.authToken = token.token
            logger.business("✅ NetworkManager: Токен восстановлен из SubscriptionManager")
        }
    }
    
    guard let token = AppConfig.authToken else {
        logger.error("❌ NetworkManager: Токен отсутствует - требуется регистрация устройства")
        completion(.failure(NetworkError.unauthorized("Токен авторизации отсутствует")))
        return
    }
    request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
}
```

### Решение 2: Автоматическая перерегистрация при 403 (ВАЖНО)

**Где:** `Core/Managers/JWTErrorRecovery.swift`

**Что делаем:**
- При 403 ошибке автоматически перерегистрируем устройство
- Ограничиваем количество попыток (защита от бесконечного цикла)

**Код:**
```swift
// В analyzeNetworkError()
case 403:
    logger.business("🔄 DEFENSIVE JWT: 403 Forbidden - перерегистрируем устройство")
    
    // ✅ ПЕРЕРЕГИСТРАЦИЯ: Автоматическая перерегистрация устройства
    Task {
        await SubscriptionManager.shared.performDeviceRegistration()
    }
    
    return .silentRetry  // Повторяем запрос после перерегистрации
```

**Защита от бесконечного цикла:**
```swift
// В SubscriptionManager
private var registrationAttempts = 0
private let maxRegistrationAttempts = 3

private func performDeviceRegistration() async {
    guard registrationAttempts < maxRegistrationAttempts else {
        logger.error("❌ Превышено максимальное количество попыток регистрации")
        return
    }
    registrationAttempts += 1
    // ... регистрация
    registrationAttempts = 0  // Сброс при успехе
}
```

### Решение 3: Проверка синхронизации при инициализации (РЕКОМЕНДУЕТСЯ)

**Где:** `Core/Managers/SubscriptionManager.swift`

**Что делаем:**
- После загрузки токена проверяем синхронизацию с AppConfig
- Если токен не синхронизирован → восстанавливаем

**Код:**
```swift
func initializeOnAppStart() async {
    loadPersistedData()
    
    // ✅ ПРОВЕРКА: Синхронизация токена с AppConfig
    if let token = currentToken {
        if AppConfig.authToken == nil {
            AppConfig.authToken = token.token
            logger.business("✅ Токен синхронизирован с AppConfig при инициализации")
        } else if AppConfig.authToken != token.token {
            // Токены не совпадают - обновляем AppConfig
            AppConfig.authToken = token.token
            logger.business("⚠️ Токены не совпадали - обновлен AppConfig")
        }
    }
}
```

## 📊 СРАВНЕНИЕ: БЫЛО vs СТАНЕТ

### БЫЛО:
```
1. Запрос → Проверка AppConfig.authToken
2. Токена нет → Ошибка ❌
3. 403 ошибка → Уведомление пользователю ❌
4. Пользователь видит ошибку и не знает что делать
```

### СТАНЕТ:
```
1. Запрос → Проверка AppConfig.authToken
2. Токена нет → Восстановление из SubscriptionManager ✅
3. Токена все еще нет → Ошибка (но с логированием)
4. 403 ошибка → Автоматическая перерегистрация ✅
5. После перерегистрации → Повтор запроса ✅
6. Пользователь не видит ошибок (или видит понятное сообщение)
```
