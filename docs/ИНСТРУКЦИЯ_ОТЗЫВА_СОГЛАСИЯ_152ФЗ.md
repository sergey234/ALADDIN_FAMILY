# 📋 ИНСТРУКЦИЯ ПО ОТЗЫВУ СОГЛАСИЯ
## Identity Theft Protection - Управление персональными данными

**Дата создания:** 10 декабря 2025  
**Версия:** 1.0  
**Соответствие:** Федеральный закон № 152-ФЗ "О персональных данных"

---

## 🎯 ЧТО ТАКОЕ ОТЗЫВ СОГЛАСИЯ?

**Отзыв согласия** - это ваше право полностью прекратить обработку ваших персональных данных в сервисе Identity Theft Protection.

### Что произойдет при отзыве?

✅ **Немедленно прекратится:**
- Мониторинг СНИЛС
- Мониторинг кредитного отчета
- Проверки в базе мошенников
- Генерация новых алертов

✅ **В течение 24 часов удалятся:**
- Все ваши согласия
- Активный мониторинг
- Кредитные отчеты
- Кэшированные результаты
- Все персональные данные

⚠️ **После удаления:**
- Вы потеряете доступ к истории мониторинга
- Алерты будут удалены
- Восстановить данные будет невозможно

## 📱 КАК ОТОЗВАТЬ СОГЛАСИЕ (iOS ПРИЛОЖЕНИЕ)

### Способ 1: Через настройки Identity Theft Protection

1. **Откройте приложение ALADDIN**
2. **Перейдите в раздел "Identity Theft Protection"**
   - На главном экране найдите карточку "Защита от кражи личности"
   - Или через меню: Настройки → Безопасность → Identity Theft Protection

3. **Откройте настройки**
   - Нажмите на иконку настроек (⚙️) в правом верхнем углу

4. **Выберите "Управление согласием"**
   - Нажмите на пункт меню "Управление согласием" или "152-ФЗ: Мои права"

5. **Просмотрите текущие согласия**
   - Вы увидите список активных согласий:
     - ✅ Согласие на обработку СНИЛС
     - ✅ Согласие на обработку паспортных данных
     - ✅ Согласие на доступ к кредитной истории

6. **Нажмите "Отозвать все согласия"**
   - Подтвердите действие в диалоговом окне
   - Введите код подтверждения (если требуется)

7. **Подтвердите отзыв**
   - Нажмите "Да, отозвать согласие"
   - ⚠️ Внимание: Это действие необратимо!

8. **Получите подтверждение**
   - Вы увидите сообщение об успешном отзыве согласия
   - Будет показан список удаленных данных

### Способ 2: Через главные настройки приложения

1. **Откройте приложение ALADDIN**
2. **Перейдите в "Настройки"** (иконка ⚙️ внизу)
3. **Выберите "Приватность и безопасность"**
4. **Выберите "Управление персональными данными"**
5. **Выберите "Identity Theft Protection"**
6. **Нажмите "Отозвать согласие"**
7. **Подтвердите действие**

## 🌐 КАК ОТОЗВАТЬ СОГЛАСИЕ (ЧЕРЕЗ API)

### Запрос через API

**Endpoint:** `POST /api/identity-theft/revoke-consent`

**Заголовки:**
```
Authorization: Bearer ваш_токен
Content-Type: application/json
```

**Тело запроса:**
```json
{
  "user_id": "ваш_user_id"
}
```

**Пример запроса (cURL):**
```bash
curl -X POST "https://api.aladdin.ai/api/identity-theft/revoke-consent" \
  -H "Authorization: Bearer ваш_токен" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "ваш_user_id"
  }'
```

**Пример запроса (Python):**
```python
import requests

url = "https://api.aladdin.ai/api/identity-theft/revoke-consent"
headers = {
    "Authorization": "Bearer ваш_токен",
    "Content-Type": "application/json"
}
data = {
    "user_id": "ваш_user_id"
}

response = requests.post(url, json=data, headers=headers)
result = response.json()
print(result)
```

### Успешный ответ

```json
{
  "success": true,
  "message": "Согласие отозвано, все персональные данные удалены",
  "user_id": "ваш_user_id",
  "deleted_items": [
    "согласия",
    "активный мониторинг",
    "кредитные отчеты",
    "кэш (5 записей)"
  ],
  "deleted_at": "2025-12-10T15:30:00"
}
```

### Ошибки

**Если согласие не было предоставлено:**
```json
{
  "success": false,
  "error": "no_consent",
  "message": "Согласие не было предоставлено, данных для удаления нет",
  "user_id": "ваш_user_id"
}
```

**Если нет авторизации:**
```json
{
  "detail": "Authorization required. Provide Bearer token in Authorization header."
}
```
Статус: `401 Unauthorized`

## ❓ ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

### Можно ли отозвать согласие частично?

**Нет.** Отзыв согласия применяется ко всем типам данных. Однако вы можете:

- Отозвать все согласия
- Затем предоставить новое согласие только для определенных типов данных

**Пример:**
1. Отозвать все согласия
2. Предоставить новое согласие только на обработку СНИЛС
3. Не предоставлять согласие на кредитную историю

### Сколько времени занимает удаление данных?

**До 24 часов** с момента отзыва согласия.

**Что происходит:**
- ✅ Согласия отзываются немедленно (в течение нескольких секунд)
- ✅ Мониторинг прекращается сразу
- ✅ Данные удаляются из активных систем в течение часа
- ✅ Данные удаляются из резервных копий в течение 24 часов
- ✅ Логи операций хранятся согласно законодательству (до 3 лет, но без персональных данных)

### Можно ли восстановить данные после отзыва?

**Нет.** После удаления данные восстановить невозможно.

⚠️ **Важно:** Если вы передумали, вам нужно будет:
1. Предоставить новое согласие
2. Заново добавить СНИЛС и другие данные
3. Начать мониторинг заново

### Что будет с моими алертами?

При отзыве согласия **все алерты удаляются** вместе с данными мониторинга.

**Рекомендация:** Если у вас есть важные алерты, сохраните их перед отзывом согласия:
1. Откройте раздел "Алерты"
2. Сделайте скриншоты важных алертов
3. Или экспортируйте данные (если функция доступна)

### Могу ли я снова использовать сервис после отзыва?

**Да!** Вы можете в любой момент:
1. Предоставить новое согласие
2. Заново настроить мониторинг
3. Начать использовать все функции сервиса

### Что делать, если я забыл отозвать согласие перед удалением аккаунта?

**При удалении аккаунта** все ваши данные, включая согласия, **автоматически удаляются**.

Вы также можете отозвать согласие **до** удаления аккаунта - это необязательно, но рекомендуется для прозрачности.

## ✅ ПРОВЕРКА СТАТУСА СОГЛАСИЯ

**Через приложение:**
1. Откройте Identity Theft Protection
2. Нажмите "Статус"
3. Проверьте раздел "Согласия"

**Через API:**
```bash
GET /api/identity-theft/status?user_id=ваш_user_id
```

**Ответ:**
