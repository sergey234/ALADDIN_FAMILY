## 1. Простыми словами: два разных мира

| Мир | Что это | Где живёт |
|-----|---------|-----------|
| **Баннеры на телефоне** | Локальные UN-уведомления (всплывашка) | `NotificationManager` + schedulers |
| **Лента / API на сервере** | Inbox `GET /api/notifications` | MAIN — Аладдин (`…180`) `:8002` / `aladdin-ai.ru` |

Их нельзя смешивать: баннер ≠ строка в серверной ленте.

## 2. Что такое «опциональные этапы» (не блокер)

Это **не** «ещё куча уведомлений, которые пользователи должны видеть каждый день».

Это **следующие уровни качества**, которые можно делать позже:

| Опционально | Что значит | Нужно ли семье прямо сейчас? |
|-------------|------------|------------------------------|
| **Живой bypass / звонок / авария** | Не smoke, а реальное событие в жизни | Нет — канал уже проверен матрицей |
| **APNs (push с сервера)** | Сервер шлёт на устройство через Apple | Отдельный контур (токен, сертификаты) |
| **Win-back 7–30 дней как в TG-боте** | Массовая «вернись» рассылка | P3, с лимитом частоты |
| **git push** | Выложить коммиты на GitHub | Только когда скажешь GO PUSH |

**Обязательное для пользователей — уже закрыто:** баннеры безопасности/семьи/вечера/привычек/антивируса + дожим trial/подписки.

## 3. Что нужно пользователям (локальные баннеры)

Полный user-набор (без VPN):

- Угрозы: blocked / detected / suspicious / bypass  
- Семья: member added / family chat  
- AI message  
- Подписка: upgrade / renewal / expired + **дожим**  
- Trial + **дожим** `trial_expired`  
- Рефка grant  
- Спокойный вечер  
- Привычки + due ping  
- Мнемо SRS  
- Antifake post-call  
- IoT compromised  
- Антивирус: complete / failed / download threat  
- Crash  

**Не в user matrix:** VPN / `network_protection_*` · тексты 🧪 smoke (только DEBUG) · biometric toggle.

**Диагностика:** soft-test — «колокольчик работает», не жизненное событие.

## 6. Куда нажать: smoke дожим → тап → Тарифы

### Шаг A — пересборка
В Xcode: Run на телефон/симулятор (свежий билд с dojim).

### Шаг B — открыть уведомления
1. Вкладка **Настройки**  
2. Пункт **«Уведомления»**  
3. Выключи: Не беспокоить / Important only / Quiet / лимит в час  

### Шаг C — smoke дожим (**только Debug-сборка**)
Прокрути до блока **QA Smoke** (в App Store Release этого блока нет — см. §11).

Нажми по одному (или найди в списке после «Прогнать все»):

| Номер (примерно) | Название на кнопке | Зачем |
|------------------|--------------------|--------|
| 11 | Trial истёк (дожим…) | тип `trial_expired` |
| 12 | Подписка истекла (день 0) | `subscription_expired` |
| 13 | Подписка — дожим D+1 | тот же type, `days_offset=1` |
| 14 | Подписка — дожим D+3 | `days_offset=3` |

Должен появиться баннер с 🧪.

### Шаг D — тап → Тарифы
1. **Тапни по баннеру** (не смахивай).  
2. Должен открыться экран **Тарифы** (`aladdin://tariffs`).  

Если баннер уже исчез — снова нажми ту же кнопку smoke и тапни сразу.

### Шаг E (опционально) — «Прогнать все N»
Кнопка **«Прогнать все … типов»** — полный прогон матрицы (~1 мин). Soft-test идёт **последним**.

### Реальные сценарии (уже проходили)
Тот же экран → блок **«Реальные сценарии»**:
1. Спокойный вечер  
2. Семейный чат  
3. Антивирус скан

## 7. Dojim vs бот — окна и «дни в подарок» (канон)

**26 smoke на устройстве — OK (2026-09-14).**

Это **два разных продукта**. Не смешивать цифры.

### 7.1 Окна напоминаний (когда пушим)

| | **Бот VPN** | **iOS ALADDIN (сейчас)** |
|--|-------------|---------------------------|
| Paid до конца | **d7 → d3 → d1 → h6** | **−3 → −1** (без −7, без h6) |
| Paid после | **expired** (+ win-back 7–30 рассылка) | **0 → +1 → +3** |
| Trial до конца | **~d1 → h6** | **−7 → −3 → −1** |
| Trial после | **trial_expired** | **0 → +1 → +3** |

Итог: iOS trial **раньше** предупреждает (−7); paid **не** шлёт d7/h6 как бот. После конца у iOS есть D+1/D+3; у бота — expired + отдельный win-back.

### 7.2 Что «добавляется» за друга (рефка) — не путать с окнами

| | **Бот VPN** | **iOS Invite Pro A** |
|--|-------------|----------------------|
| Другу | **+7 дней** VPN (paid) или **пробник ~3 суток** (trial) | **−20%** на первый оплачиваемый месяц (**не дни**) |
| Вам (пригласивший) | **+3 дня** VPN | **+7 / +14 / +30** дней защиты по уровню Bronze→Platinum |
| Qualify | оплата VPN | оплата **или ≥14 дней** активной защиты |
| Мост бот↔iOS | — | **запрещён** (Product Lock) |

Кнопка бота «+3 дня за друга» и тексты dojim iOS про «бонус дней другу» были **опасной путаницей** — в приложении другу скидка **−20%**, дни растут **вам**.

### 7.3 Что выравнивать?

- **Не копировать** VPN +3/+7 в iOS.  
- **Не копировать** iOS −20%/+7/+14/+30 в бот.  
- Окна dojim можно позже добавить paid **−7** (как d7 бота) отдельным GO — не обязательно для закрытия тестов.

## 8. API-файл: полный или нет?

### `ALADDIN_JWT_API_ARCHITECTURE_COMPLETE.md`
- Для **Notifications inbox** (§8.3 + блок smart_api_tester 2026-09-14) — **достаточно**: list/read + settings + referral/a flags.  
- Dojim **не** серверный API — это локальные calendar-баннеры; в JWT API **не нужно** отдельного endpoint «dojim».  
- Весь JWT-док = архитектура **всего** бэкенда; он не обязан быть «100% только уведомления».

### `smart_api_tester.py`
- Контракты уведомлений + referral/a — **прогнаны 6/6 и 4/4**.  
- Для задач уведомлений семьи — **полный**.  
- Не претендует на 100% всех API приложения (есть wellness/antifake/subscription отдельно).

**Добавлять в API-файл сейчас обязательно?**  
Нет. Имеет смысл только короткая пометка «dojim = local UN» (ниже уже в этом MD). При желании позже — одна строка в JWT §8.3: «iOS dojim P1 — local only, см. этот документ».

## 11. Prod UI (2026-09-14) — скрыли, не удалили

### Решение
| Вопрос | Ответ |
|--------|--------|
| Удаляем QA? | **Нет.** Скрываем через `#if DEBUG` |
| Что видит семья в App Store? | Экран **«Уведомления»** + переключатели + **одна** кнопка «Отправить тестовое» |
| Где матрица 26 / реальные сценарии / preflight? | Только **Debug** (Xcode Run / внутренние билды) |

- Типы: безопасность, семья, AI, обход  
- Звук, бейдж, тихий режим  
- Только важные / DND / высокий приоритет / лимит в час  
- Тихие часы  
- Чеклист «почему не приходят» + **«Отправить тестовое уведомление»**

- QA Smoke (список user kinds + typeKey)  
- «Сгенерировать тестовую угрозу»  
- «Прогнать все N типов»

- Preflight перед E2E  

Файлы: `Screens/NotificationSettingsScreen.swift` (`#if DEBUG`), `Core/Notifications/NotificationSmokeCatalog.swift`.

1. Xcode → схема **Debug** → Run.  
2. Настройки → **Уведомления**.  
3. Прогнать §5 (smoke + 3 сценария) и при необходимости `smart_api_tester.py --notifications-only`.  
4. Release/Archive — QA-блоков снова нет; soft-test и тумблеры на месте.
