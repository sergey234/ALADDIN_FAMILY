**Дата:** 9 декабря 2025  
**Проблемы:** 
1. При английской локализации показывается "Go to website" вместо IAP
2. VPN показывается на главной странице (main 1)

## ❌ ПРОБЛЕМА 1: "GO TO WEBSITE" ДЛЯ НЕ-РОССИЙСКИХ РЕГИОНОВ

### Текущая проблема:

В `TariffsScreen.swift` функция `getButtonText` всегда возвращает "Go to website" для платных тарифов, даже для не-российских регионов, где должна быть IAP оплата.

**Файл:** `Screens/10_TariffsScreen.swift`  
**Строки:** 189-200

**Текущий код:**
```swift
private func getButtonText(for tariff: TariffType) -> String {
    switch tariff {
    case .free:
        return localizationManager.localized("tariffs_free_button")
    case .personal, .family, .premium:
        return localizationManager.localized("tariffs_website_button") // ❌ ВСЕГДА "Go to website"
    }
}
```

**Проблема:**
- Для не-российских регионов должна быть IAP кнопка
- Но показывается "Go to website"
- Это нарушает Guideline 3.1.1

---

## ✅ РЕШЕНИЕ 1: ИСПРАВИТЬ getButtonText

### Нужно изменить:

**Файл:** `Screens/10_TariffsScreen.swift`  
**Строки:** 189-200

**Новый код:**
```swift
private func getButtonText(for tariff: TariffType) -> String {
    switch tariff {
    case .free:
        return localizationManager.localized("tariffs_free_button")
    case .personal, .family, .premium:
        // ✅ ПРОВЕРЯЕМ РЕГИОН: Для России - "Go to website", для остальных - IAP
        if AppConfig.useAlternativePayments {
            // Россия → "Go to website"
            return localizationManager.localized("tariffs_website_button")
        } else {
            // Не Россия → IAP кнопка
            return localizationManager.localized("tariffs_purchase_button")
        }
    }
}
```

**Что нужно добавить в LocalizationManager:**

**Русский:**
```swift
"tariffs_purchase_button": "Оформить подписку",
```

**Английский:**
```swift
"tariffs_purchase_button": "Subscribe",
```

## ❌ ПРОБЛЕМА 2: VPN НА ГЛАВНОЙ СТРАНИЦЕ

### Текущая проблема:

VPN показывается как первая карточка на главной странице (MainScreen), что нарушает Guideline 5.4.

**Файл:** `Screens/01_MainScreen.swift`  
**Строки:** 247-281

**Текущий код:**
```swift
// VPN карточка
NavigationLink(destination: VPNScreen()) {
    VStack(spacing: 8) {
        HStack(spacing: 8) {
            Text("🛡️")
            Text(vpnConnected ? "🟢" : "🔴")
        }
        Text(localizationManager.localized("main_vpn_title"))
        Text(localizationManager.localized("main_vpn_subtitle"))
    }
    // ... стили
}
```

**Проблема:**
- VPN показывается на главной странице как основная функция
- Это противоречит нашему письму Apple, где мы говорим, что VPN - вторичная функция
- Нарушает Guideline 5.4
