# 🔍 ОБЪЯСНЕНИЕ: Системные методы Apple (startVPNTunnel, stopVPNTunnel)

**Дата:** 17 декабря 2025

---

## ❓ ЧТО ЭТО ЗНАЧИТ?

`startVPNTunnel` и `stopVPNTunnel` - это **системные методы Apple**, которые являются частью фреймворка `NetworkExtension`. Это официальные API методы, предоставляемые Apple для работы с VPN-туннелями.

---

## 🔒 ПОЧЕМУ ИХ НЕЛЬЗЯ ПЕРЕИМЕНОВЫВАТЬ?

### 1. **Это методы Apple SDK**
- Эти методы определены в фреймворке `NetworkExtension` от Apple
- Они являются частью официального API
- Мы не можем изменить их названия - это не наш код

### 2. **Обязательные для работы NetworkExtension**
- Без этих методов невозможно создать VPN-туннель
- Apple требует использования именно этих методов для работы с NetworkExtension
- Изменение названий приведет к ошибкам компиляции

### 3. **Пример кода:**
```swift
// ✅ Это системный метод Apple - его нельзя переименовать
try manager.connection.startVPNTunnel(options: options)

// ✅ Это системный метод Apple - его нельзя переименовать
tunnelManager?.connection.stopVPNTunnel()
```
