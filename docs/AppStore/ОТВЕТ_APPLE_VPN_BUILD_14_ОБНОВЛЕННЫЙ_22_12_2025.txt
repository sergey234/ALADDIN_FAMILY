ОБЪЯСНЕНИЕ ТЕРМИНОЛОГИИ "ЗАЩИТА СЕТИ" (NETWORK PROTECTION):

Мы понимаем, что термин "Network Protection" может вызывать ассоциации с VPN. Хотим пояснить:

1. "Защита сети" (Network Protection) в ALADDIN - это функция безопасности для семейной защиты, а НЕ VPN-услуга.

2. В коде присутствуют:
   • Класс NetworkProtectionManager - управляет функциями безопасности сети (не VPN соединение)
   • Ключи локализации "network_protection_*" - используются для UI функции защиты сети
   • Экран "Защита сети" - показывает статистику безопасности, а не VPN соединение

3. КРИТИЧНО: Хотя в коде есть упоминания "Network Protection":
   • НЕТ NetworkExtension framework
   • НЕТ NEVPNManager API
   • НЕТ реального VPN соединения
   • Методы connect()/disconnect() - это заглушки, которые НЕ создают VPN туннель

4. Согласно Guideline 5.4, VPN-приложение должно использовать NEVPNManager API. ALADDIN НЕ использует этот API.
