## 🔧 ЧТО НУЖНО СДЕЛАТЬ:

### НА СЕРВЕРЕ (149.154.65.180):

**Вариант 1: Настроить роутинг в nginx**

Добавить в `/etc/nginx/sites-available/aladdin-ai.ru`:

```nginx
location = /privacy {
    return 301 /privacy.html;
}

location = /terms {
    return 301 /terms.html;
}
```

Или:

```nginx
location = /privacy {
    try_files /privacy.html =404;
}

location = /terms {
    try_files /terms.html =404;
}
```

**Вариант 2: Создать символические ссылки**

```bash
cd /var/www/aladdin-ai.ru
ln -s privacy.html privacy
ln -s terms.html terms
```

**Вариант 3: Скопировать файлы**

```bash
cd /var/www/aladdin-ai.ru
cp privacy.html privacy
cp terms.html terms
```
