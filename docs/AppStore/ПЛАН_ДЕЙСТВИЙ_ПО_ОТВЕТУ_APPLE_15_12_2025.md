2. **Тип аккаунта разработчика:**

## 🟡 ПРОБЛЕМА 2: GUIDELINE 2.1 - ОШИБКА ПРИ ПОДПИСКЕ

### Ситуация
При нажатии на кнопку подписки показывается сообщение об ошибке: "Продукты не загружены. Попытка перезагрузки..."

**Устройство проверки:** iPad Air 11-inch (M3), iPadOS 26.1

### Анализ кода

В `TariffsViewModel.swift` (строки 218-230):
```swift
if storeManager.products.isEmpty {
    errorMessage = "Продукты не загружены. Попытка перезагрузки..."
    await storeManager.loadProducts()
    
    guard !storeManager.products.isEmpty else {
        errorMessage = "Не удалось загрузить продукты. Проверьте подключение к интернету."
        return
    }
}
```

### Возможные причины

1. **Продукты не загружаются с App Store:**
   - Продукты не созданы в App Store Connect
   - Продукты созданы, но не отправлены на проверку
   - Bundle ID не совпадает
   - Product IDs не совпадают

2. **Проблема с iPad:**
   - StoreKit может работать по-другому на iPad
   - Проблема с версией iPadOS 26.1 (возможно, бета-версия?)
   - Проблема с Sandbox аккаунтом на iPad

3. **Проблема с загрузкой продуктов:**
   - `loadProducts()` вызывается, но не успевает загрузить до покупки
   - Проблема с сетью во время проверки
   - StoreKit недоступен

4. **Проблема с синхронизацией:**
   - Продукты загружаются асинхронно, но UI не ждет
   - Race condition между загрузкой и покупкой
