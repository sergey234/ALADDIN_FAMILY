### 2. Безопасное соединение Status Card (новая версия)

**Что оставить:**
- ✅ Только кнопка включить/выключить
- ✅ Небольшой размер карточки
- ✅ Ничего лишнего

**Что убрать:**
- ❌ Большая иконка щита
- ❌ Текст "Защищено" / "Не защищено"
- ❌ Описание "Соединение защищено"
- ❌ Все лишнее

**Как будет выглядеть:**
```
┌─────────────────────────────┐
│  Безопасное соединение      │
│                             │
│  [  Включить  ]             │
│  или                        │
│  [ Выключить ]              │
└─────────────────────────────┘
```

**Компактная карточка:**
- Заголовок: "Безопасное соединение"
- Toggle или кнопка: Включить/Выключить
- Минимальный размер

## 🎯 РЕКОМЕНДАЦИЯ: Вариант Б

**Почему:**
- ✅ Антивирус остается отдельной карточкой (как сейчас)
- ✅ Security Features Card показывает только функции безопасности
- ✅ Антивирус имеет свой функционал (проверка), поэтому логично отдельно

**Но можно и Вариант А** - если хотите объединить все функции безопасности в одну карточку.

### 6. Изменить карточки

#### Battery Saving Tip Card
- Заменить "VPN" на "Безопасное соединение"

#### Security Features Card
- Убрать "Шифрование"
- Оставить: Блокировка рекламы, Антитрекинг, Защита от угроз

---

### 7. Локализация

**Правило:** Заменять по 1 записи за раз, не массово

**Что заменять:**
- "VPN" → "Безопасное соединение"
- "VPN Protection" → "Secure Connection"
- И другие упоминания VPN

**Процесс:**
1. Найти одну строку с "VPN"
2. Заменить на "Безопасное соединение"
3. Проверить
4. Следующая строка
