# 🎁 ЧТО ТАКОЕ "ВВОДНЫЕ ПРЕДЛОЖЕНИЯ" В APP STORE CONNECT

**Дата:** 7 декабря 2025

---

## ❓ ЧТО ЭТО ТАКОЕ?

**Вводные предложения (Introductory Offers)** — это специальные предложения для новых подписчиков, которые позволяют:
- Предложить бесплатный пробный период
- Дать скидку на первые периоды подписки
- Привлечь новых пользователей

---

## 🎯 ТИПЫ ВВОДНЫХ ПРЕДЛОЖЕНИЙ

### 1. Бесплатный пробный период (Free Trial)
- Пользователь получает доступ бесплатно на определенное время
- После окончания пробного периода автоматически списывается полная цена
- Пример: "7 дней бесплатно, затем 290₽/месяц"

### 2. Скидка на определенный период (Discounted Price)
- Пользователь платит сниженную цену в течение установленного времени
- После окончания цена возвращается к стандартной
- Пример: "Первый месяц 50% скидка (145₽ вместо 290₽)"

### 3. Скидка на определенное количество периодов
- Пользователь получает скидку на несколько периодов подписки
- Пример: "Первые 3 месяца по 200₽, затем 290₽/месяц"

---

## ⚠️ ВАЖНО

### Это опциональная функция!

**Вводные предложения НЕ обязательны** для создания подписки. Это дополнительная опция для привлечения пользователей.

### Когда закончится вводное предложение:

- С пользователей **автоматически списывается полная цена**
- Если они не отменят подписку до окончания пробного периода/скидки
- Подписка автоматически продлевается по полной цене

---

## 🤔 НУЖНО ЛИ НАСТРАИВАТЬ ДЛЯ BASIC?

### Для Basic тарифа:

**НЕТ, не обязательно!**

Причины:
1. Basic уже бесплатный (или с минимальной ценой 1-15₽)
2. Вводное предложение имеет смысл для платных тарифов
3. Это опциональная функция

### Когда имеет смысл:

- Для платных тарифов (Individual, Family, Premium)
- Чтобы привлечь новых пользователей
- Чтобы дать возможность попробовать перед покупкой

---

## 📋 КОГДА ИСПОЛЬЗОВАТЬ

### Рекомендуется для:

✅ **Individual** (290₽/месяц):
- Бесплатный пробный период 7 дней
- Или скидка 50% на первый месяц

✅ **Family** (490₽/месяц):
- Бесплатный пробный период 7 дней
- Или скидка на первый месяц

✅ **Premium** (990₽/месяц):
- Бесплатный пробный период 7-14 дней
- Или значительная скидка на первый месяц

### Не обязательно для:

❌ **Basic** (бесплатный или 1-15₽):
- Уже бесплатный или минимальная цена
- Вводное предложение не имеет смысла

## ✅ ЧТО ДЕЛАТЬ СЕЙЧАС

### Для Basic:

1. **Пропустите "Вводные предложения"**
   - Это не обязательно
   - Basic уже бесплатный или с минимальной ценой

2. **Сосредоточьтесь на:**
   - Установке цены (минимальная 1-15₽)
   - Заполнении локализации (уже готово ✅)
   - Отправке на проверку

### Для других тарифов (позже):

Можно настроить вводные предложения для:
- Individual
- Family
- Premium

Это поможет привлечь больше пользователей.

## 🎯 ИТОГ

- Это опциональная функция
- Не обязательна для создания подписки
- Полезна для платных тарифов
- Не нужна для Basic (бесплатный тариф)

**Для вашего случая:**
- Пропустите настройку вводных предложений для Basic
