## 📋 ШАГ 4: РЕДАКТИРОВАНИЕ КОНФИГА

### 4.1. Открыть конфиг для редактирования

```bash
# Если файл называется aladdin-ai.ru
nano /etc/nginx/sites-available/aladdin-ai.ru

# Или
vim /etc/nginx/sites-available/aladdin-ai.ru
```

### 4.2. Найти блок server

Найдите блок который выглядит так:

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name aladdin-ai.ru www.aladdin-ai.ru;
    
    root /var/www/aladdin-ai.ru;
    index index.html;
    
    location / {
        try_files $uri $uri/ =404;
    }
}
```

### 4.3. Добавить location блоки

**Добавьте ПЕРЕД `location / {`:**

```nginx
# Редирект /privacy на privacy.html
location = /privacy {
    return 301 /privacy.html;
}

# Редирект /terms на terms.html
location = /terms {
    return 301 /terms.html;
}
```

**Полный пример:**

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name aladdin-ai.ru www.aladdin-ai.ru;
    
    root /var/www/aladdin-ai.ru;
    index index.html;
    
    # Редирект /privacy на privacy.html
    location = /privacy {
        return 301 /privacy.html;
    }
    
    # Редирект /terms на terms.html
    location = /terms {
        return 301 /terms.html;
    }
    
    location / {
        try_files $uri $uri/ =404;
    }
}
```

### 4.4. Если используете SSL (HTTPS)

**Найдите блок с `listen 443` и добавьте туда же:**

```nginx
server {
    listen 443 ssl;
    listen [::]:443 ssl;
    server_name aladdin-ai.ru www.aladdin-ai.ru;
    
    # SSL настройки...
    
    root /var/www/aladdin-ai.ru;
    index index.html;
    
    # Редирект /privacy на privacy.html
    location = /privacy {
        return 301 /privacy.html;
    }
    
    # Редирект /terms на terms.html
    location = /terms {
        return 301 /terms.html;
    }
    
    location / {
        try_files $uri $uri/ =404;
    }
}
```

### Проблема 2: "403 Forbidden"

**Решение:**
```bash
# Проверить права доступа
chmod 644 /var/www/aladdin-ai.ru/privacy.html

chown www-data:www-data /var/www/aladdin-ai.ru/privacy.html

```

### Проблема 3: "404 Not Found"

**Решение:**
- Проверить что файлы существуют: `ls -la /var/www/aladdin-ai.ru/privacy.html`
- Проверить путь в конфиге: `root /var/www/aladdin-ai.ru;`
- Проверить что файлы доступны: `cat /var/www/aladdin-ai.ru/privacy.html | head`

### Проблема 4: Редирект не работает

**Решение:**
- Проверить что location блоки добавлены ПЕРЕД `location / {`
- Проверить синтаксис: `nginx -t`
- Перезагрузить nginx: `systemctl reload nginx`
- Проверить логи: `tail -f /var/log/nginx/error.log`

### Проблема 5: "502 Bad Gateway"

**Решение:**
- Проверить что nginx запущен: `systemctl status nginx`
- Перезапустить nginx: `systemctl restart nginx`
- Проверить логи: `tail -f /var/log/nginx/error.log`
