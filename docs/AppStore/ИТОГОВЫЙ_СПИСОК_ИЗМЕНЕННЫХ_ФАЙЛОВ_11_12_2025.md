1. **App Store Guideline 5.4:** Apple не разрешает VPN приложения от индивидуальных разработчиков (только от организаций)
2. **Отклонение приложения:** Приложение было отклонено 3 раза из-за VPN функциональности
3. **Решение:** Применен вариант "Минимальные изменения" - код закомментирован, но не удален, чтобы можно было восстановить

## 🏗️ АРХИТЕКТУРА VPN ДО ИЗМЕНЕНИЙ

### Компоненты VPN системы:

1. **VPNManager.swift** (`Core/VPN/VPNManager.swift`)
   - Главный менеджер VPN соединений
   - Использует `NetworkExtension` framework
   - Управляет `NETunnelProviderManager`
   - Методы: `connect()`, `disconnect()`, `checkVPNStatus()`, `enableKillSwitch()`

2. **PacketTunnelProvider.swift** (`ALADDIN/ALADDINPacketTunnel/PacketTunnelProvider.swift`)
   - Network Extension для iOS
   - Наследуется от `NEPacketTunnelProvider`
   - Обрабатывает сетевые пакеты
   - Bundle ID: `family.aladdin.ios.packetTunnel`

3. **Target: ALADDINPacketTunnel**
   - Отдельный target в Xcode проекте
   - Тип: App Extension (Packet Tunnel Provider)
   - Связан с основным target через dependency

4. **Entitlements:**
   - `ALADDINPacketTunnel.entitlements` - содержит `com.apple.developer.networking.vpn.api`
   - `ALADDINPacketTunnelDebug.entitlements` - debug версия

5. **Info.plist:**
   - `ALADDIN/ALADDINPacketTunnel/Info.plist`
   - Содержит `NSExtensionPointIdentifier: com.apple.networkextension.packet-tunnel`

### Зависимости:

```
ALADDIN (main target)
  └── depends on → ALADDINPacketTunnel (extension target)
       └── uses → NetworkExtension framework
            └── requires → VPN capability in entitlements
```

       isConnecting = true
       connectionStatus = .connecting
       startTime = Date()
       
       prepareTunnelForConnection(server: server) { [weak self] manager in
           guard let self = self else { return }
           
           do {
               let options = self.makeTunnelOptions(for: server)
               try manager.connection.startVPNTunnel(options: options)
               self.log("Подключение к VPN через Packet Tunnel…")
               self.checkVPNStatus(server: server)
           } catch {
               self.log("Ошибка подключения: \(error.localizedDescription)")
               self.connectionStatus = .error(error.localizedDescription)
               self.isConnecting = false
           }
       }
   }
