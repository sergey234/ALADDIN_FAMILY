ЭТАП 1: ПРОВЕРИТЬ И ЗАПОЛНИТЬ НАЛОГОВУЮ ИНФОРМАЦИЮ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. App Store Connect → Agreements, Tax, and Banking
2. Откройте "Tax Information" (Налоговая информация)
3. Проверьте что заполнено:
   - [ ] Tax ID / ИНН
   - [ ] Страна налогообложения
   - [ ] Форма W-8BEN (для нерезидентов США) или другая
4. Если не заполнено → заполните и сохраните
5. После сохранения проверьте, появилось ли соглашение

ЭТАП 2: ПРОВЕРИТЬ И ЗАПОЛНИТЬ БАНКОВСКУЮ ИНФОРМАЦИЮ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. App Store Connect → Agreements, Tax, and Banking
2. Откройте "Banking Information" (Банковские реквизиты)
3. Проверьте что заполнено:
   - [ ] Название банка
   - [ ] Номер счета (IBAN или другой формат)
   - [ ] SWIFT/BIC код
   - [ ] Адрес банка
   - [ ] Валюта счета
4. Если не заполнено → заполните и сохраните
5. После сохранения проверьте, появилось ли соглашение

ЭТАП 3: ПРОВЕРИТЬ СТАТУС ПРОДУКТОВ IAP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. App Store Connect → My Apps → ALADDIN
2. Features → In-App Purchases
3. Проверьте все 3 продукта:
   - [ ] family.aladdin.ios.subscription.individual.v2
   - [ ] family.aladdin.ios.subscription.family
   - [ ] family.aladdin.ios.subscription.premium
4. Проверьте статус каждого продукта:
   - [ ] "Ready to Submit" (готов к отправке)
   - [ ] "Waiting for Review" (на проверке)
   - [ ] "Approved" (одобрен)
   - [ ] "Rejected" (отклонен) ← если так, нужно исправить
5. Если статус "Waiting for Review" → это нормально, нужно дождаться одобрения

ЭТАП 4: ПРОВЕРИТЬ BUNDLE ID
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. В Xcode:
   - Откройте ALADDIN.xcodeproj
   - Выберите Target "ALADDIN"
   - General → Bundle Identifier
   - Должно быть: family.aladdin.ios

2. В App Store Connect:
   - My Apps → ALADDIN → App Information
   - Bundle ID должен быть: family.aladdin.ios

3. Сравните:
   - Bundle ID в Xcode = Bundle ID в App Store Connect ✅
