### Шаг 3: Загрузить IPA (15-30 минут)
**Инструкция:** `docs/КАК_ОТПРАВИТЬ_В_APP_STORE.md`

- **Автоматически:** Через GitHub Actions workflow (если API ключи настроены)
- **Вручную:** Через Transporter или Xcode Organizer

**Проверка:**
- App Store Connect → TestFlight → Builds
- Статус: "Processing" → "Ready to Submit" (30-60 минут)

---

### Шаг 4: Отправить на ревью (10 минут)
**Что сделать:**
1. Проверить все метаданные
2. Выбрать билд (Ready to Submit)
3. Нажать "Submit for Review"
4. Подтвердить отправку
