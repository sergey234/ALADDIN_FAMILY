# ГДЕ НАЙТИ В APP STORE CONNECT - ПРОСТЫМ ЯЗЫКОМ

**Дата:** 12 декабря 2025

---

## 📱 КАК ЗАЙТИ В APP STORE CONNECT:

1. Откройте браузер
2. Зайдите на сайт: **https://appstoreconnect.apple.com**
3. Войдите со своим Apple ID
4. Выберите приложение **ALADDIN**

---

## 1️⃣ УДАЛИТЬ ФРАЗУ "Для России: оплата на сайте..."

### Где это находится:

1. В левом меню найдите раздел **"App Store"** (или "App Store" → "iOS App")
2. Нажмите на **"1.0 Prepare for Submission"** (или вашу текущую версию)
3. Прокрутите вниз до раздела **"What's New in This Version"** или **"Description"**
4. Найдите большое текстовое поле с описанием приложения
5. В этом тексте найдите фразу: **"Для России: оплата на сайте https://aladdin-ai.ru"**
6. **УДАЛИТЕ** эту фразу полностью
7. Нажмите **"Save"** (Сохранить) вверху справа

### Визуально:
```
App Store Connect
  └─ App Store (левое меню)
     └─ 1.0 Prepare for Submission
        └─ Description (большое текстовое поле)
           └─ [ЗДЕСЬ УДАЛИТЬ ФРАЗУ]
```

---

## 2️⃣ ДОБАВИТЬ PRIVACY POLICY URL

### Где это находится:

1. В левом меню найдите раздел **"App Information"** (или "Информация о приложении")
2. Прокрутите вниз до поля **"Privacy Policy URL"**
3. В это поле вставьте: **`https://aladdin-ai.ru/privacy_full.html`**
4. Нажмите **"Save"** (Сохранить)

### Визуально:
```
App Store Connect
  └─ App Information (левое меню)
     └─ Privacy Policy URL (поле для ввода)
        └─ [ВСТАВИТЬ: https://aladdin-ai.ru/privacy_full.html]
```

---

## 3️⃣ ДОБАВИТЬ TERMS OF USE URL

### Вариант 1: В Description (проще)

1. Вернитесь в раздел **"App Store"** → **"1.0 Prepare for Submission"**
2. Найдите поле **"Description"** (то же самое, где удаляли фразу)
3. В **КОНЦЕ** описания добавьте новую строку:
   ```
   Terms of Use: https://aladdin-ai.ru/privacy_full.html
   ```
4. Нажмите **"Save"**

### Вариант 2: В поле EULA (если есть)

1. В разделе **"App Information"** найдите поле **"EULA"** (End User License Agreement)
2. Если поле есть - выберите **"Custom EULA"** или добавьте URL
3. Вставьте: **`https://aladdin-ai.ru/privacy_full.html`**
4. Нажмите **"Save"**

### Визуально:
```
App Store Connect
  └─ App Store → 1.0 Prepare for Submission
     └─ Description (в КОНЦЕ текста добавить)
        └─ Terms of Use: https://aladdin-ai.ru/privacy_full.html
```

---

## 📋 ПОШАГОВЫЙ ПЛАН:

### Шаг 1: Удалить фразу (2 минуты)
1. App Store → 1.0 Prepare for Submission
2. Description → найти и удалить "Для России: оплата на сайте..."
3. Save

### Шаг 2: Добавить Privacy Policy URL (1 минута)
1. App Information (левое меню)
2. Privacy Policy URL → вставить URL
3. Save

### Шаг 3: Добавить Terms of Use URL (1 минута)
1. Вернуться в App Store → 1.0 Prepare for Submission
2. Description → в КОНЦЕ добавить "Terms of Use: https://..."
3. Save

---

## ⚠️ ВАЖНО:

- После каждого изменения нажимайте **"Save"**!
- Изменения сохраняются сразу, но могут не отображаться мгновенно
- Если не видите поле - прокрутите страницу вниз или проверьте другую вкладку
