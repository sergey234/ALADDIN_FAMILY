How do I submit a subscription for review? The first subscription needs to be 
submitted together with a new app version. Before submitting the app version 
for review, create the subscription and select it in the in-app purchases and 
subscriptions section on the app version page. After uploading the binary 
file and submitting the first subscription for review, you will be able to 
submit additional subscriptions for review from the corresponding section. 

Or do you receive all subscriptions when submitting the app? 

What does "Metadata missing" status mean? I think I've done everything.

❓ ОТВЕТ 1: КАК ОТПРАВИТЬ ПОДПИСКУ?
───────────────────────────────────────────────────────────────────────────────

✅ ПЕРВАЯ ПОДПИСКА (Premium) - ВМЕСТЕ С ВЕРСИЕЙ:

1. Откройте версию приложения (с Build 6)
2. Прокрутите вниз → "Встроенные покупки и подписки"
3. Нажмите "+" → Выберите Premium → "Готово"
4. Нажмите "Отправить на проверку"
5. Premium отправится АВТОМАТИЧЕСКИ вместе с версией

✅ ОСТАЛЬНЫЕ ПОДПИСКИ (Individual, Family, Basic) - ОТДЕЛЬНО:

ТОЛЬКО ПОСЛЕ одобрения Premium (1-3 дня):

1. Перейдите: "Функции" → "Подписки"
2. Откройте каждую подписку
3. Нажмите "Отправить на проверку" для каждой отдельно

───────────────────────────────────────────────────────────────────────────────
❓ ОТВЕТ 2: ПОЛУЧАЕТ ЛИ APPLE ВСЕ ПОДПИСКИ СРАЗУ?
───────────────────────────────────────────────────────────────────────────────

❌ НЕТ! Apple получает НЕ все подписки сразу.

✅ КАК ЭТО РАБОТАЕТ:

1. При первой отправке версии:
   → Вы выбираете ОДНУ подписку (Premium) в версии
   → Apple получает ТОЛЬКО Premium вместе с версией
   → Остальные подписки НЕ отправляются

2. После одобрения Premium:
   → Вы можете отправить остальные подписки ОТДЕЛЬНО
   → Каждую подписку нужно отправлять ПО ОТДЕЛЬНОСТИ
   → Они проверяются НЕЗАВИСИМО от версии

───────────────────────────────────────────────────────────────────────────────
❓ ОТВЕТ 3: ЧТО ЗНАЧИТ "МЕТАДАННЫЕ ОТСУТСТВУЮТ"?
───────────────────────────────────────────────────────────────────────────────

"Метаданные отсутствуют" = Apple не может найти ВСЕ необходимые данные

✅ ЧТО ДОЛЖНО БЫТЬ ЗАПОЛНЕНО:

1. ✅ Длительность подписки (1 месяц)
   → В настройках подписки → "Длительность подписки"

2. ✅ Цена (минимум 1-15₽)
   → В настройках подписки → "Цены на подписку"

3. ✅ Локализация (минимум английский)
   → В настройках подписки → "Локализация" → "Создать"
   → Заполните:
     • Отображаемое название
     • Описание подписки
   → Для каждого языка отдельно

4. ✅ Категория налогообложения
   → В настройках подписки → "Категория налогообложения"
   → Выберите: "В соответствии с основным приложением"

───────────────────────────────────────────────────────────────────────────────
🔍 КАК ПРОВЕРИТЬ, ЧТО ВСЕ ЗАПОЛНЕНО
───────────────────────────────────────────────────────────────────────────────

Для каждой подписки проверьте:

1. Откройте подписку: "Функции" → "Подписки" → Выберите подписку

2. Проверьте разделы:
   □ Длительность: "1 месяц" ✅
   □ Цена: Установлена ✅
   □ Локализация (английский):
     □ Название заполнено ✅
     □ Описание заполнено ✅
   □ Локализация (русский):
     □ Название заполнено ✅
     □ Описание заполнено ✅
   □ Категория налогообложения: Выбрана ✅

3. Сохраните изменения после каждого заполнения

4. Обновите страницу (F5) через 1-2 минуты

───────────────────────────────────────────────────────────────────────────────
🚨 ЕСЛИ СТАТУС ВСЕ ЕЩЕ "МЕТАДАННЫЕ ОТСУТСТВУЮТ"
───────────────────────────────────────────────────────────────────────────────

1. Проверьте КАЖДЫЙ раздел (см. выше)
2. Убедитесь, что ВСЕ поля заполнены
3. Нажмите "Сохранить" после каждого изменения
4. Подождите 5-10 минут
5. Обновите страницу (F5)
6. Проверьте статус снова

💡 КРАТКИЕ ОТВЕТЫ
───────────────────────────────────────────────────────────────────────────────

1. Как отправить?
   → Premium: выбрать в версии → отправить версию
   → Остальные: после одобрения → отправить отдельно

2. Получает ли Apple все сразу?
   → НЕТ, только Premium при первой отправке
   → Остальные отправляются отдельно после одобрения

3. Что значит "Метаданные отсутствуют"?
   → Не все обязательные поля заполнены
   → Нужно заполнить: длительность, цену, локализацию, категорию
