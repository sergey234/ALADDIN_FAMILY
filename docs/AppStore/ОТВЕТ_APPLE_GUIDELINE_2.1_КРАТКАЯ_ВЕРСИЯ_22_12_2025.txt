1. КАКИЕ ИНСТРУМЕНТЫ, УТИЛИТЫ, ФРЕЙМВОРКИ ИЛИ API ИСПОЛЬЗУЮТСЯ?

Функции безопасности:
• LocalAuthentication (iOS) - Биометрическая аутентификация (Face ID/Touch ID). Данные обрабатываются только на устройстве.
• CryptoKit (iOS) - Локальное шифрование данных (AES-256-GCM). Данные шифруются локально.
• Security framework (iOS) - Keychain Services для безопасного хранения токенов. Данные хранятся только локально.
• URLSession (iOS) - Сетевые запросы через HTTPS/TLS 1.2+ для коммуникации с backend.
• Alamofire (v5.8) - HTTP клиент. Не собирает пользовательские данные.
• KeychainAccess (v4.2) - Обертка для Keychain. Не собирает пользовательские данные.

Функции родительского контроля:
• SwiftUI (iOS) - Пользовательский интерфейс.
• UserDefaults (iOS) - Локальное хранение настроек родительского контроля.
• Combine (iOS) - Управление состоянием.
• Custom REST API - Собственный backend сервер для получения данных о семье и статистики.

ВАЖНО: НЕ используется NetworkExtension (VPN удален), НЕ используется ScreenTime framework.

2. СОБИРАЕТ ЛИ ПРИЛОЖЕНИЕ, ХРАНИТ ИЛИ ПЕРЕДАЕТ ПОЛЬЗОВАТЕЛЬСКИЕ ДАННЫЕ?

ДА, приложение собирает, хранит и передает ОБЕЗЛИЧЕННЫЕ данные для обеспечения безопасности.

Что собирается:
• Анонимные идентификаторы (User ID, Device ID, Family ID)
• Технические данные (тип устройства, версия iOS, версия приложения)
• Статистика безопасности (обезличенная: количество угроз, тип угрозы, без деталей)
• Статистика использования функций (вкл/выкл защиты, использование родительского контроля)

Что НЕ собирается:
• Имена, фамилии, даты рождения, адреса, телефоны, email
• Паспортные данные, СНИЛС, ИНН
• Финансовые и медицинские данные
• История посещений сайтов, содержимое сообщений, пароли
• Геолокация (отключена)

Где хранятся:
• Локально: UserDefaults, Keychain (зашифровано), локальная память
• На сервере: Обезличенная статистика на backend сервере (Россия)

Передача: Только через HTTPS/TLS 1.2+, данные обезличиваются перед передачей.

3. КАКИЕ ДАННЫЕ СОБИРАЮТСЯ, КАК ИСПОЛЬЗУЮТСЯ И ПЕРЕДАЮТСЯ ЛИ С УСТРОЙСТВА?

Детальный список:

1. Данные регистрации (анонимные):
   • Роль в семье, возрастная группа
   • Использование: Настройка интерфейса и функций
   • Передача: Да, в обезличенном виде

2. Технические данные устройства:
   • Тип устройства, модель, версия iOS
   • Использование: Совместимость и улучшение работы
   • Передача: Да, для технической поддержки

3. Статистика угроз (обезличенная):
   • Количество угроз, тип угрозы (категория), время обнаружения
   • Использование: Отображение статистики и улучшение защиты
   • Передача: Да, в агрегированном виде (без деталей о сайтах/приложениях)

4. Статистика использования функций:
   • Использование защиты сети, родительского контроля, AI помощника
   • Использование: Улучшение функциональности
   • Передача: Да, в обезличенном виде

5. Токены доступа:
   • JWT токены для авторизации
   • Использование: Аутентификация при запросах к API
   • Передача: Да, при каждом запросе (стандартная практика)
   • Хранение: Локально в Keychain (зашифровано)

6. Настройки приложения:
   • Настройки безопасности, родительского контроля, языка
   • Использование: Сохранение пользовательских предпочтений
   • Передача: НЕТ, хранятся только локально

7. Биометрические данные:
   • Face ID / Touch ID
   • Использование: Локальная аутентификация
   • Передача: НЕТ, обрабатываются только локально в Secure Enclave

Процесс: Сбор → Обезличивание → Шифрование → Передача (HTTPS) → Хранение на сервере

6. КАКОВЫ ПОЛИТИКИ ХРАНЕНИЯ ДАННЫХ И ГДЕ ЗАДОКУМЕНТИРОВАНЫ?

Политики хранения:

Локальные данные (на устройстве):
• Настройки: До удаления приложения
• Токены: В Keychain до удаления приложения или выхода
• Ключи шифрования: В Keychain до удаления приложения
• Кэш: Очищается автоматически при нехватке места

Данные на сервере:
• Анонимные ID сессий: 24 часа
• Статистика угроз: 30 дней (обезличенная)
• Агрегированная аналитика: 1 год
• Технические логи: 7 дней

Удаление данных:
• При удалении аккаунта все данные удаляются в течение 30 дней
• Локальные данные удаляются немедленно при удалении приложения
• Пользователь может запросить удаление данных через обращение в поддержку (контакты указаны в политике конфиденциальности)

Где задокументировано:
• В приложении: Настройки → Политика конфиденциальности → Раздел "Сроки хранения данных"
• В политике конфиденциальности: Полная информация о политике хранения и процедуре удаления данных
