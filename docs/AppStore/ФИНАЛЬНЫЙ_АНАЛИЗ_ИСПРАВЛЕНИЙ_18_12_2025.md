## 🧪 КАК ПРОТЕСТИРОВАТЬ БЕЗ РЕАЛЬНОГО IPAD

### Ограничения симулятора:
- ❌ StoreKit не работает в симуляторе (покупки не проходят)
- ✅ Но можно проверить логирование и обработку ошибок

### Что можно проверить:

1. **Логирование устройства:**
   ```bash
   # Запустить на iPad симуляторе
   xcrun simctl boot "iPad Air (3rd generation)"
   
   # Смотреть логи
   xcrun simctl spawn booted log stream --predicate 'processImagePath contains "ALADDIN"'
   ```

2. **UI адаптация:**
   - Проверить что интерфейс правильно отображается на iPad
   - Проверить что кнопки и элементы доступны

3. **Обработка ошибок:**
   - Проверить что ошибки правильно обрабатываются
   - Проверить что сообщения об ошибках показываются

**Команды для тестирования:**
```bash
# 1. Запустить симулятор iPad
xcrun simctl boot "iPad Air (3rd generation)"
open -a Simulator

# 2. Собрать приложение
xcodebuild -project ALADDIN.xcodeproj \
  -scheme ALADDIN \
  -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,name=iPad Air (3rd generation)' \
  build

# 3. Установить и запустить
APP_PATH=$(find ~/Library/Developer/Xcode/DerivedData/ALADDIN-*/Build/Products/Debug-iphonesimulator -name "ALADDIN.app" | head -1)
xcrun simctl install booted "$APP_PATH"
xcrun simctl launch booted family.aladdin.ios

# 4. Смотреть логи
xcrun simctl spawn booted log stream \
  --predicate 'processImagePath contains "ALADDIN"' \
  | grep -E "StoreManager|iPad|error|🔍|❌|⚠️"
```

## 📝 ПРО МЕТАДАННЫЕ В APP STORE CONNECT

### Что говорит Apple (Guideline 5.4):
> "Your VPN app was submitted by an Apple Developer Program account registered to an individual."

**Это значит:**
- Apple считает приложение VPN приложением
- Это может быть из-за метаданных в App Store Connect

**Где проверить (НЕ в коде, а в App Store Connect):**
1. **App Information** → Название приложения
2. **App Information** → Описание приложения  
3. **App Information** → Ключевые слова
4. **App Store** → Скриншоты
5. **App Store** → Категории

**В коде (Info.plist):**
- ✅ Проверено: Нет упоминаний VPN
- ✅ `CFBundleDisplayName` = "ALADDIN X AI" (без VPN)

**Действия:**
1. Войти в App Store Connect (https://appstoreconnect.apple.com)
2. Перейти в "App Information"
3. Проверить все поля на упоминания VPN
4. Удалить все упоминания VPN

## 🖼️ ПРО ПРОМО-ИЗОБРАЖЕНИЯ IAP

### Что говорит Apple (Guideline 2.3.2):
> "Your promotional image is a screenshot taken from your app. Your promotional image includes text that is small or otherwise hard to read."

**Проблемы:**
1. ❌ **Скриншот из приложения** - нельзя использовать скриншоты
2. ❌ **Маленький текст** - текст должен быть читаемым (минимум 20pt)

**Требования:**
- ✅ НЕ скриншот
- ✅ Уникальное изображение
- ✅ Текст читаемый (минимум 20pt)
- ✅ Размер: 1024x1024 пикселей
- ✅ Формат: PNG или JPEG

**Что должно быть на изображении:**
- Название тарифа (крупным шрифтом, 40-60pt)
- Основные функции (20-24pt)
- Визуальные элементы (иконки, графика)
- Цветовая схема приложения

**Где загрузить:**
- App Store Connect → In-App Purchases → каждый тариф → промо-изображение

**Нужно создать для:**
1. FREE - Бесплатный тариф
2. BASIC - Базовый тариф
3. INDIVIDUAL - Индивидуальный тариф
4. FAMILY - Семейный тариф
5. PREMIUM - Премиум тариф
