## 🎯 ЧТО МЫ ДЕЛАЕМ

## 📋 ШАГ 1: ВОЙТИ В APP STORE CONNECT

### 1.1 Откройте App Store Connect

1. **Откройте браузер** (Safari, Chrome, Firefox)
2. **Перейдите по адресу:** https://appstoreconnect.apple.com
3. **Войдите в свой аккаунт:**
   - Введите Apple ID
   - Введите пароль
   - Пройдите двухфакторную аутентификацию (если требуется)

### 1.2 Выберите приложение

1. **На главной странице** вы увидите список приложений
2. **Найдите приложение "ALADDIN"**
3. **Нажмите на название приложения** (кликните на него)

---

## 📋 ШАГ 2: ПЕРЕЙТИ В РАЗДЕЛ "ВЕРСИИ ПРИЛОЖЕНИЯ"

### 2.1 Найдите меню слева

После того, как вы открыли приложение, слева будет меню:

```
📱 ALADDIN
├── 📊 Обзор
├── 📝 Версии приложения  ← НАЖМИТЕ СЮДА!
├── 💰 Функции
├── 📈 Аналитика
└── ...
```

### 2.2 Нажмите "Версии приложения"

1. **В левом меню** найдите пункт **"Версии приложения"**
   - На английском: **"App Versions"**
   - На русском: **"Версии приложения"**

2. **Кликните на этот пункт**

3. Вы увидите страницу с версиями приложения

---

## 📋 ШАГ 3: НАЙТИ И ОТКРЫТЬ ВЕРСИЮ С BUILD 6

### 3.1 Найдите версию с build 6

На странице "Версии приложения" вы увидите:

- **Версия 1.0** (или другая версия)
- **Build:** 6 ← Это ваш загруженный build

### 3.2 Откройте версию

1. **Найдите версию**, которая использует build 6
2. **Нажмите на эту версию** (кликните на нее)
3. Откроется страница редактирования версии

---

## 📋 ШАГ 4: НАЙТИ РАЗДЕЛ "ВСТРОЕННЫЕ ПОКУПКИ И ПОДПИСКИ"

### 4.1 Прокрутите страницу вниз

На странице версии много разделов:
- Скриншоты
- Описание
- Ключевые слова
- И т.д.

**Прокрутите страницу вниз**, пока не найдете раздел:

### 4.2 Найдите раздел "Встроенные покупки и подписки"

Ищите раздел с названием:
- **"Встроенные покупки и подписки"** (русский)
- **"In-App Purchases and Subscriptions"** (английский)

**Где он находится:**
- Обычно внизу страницы
- После раздела "Информация о приложении"
- Перед кнопкой "Отправить на проверку"

## 📋 ШАГ 5: ДОБАВИТЬ ПОДПИСКУ PREMIUM

### 5.1 Найдите кнопку добавления

В разделе "Встроенные покупки и подписки" вы увидите:

```
┌─────────────────────────────────────────┐
│ Встроенные покупки и подписки          │
│                                         │
│ [  ] Нет выбранных подписок            │
│                                         │
│ [+ Добавить]  ← НАЖМИТЕ СЮДА!          │
└─────────────────────────────────────────┘
```

### 5.2 Нажмите кнопку "+" или "Добавить"

1. **Найдите кнопку:**
   - **"+"** (плюс)
   - **"Добавить"** (Add)
   - **"Добавить подписку"** (Add Subscription)

2. **Нажмите на эту кнопку**

3. Откроется окно или список с доступными подписками

### 5.3 Выберите подписку Premium

В открывшемся списке вы увидите подписки:

```
┌─────────────────────────────────────────┐
│ Выберите подписку:                     │
│                                         │
│ ☐ ALADDIN Базовый                      │
│   (family.aladdin.ios.subscription...  │
│                                         │
│ ☐ ALADDIN Личный                       │
│   (family.aladdin.ios.subscription...  │
│                                         │
│ ☐ ALADDIN Семейный                     │
│   (family.aladdin.ios.subscription...  │
│                                         │
│ ☑ ALADDIN Премиум  ← ВЫБЕРИТЕ ЭТУ!    │
│   (family.aladdin.ios.subscription...  │
│                                         │
│ [Отмена]  [Готово]  ← НАЖМИТЕ "Готово" │
└─────────────────────────────────────────┘
```

**Что делать:**
1. **Найдите "ALADDIN Премиум"** в списке
   - Product ID: `family.aladdin.ios.subscription.premium`
2. **Поставьте галочку** (чекбокс) рядом с Premium
   - Кликните на чекбокс или на название подписки
3. **Нажмите кнопку "Готово"** (Done) или "Сохранить" (Save)

### 5.4 Проверьте, что Premium выбрана

После выбора вы должны увидеть:

```
┌─────────────────────────────────────────┐
│ Встроенные покупки и подписки          │
│                                         │
│ ☑ ALADDIN Премиум                      │
│   family.aladdin.ios.subscription...    │
│                                         │
│ [+ Добавить]                            │
└─────────────────────────────────────────┘
```

**Если видите Premium в списке** — значит, все правильно! ✅

## 📋 ШАГ 6: ПРОВЕРИТЬ СТАТУС БИНАРНОГО ФАЙЛА

### 6.1 Найдите раздел "Бинарный файл"

На странице версии найдите раздел:
- **"Бинарный файл"** (Binary File)
- **"Build"** (Сборка)

### 6.2 Проверьте статус

Вы должны увидеть что-то вроде:

```
┌─────────────────────────────────────────┐
│ Бинарный файл                           │
│                                         │
│ Build 6                                 │
│ Статус: ✅ Готово к отправке           │
│                                         │
│ [Выбрать другой build]                  │
└─────────────────────────────────────────┘
```

**Важно:** Статус должен быть:
- ✅ **"Готово"** (Ready)
- ✅ **"Готово к отправке"** (Ready to Submit)
- ✅ **"Обработано"** (Processed)

**Если статус:**
- ⏳ **"Обрабатывается"** (Processing) — подождите 10-30 минут
- ❌ **"Ошибка"** (Error) — нужно загрузить build заново

## 📋 ШАГ 7: ПРОВЕРИТЬ ВСЕ ОБЯЗАТЕЛЬНЫЕ ПОЛЯ

### 7.1 Прокрутите страницу и проверьте

Перед отправкой убедитесь, что заполнены:

- [ ] **Скриншоты приложения** (минимум 1 для iPhone)
- [ ] **Описание приложения** (на русском и/или английском)
- [ ] **Ключевые слова** (если требуется)
- [ ] **Категория приложения**
- [ ] **Контактная информация**
- [ ] **Информация о конфиденциальности**
- [ ] **Подписка Premium выбрана** ✅

### 7.2 Если что-то не заполнено

1. **Заполните недостающие поля**
2. **Нажмите "Сохранить"** (Save) в правом верхнем углу
3. **Подождите сохранения** (обычно несколько секунд)

## 📋 ШАГ 8: ОТПРАВИТЬ НА ПРОВЕРКУ

### 8.1 Найдите кнопку "Отправить на проверку"

**Где искать:**
- **В правом верхнем углу** страницы
- **Внизу страницы** (после всех разделов)
- **В правой боковой панели** (если есть)

**Как выглядит кнопка:**
- **"Отправить на проверку"** (русский)

### 8.2 Нажмите кнопку

1. **Найдите кнопку "Отправить на проверку"**
2. **Нажмите на нее**

### 8.3 Подтвердите отправку

Появится окно подтверждения:

```
┌─────────────────────────────────────────┐
```

После нажатия:
- Статус изменится на **"Ожидает проверки"** (Waiting for Review)

## ⏱️ СРОКИ ПРОВЕРКИ

### Обычные сроки:

- **Обработка бинарного файла:** 10-30 минут (уже прошло, если build загружен)
- **Проверка Apple:** 1-3 дня (после отправки)

### Что происходит:

1. **День 1:** Apple получает вашу заявку
2. **День 1-2:** Начало проверки
3. **День 2-3:** Завершение проверки
4. **Результат:** Одобрено или требуется доработка

## 🚨 ЧТО ДЕЛАТЬ, ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Проблема 1: Не вижу кнопку "Отправить на проверку"

**Причины:**
- Не все обязательные поля заполнены
- Бинарный файл еще обрабатывается
- Подписка не выбрана

**Решение:**
1. Проверьте все обязательные поля
2. Дождитесь обработки бинарного файла
3. Убедитесь, что Premium выбрана

### Проблема 2: Не могу выбрать подписку Premium

**Причины:**
- Подписка не создана в App Store Connect
- Подписка не сохранена
- Не все поля подписки заполнены

**Решение:**
1. Перейдите в "Функции" → "Подписки"
2. Найдите Premium
3. Убедитесь, что все поля заполнены
4. Сохраните подписку
5. Вернитесь в версию и попробуйте снова

### Проблема 3: Бинарный файл не обработан

**Причины:**
- Загрузка еще не завершена
- Ошибка при обработке

**Решение:**
1. Подождите 30-60 минут
2. Обновите страницу (F5 или Cmd+R)
3. Если ошибка — загрузите build заново

### Проблема 4: Кнопка неактивна (серая)

**Причины:**
- Не все обязательные поля заполнены
- Есть ошибки в данных

**Решение:**
1. Прокрутите страницу вверх
2. Найдите поля с красными предупреждениями
3. Заполните их
4. Сохраните изменения
