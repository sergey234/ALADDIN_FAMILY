## ⚠️ ВАЖНЫЕ ПРИМЕЧАНИЯ

1. **По одному изменению за раз:** Каждое изменение делается отдельно, с проверкой после каждого шага
2. **Проверка после каждого шага:** После каждого изменения проверяем компиляцию и работу приложения
3. **Русский + Английский:** Каждое изменение делается в двух локализациях (русский и английский)
4. **Отсутствующие ключи:** Некоторые английские ключи могут отсутствовать - их нужно будет добавить
5. **Где используется:** Для каждого ключа указано, где он используется в коде
