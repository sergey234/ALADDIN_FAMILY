## ✅ ЧТО НУЖНО СДЕЛАТЬ

### 1. Создать изображения BASIC:

- [ ] `basic_en_1024x1024.png` (английская версия)
- [ ] `basic_ru_1024x1024.png` (русская версия)

**Требования:**
- Размер: 1024x1024 пикселей
- Формат: PNG
- Не скриншот из приложения
- Текст читаемый (минимум 20pt)
- Заголовок крупный (40-60pt)

**Содержание:**
- Заголовок: "BASIC" / "БАЗОВЫЙ"
- Подзаголовок: "For one user" / "Для одного пользователя"
- Функции: 3 основных пункта (см. выше)

### 2. Загрузить в App Store Connect:

- [ ] App Store Connect → My Apps → Ваше приложение
- [ ] Features → In-App Purchases
- [ ] Для каждого тарифа (BASIC, INDIVIDUAL, FAMILY, PREMIUM):
  - [ ] Открыть тариф
  - [ ] Раздел "Promotional Image"
  - [ ] Загрузить соответствующее изображение 1024x1024

### 3. Проверить соответствие требованиям:

- [ ] Все изображения не скриншоты
- [ ] Текст читаемый (минимум 20pt)
- [ ] Заголовки крупные (40-60pt)
- [ ] Уникальный дизайн для каждого тарифа
- [ ] Размер точно 1024x1024
