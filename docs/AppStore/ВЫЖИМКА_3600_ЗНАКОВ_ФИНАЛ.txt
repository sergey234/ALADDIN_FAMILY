Спасибо за ваш запрос. Мы обеспечиваем функции безопасности и родительского контроля, используя стандартные iOS API и наш серверный backend, без использования NEVPNManager API, Screen Time API или PermissionKit framework.

ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ - СТАНДАРТНЫЕ iOS API

Функции безопасности:

LocalAuthentication (стандартный iOS API). Файл: Core/Security/SecurityManager.swift. Биометрическая аутентификация (Face ID/Touch ID). Пример: Пользователь открывает приложение, система запрашивает биометрию через LocalAuthentication, данные обрабатываются только на устройстве, никогда не передаются. Стандартный API, не требует специальных разрешений.

CryptoKit (стандартный iOS API). Файл: Core/Security/SecurityManager.swift. Локальное шифрование данных (AES-256-GCM). Пример: Пользовательские данные шифруются локально на устройстве, ключи хранятся в Keychain, зашифрованные данные могут быть отправлены на backend, но ключи никогда не покидают устройство.

Security framework (Keychain Services). Файл: Core/Security/SecurityManager.swift. Безопасное хранение токенов, паролей, ключей. Пример: Приложение сохраняет токены в Keychain через Security framework, Keychain обеспечивает аппаратную защиту (Secure Enclave), данные доступны только приложению и его расширениям через App Groups.

URLSession (стандартный iOS API). Файл: Core/Network/NetworkManager.swift. HTTPS коммуникация с backend, SSL Pinning для валидации сертификатов. Пример: Приложение устанавливает HTTPS соединение через URLSession, SSL Pinning проверяет сертификат, все данные передаются через TLS 1.2+, backend получает только обезличенные метаданные (URL, домены, типы контента). Стандартный API, нет VPN функциональности.

SafariServices (SFContentBlockerManager). Файл: Core/ContentBlocker/ContentBlockerManager.swift, Extension: ALADDINContentBlocker/ActionRequestHandler.swift. Блокировка нежелательного контента в Safari. Пример: Родитель настраивает категории блокировки в приложении, приложение создает JSON правила согласно стандарту Apple Content Blocker, правила сохраняются в App Group, SFContentBlockerManager активирует Extension, когда ребенок открывает Safari и пытается зайти на заблокированный сайт, Safari автоматически блокирует его, ребенок видит страницу "Сайт заблокирован". Стандартный iOS API, работает только в Safari.

Backend анализ безопасности. Файл: Core/Network/APIService.swift, Endpoints: /protection/*, /analytics/threats. Пример: Приложение отправляет обезличенные метаданные на backend сервер, backend анализирует с использованием AI/ML на сервере, определяет потенциальные угрозы (мошеннические сайты, фишинг, вредоносный контент), результаты возвращаются как рекомендации и оповещения, пользователь получает уведомление о потенциальной угрозе для всей семьи, пользователь принимает обоснованное решение на основе рекомендаций. НЕТ блокировки или принудительного применения на системном уровне - мы предоставляем только рекомендации.
