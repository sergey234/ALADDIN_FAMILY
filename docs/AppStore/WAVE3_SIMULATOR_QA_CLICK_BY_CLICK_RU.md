## 2. Старт в симуляторе

1. Xcode → открыть **`ALADDIN.xcodeproj`** (не старый workspace).  
2. Scheme **ALADDIN** · iPhone 15/16 Simulator.  
3. Run (▶).  
4. Войти как **родитель** тестовой семьи (или создать семью).  
5. Внизу таб **Семья** (Family).

Дальше все пути от экрана **Семья**.

---

## 3. Экранное время (ST / A0–A3) — симулятор

| # | Куда жать | Что увидеть / ОК |
|---|-----------|------------------|
| 1 | Таб **Семья** | Список семьи / карточки |
| 2 | Карточка **ребёнка** (или блок родительского контроля) | Открывается деталь |
| 3 | Строка **«Экранное время»** | Открывается sheet настроек |
| 4 | Кнопка настройки / **Screen Time** | Может запросить Family Controls / экранное время Apple |
| 5 | Лимит (если UI даёт) → Save | Честный текст: лимит применяется через систему, не «фейковые минуты» |

**Симулятор:** Family Controls часто **не полноценны** (нет реального Shield / минут с ребёнка).  
Ок для сима: экран открывается, нет crash, нет сырых ключей локализации (`family_screen_time_…`).  
Полный A0/A2 — **только 2 iPhone**.

## 4. Фильтр контента Safari + честность system (F3)

| # | Куда жать | Что увидеть |
|---|-----------|-------------|
| 1 | **Семья** → блок фильтров / **блокировка контента** (тумблер + шестерёнка) | Modal Content Block |
| 2 | Прочитать текст честности | Должно быть про **Safari (Content Blocker)** |
| 3 | Если флаг system filter on | Текст про **системный фильтр (не VPN)** — «доступен / готовится» без обещания VPN |

**Симулятор:** Safari Content Blocker можно включить в Settings → Safari → Extensions (если appex установлен).  
Полный **NE Content Filter** для всех приложений — **не проверить на симе** как на device; смотрим только UI-честность.

## 5. Места семьи / геозоны (L*)

| # | Куда жать | Что увидеть |
|---|-----------|-------------|
| 1 | **Семья** → строка **«Места семьи»** / геозоны | Sheet **Места семьи** |
| 2 | Если первый раз → **«Понятно, включить»** (согласие) | Consent принят |
| 3 | Взрослый: тумблер **«Мои места для семьи»** | Opt-in без слова «следить» |
| 4 | **Добавить место** / пустой стейт | Форма адреса или **«Моя точка»** |
| 5 | Сохранить дом с реальной точкой | Статус: мониторинг / нужно Always |
| 6 | Если просит Always → **«Разрешить Всегда»** / Settings | В симе: Settings → Privacy → Location → ALADDIN → Always |

**Симулятор:** enter/exit пуши часто **не работают** как на улице. Проверяем: UI, согласие, нет demo-адреса, нет crash.  
Walk-test enter/exit — **на улице с iPhone**.

## 6. Срочный сигнал семье (G)

Путь A — из **Мест семьи** (тот же sheet):

| # | Куда жать | Что увидеть |
|---|-----------|-------------|
| 1 | **Семья** → **Места семьи** | Sheet |
| 2 | Тумблер **«Срочный сигнал семье»** → Вкл | Согласие / Health/Motion может спросить |
| 3 | **«Отправить сигнал сейчас»** | Тост/статус «Сигнал отправлен семье» |
| 4 | Открыть **семейный чат / ленту** | Сообщение вида «🆘 Срочный сигнал…» |

Путь B — кнопка **«Нужна помощь»** (если видна на Family / emergency):

| # | Куда жать | Ок |
|---|-----------|-----|
| 1 | **Нужна помощь** → подтвердить | Сигнал уходит семье |

**Симулятор:** ручная кнопка — да. Падение HealthKit — часто нет; motion на симе ограничен.

## 7. Shield Action «Спросить родителя» (B)

| На симе | На 2 iPhone |
|---------|-------------|
| Target есть, UI кода есть | Ребёнок упирается в Shield → **Ask Parent** / Close |
| На симе Shield обычно **не всплывает** | Родитель видит local banner / уведомление |

**Симулятор:** пункт можно **пропустить** или только убедиться, что сборка не падает. Полный тест — device.
