# 📋 ЧТО ТАКОЕ "МЕТАДАННЫЕ ОТСУТСТВУЮТ" В APP STORE CONNECT

**Дата:** 7 декабря 2025

---

## ❓ ЧТО ЭТО ЗНАЧИТ?

**Статус "Метаданные отсутствуют"** означает, что для вашей подписки не заполнены обязательные метаданные.

Без этой информации подписка **не может быть отправлена на проверку** и опубликована в App Store.

---

## 📝 ЧТО НУЖНО ЗАПОЛНИТЬ?

### Обязательные метаданные:

1. **Продолжительность подписки** (Duration)
   - Например: 1 месяц, 1 год
   - Это уже должно быть заполнено

2. **Цена подписки** (Price)
   - Нужно добавить цену для каждого региона
   - Для бесплатной подписки: выбрать "Бесплатно" (Free)

3. **Локализация** (Localization)
   - Отображаемое название (Display Name)
   - Описание подписки (Description)
   - Минимум: русский и английский языки

4. **Информация для проверки** (Review Information)
   - Снимок экрана (опционально)
   - Примечания к проверке (опционально)

---

## ✅ КАК ИСПРАВИТЬ?

### Шаг 1: Перейти к подписке

1. Войдите в App Store Connect
2. Выберите ваше приложение
3. Перейдите в раздел **"Функции"** → **"Подписки"**
4. Выберите подписку со статусом "Метаданные отсутствуют"

### Шаг 2: Заполнить цену

1. Найдите раздел **"Цены на подписку"** (Pricing)
2. Нажмите **"Добавить цену подписки"** (Add Subscription Price)
3. Для бесплатной подписки:
   - Выберите **"Бесплатно"** (Free) или минимальную цену
   - Или установите цену 0 для всех регионов

### Шаг 3: Заполнить локализацию

1. Найдите раздел **"Локализация"** (Localization)
2. Нажмите **"Создать"** (Create) или выберите язык
3. Заполните:
   - **Отображаемое название:** Например, "ALADDIN Базовый"
   - **Описание подписки:** Например, "1 устройство, активная базовая защита. Блокировка сайтов."

4. Повторите для всех языков (минимум: русский и английский)

### Шаг 4: Проверить статус

После заполнения всех обязательных полей:
- Статус должен измениться на **"Готово к отправке"** (Ready to Submit)
- Или **"Подготовка к отправке"** (Preparing for Submission)

---

## 🎯 ДЛЯ ВАШЕГО СЛУЧАЯ (BASIC)

### Что нужно заполнить для Basic:

1. **Цена:**
   - Выбрать "Бесплатно" (Free) или установить 0₽

2. **Локализация (русский):**
   - Отображаемое название: `ALADDIN Базовый`
   - Описание: `1 устройство, активная базовая защита. Блокировка сайтов.`

3. **Локализация (английский):**
   - Display Name: `ALADDIN Basic`
   - Description: `1 device, active basic protection. Website blocking.`

- Минимум нужны локализации для русского и английского языков
