## 📋 КОМАНДЫ ДЛЯ ВЫПОЛНЕНИЯ НА СЕРВЕРЕ

После подключения выполните:

```bash
# 1. Проверить файлы
ls -la /var/www/aladdin-ai.ru/privacy.html
ls -la /var/www/aladdin-ai.ru/terms.html

# 2. Создать резервную копию
sudo cp /etc/nginx/sites-available/aladdin-ai.ru /etc/nginx/sites-available/aladdin-ai.ru.backup.$(date +%Y%m%d_%H%M%S)

# 3. Открыть конфиг
sudo nano /etc/nginx/sites-available/aladdin-ai.ru

# 4. Найти блок server { ... } и добавить ПЕРЕД location / { :
#    location = /privacy {
#        return 301 /privacy.html;
#    }
#    location = /terms {
#        return 301 /terms.html;
#    }

# 5. Сохранить (Ctrl+O, Enter, Ctrl+X)

# 6. Проверить синтаксис
sudo nginx -t

# 7. Перезагрузить nginx
sudo systemctl reload nginx

# 8. Проверить работу
curl -I https://aladdin-ai.ru/privacy
curl -I https://aladdin-ai.ru/terms
```

## 🚀 АВТОМАТИЧЕСКИЙ СКРИПТ

Если хотите автоматизировать, скопируйте файл `команды_для_сервера.sh` на сервер и выполните:

```bash
# На локальном компьютере
scp docs/AppStore/команды_для_сервера.sh sergio675@149.154.65.180:/tmp/

# На сервере
ssh sergio675@149.154.65.180
chmod +x /tmp/команды_для_сервера.sh
sudo /tmp/команды_для_сервера.sh
```
