### ШАГ 5: Добавить location блоки

**Добавьте следующие блоки ВНУТРИ секции `server {}`:**

```nginx
# Роутинг для Privacy Policy
location = /privacy {
    return 301 /privacy.html;
}

# Роутинг для Terms of Use
location = /terms {
    return 301 /terms.html;
}
```

**Пример полной секции server (после добавления):**

```nginx
server {
    listen 443 ssl http2;
    server_name aladdin-ai.ru;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    root /var/www/aladdin-ai.ru;
    index index.html;
    
    # Роутинг для Privacy Policy
    location = /privacy {
        return 301 /privacy.html;
    }
    
    # Роутинг для Terms of Use
    location = /terms {
        return 301 /terms.html;
    }
    
    # Остальные location блоки...
    location / {
        try_files $uri $uri/ =404;
    }
}
```

**ВАЖНО:**
- Блоки должны быть ВНУТРИ `server {}`
- `location = /privacy` означает точное совпадение (без слэша в конце)
- `return 301` - постоянный редирект

### ШАГ 6: Сохранить и выйти

**В nano:**
- `Ctrl + O` - сохранить
- `Enter` - подтвердить имя файла
- `Ctrl + X` - выйти

**В vi:**
- `Esc` - выйти из режима редактирования
- `:wq` - сохранить и выйти
- `:q!` - выйти без сохранения (если что-то пошло не так)

## 🔧 АЛЬТЕРНАТИВНЫЙ ВАРИАНТ (если редирект не нужен)

Если хотите чтобы `/privacy` напрямую показывал содержимое `privacy.html`:

```nginx
location = /privacy {
    try_files /privacy.html =404;
}

location = /terms {
    try_files /terms.html =404;
}
```

**Или еще проще:**
```nginx
location = /privacy {
    alias /var/www/aladdin-ai.ru/privacy.html;
}

location = /terms {
    alias /var/www/aladdin-ai.ru/terms.html;
}
```

## ⚠️ РЕШЕНИЕ ПРОБЛЕМ

### Проблема 1: nginx -t показывает ошибку

**Решение:**
- Проверьте синтаксис
- Убедитесь что все скобки закрыты
- Проверьте что location блоки внутри server {}

### Проблема 2: Редирект не работает

**Решение:**
- Проверьте что файлы существуют: `ls -la /var/www/aladdin-ai.ru/privacy.html`
- Проверьте права доступа: `chmod 644 /var/www/aladdin-ai.ru/privacy.html`
- Проверьте что nginx перезагружен: `systemctl status nginx`

### Проблема 3: 404 ошибка

**Решение:**
- Проверьте путь к файлам: `root /var/www/aladdin-ai.ru;`
- Проверьте что файлы в правильной директории
- Проверьте логи: `tail -f /var/log/nginx/error.log`
