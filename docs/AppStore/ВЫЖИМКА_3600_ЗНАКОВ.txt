Спасибо за ваш запрос. Мы обеспечиваем функции безопасности и родительского контроля, используя стандартные iOS API и наш серверный backend, без использования NEVPNManager API, Screen Time API или PermissionKit framework.

ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ - СТАНДАРТНЫЕ iOS API

Функции безопасности:

LocalAuthentication (стандартный iOS API). Файл: Core/Security/SecurityManager.swift. Биометрическая аутентификация (Face ID/Touch ID). Пример: Пользователь открывает приложение, система запрашивает биометрию через LocalAuthentication, данные обрабатываются только на устройстве, никогда не передаются. Стандартный API, не требует специальных разрешений.

CryptoKit (стандартный iOS API). Файл: Core/Security/SecurityManager.swift. Локальное шифрование данных (AES-256-GCM). Пример: Пользовательские данные шифруются локально на устройстве, ключи хранятся в Keychain, зашифрованные данные могут быть отправлены на backend, но ключи никогда не покидают устройство.

Security framework (Keychain Services). Файл: Core/Security/SecurityManager.swift. Безопасное хранение токенов, паролей, ключей. Пример: Приложение сохраняет токены в Keychain через Security framework, Keychain обеспечивает аппаратную защиту (Secure Enclave), данные доступны только приложению и его расширениям через App Groups.

URLSession (стандартный iOS API). Файл: Core/Network/NetworkManager.swift. HTTPS коммуникация с backend, SSL Pinning для валидации сертификатов. Пример: Приложение устанавливает HTTPS соединение через URLSession, SSL Pinning проверяет сертификат, все данные передаются через TLS 1.2+, backend получает только обезличенные метаданные (URL, домены, типы контента). Стандартный API, нет VPN функциональности.

SafariServices (SFContentBlockerManager). Файл: Core/ContentBlocker/ContentBlockerManager.swift, Extension: ALADDINContentBlocker/ActionRequestHandler.swift. Блокировка нежелательного контента в Safari. Пример: Родитель настраивает категории блокировки в приложении, приложение создает JSON правила согласно стандарту Apple Content Blocker, правила сохраняются в App Group, SFContentBlockerManager активирует Extension, когда ребенок открывает Safari и пытается зайти на заблокированный сайт, Safari автоматически блокирует его, ребенок видит страницу "Сайт заблокирован". Стандартный iOS API, работает только в Safari.

Backend анализ безопасности. Файл: Core/Network/APIService.swift, Endpoints: /protection/*, /analytics/threats. Пример: Приложение отправляет обезличенные метаданные на backend сервер, backend анализирует с использованием AI/ML на сервере, определяет потенциальные угрозы (мошеннические сайты, фишинг, вредоносный контент), результаты возвращаются как рекомендации и оповещения, пользователь получает уведомление о потенциальной угрозе для всей семьи, пользователь принимает обоснованное решение на основе рекомендаций. НЕТ блокировки или принудительного применения на системном уровне - мы предоставляем только рекомендации.

Функции родительского контроля:

SwiftUI (стандартный iOS API). Файл: Screens/07_ParentalControlScreen.swift. Пользовательский интерфейс для настроек. Пример: Родитель открывает экран "Родительский контроль", SwiftUI отображает интерфейс с настройками (лимиты времени, категории контента, правила), родитель настраивает предпочтения через стандартные SwiftUI компоненты (Toggle, Picker, Slider), настройки сохраняются локально и синхронизируются с backend.

UserDefaults / @AppStorage (стандартный iOS API). Файл: ViewModels/ParentalControlViewModel.swift. Локальное хранение предпочтений. Пример: Родитель настраивает правила (например, "блокировать взрослый контент"), настройки сохраняются локально в UserDefaults через @AppStorage, при следующем открытии приложения настройки загружаются автоматически, настройки также синхронизируются с backend для использования на других устройствах семьи.

Backend аналитика и отчеты. Файл: Core/Network/APIService.swift, Endpoints: /api/v1/parental-control/*, /analytics. Пример: Родитель настраивает предпочтения в приложении (например, "отслеживать время использования приложений"), предпочтения хранятся на backend сервере, приложение отправляет метаданные активности на backend, backend предоставляет аналитику и отчеты (например, "ребенок использовал YouTube 2 часа сегодня"), приложение отображает отчеты родителям, родители получают уведомления о важных событиях (например, "ребенок пытался зайти на заблокированный сайт"), родители используют отчеты для общения с детьми и руководства их поведением. НЕТ принудительного применения на системном уровне - родители используют отчеты для семейного общения.

UserNotifications (стандартный iOS API). Файл: Core/Notifications/NotificationManager.swift. Локальные уведомления и Push Notifications через APNs. Пример: Backend обнаруживает потенциальную угрозу или важное событие, backend отправляет Push Notification родителям через APNs, родители получают уведомление на устройство в течение 2-7 секунд, уведомление содержит информацию о событии, родитель может открыть приложение для просмотра детального отчета. Стандартный API, требует согласия пользователя.

CoreLocation (стандартный iOS API, опционально). Функции безопасности семьи (геозоны, обмен местоположением). Пример: Родитель включает функцию "Геозоны" в настройках, приложение запрашивает разрешение с четким описанием: "Для функций безопасности семьи (геозоны, обмен местоположением)", если пользователь дает согласие, приложение может отслеживать местоположение для создания геозон (например, "дом", "школа", спортивная секция или друзья), родитель получает уведомления, когда ребенок входит или выходит из геозоны, пользователь может отключить эту функцию в любой момент. Стандартный API, требуется согласие пользователя.

ЧТО МЫ НЕ ИСПОЛЬЗУЕМ:

NEVPNManager - Не используется (NetworkExtension framework закомментирован в коде). VPN функциональность - Удалена из приложения согласно руководящим принципам Apple. Screen Time API - Не используется (мы предоставляем собственный мониторинг через backend аналитику). PermissionKit framework - Не используется (мы используем стандартные iOS запросы разрешений).
