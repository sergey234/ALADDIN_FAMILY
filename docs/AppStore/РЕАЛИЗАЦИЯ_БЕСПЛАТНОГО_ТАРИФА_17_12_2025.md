# РЕАЛИЗАЦИЯ БЕСПЛАТНОГО ТАРИФА (LIFETIME)

**Дата:** 17 декабря 2025  
**Задача:** Автоматическая активация бесплатного тарифа при первом запуске

---

## 📋 ПРОБЛЕМА

1. **В UI есть бесплатный тариф** (`.free` с ценой "0 ₽")
2. **В StoreManager нет логики** для бесплатного тарифа
3. **Все тарифы - платные подписки** через StoreKit
4. **Нет автоматической активации** при первом запуске

---

## ✅ РЕШЕНИЕ

### 1. Добавить логику бесплатного тарифа в StoreManager

**Что нужно добавить:**
- Константа для бесплатного тарифа: `FREE_TARIFF_ID = "free"`
- Метод проверки: `hasFreeTariff() -> Bool`
- Метод активации: `activateFreeTariff()`
- Автоматическая активация при первом запуске

### 2. Логика проверки тарифа

**Порядок проверки:**
1. Проверить платную подписку через StoreKit
2. Если платной подписки нет → проверить бесплатный тариф
3. Если бесплатного тарифа нет → активировать автоматически

### 3. Lifetime подписка

**Что такое "Continuing Subscription" (Континунгулы):**
- **Простыми словами:** Это подписка, которая продолжается автоматически
- **В App Store Connect:** Auto-Renewable Subscription (автоматически возобновляемая)
- **Для lifetime:** Нужно использовать **Non-Renewing Subscription** или локальную логику

**Варианты для lifetime:**
1. **Non-Renewing Subscription** - одноразовая покупка, не возобновляется
2. **Локальная логика** - хранить в UserDefaults/Keychain (для бесплатного тарифа)

## 🔧 РЕАЛИЗАЦИЯ

### Шаг 1: Добавить константы в StoreManager

```swift
// MARK: - Free Tariff
static let FREE_TARIFF_ID = "free"
private let FREE_TARIFF_KEY = "hasFreeTariffActivated"

var hasFreeTariff: Bool {
    UserDefaults.standard.bool(forKey: FREE_TARIFF_KEY)
}

func activateFreeTariff() {
    UserDefaults.standard.set(true, forKey: FREE_TARIFF_KEY)
    print("✅ Free tariff activated")
}
```

### Шаг 2: Обновить метод проверки подписки

```swift
func hasActiveSubscription() -> Bool {
    // Проверяем платную подписку
    if !purchasedProductIDs.isEmpty {
        return true
    }
    
    // Если платной подписки нет → проверяем бесплатный тариф
    return hasFreeTariff
}

func currentTariffType() -> String {
    // Если есть платная подписка → возвращаем её
    if let active = activeSubscription {
        return active.id
    }
    
    // Если есть бесплатный тариф → возвращаем "free"
    if hasFreeTariff {
        return FREE_TARIFF_ID
    }
    
    // По умолчанию → нет тарифа
    return ""
}
```

### Шаг 3: Автоматическая активация при первом запуске

**В ALADDINApp.swift или при инициализации StoreManager:**

```swift
func initializeFreeTariffIfNeeded() {
    // Проверяем первый запуск
    let isFirstLaunch = !UserDefaults.standard.bool(forKey: "hasLaunchedBefore")
    
    if isFirstLaunch {
        // Активируем бесплатный тариф
        storeManager.activateFreeTariff()
        UserDefaults.standard.set(true, forKey: "hasLaunchedBefore")
        print("✅ First launch: Free tariff activated")
    }
}
```

## 📝 ИТОГОВАЯ ЛОГИКА

1. **При первом запуске:**
   - Автоматически активируется бесплатный тариф
   - Сохраняется в UserDefaults
   - Пользователь получает доступ к базовым функциям

2. **При последующих запусках:**
   - Проверяется платная подписка
   - Если платной нет → используется бесплатный тариф
   - Если платная есть → используется платная подписка

3. **При покупке платной подписки:**
   - Платная подписка имеет приоритет
   - Бесплатный тариф остается активным (на случай отмены подписки)

---

## ⚠️ ВАЖНО

**Для App Store Connect:**
- Бесплатный тариф НЕ нужно создавать как подписку в App Store Connect
- Это локальная логика в приложении
- Пользователь получает бесплатный тариф автоматически при установке

**Для lifetime подписки:**
- Если нужна платная lifetime подписка → использовать Non-Renewing Subscription
- Если нужен бесплатный lifetime → использовать локальную логику (как выше)
