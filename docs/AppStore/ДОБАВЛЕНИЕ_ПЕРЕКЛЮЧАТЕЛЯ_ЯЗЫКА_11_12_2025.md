## 📝 ЧТО НУЖНО ДОБАВИТЬ:

### В HTML (в header):

```html
<div style="text-align: right; margin-bottom: 16px;">
  <button onclick="switchLanguage('ru')" id="lang-ru" style="padding: 8px 16px; margin: 0 4px; border: 1px solid #ccc; background: #fff; cursor: pointer;">RU</button>
  <button onclick="switchLanguage('en')" id="lang-en" style="padding: 8px 16px; margin: 0 4px; border: 1px solid #ccc; background: #fff; cursor: pointer;">EN</button>
</div>
```

### JavaScript для переключения:

```javascript
<script>
const translations = {
  ru: {
    title: "Политика конфиденциальности",
    // ... все русские тексты
  },
  en: {
    title: "Privacy Policy",
    // ... все английские тексты
  }
};

function switchLanguage(lang) {
  // Переключение контента
  document.documentElement.lang = lang;
  // Обновление всех текстов на странице
}
</script>
```
