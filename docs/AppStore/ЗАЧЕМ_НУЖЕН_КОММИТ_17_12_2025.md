# ЗАЧЕМ НУЖЕН КОММИТ И КТО ЕГО ВИДИТ?

**Дата:** 17 декабря 2025

---

## 🎯 ЗАЧЕМ НУЖЕН КОММИТ?

### 1. **Сохранение изменений в истории проекта**
- Коммит = снимок состояния кода в определенный момент времени
- Позволяет вернуться к предыдущим версиям, если что-то сломалось
- История всех изменений в проекте

### 2. **Синхронизация с GitHub**
- После коммита можно отправить изменения в GitHub (push)
- Команда может видеть изменения
- Резервная копия кода в облаке

### 3. **Запуск автоматических процессов (CI/CD)**
- GitHub Actions (workflow) запускается автоматически при push
- Автоматическая сборка приложения
- Автоматические тесты

### 4. **Документирование изменений**
- Коммит сообщение = описание того, что было изменено
- Легче понять историю разработки
- Легче найти когда была добавлена функция

---

## 👀 КТО ВИДИТ КОММИТЫ?

### ✅ ВИДЯТ:
1. **Вы (разработчик)** - в локальном репозитории
2. **Ваша команда** - если есть доступ к GitHub репозиторию
3. **GitHub** - все коммиты хранятся на GitHub
4. **GitHub Actions** - автоматические процессы видят коммиты

### ❌ НЕ ВИДЯТ:
1. **Apple** - НЕ видит коммиты GitHub
2. **Пользователи приложения** - НЕ видят коммиты
3. **App Store** - НЕ видит коммиты

---

## 🍎 ВИДИТ ЛИ APPLE КОММИТЫ?

### ❌ НЕТ, APPLE НЕ ВИДИТ КОММИТЫ!

**Что Apple видит:**
- ✅ Бинарный файл приложения (.ipa)
- ✅ Метаданные в App Store Connect (описание, скриншоты, цены)
- ✅ Ваши ответы в App Store Connect (письма)
- ✅ Версию приложения (1.0, 1.1, и т.д.)

**Что Apple НЕ видит:**
- ❌ Коммиты GitHub
- ❌ Сообщения коммитов
- ❌ История изменений в коде
- ❌ Исходный код (только скомпилированный бинарник)

---

## 📋 ЗАЧЕМ КОММИТИТЬ ИЗМЕНЕНИЯ БЕСПЛАТНОГО ТАРИФА?

1. **Сохранение в истории** - если что-то сломается, можно вернуться
2. **Синхронизация** - изменения будут в GitHub
3. **Автоматическая сборка** - workflow соберет новую версию с бесплатным тарифом
4. **Документирование** - в истории будет видно, когда добавлен бесплатный тариф

## ✅ ИТОГ

**Коммит нужен для:**
- Сохранения изменений
- Синхронизации с GitHub
- Автоматической сборки
- Документирования

**Apple НЕ видит коммиты** - они видят только бинарный файл и метаданные!
