**Задача:** Удалить все упоминания VPN из метаданных в App Store Connect

**Что нужно проверить и исправить:**
- [ ] **Название приложения** - не должно содержать "VPN"
- [ ] **Описание приложения** - не должно содержать "VPN"
- [ ] **Ключевые слова** - удалить "VPN"
- [ ] **Скриншоты** - не должно быть упоминаний VPN
- [ ] **Категории** - не должна быть категория "VPN"
- [ ] **Подкатегории** - проверить

**Действия:**
1. Войти в App Store Connect
2. Перейти в раздел "App Information"
3. Проверить все поля на упоминания VPN
4. Заменить все упоминания VPN на "Network Protection" или "Secure Connection"

**Приоритет:** 🔴 КРИТИЧНО

### 2. ❌ Guideline 2.3.2 - Рекламное изображение IAP

**Задача:** Создать новые промо-изображения для In-App Purchase

**Требования Apple:**
- ✅ НЕ должно быть скриншотом из приложения
- ✅ Должно быть уникальным изображением
- ✅ Текст должен быть читаемым (минимум 20pt)
- ✅ Размер: 1024x1024 пикселей
- ✅ Формат: PNG или JPEG

**Что должно быть на изображении:**
- ✅ Название тарифа (крупным шрифтом)
- ✅ Основные функции тарифа (читаемым текстом)
- ✅ Визуальные элементы (иконки, графика)
- ✅ Цветовая схема приложения

**Нужно создать изображения для каждого тарифа:**
1. **FREE** - Бесплатный тариф
2. **BASIC** - Базовый тариф
3. **INDIVIDUAL** - Индивидуальный тариф
4. **FAMILY** - Семейный тариф
5. **PREMIUM** - Премиум тариф

**Действия:**
1. Создать 5 изображений (1024x1024)
2. Войти в App Store Connect
3. Перейти в раздел "In-App Purchases"
4. Для каждого тарифа:
   - Выбрать тариф
   - Загрузить новое рекламное изображение
   - Сохранить изменения

**Приоритет:** 🟡 ВАЖНО
