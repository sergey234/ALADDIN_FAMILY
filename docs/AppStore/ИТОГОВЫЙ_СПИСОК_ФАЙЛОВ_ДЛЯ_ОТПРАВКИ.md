## 🔐 GITHUB SECRETS (НЕ В РЕПОЗИТОРИИ!)

### Обязательные Secrets (7 штук):

**Где настроить:**
- GitHub → Settings → Secrets and variables → Actions
- Добавить каждый secret отдельно

**Список:**

1. **APP_STORE_CONNECT_API_KEY**
   - Приватный ключ API (.p8 файл)
   - Формат: содержимое файла AuthKey_XXXXX.p8
   - Используется: аутентификация в App Store Connect API

2. **APP_STORE_CONNECT_ISSUER_ID**
   - ID издателя из App Store Connect
   - Формат: UUID
   - Используется: аутентификация в App Store Connect API

3. **APP_STORE_CONNECT_API_KEY_ID**
   - ID API ключа
   - Формат: 10 символов
   - Используется: аутентификация в App Store Connect API

4. **PROVISIONING_PROFILE_APP**
   - Профиль для основного приложения (family.aladdin.ios)
   - Формат: base64 encoded .mobileprovision
   - UUID: 4dc2e0ff-f7bd-4ac0-aca8-98143ea99e7f

5. **PROVISIONING_PROFILE_EXTENSION**
   - Профиль для расширения (family.aladdin.ios.packetTunnel)
   - Формат: base64 encoded .mobileprovision
   - UUID: d1e59dc9-2171-4eca-a316-1bf714c895ec

6. **APPLE_DISTRIBUTION_CERTIFICATE**
   - Сертификат распределения
   - Формат: base64 encoded .p12
   - Используется: подпись IPA

7. **APPLE_DISTRIBUTION_CERTIFICATE_PASSWORD**
   - Пароль сертификата
   - Формат: строка
   - Используется: расшифровка сертификата

   - Setup Xcode 16.2.0
   - Setup сертификатов и профилей
   - `xcodebuild archive` → ALADDIN.xcarchive

   - Проверка API ключей
   - `apple-actions/upload-testflight-build@v1`
   - Загрузка IPA в App Store Connect
   - Получение Delivery UUID

4. **Артефакт:**
   - IPA сохраняется как артефакт
   - Название: ALADDIN-IPA
   - Retention: 30 дней
