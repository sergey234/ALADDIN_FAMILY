# ВАРИАНТЫ ИЛЛЮСТРАЦИЙ ДЛЯ IAP ТАРИФОВ
## Соответствие требованиям Apple

---

## ТРЕБОВАНИЯ APPLE (НАПОМИНАНИЕ):

1. ✅ **НЕ скриншот** - уникальное изображение
2. ✅ **Размер:** 1024x1024px, PNG/JPG, RGB, 72 dpi
3. ✅ **Читаемость:** Если текст - минимум 17pt (лучше избегать текста)
4. ✅ **Уникальность:** Каждый тариф должен иметь уникальную иллюстрацию
5. ✅ **Представление IAP:** Иллюстрация должна точно представлять продукт
6. ⚠️ **Текст не рекомендуется** - лучше использовать только визуальные элементы

---

## КОНЦЕПЦИЯ ИЛЛЮСТРАЦИЙ ДЛЯ КАЖДОГО ТАРИФА:

### INDIVIDUAL (Личный тариф):
**Ключевая идея:** Персональная защита, один человек, индивидуальность

### FAMILY (Семейный тариф):
**Ключевая идея:** Семейная защита, несколько людей, безопасность семьи

### PREMIUM (Премиум тариф):
**Ключевая идея:** Максимальная защита, премиум статус, эксклюзивность

---

## ВАРИАНТ 1: СТИЛИЗОВАННЫЕ ЛЮДИ/СИЛУЭТЫ (FLAT-СТИЛЬ)

### INDIVIDUAL:
```
┌─────────────────────────────────┐
│                                 │
│      ┌─────┐                    │
│      │  👤 │  ← Один человек    │
│      └─────┘   в защитном       │
│        🛡️      щите/круге       │
│                                 │
│    [Градиентный фон - синий]    │
│                                 │
│   Декоративные элементы:        │
│   • Защитные кольца вокруг      │
│   • AI символы (тонкие линии)   │
│   • Замки/защитные элементы     │
│                                 │
└─────────────────────────────────┘
```

**Элементы:**
- Один стилизованный силуэт человека (плоский стиль, синий цвет)
- Защитный щит/круг вокруг него
- Декоративные элементы защиты (кольца, линии)
- Градиентный синий фон
- Без текста, только визуальные элементы

### FAMILY:
```
┌─────────────────────────────────┐
│                                 │
│    ┌───┐  ┌───┐                │
│    │👤 │  │👤 │  ← Взрослые    │
│    └───┘  └───┘                │
│    ┌──┐ ┌──┐ ┌──┐              │
│    │👶│ │👶│ │👶│  ← Дети      │
│    └──┘ └──┘ └──┘              │
│      🛡️      ← Общий щит       │
│                                 │
│    [Градиентный фон - золотой]  │
│                                 │
│   Декоративные элементы:        │
│   • Соединяющие линии           │
│   • Семейные символы            │
│                                 │
└─────────────────────────────────┘
```

**Элементы:**
- Несколько стилизованных силуэтов (2 взрослых + дети)
- Общий защитный щит/круг вокруг всех
- Соединяющие линии между членами семьи
- Градиентный золотой фон
- Без текста

### PREMIUM:
```
┌─────────────────────────────────┐
│         ⭐                      │
│                                 │
│      ┌───────┐                  │
│      │   👤  │                  │

│      │   ⚡  │     с множеством │
│      └───────┘     защит        │
│         ⚡                       │

│    [Градиентный фон - фиолетовый│

│                                 │
│   Декоративные элементы:        │
│   • Короны/звезды               │
│   • Множественные защитные слои │
│   • Премиум символы (⭐, 💎)     │
│                                 │
└─────────────────────────────────┘
```

**Элементы:**
- Человек с множественными слоями защиты
- Корона или звезды (премиум статус)
- Более сложные декоративные элементы
- Градиентный фиолетовый фон с золотыми акцентами
- Без текста

## ВАРИАНТ 2: АБСТРАКТНЫЕ ГЕОМЕТРИЧЕСКИЕ ФОРМЫ

### INDIVIDUAL:
- Один большой круг/щит (синий)
- Внутри: простые геометрические формы (треугольник, квадрат)
- Символизирует: единую защиту
- Фон: синий градиент
- Минималистичный стиль

### FAMILY:
- Несколько перекрывающихся кругов (золотые)
- Соединяющиеся элементы между ними
- Символизирует: связанную защиту семьи
- Фон: золотой градиент
- Показывает связь между элементами

### PREMIUM:
- Многослойные геометрические формы (фиолетовые/золотые)
- Сложная структура с множеством слоев
- Звезды/короны в виде геометрических форм
- Фон: фиолетовый градиент с золотыми акцентами
- Показывает сложность и премиум статус

## ВАРИАНТ 3: ЗАЩИТНЫЕ ЩИТЫ/КОЛЬЦА

### INDIVIDUAL:
- Один большой щит (синий)
- Внутри: символы защиты (замки, ключи, AI символы)
- Простая композиция
- Фон: синий градиент

### FAMILY:
- Несколько щитов, соединенных вместе (золотые)
- В центре: семейный символ
- Показывает коллективную защиту
- Фон: золотой градиент

### PREMIUM:
- Многослойный щит с короной (фиолетовый/золотой)
- Множественные защитные слои
- Премиум символы (звезды, алмазы)
- Фон: фиолетовый градиент с золотыми акцентами

---

## ВАРИАНТ 4: МИНИМАЛИСТИЧНЫЕ ИКОНКИ-ПЕРСОНАЖИ

### INDIVIDUAL:
- Один милый персонаж-защитник (синий)
- Стиль: flat, простой
- Символы защиты вокруг него
- Дружелюбный, но профессиональный вид

### FAMILY:
- Несколько персонажей-защитников (золотые)
- Разные размеры (взрослые и дети)
- Показывают взаимодействие
- Семейная атмосфера

### PREMIUM:
- Один персонаж-защитник с короной (фиолетовый/золотой)
- Более детализированный
- Премиум аксессуары (плащ, корона, щит)
- Эксклюзивный вид

## ВАРИАНТ 5: КОМБИНИРОВАННЫЙ (РЕКОМЕНДУЕТСЯ) ⭐⭐⭐⭐⭐

### INDIVIDUAL:
**Композиция:**
- Центр: один стилизованный силуэт человека (плоский стиль, синий)
- Вокруг: защитное кольцо/щит
- Декоративные элементы: тонкие линии (AI символы), замки
- Фон: синий градиент
- Стиль: flat, минималистичный

**Цвета:**
- Основной: #2E5BFF (синий)
- Акцент: #60A5FA (светлый синий)
- Фон: темно-синий градиент

### FAMILY:
**Композиция:**
- Центр: группа стилизованных силуэтов (2 взрослых + 2-3 детей)
- Вокруг: большой общий защитный щит/круг
- Соединяющие линии между фигурами
- Декоративные элементы: семейные символы
- Фон: золотой градиент

**Цвета:**
- Основной: #F59E0B (золотой)
- Акцент: #FCD34D (светлый золотой)
- Фон: темно-золотой градиент

### PREMIUM:
**Композиция:**
- Центр: один человек с короной или множественными защитными слоями
- Вокруг: несколько концентрических защитных колец
- Декоративные элементы: звезды, корона, премиум символы
- Фон: фиолетовый градиент с золотыми акцентами

**Цвета:**
- Основной: #A855F7 (фиолетовый)
- Акцент: #F59E0B (золотой)
- Фон: фиолетовый градиент с золотыми вкраплениями
