## 📝 ИНСТРУКЦИЯ ПО ГЕНЕРАЦИИ ДЕМО QR-КОДА

### Способ 1: Использовать RecoveryCodeModal

1. Открыть приложение в симуляторе/устройстве
2. Создать семью (или использовать тестовый код)
3. В RecoveryCodeModal будет показан QR-код
4. Сделать скриншот QR-кода

### Способ 2: Онлайн генератор

1. Перейти на https://www.qr-code-generator.com/
2. Ввести текст: `FAM-DEMO-CODE-2025`
3. Скачать QR-код как изображение
4. Загрузить в App Review Information

### Способ 3: Программно (Swift)

```swift
import CoreImage.CIFilterBuiltins

func generateQRCode(from string: String) -> UIImage? {
    let context = CIContext()
    let filter = CIFilter.qrCodeGenerator()
    filter.message = Data(string.utf8)
    
    if let outputImage = filter.outputImage {
        let transform = CGAffineTransform(scaleX: 10, y: 10)
        let scaledImage = outputImage.transformed(by: transform)
        
        if let cgImage = context.createCGImage(scaledImage, from: scaledImage.extent) {
            return UIImage(cgImage: cgImage)
        }
    }
    return nil
}

// Использование:
let qrCode = generateQRCode(from: "FAM-DEMO-CODE-2025")
```
