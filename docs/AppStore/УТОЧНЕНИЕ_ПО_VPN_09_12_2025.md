## 📋 ПОДРОБНЫЙ ПЛАН

### 1. Удалить VPN с главной страницы

**Файл:** `Screens/01_MainScreen.swift`

**Найти и удалить:**
```swift
// VPN карточка
NavigationLink(destination: VPNScreen()) {
    VStack(spacing: 8) {
        HStack(spacing: 8) {
            Text("🛡️")
            Text(vpnConnected ? "🟢" : "🔴")
        }
        Text(localizationManager.localized("main_vpn_title"))
        Text(localizationManager.localized("main_vpn_subtitle"))
    }
    // ... стили
}
```

**Результат:** Главная страница без VPN карточки

---

### 2. Добавить VPN в настройки

**Файл:** `Screens/05_SettingsScreen.swift`

**Добавить раздел:**
```swift
Section(header: Text(localizationManager.localized("settings_protection_section"))) {
    NavigationLink(destination: VPNScreen()) {
        HStack {
            Text("🛡️")
                .font(.system(size: 20))
            VStack(alignment: .leading, spacing: 4) {
                Text(localizationManager.localized("settings_protection_title"))
                    .font(.body)
                Text(localizationManager.localized("settings_protection_subtitle"))
                    .font(.caption)
                    .foregroundColor(.secondary)
            }
            Spacer()
            if vpnConnected {
                Text("🟢")
                    .font(.system(size: 20))
            } else {
                Text("🔴")
                    .font(.system(size: 20))
            }
        }
    }
}
```

**Здесь используем переименование:**
- `settings_protection_title` = "Безопасное соединение" (НЕ "VPN")
- `settings_protection_subtitle` = "Защита данных в публичных сетях"
