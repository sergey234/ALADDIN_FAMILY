# 🔍 ИНСТРУКЦИЯ: КАК ПРОВЕРИТЬ РЕГИОН В СИМУЛЯТОРЕ

**Дата:** 9 декабря 2025

---

## ❓ ПРОБЛЕМА

Вы видите ошибку "In-App Purchase недоступен в симуляторе" вместо открытия сайта.

**Это значит:**
- Код определил регион как "не Россия"
- Попал в блок IAP вместо блока QR оплаты
- В симуляторе регион может определяться неправильно

---

## 🔍 КАК ПРОВЕРИТЬ РЕГИОН

### Шаг 1: Запустить приложение в Xcode

1. Откройте Xcode
2. Запустите приложение (⌘R)
3. Откройте консоль (⌘⇧Y или View → Debug Area → Activate Console)

### Шаг 2: Нажать кнопку "Оформить подписку"

1. В приложении откройте экран тарифов
2. Нажмите кнопку "Оформить подписку" на любом платном тарифе
3. Посмотрите в консоль Xcode

### Шаг 3: Проверить вывод в консоли

**Вы должны увидеть:**
```
🔍 DEBUG Payment: regionCode = 'RU', useAlternativePayments = true
🇷🇺 Российский регион: открываем сайт для QR оплаты
🌐 Открываем сайт: https://aladdin-ai.ru с тарифом: premium
✅ URLHelper.openWebsite: открываем URL https://aladdin-ai.ru?tariff=premium
```

**Если видите:**
```
🔍 DEBUG Payment: regionCode = 'US', useAlternativePayments = false
🌍 Не российский регион: открываем IAP
```

**Это значит:** Регион определяется неправильно!

---

## ✅ РЕШЕНИЕ: УСТАНОВИТЬ РЕГИОН В СИМУЛЯТОРЕ

### Способ 1: Через настройки симулятора

1. **В симуляторе:**
   - Откройте приложение "Settings" (Настройки)
   - Перейдите: General → Language & Region
   - Найдите "Region"
   - Установите "Russia" (Россия)
   - Перезапустите приложение

2. **Проверьте снова:**
   - Нажмите кнопку "Оформить подписку"
   - Посмотрите в консоль
   - Должно быть: `regionCode = 'RU'`

### Способ 2: Через настройки Xcode

1. **В Xcode:**
   - Выберите симулятор
   - Device → Device Settings
   - Language & Region → Region
   - Установите "Russia"

---

## 🔧 ВРЕМЕННОЕ РЕШЕНИЕ ДЛЯ ТЕСТИРОВАНИЯ

Если нужно быстро протестировать, можно временно принудительно установить регион:

**Файл:** `Core/Config/AppConfig.swift`  
**Строки:** 187-189

**Временно изменить:**
```swift
static var isRussianRegion: Bool {
    #if DEBUG
    // ✅ ВРЕМЕННО: Для тестирования в симуляторе
    return true  // Принудительно Россия
    #endif
    return Locale.current.regionCode == "RU"
}
```

**⚠️ ВАЖНО:** После тестирования верните обратно!

## 📋 ЧТО ДОЛЖНО ПРОИЗОЙТИ

### Если регион правильный (RU):

1. В консоли: `regionCode = 'RU', useAlternativePayments = true`
2. В консоли: `🇷🇺 Российский регион: открываем сайт`
3. В консоли: `🌐 Открываем сайт: https://aladdin-ai.ru`
4. **Открывается Safari** с сайтом aladdin-ai.ru

### Если регион неправильный:

1. В консоли: `regionCode = 'US' (или другой), useAlternativePayments = false`
2. В консоли: `🌍 Не российский регион: открываем IAP`
3. **Показывается ошибка** "In-App Purchase недоступен в симуляторе"

---

## 🎯 СЛЕДУЮЩИЕ ШАГИ

1. **Проверьте консоль** - какой регион определяется
2. **Если не RU:**
   - Установите регион в симуляторе на "Russia"
   - Или используйте временное решение для тестирования
3. **Проверьте снова** - должен открываться сайт
