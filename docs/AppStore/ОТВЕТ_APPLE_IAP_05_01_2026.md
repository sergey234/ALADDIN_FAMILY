### ЭТАП 1: ПРОВЕРКА APP STORE CONNECT (КРИТИЧНО!)

#### 1.1. Проверить наличие продуктов In-App Purchase

**Действия:**
1. Войти в [App Store Connect](https://appstoreconnect.apple.com)
2. Выбрать приложение "ALADDIN"
3. Перейти в раздел **Features → In-App Purchases**
4. Проверить наличие всех 3 продуктов:
   - ✅ `family.aladdin.ios.subscription.individual.v2` (Индивидуальный)
   - ✅ `family.aladdin.ios.subscription.family` (Семейный)
   - ✅ `family.aladdin.ios.subscription.premium` (Премиум)

**Что проверить:**
- [ ] Все 3 продукта созданы
- [ ] Все продукты в статусе **"Ready to Submit"** или **"Approved"**
- [ ] У каждого продукта заполнены:
  - [ ] Reference Name (название)
  - [ ] Product ID (должен совпадать с кодом)
  - [ ] Subscription Group (группа подписок)
  - [ ] Subscription Duration (период подписки - 1 месяц)
  - [ ] Price (цена)
  - [ ] Localization (локализация для всех языков)

#### 1.2. Проверить Bundle ID

**Действия:**
1. В App Store Connect → My Apps → ALADDIN
2. Проверить Bundle ID: должен быть `family.aladdin.ios`
3. Убедиться, что Bundle ID в коде совпадает:
   - Проверить в Xcode: Target → General → Bundle Identifier
   - Должно быть: `family.aladdin.ios`

#### 1.3. Проверить Paid Apps Agreement

**Действия:**
1. В App Store Connect → **Agreements, Tax, and Banking**
2. Проверить статус соглашений:
   - [ ] **Paid Apps Agreement** - должен быть **"Active"** (активен)
   - [ ] Если не активен → нажать "Request" и заполнить все данные
3. Проверить налоговую информацию:
   - [ ] Заполнена налоговая информация
   - [ ] Заполнена банковская информация

**КРИТИЧНО:** Без активного Paid Apps Agreement покупки не будут работать!

### ЭТАП 4: ТЕСТИРОВАНИЕ В SANDBOX

#### 4.1. Создать Sandbox тестовый аккаунт

**Действия:**
1. В App Store Connect → **Users and Access → Sandbox Testers**
2. Создать новый тестовый аккаунт:
   - Email (должен быть уникальным, не использоваться в обычном Apple ID)
   - Пароль
   - Страна (любая, кроме России для тестирования IAP)
3. Сохранить данные аккаунта

#### 4.2. Настроить устройство для тестирования

**Действия:**
1. На iPad:
   - Выйти из обычного Apple ID: **Настройки → [Ваше имя] → Выйти**
   - Войти в Sandbox аккаунт: **Настройки → App Store → Войти** (использовать sandbox email)
2. Установить приложение через TestFlight или Xcode
3. Открыть приложение

#### 4.3. Протестировать покупку

**Действия:**
1. Открыть экран тарифов
2. Выбрать тариф (например, Individual)
3. Нажать "Купить"
4. Должно появиться окно подтверждения покупки
5. Подтвердить покупку (в sandbox это бесплатно)
6. Проверить что покупка прошла успешно

**Что проверить:**
- [ ] Продукты загружаются при открытии экрана тарифов
- [ ] При нажатии "Купить" появляется окно подтверждения
- [ ] Покупка проходит успешно
- [ ] Тариф активируется после покупки
- [ ] Нет ошибок в консоли
