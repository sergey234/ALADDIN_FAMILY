## ФАЙЛЫ ДЛЯ КОММИТА В GITHUB

### ✅ ОСНОВНЫЕ ИЗМЕНЕНИЯ (КРИТИЧНО):

1. **Core/Network/NetworkManager.swift**
   - Удален домен `"vpn.aladdin.family"` из SSL pinning

2. **Core/Notifications/NotificationManager.swift**
   - Переименованы все VPN методы и категории на Network Protection
   - `sendVPNConnectedNotification()` → `sendNetworkProtectionConnectedNotification()`
   - `NotificationCategory.vpn` → `.networkProtection`
   - `NotificationSettings.vpnEnabled` → `.networkProtectionEnabled`

3. **Core/Offline/OfflineStorageManager.swift**
   - `case .vpnStatus` → `.networkProtectionStatus`
   - `"VPN Статус"` → `"Статус защиты сети"`

4. **Core/Analytics/AnalyticsManager.swift**
   - `trackVPNConnect()` → `trackNetworkProtectionConnect()`
   - `trackVPNDisconnect()` → `trackNetworkProtectionDisconnect()`

5. **Core/Analytics/AnalyticsService.swift**
   - `AnalyticsVPNStats` → `AnalyticsNetworkProtectionStats`
   - `vpnStats` → `networkProtectionStats`

6. **ALADDINWidgets/ALADDINWidgets.swift**
   - `VPNStatusWidget` → `NetworkProtectionStatusWidget`
   - Все связанные структуры переименованы

7. **ALADDINWidgets/SharedDataManager.swift**
   - `updateVPNData()` → `updateNetworkProtectionData()`
   - `getVPNData()` → `getNetworkProtectionData()`
   - Все ключи UserDefaults переименованы

8. **Screens/NotificationSettingsScreen.swift**
   - `"VPN"` → `"Защита сети"`
   - `settings.vpnEnabled` → `settings.networkProtectionEnabled`

9. **Screens/SecurityEducationScreen.swift**
   - `"Используй VPN"` → `"Используй защиту сети"`

10. **Screens/SimpleTermsOfServiceScreen.swift**
    - `"включающее VPN"` → `"включающее защиту сети"`

11. **Core/Navigation/NavigationManager.swift**
    - Удален deprecated метод `switchToVPNScreen()`
