## ТАРИФ 1: INDIVIDUAL (ЛИЧНЫЙ)

### ВИЗУАЛЬНАЯ ИСТОРИЯ:
**"Защищенный одиночка в цифровом мире"**

**Концепция:**
Один человек, уверенно идущий по современному цифровому пейзажу. Вокруг него - невидимая защитная аура/силовое поле, которое блокирует угрозы. Он спокоен, уверен, идет вперед. Визуально показываем: "Ты один, но под защитой. Свобода + безопасность".

**Эмоция:** Независимость, уверенность, персональная сила

**Визуальные элементы:**
- Один стилизованный силуэт человека (современный, стильный)
- Невидимая защитная аура (светящиеся частицы/волны вокруг)
- Цифровой пейзаж на фоне (абстрактные линии, сеть, данные)
- Спокойная цветовая палитра: глубокий синий с акцентами
- Движение вперед (динамика, прогресс)

**"Семья под единым щитом любви и защиты"**

**Концепция:**
Семья (2 взрослых + дети) в теплом, объединяющем круге света. Они вместе, защищены общим щитом. Визуально показываем: "Ваша семья - в безопасности. Все под защитой. Вместе сильнее".

**Эмоция:** Забота, единство, семейная безопасность, любовь

**Визуальные элементы:**
- Группа стилизованных силуэтов (взрослые + дети разных размеров)
- Объединяющий круг теплого света вокруг всех
- Соединяющие линии между членами семьи (показывают связь)
- Теплая цветовая палитра: золотые, оранжевые тона
- Композиция "вместе" - показываем единство

## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ ДЛЯ ГЕНЕРАЦИИ:

1. **Размер:** 1024x1024px, квадрат
2. **Формат:** PNG, RGB, 72 dpi
3. **Стиль:** Modern minimalist, flat design с легкой глубиной
4. **Без текста:** Только визуальные элементы
5. **Центрированная композиция:** Все важное в центре
6. **Цвета:** Использовать точные hex-коды для каждого тарифа
7. **Масштабируемость:** Должно быть четким при уменьшении

---

## ПРОЦЕСС СОЗДАНИЯ:

1. **Выбрать промпт** для каждого тарифа
2. **Сгенерировать изображение** в инструменте (nano-banana pro или другой AI генератор)
3. **Проверить соответствие:**
   - Размер 1024x1024
   - Нет текста
   - Центральная композиция
   - Цвета соответствуют тарифу
4. **При необходимости:** Повторно сгенерировать с уточнениями
