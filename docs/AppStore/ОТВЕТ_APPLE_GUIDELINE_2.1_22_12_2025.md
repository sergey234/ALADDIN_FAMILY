## 📋 ВОПРОСЫ APPLE И НАШИ ОТВЕТЫ

### **ВОПРОС 1: Какие инструменты, утилиты, фреймворки или API используются для предоставления функций безопасности и родительского контроля?**

#### ✅ **НАШ ОТВЕТ:**

**1. Функции безопасности:**

**iOS Native Frameworks:**
- **`LocalAuthentication`** - Биометрическая аутентификация (Face ID, Touch ID)
  - Использование: Локальная аутентификация пользователей
  - Файл: `Core/Security/SecurityManager.swift`
  - Данные обрабатываются только на устройстве, не передаются на сервер

- **`CryptoKit`** - Шифрование данных
  - Использование: Локальное шифрование данных пользователя
  - Файл: `Core/Security/SecurityManager.swift`
  - Алгоритм: AES-256-GCM
  - Данные шифруются локально, ключи хранятся в Keychain

- **`Security` framework** - Keychain Services
  - Использование: Безопасное хранение токенов, паролей, ключей шифрования
  - Файл: `Core/Security/KeychainManager.swift`
  - Данные хранятся только локально на устройстве

- **`URLSession`** - Сетевые запросы
  - Использование: Коммуникация с backend сервером для получения конфигурации защиты
  - Файл: `Core/Network/NetworkManager.swift`
  - Используется HTTPS с TLS 1.2+

**Third-Party Libraries:**
- **`Alamofire`** (v5.8) - HTTP клиент
  - Использование: Упрощение сетевых запросов
  - Не собирает пользовательские данные

- **`KeychainAccess`** (v4.2) - Обертка для Keychain
  - Использование: Упрощение работы с Keychain
  - Не собирает пользовательские данные

**2. Функции родительского контроля:**

**iOS Native Frameworks:**
- **`SwiftUI`** - Пользовательский интерфейс
  - Использование: Отображение экранов родительского контроля
  - Файл: `Screens/07_ParentalControlScreen.swift`

- **`UserDefaults`** - Локальное хранение настроек
  - Использование: Хранение настроек родительского контроля (локально)
  - Файл: `ViewModels/ParentalControlViewModel.swift`
  - Данные хранятся только на устройстве

- **`Combine`** - Реактивное программирование
  - Использование: Управление состоянием родительского контроля
  - Файл: `ViewModels/ParentalControlViewModel.swift`

**Backend API:**
- **Custom REST API** - Собственный backend сервер
  - Использование: Получение данных о членах семьи, статистики угроз
  - Файл: `Core/Network/APIService.swift`
  - Endpoints: `/family/members`, `/family/stats`, `/analytics`

**ВАЖНО:**
- ❌ **НЕ используется** `NetworkExtension` framework (VPN функциональность удалена)
- ❌ **НЕ используется** `ScreenTime` framework (не требуется для базового родительского контроля)
- ❌ **НЕ используется** `Managed App Configuration` (не требуется для нашей реализации)

### **ВОПРОС 2: Собирает ли приложение, хранит или передает пользовательские данные?**

#### ✅ **НАШ ОТВЕТ:**

**ДА, приложение собирает, хранит и передает ОБЕЗЛИЧЕННЫЕ данные для обеспечения безопасности.**

**Что собирается:**

**1. Обезличенные идентификаторы:**
- Анонимный User ID (формат: `aladdin_family_abc123`)
- ID устройства (без привязки к владельцу)
- ID семейной группы (анонимный)

**2. Технические данные:**
- Тип устройства (iPhone, iPad)
- Версия iOS
- Версия приложения
- Язык интерфейса

**3. Статистика безопасности (обезличенная):**
- Количество заблокированных угроз (без деталей)
- Тип угрозы (общая категория: "web", "app", "network", "file")
- Время обнаружения угрозы (без привязки к пользователю)

**4. Статистика использования функций:**
- Использование функций защиты сети (вкл/выкл)
- Использование родительского контроля (действия)
- Использование AI помощника (количество сообщений, без содержания)

**Что НЕ собирается:**
- ❌ Имена, фамилии, даты рождения
- ❌ Адреса, телефоны, email
- ❌ Паспортные данные, СНИЛС, ИНН
- ❌ Финансовые данные
- ❌ Медицинская информация
- ❌ История посещений сайтов
- ❌ Содержимое сообщений
- ❌ Пароли и логины
- ❌ Геолокация (отключена в настройках)

**Где хранятся данные:**

**Локально на устройстве:**
- Настройки приложения → `UserDefaults`
- Токены доступа → `Keychain` (зашифровано)
- Ключи шифрования → `Keychain` (зашифровано)
- Кэш данных → Локальная память устройства

**На сервере:**
- Обезличенная статистика угроз → Backend сервер (Россия)
- Анонимные ID сессий → Backend сервер (Россия)
- Агрегированная аналитика → Backend сервер (Россия)

**Передача данных:**
- Данные передаются только через HTTPS с TLS 1.2+
- Все данные обезличиваются перед передачей
- Передача происходит только для обеспечения безопасности и функциональности приложения

### **ВОПРОС 3: Если да, какие пользовательские данные собирает приложение, как они используются и передаются ли они с устройства?**

#### ✅ **НАШ ОТВЕТ:**

**Детальный список собираемых данных:**

**1. Данные регистрации (анонимные):**
- **Что:** Роль в семье (родитель/ребенок/подросток/пожилой), возрастная группа (7-12 лет, 13-17 лет и т.д.)
- **Как используется:** Для настройки интерфейса и функций безопасности
- **Передача:** Да, передается на сервер в обезличенном виде (только роль и возрастная группа, без имени)

**2. Технические данные устройства:**
- **Что:** Тип устройства, модель, версия iOS, версия приложения
- **Как используется:** Для обеспечения совместимости и улучшения работы приложения
- **Передача:** Да, передается на сервер для технической поддержки

**3. Статистика угроз (обезличенная):**
- **Что:** Количество заблокированных угроз, тип угрозы (категория), время обнаружения
- **Как используется:** Для отображения статистики безопасности пользователю и улучшения защиты
- **Передача:** Да, передается на сервер в агрегированном виде (без деталей о конкретных сайтах или приложениях)

**4. Статистика использования функций:**
- **Что:** Использование функций защиты сети, родительского контроля, AI помощника
- **Как используется:** Для улучшения функциональности приложения
- **Передача:** Да, передается на сервер в обезличенном виде

**5. Токены доступа:**
- **Что:** JWT токены для авторизации
- **Как используется:** Для аутентификации пользователя при запросах к API
- **Передача:** Да, передается на сервер при каждом запросе (стандартная практика)
- **Хранение:** Локально в Keychain (зашифровано)

**6. Настройки приложения:**
- **Что:** Настройки безопасности, родительского контроля, языка интерфейса
- **Как используется:** Для сохранения пользовательских предпочтений
- **Передача:** Нет, хранятся только локально на устройстве

**7. Биометрические данные:**
- **Что:** Face ID / Touch ID
- **Как используется:** Для локальной аутентификации
- **Передача:** НЕТ, обрабатываются только локально на устройстве в Secure Enclave, никогда не передаются на сервер

**Процесс передачи данных:**

1. **Сбор данных:** Данные собираются локально на устройстве
2. **Обезличивание:** Все персональные данные обезличиваются перед передачей
3. **Шифрование:** Данные шифруются при передаче (HTTPS/TLS)
4. **Передача:** Данные передаются на наш backend сервер (Россия)
5. **Хранение:** Данные хранятся на сервере в обезличенном виде
6. **Использование:** Данные используются только для обеспечения безопасности и функциональности приложения

- **Настройки приложения:** Хранятся до удаления приложения
- **Токены доступа:** Хранятся в Keychain до удаления приложения или выхода пользователя
