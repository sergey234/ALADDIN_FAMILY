### ПРОБЛЕМА 1: КРАШ ПРИ НАЖАТИИ НА SUBSCRIBE

**Описание:**
- Приложение падает при нажатии на кнопку "Subscribe"
- Тип краша: `EXC_BREAKPOINT (SIGTRAP)`
- Происходит в главном потоке (Thread 0)
- Связано с Swift Concurrency (`libswift_Concurrency.dylib`)

**Анализ логов:**
```
Exception Type:  EXC_BREAKPOINT (SIGTRAP)
Exception Codes: 0x0000000000000001, 0x00000001024499a8
Thread 0 Crashed:
0   ALADDIN   0x1024499a8  0x10219c000 + 2808232
1   ALADDIN   0x10261e558  0x10219c000 + 4728152
2   ALADDIN   0x10261ad2c  0x10219c000 + 4713772
3   ALADDIN   0x10226d341  0x10219c000 + 856897
4   ALADDIN   0x1021f36f1  0x10219c000 + 358129
5   ALADDIN   0x10261e3d1  0x10219c000 + 4727761
6   ALADDIN   0x1021f36f1  0x10219c000 + 358129
7   libswift_Concurrency.dylib  0x192677c75 completeTaskWithClosure
```

**Причина:**
1. **Force unwrap или небезопасный доступ** в асинхронном коде
2. **Проблема с инициализацией StoreManager** - продукты могут быть не загружены
3. **Race condition** между загрузкой продуктов и попыткой покупки
4. **Отсутствие проверки на nil** перед вызовом `product.purchase()`

**Код проблемы (TariffsViewModel.swift:274):**
```swift
let transaction = try await storeManager.purchase(product)
// Если product == nil или не инициализирован → краш
```

**РЕШЕНИЕ:**

1. **Добавить защиту от nil:**
```swift
// В TariffsViewModel.swift, функция purchaseTariff()
guard let product = storeManager.product(for: productID) else {
    isLoading = false
    errorMessage = "Продукт недоступен. Пожалуйста, попробуйте позже."
    print("❌ Продукт не найден: \(productID.rawValue)")
    return
}

// Проверка что продукт загружен
guard !storeManager.products.isEmpty else {
    isLoading = false
    errorMessage = "Загрузка продуктов... Пожалуйста, подождите."
    // Попытка перезагрузки
    await storeManager.loadProducts()
    return
}
```

2. **Добавить try-catch с детальной обработкой:**
```swift
do {
    // Проверка что StoreKit доступен
    guard !storeManager.isLoading else {
        errorMessage = "Идет загрузка. Пожалуйста, подождите."
        return
    }
    
    let transaction = try await storeManager.purchase(product)
    // ... остальной код
} catch StoreError.simulatorNotSupported {
    errorMessage = "In-App Purchase недоступен в симуляторе."
} catch StoreError.productNotFound {
    errorMessage = "Продукт не найден. Проверьте настройки в App Store Connect."
} catch {
    errorMessage = "Ошибка покупки: \(error.localizedDescription)"
    print("❌ Purchase error details: \(error)")
}
```

3. **Добавить проверку инициализации StoreManager:**
```swift
// В StoreManager.swift
func purchase(_ product: Product) async throws -> Transaction? {
    // ✅ КРИТИЧЕСКАЯ ЗАЩИТА: Проверка что продукт валиден
    guard !product.id.isEmpty else {
        throw StoreError.productNotFound
    }
    
    // ✅ Проверка что StoreKit доступен
    guard !isLoading else {
        throw StoreError.storeNotReady
    }
    
    // ... остальной код
}
```

4. **Добавить enum для ошибок:**
```swift
enum StoreError: LocalizedError {
    case failedVerification
    case productNotFound
    case simulatorNotSupported
    case storeNotReady  // ✅ НОВОЕ
    case purchaseInProgress  // ✅ НОВОЕ
    
    var errorDescription: String? {
        switch self {
        case .storeNotReady:
            return "StoreKit не готов. Пожалуйста, подождите."
        case .purchaseInProgress:
            return "Покупка уже выполняется. Пожалуйста, подождите."
        // ... остальные
        }
    }
}
```

### ПРОБЛЕМА 5: VPN ПРИЛОЖЕНИЕ ОТ ФИЗИЧЕСКОГО ЛИЦА (Guideline 5.4)

**Описание:**
- Приложение использует NetworkExtension (PacketTunnelProvider)
- Это делает его VPN приложением
- VPN приложения должны быть от компании/организации, а не от физического лица

**Где найдено:**
- `ALADDIN/ALADDINPacketTunnel/Info.plist` - PacketTunnel extension
- `Core/VPN/VPNManager.swift` - VPN функциональность

**РЕШЕНИЕ:**

**ВАРИАНТ А: Перевести аккаунт на компанию (РЕКОМЕНДУЕТСЯ)**

1. **Создать Apple Developer Program аккаунт для компании:**
   - Зарегистрировать компанию/ООО
   - Создать новый Apple Developer Program аккаунт (Company/Organization)
   - Стоимость: $99/год

2. **Передать приложение:**
   - В App Store Connect → App Transfer
   - Передать приложение с текущего аккаунта (Individual) на новый (Company)
   - Процесс занимает 1-2 недели

3. **Обновить сертификаты:**
   - Создать новые сертификаты для компании
   - Обновить provisioning profiles

**ВАРИАНТ Б: Удалить VPN функциональность (НЕ РЕКОМЕНДУЕТСЯ)**

1. **Удалить NetworkExtension:**
   - Удалить `ALADDINPacketTunnel` target
   - Удалить `VPNManager.swift`
   - Удалить VPN экраны

2. **Переименовать функциональность:**
   - "VPN" → "Network Protection" или "Secure Connection"
   - Убрать все упоминания VPN

3. **ПРОБЛЕМА:** Это удалит ключевую функциональность приложения

**ВАРИАНТ В: Использовать альтернативный подход (КОМПРОМИСС)**

1. **Оставить VPN, но изменить позиционирование:**
   - Не называть это VPN в описании
   - Использовать термин "Network Protection" или "Secure Connection"
   - Убрать из категории VPN в App Store

2. **ПРОБЛЕМА:** Apple все равно может определить это как VPN по NetworkExtension

**РЕКОМЕНДАЦИЯ:**
- **Использовать Вариант А** - перевести на компанию
- Это единственный способ гарантированно решить проблему
- VPN - ключевая функция, удалять нельзя
