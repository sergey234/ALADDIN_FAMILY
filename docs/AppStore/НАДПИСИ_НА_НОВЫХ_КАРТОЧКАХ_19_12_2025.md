# НАДПИСИ НА НОВЫХ КАРТОЧКАХ ТАРИФОВ

## ВАЖНО: ДВА ВАРИАНТА

---

## ВАРИАНТ 1: БЕЗ ТЕКСТА НА ИЗОБРАЖЕНИИ (Рекомендуется Apple) ⭐

### На самом промо-изображении:
- ❌ **НЕТ текста** - только визуальные иллюстрации
- ✅ Чистая иллюстрация без надписей

### Где будет текст:
Текст отображается **вне изображения** в App Store Connect:

1. **Display Name (Название тарифа):**
   - ALADDIN INDIVIDUAL
   - ALADDIN FAMILY  
   - ALADDIN PREMIUM
   - (Это настраивается в App Store Connect, не на изображении)

2. **Description (Описание):**
   - Краткое описание до 45 символов
   - (Тоже в метаданных, не на изображении)

**Преимущества:**
- ✅ Полностью соответствует рекомендациям Apple
- ✅ Нет риска скрытия текста фреймом
- ✅ Профессиональный вид

## ВАРИАНТ 2: С ЗАГОЛОВКОМ НА ИЗОБРАЖЕНИИ (Допустимо)

### На промо-изображении будет:

#### INDIVIDUAL:
- **ALADDIN INDIVIDUAL** (72pt, белый, жирный, вверху по центру)

#### FAMILY:
- **ALADDIN FAMILY** (72pt, белый, жирный, вверху по центру)

#### PREMIUM:
- **ALADDIN PREMIUM** (72pt, белый, жирный, вверху по центру)

### Без дополнительного текста:
- ❌ НЕТ списка функций
- ❌ НЕТ описаний
- ✅ Только название тарифа (заголовок)

**Преимущества:**
- ✅ Понятно сразу какой тариф
- ✅ Все еще соответствует требованиям (крупный текст, в центре)
- ⚠️ Но Apple рекомендует избегать даже этого

## РЕКОМЕНДАЦИЯ:

### Для максимального соответствия Apple:
**ВАРИАНТ 1 - БЕЗ ТЕКСТА** ⭐

- Иллюстрация без надписей
- Название тарифа будет отображаться через Display Name в App Store Connect
- Описание будет через Description в метаданных
- Это идеально соответствует рекомендациям Apple

## ЧТО БУДЕТ ВИДЕТЬ ПОЛЬЗОВАТЕЛЬ В APP STORE:

### Если изображение БЕЗ текста:
```
┌─────────────────────────┐
│                         │
│   [ИЛЛЮСТРАЦИЯ]         │  ← Без текста, только визуал
│                         │
└─────────────────────────┘
         ↓
┌─────────────────────────┐
│ ALADDIN INDIVIDUAL      │  ← Display Name (App Store Connect)
│ Расширенная защита до   │  ← Description (App Store Connect)
│ 3 устройств...          │
└─────────────────────────┘
```

### Если изображение С заголовком:
```
┌─────────────────────────┐
│ ALADDIN INDIVIDUAL      │  ← На самом изображении (72pt)
│                         │
│   [ИЛЛЮСТРАЦИЯ]         │
│                         │
└─────────────────────────┘
         ↓
┌─────────────────────────┐
│ ALADDIN INDIVIDUAL      │  ← Display Name (может дублироваться)
│ Описание тарифа...      │  ← Description
└─────────────────────────┘
```
