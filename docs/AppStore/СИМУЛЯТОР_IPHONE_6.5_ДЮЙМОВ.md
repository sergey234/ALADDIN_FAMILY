# 📱 СИМУЛЯТОР ДЛЯ IPHONE 6.5-ДЮЙМОВОГО ДИСПЛЕЯ

**Требование App Store:** Скриншоты для iPhone 6.5" (1242x2688 пикселей)

---

## 🎯 ПРАВИЛЬНЫЙ СИМУЛЯТОР

### ✅ iPhone 11 Pro Max (РЕКОМЕНДУЕТСЯ)

**Параметры:**
- **Размер дисплея:** 6.5 дюймов
- **Разрешение:** 1242 x 2688 пикселей
- **Масштаб:** 3x (@3x)
- **Соотношение сторон:** 19.5:9

**Как выбрать в Xcode:**
1. В Xcode нажмите на список устройств (вверху)
2. Выберите **"iOS Simulator"**
3. Найдите **"iPhone 11 Pro Max"**
4. Выберите его

**Команда для запуска:**
```bash
xcrun simctl boot "iPhone 11 Pro Max"
```

## 🖼️ КАК СДЕЛАТЬ СКРИНШОТЫ

### В Xcode:

1. **Запустите приложение** в симуляторе iPhone 11 Pro Max
2. **Откройте нужный экран**
3. **Сделайте скриншот:**
   - **Mac:** `Cmd + S` (в симуляторе)
   - Или: **Device** → **Screenshot** в меню симулятора

### Через команду:

```bash
xcrun simctl io booted screenshot screenshot_6.5.png
```

**Результат:**
- Файл будет сохранен в текущей директории
- Разрешение: 1242x2688 пикселей
- Формат: PNG

## ✅ ПРОВЕРКА РАЗРЕШЕНИЯ

### После создания скриншота:

```bash
# Проверить размер скриншота
file screenshot_6.5.png
sips -g pixelWidth -g pixelHeight screenshot_6.5.png
```

**Должно быть:**
- **Width:** 1242 пикселей
- **Height:** 2688 пикселей
