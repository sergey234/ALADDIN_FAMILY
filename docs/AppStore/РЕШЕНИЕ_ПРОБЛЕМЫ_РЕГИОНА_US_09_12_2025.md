# ✅ РЕШЕНИЕ: РЕГИОН ОПРЕДЕЛЯЕТСЯ КАК 'US' ВМЕСТО 'RU'

**Дата:** 9 декабря 2025  
**Проблема:** Симулятор определяет регион как 'US', поэтому открывается IAP вместо сайта

---

## 🔍 ЧТО ВИДНО В ЛОГАХ

```
🔍 DEBUG Payment: regionCode = 'US', useAlternativePayments = false
🌍 Не российский регион: открываем IAP
```

**Проблема:**
- Регион определяется как 'US' (США)
- `useAlternativePayments = false`
- Код попадает в блок IAP вместо блока QR оплаты

---

## ✅ РЕШЕНИЕ: УСТАНОВИТЬ РЕГИОН В СИМУЛЯТОРЕ

### Способ 1: Через настройки симулятора (рекомендуется)

1. **В симуляторе:**
   - Откройте приложение **Settings** (Настройки)
   - Перейдите: **General** → **Language & Region**
   - Найдите **"Region"**
   - Нажмите на текущий регион (сейчас "United States")
   - Выберите **"Russia"** (Россия)
   - Нажмите **"Done"**

2. **Перезапустите приложение:**
   - Остановите приложение в Xcode (⌘.)
   - Запустите снова (⌘R)

3. **Проверьте:**
   - Откройте экран тарифов
   - Нажмите "Оформить подписку"
   - В консоли должно быть:
     ```
     🔍 DEBUG Payment: regionCode = 'RU', useAlternativePayments = true
     🇷🇺 Российский регион: открываем сайт для QR оплаты
     ```

---

### Способ 2: Через настройки Xcode

1. **В Xcode:**
   - Выберите симулятор в верхней панели
   - Device → Device Settings
   - Language & Region → Region
   - Установите **"Russia"**

2. **Перезапустите приложение**

---

### Способ 3: Временное решение для тестирования (только для разработки)

**Файл:** `Core/Config/AppConfig.swift`  
**Строки:** 187-189

**Временно изменить:**
```swift
static var isRussianRegion: Bool {
    #if DEBUG
    // ✅ ВРЕМЕННО: Для тестирования в симуляторе
    // Раскомментируйте следующую строку для принудительной установки России:
    return true  // Принудительно Россия
    #endif
```

**⚠️ ВАЖНО:** 
- Это только для тестирования!
- После тестирования верните обратно: `return Locale.current.regionCode == "RU"`

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ

### Шаг 1: Открыть настройки в симуляторе

1. В симуляторе найдите иконку **Settings** (⚙️)
2. Нажмите на неё

### Шаг 2: Перейти в Language & Region

1. Прокрутите вниз до **"General"**
2. Нажмите **"General"**
3. Найдите **"Language & Region"**
4. Нажмите на него

### Шаг 3: Изменить Region

1. Найдите **"Region"**
2. Нажмите на текущий регион (сейчас "United States")
3. В списке найдите **"Russia"** (Россия)
4. Нажмите на "Russia"
5. Нажмите **"Done"** в правом верхнем углу

### Шаг 4: Перезапустить приложение

1. В Xcode остановите приложение (⌘.)
2. Запустите снова (⌘R)
3. Откройте экран тарифов
4. Нажмите "Оформить подписку"

### Шаг 5: Проверить консоль

**Должно быть:**
```
🔍 DEBUG Payment: regionCode = 'RU', useAlternativePayments = true
🇷🇺 Российский регион: открываем сайт для QR оплаты
🌐 Открываем сайт: https://aladdin-ai.ru с тарифом: premium
✅ URLHelper.openWebsite: открываем URL https://aladdin-ai.ru?tariff=premium
```

**И должно открыться Safari с сайтом!**
