## ✅ ПОДТВЕРЖДЕННЫЕ ИЗМЕНЕНИЯ

### 1. Antivirus Card - ОСТАВИТЬ СТАТИСТИКУ

**Что оставить:**
- ✅ Заголовок: "Антивирус"
- ✅ Toggle: включить/выключить
- ✅ Статистика (4 показателя):
  - Файлов проверено
  - Угроз найдено
  - Последняя проверка
  - Защита (%)
- ✅ Кнопка: "Запустить проверку"

**Как будет выглядеть:**
```

│                             │

│  │ Файл│ Угр │ Наз │ Защ │ │

│                             │
│  [  Запустить проверку  ]   │
└─────────────────────────────┘
```

### 2. Безопасное соединение Status Card - КОМПАКТНАЯ ВЕРСИЯ

**Что оставить:**
- ✅ Заголовок: "Безопасное соединение"
- ✅ Индикатор (красный/зеленый) небольшого размера
- ✅ Кнопка: Включить/Выключить

**Что убрать:**
- ❌ Большая иконка щита
- ❌ Текст "Защищено" / "Не защищено"
- ❌ Описание "Соединение защищено"
- ❌ Все лишнее

**Как будет выглядеть:**
```
┌─────────────────────────────┐
│  Безопасное соединение      │
│                             │
│  🟢 (или 🔴)                │
│                             │
│  [  Включить  ]             │
│  или                        │
│  [ Выключить ]              │
└─────────────────────────────┘
```

**Индикатор:**
- 🟢 Зеленый = Включено
- 🔴 Красный = Выключено
- Небольшого размера (например, 20x20 или 24x24)
