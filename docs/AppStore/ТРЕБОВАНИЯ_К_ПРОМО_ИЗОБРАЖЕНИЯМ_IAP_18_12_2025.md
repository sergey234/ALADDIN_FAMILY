## 📋 ТРЕБОВАНИЯ К ИЗОБРАЖЕНИЯМ

### Технические требования:

- ✅ **Размер:** 1024x1024 пикселей (обязательно!)
- ✅ **Формат:** PNG или JPEG (рекомендуется PNG)
- ✅ **Не скриншот** из приложения
- ✅ **Уникальное изображение** (не повторяет другие)
- ✅ **Читаемый текст** (минимум 20pt, лучше 24–40pt)
- ✅ **Высокое качество** (не размытое)

### Дизайн требования:

- ✅ **Название тарифа:** крупным шрифтом (40–60pt), жирный
- ✅ **Основные функции:** (20–24pt), читаемый
- ✅ **Визуальные элементы:** иконки, графика, не просто текст
- ✅ **Цветовая схема:** соответствует бренду ALADDIN
- ✅ **Контрастность:** текст хорошо читается на фоне

## 🎨 СПЕЦИФИКАЦИЯ ДЛЯ BASIC ТАРИФА

### Информация о тарифе (из StoreManager.swift):

```swift
case basic = "family.aladdin.ios.subscription.basic.v2"
displayName: "Базовый" (RU) / "Basic" (EN)
description: "1 устройство, базовая защита"
features: ["1 устройство", "Базовая защита", "Ограниченная аналитика"]
```

### Что должно быть на изображении BASIC:

#### 🇷🇺 Русская версия (`basic_ru_1024x1024.png`):

1. **Заголовок:** "БАЗОВЫЙ" или "BASIC" (40–60pt, жирный, верх)
2. **Подзаголовок:** "Для одного пользователя" (24–30pt, по центру)
3. **Основные функции** (20–24pt, читаемый):
   - ✅ 1 устройство
   - ✅ Базовая защита
   - ✅ Ограниченная аналитика
4. **Визуальные элементы:**
   - Иконка/графика: щит, один телефон/устройство
   - Цвет: базовый (можно синий/зеленый)
5. **Фон:** чистый, не скриншот приложения

#### 🇬🇧 Английская версия (`basic_en_1024x1024.png`):

1. **Заголовок:** "BASIC" (40–60pt, bold, top)
2. **Подзаголовок:** "For one user" (24–30pt, center)
3. **Основные функции** (20–24pt, readable):
   - ✅ 1 device
   - ✅ Basic protection
   - ✅ Limited analytics
4. **Визуальные элементы:**
   - Icon/graphics: shield, one phone/device
   - Color: basic (blue/green)
5. **Background:** clean, not app screenshot

## 📐 ШАБЛОН КОМПОЗИЦИИ (1024x1024)

### Структура изображения:

```
┌─────────────────────────────────────┐
│                                     │
│         [ЛОГОТИП/ИКОНКА]           │ 100-150px
│                                     │
│         "BASIC" / "БАЗОВЫЙ"        │ 40-60pt, жирный
│    "For one user" / "Для одного"   │ 24-30pt
│                                     │
│  ┌─────────────────────────────┐   │
│  │  ✅ 1 device / 1 устройство  │   │
│  │  ✅ Basic protection         │   │ 20-24pt
│  │  ✅ Limited analytics        │   │
│  └─────────────────────────────┘   │
│                                     │
│      [ВИЗУАЛЬНЫЙ ЭЛЕМЕНТ]          │
│    (щит, устройство, графика)      │
│                                     │
└─────────────────────────────────────┘
```

### Отступы:
- Верх: 50-80px (для логотипа/иконки)
- Заголовок: отступ 40px от верха
- Функции: отступ 60px от заголовка
- Визуальный элемент: нижняя треть изображения
- Боковые отступы: 60-80px
