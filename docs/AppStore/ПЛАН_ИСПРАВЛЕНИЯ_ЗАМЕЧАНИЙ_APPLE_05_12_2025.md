### ✅ ПРОБЛЕМА 1: Guideline 2.1 - Face Data (Данные лица)

**Что спрашивает Apple:**
- Какие данные лица собирает приложение?
- Как используются эти данные?
- Передаются ли третьим лицам? Где хранятся?
- Как долго хранятся?
- Где в Privacy Policy это описано?

**ПРОСТОЕ ОБЪЯСНЕНИЕ:**
Приложение **НЕ собирает данные лица** (face data). Мы используем только **Face ID** - это встроенная функция iOS для аутентификации. Face ID работает **локально на устройстве**, данные лица **не покидают устройство** и **не передаются** никуда.

**ЧТО НУЖНО СДЕЛАТЬ:**
1. ✅ Обновить Privacy Policy - добавить раздел о Face ID
2. ✅ Ответить на вопросы Apple в App Review Information
3. ✅ Уточнить описание в Info.plist (NSFaceIDUsageDescription уже есть)

**ПЛАН РЕАЛИЗАЦИИ:**
1. Открыть `docs/legal/privacy.md`
2. Добавить раздел:
   ```
   ## Face ID (Распознавание лица)
   
   Приложение использует Face ID для безопасной аутентификации пользователя.
   - Данные лица НЕ собираются
   - Данные лица НЕ передаются третьим лицам
   - Данные лица хранятся только локально на устройстве (в Secure Enclave)
   - Данные лица НЕ сохраняются на наших серверах
   - Данные лица удаляются при удалении приложения
   ```
3. В App Store Connect → App Review Information → Notes добавить ответы на вопросы

**ПЛАН РЕАЛИЗАЦИИ:**
1. В App Store Connect → App Review Information → Notes добавить:
   ```
   Как получить код:
   - При создании новой семьи автоматически генерируется Recovery Code
   - Код отображается в модальном окне после создания семьи
   - Код можно скопировать или поделиться через QR-код
   
   Плата:
   - Код БЕСПЛАТНЫЙ
   ```

### ✅ ПРОБЛЕМА 4: Guideline 2.1 - КРАШ на iPad

**Что говорит Apple:**
Приложение крашится при нажатии на кнопку Share на iPad Air 11-inch (M3), iPadOS 26.1

**ПРОСТОЕ ОБЪЯСНЕНИЕ:**
На iPad `UIActivityViewController` должен отображаться как **popover** (всплывающее окно), а не как sheet. Нужно указать `popoverPresentationController` с источником (sourceView или barButtonItem).

**ЧТО НУЖНО СДЕЛАТЬ:**
1. ✅ Исправить ShareSheet для iPad
2. ✅ Добавить поддержку popover
3. ✅ Протестировать на iPad

**ПЛАН РЕАЛИЗАЦИИ:**
1. Найти все места где используется ShareSheet
2. Обновить ShareSheet компонент:
   ```swift
   struct ShareSheet: UIViewControllerRepresentable {
       let activityItems: [Any]
       var sourceView: UIView? = nil
       
       func makeUIViewController(context: Context) -> UIActivityViewController {
           let controller = UIActivityViewController(
               activityItems: activityItems,
               applicationActivities: nil
           )
           
           // Для iPad - popover
           if let popover = controller.popoverPresentationController {
               if let sourceView = sourceView {
                   popover.sourceView = sourceView
                   popover.sourceRect = sourceView.bounds
               } else {
                   // Fallback на центр экрана
                   popover.sourceView = UIApplication.shared.windows.first
                   popover.sourceRect = CGRect(x: UIScreen.main.bounds.width/2, y: UIScreen.main.bounds.height/2, width: 0, height: 0)
               }
               popover.permittedArrowDirections = .any
           }
           
           return controller
       }
   }
   ```
3. Обновить все места использования ShareSheet

### ✅ ПРОБЛЕМА 8: Guideline 2.1 - Бизнес-модель

**Что спрашивает Apple:**
- Кто использует платный контент и подписки?
- Где можно купить?
- Какой контент доступен?
- Какие платные функции не используют in-app purchase?

**ПРОСТОЕ ОБЪЯСНЕНИЕ:**
Приложение использует **гибридную модель**:
- Подписка через **App Store (IAP)** - для iOS пользователей
- Подписка через **сайт (QR-код)** - для пользователей Android или тех, кто предпочитает оплату на сайте

**ЧТО НУЖНО СДЕЛАТЬ:**
1. ✅ Ответить на все вопросы в App Review Information
2. ✅ Объяснить бизнес-модель

**ПЛАН РЕАЛИЗАЦИИ:**
1. В App Store Connect → App Review Information → Notes добавить:
   ```
   Бизнес-модель:
   
   1. Кто использует платный контент:
   - Все пользователи, которые хотят получить доступ к премиум функциям
   - Подписка активируется через код активации
   
   2. Где можно купить:
   - В приложении: через App Store In-App Purchase (IAP)

   - Оплата на сайте → получение кода → активация в приложении
   - Это альтернативный способ оплаты для пользователей, которые предпочитают оплату на сайте
   - Код активации вводится вручную в приложении
   ```
