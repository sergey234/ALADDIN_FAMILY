## 📋 ШАГ 3: НАСТРОЙКА РОУТИНГА

### ВАРИАНТ 1: РЕДИРЕКТ (РЕКОМЕНДУЕТСЯ)

Добавить в конфиг nginx (внутри блока `server { ... }`):

```nginx
# Редирект /privacy на privacy.html
location = /privacy {
    return 301 /privacy.html;
}

# Редирект /terms на terms.html
location = /terms {
    return 301 /terms.html;
}
```

**Полный пример блока server:**

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name aladdin-ai.ru www.aladdin-ai.ru;
    
    root /var/www/aladdin-ai.ru;
    index index.html;
    
    # Редирект /privacy на privacy.html
    location = /privacy {
        return 301 /privacy.html;
    }
    
    # Редирект /terms на terms.html
    location = /terms {
        return 301 /terms.html;
    }
    
    # Остальные location блоки...
    location / {
        try_files $uri $uri/ =404;
    }
}
```

### ВАРИАНТ 2: ПРЯМОЕ ОТОБРАЖЕНИЕ (БЕЗ РЕДИРЕКТА)

Добавить в конфиг nginx:

```nginx
# Прямое отображение privacy.html
location = /privacy {
    try_files /privacy.html =404;
}

# Прямое отображение terms.html
location = /terms {
    try_files /terms.html =404;
}
```

### ВАРИАНТ 3: СИМВОЛИЧЕСКИЕ ССЫЛКИ

```bash
cd /var/www/aladdin-ai.ru
# или другой путь к сайту

# Создать символические ссылки
ln -s privacy.html privacy

**Должны увидеть:**
```

**Плюсы:** Не нужно редактировать nginx  
**Минусы:** Может не работать если nginx не разрешает следовать символическим ссылкам

## 🔧 РЕШЕНИЕ ПРОБЛЕМ

### Проблема 1: "nginx: command not found"

**Решение:**
```bash
# Установить nginx
apt-get update
apt-get install nginx
```

### Проблема 2: "403 Forbidden"

**Решение:**
```bash
# Проверить права доступа
chmod 644 /var/www/aladdin-ai.ru/privacy.html
chmod 644 /var/www/aladdin-ai.ru/terms.html
chown www-data:www-data /var/www/aladdin-ai.ru/privacy.html
chown www-data:www-data /var/www/aladdin-ai.ru/terms.html
```

### Проблема 3: "404 Not Found"

**Решение:**
- Проверить что файлы существуют: `ls -la /var/www/aladdin-ai.ru/privacy.html`
- Проверить путь в конфиге nginx: `root /var/www/aladdin-ai.ru;`
- Проверить что файлы доступны: `cat /var/www/aladdin-ai.ru/privacy.html | head`

### Проблема 4: Редирект не работает

**Решение:**
- Проверить что location блоки добавлены ПЕРЕД `location / {`
- Проверить синтаксис: `nginx -t`
- Перезагрузить nginx: `systemctl reload nginx`
