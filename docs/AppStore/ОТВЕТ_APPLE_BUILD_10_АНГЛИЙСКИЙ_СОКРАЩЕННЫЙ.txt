GUIDELINE 2.1 - PERFORMANCE - APP COMPLETENESS (SUBSCRIPTION ERROR ON IPAD)

Clarification: In the current version, the ALADDIN app is optimized and tested only for iPhone. iPad support is disabled in project settings. As we previously notified you in our letter dated December 5, 2025, the current version of the mobile app is not intended for iPad.

Technical Project Settings:

TARGETED_DEVICE_FAMILY = "1" (iPhone only) set in project settings

LSRequiresIPhoneOS = true set in Info.plist

App compiled only for iPhone

App is not intended for installation on iPad in current version

Users will not be able to download the app on iPad from App Store

Our Positioning:

1. The app is not intended for installation on iPad in the current version

2. We have not tested the app on iPad. We plan to add iPad support in the near future in upcoming updates.

3. All app functions have been tested on iPhone

4. iPad support will be considered in future versions after full interface adaptation.

The error on iPad is not an issue, as the app is currently not fully adapted for iPad in the current version.
