### 2. ✅ Проверка загрузки продуктов перед покупкой

**Файл:** `Core/Store/StoreManager.swift`  
**Строки:** 156-164

**Код:**
```swift
// ✅ ДОБАВЛЕНО ДЛЯ IPAD: Проверка что продукты загружены
guard !products.isEmpty else {
    print("⚠️ [StoreManager] Products not loaded, attempting to load...")
    await loadProducts()
    guard !products.isEmpty else {
        print("❌ [StoreManager] Failed to load products")
        throw StoreError.productsNotLoaded
    }
}
```

**Поможет:** ✅ Да - может быть причиной ошибки на iPad

**Почему это важно:**
- На iPad продукты могут загружаться медленнее
- StoreKit может работать по-разному на iPad
- Автоматическая перезагрузка продуктов решает проблему
