## 💳 ВАРИАНТЫ ДЛЯ КНОПКИ ОПЛАТЫ

### ✅ ВАРИАНТ А: Проверять регион в getButtonText

**Что делаем:**
- Для России → "Оплата по QR" (вместо "Перейти на сайт")
- Для остальных → "Subscribe" / "Оформить подписку"

**Техническая реализация:**

**Файл:** `Screens/10_TariffsScreen.swift`  
**Функция:** `getButtonText(for tariff:)` (строки 189-198)

**Новый код:**
```swift
private func getButtonText(for tariff: TariffType) -> String {
    if tariff == .free {
        return localizationManager.localized("tariffs_free_button")
    } else if selectedTariff == tariff {
        return localizationManager.localized("tariffs_selected")
    } else {
        // ✅ Проверяем регион
        if AppConfig.useAlternativePayments {
            // Россия → QR оплата
            return localizationManager.localized("tariffs_qr_payment_button")
        } else {
            // Не Россия → IAP через App Store
            return localizationManager.localized("tariffs_purchase_button")
        }
    }
}
```

**Что нужно добавить в LocalizationManager:**

**Русский (строка ~1357):**
```swift
"tariffs_qr_payment_button": "Оплата по QR",
"tariffs_purchase_button": "Оформить подписку",
```

**Английский (строка ~3870):**
```swift
"tariffs_qr_payment_button": "Pay via QR",
"tariffs_purchase_button": "Subscribe",
```

**Как это работает:**

1. **Пользователь в России:**
   - Видит кнопку: "Оплата по QR"
   - Нажимает → открывается сайт aladdin-ai.ru
   - Оплачивает через QR-код
   - Получает код активации
   - Вводит код в приложении

2. **Пользователь в США/Европе:**
   - Видит кнопку: "Subscribe" / "Оформить подписку"
   - Нажимает → открывается стандартное окно App Store
   - Видит: "ALADDIN Premium - $9.99/month"
   - Нажимает "Купить" → оплачивает через Apple Pay
   - Подписка активируется автоматически
   - **НЕТ перехода на сайт!**

**Плюсы:**
- ✅ Полностью соответствует Guideline 3.1.1
- ✅ Для не-российских регионов всегда IAP
- ✅ Для России четко указано "Оплата по QR" (понятно пользователю)
- ✅ Минимальные изменения в коде
- ✅ Логика уже есть в `AppConfig.useAlternativePayments`
- ✅ Разные тексты для разных регионов (более понятно)

**Минусы:**
- ⚠️ Нужно добавить две строки локализации
- ⚠️ Российские пользователи видят "Оплата по QR" (но это нормально, так как IAP в России недоступен)

**Сложность:** ⭐ (очень просто)
