1. WHAT TOOLS, UTILITIES, FRAMEWORKS OR APIs ARE USED?

Security features:

• LocalAuthentication (iOS) - Biometric authentication (Face ID/Touch ID). Data is processed only on the device.

• CryptoKit (iOS) - Local data encryption (AES-256-GCM). Data is encrypted locally.

• Security framework (iOS) - Keychain Services for secure token storage. Data is stored only locally.

• URLSession (iOS) - Network requests via HTTPS/TLS 1.2+ for backend communication.

• Alamofire (v5.8) - HTTP client. Does not collect user data.

• KeychainAccess (v4.2) - Keychain wrapper. Does not collect user data.

Parental control features:

• SwiftUI (iOS) - User interface.

• UserDefaults (iOS) - Local storage of parental control settings.

• Combine (iOS) - State management.

• Custom REST API - Own backend server for obtaining data about (User ID, Device ID, Family ID) users and their statistics.

NetworkExtension is not used and ScreenTime framework is not used.

2. DOES THE APP COLLECT, STORE OR TRANSMIT USER DATA?

The app collects, stores and transmits De-identified data for security purposes.

What is collected:

• Anonymous identifiers (User ID, Device ID, Family ID)

• Technical data (device type, iOS version, app version)

• Security statistics (de-identified: number of threats, threat type, without details)

• Function usage statistics (on/off protection, parental control usage)

What is NOT collected:

• Names, surnames, dates of birth, addresses, phones, email

• Passport data, SNILS, TIN

• Financial and medical data

• Website visit history, message content, passwords

• Geolocation

Where stored:

• Locally: UserDefaults, Keychain (encrypted), local memory

• On server: De-identified statistics on backend server (Russia)

Transmission: Only via HTTPS/TLS 1.2+, de-identified data

3. WHAT DATA IS COLLECTED, HOW IS IT USED AND IS IT TRANSMITTED FROM THE DEVICE?

Detailed list:

1. Registration data (anonymous):

   • Family role (Mom-Dad-Son-Daughter-Grandmother-Grandfather), age group 5-60+

   • Usage: Interface and function configuration

   • Transmission: In de-identified form

2. Device technical data:

   • Device type, model, iOS version

   • Usage: Compatibility and performance improvement

   • Transmission: Yes, for technical support

3. Threat statistics (de-identified):

   • Number of threats, threat type (category), detection time

   • Usage: Statistics display and protection improvement

   • Transmission: Yes, in aggregated form (without details about websites/applications)

4. Function usage statistics:

   • Usage, parental control, AI assistant

   • Usage: Functionality improvement

   • Transmission: Yes, in de-identified form

5. Access tokens:

   • JWT tokens for authorization

   • Usage: Authentication for API requests

   • Transmission: Yes, with each request (standard practice)

   • Storage: Locally in Keychain (encrypted)

6. App settings:

   • Security settings, parental control, language

   • Usage: Saving user preferences

   • Transmission: NO, stored only locally

7. Biometric data:

   • Face ID / Touch ID

   • Usage: Local authentication

   • Transmission: NO, processed only locally in Secure Enclave

Process: Collection → De-identification → Encryption → Transmission (HTTPS) → Storage on server

6. WHAT ARE THE DATA RETENTION POLICIES AND WHERE ARE THEY DOCUMENTED?

Retention policies:

Local data (on device):

• Settings: Until app deletion

• Tokens: In Keychain until app deletion or logout

• Encryption keys: In Keychain until app deletion

• Cache: Automatically cleared when space is low

Data on server:

• Anonymous session IDs: 24 hours

• Threat statistics: 30 days (de-identified)

• Aggregated analytics: 1 year

• Technical logs: 7 days

Data deletion:

• When account is deleted, all data is deleted within 30 days

• Local data is deleted immediately when app is deleted

• User can request data deletion by contacting support (contacts are indicated in privacy policy)

Where documented:

• In the app: Settings → Privacy Policy → "Data Retention Periods" section

• In privacy policy: Complete information about retention policy and data deletion procedure

User data is not shared with third parties.

Exceptions (technical services):

1. Backend server (our own):

   • Data: De-identified data for security

   • Purpose: Functionality provision, threat protection

What is NOT shared:

• Data is NOT shared with advertising networks

• Data is NOT shared with analytics services (Firebase, Google Analytics)
