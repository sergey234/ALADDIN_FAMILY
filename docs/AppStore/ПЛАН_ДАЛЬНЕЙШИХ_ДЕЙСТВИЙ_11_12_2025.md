### 🎯 ПРИОРИТЕТ 1: НАСТРОЙКА СЕРВЕРА (30 минут)

**Задача:** Настроить роутинг для `/privacy` и `/terms`

**Инструкция:** `docs/AppStore/ИНСТРУКЦИЯ_НАСТРОЙКА_РОУТИНГА_СЕРВЕР_11_12_2025.md`

**Шаги:**
1. Подключиться к серверу: `ssh root@149.154.65.180`
2. Отредактировать nginx конфиг: `/etc/nginx/sites-available/aladdin-ai.ru`
3. Добавить location блоки:
   ```nginx
   location = /privacy {
       return 301 /privacy.html;
   }
   location = /terms {
       return 301 /terms.html;
   }
   ```
4. Проверить: `nginx -t`
5. Перезагрузить: `systemctl reload nginx`
6. Проверить работу: 
   ```bash
   curl -I https://aladdin-ai.ru/privacy
   curl -I https://aladdin-ai.ru/terms
   ```

**Ожидаемый результат:**
- ✅ `https://aladdin-ai.ru/privacy` → показывает `privacy.html`
- ✅ `https://aladdin-ai.ru/terms` → показывает `terms.html`

### 🎯 ПРИОРИТЕТ 2: APP STORE CONNECT - ПРОДУКТЫ (1-2 часа)

**Задача:** Создать и настроить In-App Purchase продукты

**Шаги:**

1. **Войти в App Store Connect:**
   - https://appstoreconnect.apple.com
   - Выбрать приложение ALADDIN

2. **Создать 4 продукта подписки:**
   - Basic (месяц)
   - Individual (месяц)
   - Family (месяц)
   - Premium (месяц)

3. **Для каждого продукта:**
   - Product ID: `family.aladdin.ios.subscription.basic` (и т.д.)
   - Тип: Auto-Renewable Subscription
   - Цена: установить согласно тарифам
   - Локализация: русский и английский
   - Описание: добавить описание тарифа

4. **Добавить скриншоты для App Review:**
   - Для каждого продукта добавить скриншот экрана подписки
   - Размер: согласно требованиям Apple
   - Формат: PNG или JPEG

5. **Отправить на проверку:**
   - После создания всех продуктов, отправить на проверку Apple

**Важно:**
- Product ID должны совпадать с теми, что в коде приложения
- Проверить что продукты одобрены Apple перед отправкой приложения
