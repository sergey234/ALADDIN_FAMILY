### Guideline 3.1.1 - Business - Payments - In-App Purchase

**Проблема:**
- Приложение включает или получает доступ к платному цифровому контенту, услугам или функциональности способами, отличными от in-app purchase
- Подписки, купленные вне приложения, доступны, но эти подписки недоступны для покупки через in-app purchase

**Требование:**
- Все платные подписки должны быть доступны для покупки через in-app purchase
- Приложение должно использовать только in-app purchase для покупки подписок

## ✅ ТЕХНИЧЕСКИЕ ИЗМЕНЕНИЯ В КОДЕ

### 1. ИСПРАВЛЕНИЕ КРИТИЧЕСКОГО НЕСООТВЕТСТВИЯ IAP

**Файл:** `Core/Config/AppConfig.swift`

**Проблема:**
- `useAlternativePayments` всегда возвращал `true`
- IAP был отключен для всех пользователей
- Это нарушало Guideline 3.1.1

**Исправление:**

**Было:**
```swift
static var useAlternativePayments: Bool {
    // ✅ ВСЕГДА true - используем только QR оплату (IAP в России недоступен)
    return true
}
```

**Стало:**
```swift
/**
 * Включить альтернативные способы оплаты (QR-коды)
 * В России IAP недоступен → используем QR оплату
 * Для остальных стран → используем IAP (App Store)
 * 
 * ✅ ИСПРАВЛЕНО: Использовать QR оплату ТОЛЬКО для России
 * Для соответствия Guideline 3.1.1 IAP должен быть доступен для всех стран кроме России
 */
static var useAlternativePayments: Bool {
    // Использовать QR оплату ТОЛЬКО для России
    return isRussianRegion
}
```

**Результат:**
- ✅ Для России: QR оплата (IAP недоступен)
- ✅ Для остальных стран: IAP (App Store)
- ✅ Соответствует Guideline 3.1.1

**Строки кода:** 199-202

## 📊 ТЕКУЩАЯ РЕАЛИЗАЦИЯ IAP

### StoreManager.swift

**Файл:** `Core/Store/StoreManager.swift`

**Реализованные функции:**

1. **Product Loading:**
   - `loadProducts()` - загрузка продуктов из App Store
   - Использует `Product.products(for: productIDs)` (StoreKit 2)
   - Строки: 92-115

2. **Purchase Flow:**
   - `purchase(_ product: Product)` - покупка подписки
   - Использует `product.purchase()` (StoreKit 2)
   - Строки: 117-145

3. **Transaction Verification:**
   - `checkVerified(_ result: VerificationResult<Transaction>)` - верификация транзакций
   - Строки: 126, 229

4. **Subscription Management:**
   - `updatePurchasedProducts()` - обновление статуса подписок
   - Использует `Transaction.currentEntitlements` (StoreKit 2)
   - Строки: 147-197

5. **Restore Purchases:**
   - `restorePurchases()` - восстановление покупок
   - Использует `AppStore.sync()` (StoreKit 2)
   - Строки: 168-178

6. **Transaction Listener:**
   - `listenForTransactions()` - слушатель транзакций
   - Использует `Transaction.updates` (StoreKit 2)
   - Строки: 199-234

**Product IDs:**
