# АНАЛИЗ И УЛУЧШЕНИЯ ПРОМО-ИЗОБРАЖЕНИЙ IAP

## ТРЕБОВАНИЯ APPLE ДЛЯ ПРОМО-ИЗОБРАЖЕНИЙ IAP:

1. **Размер:** Точно 1024x1024 пикселей ✅
2. **Формат:** PNG или JPG, RGB, 72 dpi, flattened (без альфа-канала) ✅
3. **НЕ скриншот** - уникальное изображение ✅
4. **Читаемый текст:**
   - Минимум 20pt (но лучше 24-40pt для основного текста)
   - Название тарифа: 40-60pt (лучше 60-72pt)
   - Основные функции: 20-24pt (лучше 26-28pt)
5. **Точное представление IAP продукта** ✅

## ВОЗМОЖНЫЕ ПРОБЛЕМЫ С ТЕКУЩИМИ ИЗОБРАЖЕНИЯМИ:

### 1. РАЗМЕР ШРИФТА
**Текущее состояние:**
- Заголовок: 64pt (может быть недостаточно крупным)
- Функции: 26pt (хорошо, но можно увеличить до 28-30pt)
- Номера: 30pt (можно увеличить до 32-34pt)

**Рекомендация:** 
- Увеличить заголовок до **72-80pt** для лучшей читаемости
- Увеличить функции до **28-30pt**
- Увеличить номера до **32-34pt**

### 2. КОНТРАСТНОСТЬ ТЕКСТА
**Текущее состояние:**
- Белый текст на темном фоне (хорошо, но может быть лучше)
- Тени используются, но могут быть усилены

**Рекомендация:**
- Добавить более яркую тень/контур для текста
- Увеличить контрастность белого текста
- Возможно использовать полужирный шрифт для всех текстов

### 3. ПЛОТНОСТЬ ИНФОРМАЦИИ
**Текущее состояние:**
- Много функций на одном изображении
- Функции могут перекрываться или быть слишком мелкими

**Рекомендация:**
- Увеличить межстрочный интервал между функциями
- Уменьшить количество функций, показать только самые важные (5-7 функций)
- Увеличить отступы от краев

### 4. ВИЗУАЛЬНАЯ ИЕРАРХИЯ
**Текущее состояние:**
- Заголовок, функции, декоративные элементы
- "Изюминка" в правом верхнем углу может отвлекать

**Рекомендация:**
- Сделать заголовок более заметным (больше, контрастнее)
- Упростить декоративные элементы, чтобы не отвлекать от текста
- Сделать "изюминку" менее заметной или убрать

### 5. ЧИТАЕМОСТЬ НА МАЛЫХ ЭКРАНАХ
**Текущее состояние:**
- Изображение 1024x1024 будет отображаться на разных устройствах
- Текст может быть слишком мелким на некоторых экранах

**Рекомендация:**
- Убедиться, что даже самый мелкий текст читаем на 1024px экране
- Протестировать изображение при уменьшении до 50% (512px)

1. **Шрифт:**
   - Использовать более жирный шрифт (bold) для всех текстов
   - Увеличить все размеры шрифтов на 10-15%

2. **Контраст:**
   - Добавить более толстую тень (offset 4-5px вместо 3px)
   - Использовать более яркий белый (#FFFFFF вместо текущего)

3. **Размещение:**
   - Увеличить отступы от краев до 80-100px
   - Увеличить межстрочный интервал между функциями на 20-30%

4. **Упрощение:**
   - Уменьшить количество декоративных элементов
   - Сделать рамку менее заметной
   - Упростить "изюминку" или сделать её менее контрастной
