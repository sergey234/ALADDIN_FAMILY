## ⚠️ ЧТО НУЖНО СДЕЛАТЬ СЕЙЧАС

### 1. Изменить Age Rating (5 минут)

1. Зайти в **App Store Connect**
2. **My Apps** → **ALADDIN**
3. **App Information** (слева)
4. **Age Rating**
5. **In-App Controls:**
   - Parental Controls: **None** ✅
   - Age Assurance: **None** ✅
6. **Сохранить**

---

### 2. Добавить ответы в App Review Information (10 минут)

1. **App Store Connect** → **My Apps** → **ALADDIN**
2. Версия **1.0.0 (4)** → **App Review Information**
3. В поле **"Notes"** скопировать ответы из файла:
   ```
   docs/AppStore/ОТВЕТЫ_ДЛЯ_APPLE_05_12_2025.md
   ```
4. **Сохранить**

---

### 3. Сгенерировать и загрузить демо QR-код (5 минут)

**Способ 1: Онлайн генератор (самый простой)**
1. Перейти на https://www.qr-code-generator.com/
2. Ввести текст: `FAM-DEMO-CODE-2025`
3. Скачать QR-код как изображение (PNG)
4. В **App Review Information** → **Attachments** → загрузить QR-код

**Способ 2: Использовать приложение**
1. Открыть приложение
2. Создать семью
3. В RecoveryCodeModal будет показан QR-код
4. Сделать скриншот
5. Загрузить в App Review Information

---

### 4. Собрать и отправить новую версию (15 минут)

1. **Xcode** → **Product** → **Archive**
2. **Distribute App** → **App Store Connect**
3. Загрузить новую версию
4. В **App Store Connect** → **Submit for Review**
