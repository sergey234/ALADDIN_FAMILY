## 📋 ПРИЧИНА ПРОБЛЕМЫ

**Проблема не в коде приложения**, а в том, что:

1. **Продукты находятся на проверке в App Store Connect**
   - Статус: "Waiting for Review" или "In Review"
   - Пока продукты не одобрены, они недоступны для Sandbox тестирования

2. **Apple Sandbox API не возвращает продукты, которые находятся на проверке**
   - Это стандартное поведение Apple
   - Продукты становятся доступными только после одобрения

3. **Код приложения работает корректно**
   - Запросы отправляются правильно
   - Обработка ошибок реализована
   - Локализация работает
