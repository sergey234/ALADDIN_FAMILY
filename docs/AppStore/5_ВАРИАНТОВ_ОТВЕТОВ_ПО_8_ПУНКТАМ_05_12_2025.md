4. Какие платные функции не используют in-app purchase?
Оплата на сайте + активация кода:
- Пользователь оплачивает подписку на сайте (банковской картой) - это происходит вне приложения
- Получает код активации по email после оплаты
- Вводит код в приложении вручную для активации уже оплаченной подписки
- Код активации используется только для активации подписки, а не для покупки

Обоснование альтернативного способа оплаты:
- Код активации - это способ активации уже оплаченной подписки, а не способ покупки через приложение
- Пользователь может выбрать удобный способ оплаты: IAP или оплата на сайте
- Это позволяет пользователям, использующим приложение на нескольких платформах (iOS и Android), использовать один код активации для всех устройств
- Это соответствует правилам Apple для альтернативных способов оплаты, когда оплата происходит вне приложения

Важно: Оплата на сайте происходит полностью вне приложения. Код активации используется только для активации уже оплаченной подписки, а не для совершения покупки через приложение.
