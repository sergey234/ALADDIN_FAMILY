**Задача:** Создать новые промо-изображения для In-App Purchase

**Требования Apple:**
- ✅ НЕ должно быть скриншотом из приложения
- ✅ Должно быть уникальным изображением
- ✅ Текст должен быть читаемым (минимум 20pt)
- ✅ Размер: 1024x1024 пикселей
- ✅ Формат: PNG или JPEG

**Нужно создать изображения для каждого тарифа:**
1. **FREE** - Бесплатный тариф
2. **BASIC** - Базовый тариф
3. **INDIVIDUAL** - Индивидуальный тариф
4. **FAMILY** - Семейный тариф
5. **PREMIUM** - Премиум тариф

**Действия:**
1. Создать 5 изображений (1024x1024)
2. Войти в App Store Connect
3. Перейти в раздел "In-App Purchases"
4. Для каждого тарифа загрузить новое изображение

**Приоритет:** 🟡 **ВАЖНО**  
**Время:** 1-2 часа
