## 🔍 Что такое IAP

### IAP (In-App Purchase) = Покупки внутри приложения через App Store

**В вашем приложении:**
- ✅ IAP **настроен в коде** (StoreKit 2)
- ✅ Используется для пользователей **за пределами России**
- ✅ В России используется альтернативная оплата (QR-код)

## 🛒 Процесс покупки

### Как пользователь покупает подписку:

#### **Шаг 1: Пользователь открывает экран тарифов**
- Экран: `Screens/10_TariffsScreen.swift`
- Пользователь видит 4 тарифа:
  - 🆓 Бесплатный
  - 💎 Персональный
  - 👨‍👩‍👧‍👦 Семейный (рекомендуется)
  - ⭐ Премиум

#### **Шаг 2: Пользователь выбирает тариф**
- Нажимает на карточку тарифа
- Видит кнопку "Оформить подписку" или "Перейти на сайт"

#### **Шаг 3: Проверка региона**

**Код:** `ViewModels/TariffsViewModel.swift` → `purchaseTariff()`

```swift
// Проверяем регион
if AppConfig.useAlternativePayments {
    // Россия → QR оплата
} else {
    // Не Россия → IAP (App Store)
}
```

**Логика:**
- 🇷🇺 **Россия** → Переход на сайт (QR-код оплата)
- 🌍 **Другие страны** → IAP через App Store

#### **Шаг 4: Запуск IAP (для не-России)**

**Файл:** `Core/Store/StoreManager.swift`

1. **Загрузка продуктов из App Store:**
   ```swift
   products = try await Product.products(for: productIDs)
   ```

2. **Инициация покупки:**
   ```swift
   let result = try await product.purchase()
   ```

3. **Показывается системный диалог Apple:**
   - Пользователь подтверждает покупку
   - Вводит пароль Face ID / Touch ID
   - Apple обрабатывает платеж

4. **Проверка транзакции:**
   ```swift
   let transaction = try checkVerified(verification)
   ```

5. **Активация подписки:**
   ```swift
   await transaction.finish()
   // Сохранение тарифа в TariffManager
   // Отправка уведомления о покупке
   ```

---

### ✅ Шаг 2: Настроить Subscription Group

**Что это:** Группа подписок, из которой пользователь может выбрать только одну активную

**Важно:**
- Все 4 продукта должны быть в одной группе
- Пользователь может иметь только одну активную подписку
- При покупке новой подписки, старая отменяется

---

### ✅ Шаг 3: Заполнить метаданные

**Для каждого продукта нужно указать:**

1. **Display Name (Название):**
   - Basic: "ALADDIN Basic"
   - Individual: "ALADDIN Individual"
   - Family: "ALADDIN Family"
   - Premium: "ALADDIN Premium"

2. **Description (Описание):**
   - Basic: "1 устройство, базовая защита"
   - Individual: "1 устройство, полная защита, AI помощник"
   - Family: "До 5 устройств, родительский контроль"
   - Premium: "До 10 устройств, все функции, приоритетная поддержка"

3. **Subscription Period:** 1 месяц

4. **Price:** Установить цены для каждого региона (или использовать Auto)

---

### ✅ Шаг 4: Добавить локализацию

**Для каждого продукта:**
- Добавить русский язык (если нужно)
- Добавить английский язык (обязательно)

---

### ✅ Шаг 5: Загрузить скриншоты (опционально)

**Для каждого продукта можно загрузить:**
- Скриншоты приложения (для отображения в App Store)
- Промо-изображения

---

### ✅ Шаг 6: Отправить на проверку

**Важно:**
- Все продукты должны быть в статусе **"Ready to Submit"**
- После создания продуктов, их нужно **отправить на проверку Apple**
- Apple проверит метаданные и одобрит (или отклонит) продукты

```

   ↓

   ↓
9. Apple обрабатывает платеж
   ↓

   ↓
11. Активирует подписку в приложении
   ↓
12. Сохраняет тариф в TariffManager
   ↓
13. Отправляет уведомление о покупке
```

## ❓ Часто задаваемые вопросы

### 1. Нужно ли что-то менять в коде?

**Нет!** Код уже настроен. Нужно только создать продукты в App Store Connect.

---

### 2. Как протестировать IAP?

**Важно:** IAP нельзя протестировать в симуляторе!

**Как протестировать:**
1. Создать тестовый аккаунт в App Store Connect
2. Использовать Sandbox Environment (реальное устройство)
3. Войти в App Store с тестовым аккаунтом на устройстве
4. Запустить приложение и попробовать купить подписку

---

### 3. Что происходит после покупки?

1. Apple обрабатывает платеж
2. StoreManager проверяет транзакцию
3. Подписка активируется в приложении
4. Тариф сохраняется в `TariffManager`
5. Отправляется уведомление о покупке
6. Планируются уведомления о продлении

---

### 4. Как работает автоматическое продление?

- Apple автоматически продлевает подписку каждый месяц
- Списывает деньги с карты пользователя
- Отправляет обновление транзакции в приложение
- Приложение обновляет статус подписки

---

### 5. Что если пользователь отменит подписку?

- Подписка остается активной до конца периода
- После окончания периода, функции блокируются
- Пользователь может восстановить покупки через "Restore Purchases"
