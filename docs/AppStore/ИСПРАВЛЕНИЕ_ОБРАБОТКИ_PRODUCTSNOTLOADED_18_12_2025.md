## 🔧 ЧТО СДЕЛАНО

### Улучшена обработка ошибки `productsNotLoaded`

**Проблема:**
- Ошибка `productsNotLoaded` показывалась как "Ошибка покупки: Продукты не загружены..."
- Это пугало пользователя словом "Ошибка покупки"

**Решение:**
- ✅ Добавлена специальная обработка для `productsNotLoaded`
- ✅ Более дружелюбное сообщение без слова "Ошибка покупки"
- ✅ Сообщение: "Не удалось загрузить тарифы. Проверьте подключение к интернету и попробуйте снова."

---

## 📝 ИЗМЕНЕНИЯ В КОДЕ

### Файл: `ViewModels/TariffsViewModel.swift`

**Было (2 места):**
```swift
} catch {
    isLoading = false
    let errorDesc = error.localizedDescription
    errorMessage = "Ошибка покупки: \(errorDesc)"
    // ...
}
```

**Стало:**
```swift
} catch {
    isLoading = false
    
    // ✅ УЛУЧШЕНИЕ: Специальная обработка для productsNotLoaded
    if let storeError = error as? StoreError, storeError == .productsNotLoaded {
        errorMessage = "Не удалось загрузить тарифы. Проверьте подключение к интернету и попробуйте снова."
        print("❌ [TariffsViewModel] Products not loaded error")
    } else {
        let errorDesc = error.localizedDescription
        errorMessage = "Ошибка покупки: \(errorDesc)"
        print("❌ [TariffsViewModel] IAP Purchase failed: \(errorDesc)")
    }
    
    // ... остальной код логирования
}
```

## 🔍 КАК ЭТО РАБОТАЕТ

### Сценарий 1: Продукты не загружены

1. Пользователь пытается купить подписку
2. `StoreManager` проверяет что продукты загружены
3. Если нет - пытается загрузить автоматически
4. Если загрузка не удалась - выбрасывает `StoreError.productsNotLoaded`
5. `TariffsViewModel` ловит ошибку
6. Показывает: **"Не удалось загрузить тарифы. Проверьте подключение к интернету и попробуйте снова."**

### Сценарий 2: Другая ошибка

1. Пользователь пытается купить подписку
2. Происходит другая ошибка (например, `productNotFound`)
3. `TariffsViewModel` ловит ошибку
4. Показывает: **"Ошибка покупки: [описание ошибки]"**
