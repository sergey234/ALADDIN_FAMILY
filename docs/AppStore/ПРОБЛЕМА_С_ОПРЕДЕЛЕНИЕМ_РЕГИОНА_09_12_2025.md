# 🚨 ПРОБЛЕМА: ОПРЕДЕЛЕНИЕ РЕГИОНА В СИМУЛЯТОРЕ

**Дата:** 9 декабря 2025  
**Проблема:** В симуляторе показывается ошибка IAP вместо открытия сайта

---

## ❌ ПРОБЛЕМА

**Что происходит:**
1. Пользователь видит кнопку: "Оформить подписку" ✅
2. Нажимает кнопку
3. Появляется ошибка: "In-App Purchase недоступен в симуляторе" ❌
4. Сайт НЕ открывается

**Почему:**
- Код попал в блок `else` (не Россия), а не в блок `if AppConfig.useAlternativePayments` (Россия)
- Это значит, что `AppConfig.useAlternativePayments` возвращает `false`
- В симуляторе `Locale.current.regionCode` может не возвращать "RU"

---

## 🔍 ДИАГНОСТИКА

### Как определяется регион:

**Файл:** `Core/Config/AppConfig.swift`  
**Строки:** 187-202

```swift
static var isRussianRegion: Bool {
    return Locale.current.regionCode == "RU"
}

static var useAlternativePayments: Bool {
    return isRussianRegion
}
```

**Проблема:**
- В симуляторе `Locale.current.regionCode` может возвращать `nil` или другой код
- Зависит от настроек симулятора
- Может быть "US", "GB" или другой регион
