🔍 КАК РАБОТАЕТ ЛОКАЛИЗАЦИЯ В iOS:

В вашем проекте используется LocalizationManager.swift со словарем:

```swift
var translations: [Language: [String: String]] = [
    .russian: [
        "faq_how_vpn_works": "Как работает защита сети?",
        "vpn_title": "Заголовок",  // <-- НЕ используется в коде
        // ... еще 378 ключей vpn_*
    ]
]
```

⚠️ ВАЖНО: Если ключ НЕ используется в коде через localized("key"),
          то он НЕ попадает в финальную сборку!

📋 ЧТО ВИДИТ APPLE:

1. ✅ БИНАРНЫЙ КОД (скомпилированный):
   - Swift компилятор включает только используемые строки
   - Неиспользуемые ключи из словаря НЕ попадают в binary
   - Apple проверяет в основном binary, а не исходный код

2. ⚠️ ИСХОДНЫЙ КОД (если Apple получит доступ):
   - Может увидеть словарь с 380 ключами vpn_*
   - НО: Apple обычно НЕ запрашивает исходный код
   - Apple проверяет скомпилированный binary

3. ✅ .STRINGS ФАЙЛЫ:
   - В вашем проекте есть Resources/Localization/*.strings
   - НО: LocalizationManager.swift НЕ использует .strings файлы!
   - Используется встроенный словарь в Swift коде
   - Apple не увидит отдельные .strings файлы с VPN ключами
