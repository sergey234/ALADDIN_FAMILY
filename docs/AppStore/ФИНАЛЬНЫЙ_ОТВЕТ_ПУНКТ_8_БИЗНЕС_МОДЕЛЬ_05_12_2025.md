## 1. Кто использует платный контент и подписки?

Все пользователи, которые хотят получить доступ к **премиум функциям безопасности**:
- Расширенная защита семьи
- Дополнительные функции безопасности в сети интернет
- VPN защита от вирусов, фишинга
- AI помощник по безопасности
- Расширенная статистика и аналитика
- Дополнительные функции родительского контроля
- Приоритетная поддержка

---

## 2. Где можно купить?

Подписка доступна **двумя способами**:

**Вариант 1: App Store In-App Purchase (IAP) - основной способ**
- Покупка напрямую в приложении через App Store
- Автоматическая активация подписки после оплаты
- Управление подпиской через настройки Apple ID
- Автоматическое продление подписки
- Доступен для всех пользователей независимо от региона

**Вариант 2: Код активации для подписок, приобретённых вне приложения**

Процесс:
1. Пользователь самостоятельно приобретает подписку на нашем сайте https://aladdin-ai.ru/ (вне приложения)
2. После успешной оплаты на сайте пользователь получает код активации на странице подтверждения оплаты (формат: ACT-XXXX-XXXX-XXXX)
3. Пользователь вводит код вручную в приложении для активации уже оплаченной подписки

---

## 3. Какой контент доступен?

После активации подписки (любым из способов) пользователь получает доступ к **одинаковому набору премиум функций**:
- Премиум функциям безопасности
- Расширенной защите семьи
- VPN защите от вирусов, фишинга
- AI помощнику по безопасности
- Образовательному контенту для детей
- Дополнительным функциям родительского контроля
- Расширенной статистике угроз и оповещений
- Приоритетной поддержке

---

## 4. Какие платные функции не используют in-app purchase?

**Код активации для подписок, приобретённых вне приложения:**

Процесс:
1. Пользователь самостоятельно приобретает подписку на нашем сайте https://aladdin-ai.ru/ (вне приложения)
2. После успешной оплаты на сайте пользователь получает код активации на странице подтверждения оплаты
3. Пользователь вводит код вручную в приложении для активации уже оплаченной подписки

**Обоснование (Guideline 3.1.3(b) - Мультиплатформенные сервисы):**

Приложение предоставляет доступ к подпискам, приобретённым пользователем вне приложения, в соответствии с Guideline 3.1.3(b). Это позволяет пользователям использовать подписки, купленные на других платформах (веб-сайт, Android), для доступа к контенту в iOS приложении.

**Важно:**
- IAP доступен в приложении как основной способ оплаты для всех пользователей
- Код активации используется только для активации уже оплаченной подписки, а не для совершения покупки через приложение
- Приложение не направляет пользователей на сайт для покупки
- Приложение не содержит ссылок на сайт для покупки подписки
- Пользователь самостоятельно инициирует покупку на сайте (вне приложения)
- После покупки на сайте пользователь получает код активации и вводит его в приложении для доступа к уже оплаченной подписке
