# ИНСТРУКЦИИ ДЛЯ APP STORE CONNECT - МЕТАДАННЫЕ

**Дата:** 15 декабря 2025  
**Цель:** Удалить все упоминания VPN из метаданных приложения

---

## 📋 ЧТО НУЖНО ПРОВЕРИТЬ И ИЗМЕНИТЬ В APP STORE CONNECT

### 🔴 КРИТИЧНО - ОБЯЗАТЕЛЬНО ПРОВЕРИТЬ:

#### 1. **App Information (Информация о приложении)**

**Где найти:** App Store Connect → Ваше приложение → App Information

**Что проверить:**
- [ ] **Name (Название):** Убедиться, что нет слова "VPN"
- [ ] **Subtitle (Подзаголовок):** Убедиться, что нет слова "VPN"
- [ ] **Category (Категория):** 
  - Должно быть: "Parental Control" или "Family Safety"
  - НЕ должно быть: "VPN" или "Network Tools"

---

#### 2. **App Store Listing (Описание в App Store)**

**Где найти:** App Store Connect → Ваше приложение → App Store → [Выбранная версия] → App Store Listing

**Что проверить и изменить:**

**A. Description (Описание приложения):**
- [ ] Прочитать описание полностью
- [ ] Удалить все упоминания "VPN"
- [ ] Удалить все упоминания "Virtual Private Network"
- [ ] Заменить на "Network Protection" / "Защита сети" (если нужно)
- [ ] Убедиться, что описание фокусируется на "Family Safety" и "Parental Control"

**Пример правильного описания:**
```
ALADDIN - Family Safety & Parental Control

Protect your family with comprehensive security features:
- Parental Control
- Device Protection
- Threat Detection
- Screen Time Management
- Network Protection (secondary security feature)
```

**B. Keywords (Ключевые слова):**
- [ ] Удалить "VPN"
- [ ] Удалить "virtual private network"
- [ ] Удалить "VPN app"
- [ ] Оставить только: "family safety", "parental control", "device protection", "threat detection"

**C. Promotional Text (Промо-текст):**
- [ ] Проверить, нет ли упоминаний VPN
- [ ] Удалить, если есть

**D. What's New (Что нового):**
- [ ] Проверить, нет ли упоминаний VPN
- [ ] Удалить, если есть

---

#### 3. **Screenshots (Скриншоты)**

**Где найти:** App Store Connect → Ваше приложение → App Store → [Выбранная версия] → Screenshots

**Что проверить:**
- [ ] Просмотреть все скриншоты
- [ ] Убедиться, что нет текста "VPN" на скриншотах
- [ ] Убедиться, что нет упоминаний "VPN" в интерфейсе на скриншотах
- [ ] Если есть скриншоты с VPN - заменить на скриншоты с "Network Protection" или другими функциями

**Рекомендация:** Использовать скриншоты:
- Главный экран с карточками функций
- Экран родительского контроля
- Экран аналитики
- Экран тарифов
- НЕ использовать скриншоты экрана "Network Protection" (если там есть упоминания VPN)

---

#### 4. **App Preview (Видео-превью)**

**Где найти:** App Store Connect → Ваше приложение → App Store → [Выбранная версия] → App Preview

**Что проверить:**
- [ ] Просмотреть видео полностью
- [ ] Убедиться, что нет упоминаний "VPN" в видео
- [ ] Убедиться, что нет текста "VPN" в видео
- [ ] Если есть - заменить видео

---

#### 5. **Support URL (URL поддержки)**

**Где найти:** App Store Connect → Ваше приложение → App Information → Support URL

**Что проверить:**
- [ ] Убедиться, что на странице поддержки нет упоминаний VPN
- [ ] Если есть - обновить страницу

---

#### 6. **Marketing URL (Маркетинговый URL)**

**Где найти:** App Store Connect → Ваше приложение → App Information → Marketing URL

**Что проверить:**
- [ ] Убедиться, что на маркетинговой странице нет упоминаний VPN
- [ ] Если есть - обновить страницу

---

#### 7. **Privacy Policy URL (URL политики конфиденциальности)**

**Где найти:** App Store Connect → Ваше приложение → App Information → Privacy Policy URL

**Что проверить:**
- [ ] Убедиться, что в политике конфиденциальности нет упоминаний VPN как основной функции
- [ ] Если есть упоминания - обновить текст

## 📝 ПОШАГОВАЯ ИНСТРУКЦИЯ

### ШАГ 1: Войти в App Store Connect
1. Откройте https://appstoreconnect.apple.com
2. Войдите в свой аккаунт
3. Выберите ваше приложение ALADDIN

### ШАГ 2: Проверить App Information
1. Перейдите в раздел "App Information"
2. Проверьте Name, Subtitle, Category
3. Измените, если нужно

### ШАГ 3: Проверить App Store Listing
1. Перейдите в раздел "App Store"
2. Выберите версию приложения
3. Перейдите в "App Store Listing"
4. Проверьте Description, Keywords, Promotional Text
5. Удалите все упоминания VPN

### ШАГ 4: Проверить Screenshots
1. В том же разделе "App Store Listing"
2. Просмотрите все скриншоты
3. Замените, если есть упоминания VPN

### ШАГ 5: Сохранить изменения
1. Нажмите "Save" после каждого изменения
2. Убедитесь, что все изменения сохранены

## 🔍 КАК НАЙТИ УПОМИНАНИЯ VPN

### Поиск в App Store Connect:

1. **В Description:**
   - Используйте Ctrl+F (Cmd+F на Mac)
   - Поиск: "VPN", "vpn", "Virtual Private Network"

2. **В Keywords:**
   - Просмотрите список ключевых слов
   - Удалите все, что связано с VPN

3. **В Screenshots:**
   - Просмотрите каждый скриншот
   - Ищите текст "VPN" на изображениях
