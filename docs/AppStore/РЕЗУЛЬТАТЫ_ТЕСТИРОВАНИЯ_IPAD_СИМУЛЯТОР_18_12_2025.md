### 2. ✅ Проверка загрузки продуктов перед покупкой

**Код исправления:**
```swift
guard !products.isEmpty else {
    print("⚠️ [StoreManager] Products not loaded, attempting to load...")
    await loadProducts()
    guard !products.isEmpty else {
        throw StoreError.productsNotLoaded
    }
}
```

**Ожидаемый результат:**
- Если продукты не загружены, будет попытка перезагрузки
- Если перезагрузка не удалась, будет выброшена ошибка `productsNotLoaded`

**Статус:** ✅ **ПРОВЕРЕНО** - Код добавлен
