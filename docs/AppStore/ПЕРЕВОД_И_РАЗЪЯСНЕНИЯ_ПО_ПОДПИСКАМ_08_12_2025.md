## ❓ РАЗЪЯСНЕНИЯ ПО ВОПРОСАМ

### Вопрос 1: Как отправить подписку на проверку?

**Ответ:**

Есть **два способа** отправки подписок:

#### Способ 1: Первая подписка (Premium) — вместе с версией приложения

1. **Создайте подписку** в App Store Connect (если еще не создана)
2. **Откройте версию приложения** (например, версия 1.0 с Build 6)
3. **Прокрутите вниз** до раздела **"Встроенные покупки и подписки"**
4. **Нажмите "+"** и **выберите Premium**
5. **Загрузите бинарный файл** (Build 6) — уже сделано ✅
6. **Отправьте версию на проверку** — Premium отправится автоматически вместе с версией

#### Способ 2: Остальные подписки (Individual, Family, Basic) — отдельно

**ВАЖНО:** Это можно сделать **ТОЛЬКО ПОСЛЕ** того, как Apple одобрит первую подписку (Premium).

1. **Дождитесь одобрения Premium** (обычно 1-3 дня)
2. **Перейдите в раздел "Функции" → "Подписки"**
3. **Откройте каждую подписку** (Individual, Family, Basic)
4. **Нажмите "Отправить на проверку"** для каждой подписки отдельно

---

### Вопрос 2: Получает ли Apple все подписки при отправке приложения?

**Ответ:**

**НЕТ, не все сразу!**

**Как это работает:**

1. **При первой отправке версии:**
   - Вы выбираете **ОДНУ подписку** (Premium) в версии приложения
   - Apple получает **только эту одну подписку** вместе с версией
   - Остальные подписки (Individual, Family, Basic) **НЕ отправляются**

2. **После одобрения Premium:**
   - Вы можете отправить **остальные подписки отдельно**
   - Каждую подписку нужно отправлять **по отдельности**
   - Они будут проверяться **независимо** от версии приложения

**Почему так:**
- Apple требует, чтобы **первая подписка** была отправлена вместе с версией
- Это позволяет Apple проверить интеграцию подписки с приложением
- После этого остальные подписки можно отправлять отдельно

### Вопрос 3: Что значит "Статус: Метаданные отсутствуют"?

**Ответ:**

**"Метаданные отсутствуют" (Metadata missing)** означает, что Apple не может найти **все необходимые данные** для подписки.

**Что такое метаданные:**
- Это **информация о подписке**, которую Apple использует для проверки и отображения в App Store

**Что должно быть заполнено (обязательные метаданные):**

1. ✅ **Длительность подписки** (Duration)
   - Например: 1 месяц, 3 месяца, 1 год
   - **Где:** В настройках подписки → "Длительность подписки"

2. ✅ **Цена** (Price)
   - Минимальная цена: 1-15 рублей (зависит от страны)
   - **Где:** В настройках подписки → "Цены на подписку"

3. ✅ **Локализация** (Localization)
   - **Отображаемое название** (Display Name)
   - **Описание подписки** (Description)
   - **Минимум:** Английский (США)
   - **Рекомендуется:** Русский + Английский
   - **Где:** В настройках подписки → "Локализация" → "Создать"

4. ✅ **Категория налогообложения** (Tax Category)
   - Обычно: "В соответствии с основным приложением"
   - **Где:** В настройках подписки → "Категория налогообложения"

## 🔍 КАК ПРОВЕРИТЬ, ЧТО ВСЕ МЕТАДАННЫЕ ЗАПОЛНЕНЫ

### Шаг 1: Откройте подписку

1. **App Store Connect** → **Функции** → **Подписки**
2. **Нажмите на подписку** (например, Premium)

### Шаг 2: Проверьте каждый раздел

#### ✅ Раздел "Длительность подписки"

Должно быть:
```
Длительность подписки: 1 месяц ✅
```

Если пусто:
- Нажмите "Изменить"
- Выберите "1 месяц"
- Сохраните

#### ✅ Раздел "Цены на подписку"

Должно быть:
```
Текущая цена для новых подписчиков: 990₽ ✅
```

Если пусто:
- Нажмите "Редактировать"
- Установите цену для всех стран
- Сохраните

#### ✅ Раздел "Локализация"

Должно быть:
```
Локализации:
✅ английский (США)
  - Отображаемое название: ALADDIN Premium
  - Описание: 10 devices, all features, priority, VPN

✅ русский
  - Отображаемое название: ALADDIN Премиум
  - Описание: 10 подключенных устройств! максимальная защита в сети
```

Если пусто или неполное:
- Нажмите "Создать" или "Редактировать"
- Заполните название и описание для каждого языка
- Сохраните

#### ✅ Раздел "Категория налогообложения"

Должно быть:
```
Категория: В соответствии с основным приложением ✅
```

Если пусто:
- Нажмите "Редактировать"
- Выберите "В соответствии с основным приложением"
- Сохраните

## 🚨 ЧТО ДЕЛАТЬ, ЕСЛИ "МЕТАДАННЫЕ ОТСУТСТВУЮТ"

### Если статус все еще "Метаданные отсутствуют":

1. **Проверьте каждый раздел** (см. выше)
2. **Убедитесь, что все поля заполнены:**
   - Длительность ✅
   - Цена ✅
   - Локализация (минимум английский) ✅
   - Категория налогообложения ✅

3. **Сохраните изменения:**
   - После каждого изменения нажимайте **"Сохранить"**
   - Подождите несколько секунд

4. **Обновите страницу:**
   - Нажмите **F5** или **Cmd+R**
   - Подождите 1-2 минуты
   - Статус должен обновиться

5. **Если статус не меняется:**
   - Подождите **5-10 минут** (Apple обрабатывает изменения)
   - Обновите страницу снова
   - Проверьте, что все поля действительно сохранены

## 🎯 ИТОГОВЫЕ ОТВЕТЫ

### 1. Как отправить подписку?

**Premium (первая):**
- Выберите в версии приложения
- Отправьте версию на проверку
- Premium отправится автоматически

**Остальные (Individual, Family, Basic):**
- После одобрения Premium
- Отправьте каждую отдельно из раздела "Подписки"

### 2. Получает ли Apple все подписки сразу?

**НЕТ:**
- При первой отправке: только Premium (выбранная в версии)
- Остальные: отправляются отдельно после одобрения Premium

### 3. Что значит "Метаданные отсутствуют"?

**Это значит, что не все обязательные поля заполнены:**
- Длительность
- Цена
- Локализация (название и описание)
- Категория налогообложения

**Что делать:**
- Проверьте каждый раздел
- Заполните недостающие поля
- Сохраните изменения
- Обновите страницу
