# Отдельный продукт: свой scrape-сервис «как Levels» (не ALADDIN iOS)

**Статус:** архитектурное решение (docs) · код — отдельный GO · **не** часть iOS-релиза  
**Дата:** 2026-09-21  
**Важно:** это **другой продукт**, не Firecrawl для Hermes и не фича приложения ALADDIN.

---

## 1. Для чего Levels это делал? (просто)

У него несколько сайтов/сервисов (Nomads, Remote OK, Photo AI…).  
Им нужно **регулярно забирать данные с чужих страниц**: вакансии, цены, картинки, списки городов и т.п.

Раньше он платил чужому сервису (~$249/мес):  
«открой страницу → если сайт блокирует ботов, обойди → верни мне текст/HTML/JSON».

Это как нанять такси каждый день вместо своей машины: удобно, но дорого, и ты зависишь от чужого тарифа.

Он сделал **свою маленькую «машину»** только под **свои** маршруты (свои сайты-источники).  
~90% поездок ок, бензин ~$1 (свой VPS), не $249 чужой службе.

**Не цель Levels:** продать всем новый Browserless.  
**Цель:** перестать платить за то, что нужно только его продуктам.

## 3. Решение: как сделать (три этажа)

Строим **не «любой сайт мира» сразу**, а лестницу. Так Levels и выиграл: сначала свои URL, потом расширение.

```text
[Клиент]  POST /v1/fetch  { url, wait_for?, format: html|text|json }
    ↓
[API]     маленький FastAPI/Flask на одном VPS
    ↓
[Очередь] Redis / просто asyncio queue
    ↓
[Worker]  Playwright (headless Chromium)
    ↓
[Антибот] по уровню сложности URL (см. этажи)
    ↓
[Ответ]   HTML / text / выбранные CSS-селекторы → JSON
```

### Этаж A — «свой Levels для своих сайтов» (~$1–5/мес) ✅ рекомендуем старт

| Что | Как |
|-----|-----|
| Браузер | Playwright + Chromium на одном маленьком VPS (или Docker) |
| Сеть | Обычный IP VPS; без residential |
| Антибот | Задержки, нормальный User-Agent, иногда cookies вручную для 2–3 доменов |
| API | `POST /fetch` + секретный токен |
| Успех | 80–95% на **белом списке** доменов |
| Не умеет | Жёсткий Cloudflare / «докажи что ты человек» на незнакомых сайтах |

**Это и есть образ Levels:** свои продукты → свои источники → свой worker.

### Этаж B — «трудные сайты» (+$20–80/мес прокси)

| Что | Как |
|-----|-----|
| Прокси | Residential/mobile pool (Bright Data / IPRoyal / аналог) **только** для доменов из списка «hard» |
| Обход | playwright-stealth / camoufox / готовые fingerprint-профили |
| Капча | Отдельный сервис капчи **только** если без неё нельзя (дорого — считать ROI) |
| Успех | ближе к «SaaS за $249», но вы платите прокси, не маржу Browserless |

### Этаж C — «продаём как SaaS всем» ❌ не первый шаг

Маркетплейс, биллинг, abuse, ToS чужих сайтов, поддержка 24/7.  
Это уже компания, не «скрипт за $1». Levels **этого не делал** в той истории.

## 4. Минимальный стек (конкретный рецепт Этажа A)

| Компонент | Выбор | Зачем |
|-----------|-------|--------|
| VPS | 1× маленькая машина (2–4 GB RAM) | Chromium ест память |
| Runtime | Docker: `mcr.microsoft.com/playwright` | одинаковый браузер |
| API | FastAPI + API key | просто как у SaaS |
| Хранение | без БД сначала; опционально SQLite кэш URL→результат TTL | дешево |
| Мониторинг | cron health + Telegram «worker down» | как у ALADDIN health |
| Секреты | `.env` на VPS, не в git | конституция |

Псевдо-контракт:

```json
// POST /v1/fetch
{ "url": "https://example.com/page", "format": "text", "timeout_ms": 30000 }

// 200
{ "ok": true, "status": 200, "body": "...", "ms": 1200 }
```

Белый список доменов в конфиге — пока продукт «для себя».  
Публичный «любой URL» — только после Этажа B + юр.оферты.

## 5. Плюсы / минусы решения

| Плюсы | Минусы |
|-------|--------|
| Контроль, нет $249 чужой маржи | Сами чините, когда сайт сменил вёрстку |
| Можно заточить под 5 доменов идеально | Cloudflare на новых доменах сломает Этаж A |
| Путь в продукт: сначала internal, потом платный API | Residential прокси = снова ежемесячный $ |
| Не путается с ALADDIN iOS | Нужен отдельный репо/каталог и отдельные коммиты |

---

## 6. Порядок работ (когда скажете GO на этот продукт)

1. Назвать продукт (рабочее: **FetchLite** / своё имя).  
2. Список **5–10 URL**, которые реально нужны (боль).  
3. Этаж A на отдельном VPS (не ломая VPN/bot ALADDIN).  
4. Замер: % успеха / latency / $/мес.  
5. Если <80% — Этаж B только для failing доменов.  
6. Продажа наружу — отдельное решение C-level, не автоматом.

Фраза GO (пример):

```text
GO FetchLite Этаж A — отдельный продукт, не iOS. Белый список URL приложу.
```
