3. **Использовать правильный тип сохранения:**

   - Сложные настройки → `ComponentConfigurationService`
   - Статус компонентов → `ComponentStatusService`

### Как делать:

1. **Для тумблеров с @State:**
   - Заменить на `@AppStorage` с уникальным ключом
   - Проверить сохранение после выхода из приложения
   - При необходимости добавить синхронизацию с сервером

2. **Для модальных окон с @State:**
   - Добавить метод `saveSettings()`
   - Использовать `ComponentConfigurationService.saveConfiguration()`
   - Добавить загрузку настроек в `onAppear`

3. **Для других элементов (слайдеры, пикеры, TextField):**
   - Заменить `@State` на `@AppStorage` (для простых)
   - Или добавить в `saveSettings()` через `ComponentConfigurationService` (для сложных)
