# 📋 ЛОГИКА РАБОТЫ КОМПОНЕНТОВ ЗАЩИТЫ

**Дата:** 2025-01-08

---

## 🔍 ОБЗОР КОМПОНЕНТОВ

В приложении ALADDIN реализовано 7 компонентов защиты, которые работают автоматически после включения:

1. **Отчет о вождении** (Driving Reports Agent)
2. **Умная категория контента** (AI Categories Agent)
3. **Защита кражи личности** (Russian Identity Theft Protection Agent)
4. **Мониторинг Дарк вэб** (Dark Web Monitoring Agent)
5. **Пузырь местоположения** (Location Bubble Agent)
6. **Очистка данных** (Personal Data Cleanup Agent)
7. **Блокировка рекламных трекеров** (Anti Tracker Agent)

---

## 1. 📊 ОТЧЕТ О ВОЖДЕНИИ (Driving Reports Agent)

### Что делает:
- Отслеживает стиль вождения пользователя
- Анализирует скорость, резкие торможения, ускорения
- Создает отчеты о безопасности вождения
- Отправляет уведомления родителям (если включено)

### Как включить:
1. Открыть **Настройки** → **Расширенные настройки**
2. Найти раздел **"Мониторинг"**
3. Найти **"Отчет о вождении"** (Driving Reports Agent)
4. Включить тумблер

### Где проверять отчеты:
- **Экран Аналитики** (`04_AnalyticsScreen.swift`)
  - Раздел "Статистика вождения"
  - Графики скорости, торможений
  - Оценка безопасности вождения
  
- **Экран Уведомлений** (`12_NotificationsScreen.swift`)
  - Уведомления о резких маневрах
  - Еженедельные отчеты о вождении

### Логика работы:
1. **Автоматический сбор данных:**
   - Использует GPS и акселерометр устройства
   - Отслеживает движение в автомобиле
   - Определяет начало и конец поездки

2. **Анализ данных:**
   - Скорость превышена → предупреждение
   - Резкое торможение → запись в отчет
   - Резкое ускорение → запись в отчет
   - Резкие повороты → запись в отчет

3. **Создание отчетов:**
   - Ежедневные отчеты
   - Еженедельные сводки
   - Отправка родителям (если включено)

4. **API методы:**
   - `GET /components/driving_reports_agent/reports` - получить отчеты
   - `POST /components/driving_reports_agent/report` - создать отчет
   - `GET /components/driving_reports_agent/stats` - статистика

### Действия пользователя:
- **Включить компонент** → автоматическая работа
- **Проверить отчеты** → Экран Аналитики → Раздел "Вождение"
- **Настроить уведомления** → Модальное окно настроек компонента

## 2. 🤖 УМНАЯ КАТЕГОРИЯ КОНТЕНТА (AI Categories Agent)

### Что делает:
- Автоматически категоризирует контент с помощью AI
- Определяет тип контента (игры, образование, развлечения)
- Блокирует нежелательный контент
- Предлагает альтернативный контент

### Как включить:
1. Открыть **Настройки** → **Расширенные настройки**
2. Найти раздел **"Мониторинг"**
3. Найти **"Умная категория контента"** (AI Categories Agent)
4. Включить тумблер

### Где проверять:
- **Экран Детского контента** (`08_ChildInterfaceScreen.swift`)
  - Категории контента автоматически определяются
  - Блокировка нежелательного контента
  
- **Экран Аналитики** (`04_AnalyticsScreen.swift`)
  - Статистика категоризации
  - Количество заблокированного контента

### Логика работы:
1. **Анализ контента:**
   - Сканирует открываемые сайты
   - Анализирует приложения
   - Определяет категорию с помощью AI

2. **Категоризация:**
   - Образовательный контент → разрешен
   - Игры → разрешены (с ограничениями)
   - Взрослый контент → заблокирован
   - Насилие → заблокирован

3. **Блокировка:**
   - Автоматическая блокировка нежелательного контента
   - Уведомление родителям
   - Запись в лог

4. **API методы:**
   - `POST /components/ai_categories_agent/categorize` - категоризировать контент
   - `GET /components/ai_categories_agent/stats` - статистика категоризации
   - `GET /components/ai_categories_agent/blocked` - заблокированный контент

### Действия пользователя:
- **Включить компонент** → автоматическая работа
- **Проверить статистику** → Экран Аналитики → Раздел "Категоризация"
- **Настроить категории** → Модальное окно настроек компонента

- Отслеживает продажу личных данных
- Предупреждает об обнаруженных утечках

### Как включить:

2. Найти раздел **"Мониторинг"**
3. Найти **"Мониторинг Дарк вэб"** (Dark Web Monitoring Agent)
4. Включить тумблер

### Где проверять:

## 5. 📍 ПУЗЫРЬ МЕСТОПОЛОЖЕНИЯ (Location Bubble Agent)

### Что делает:
- Скрывает точное местоположение пользователя
- Показывает приблизительное местоположение (пузырь)
- Защищает от отслеживания по GPS
- Позволяет делиться местоположением безопасно

### Как включить:
1. Открыть **Настройки** → **Расширенные настройки**
2. Найти раздел **"Приватность"**
3. Найти **"Пузырь местоположения"** (Location Bubble Agent)
4. Включить тумблер

### Где проверять:
- **Экран Настроек** (`05_SettingsScreen.swift`)
  - Статус защиты местоположения
  - Настройки точности
  
- **Экран Аналитики** (`04_AnalyticsScreen.swift`)
  - Статистика защиты
  - Количество заблокированных запросов

### Логика работы:
1. **Защита местоположения:**
   - Перехватывает запросы к GPS
   - Добавляет случайное смещение (100-500 метров)
   - Создает "пузырь" местоположения

2. **Настройки точности:**
   - Высокая точность → маленький пузырь (100 м)
   - Средняя точность → средний пузырь (300 м)
   - Низкая точность → большой пузырь (500 м)

3. **Блокировка:**
   - Блокирует точные запросы местоположения
   - Разрешает приблизительные запросы
   - Логирует все запросы

4. **API методы:**
   - `POST /components/location_bubble_agent/update` - обновить настройки
   - `GET /components/location_bubble_agent/stats` - статистика
   - `GET /components/location_bubble_agent/requests` - история запросов

### Действия пользователя:
- **Включить компонент** → автоматическая работа
- **Настроить точность** → Модальное окно настроек компонента → Выбрать уровень точности
- **Проверить статистику** → Экран Аналитики → Раздел "Приватность"

## 6. 🧹 ОЧИСТКА ДАННЫХ (Personal Data Cleanup Agent)

### Что делает:
- Автоматически удаляет старые данные
- Очищает кэш приложений
- Удаляет временные файлы
- Освобождает место на устройстве

### Как включить:
1. Открыть **Настройки** → **Расширенные настройки**
2. Найти раздел **"Приватность"**
3. Найти **"Очистка данных"** (Personal Data Cleanup Agent)
4. Включить тумблер

### Где проверять:
- **Экран Настроек** (`05_SettingsScreen.swift`)
  - Статус очистки
  - Освобожденное место
  
- **Экран Аналитики** (`04_AnalyticsScreen.swift`)
  - Статистика очистки
  - История очисток

### Логика работы:
1. **Автоматическая очистка:**
   - Ежедневная очистка кэша
   - Удаление старых временных файлов
   - Очистка логов (старше 30 дней)

2. **Настройки:**
   - Частота очистки (ежедневно, еженедельно, ежемесячно)
   - Что очищать (кэш, логи, временные файлы)
   - Минимальный размер для очистки

3. **Безопасность:**
   - Не удаляет важные данные
   - Создает резервные копии перед удалением
   - Уведомляет о больших очистках

4. **API методы:**
   - `POST /components/personal_data_cleanup_agent/cleanup` - запустить очистку
   - `GET /components/personal_data_cleanup_agent/stats` - статистика
   - `GET /components/personal_data_cleanup_agent/history` - история очисток

### Действия пользователя:
- **Включить компонент** → автоматическая работа
- **Настроить очистку** → Модальное окно настроек компонента → Выбрать частоту и что очищать
- **Запустить очистку вручную** → Модальное окно настроек компонента → "Очистить сейчас"
- **Проверить статистику** → Экран Аналитики → Раздел "Очистка"

## 7. 🚫 БЛОКИРОВКА РЕКЛАМНЫХ ТРЕКЕРОВ (Anti Tracker Agent)

### Что делает:
- Блокирует рекламные трекеры
- Защищает от отслеживания в интернете
- Блокирует cookies от рекламных сетей
- Улучшает приватность браузинга

### Как включить:
1. Открыть **Настройки** → **Расширенные настройки**
2. Найти раздел **"Приватность"**
3. Найти **"Блокировка рекламных трекеров"** (Anti Tracker Agent)
4. Включить тумблер

### Где проверять:
- **Экран Аналитики** (`04_AnalyticsScreen.swift`)
  - Статистика блокировки
  - Количество заблокированных трекеров
  
- **Экран Уведомлений** (`12_NotificationsScreen.swift`)
  - Уведомления о блокировке трекеров (опционально)

### Логика работы:
1. **Блокировка трекеров:**
   - Перехватывает запросы к рекламным сетям
   - Блокирует cookies от трекеров
   - Блокирует скрипты отслеживания

2. **Списки трекеров:**
   - Google Analytics → блокируется
   - Facebook Pixel → блокируется
   - Яндекс.Метрика → блокируется
   - Другие рекламные сети → блокируются

3. **Настройки:**
   - Уровень блокировки (строгий, средний, мягкий)
   - Белый список сайтов (разрешить трекеры)
   - Уведомления о блокировке

4. **API методы:**
   - `GET /components/anti_tracker_agent/blocked` - получить заблокированные трекеры
   - `POST /components/anti_tracker_agent/whitelist` - добавить в белый список
   - `GET /components/anti_tracker_agent/stats` - статистика

### Действия пользователя:
- **Включить компонент** → автоматическая работа
- **Настроить уровень блокировки** → Модальное окно настроек компонента → Выбрать уровень
- **Добавить сайты в белый список** → Модальное окно настроек компонента → "Белый список"
- **Проверить статистику** → Экран Аналитики → Раздел "Приватность"

## 🔄 ОБЩАЯ ЛОГИКА РАБОТЫ

### 1. Включение компонента:
1. Пользователь открывает **Настройки** → **Расширенные настройки**
2. Находит нужный компонент в разделе
3. Включает тумблер
4. Компонент автоматически активируется

### 2. Работа компонента:
1. Компонент работает в фоне автоматически
2. Собирает данные / блокирует угрозы
3. Отправляет данные на сервер
4. Создает уведомления при необходимости

### 3. Просмотр результатов:
1. Пользователь открывает **Аналитика** или **Уведомления**
2. Видит статистику и отчеты
3. Может настроить компонент через модальное окно

### 4. Настройка компонента:
1. Пользователь нажимает на карточку компонента
2. Открывается модальное окно с настройками
3. Пользователь настраивает параметры
4. Сохраняет настройки
