## 🔧 КООРДИНАЛЬНЫЕ ИЗМЕНЕНИЯ

### **ИЗМЕНЕНИЕ #1: Логика обновления токена**

**Было:**
```swift
// Только перерегистрация устройства
await performEmergencyReRegistration()
```

**Стало:**
```swift
// Гибридная система: refreshToken + fallback
if let refreshToken = KeychainManager.shared.loadString(forKey: .refreshToken) {
    // Попытка 1
    do {
        let response = try await refreshTokenWithRetry(refreshToken: refreshToken, attempt: 1)
        await saveNewToken(response)
        return
    } catch {
        // Попытка 2
        do {
            try await Task.sleep(nanoseconds: 2_000_000_000)
            let response = try await refreshTokenWithRetry(refreshToken: refreshToken, attempt: 2)
            await saveNewToken(response)
            return
        } catch {
            // Fallback
            await performEmergencyReRegistration()
        }
    }
} else {
    // Fallback
    await performEmergencyReRegistration()
}
```

**Влияние:**
- ✅ Улучшенная надежность
- ✅ Сохранение тарифов
- ⚠️ Более сложная логика

---

### **ИЗМЕНЕНИЕ #2: Согласование с тарифами**

**Было:**
```swift
// Простое сохранение токена
AppConfig.authToken = response.access_token
await SubscriptionManager.shared.storeToken(jwtToken)
```

**Стало:**
```swift
// Сохранение токена с согласованием тарифов
AppConfig.authToken = response.access_token

// Декодируем JWT и извлекаем тариф
if let (subscriptionLevel, trialInfo, limits, components) = extractSubscriptionFromJWT(response.access_token) {
    // Сохраняем токен с тарифом
    let jwtToken = JWTToken(
        token: response.access_token,
        deviceId: currentToken?.deviceId ?? deviceId,
        subscriptionLevel: subscriptionLevel,
        trialInfo: trialInfo,
        expiresAt: expiresAt,
        issuedAt: Date(),
        issuer: issuer,
        limits: limits,
        components: components
    )
    await SubscriptionManager.shared.storeToken(jwtToken)
} else {
    // Fallback: запрашиваем тариф с сервера
    await fetchSubscriptionFromServer()
}
```

**Влияние:**
- ✅ Сохранение тарифов
- ✅ Сохранение trial информации
- ⚠️ Дополнительная логика декодирования JWT

---

### **ИЗМЕНЕНИЕ #3: Сохранение тарифа при fallback**

**Было:**
```swift
// Простая перерегистрация
try await SubscriptionManager.shared.registerDeviceAnonymously()

// Перерегистрация с сохранением тарифа
let currentLevel = await SubscriptionManager.shared.getCurrentLevel()

try await SubscriptionManager.shared.registerDeviceAnonymously()

let newLevel = await SubscriptionManager.shared.getCurrentLevel()
if newLevel != currentLevel && currentLevel != .free {

}
```

**Влияние:**
