## 🎯 ВОЗМОЖНЫЕ ПРИЧИНЫ

### 1. SSL Handshake (наиболее вероятно!)

**Проблема:**
- При 1000 одновременных соединений каждый запрос может требовать SSL handshake
- SSL handshake может занимать 100-500ms
- Если SSL session cache не работает эффективно, каждый запрос будет медленным

**Проверка:**
- `ssl_session_cache` настроен на 100m
- `ssl_session_timeout` настроен на 1d
- Но возможно, при большой нагрузке кэш не успевает работать

### 2. Nginx Connection Pooling

**Проблема:**
- Nginx может не переиспользовать соединения к upstream (API Gateway)
- Каждый запрос может создавать новое соединение
- Это добавляет задержку на установку соединения

**Проверка:**
- Нужно проверить, используется ли `keepalive` для upstream
- Нужно проверить `upstream` конфигурацию

### 3. Nginx Worker Connections

**Проблема:**
- При 1000 одновременных соединений может не хватать worker connections
- Соединения могут ждать в очереди
- Это добавляет задержку

**Проверка:**
- `worker_connections` = 8,192 (должно быть достаточно)
- Но нужно проверить реальное использование

### 4. Nginx Proxy Buffering

**Проблема:**
- Буферизация может добавлять задержку
- Большие буферы могут замедлять обработку

**Проверка:**
- `proxy_buffer_size` = 4k (маленький)
- `proxy_buffers` = 8 4k (маленькие)
- Возможно, нужно увеличить

## 🔧 РЕШЕНИЯ

### 1. Оптимизация SSL

```nginx
ssl_session_cache shared:SSL:100m;
ssl_session_timeout 1d;
ssl_session_tickets on;

# Добавить:
ssl_buffer_size 16k;  # Увеличить буфер SSL
ssl_protocols TLSv1.2 TLSv1.3;  # Использовать быстрые протоколы
ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256';  # Быстрые шифры
```

### 2. Upstream Keepalive

```nginx
upstream api_gateway {
    server localhost:8001;
    keepalive 100;  # Переиспользование соединений
}

location /api/ {
    proxy_pass http://api_gateway;
    proxy_http_version 1.1;
    proxy_set_header Connection "";
    # ...
}
```

### 3. Увеличение Worker Connections

```nginx
worker_processes auto;
worker_connections 16384;  # Увеличить еще больше
```

### 4. Оптимизация Proxy Buffers

```nginx
proxy_buffer_size 16k;
proxy_buffers 8 16k;
proxy_busy_buffers_size 32k;
```
