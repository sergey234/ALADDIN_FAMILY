## ⚠️ ОСТАВШИЕСЯ ЗАДАЧИ

### 🔴 КРИТИЧНО: Исправить блокирующую очередь

**Проблема:**
- `queue.Queue()` в `monitor_manager.py` блокирует event loop

**Решение:**
```python
# Заменить:
self.metrics_queue = queue.Queue()

# На:
self.metrics_queue = asyncio.Queue()
```

**Ожидаемый эффект:**
- P95: с 8,500ms до < 2,000ms
