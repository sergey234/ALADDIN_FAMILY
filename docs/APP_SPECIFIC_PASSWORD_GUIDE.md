# 🔐 ИНСТРУКЦИЯ: Как получить App-Specific Password

**Дата:** 27 ноября 2025  
**Для:** GitHub Actions загрузки в App Store

---

## 📍 ГДЕ НАХОДИТСЯ

В настройках Apple ID:
1. **Вход в учетную запись и безопасность** → **Пароли приложений**

---

## ✅ ПОШАГОВАЯ ИНСТРУКЦИЯ

### **ШАГ 1: Открыть "Пароли приложений"**

1. На странице настроек Apple ID найдите раздел **"Пароли приложений"**
2. Нажмите на **"Пароли приложений"** (или **"Подробнее"** рядом с ним)
3. Откроется страница с паролями приложений

---

### **ШАГ 2: Создать новый пароль**

1. На странице "Пароли приложений" нажмите **"Создать пароль приложения"** (или кнопку **"+"**)
2. Введите **название:** `GitHub Actions`
3. Нажмите **"Создать"** (или **"Готово"**)

---

### **ШАГ 3: Скопировать пароль**

1. Появится окно с паролем (формат: `xxxx-xxxx-xxxx-xxxx`)
2. **⚠️ ВАЖНО:** Пароль показывается только один раз!
3. **Скопируйте пароль** полностью
4. **Сохраните его** в безопасном месте (например, в заметках)
5. Нажмите **"Готово"** (или закройте окно)

---

## 📝 ПРИМЕР ПАРОЛЯ

Пароль выглядит так:
```
abcd-efgh-ijkl-mnop
```

**Формат:** 4 группы по 4 символа, разделённые дефисами

---

## ✅ ЧТО ДЕЛАТЬ ДАЛЬШЕ

После получения пароля:

1. **Скопируйте пароль** (например, `abcd-efgh-ijkl-mnop`)
2. **Сохраните его** — он понадобится для шага 2 (добавление секретов в GitHub)
3. **Переходите к шагу 2:** Добавить секреты в GitHub

---

## ⚠️ ВАЖНО

- Пароль показывается **только один раз**
- Если потеряете пароль — нужно создать новый
- Один пароль можно использовать для нескольких сервисов (но лучше создать отдельный для GitHub Actions)

---

## 🔗 СЛЕДУЮЩИЙ ШАГ

После получения пароля:
- Откройте: https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions
- Добавьте секреты (см. `docs/STEP_BY_STEP_GITHUB_SETUP.md`)

---

**Готово!** Нажмите на "Пароли приложений" и создайте новый пароль! 🔐
