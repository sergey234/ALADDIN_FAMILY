# ⚠️ ПРОБЛЕМА: КЭШИРОВАНИЕ СТАРЫХ ОТВЕТОВ

**Дата:** 2026-03-14  
**Проблема:** Мобильное приложение получает старые ответы "SFM_PROXIED" вместо реальных данных

---

## 🔍 АНАЛИЗ ПРОБЛЕМЫ

### **Что происходит:**

1. ✅ **Прямой curl запрос** → возвращает правильные данные (`real_sfm`)
2. ❌ **Мобильное приложение** → получает старые ответы "SFM_PROXIED" с timestamp `2026-03-15T15:06:18`

### **Причина:**

**КЭШИРОВАНИЕ!** Мобильное приложение получает закэшированные ответы от:
- CDN (Cloudflare или другой)
- Nginx прокси
- Браузер/приложение кэш

---

## ✅ РЕШЕНИЕ

### **1. Проверка на сервере:**

```bash
# Прямой запрос к серверу (минуя CDN)
curl -s "http://149.154.65.180:8002/api/reports/driving/stats"
# Результат: ✅ Правильные данные (`real_sfm`)

# Через CDN
curl -s "https://aladdin-ai.ru/api/reports/driving/stats"
# Результат: ✅ Правильные данные (`real_sfm`)
```

### **2. Очистка кэша:**

**На стороне сервера (Nginx):**
```bash
# Проверить настройки кэширования Nginx
grep -r "proxy_cache" /etc/nginx/
```

**На стороне CDN:**
- Очистить кэш в панели управления CDN
- Или добавить заголовки `Cache-Control: no-cache` в ответы API

### **3. Добавление заголовков в ответы:**

**В main.py добавить:**
```python
from fastapi.responses import JSONResponse

@app.middleware("http")
async def add_cache_headers(request: Request, call_next):
    response = await call_next(request)
    response.headers["Cache-Control"] = "no-cache, no-store, must-revalidate"
    response.headers["Pragma"] = "no-cache"
    response.headers["Expires"] = "0"
    return response
```

## 🎯 ВРЕМЕННОЕ РЕШЕНИЕ

### **Для мобильного приложения:**

1. **Добавить заголовки в запросы:**
```swift
request.setValue("no-cache", forHTTPHeaderField: "Cache-Control")
request.setValue("no-cache", forHTTPHeaderField: "Pragma")
```

2. **Или добавить timestamp в URL:**
```swift
let url = "https://aladdin-ai.ru/api/reports/driving/stats?t=\(Date().timeIntervalSince1970)"
```
