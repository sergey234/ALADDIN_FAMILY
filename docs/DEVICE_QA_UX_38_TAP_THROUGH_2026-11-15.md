# Device QA · UX 38 — куда нажимать (просто)

**Кто:** вы (владелец) на своей сборке  
**Агент:** без GO **не** собирает  
**Цель:** увидеть «было → стало» по плану P0+P1

---

## 1. Что значит «S19–36 полный Life360 — НЕТ»

Простыми словами:

| | |
|--|--|
| **Скрины S19–S36** | Это **скрины Life360** (их настройки, Help, Pet Finder, реклама Nativo, Gold…). |
| **«Полный Life360»** | Скопировать у них **все** окна 1:1. |
| **Почему НЕТ** | Вы сами зафиксировали: **не** клонировать Nativo, Pet Finder, Tile Help, Gold 1:1. |
| **Что вместо этого сделали** | На карте **шестерёнка** → короткое меню ALADDIN: Роли / Места / Конфиденциальность / Уведомления. Аккаунт — как раньше в **Профиле**. Help/Gold — потом (P2), не сейчас. |

**Итог:** мы **не забыли** S19–36. Мы **намеренно** не делаем полный клон — только нужные входы в ALADDIN.

## 2. Старт теста

1. Соберите и откройте ALADDIN (симулятор или iPhone).  
2. Дойдите до **Aladdin start** (Удобный / орбита с тремя дверями).  
3. Язык сначала **RU**.  
4. В логах Xcode (по желанию): `WHERE_PHONE` / `TRIP_AUTO`.

## 4. Галочки в конце (PASS)

- [ ] Hero: один слой, почти во весь круг, двери не перекрыты  
- [ ] Strip: «Семья · N из M мест» + «Добавить в семью»  
- [ ] Тап по карте не выкидывает  
- [ ] Refresh = иконка; точность честная  
- [ ] Поездка → push + золотой трек **или** честный error  
- [ ] Вождение: нет «Ничего не выдумываем»; Готово работает; default «Вы»  
- [ ] Дата «С понедельника…»; период выбирается  
- [ ] Фото в журнале выбирается  
- [ ] Конверт + шестерёнка работают  
- [ ] Trial CTA = дата (если показан), не слоты  

**PASS** = все пункты 1–26 по вашей сборке.  
Help / Gold / Pet / Nativo — **не** в этом прогоне.
