## ⚠️ ПРОБЛЕМЫ

### 1. Неправильный ключ для заголовка

**В коде:**
```swift
.navigationTitle(localizationManager.localized("component_family_notification_manager_title"))
```

**Должно быть:**
```swift
.navigationTitle(localizationManager.localized("component.family_notification_manager.title"))
```

### 2. Отсутствуют все ключи для разделов

Все ключи с префиксом `family_notifications_*` отсутствуют в LocalizationManager.

### 3. Хардкод в saveSettings()

**В коде:**
```swift
toastManager.showSuccess("Настройки сохранены")
```

**Должно быть:**
```swift
toastManager.showSuccess(localizationManager.localized("settings_saved"))
```
