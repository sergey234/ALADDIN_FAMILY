#### Задача 1.1: Переделать структуру Lesson для использования ключей локализации

**Текущая проблема:**
```swift
let lessons: [Lesson] = [
    Lesson(
        id: 1,
        icon: "🔐",
        title: "Безопасные пароли",  // ❌ Hardcoded
        description: "Как создать надёжный пароль",  // ❌ Hardcoded
        content: [
            "Пароль должен быть длинным...",  // ❌ Hardcoded
            // ...
        ],
        quizQuestions: [
            QuizQuestion(
                question: "Пароль должен быть:",  // ❌ Hardcoded
                options: ["Коротким", ...],  // ❌ Hardcoded
                correctAnswer: 1
            )
        ]
    ),
    // ... еще 5 уроков
]
```

**Решение:**
1. Изменить структуру `Lesson` - использовать ключи локализации вместо строк
2. Создать computed property `lessons` который возвращает локализованные уроки
3. Обновить структуру `QuizQuestion` - использовать ключи для вопросов и опций

**Файлы для изменения:**
- `Screens/YoungDefenderView.swift` - строки 33-229

**Ключи локализации (уже добавлены):**
- `young_defender_lesson_1_title` до `young_defender_lesson_6_title`
- `young_defender_lesson_X_desc` - описания
- `young_defender_lesson_X_content_1` до `young_defender_lesson_X_content_5` - содержимое
- `young_defender_lesson_X_quiz_Y_q` - вопросы
- `young_defender_lesson_X_quiz_Y_a1` до `young_defender_lesson_X_quiz_Y_a4` - варианты ответов

**Шаги выполнения:**
1. Изменить структуру `Lesson` - добавить ключи локализации:
   ```swift
   struct Lesson {
       let id: Int
       let icon: String
       let titleKey: String
       let descriptionKey: String
       let contentKeys: [String]
       let quizQuestions: [QuizQuestion]
   }
   ```

2. Изменить структуру `QuizQuestion`:
   ```swift

       let questionKey: String

   ```

3. Создать computed property `lessons` который использует LocalizationManager:
   ```swift

               id: 1,

               contentKeys: [
                   "young_defender_lesson_1_content_1",
                   // ...
               ],
               quizQuestions: [
                   QuizQuestion(
                       questionKey: "young_defender_lesson_1_quiz_1_q",

                           "young_defender_lesson_1_quiz_1_a1",
                           // ...
                       ],
                       correctAnswer: 1
                   )
               ]
           ),
           // ... остальные уроки
       ]
   }
   ```

4. Обновить все места использования `lesson.title` → `localizationManager.localized(lesson.titleKey)`
5. Обновить все места использования `lesson.description` → `localizationManager.localized(lesson.descriptionKey)`
