# ALADDIN Antifake vs Truecaller-style apps (G-06)

**Audience:** marketing, support, App Review. **Not** a competitive attack page.

| | ALADDIN Antifake | Typical caller-ID app |
|---|------------------|----------------------|
| **Goal** | Family safety: check content you share + labels from our fraud DB | Global caller ID from crowd phone book |
| **Call audio** | No background listening; post-call recording upload only | Often implies live ID on every call |
| **Data source** | Curated `antifake_scam_numbers` + moderated reports | Billions of crowd-sourced contacts |
| **Contacts upload** | **No** address-book harvest for antifake | Often requires contact access |
| **Verdict** | AI assist with disclaimer; `uncertain` allowed | Often binary spam/not spam |
| **iOS 15.2+** | Call Directory extension + Share + Hub | Call Directory + varies |
| **Premium** | Hub tabs + sync + analyze APIs | Subscription tiers |

**Honest line:** «Мы не заменяем глобальный caller ID — мы помогаем семье проверить подозрительный контент и видеть метки по нашей базе.»

**EN:** «We are not a global phone book — we help families check suspicious content and see labels from our database.»
