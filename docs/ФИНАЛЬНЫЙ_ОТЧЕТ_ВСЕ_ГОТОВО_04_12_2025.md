## 📊 ОТВЕТЫ НА ВОПРОСЫ

### 1. **RAM и посетители**

**Ответ:** НЕТ, RAM не будет расти пропорционально посетителям.

**Почему:**
- RAM используется для процессов, а не для каждого посетителя
- Каждый запрос обрабатывается и соединение закрывается
- RAM растет только при увеличении количества worker-процессов

**Текущее состояние:**
- Используется: 2.4GB из 3.7GB (65%) - нормально
- Основной потребитель: api_gateway (12 workers = ~1.6GB)
- Можно оптимизировать: уменьшить workers до 4-6 → освободит ~800MB

### 5. **Бесплатные подписки для друзей** 🎁

**Ответ:** ✅ РЕАЛИЗОВАНО!

**Как работает:**

1. **Создание подписки:**
   ```
   POST /api/admin/subscriptions/create-free
   {
     "alias": "friend123",
     "tariff_id": "lifetime",  // или "yearly"
     "duration_years": 1  // опционально
   }
   ```

2. **Что происходит:**
   - Создается Payment со статусом "paid" и amount=0
   - Генерируется код активации (ALDN-XXXX-XXXX)
   - Для "yearly" - срок 1 год (или указанное количество лет)
   - Для "lifetime" - срок до 2100 года (навсегда)

3. **Пользователь получает:**
   - Код активации
   - Вводит код в приложении → подписка активируется

**Безопасность:**
- ✅ Требуется админ-ключ
- ✅ Только авторизованные администраторы
- ✅ Все действия логируются

**Проверка подписок:**
```
GET /api/admin/subscriptions/user/{alias}
```
