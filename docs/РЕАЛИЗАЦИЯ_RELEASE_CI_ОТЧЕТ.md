## 📝 ЧТО НУЖНО СДЕЛАТЬ ДАЛЬШЕ

### ШАГ 1: Создать конфигурацию Release-CI в Xcode

**Следуйте инструкции:** `docs/ИНСТРУКЦИЯ_СОЗДАНИЯ_RELEASE_CI.md`

**Кратко:**
1. Открыть проект в Xcode
2. PROJECT → ALADDIN → Info
3. Duplicate "Release" Configuration → переименовать в "Release-CI"
4. Для каждого таргета (ALADDIN и ALADDINPacketTunnel):
   - Build Settings → Code Signing Style → Release-CI = Manual
5. Сохранить проект

### ШАГ 2: Проверить изменения

```bash
# Проверить, что Release-CI создана
grep -A 5 "Release-CI" ALADDIN.xcodeproj/project.pbxproj | grep "CODE_SIGN_STYLE"

# Должно быть: CODE_SIGN_STYLE = Manual;
```

### ШАГ 3: Запустить workflow

После создания конфигурации:
1. Workflow автоматически использует `-configuration Release-CI`
2. Xcode будет использовать Manual signing из настроек проекта
3. Параметры из командной строки и xcconfig должны работать

## 🚨 ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

### Ошибка: "configuration 'Release-CI' not found"

**Причина:** Конфигурация Release-CI не создана в Xcode

**Решение:**
1. Следуйте инструкции: `docs/ИНСТРУКЦИЯ_СОЗДАНИЯ_RELEASE_CI.md`
2. Убедитесь, что проект сохранен
3. Проверьте, что изменения в project.pbxproj закоммичены

### Ошибка: "requires a provisioning profile" (все еще)

**Причина:** Manual signing не установлен для Release-CI

**Решение:**
1. Проверьте Build Settings для обоих таргетов
2. Убедитесь, что Code Signing Style = Manual для Release-CI
3. Пересохраните проект
