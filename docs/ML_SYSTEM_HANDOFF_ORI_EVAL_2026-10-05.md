## 1. Зачем вся работа

Мы платим OpenRouter за ответы бота и помощника. Сейчас почти везде стоит одна модель: `deepseek/deepseek-v4-flash`. Её выбрали руками, потому что более дорогая Pro не проходила на длинном промпте Hermes (ошибка 402).

**Цель:** один раз сравнить недорогие модели на наших вопросах и оставить самую дешёвую, которая отвечает правильно. Не гнаться за «самой умной» в каталоге.

**Правило выбора:** проходит порог качества → берём ту, у которой меньше долларов за один правильно закрытый вопрос.

## 5. Задачи по пунктам

### ori-02 — Список мест, где мы зовём модель

| | |
|--|--|
| **Когда** | Сразу. Первый живой шаг. |
| **Зачем** | Чтобы тестировать одну дверь, а не весь репозиторий. |
| **Делать** | Одна таблица в registry: место, переменная окружения, модель сейчас, запасная модель, какой сервер. Источники уже есть: аудит Hermes, статус Flash бота, `security/services/asa/llm.py`, `scripts/check_ai_provider_flags.py`. |

| **Готово** | Четыре строки: Hermes, прямой запасной вызов, ассистент магазина, ASA. Статус в registry ✅. |

### ori-03 — Учебные вопросы магазина

| | |
|--|--|
| **Когда** | Сразу после ori-02. |
| **Зачем** | Одинаковые вопросы для всех моделей. Иначе сравнение нечестное. |

Выдуманные заказы, без имён и без реальных чатов. Файл рядом с ботом, например `telegram_stars_shop_bot/evals/shop/fixtures.json`. |
| **Не делать** | Копировать `llm_judge_cases.yaml`. Брать логи Telegram. |

### ori-04 — Пробный запуск Ori

| | |
|--|--|
| **Когда** | Только после фразы владельца **GO ORI $2**. Вместе с ori-05, не отдельно. |
| **Зачем** | Поставить инструмент и войти в аккаунт. Проверить, что он видит наши примеры. |
| **Делать** | Запуск во временной папке (так устроен `spawn-ori-eval`: в репозиторий сам ничего не кладёт). Потолок трат $2 на весь первый прогон, вместе со сравнением. |

**Когда:** смотреть только после Hermes.

**Делать:** отдельный GitHub Action по кнопке и раз в месяц. Секрет ключа — в настройках GitHub, не в файле.
