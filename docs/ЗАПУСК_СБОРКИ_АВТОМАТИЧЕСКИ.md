## 🤖 СПОСОБ 2: Через скрипт (требует токен)

### Шаг 1: Создать GitHub Personal Access Token

1. Откройте: https://github.com/settings/tokens
2. Нажмите "Generate new token" → "Generate new token (classic)"
3. Название: `ALADDIN Build Trigger`
4. Права:
   - ✅ `repo` (полный доступ к репозиторию)
   - ✅ `workflow` (запуск workflows)
5. Нажмите "Generate token"
6. **Скопируйте токен** (он показывается только один раз!)

### Шаг 2: Установить токен

```bash
export GITHUB_TOKEN=your_token_here
```

Или добавить в `~/.zshrc`:
```bash
echo 'export GITHUB_TOKEN=your_token_here' >> ~/.zshrc
source ~/.zshrc
```

### Шаг 3: Запустить скрипт

```bash
cd /Users/sergejhlystov/ALADDIN_NEW/ALADDIN_NEW/mobile_apps/ALADDIN_iOS
./scripts/trigger_appstore_build.sh
```
