## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Алгоритм генерации пузыря:

1. Определяется радиус (из настроек или явно указанный)
2. Генерируется случайное расстояние от центра (0 до radius)
3. Генерируется случайный угол (0 до 2π)
4. Вычисляется смещение в градусах:
   - 1 градус широты ≈ 111 км
   - 1 градус долготы ≈ 111 км * cos(широта)
5. Вычисляются приблизительные координаты

### Формула гаверсинуса:

Используется для вычисления расстояния между точками:
```
a = sin²(Δφ/2) + cos(φ1) * cos(φ2) * sin²(Δλ/2)
c = 2 * atan2(√a, √(1-a))
distance = R * c
```

где:
- R = 6371000 м (радиус Земли)
- φ1, φ2 = широты в радианах
- Δφ, Δλ = разности широт и долгот в радианах
