## 🎯 ОБЩАЯ ИНФОРМАЦИЯ О ПРОЕКТЕ

### 📱 Название проекта
**ALADDIN Family Security** - Система безопасности для защиты семей от мошенников и киберугроз

### 🏗️ Архитектура проекта
- **Мобильное приложение:** iOS 15.0+ (Swift 5.0, SwiftUI)
- **Серверная система:** Python Backend (SFM - Security Framework Manager)
- **Архитектура:** MVVM (мобильное) + Микросервисная (серверное)
- **Версия:** 1.0.0 (Build 10)

### 🎯 Основные функции
- ✅ Защита от мошенничества (3,581+ функций)
