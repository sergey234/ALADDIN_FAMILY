# 🔧 ИНСТРУКЦИЯ: Как выбрать Packet Tunnel Provider (если подменю не появляется)

**Проблема:** После отметки "Network Extensions" подменю не появляется, только галочка ставится/убирается  
**Решение:** Использовать альтернативные способы выбора типа Network Extension

---

## ✅ СПОСОБ 1: Кликнуть на саму строку "Network Extensions"

1. **Зайдите на:** https://developer.apple.com/account/resources/identifiers/list
2. **Кликните на `family.aladdin.ios.packetTunnel`**
3. **Прокрутите до раздела "Capabilities"**
4. **Найдите "Network Extensions"** в списке
5. **Кликните на саму строку "Network Extensions"** (не на галочку, а на текст)
   - Попробуйте кликнуть на слово "Network Extensions"
   - Или на область справа от галочки
6. **Должно открыться окно** или **детали** с опциями

---

## ✅ СПОСОБ 2: Проверить, есть ли кнопка "Configure" или "Edit"

1. **После включения "Network Extensions"** (галочка ☑️)
2. **Посмотрите рядом со строкой "Network Extensions":**
   - Может быть кнопка **"Configure"**
   - Или кнопка **"Edit"**
   - Или стрелка **">"** или **"▶"**
3. **Кликните на эту кнопку/стрелку**
4. **Должно открыться окно** с выбором типа

---

## ✅ СПОСОБ 3: Проверить вкладку "App Services" или "Details"

1. **В окне Bundle ID** найдите вкладки:
   - **"App Services"** (или "Services")
   - **"Details"**
   - **"Capabilities"**
2. **Перейдите на вкладку "App Services"** (если есть)
3. **Найдите "Network Extensions"** там
4. **Там может быть выбор типа**

---

## ✅ СПОСОБ 4: Проверить после сохранения

1. **Отметьте галочку** ☑️ рядом с "Network Extensions"
2. **Нажмите "Save"** (внизу справа)
3. **Дождитесь сохранения** (5-10 секунд)
4. **Обновите страницу** (F5 или Cmd+R)
5. **Снова откройте Bundle ID**
6. **Проверьте, появилось ли подменю** или **дополнительные опции**

---

## ✅ СПОСОБ 5: Использовать старый интерфейс (если доступен)

1. **Попробуйте использовать старую версию интерфейса:**
   - В URL может быть параметр для старого интерфейса
   - Или попробуйте другой браузер

2. **Или используйте Xcode для настройки:**
   - В Xcode: Signing & Capabilities
   - Добавьте Capability "Network Extensions"
   - Xcode может показать опции выбора типа

---

## ✅ СПОСОБ 6: Проверить через Xcode

1. **Откройте Xcode**
2. **Откройте проект ALADDIN**
3. **Выберите target "ALADDINPacketTunnel"**
4. **Вкладка "Signing & Capabilities"**
5. **Нажмите "+ Capability"**
6. **Добавьте "Network Extensions"**
7. **Xcode может показать опции** для выбора типа
8. **Выберите "Packet Tunnel Provider"**

---

## ⚠️ ВАЖНО: Проверить, что capabilities уже включены правильно

Возможно, Packet Tunnel Provider уже включён, но provisioning profile не обновлён.

**Проверьте:**

1. **В Apple Developer Portal** откройте Bundle ID
2. **Посмотрите на строку "Network Extensions":**
   - Если рядом есть **текст** или **иконка** — кликните на неё
   - Может быть написано: "Packet Tunnel Provider" рядом с галочкой

3. **Или проверьте через Xcode:**
   - Xcode → Preferences → Accounts
   - Выберите Apple ID → View Details
   - Найдите профиль для `family.aladdin.ios.packetTunnel`
   - Посмотрите, какие capabilities включены

---

## 🔧 АЛЬТЕРНАТИВНОЕ РЕШЕНИЕ: Пересоздать Bundle ID

Если ничего не помогает:

1. **Создайте новый Bundle ID:**
   - `family.aladdin.ios.packetTunnel.new`
2. **Включите все capabilities** с самого начала
3. **Обновите проект** в Xcode с новым Bundle ID
4. **Или используйте старый Bundle ID**, но удалите и создайте заново

---

## 📝 ЧТО ПРОВЕРИТЬ СЕЙЧАС

1. **Кликните на саму строку "Network Extensions"** (не на галочку)
2. **Проверьте, есть ли кнопка "Configure" или стрелка** рядом
3. **Сохраните и обновите страницу** — может появиться подменю
4. **Попробуйте через Xcode** — там может быть проще выбрать тип

---

## ✅ БЫСТРОЕ РЕШЕНИЕ: Через Xcode

**Самый простой способ:**

1. **В Xcode:** Signing & Capabilities
2. **Target: ALADDINPacketTunnel**
3. **Нажмите "+ Capability"**
4. **Добавьте "Network Extensions"**
5. **Xcode покажет опции** для выбора типа
6. **Выберите "Packet Tunnel Provider"**
7. **Xcode автоматически обновит** Bundle ID в Apple Developer Portal

---

**Попробуйте способ 6 (через Xcode) — это самый простой способ!** 🚀
