## ⚠️ КРИТИЧЕСКАЯ ПРОБЛЕМА

### Extension отсутствует в архиве Xcode!

**Проблема:**
- В архиве Xcode (`ALADDIN 29.11.2025, 02.12.xcarchive`) **НЕТ** Extension (ALADDINPacketTunnel.appex)
- Папка `PlugIns/` отсутствует в архиве
- dSYM для Extension есть, но самого Extension нет!

**Причины:**
1. Extension не был включен в схему сборки при создании архива в Xcode
2. Extension target не был добавлен в зависимости основного приложения
3. Extension не был собран при создании архива

**Решение:**
- ✅ **GitHub Actions версия:** Extension должен быть включен (проверить IPA!)
- ⚠️ **Xcode архив:** Нужно пересобрать архив с включенным Extension

## ✅ ПРОВЕРКА GITHUB ACTIONS

### Что настроено в workflow:

1. ✅ **Профиль Extension устанавливается:**
   - `PROVISIONING_PROFILE_EXTENSION` → `extension.mobileprovision`
   - UUID извлекается: `EXT_PROFILE_UUID`

2. ✅ **xcconfig создается с Extension:**
   ```xcconfig
   ALADDINPacketTunnel_CODE_SIGN_STYLE = Manual
   ALADDINPacketTunnel_PROVISIONING_PROFILE_SPECIFIER = {ext_profile_uuid}
   ALADDINPacketTunnel_PROVISIONING_PROFILE = {ext_profile_file}
   ALADDINPacketTunnel_PRODUCT_BUNDLE_IDENTIFIER = family.aladdin.ios.packetTunnel
   ```

3. ✅ **xcodebuild archive включает Extension:**
   - Параметры для Extension передаются в xcodebuild
   - Extension должен быть собран автоматически

**Вывод:** ✅ Extension **ДОЛЖЕН** быть включен в GitHub Actions версию!

## 🔍 КАК ПРОВЕРИТЬ IPA ИЗ GITHUB ACTIONS

### Пошаговая инструкция:

1. **Скачать IPA из GitHub Actions:**
   - Перейти в GitHub → Actions → последний workflow run
   - Найти артефакт `ALADDIN-IPA`
   - Скачать ZIP файл

2. **Распаковать IPA:**
   ```bash
   unzip ALADDIN-IPA.zip
   unzip ALADDIN.ipa -d extracted/
   ```

3. **Проверить наличие Extension:**
   ```bash
   ls -lh extracted/Payload/ALADDIN.app/PlugIns/
   ```

4. **Проверить подпись Extension:**
   ```bash
   codesign -dvv extracted/Payload/ALADDIN.app/PlugIns/ALADDINPacketTunnel.appex
   ```

5. **Проверить версию и Bundle ID:**
   ```bash
   plutil -p extracted/Payload/ALADDIN.app/Info.plist | grep -E "CFBundleShortVersionString|CFBundleVersion|CFBundleIdentifier"
   plutil -p extracted/Payload/ALADDIN.app/PlugIns/ALADDINPacketTunnel.appex/Info.plist | grep -E "CFBundleShortVersionString|CFBundleVersion|CFBundleIdentifier"
   ```

**Ожидаемый результат:**
- ✅ Папка `PlugIns/` должна существовать
- ✅ `ALADDINPacketTunnel.appex` должен быть внутри
- ✅ Extension должен быть подписан
- ✅ Версии должны быть `1.0.0` (1)
