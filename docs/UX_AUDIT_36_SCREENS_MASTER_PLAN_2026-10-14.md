## 0. Как устроено приложение (кратко для другой ML)

### 0.1 Три продукта в одном репо

| Продукт | Что это | Важно |
|---------|---------|--------|
| **iOS app** | SwiftUI, экраны, ViewModels | Релиз только с `master` |
| **API семьи** | FastAPI на 🇷🇺 MAIN FirstVDS (`…180`) `:8002`, снаружи `https://aladdin-ai.ru` | JWT Bearer |
| **Telegram bot / VPN** | Отдельный продукт | **Не** коммитить в iOS-релиз |

### 0.2 Как ходят экраны на сервер

```text
Экран (Screens/)
  → ViewModel / Manager
  → APIService / CompanionAPIService / WellnessAPIService
  → NetworkManager (Authorization: Bearer JWT, язык X-Aladdin-Lang)
  → https://aladdin-ai.ru → FastAPI :8002
```

- Пути клиента: `Core/Config/AppConfig.swift` → `Endpoint`
- Навигация: `NavigationManager.currentScreen` (не общий TabBar всего приложения)
- Токен: Keychain после `POST /api/auth/register-device`
- OpenAPI SSOT: `GET https://aladdin-ai.ru/openapi.json` (не `/api/openapi.json`)
- Проверка API: `smart_api_tester.py` (реальные HTTP), `openapi_conformant_audit.py`
- APNs реестр бэка: `app/security/notifications/push_token_registry.py`

### 0.3 Сквозные правила правок (обязательны)

1. **Текст для людей:** коротко, ясно, без «сервер», «HTTP», «fallback», «Grok», «152-ФЗ» в бытовых подсказках (юридические экраны — отдельно).
2. **Локализация:** ключ в `Resources/Localization/{ru,en}.lproj/Localizable.strings` **сначала**; в `LocalizationManager.swift` только точечный `StrReplace` (не переписывать mega-file).
3. **Контраст:** заголовки и подписи — светлые на тёмном (белый / near-white), не серый на тёмно-синем.
4. **Имена семьи:** роли и подписи («Родитель», «Ребёнок», «Ваше сообщение») **всегда** от языка приложения, не смесь EN/RU.
5. **Единорог:** запрещён путь `unicorn_master_crop_*` как основной вид; только целый master (PNG/Rive `Hero360`).
6. **Не mock** parental / family / antifake в проде.
7. После правок LocManager: `./scripts/verify_localization_manager_integrity.sh`
8. Сборка / симулятор — только после **GO на сборку** владельца.

### Экран 1 — Угроза в карантине / кибер-скан (EICAR и др.)

**Что это:** карточка найденной «угрозы» в разделе защиты устройства (антивирус / кибер-компоненты). Сейчас видно что-то вроде «eicar test file — standard anti malware…» на английском при русском языке.

**Замечания:** весь текст должен быть на языке пользователя; кратко: что за угроза, где лежит, что делать. То же для IoT и других карточек в этом разделе.

**Почему так:** тестовый файл EICAR часто приходит с сервера/сканера **сырым английским именем**; UI не прогоняет имя через локализацию и не добавляет человеческое пояснение.

**Лучшее решение (рекомендация):**

1. Для известных шаблонов (EICAR и каталог `DeviceCyberThreat`) — **свой заголовок + 3 поля**: Что / Где / Что сделать.  
2. Неизвестное имя файла — показывать безопасно, но подпись всегда локализована: «Подозрительный файл».  
3. IoT / компоненты — тот же шаблон карточки.

**Локализация (пример EICAR):**

| Поле | RU | EN |
|------|----|----|
| Заголовок | Тестовая проверка антивируса | Antivirus self-check |
| Что это | Учебный тестовый файл. Он не вирус, но антивирус должен его заметить. | A harmless test file. Real antivirus should detect it. |
| Где | В карантине на этом телефоне | In quarantine on this phone |
| Что сделать | Можно оставить в карантине или удалить. Для обычных угроз — не открывайте файл. | Keep in quarantine or delete. For real threats — do not open the file. |

**План:** каталог угроз → маппинг id→ключи → единый UI-компонент «карточка угрозы» → IoT/Components тем же компонентом.

**Чеклист:**

- [x] EICAR на RU без английского тела  
- [x] EICAR на EN человеческий  
- [x] Поля Что / Где / Что сделать  
- [x] IoT и «Компоненты» тем же шаблоном (`DeviceScanResultCard`)  
- [x] Нет сырого `eicar.com` как единственного текста

### Экран 6 — «Награды и статистика временно недоступны»

**Что это:** реферальный / награды блок (`referral_soft_stats_unavailable`).

**Почему так (часто):**

1. Эндпоинт `/api/referral/*` или gamification вернул 5xx/timeout.

- Кэш последнего успешного ответа.  
- Текст: «Пока не удалось загрузить награды. Приглашать можно — цифры появятся чуть позже.»

**Чеклист:**

- [ ] Soft-fail не пугает

### Экран 14 — «Осторожно» + HTTP 504 у героя

### Экран 16 — Места семьи (геозоны) + нет пушей

**Что это:** список мест + «Ждём к времени».

**Замечания:** плохой контраст текста; нет уведомлений о посещении в тестовой сети.

**Логика (простыми словами):** телефон ребёнка замечает вход/выход из зоны → событие уходит на сервер → родителям push (APNs). Без включённого фильтра/токена/гео-разрешений пуша не будет.
