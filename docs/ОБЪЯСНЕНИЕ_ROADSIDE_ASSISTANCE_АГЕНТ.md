## 🎯 КАК РАБОТАЕТ АГЕНТ?

### 1. **Архитектура работы**

Roadside Assistance Agent работает в **двух режимах**:

#### Режим 1: **MANUAL (Ручной)** - ✅ РАБОТАЕТ СЕЙЧАС
- Агент создает запрос на помощь
- Сохраняет информацию о проблеме, местоположении, типе проблемы
- **НЕ** отправляет запрос партнеру автоматически
- Пользователь видит запрос в приложении
- Можно вручную связаться со службой помощи (112, службы техпомощи)

**Когда использовать:**
- Пока нет договоров с партнерами
- Для тестирования функционала
- Для пользователей, которые хотят сами вызывать помощь

#### Режим 2: **ПАРТНЕРСКИЙ** - ⚠️ ТРЕБУЕТ ДОГОВОРОВ
- Агент создает запрос
- **Автоматически** отправляет запрос партнеру через API
- Партнер назначает службу помощи
- Агент отслеживает статус в реальном времени
- Пользователь получает уведомления о прибытии помощи

**Когда использовать:**
- После заключения договоров с партнерами
- Для автоматической интеграции со службами помощи

## 🔧 ПРИНЦИП ДЕЙСТВИЯ (ПОШАГОВО)

### Шаг 1: Пользователь вызывает помощь

```
iOS App → POST /api/roadside-assistance/call
{
    "user_id": "user123",
    "problem_type": "tire_change",  // Тип проблемы
    "location": {
        "latitude": 55.7558,
        "longitude": 37.6173,
        "address": "Москва, Ленинградский проспект, 10"
    },
    "description": "Прокол переднего левого колеса",
    "vehicle_info": {
        "make": "Toyota",
        "model": "Camry",
        "year": 2020
    }
}
```

### Шаг 2: Агент создает запрос

```python
# Агент генерирует уникальный ID
request_id = "RSA-20251214-A1B2C3D4"

# Создает запрос
assistance_request = AssistanceRequest(
    request_id=request_id,
    user_id="user123",
    partner="manual",  # или "rosgosstrah", "alfastrahovanie" и т.д.
    problem_type=ProblemType.TIRE_CHANGE,
    status=AssistanceStatus.PENDING,
    location=location,
    ...
)
```

### Шаг 3: Отправка партнеру (если не MANUAL)

**Если партнер настроен:**
```python
# Агент отправляет запрос через API партнера
partner_response = {
    "request_id": "RGS-2025-12-14-001234",
    "status": "dispatched",
    "estimated_arrival": "2025-12-14T16:45:00",
    "service_provider": {
        "name": "Автопомощь 24/7",
        "phone": "+79991111111",
        "vehicle_number": "А123БВ777",
        "driver_name": "Иван Иванов"
    }
}
```

**Если MANUAL:**
- Запрос сохраняется в системе
- Пользователь видит информацию
- Можно вручную вызвать помощь

### Шаг 4: Отслеживание статуса

```python
# Периодическая проверка статуса (каждые 30 секунд)
GET /api/roadside-assistance/status/{request_id}

# Статусы:
- pending → dispatched → on_way → arrived → in_progress → completed
```

### Шаг 5: Отмена (если нужно)

```python
POST /api/roadside-assistance/cancel/{request_id}
```

## 🤝 ПАРТНЕРСТВО: НУЖНЫ ЛИ ДОГОВОРЫ?

### ✅ КОРОТКИЙ ОТВЕТ: **ДА, для полной функциональности нужны договоры**

### 📋 ДЕТАЛЬНОЕ ОБЪЯСНЕНИЕ:

#### 1. **Текущее состояние (БЕЗ договоров):**

✅ **Что работает:**
- Создание запросов на помощь
- Сохранение информации (проблема, местоположение, тип)
- Отслеживание статуса (локально)
- История запросов
- Отмена запросов
- **Режим MANUAL** - пользователь сам вызывает помощь

❌ **Что НЕ работает:**
- Автоматическая отправка запросов партнерам
- Получение реальных служб помощи от партнеров
- Автоматическое отслеживание прибытия помощи
- Интеграция с реальными API партнеров

#### 2. **После заключения договоров:**

✅ **Что появится:**
- Автоматическая интеграция с партнерами
- Реальные службы помощи назначаются автоматически
- Отслеживание в реальном времени
- Уведомления о прибытии помощи
- Автоматическое обновление статусов

## 🏢 КАКИЕ ПАРТНЕРЫ ПОДДЕРЖИВАЮТСЯ?

Агент поддерживает интеграцию с:

1. **Росгосстрах** (`rosgosstrah`)
   - API: `https://api.rosgosstrah.ru/roadside-assistance`
   - Требуется: API ключ, договор

2. **АльфаСтрахование** (`alfastrahovanie`)
   - API: `https://api.alfastrah.ru/roadside-assistance`
   - Требуется: API ключ, договор

3. **Ингосстрах** (`ingosstrah`)
   - API: `https://api.ingos.ru/roadside-assistance`
   - Требуется: API ключ, договор

4. **РЕСО-Гарантия** (`reso`)
   - API: `https://api.reso.ru/roadside-assistance`
   - Требуется: API ключ, договор

5. **MANUAL** (`manual`) - ✅ РАБОТАЕТ БЕЗ ДОГОВОРОВ
   - Ручной режим
   - Пользователь сам вызывает помощь

## 📝 ЧТО НУЖНО ДЛЯ ПАРТНЕРСТВА?

### Для каждого партнера нужно:

1. **Договор на оказание услуг:**
   - Условия сотрудничества
   - Тарифы на услуги
   - Область покрытия (регионы)

2. **API доступ:**
   - API ключ (для авторизации)
   - API endpoint (URL для запросов)
   - Документация API

3. **Техническая интеграция:**
   - Настройка API ключей в конфигурации
   - Тестирование интеграции
   - Обработка ошибок

## 🚀 ТЕКУЩАЯ РЕАЛИЗАЦИЯ

### ✅ Что уже готово:

1. **Базовый агент** (`roadside_assistance_agent.py`)
   - Создание запросов
   - Отслеживание статусов
   - История запросов
   - Отмена запросов

2. **API endpoints** (`roadside_assistance_router.py`)
   - `POST /api/roadside-assistance/call` - вызов помощи
   - `GET /api/roadside-assistance/status/{request_id}` - статус
   - `POST /api/roadside-assistance/cancel/{request_id}` - отмена
   - `GET /api/roadside-assistance/history` - история
   - `GET /api/roadside-assistance/health` - health check

3. **Поддержка партнеров:**
   - Структура для интеграции готова
   - Методы отправки запросов готовы (заглушки)
   - После получения API ключей - просто раскомментировать код

4. **Режим MANUAL:**
   - ✅ Работает без договоров
   - Пользователь может использовать функционал

### ⚠️ Что нужно для полной функциональности:

1. **Договоры с партнерами:**
   - Росгосстрах
   - АльфаСтрахование
   - Ингосстрах
   - РЕСО-Гарантия
   - Или другие службы помощи

2. **API ключи:**
   - Получить от каждого партнера
   - Настроить в переменных окружения

3. **Активация интеграции:**
   - Раскомментировать код отправки запросов
   - Протестировать с реальными API
