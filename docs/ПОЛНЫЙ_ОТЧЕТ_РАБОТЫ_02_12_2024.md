## 🎯 ОБЗОР РАБОТЫ

**Дата:** 2 декабря 2024  
**Основная задача:** Исправить ошибки GitHub Actions workflow для сборки iOS приложения  
**Workflow файл:** `.github/workflows/check-secrets.yml`  
**Основная проблема:** Xcode не может найти provisioning profiles в CI, даже с правильными параметрами

---

## ❌ ВСЕ ОШИБКИ, КОТОРЫЕ БЫЛИ

### 1. **Ошибка: "Exceeded max expression length 21000"**
**Описание:** Блок "Setup Provisioning Profiles" превышал лимит GitHub Actions в 21000 символов  
**Местоположение:** `.github/workflows/check-secrets.yml`, блок "Setup Provisioning Profiles"  
**Симптомы:**
- Workflow не запускался
- Ошибка валидации YAML: `(Line: 431, Col: 12): Exceeded max expression length 21000`

**Решение:** ✅ Разбит на 5 отдельных шагов:
- "Decode App Profile"
- "Extract App Profile UUID"
- "Decode Extension Profile"
- "Extract Extension Profile UUID"
- "Verify Profiles"

---

### 2. **Ошибка: "Failed to decode PROVISIONING_PROFILE_APP (invalid base64)"**
**Описание:** Base64 декодирование не удавалось из-за невалидных символов  
**Симптомы:**
- `base64: stdin: (null): error decoding base64 input stream`
- В секрете был символ `%` в конце

**Решение:** ✅ Добавлена очистка base64 строки:
- `tr -dc 'A-Za-z0-9+/='` для удаления невалидных символов
- Добавлена диагностика: длина секрета, первые/последние 50 символов

---

### 3. **Ошибка: "ALADDIN" requires a provisioning profile**
**Описание:** Xcode не мог найти provisioning profile для основного таргета  
**Симптомы:**
- `"ALADDIN" requires a provisioning profile. Select a provisioning profile in the Signing & Capabilities editor.`
- Профили установлены, но Xcode их не видит

**Решение:** ✅ Улучшена логика поиска профилей:
- Приоритет: UUID → полный путь к файлу → bundle ID
- Добавлено переименование файлов в `UUID.mobileprovision`
- Добавлена передача полного пути в `PROVISIONING_PROFILE`

---

### 4. **Ошибка: "ALADDINPacketTunnel" requires a provisioning profile with Network Extensions and Personal VPN features**
**Описание:** Xcode не мог найти provisioning profile для extension таргета  
**Симптомы:**
- `"ALADDINPacketTunnel" requires a provisioning profile with the Network Extensions and Personal VPN features.`
- Extension profile не был установлен (секрет `PROVISIONING_PROFILE_EXTENSION` отсутствовал)

**Решение:** ✅ Добавлена обработка отсутствующего секрета:
- Graceful handling: если секрет не установлен, используется bundle ID fallback
- Создан документ с инструкциями по добавлению секрета

---

### 5. **Ошибка: UUID не извлекался из профилей**
**Описание:** UUID не извлекался из XML профилей из-за форматирования  
**Симптомы:**
- `plutil` не мог извлечь UUID
- `grep` и `strings` также не находили UUID
- XML содержал табы и переносы строк

**Решение:** ✅ Улучшена логика извлечения UUID:
- Добавлен `awk` как основной метод после `plutil`
- Добавлен `sed` для обработки XML с табами/переносами
- Добавлен `tr -d '\t '` для очистки UUID
- Исправлен regex на case-insensitive: `[0-9A-Fa-f]{8}-...`

---

### 6. **Ошибка: UUID извлекался, но не проходил валидацию**
**Описание:** UUID извлекался (например, `039a47c4-b057-4712-a90a-5bb21d9a500e`), но не проходил regex проверку  
**Симптомы:**
- UUID в lowercase, а regex был case-sensitive
- `⚠️ AWK_UUID doesn't match regex pattern`

**Решение:** ✅ Исправлен regex на case-insensitive:
- Было: `^[0-9A-F]{8}-[0-9A-F]{4}-[0-9A-F]{4}-[0-9A-F]{4}-[0-9A-F]{12}$`
- Стало: `^[0-9A-Fa-f]{8}-[0-9A-Fa-f]{4}-[0-9A-Fa-f]{4}-[0-9A-Fa-f]{4}-[0-9A-Fa-f]{12}$`

---

### 7. **Ошибка: "syntax error: unexpected end of file"**
**Описание:** Отсутствовал `fi` для закрытия `if-else` блока  
**Симптомы:**
- `/Users/runner/work/_temp/.../sh: line 168: syntax error: unexpected end of file`
- В блоке "Extract App Profile UUID" не хватало `fi`

**Решение:** ✅ Добавлен недостающий `fi` для закрытия блока

---

### 8. **Ошибка: "Exceeded max expression length 21000" в "Build Archive (with signing)"**
**Описание:** Блок "Build Archive (with signing)" превышал лимит 21000 символов  
**Симптомы:**
- `(Line: 1301, Col: 12): Exceeded max expression length 21000`
- Размер блока: 20069 символов (близко к лимиту)

**Решение:** ✅ Удалено дублирование:
- Удален дублирующий `xcodebuild` команда
- Удалено дублирующее создание `xcconfig` файла
- Размер уменьшен с 20069 до 19325 символов

---

### 9. **Ошибка: Xcode не может найти профили (ПЕРСИСТЕНТНАЯ)**
**Описание:** Xcode все еще не может найти provisioning profiles, даже с полными путями и UUID  
**Симптомы:**
- Профили установлены правильно
- UUID извлечены правильно
- Полные пути переданы в `PROVISIONING_PROFILE`
- Но Xcode все равно выдает: `"ALADDIN" requires a provisioning profile`

**Причина:** Проект настроен на `CODE_SIGN_STYLE = Automatic` в `project.pbxproj`, и Xcode игнорирует параметры Manual signing из командной строки и xcconfig файла.

**Решение:** ⚠️ **НЕ РЕШЕНО** - требуется изменение настроек проекта
