- Бонусы только **продуктом**: дни семейной защиты / скидка другу / слот (по уровню)
- Qualify: **оплата** или **≥14 дней** активной защиты
- Уровни Bronze → Platinum (один этаж)
- Ledger «за что начислили»
- Антиабуз: нельзя себе; 1 бонус на пару семей; у реферера активный тариф
- UI рефки только для **parent / elderly**
- P0: push grant, funnel analytics, CTA в Профиле/Семье, i18n safe
