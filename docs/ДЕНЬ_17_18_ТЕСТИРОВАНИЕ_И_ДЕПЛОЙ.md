## 📝 ИНСТРУКЦИИ ПО ДЕПЛОЮ

### 1. Установка зависимостей

```bash
pip install fastapi pydantic pytest uvicorn
```

### 2. Загрузка базы мошенников

База мошенников должна быть загружена в один из форматов:
- JSON: `fraud_database.json`
- CSV: `fraud_database.csv`
- SQLite: `fraud_database.db`

Размещение: `security/data/fraud_database.*`

### 3. Настройка логирования

Настроить логирование в соответствии с политикой безопасности:
- Все операции с персональными данными должны логироваться
- Логи должны храниться согласно законодательству (не более 3 лет)

### 4. Интеграция с ThreatEventBus

Убедиться, что `ThreatEventBus` настроен и работает:
- Уведомления о согласиях будут отправляться через bus
- Настроить каналы доставки (push, email)

### 5. Настройка периодических задач

Настроить автоматический запуск `check_expired_consents()`:
- Рекомендуется: раз в день (cron job или scheduled task)
- Проверка истекших согласий
- Отправка уведомлений

### 6. Мониторинг

Настроить метрики мониторинга:
- Количество активных согласий
- Количество истекших согласий
- Количество отзывов согласий
- Производительность проверок
- Использование памяти
