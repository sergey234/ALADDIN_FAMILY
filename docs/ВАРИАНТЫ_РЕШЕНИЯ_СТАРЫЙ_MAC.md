## 🎯 ВАРИАНТ 1: GITHUB ACTIONS (РЕКОМЕНДУЕТСЯ) ⭐

**Бесплатно для публичных репозиториев, автоматическая сборка на облачных серверах Apple.**

### Преимущества:
- ✅ **Бесплатно** (для публичных репозиториев)
- ✅ Автоматическая сборка
- ✅ Использует Xcode 16+ на серверах Apple
- ✅ Не требует обновления Mac
- ✅ Автоматическая загрузка в App Store Connect

### Как настроить:

1. **Создать GitHub репозиторий** (если нет)
2. **Загрузить код в репозиторий**
3. **Создать API ключ в App Store Connect:**
   - App Store Connect → Users and Access → Keys
   - Создать новый ключ
   - Скачать .p8 файл
   - Сохранить Issuer ID и Key ID

4. **Добавить секреты в GitHub:**
   - Repository → Settings → Secrets → Actions
   - Добавить:
     - `APP_STORE_CONNECT_API_KEY` (содержимое .p8 файла)
     - `APP_STORE_CONNECT_ISSUER_ID`
     - `APP_STORE_CONNECT_API_KEY_ID`

5. **Создать workflow файл:**
   - Файл уже создан: `.github/workflows/build.yml`
   - Настроить под ваш проект

6. **Запустить сборку:**
   - Push в репозиторий
   - Или через GitHub UI → Actions → Run workflow

### Время настройки: 30-60 минут  
### Стоимость: Бесплатно (публичный репозиторий)
