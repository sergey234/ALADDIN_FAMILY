## Проблема #1: Ошибка 422 при регистрации устройства (КРИТИЧНО)

### Описание проблемы:
- Сервер ожидает `device_id` и `device_type` (snake_case)
- Клиент отправляет `deviceId` и `deviceType` (camelCase)
- Ошибка: `"Field required", "loc":["body","device_id"]`

### Решение:
1. Добавить `CodingKeys` в `DeviceRegisterRequest` для конвертации в snake_case
2. Улучшить обработку ошибки 422 - не переходить в offline режим
3. Добавить детальное логирование запроса и ответа

### Файлы для изменения:
- `Core/Models/APIModels.swift` - добавить CodingKeys
- `Core/Managers/SubscriptionManager.swift` - улучшить обработку ошибок
