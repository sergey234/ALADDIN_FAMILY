## 📋 КАК ЭТО РАБОТАЕТ

### 1. Сбор угроз

`ThreatIntelligenceAgent` собирает данные об угрозах из различных источников:
- RSS фиды
- API источников угроз
- Правительственные источники
- Академические источники
- Коммерческие источники
- Сообщества

### 2. Анализ угроз

Агент анализирует собранные угрозы:
- Классификация типа угрозы
- Предсказание серьезности
- Анализ индикаторов компрометации (IOCs)
- Оценка качества данных

### 3. Индикаторы компрометации (IOCs)

Агент собирает и анализирует IOCs:
- IP адреса
- Домены
- URL
- Email адреса
- Хеши файлов
- И другие индикаторы

### 4. Мониторинг утечек

**Как это работает для "Утечек в тёмной сети":**

1. **Сбор данных об утечках:**
   - Агент собирает информацию об утечках данных из различных источников
   - RSS фиды с информацией об утечках
   - API источников утечек
   - Правительственные отчеты об утечках

2. **Анализ утечек:**
   - Классификация типа утечки
   - Определение серьезности
   - Анализ затронутых данных
   - Идентификация пострадавших систем

3. **Сопоставление с данными пользователя:**
   - Сравнение собранных данных об утечках с данными пользователей
   - Проверка email адресов
   - Проверка доменов
   - Проверка других идентификаторов

4. **Генерация алертов:**
   - При обнаружении совпадений - генерация алерта
   - Оценка риска
   - Рекомендации по действиям

## 🎯 РЕКОМЕНДАЦИЯ

Для полноценного Dark Web мониторинга (как у Aura/Norton) нужно:

1. **Расширить ThreatIntelligenceAgent:**
   - Добавить метод `check_user_email_breach(email: str)`
   - Интегрировать с Have I Been Pwned API
   - Интегрировать с BreachDirectory API
   - Добавить персональный мониторинг

2. **Или создать отдельный агент:**
   - `dark_web_monitoring_agent.py`
   - Специализированный на персональном мониторинге утечек
   - Интеграция с ThreatIntelligenceAgent
