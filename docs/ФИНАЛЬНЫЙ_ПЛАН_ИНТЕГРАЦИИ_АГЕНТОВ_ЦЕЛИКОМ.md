- Автоматическое обнаружение аварий
- Экстренные уведомления

**Интеграция:**
- ✅ API уже есть (`/api/crash-detection/*`)
- ❌ UI не реализован
- **Нужно:** Экран для включения/выключения агента + статус мониторинга

**Endpoints:**
- `/api/crash-detection/enable` - Включить агента
- `/api/crash-detection/disable` - Выключить агента
- `/api/crash-detection/status` - Статус агента
- `/api/crash-detection/start-monitoring` - Запустить мониторинг
