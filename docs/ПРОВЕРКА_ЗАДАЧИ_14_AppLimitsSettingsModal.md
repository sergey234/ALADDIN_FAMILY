## 📝 ВАЖНЫЕ ДЕТАЛИ

1. **Функция `saveAppLimitForApp(app:limit:)` (строки 3582-3593):**
   - Вызывается автоматически при изменении слайдера через Binding setter
   - Сохраняет лимит для конкретного приложения в UserDefaults с динамическим ключом
   - Обновляет значение в массиве `appLimits` и сохраняет весь массив
   - Ключ формируется как: `app_\(app.lowercased().replacingOccurrences(of: " ", with: "_"))_time_limit`

2. **Функция `loadAppLimits()` (строки 3553-3591):**
   - Сначала загружает общий массив из `app_limits_settings`
   - Затем проверяет индивидуальные ключи для каждого приложения
   - Если индивидуальный ключ существует, использует его значение (приоритет выше)
   - Это позволяет сохранять индивидуальные настройки для каждого приложения

3. **Binding с автоматическим сохранением:**
   - Используется Binding с get/set, который вызывает `saveAppLimitForApp()` при изменении
   - Это обеспечивает автоматическое сохранение при каждом изменении слайдера
   - Не нужно нажимать кнопку "Сохранить" для сохранения изменений

4. **Двойное сохранение:**
   - Индивидуальные ключи: `app_instagram_time_limit`, `app_tiktok_time_limit`, и т.д.
   - Общий массив: `app_limits_settings` (для совместимости с существующим кодом)
   - Это обеспечивает надежность и позволяет легко получить значение для конкретного приложения
