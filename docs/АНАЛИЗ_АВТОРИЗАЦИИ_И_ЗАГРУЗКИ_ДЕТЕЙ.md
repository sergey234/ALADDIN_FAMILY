## 🔐 1. КАК ПРОИСХОДИТ АВТОРИЗАЦИЯ

### Процесс авторизации:

1. **Регистрация семьи:**
   - Пользователь открывает приложение
   - Проходит онбординг (если первый запуск)
   - Выбирает роль (Родитель, Ребенок, Подросток, Пожилой)
   - Выбирает возрастную группу
   - Вводит имя
   - Нажимает "Создать семью" или "Присоединиться к семье"

2. **Получение токена:**
   - Приложение отправляет запрос на сервер: `POST /api/auth/register` или `POST /api/auth/login`
   - Сервер создает пользователя и возвращает токены:
     - `access_token` - токен доступа (действует 24 часа)
     - `refresh_token` - токен обновления (для продления сессии)

3. **Сохранение токена:**
   - Токен сохраняется в **Keychain** (безопасное хранилище iOS)
   - Также сохраняется в **UserDefaults** для обратной совместимости
   - Устанавливается в `AppConfig.authToken` для использования в API запросах

**Код сохранения токена:**
```swift
// ViewModels/FamilyRegistrationViewModel.swift
private func saveTokens(accessToken: String, refreshToken: String?) -> Bool {
    // Сохраняем в Keychain
    KeychainManager.shared.save(accessToken, forKey: .authToken)
    if let refreshToken = refreshToken {
        KeychainManager.shared.save(refreshToken, forKey: .refreshToken)
    }
    
    // Сохраняем в AppConfig для использования в API
    AppConfig.authToken = accessToken
    
    // Отправляем уведомление об успешной авторизации
    NotificationCenter.default.post(name: NSNotification.Name("UserDidLogin"), object: nil)
}
```

## ❌ 3. ПОЧЕМУ МОЖЕТ НЕ БЫТЬ ТОКЕНА? ПРИЧИНЫ

### Причины отсутствия токена:

1. **Первый запуск приложения:**
   - Пользователь еще не зарегистрировался
   - Токен будет создан после регистрации

2. **Токен истек:**
   - Access token действует 24 часа
   - Если не обновился через refresh_token - токен становится невалидным

3. **Пользователь вышел из аккаунта:**
   - Токен был удален вручную
   - Или произошел сброс данных приложения

4. **Ошибка при сохранении токена:**
   - Проблемы с Keychain
   - Проблемы с UserDefaults

5. **Ошибка при регистрации:**
   - Сервер не вернул токен
   - Ошибка сети при регистрации

**Проверка токена в коде:**
```swift
// Core/Config/AppConfig.swift
static var authToken: String? {
    get {
        // Сначала пробуем Keychain (основное хранилище)
        if let keychainToken = KeychainManager.shared.loadString(forKey: .authToken) {
            return keychainToken
        }
        // Fallback на UserDefaults для обратной совместимости
        return UserDefaults.standard.string(forKey: AppConfig.UserDefaultsKeys.authToken)
    }
}
```

## 🔍 4. ПРОБЛЕМА: ЗАРЕГИСТРИРОВАЛ 1 РЕБЕНКА, НО ПОКАЗЫВАЕТ ЧТО ДЕТЕЙ НЕТ

### Анализ проблемы:

#### **Проблема #1: Дети сохраняются в UserDefaults, но загружаются из API**

**Логика работы:**

1. **При регистрации ребенка:**
   - Ребенок сохраняется в `UserDefaults` с ключом `"family_members_list"`
   - Это происходит в `saveCreatorAsFamilyMember()` или `saveJoinedMemberAsFamilyMember()`

2. **При загрузке детей в ParentalControlScreen:**
   - Используется `apiService.getFamilyMembers()` - загружает детей **из API**, а не из UserDefaults
   - Если API не возвращает детей (нет токена, ошибка сети, дети не синхронизированы с сервером) - список пустой

**Код загрузки детей:**
```swift
// Screens/07_ParentalControlScreen.swift
private func loadChildMembers() {
    // Проверяем токен
    guard AppConfig.authToken != nil else {
        // Если токена нет - список пустой
        self.children = []
        return
    }
    
    // Загружаем детей из API
    apiService.getFamilyMembers { result in
        switch result {
        case .success(let members):
            self.children = members  // Дети из API
            // Фильтруем только child и teenager
            if childMembers.isEmpty {
                // Если после фильтрации нет детей - показываем "Нет детей"
            }
        case .failure(let error):
            // Ошибка загрузки
        }
    }
}
```

**Фильтрация детей:**
```swift
// Screens/07_ParentalControlScreen.swift
private var childMembers: [FamilyMemberResponse] {
    children.filter { member in
        let role = member.role.lowercased()
        return role == "child" || role == "teenager"
    }
}
```

#### **Проблема #2: Несоответствие ролей между UserDefaults и API**

**В UserDefaults сохраняется:**
- `FamilyMemberCard.FamilyRole` (enum: `.parent`, `.child`, `.teenager`, `.elderly`)

**В API ожидается:**
- Строка: `"parent"`, `"child"`, `"teenager"`, `"elderly"`

**Если роль в API не совпадает с ожидаемой** - ребенок не пройдет фильтрацию.

#### **Проблема #3: Дети не синхронизированы с сервером**

**Что происходит:**
1. Ребенок регистрируется локально → сохраняется в UserDefaults
2. Но если регистрация на сервере не завершена → API не знает о ребенке
3. При загрузке из API → список пустой

## 🔧 РЕШЕНИЕ ПРОБЛЕМЫ

### Решение #1: Добавить загрузку из UserDefaults как fallback

**Исправление:**
```swift
// Screens/07_ParentalControlScreen.swift
private func loadChildMembers() {
    isChildrenLoading = true
    childrenErrorMessage = nil
    
    // ✅ ИСПРАВЛЕНИЕ: Сначала пробуем загрузить из UserDefaults (локальный кэш)
    if let savedData = UserDefaults.standard.data(forKey: "family_members_list"),
       let decoded = try? JSONDecoder().decode([FamilyMemberData].self, from: savedData) {
        // Преобразуем FamilyMemberData в FamilyMemberResponse для совместимости
        let localChildren = decoded.filter { member in
            member.role == .child || member.role == .teenager
        }
        
        if !localChildren.isEmpty {
            // Преобразуем в FamilyMemberResponse
            let convertedChildren = localChildren.map { member in
                FamilyMemberResponse(
                    id: UUID().uuidString, // Временный ID
                    name: member.name,
                    role: member.role.rawValue, // Преобразуем enum в строку
                    status: member.status.rawValue,
                    threatsBlocked: member.threatsBlocked,
                    lastActive: member.lastActive
                )
            }
            self.children = convertedChildren
            print("✅ Загружено \(convertedChildren.count) детей из локального кэша")
        }
    }
    
    // Проверяем токен перед загрузкой из API
    guard AppConfig.authToken != nil else {
        DispatchQueue.main.async {
            self.isChildrenLoading = false
            // Если есть локальные дети - не показываем ошибку
            if !self.childMembers.isEmpty {
                self.childrenErrorMessage = nil
            } else {
                self.children = []
                self.childrenErrorMessage = nil
            }
        }
        return
    }
    
    // Загружаем из API для синхронизации
    apiService.getFamilyMembers { result in
        DispatchQueue.main.async {
            self.isChildrenLoading = false
            switch result {
            case .success(let members):
                // Обновляем список детей из API
                self.children = members
                
                // Если после фильтрации нет детей, но есть локальные - используем локальные
                if childMembers.isEmpty {
                    // Пробуем снова загрузить из UserDefaults
                    if let savedData = UserDefaults.standard.data(forKey: "family_members_list"),
                       let decoded = try? JSONDecoder().decode([FamilyMemberData].self, from: savedData) {
                        let localChildren = decoded.filter { member in
                            member.role == .child || member.role == .teenager
                        }
                        if !localChildren.isEmpty {
                            // Используем локальные данные
                            let convertedChildren = localChildren.map { member in
                                FamilyMemberResponse(
                                    id: UUID().uuidString,
                                    name: member.name,
                                    role: member.role.rawValue,
                                    status: member.status.rawValue,
                                    threatsBlocked: member.threatsBlocked,
                                    lastActive: member.lastActive
                                )
                            }
                            self.children = convertedChildren
                            print("✅ Используем локальные данные: \(convertedChildren.count) детей")
                        }
                    }
                }
                
                if childMembers.isEmpty {
                    self.childrenErrorMessage = nil
                    self.statsErrorMessage = localizationManager.localized("parental_children_empty")
                    return
                }
                
                guard let resolvedId = resolveSelectedChildID() else {
                    self.statsErrorMessage = localizationManager.localized("parental_children_empty")
                    return
                }
                loadParentalControlData(for: resolvedId)
            case .failure(let error):
                // Если ошибка API, но есть локальные данные - используем их
                if !self.childMembers.isEmpty {
                    print("⚠️ Ошибка загрузки из API, используем локальные данные")
                    self.childrenErrorMessage = nil
                } else {
                    let networkError = NetworkError.from(error)
                    if case .unauthorized = networkError {
                        self.children = []
                        self.childrenErrorMessage = nil
                    } else {
                        let message = localizationManager.localized("parental_children_error_generic")
                        self.childrenErrorMessage = message
                        self.statsErrorMessage = message
                    }
                }
            }
        }
    }
}
```

## 📊 СВОДНАЯ ТАБЛИЦА ПРОБЛЕМ И РЕШЕНИЙ

| Проблема | Причина | Решение |
|----------|---------|---------|
| **Дети не отображаются после регистрации** | Загружаются только из API, а не из UserDefaults | Добавить загрузку из UserDefaults как fallback |
| **Токен отсутствует** | Пользователь не зарегистрировался или токен истек | Проверить процесс регистрации и обновления токена |
| **Роли не совпадают** | Разные форматы ролей в UserDefaults и API | Преобразовать роли при загрузке |
| **Дети не синхронизированы с сервером** | Регистрация не завершена на сервере | Использовать локальные данные до синхронизации |
