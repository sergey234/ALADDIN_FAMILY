## 📝 ВАЖНЫЕ ДЕТАЛИ

1. **Функция `sync2FAStatusToServer()` (строки 686-701):**
   - Вызывается автоматически при изменении тумблера через Binding setter
   - Синхронизирует статус 2FA с сервером через APIService
   - При ошибке откатывает изменение и показывает ошибку
   - TODO: Требуется реализация метода `apiService.update2FAStatus(enabled:)`

2. **Функция `load2FAStatusFromServer()` (строки 675-685):**
   - Вызывается при открытии модального окна (`.onAppear`)
   - Загружает текущий статус 2FA с сервера
   - Обновляет значение `isEnabled` из ответа сервера
   - TODO: Требуется реализация метода `apiService.get2FAStatus()`

3. **Binding с автоматической синхронизацией:**
   - Используется Binding с get/set, который вызывает `sync2FAStatusToServer()` при изменении
   - Это обеспечивает автоматическую синхронизацию при каждом изменении тумблера

4. **Обработка ошибок:**
   - При ошибке синхронизации показывается ошибка через `toastManager.showError()`
   - Значение откатывается к предыдущему состоянию (`isEnabled = !enabled`)
