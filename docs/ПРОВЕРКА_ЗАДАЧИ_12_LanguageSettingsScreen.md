## 📝 ВАЖНЫЕ ДЕТАЛИ

1. **Функциональность тумблера:**
   - При включении (`isSystemLanguage = true`) автоматически применяется язык системы
   - При выборе языка вручную тумблер отключается (`isSystemLanguage = false`)
   - Состояние сохраняется между сессиями через @AppStorage

2. **Интеграция с LocalizationManager:**
   - При включении тумблера определяется язык системы через `Locale.current.languageCode`
   - Применяется язык через `applyLanguage(resolvedLanguage)`
   - Язык синхронизируется с `LocalizationManager`

3. **UI логика:**
   - Тумблер отображается в секции "Автоматический выбор языка"
   - При включенном тумблере галочка не показывается у языков в списке
   - При выключенном тумблере показывается галочка у выбранного языка
