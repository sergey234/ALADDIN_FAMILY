## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### **Алгоритм обнаружения:**

1. **Вычисление G-силы:**
   ```python
   magnitude = √(x² + y² + z²)
   g_force = magnitude / 9.8  # 1G = 9.8 м/с²
   ```

2. **Проверка порога:**
   - Порог по умолчанию: 3.0G
   - Настраивается через конфигурацию

3. **Фильтр ложных срабатываний:**
   - Анализ буфера (последние 3 измерения)
   - Проверка резкого изменения G-силы (>1.0G)
   - Проверка гироскопа (угловая скорость >5 рад/с)

4. **Определение серьезности:**
   - LOW: 3.0-4.0G
   - MEDIUM: 4.0-5.0G
   - HIGH: 5.0-8.0G
   - CRITICAL: >8.0G

---

### **Вычисление скорости из акселерометра:**

```python
# Горизонтальное ускорение (убираем гравитацию)
horizontal_accel = √(x² + y²)

# Интеграция: v = v₀ + a * dt
dt = 0.1  # 0.1 сек (100 Гц)
current_velocity = last_velocity + horizontal_accel * dt

# Конвертация м/с → км/ч
speed_kmh = current_velocity * 3.6
```

**Примечание:** Накопление ошибки со временем, но работает без GPS.
