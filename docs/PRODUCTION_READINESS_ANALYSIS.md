**🔍 Что это такое простыми словами:**

Code Signing (подпись кода) — это как "печать" на вашем приложении. Apple ставит цифровую подпись, которая подтверждает:
- ✅ Приложение создано вами (не подделка)
- ✅ Код не был изменен злоумышленниками
- ✅ Приложение безопасно для пользователей

Представьте, что вы отправляете посылку. Code Signing — это как пломба на посылке. Если пломба цела, значит содержимое не вскрывали и не подменили.

Archive (архив) — это упаковка вашего приложения в специальный формат для App Store. Это как упаковать товар в коробку перед отправкой в магазин.

Upload (загрузка) — это отправка упакованного приложения на серверы Apple. После этого Apple сможет проверить ваше приложение и опубликовать его в App Store.
