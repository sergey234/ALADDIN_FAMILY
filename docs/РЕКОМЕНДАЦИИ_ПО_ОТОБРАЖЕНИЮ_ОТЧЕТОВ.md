## 🎨 ДИЗАЙН КАРТОЧЕК В АНАЛИТИКЕ

### Компонент карточки:

```swift
struct ComponentReportCard: View {
    let componentId: String
    let icon: String
    let title: String
    let metrics: [String: String]  // ["Метрика 1": "Значение 1", "Метрика 2": "Значение 2"]
    let onTap: () -> Void
    
    var body: some View {
        Button(action: onTap) {
            HStack(spacing: Spacing.m) {
                // Иконка
                Text(icon)
                    .font(.system(size: 32))
                
                // Информация
                VStack(alignment: .leading, spacing: Spacing.xs) {
                    Text(title)
                        .font(.bodyBold)
                        .foregroundColor(.textPrimary)
                    
                    // Метрики
                    ForEach(Array(metrics.prefix(2)), id: \.key) { key, value in
                        HStack {
                            Text(key)
                                .font(.caption)
                                .foregroundColor(.textSecondary)
                            Text(value)
                                .font(.captionBold)
                                .foregroundColor(.textPrimary)
                        }
                    }
                }
                
                Spacer()
                
                // Стрелка
                Image(systemName: "chevron.right")
                    .foregroundColor(.textSecondary)
            }
            .padding(Spacing.m)
            .background(cardBackground)
            .cornerRadius(CornerRadius.medium)
        }
    }
}
```

## 📱 НАВИГАЦИЯ

### Из Аналитики:
1. Пользователь открывает **Аналитика**
2. Прокручивает вниз до раздела **"Компоненты защиты"**
3. Видит карточки всех компонентов
4. Нажимает на карточку → открывается детальный экран

### Из Настроек:
1. Пользователь открывает **Настройки** → **Расширенные настройки**
2. Находит нужный компонент
3. Нажимает на карточку компонента
4. В модальном окне есть кнопка **"Просмотреть отчеты"** → открывается детальный экран

### Из Уведомлений:
1. Пользователь получает уведомление от компонента
2. Нажимает на уведомление
3. Переходит на детальный экран компонента
