
#### Логика взаимодействия:

1. **Определение семьи:**
   - Backend определяет `familyId` из токена авторизации
   - Или передается явно в запросе (если токен не содержит familyId)

2. **Отправка сообщения:**
   - Пользователь вводит текст
   - Нажимает "Отправить"
   - Отправляется POST запрос с `message` и `familyId`
   - Backend сохраняет сообщение в БД с `family_id`, `sender_id`, `timestamp`
   - Backend определяет `isCurrentUser` сравнивая `sender_id` с `current_user_id` из токена

3. **Получение сообщений:**
   - GET запрос к `/family/chat/messages`
   - Backend возвращает все сообщения для данной семьи
   - Backend помечает `isCurrentUser: true` для сообщений текущего пользователя
   - Frontend отображает сообщения с правильным выравниванием

4. **Синхронизация:**
   - **Вариант 1:** Polling (периодические запросы каждые 5-10 секунд)
   - **Вариант 2:** WebSocket (real-time обновления)
   - **Вариант 3:** Push-уведомления (при новом сообщении)

5. **Количество участников онлайн:**
   - Backend должен возвращать количество активных участников
   - Или отдельный endpoint `/family/chat/online`
   - Или в ответе `getFamilyChatMessages` добавить поле `onlineCount`

### 6️⃣ ЧТО НУЖНО ИСПРАВИТЬ

#### 🔧 ЗАДАЧА 1: Определение familyId
**Проблема:** `familyId` передается как `nil`

**Решение:**
1. ✅ Получить `familyId` из UserDefaults с ключом `"family_id"` (используется в `FamilyScreen.swift`)
2. Если нет - backend должен определить из токена авторизации

**Код:**
```swift
private func getFamilyId() -> String? {
    // Получаем из UserDefaults (ключ используется в FamilyScreen)
    return UserDefaults.standard.string(forKey: "family_id")
}
```

**Примечание:** `family_id` сохраняется при создании/присоединении к семье через `CreateFamilyResponse` или `JoinFamilyResponse`.

#### 🔧 ЗАДАЧА 2: Количество участников онлайн
**Проблема:** Hardcoded значение "4"

**Решение:**
1. ✅ Получить количество из `family_members_list` (используется в других экранах)
2. Или добавить отдельный API endpoint `/family/chat/online`
3. Или добавить поле `onlineCount` в ответ `getFamilyChatMessages`

**Код:**
```swift
private func getOnlineMembersCount() -> Int {
    guard let savedData = UserDefaults.standard.data(forKey: "family_members_list"),
          let members = try? JSONDecoder().decode([FamilyMemberData].self, from: savedData) else {
        return 0
    }
    return members.count
}
```

**Примечание:** В реальности количество "онлайн" должно определяться на backend, но для MVP можно использовать общее количество участников семьи.

#### 🔧 ЗАДАЧА 3: Автообновление сообщений
**Проблема:** Нет автоматического обновления

**Решение:**
1. Добавить Timer для polling каждые 5-10 секунд
2. Или реализовать WebSocket соединение
3. Или использовать NotificationCenter для обновления при возврате на экран

**Код:**

```swift
@State private var refreshTimer: Timer?

private func startAutoRefresh() {
```
