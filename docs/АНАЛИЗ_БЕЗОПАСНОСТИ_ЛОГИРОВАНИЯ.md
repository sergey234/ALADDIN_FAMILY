## ⚠️ ПОТЕНЦИАЛЬНЫЕ РИСКИ

### **1. Endpoint может содержать токены**

**Проблема:**
Если endpoint содержит токен в URL (например: `/api/users?token=abc123`), он будет залогирован.

**Решение:**
✅ **УЖЕ РЕАЛИЗОВАНО** - мы используем только пути без параметров:
```swift
// ✅ ПРАВИЛЬНО - только путь
userInfo["endpoint"] = "/api/users"  // Без query параметров

// ❌ НЕ ДЕЛАЕМ - не логируем полный URL с параметрами
```

**Статус:** ✅ **ЗАЩИЩЕНО**

---

### **2. Ошибки могут содержать чувствительные данные**

**Проблема:**
Если ошибка содержит чувствительные данные в `localizedDescription`, они могут быть залогированы.

**Решение:**
✅ **УЖЕ РЕАЛИЗОВАНО** - мы логируем только тип ошибки и контекст, не полное сообщение:
```swift
// ✅ ПРАВИЛЬНО - только тип и контекст
CrashReportingManager.shared.recordNetworkError(
    error,
    endpoint: "/api/users",
    method: "GET"
)

// ❌ НЕ ДЕЛАЕМ - не логируем error.localizedDescription напрямую
```

**Статус:** ✅ **ЗАЩИЩЕНО**

---

### **3. User ID может быть email**

**Проблема:**
Если User ID является email адресом, он будет залогирован в Analytics и Crashlytics.

**Решение:**
⚠️ **РЕКОМЕНДАЦИЯ** - использовать только хешированные ID или UUID:
```swift
// ✅ ПРАВИЛЬНО - используем UUID или хеш
AnalyticsManager.shared.setUserID("user-uuid-12345")

// ❌ НЕПРАВИЛЬНО - не используем email
// AnalyticsManager.shared.setUserID("user@example.com")
```

**Статус:** ⚠️ **ТРЕБУЕТ ПРОВЕРКИ** - нужно убедиться, что User ID не является email

private func sanitizeEndpoint(_ endpoint: String) -> String {
    // Удаляем query параметры, которые могут содержать токены
