## 📋 ОБЩАЯ ИНФОРМАЦИЯ

### Что такое Identity Theft Protection?

**Identity Theft Protection** (Защита от кражи личности) - это сервис, который помогает защитить ваши персональные данные от мошенников путем:

- Мониторинга СНИЛС на подозрительную активность
- Мониторинга кредитных отчетов через НБКИ и ОКБ
- Проверки данных в базе мошенников (147,000+ записей)
- Обнаружения признаков кражи личности
- Предоставления инструкций по защите (кредитный замок и др.)

### Какие данные мы обрабатываем?

Для работы сервиса нам необходимы следующие персональные данные:

1. **СНИЛС (Страховой номер индивидуального лицевого счета)**
   - Требуется: для мониторинга подозрительной активности
   - Обработка: только с вашего согласия
   - Хранение: только SHA-256 хеш (не исходный номер)

2. **Паспортные данные (серия и номер паспорта)**
   - Требуется: для проверки в базе мошенников
   - Обработка: только с вашего согласия
   - Хранение: только SHA-256 хеш (не исходные данные)

3. **Информация о кредитной истории**
   - Требуется: для мониторинга подозрительных изменений
   - Обработка: только с вашего согласия
   - Источник: НБКИ, ОКБ (через их API при наличии партнерства)

4. **ID пользователя**
   - Требуется: для связи данных с вашим аккаунтом
   - Хранение: в зашифрованном виде

## ✅ СОГЛАСИЕ НА ОБРАБОТКУ ДАННЫХ (152-ФЗ)

### Как работает согласие?

Перед началом использования сервиса Identity Theft Protection вы должны предоставить **явное согласие** на обработку персональных данных.

### Типы согласий:

1. **Согласие на обработку СНИЛС**
   - Разрешает мониторинг СНИЛС
   - Срок действия: до 10 лет (или до отзыва)
   - Можно отозвать в любой момент

2. **Согласие на обработку паспортных данных**
   - Разрешает проверку в базе мошенников
   - Срок действия: до 10 лет (или до отзыва)
   - Можно отозвать в любой момент

3. **Согласие на доступ к кредитной истории**
   - Разрешает мониторинг кредитных отчетов
   - Срок действия: до 10 лет (или до отзыва)
   - Можно отозвать в любой момент

### Как предоставить согласие?

**Через мобильное приложение iOS:**
1. Откройте раздел "Identity Theft Protection"
2. Нажмите "Начать мониторинг"
3. Ознакомьтесь с условиями обработки данных
4. Выберите типы данных для мониторинга
5. Нажмите "Принять и начать мониторинг"

**Через API:**
```json
POST /api/identity-theft/consent
{
  "user_id": "ваш_user_id",
  "consent_types": {
    "snils": true,
    "passport": true,
    "credit": true
  },
  "duration_days": 365
}
```

### Как отозвать согласие?

**Через мобильное приложение iOS:**
1. Откройте настройки Identity Theft Protection
2. Нажмите "Управление согласием"
3. Нажмите "Отозвать согласие"
4. Подтвердите отзыв

**Через API:**
```json
POST /api/identity-theft/revoke-consent
{
  "user_id": "ваш_user_id"
}
```

**⚠️ ВАЖНО:** При отзыве согласия все ваши персональные данные автоматически удаляются в течение 24 часов.

## 🔐 МЕРЫ БЕЗОПАСНОСТИ

### Хеширование данных (SHA-256)

**Мы НЕ храним исходные данные!**

Все персональные данные (СНИЛС, паспорт) **хешируются** с использованием алгоритма SHA-256 перед хранением.

**Что это значит?**
- Исходный СНИЛС: `123-456-789 01`
- Хранится только хеш: `a3f5e8b9c2d1...` (64 символа)
- Хеш невозможно обратить обратно в исходный номер
- Даже если хеш попадет к злоумышленникам, они не смогут восстановить ваш СНИЛС

**Пример:**
```
Исходный СНИЛС: 12345678901
↓ (SHA-256 хеширование)
Хранимый хеш: 7f3a8b9c2d1e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6d7e8f9
```

### Минимизация данных

Мы обрабатываем только **минимально необходимые** данные:

- ✅ Храним только хеши (не исходные данные)
- ✅ Храним только необходимые метаданные (даты проверок, результаты)
- ✅ Не передаем данные третьим лицам без вашего согласия
- ✅ Удаляем данные при отзыве согласия

### Логирование операций

Все операции с персональными данными **логируются** с метками `[152-ФЗ]`:

- Время начала обработки
- Тип обрабатываемых данных
- Результат обработки
- Отказы в доступе
- Удаление данных

**Пример лога:**
```
2025-12-10 14:30:25 [152-ФЗ] Начало обработки СНИЛС: пользователь user_123
2025-12-10 14:30:26 [152-ФЗ] Доступ разрешен: пользователь user_123, тип данных snils
2025-12-10 14:30:27 [152-ФЗ] Обработка СНИЛС завершена: пользователь user_123, риск 0.25
```

## 📊 КАК ИСПОЛЬЗУЮТСЯ ДАННЫЕ

### 1. Мониторинг СНИЛС

**Цель:** Обнаружение подозрительной активности

**Как это работает:**
1. Вы предоставляете СНИЛС
2. СНИЛС хешируется (SHA-256)
3. Хеш проверяется в базе мошенников
4. Хеш проверяется на подозрительную активность (через ПФР/Госуслуги при наличии API)
5. Результат сохраняется (только хеш и метаданные)

**Что хранится:**
- Хеш СНИЛС
- Дата последней проверки
- Количество совпадений в базе мошенников
- Оценка риска
- Алерты (если обнаружены проблемы)

**Что НЕ хранится:**
- ❌ Исходный номер СНИЛС

### 2. Мониторинг кредитного отчета

**Цель:** Обнаружение подозрительных изменений в кредитной истории

**Как это работает:**
1. Вы предоставляете согласие на доступ к кредитной истории
2. Система запрашивает отчеты через НБКИ и ОКБ (при наличии API)
3. Анализируются изменения (новые кредиты, запросы, просрочки)
4. Генерируются алерты при обнаружении подозрительной активности

**Что хранится:**
- Хеш СНИЛС (для связи)
- Кредитный скоринг (если доступен)
- Количество кредитов
- Количество запросов
- Подозрительные изменения
- Даты проверок

**Что НЕ хранится:**
- ❌ Исходный СНИЛС
- ❌ Детали кредитных договоров (номера, суммы)
- ❌ Персональные данные третьих лиц

### 3. Проверка в базе мошенников

**Цель:** Обнаружение совпадений в базе данных мошенников

**Как это работает:**
1. Ваши данные (СНИЛС или паспорт) хешируются
2. Хеш проверяется в базе из 147,000+ записей
3. Используется индексированный поиск (O(1) сложность)
4. При совпадении генерируется алерт

**База мошенников:**
- Источник: агрегированные данные из открытых источников
- Обновление: периодически
- Содержит: хеши СНИЛС и паспортов мошенников

## 🗑️ УДАЛЕНИЕ ДАННЫХ

### Когда данные удаляются?

1. **При отзыве согласия:**
   - Все данные удаляются автоматически в течение 24 часов
   - Удаляется из всех систем: мониторинг, отчеты, кэш

2. **При истечении срока согласия:**
   - Если согласие не продлено, данные удаляются автоматически

3. **По запросу пользователя:**
   - Вы можете запросить удаление всех данных в любой момент

### Что удаляется?

При отзыве согласия удаляются:

- ✅ Согласия (`user_consents`)
- ✅ Активный мониторинг (`active_monitoring`)
- ✅ Кредитные отчеты (`credit_reports`)
- ✅ Кэшированные результаты (`cache`)

### Как проверить удаление?

После отзыва согласия вы получите подтверждение:

```json
{
  "success": true,
  "message": "Согласие отозвано, все персональные данные удалены",
  "user_id": "ваш_user_id",
  "deleted_items": [
    "согласия",
    "активный мониторинг",
    "кредитные отчеты",
    "кэш (5 записей)"
  ],
  "deleted_at": "2025-12-10T15:30:00"
}
```
