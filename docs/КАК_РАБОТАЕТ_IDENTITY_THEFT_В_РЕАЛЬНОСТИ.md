### ШАГ 5: Обработка на Backend (наш агент)

**Что делает `RussianIdentityTheftProtectionAgent.monitor_snils()`:**

#### 5.1 Проверка согласия (152-ФЗ)
```python
if not self._check_consent(user_id, "snils"):
    return {"error": "user_consent_required"}
```
✅ Согласие есть → продолжаем

#### 5.2 Валидация СНИЛС
```python
if not self._validate_snils(snils):
    return {"error": "invalid_snils"}
```
✅ Формат правильный (11 цифр) → продолжаем

#### 5.3 Хеширование СНИЛС
```python
snils_hash = self._hash_snils(snils)
# "123-456-789 01" → "a3f5b2c9d8e7f6a5b4c3d2e1f0a9b8c7..."
```
**Важно:** Реальный СНИЛС НЕ сохраняется, только хеш!

#### 5.4 Проверка в базе мошенников

**Что происходит:**
```python
# 1. Проверка кэша (быстро)
cache_key = f"fraud_snils_{snils_hash}"
if cached_result exists:
    return cached_result  # Мгновенно!

# 2. Поиск по индексу (быстро)
matches = self.fraud_index_snils.get(snils_hash, [])
# O(1) поиск - мгновенно!
```

**Примеры результатов:**

**Случай А: СНИЛС НЕ найден в базе мошенников**
```python
matches = []  # Пустой список
risk_score = 0.0  # Риск = 0%
```

**Случай Б: СНИЛС НАЙДЕН в базе мошенников!** ⚠️
```python
matches = [
    FraudRecord(
        id="fraud_123",
        snils_hash="a3f5b2c9...",
        fraud_type="identity_theft",
        detected_at="2024-11-15",
        description="Использован для получения кредита"
    )
]
risk_score = 0.8  # Риск = 80% (высокий!)
```

#### 5.5 Расчет риска
```python
risk_score = self._calculate_snils_risk(fraud_matches, suspicious_activity)

# Если найден в базе:
if fraud_matches:
    risk_score = 0.8  # 80% риск

# Определение уровня серьезности:
if risk_score >= 0.8:
    severity = "critical"  # Критический
elif risk_score >= 0.6:
    severity = "high"      # Высокий
```

#### 5.6 Сохранение результата
```python
self.active_monitoring[user_id] = {
    "snils_hash": snils_hash,
    "last_check": "2025-12-09T10:30:15",
    "snils_risk_score": risk_score
}
```

## 📱 СЦЕНАРИЙ 2: АВТОМАТИЧЕСКИЙ МОНИТОРИНГ

### Что это?

После первой проверки система может автоматически проверять СНИЛС пользователя периодически (например, каждые 24 часа).

### Как это работает:

1. **Пользователь включил мониторинг:**
   - В приложении переключатель "Автоматический мониторинг" = ВКЛ
   - Система сохраняет: проверять каждые 24 часа

2. **Каждые 24 часа:**
   - Система автоматически вызывает `monitor_snils()`
   - Проверяет СНИЛС в базе мошенников
   - Если что-то изменилось → отправляет уведомление

3. **Если обнаружена проблема:**
   - Push-уведомление: "⚠️ Обнаружена подозрительная активность!"
   - Открывается приложение → показывается алерт
   - Пользователь видит детали проблемы
