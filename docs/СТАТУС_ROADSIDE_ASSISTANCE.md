## 🎯 РЕЖИМ РАБОТЫ: MANUAL (по умолчанию)

### ✅ Что работает СЕЙЧАС:

1. **Создание запросов на помощь:**
   - Пользователь выбирает тип проблемы
   - Приложение определяет местоположение (GPS)
   - Запрос сохраняется в системе
   - Генерируется уникальный ID

2. **Отслеживание статуса:**
   - Пользователь видит информацию о запросе
   - Статус можно обновлять вручную
   - История запросов доступна

3. **Отмена запросов:**
   - Пользователь может отменить запрос
   - Статус обновляется на "cancelled"

4. **Все типы проблем поддерживаются:**
   - Буксировка (towing)
   - Запуск двигателя (jump_start)
   - Замена колеса (tire_change)
   - Открытие замка (lockout)
   - Доставка топлива (fuel_delivery)
   - Замена аккумулятора (battery_replacement)
   - Ремонт лобового стекла (windshield_repair)
   - Другое (other)

### ⚠️ Что будет работать ПОСЛЕ партнерства:

1. **Автоматическая отправка запросов партнерам**
2. **Автоматическое назначение служб помощи**
3. **Отслеживание прибытия помощи в реальном времени**
4. **Уведомления о статусе**
