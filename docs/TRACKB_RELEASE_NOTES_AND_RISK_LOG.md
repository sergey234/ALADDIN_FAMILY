# Track B Release Notes + Risk Log Standard

Scope:

- mandatory phase-close artifact before release merge.

## Required sections per phase

1. **Release notes**
   - user-visible changes
   - technical changes
   - migration/compatibility notes

2. **Known limitations**
   - open constraints
   - deferred items with owner
   - temporary workarounds

3. **Risk log update**
   - top risks
   - impact/likelihood
   - mitigation owner
   - target resolution window

## Phase-close checklist

- section completeness validated by smoke;
- artifact linked in PR description;
- plan-fact dashboard updated after sign-off.
