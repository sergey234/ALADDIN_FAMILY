## 🎯 КАК ЭТО БУДЕТ РАБОТАТЬ В iOS

### Процесс:

1. **Пользователь видит проблему:**
   - Данные найдены в базе мошенников
   - Показывается алерт с высокой оценкой риска

2. **Пользователь видит рекомендацию:**
   - "Заморозьте кредитную историю в НБКИ и ОКБ"
   - Кнопка "Как заморозить?"

3. **Открывается экран инструкций:**
   - Объяснение как работает заморозка
   - Пошаговые инструкции для НБКИ
   - Пошаговые инструкции для ОКБ
   - Ссылки на сайты
   - Возможность открыть сайты из приложения

4. **Пользователь действует:**
   - Открывает сайт НБКИ из приложения
   - Идет в НБКИ лично (с паспортом)
   - Подает заявление на заморозку
   - То же самое для ОКБ

5. **Кредитная история замораживается:**
   - Бюро устанавливает флаг "заморожено"
   - Банки не могут получить доступ
   - Мошенники не могут взять кредит
