# 🔍 Диагностика проблемы с профилем

## Проблема

Профиль не может быть декодирован через `security cms`:
```
security: failed to add data to decoder: UNKNOWN (-8183)
security: problem decoding
```

## Что работает ✅

1. ✅ Профиль декодирован из base64 (3194 байт)
2. ✅ Тип файла правильный: `data` (PKCS#7 формат)
3. ✅ Первые байты правильные: `3082 0c76` (PKCS#7 заголовок)

## Что НЕ работает ❌

1. ❌ `security cms` не может декодировать профиль
2. ❌ UUID не может быть извлечен
3. ❌ Xcode не может загрузить профиль: "Profile is missing the required UUID property"

## Причины

Ошибка `UNKNOWN (-8183)` обычно означает:
- Профиль поврежден при сохранении в секрет
- Профиль неправильно закодирован в base64
- Профиль не является валидным `.mobileprovision` файлом
- Профиль может быть старым или истекшим

## Решение

### Шаг 1: Проверить профиль локально

1. Скачайте профиль из Apple Developer Portal:
   - https://developer.apple.com/account/resources/profiles/list
   - Найдите профиль для `family.aladdin.ios`
   - Скачайте `.mobileprovision` файл

2. Проверьте профиль локально:
```bash
# Проверить что профиль валидный
security cms -D -i ~/Downloads/your_profile.mobileprovision

# Если работает - извлечь UUID
security cms -D -i ~/Downloads/your_profile.mobileprovision | plutil -extract UUID raw -o - -
```

### Шаг 2: Правильно закодировать в base64

```bash
# Закодировать профиль в base64 (БЕЗ переносов строк!)
base64 -i ~/Downloads/your_profile.mobileprovision | tr -d '\n' > profile_base64.txt

# Или одной командой:
cat ~/Downloads/your_profile.mobileprovision | base64 | tr -d '\n'
```

**ВАЖНО:** 
- Не добавляйте переносы строк в base64
- Не добавляйте пробелы
- Используйте `tr -d '\n'` чтобы убрать все переносы

### Шаг 3: Обновить секрет в GitHub

1. Откройте: https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions
2. Найдите секрет `PROVISIONING_PROFILE_APP`
3. Удалите старый секрет
4. Создайте новый секрет с правильным base64 (из шага 2)
5. Сохраните

### Шаг 4: Проверить extension профиль

То же самое для `PROVISIONING_PROFILE_EXTENSION`:
- Скачайте профиль для `family.aladdin.ios.packetTunnel`
- Закодируйте в base64
- Обновите секрет

## Проверка после обновления

После обновления секретов, запустите workflow и проверьте:
1. ✅ `security cms` успешно декодирует профиль
2. ✅ UUID извлекается
3. ✅ Профиль переименовывается в `UUID.mobileprovision`
4. ✅ Xcode находит профиль

## Альтернативное решение

Если профили все еще не работают, можно попробовать:
1. Удалить старые профили в Apple Developer Portal
2. Создать новые профили заново
3. Скачать и закодировать заново
