## 5) Recommendations (engineering)

1. **Do not put 275 experiences on one scroll:** keep `ChildContentScreen` as category hub + optional compact journey cards; each item opens `ChildContentExperienceScreen` (navigation stack).
2. **Content scale:** grow `ContentSeedProvider` / server manifest; avoid loading all payloads at once — use existing `ContentManager` + pagination patterns.
3. **Heavy modules (SceneKit, PencilKit):** one active experience at a time; release resources on dismiss; profile with Instruments if adding many 3D scenes.
4. **Matrix maintenance:** when product adds a new theme, add a row here — the matrix is a living registry, not a frozen law.
