### **ШАГ 1.6: Проверить все созданные таблицы**

```bash
psql -U postgres -d aladdin_db << EOF
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'public' 
AND table_name IN (
    'crash_detection_alerts',
    'roadside_assistance_requests',
    'parental_control_stats',
    'parental_bypass_stats',
    'analytics_metrics'
)
ORDER BY table_name;
EOF
```

**Ожидаемый результат:** 5 таблиц

### **Проблема 2: Ошибка "relation already exists"**

**Решение:**
```bash
# Проверить существующие таблицы
psql -U postgres -d aladdin_db -c "\dt"

# Если таблица уже существует, можно:
# 1. Пропустить миграцию (если структура совпадает)
# 2. Удалить таблицу и применить заново (ОСТОРОЖНО!)
# 3. Использовать CREATE TABLE IF NOT EXISTS (уже в миграциях)
```

---
