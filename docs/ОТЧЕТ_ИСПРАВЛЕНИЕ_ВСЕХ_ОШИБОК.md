## 📋 ДЕТАЛЬНЫЕ ИЗМЕНЕНИЯ

### 1. Добавлен `@MainActor` для доступа к `ComponentStatusService`

**Причина:** 
- `ComponentStatusService` помечен как `@MainActor`
- Доступ к его свойствам должен быть на главном потоке
- Используем `Task { @MainActor in }` для обеспечения правильного контекста

### 2. Получение реального статуса компонента

**Причина:**
- `isEnabled: true` - это хардкод, не отражает реальное состояние компонента
- Реальный статус хранится в `ComponentStatusService.componentStatuses[componentId]`
- Если статус не найден, используем `true` как значение по умолчанию

### 3. Упрощение обработки ошибок в `APIService`

**Было:**
```swift
if let urlError = error as? URLError {
    continuation.resume(throwing: error)
} else if let networkError = error as? NetworkError,
          case .invalidStatusCode(let code) = networkError,
          code == 405 {
    // ...
}
```

**Стало:**
```swift
if let networkError = error as? NetworkError,
   case .invalidStatusCode(let code) = networkError,
   code == 405 {
    // ...
} else {
    continuation.resume(throwing: error)
}
```
