## 📊 ВСЕ 12 ФУНКЦИЙ DARK WEB MONITORING

### 1. `check_email_breach`
**Описание:** Комплексная проверка email на утечки через все источники (HIBP, BreachDirectory, российские базы)  
**Параметры:** `email`, `include_hibp`, `include_breachdirectory`, `include_russian`  
**Возвращает:** Результат проверки с количеством утечек и списком breaches

### 2. `check_email_breach_hibp`
**Описание:** Проверка email через Have I Been Pwned API с k-анонимностью  
**Параметры:** `email`  
**Возвращает:** Список найденных утечек

### 3. `check_email_breach_breachdirectory`
**Описание:** Проверка email через BreachDirectory API  
**Параметры:** `email`  
**Возвращает:** Список найденных утечек

### 4. `check_email_breach_russian`
**Описание:** Проверка email через российские базы утечек  
**Параметры:** `email`  
**Возвращает:** Список найденных утечек

### 5. `check_phone_breach`
**Описание:** Проверка номера телефона на утечки  
**Параметры:** `phone`  
**Возвращает:** Результат проверки

### 6. `monitor_user_data`
**Описание:** Мониторинг данных пользователя (email и/или телефон)  
**Параметры:** `user_id`, `email`, `phone`  
**Возвращает:** Результат проверки

### 7. `start_monitoring`
**Описание:** Запуск автоматического мониторинга данных пользователя  
**Параметры:** `user_id`, `email`, `phone`, `interval_hours`  
**Возвращает:** Результат запуска мониторинга

### 8. `stop_monitoring`
**Описание:** Остановка автоматического мониторинга  
**Параметры:** `user_id`  
**Возвращает:** Результат остановки

### 9. `get_monitoring_status`
**Описание:** Получение статуса мониторинга для пользователя или всех активных мониторингов  
**Параметры:** `user_id` (опционально, None = все мониторинги)  
**Возвращает:** Статус мониторинга

### 10. `collect_threats`
**Описание:** Сбор угроз (утечек данных) из всех активных мониторингов (ThreatMonitoringInterface)  
**Параметры:** нет  
**Возвращает:** Список угроз

### 11. `analyze_threats`
**Описание:** Анализ собранных угроз с рекомендациями (ThreatMonitoringInterface)  
**Параметры:** `threats`  
**Возвращает:** Список проанализированных угроз

### 12. `send_alert`
**Описание:** Отправка уведомления об утечке данных (ThreatMonitoringInterface)  
**Параметры:** `alert`  
**Возвращает:** True если уведомление отправлено успешно
