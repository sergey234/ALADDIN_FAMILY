## §3. A11y — одна строка на экран (спека для VoiceOver)

**Зачем:** VoiceOver должен за **один жест** понять смысл шага, не перечитывая декор.

**Правило:** одна **короткая** реплика на весь экран слайда (внешний контейнер карусели можно оставить «Страница X из Y»; ниже — **смысловая** строка для контента).

| `currentPage` | Экран | Рекомендуемая одна строка (RU, спека) | Сейчас в коде (`14_OnboardingScreen`) |
|---------------|--------|----------------------------------------|----------------------------------------|
| 0 | Язык | «Выбор языка приложения» | `Выбор языка приложения` ✓ |
| 1 | Семья | «Защита всей семьи в одном приложении» | `Страница онбординга: {title}` — ок, title из локализации |
| 2 | ИИ | «Персональный помощник по безопасности» | как выше |
| 3 | Родители | «Родительский контроль и спокойствие» | как выше |
| 4 | Радар | «Аналитика и раннее предупреждение угроз» | как выше |
| 5 | Дети | «Безопасность и обучение для детей» | как выше |
| 6 | 23+ | «Защита для взрослых: фейки и мошенники» | как выше |
| 7 | Приглашение | «Присоединиться к семейной защите» | как выше |
| Main | Главная | «Главный экран: семья, защита, тарифы» | _уточнить в `01_MainScreen` при Фазе C / a11y Main_ |

**Локализации:** для EN/DE/FR/AR в **Фазе C** завести ключи `onboarding_a11y_screen_*` и подставлять вместо жёсткого RU, если продукт требует; до этого RU-спека достаточно для внутреннего согласования.

| Проверка | Статус |
|----------|--------|
| Спека согласована с продуктом | ☐ |
| Решение по ключам локализации a11y | ☐ Не нужно / ☐ Нужны ключи (список в задаче) |
