#### 1.2 FamilyContentBlockModal - сохранение категорий
**Файл:** `Components/Modals/FamilyContentBlockModal.swift`  
**Строки:** 241-248

**Проблема:**
- Есть `loadSettings()` но нет `saveSettings()`
- `selectedCategories` не сохраняется

**Решение:**
```swift
private func saveSettings() {
    Task {
        do {
            let config = ComponentConfiguration(
                componentId: "content_blocker_manager",
                isEnabled: isEnabled,
                priority: .normal,
                additionalSettings: [
                    "selectedCategories": AnyCodable(selectedCategories.map { $0.rawValue })
                ]
            )
            
            try await ComponentConfigurationService.shared.saveConfiguration(
                componentId: "content_blocker_manager",
                configuration: config
            )
            
            await MainActor.run {
                HapticFeedback.notification(.success)
                isPresented = false
            }
        } catch {
            // Сохранить локально в UserDefaults
            if let encoded = try? JSONEncoder().encode(Array(selectedCategories)) {
                UserDefaults.standard.set(encoded, forKey: "content_blocker_selected_categories")
            }
            await MainActor.run {
                HapticFeedback.notification(.success)
                isPresented = false
            }
        }
    }
}
```

**Оценка:** 20 минут

### 1. Единый подход к сохранению

#### Для компонентов (42 компонента):

- ✅ Уже реализовано и работает
- ✅ Синхронизация с сервером
- ✅ Работает без интернета

#### Для простых настроек (Bool, String, Int):
✅ **Использовать:** `@AppStorage`
- ✅ Автоматическое сохранение
- ✅ Простота использования
- ✅ Пример: `FamilyTimeControlModal`, `GamesSettingsManager`

#### Для сложных структур (Set, Array, Dictionary):
✅ **Использовать:** `UserDefaults` с JSON encoding
- ✅ Или `ComponentConfigurationService` с `additionalSettings`
- ✅ Пример: `FamilyContentBlockModal`, `GeofencesSettingsModal`

**Пример:**
