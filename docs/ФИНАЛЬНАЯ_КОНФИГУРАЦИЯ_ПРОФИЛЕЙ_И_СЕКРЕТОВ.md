### ШАГ 1: Анализ проблемы

**Проблема:**
- Ошибка: `Provisioning profile "ALADDIN App Store Distribution" doesn't include signing certificate "Apple Distribution: SERGEY KHLYSTOV (***)"`
- Xcode проверяет сертификаты по fingerprint, а не по имени
- В профилях был встроен другой сертификат с таким же именем, но другим fingerprint

**Решение:**
- Обновить профили в Apple Developer Portal с правильным сертификатом
