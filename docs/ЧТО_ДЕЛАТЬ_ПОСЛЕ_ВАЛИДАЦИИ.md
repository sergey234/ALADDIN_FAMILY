## 📋 ПОШАГОВЫЙ ПЛАН

### Этап 1: Загрузить билд в App Store Connect (15-30 минут)

#### Вариант A: Через Xcode (РЕКОМЕНДУЕТСЯ)

1. **В окне валидации:**
   - Если есть кнопка **"Upload"** — нажмите её
   - Или закройте окно валидации

2. **В Organizer:**
   - Выберите ваш Archive
   - Нажмите **"Distribute App"**
   - Выберите **"App Store Connect"**
   - Нажмите **"Next"**
   - Выберите **"Upload"** (не Export!)
   - Выберите приложение **"ALADDIN X AI"**
   - Нажмите **"Next"**
   - Проверьте информацию
   - Нажмите **"Upload"**
   - Дождитесь загрузки (10-20 минут)

#### Вариант B: Через Transporter

1. **Экспортируйте билд:**
   - Organizer → Distribute App → Export
   - Сохраните .ipa файл

2. **Загрузите через Transporter:**
   - Откройте Transporter
   - Перетащите .ipa файл
   - Нажмите "Deliver"
