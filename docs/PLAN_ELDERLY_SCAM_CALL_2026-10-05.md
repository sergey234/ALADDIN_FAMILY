## 1. Зачем

Родственник должен узнать, что пожилому человеку только что могли звонить мошенники, и сразу перезвонить. Человек 60+ не будет загружать запись разговора.

МТС делает это как оператор: сеть видит звонок. Мы приложение. iOS не отдаёт номер входящего и не даёт слушать обычный звонок. Поэтому сигнал уходит **только после нажатия** «просили деньги или код».

Семью и роль «люди 60+» заново не строим.

---

## 2. Что уже есть — использовать, не писать с нуля

| Кусок | Где | Как использовать |
|-------|-----|------------------|
| Роль `elderly` | `ViewModels/FamilyRegistrationViewModel.swift` | Экран после звонка только для этой роли |
| Конец звонка, без номера | `Core/Security/AntifakeCallObserverService.swift` | Показать большой экран. Сейчас отсюда уходит мелкое «загрузите запись» |
| Подпись номера на экране вызова | `ALADDINCallDirectory/CallDirectoryHandler.swift` · `Shared/Components/AntifakeCallDirectorySettingsCard.swift` | Карточку включения перенести в интерфейс 60+. Сам список не изобретать |
| Push родителям после проверки антифейка | `app/services/antifake_family_notify.py` | **Не вызывать** для этой кнопки. Там вердикт `likely_fake` и пауза 15 минут |
| Проверка записи | Hub → вкладка «Звонок» | Маленькая ссылка. Не главный путь |
| SOS | `Screens/09_ElderlyInterfaceScreen.swift` | Не смешивать с кнопкой про мошенников. SOS — помощь, эта кнопка — «перезвоните» |

Наблюдатель звонка сегодня стартует только если антифейк-хаб доступен (`AntifakeAccessPolicy.isHubAvailable`). Для роли 60+ экран с двумя кнопками должен появляться и без хаба. Проверка записи по-прежнему открывает хаб или экран тарифа.

## 3. Чего не делать

- Не обещать «мы видим мошенника, пока он на линии».
- Не слушать звонок в фоне и не сбрасывать его автоматически.
- Не делать переадресацию всех звонков на наш сервер.
- Не делать Live Caller ID в этой работе. Задача `af-H-03` остаётся на паузе. Она подписывает номер на экране и **не** шлёт push родным.
- Не вешать эту кнопку на паузу 15 минут из `maybe_notify_parents_likely_fake`.
- Не писать родителям текст «вероятно подделка, 72%».
- Не коммитить бота в iOS-релиз. Не деплоить API на 🇷🇺 MAIN (`…180`) без фразы **GO ELD PUSH**.

## 5. Порядок

```text
1. Слой Б — экран на телефоне пожилого
2. Слой В — событие и push родителю
3. Тексты и честность Apple
4. Слой А — включение подписи номеров в интерфейсе 60+
5. Проверка на устройстве (владелец)
Live Caller ID — не в этом плане
```

Слой Б без слоя В бесполезен: кнопка есть, родным тишина. Делать их одним заходом. Слой А можно следом: он предупреждает самого человека, пока телефон звонит, и от пуша не зависит.

## 6. Слой Б — трубку положили

**Зачем.** Человек 60+ должен понять экран за секунду и нажать одну кнопку. Мелкое уведомление «загрузите запись» для этого не годится.

**Как.**

1. В `AntifakeCallObserverService` после `call.hasEnded` для роли `elderly` открывать полный экран, а не только `sendAntifakePostCallNotification`.
2. Наблюдатель для роли 60+ запускать даже если хаб антифейка закрыт тарифом. Иначе кнопки никогда не появятся.
3. Экран, крупный шрифт, как остальной интерфейс 60+ (`Screens/09_ElderlyInterfaceScreen.swift`):
   - заголовок вроде «Звонок закончился»;
   - кнопка «Просили деньги или код»;
   - кнопка «Всё спокойно»;
   - внизу мелко «Если есть запись» → существующий путь Hub «Звонок» или тариф, если хаба нет.
4. «Всё спокойно» закрывает экран. Сеть не трогать.
5. Для ролей parent / child этот новый экран не показывать. У них остаётся текущее напоминание про запись.

**Не делать.** Не читать номер из CallKit: его там нет. Не подставлять имя «мама» наугад, если в семье имя не задано — «близкий человек».

---

## 7. Слой В — телефон сына или дочери

**Зачем.** Родитель должен получить отдельный срочный сигнал и перезвонить, а не открывать отчёт антифейка.

**Как.**

1. Новый запрос с телефона пожилого, только по нажатию первой кнопки. Не создавать `antifake_jobs` и не звать `maybe_notify_parents_likely_fake`.
2. Сервер берёт родителей так же, как семейные пуши антифейка (`get_parent_user_ids` / токены), но своим текстом:
   - заголовок: «Подозрительный звонок»;
   - текст: «Близкий человек сообщил: просили деньги или код. Позвоните ему».
   - если в семье есть имя — подставить его.
3. В пуше действие «Позвонить», если номер пожилого есть в семье. Нет номера — открыть карточку семьи.
4. Своя короткая защита от случайных повторных нажатий (несколько секунд), не 15 минут.
5. Ошибка сети на телефоне пожилого: честный текст «не отправилось, нажмите ещё раз». Без молчаливого успеха.

Выкладка этого API на 🇷🇺 MAIN — FirstVDS / Аладдин · запас · Россия (`…180`) только после **GO ELD PUSH** и по `ALADDIN_SERVER_CONNECTION_GUIDE_FOR_ML_SYSTEMS.md`.

## 8. Слой А — пока телефон звонит

**Зачем.** Подпись «возможный мошенник?» на экране вызова видит сам человек, до того как снимет трубку. Родным в этот момент ничего не приходит. Так и задумано.

**Как.**

1. Поставить уже готовую `AntifakeCallDirectorySettingsCard` на экран 60+ коротким блоком: «Подписи опасных номеров» и кнопка включения в настройках iPhone.
2. Не копировать второе расширение Call Directory.
3. Список номеров по-прежнему синхронизируется тем же `GET /api/antifake/call-directory`. В этой задаче не писать новый сборщик номеров. Если синхронизация с экрана 60+ не вызывается — вызвать существующий sync.
4. Тексты: подпись на чужом номере, не «мы заблокировали мошенника в сети».

## 9. Тексты

Писать так, будто кнопку нажимает человек, а не сеть.

| Можно | Нельзя |
|-------|--------|
| «Если просили деньги или код — нажмите. Мы напишем семье» | «Мы определили мошенника» |
| «Подпись появится на экране звонка для номеров из списка» | «Все мошенники блокируются» |
| «Запись можно проверить отдельно, если она у вас есть» | «Мы прослушали разговор» |

Ключи класть в `Core/Localization/LocalizationManager.swift` (RU и EN).

## 10. Проверка

Локально, до слова «готово»:

- роль elderly, звонок завершён → полный экран;
- «всё спокойно» → нет запроса;
- «просили деньги» → один запрос, пуш родителю с нужным текстом;
- второе нажатие сразу → не пачка одинаковых пушей, но и не молчание на 15 минут;
- роль parent → старое напоминание про запись, без этого экрана;
- ссылка на запись не обходит тариф;
- карточка Call Directory видна на экране 60+.

На телефоне владельца (DEVICE): реальный звонок, крупный текст, пуш на второй телефон семьи.
