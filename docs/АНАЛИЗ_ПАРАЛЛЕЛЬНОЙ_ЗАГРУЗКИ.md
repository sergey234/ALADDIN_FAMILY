## 📋 ЧТО ТАКОЕ ПАРАЛЛЕЛЬНАЯ ЗАГРУЗКА ЧЕРЕЗ `withThrowingTaskGroup`?

### Простое объяснение:

**Последовательная загрузка (медленно):**
```
Загрузить компонент 1 → ждать → загрузить компонент 2 → ждать → загрузить компонент 3...
Время: 1 сек + 1 сек + 1 сек = 3 секунды (для 3 компонентов)
```

**Параллельная загрузка (быстро):**
```
Загрузить компонент 1 ┐
Загрузить компонент 2 ├─ одновременно → ждать → все готово
Загрузить компонент 3 ┘
Время: max(1 сек, 1 сек, 1 сек) = 1 секунда (для 3 компонентов)
```

### Техническое объяснение:

`withThrowingTaskGroup` - это механизм Swift для параллельного выполнения нескольких асинхронных задач одновременно.

**Как это работает:**
1. Создаем группу задач (`TaskGroup`)
2. Добавляем все задачи в группу (`group.addTask`)
3. Все задачи выполняются **одновременно** (параллельно)
4. Собираем результаты по мере их готовности (`for try await`)

```swift
// Время: ~13 секунд (если каждый запрос 1 сек)
```

**Стало (параллельно):**
```swift
try await withThrowingTaskGroup(of: (String, ComponentStatus).self) { group in
    for componentId in componentIds {
        group.addTask { [weak self] in
            guard let self = self else { throw ... }
            let status = try await self.statusService.getStatus(for: componentId)
            return (componentId, status)
        }
    }
    
    for try await (componentId, status) in group {
        // Статусы автоматически сохраняются в ComponentStatusService
    }
}
// Время: ~1 секунда (все запросы одновременно)
```

**Ускорение:** ~13 раз (для 13 компонентов)

## 📝 ШАБЛОН ДЛЯ ПАРАЛЛЕЛЬНОЙ ЗАГРУЗКИ

```swift
// ✅ ПРАВИЛЬНО: Параллельная загрузка
try await withThrowingTaskGroup(of: (String, ComponentStatus).self) { group in
    for componentId in componentIds {
        group.addTask { [weak self] in
            guard let self = self else {
                throw ComponentError.unknown(NSError(domain: "ViewModel", code: -1))
            }
            let status = try await self.statusService.getStatus(for: componentId)
            return (componentId, status)
        }
    }
    
    // Собираем результаты
    for try await (componentId, status) in group {
        // Обработка результата
        updateStatusForComponent(componentId: componentId, status: status)
    }
}

// ❌ НЕПРАВИЛЬНО: Последовательная загрузка
for componentId in componentIds {
    let status = try await statusService.getStatus(for: componentId)
    updateStatusForComponent(componentId: componentId, status: status)
}
```
