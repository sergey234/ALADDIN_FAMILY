## 📝 КАК ИЗМЕНИТЬ САЙТ НА СЕРВЕРЕ

### 1. Подключитесь к серверу:

```bash
ssh root@149.154.65.180
# Введите пароль при запросе
```

### 2. Найдите файлы сайта:

```bash
# Обычно файлы находятся в:
cd /var/www/html
# или
cd /var/www/aladdin-ai.ru
# или
cd /usr/share/nginx/html

# Проверьте структуру
ls -la
```

### 3. Создайте бэкап перед изменениями:

```bash
# Создать бэкап
tar -czf /root/backup_$(date +%Y%m%d_%H%M%S).tar.gz /var/www/html

# Или скопировать в отдельную папку
cp -r /var/www/html /root/backup_html_$(date +%Y%m%d)
```

### 4. Редактируйте файлы:

```bash
# Редактировать HTML файл
nano /var/www/html/index.html
# или
vi /var/www/html/index.html

# Или использовать любой другой редактор
```

### 5. Проверьте изменения:

```bash
# Проверить синтаксис (если есть)
nginx -t

# Перезагрузить веб-сервер (если нужно)
systemctl reload nginx
# или
systemctl reload apache2
```

## 🔄 ОБНОВЛЕНИЕ САЙТА ИЗ ЛОКАЛЬНОЙ КОПИИ

### Вариант 1: Через SCP (копирование файлов)

**На вашем локальном компьютере:**

```bash
# Скопировать файлы на сервер
scp -r /путь/к/локальным/файлам/* root@149.154.65.180:/var/www/html/

# Или конкретный файл
scp index.html root@149.154.65.180:/var/www/html/
```

### Вариант 2: Через Git (если сайт в репозитории)

**На сервере:**

```bash
cd /var/www/html
git pull origin main
# или
git pull origin master
```

### Вариант 3: Через rsync (синхронизация)

**На вашем локальном компьютере:**

```bash
rsync -avz --exclude='.git' /путь/к/локальным/файлам/ root@149.154.65.180:/var/www/html/
```

## 📋 ПОЛЕЗНЫЕ КОМАНДЫ НА СЕРВЕРЕ

### Проверка статуса:

```bash
# Статус веб-сервера
systemctl status nginx
# или
systemctl status apache2

# Проверить открытые порты
netstat -tulpn | grep :80
netstat -tulpn | grep :443
```

### Логи:

```bash
# Nginx логи доступа
tail -f /var/log/nginx/access.log

# Nginx логи ошибок
tail -f /var/log/nginx/error.log

# Системные логи
journalctl -u nginx -f
```

### Проверка конфигурации:

```bash
# Проверить конфигурацию Nginx
nginx -t

# Перезагрузить Nginx
systemctl reload nginx

# Перезапустить Nginx
systemctl restart nginx
```

### Поиск файлов:

```bash
# Найти все HTML файлы
find /var/www -name "*.html"

# Найти все PHP файлы
find /var/www -name "*.php"

# Найти файлы по содержимому
grep -r "ALADDIN" /var/www/html/
```

## 🔧 ИЗМЕНЕНИЕ КОНТЕНТА САЙТА

### Изменить текст на главной странице:

```bash
# Найти файл
find /var/www -name "index.html" -o -name "index.php"

# Редактировать
nano /var/www/html/index.html

# После изменений проверить
curl http://localhost
```

### Изменить конфигурацию Nginx:

```bash
# Редактировать конфигурацию
nano /etc/nginx/sites-available/default
# или
nano /etc/nginx/conf.d/aladdin-ai.ru.conf

# Проверить конфигурацию
nginx -t

# Применить изменения
systemctl reload nginx
```

### Обновить SSL сертификат:

```bash
# Если используется Let's Encrypt
certbot renew

# Проверить срок действия
openssl x509 -in /etc/letsencrypt/live/aladdin-ai.ru/cert.pem -noout -dates
```

## 🔒 БЕЗОПАСНОСТЬ

