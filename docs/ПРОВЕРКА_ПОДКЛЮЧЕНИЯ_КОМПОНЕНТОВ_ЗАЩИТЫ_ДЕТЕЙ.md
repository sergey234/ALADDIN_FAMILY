### 1. **Обнаружение самоповреждений** (`self_harm_detection_agent`)

**Что это простыми словами:**
- 🤖 **AI-робот**, который читает все сообщения, видео и тексты, которые видит ребенок
- 🔍 **Ищет опасные слова** и фразы о самоповреждении (например, "хочу навредить себе", "не хочу жить")
- 🚨 **Сообщает родителям**, если находит что-то опасное
- 💬 **Может помочь ребенку** - предложить поговорить с психологом или родителями

**Как работает:**
1. Ребенок отправляет сообщение или смотрит видео
2. AI-робот анализирует текст/видео
3. Если находит опасные признаки - отправляет уведомление родителям
4. Родители могут помочь ребенку

**Подключение к серверу:**
- ✅ Компонент зарегистрирован в `SafeFunctionManager` на сервере
- ✅ Обработчик `_setup_self_harm_detection_handler()` настроен
- ✅ Использует BERT модель для анализа текста
- ✅ API endpoint: `/api/components/status/self_harm_detection_agent`

4. Родители могут просмотреть подозрительные сообщения

**Подключение к серверу:**

### 1. Загрузка статусов:

**Код в мобильном приложении:**
```swift
// ViewModels/ParentalControlViewModel.swift
func loadComponentStatuses() async {
    let componentIds = [
        ("self_harm_detection_agent", .critical),
        ("grooming_detection_agent", .critical),
        ("online_predators_agent", .critical),
        ("parental_control_bot", .high),
        ("psychological_support_agent", .normal)
    ]
    
    // Загружаем статусы параллельно
    for (componentId, priority) in componentIds {
        let status = try await statusService.getStatus(for: componentId)
        updateStatusForComponent(componentId: componentId, status: status)
    }
}
```

**Что происходит:**
1. Приложение отправляет запрос на сервер: `GET /api/components/status/self_harm_detection_agent`
2. Сервер проверяет статус в базе данных
3. Возвращает `{ "component_id": "self_harm_detection_agent", "is_enabled": true/false }`
4. Приложение обновляет UI (включает/выключает тумблер)

## 📝 ПОДТВЕРЖДЕНИЕ ИСПРАВЛЕНИЯ ПРОБЛЕМЫ #1

### Проблема: "Не удалось загрузить список детей" показывается неправильно

**Исправление применено:**
- ✅ В `ParentalControlScreen.loadChildMembers()` добавлена проверка токена
- ✅ Если токена нет - не показываем ошибку (это нормально для неавторизованных)
- ✅ Если после фильтрации нет детей - показываем "Нет детей" вместо ошибки
- ✅ Для ошибки `unauthorized` не показываем ошибку загрузки детей

**Код исправления:**
```swift
// Screens/07_ParentalControlScreen.swift
private func loadChildMembers() {
    // ✅ ИСПРАВЛЕНИЕ: Проверяем токен перед загрузкой
    guard AppConfig.authToken != nil else {
        // Не показываем ошибку, если нет токена
        self.children = []
        self.childrenErrorMessage = nil
        return
    }
    
    apiService.getFamilyMembers { result in
        switch result {
        case .success(let members):
            // ✅ ИСПРАВЛЕНИЕ: Проверяем, есть ли дети после фильтрации
            if childMembers.isEmpty {
                // Если нет детей, не показываем ошибку - это нормальная ситуация
                self.childrenErrorMessage = nil
                self.statsErrorMessage = localizationManager.localized("parental_children_empty")
                return
            }
        case .failure(let error):
            // ✅ ИСПРАВЛЕНИЕ: Проверяем тип ошибки
            let networkError = NetworkError.from(error)
            if case .unauthorized = networkError {
                // Для ошибки авторизации не показываем ошибку загрузки детей
                self.children = []
                self.childrenErrorMessage = nil
            }
        }
    }
}
```
