## Yandex SpeechKit (облако)

Источник тарифов: [Yandex Cloud SpeechKit pricing](https://yandex.cloud/ru/docs/speechkit/pricing), PDF тарифов 2025–2026.

| API | Единица | Ориентир (с НДС) |
|-----|---------|------------------|
| **v1 синтез** | 1 млн символов | **~1 320 ₽** (~$14–15 по курсу) |
| **v3 стандарт** | 1 запрос | **~0,16 ₽** (короткая фраза = 1 request) |
| **v3 длинный текст** | 250 символов | биллинг блоками по 250 символов |

### Пример на 2M символов/мес (v1)

- 2 × 1,32 ₽ ≈ **2 640 ₽/мес** (~$28–30)

### Пример на 20k запросов/мес (v3, ~100 символов/ответ)

- 20 000 × 0,16 ₽ ≈ **3 200 ₽/мес**

## Рекомендация по этапам

1. **Сейчас:** пилот **ElevenLabs genie** (VOICE-PREM-03) — быстрее time-to-wow для Premium.
