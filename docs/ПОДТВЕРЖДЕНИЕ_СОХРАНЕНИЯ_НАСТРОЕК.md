## 🔍 АНАЛИЗ ТЕКУЩЕЙ АРХИТЕКТУРЫ

### ✅ ЧТО УЖЕ РАБОТАЕТ:

#### 1. ComponentCacheService
```swift
// Сохраняет в UserDefaults (персистентно)
func saveConfiguration(componentId: String, configuration: ComponentConfiguration) async {
    var configurations = await loadAllConfigurations()
    configurations[componentId] = configuration
    await saveAllConfigurations(configurations)
}

private func saveAllConfigurations(_ configurations: [String: ComponentConfiguration]) async {
    if let encoded = try? JSONEncoder().encode(configurations) {
        userDefaults.set(encoded, forKey: configurationsKey) // ✅ Сохраняется в UserDefaults
        userDefaults.set(Date(), forKey: cacheExpirationKey)
    }
}
```

**✅ ПОДТВЕРЖДЕНИЕ:** 
- Использует `UserDefaults.standard` - это персистентное хранилище
- Данные сохраняются между запусками приложения
- Работает даже без интернета

#### 2. ComponentStatusService

## ⚠️ ПРОБЛЕМЫ С ПРЕДЛОЖЕННЫМ РЕШЕНИЕМ

### Проблема 1: @AppStorage с динамическими ключами

**❌ НЕ РАБОТАЕТ:**
```swift
// Это НЕ скомпилируется
@AppStorage("component_\(componentId)_setting") private var setting: Bool = false
```

**✅ РАБОТАЕТ:**
```swift
// Конкретный ключ для каждого компонента
@AppStorage("component_phishing_protection_agent_block_suspicious_links") 
private var blockSuspiciousLinks: Bool = true
```

**Проблема:** Нужно создавать отдельный `@AppStorage` для каждого параметра каждого компонента - это много кода.

---

### Проблема 2: Двойное сохранение

**Текущее предложение:**
1. Сохранить через `@AppStorage` (локально)
2. Сохранить через `ComponentConfigurationService` (сервер + кэш)

**Проблема:** `ComponentConfigurationService` уже сохраняет в `ComponentCacheService`, который использует `UserDefaults`. Получается двойное сохранение в одно и то же место.

---

## ✅ ОПТИМАЛЬНОЕ РЕШЕНИЕ

### Вариант 1: Использовать только ComponentConfigurationService (РЕКОМЕНДУЕТСЯ)

**Преимущества:**
- ✅ Уже работает и сохраняет в UserDefaults
- ✅ Синхронизируется с сервером
- ✅ Единая точка сохранения
- ✅ Не нужно дублировать код

**Реализация:**
```swift
struct PhishingProtectionSettingsModal: View {
    let componentId: String
    @Binding var isPresented: Bool
    
    // ✅ Использовать @State для UI, но сохранять через сервис
    @State private var blockSuspiciousLinks: Bool = true
    @State private var warnBeforeOpening: Bool = true
    // ...
    
    @StateObject private var configurationService = ComponentConfigurationService.shared
    @StateObject private var toastManager = ToastManager.shared
    
    var body: some View {
        // ... UI ...
        .onAppear {
            loadSettings()
        }
    }
    
    // ✅ Загрузка из кэша (UserDefaults)
    private func loadSettings() {
        Task {
            do {
                let config = try await configurationService.getConfiguration(for: componentId)
                // Применить настройки из конфигурации
                if let settings = config.additionalSettings {
                    blockSuspiciousLinks = settings["blockSuspiciousLinks"]?.value as? Bool ?? true
                    warnBeforeOpening = settings["warnBeforeOpening"]?.value as? Bool ?? true
                    // ...
                }
            } catch {
                // Загрузить из локального кэша (ComponentCacheService уже сохранил)
                // Или использовать дефолтные значения
            }
        }
    }
    
    // ✅ Сохранение через сервис (автоматически сохраняет в UserDefaults)
    private func saveSettings() {
        Task {
            do {
                let config = ComponentConfiguration(
                    componentId: componentId,
                    isEnabled: true, // или получить из статуса
                    priority: .normal,
                    additionalSettings: [
                        "blockSuspiciousLinks": AnyCodable(blockSuspiciousLinks),
                        "warnBeforeOpening": AnyCodable(warnBeforeOpening),
                        "checkEmailLinks": AnyCodable(checkEmailLinks),
                        "checkSMSLinks": AnyCodable(checkSMSLinks),
                        "blockKnownPhishingDomains": AnyCodable(blockKnownPhishingDomains),
                        "sensitivityLevel": AnyCodable(sensitivityLevel)
                    ]
                )
                
                // ✅ Сохраняет в UserDefaults через ComponentCacheService
                // ✅ Синхронизирует с сервером
                try await configurationService.saveConfiguration(
                    componentId: componentId,
                    configuration: config
                )
                
                await MainActor.run {
                    toastManager.showSuccess("Настройки сохранены")
                    isPresented = false
                }
            } catch {
                // Настройки уже сохранены в кэш (ComponentCacheService)
                await MainActor.run {
                    toastManager.showSuccess("Настройки сохранены локально")
                    isPresented = false
                }
            }
        }
    }
}
```

**✅ ПОДТВЕРЖДЕНИЕ:**
- `ComponentConfigurationService.saveConfiguration()` вызывает `cacheManager.saveConfiguration()`
- `ComponentCacheService.saveConfiguration()` сохраняет в `UserDefaults.standard`
- Данные персистентны между запусками приложения
