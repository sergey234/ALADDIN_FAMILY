- Используют ту же систему категорий (12 категорий)

- Управляются через один интерфейс
- Статистика объединена (`contentBlocked.websitesBlocked + appsBlocked + searchQueriesBlocked`)

Это правильное архитектурное решение, так как:
- ✅ Упрощает управление (один интерфейс вместо трех)
- ✅ Обеспечивает консистентность правил
- ✅ Уменьшает количество карточек на экране
