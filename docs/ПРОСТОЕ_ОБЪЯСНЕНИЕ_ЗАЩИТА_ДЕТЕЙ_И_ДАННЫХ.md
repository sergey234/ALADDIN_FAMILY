## 👶 ЗАЩИТА ДЕТЕЙ (РФ) - ПРОСТЫМИ СЛОВАМИ

### 🎯 Для чего это нужно?

**Защита детей (РФ)** - это настройка, которая помогает соблюдать законы России о защите детей в интернете.

### 📝 Простыми словами:

**Как родитель, вы хотите:**
- ✅ Защитить ребенка от опасного контента
- ✅ Ограничить время использования телефона
- ✅ Знать, что ребенок делает в интернете
- ✅ Соответствовать законам России

**Приложение помогает:**
- ✅ Автоматически блокирует опасные сайты
- ✅ Ограничивает время использования
- ✅ Сохраняет данные только определенное время (30-365 дней)
- ✅ Автоматически удаляет старые данные

### 👥 Профили: "Дети" или "Взрослые"

**"Дети"** - строгие ограничения:
- Блокирует больше сайтов
- Ограничивает больше времени
- Сохраняет данные меньше времени (30-90 дней)

**"Взрослые"** - обычные ограничения:
- Блокирует только опасные сайты
- Ограничивает время меньше
- Сохраняет данные дольше (до 365 дней)

### 🗺️ Регионы: Москва, СПб, Московская область, Ленинградская область

**Зачем выбирать регион?**

В разных регионах России могут быть разные требования к защите детей. Приложение применяет настройки, которые соответствуют законам вашего региона.

**Пример:**
- В Москве могут быть одни требования
- В Санкт-Петербурге - другие
- В Московской области - третьи

**Вы выбираете регион, где вы живете, и приложение автоматически применяет правильные настройки!**

## 🔒 ЗАЩИТА ДАННЫХ (152-ФЗ) - ПРОСТЫМИ СЛОВАМИ

### 🎯 Для чего это нужно?

**Защита данных (152-ФЗ)** - это настройка, которая помогает соблюдать закон России о защите персональных данных (152-ФЗ).

### 📝 Простыми словами:

**Закон 152-ФЗ говорит:**
- ✅ Ваши персональные данные должны быть защищены
- ✅ Данные должны храниться определенное время
- ✅ Данные должны быть зашифрованы
- ✅ Данные должны быть удалены после истечения срока

**Приложение помогает:**
- ✅ Шифрует ваши данные (делает их секретными)
- ✅ Сохраняет данные только определенное время (90-1095 дней)
- ✅ Автоматически удаляет старые данные
- ✅ Соответствует закону 152-ФЗ

### 👥 Профили: "Физическое лицо" или "Юридическое лицо"

**"Физическое лицо"** - для обычных людей:
- Вы используете приложение для себя
- Данные хранятся 90-365 дней
- Простые настройки

**"Юридическое лицо"** - для компаний и организаций:
- Вы используете приложение для бизнеса
- Данные хранятся дольше (до 1095 дней)
- Более строгие требования к шифрованию

### 🔐 Шифрование: "Включено" или "Выключено"

**Шифрование** - это превращение ваших данных в секретный код.

**Простыми словами:**
- **Без шифрования:** Все видят ваши данные как есть
- **С шифрованием:** Все видят только "абракадабру" (секретный код)

**Пример:**
- Вы вводите пароль: "МойПароль123"
- Без шифрования: все видят "МойПароль123"
- С шифрованием: все видят "Xk9#mP2$qL" (не могут прочитать)

**Рекомендуется:** Всегда включать шифрование! 🔒

### 🗺️ Регионы: Москва, СПб, Московская область, Ленинградская область

**Зачем выбирать регион?**

В разных регионах России могут быть разные требования к защите данных. Приложение применяет настройки, которые соответствуют законам вашего региона.

**Пример:**
- В Москве могут быть одни требования к хранению данных
- В Санкт-Петербурге - другие
- В Московской области - третьи

**Вы выбираете регион, где вы живете, и приложение автоматически применяет правильные настройки!**
