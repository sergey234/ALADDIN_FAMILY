## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### **Приоритет источников данных:**

1. **GPS/ГЛОНАСС (основной):**
   - Точная скорость
   - Точное местоположение
   - Используется если доступно

2. **Акселерометр (запасной):**
   - Вычисление скорости из ускорения
   - Используется только если GPS недоступен

3. **Геозоны (запасной для местоположения):**
   - Радиус 500м (iOS ограничение)
   - Используется если точный GPS недоступен

---

### **Алгоритм обнаружения:**

```
1. Получение данных акселерометра (обязательно)
   ↓
2. Вычисление G-силы: √(x² + y² + z²) / 9.8
   ↓
3. Проверка порога: если G-сила < 3.0G → норма
   ↓
4. Фильтр ложных срабатываний:
   - Анализ буфера (последние 3 измерения)
   - Резкое изменение G-силы (>1.0G)
   - Проверка гироскопа (угловая скорость >5 рад/с)
   ↓
5. Определение серьезности по G-силе
   ↓
6. Автоматический вызов 112 (если HIGH/CRITICAL)
   ↓
7. Публикация события в ThreatEventBus
```
