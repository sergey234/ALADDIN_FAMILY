- [x] ✅ Удаление дефисов и пробелов перед хешированием

**Код:**
```python
def _hash_snils(self, snils: str) -> str:
    # Удаление дефисов и пробелов
    digits_only = re.sub(r'[-\s]', '', snils)
    # SHA-256 хеширование
    return hashlib.sha256(digits_only.encode()).hexdigest()
```
