## ✅ ЧТО ПРОВЕРИТЬ ПЕРЕД ЗАПУСКОМ

### Секреты в GitHub (обязательно):
1. Откройте: https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions
2. Проверьте наличие:
   - ✅ `APPLE_TEAM_ID`
   - ✅ `PROVISIONING_PROFILE_APP`
   - ✅ `PROVISIONING_PROFILE_EXTENSION`

**Если секретов нет → добавьте их перед запуском!**

## 📋 ЧТО ПРОИСХОДИТ

1. **Setup Provisioning Profiles** - установка profiles из секретов
2. **Build Archive (with signing)** - сборка с подписью
3. **Export IPA** - создание IPA файла
4. **Upload to App Store Connect** - загрузка (если API ключи есть)
5. **Upload IPA as artifact** - сохранение IPA для скачивания

## ✅ УСПЕШНАЯ СБОРКА

**Должно быть в логах:**
```
✅ App provisioning profile installed
✅ Extension provisioning profile installed
Building archive with manual signing...
** ARCHIVE SUCCEEDED **
IPA file: ./build/export/ALADDIN.ipa
✅ IPA file found
```

**Результат:**
- IPA файл в артефактах: `ALADDIN-IPA`
- Если API ключи настроены → автоматическая загрузка в App Store Connect
