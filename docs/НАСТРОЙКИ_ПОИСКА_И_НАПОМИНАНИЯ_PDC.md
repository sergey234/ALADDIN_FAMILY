# ⚙️ НАСТРОЙКИ ПОИСКА И НАПОМИНАНИЯ

**Дата:** 13 декабря 2025  
**Агент:** Personal Data Cleanup

---

## 🎯 НОВАЯ ФУНКЦИОНАЛЬНОСТЬ

### ✅ Реализовано:

1. **Напоминания раз в 45 дней** (по умолчанию)
   - Автоматическое напоминание пользователю
   - Показывается в статусе поиска
   - Пользователь может сам решить, когда искать

2. **Настройки пользователя**
   - Пользователь может включить автоматический поиск
   - Пользователь может установить свой интервал (7-365 дней)
   - Настройки сохраняются для каждого пользователя

3. **Гибкая система**
   - По умолчанию: поиск по запросу + напоминания
   - Пользователь может включить автоматический поиск
   - Каждый пользователь имеет свои настройки

---

## 📊 РЕЖИМЫ РАБОТЫ

### Режим 1: По запросу + напоминания (по умолчанию) ⭐

**Как работает:**
- Поиск выполняется только когда пользователь нажимает "Сканировать"
- Через 45 дней после последнего поиска появляется напоминание
- Пользователь видит уведомление: "Рекомендуется проверить данные"
- Пользователь сам решает, когда выполнить поиск

**Настройки:**
```json
{
    "enable_auto_scan": false,  // Автоматический поиск выключен
    "reminder_interval_days": 45  // Напоминание каждые 45 дней
}
```

**Пример:**
```
День 1:  Пользователь запросил поиск → Поиск выполнен ✅
День 45: Напоминание → "Рекомендуется проверить данные" 🔔
День 50: Пользователь запросил поиск → Поиск выполнен ✅
День 95: Напоминание → "Рекомендуется проверить данные" 🔔
```

**Когда использовать:**
- ✅ Для большинства пользователей (рекомендуется)
- ✅ Если пользователь хочет контролировать процесс
- ✅ Для экономии ресурсов сервера

---

### Режим 2: Автоматический поиск (пользователь включает)

**Как работает:**
- Пользователь включает автоматический поиск в настройках
- Поиск выполняется автоматически каждые N дней (по умолчанию 30)
- Пользователь может установить свой интервал (7-365 дней)
- Напоминания не нужны (поиск автоматический)

**Настройки:**
```json
{
    "enable_auto_scan": true,  // Пользователь включил
    "scan_interval_days": 30   // Интервал (пользователь может изменить)
}
```

**Пример:**
```
День 1:  Пользователь включил авто-поиск → Настройки сохранены ⚙️
День 30: Автоматический поиск → Поиск выполнен ✅
День 60: Автоматический поиск → Поиск выполнен ✅
День 90: Автоматический поиск → Поиск выполнен ✅
```

**Когда использовать:**
- ✅ Если пользователь хочет "забыть" о проблеме
- ✅ Если данные могут появляться часто
- ✅ Для активных пользователей

## 🔧 API ENDPOINTS

### 1. Получить статус поиска (с напоминаниями)

```
GET /api/data-cleanup/scan-status?user_id=user123
```

**Ответ:**
```json
{
    "status": "success",
    "scan_status": {
        "last_scan": "2025-11-01T10:00:00",
        "days_since_scan": 42.5,
        "next_scan_in_days": 2.5,
        "sites_found": 3,
        "auto_scan_enabled": false,
        "scan_interval_days": 30,
        "reminder_interval_days": 45,
        "needs_reminder": false,  // true если прошло >= 45 дней
        "reminder_message": null   // Сообщение, если нужно напоминание
    }
}
```

**Если нужно напоминание:**
```json
{
    "needs_reminder": true,
    "reminder_message": "Рекомендуется проверить данные. Последняя проверка была 45 дней назад"
}
```

---

### 2. Получить настройки пользователя

```
GET /api/data-cleanup/preferences?user_id=user123
```

**Ответ:**
```json
{
    "status": "success",
    "preferences": {
        "enable_auto_scan": false,
        "scan_interval_days": 30
    }
}
```

---

### 3. Обновить настройки пользователя

```
POST /api/data-cleanup/preferences
{
    "user_id": "user123",
    "enable_auto_scan": true,      // Включить автоматический поиск
    "scan_interval_days": 45        // Установить интервал 45 дней
}
```

**Ответ:**
```json
{
    "status": "success",
    "preferences": {
        "enable_auto_scan": true,
        "scan_interval_days": 45
    }
}
```

**Валидация:**
- `scan_interval_days`: минимум 7 дней, максимум 365 дней
- Если указано меньше 7 → устанавливается 7
- Если указано больше 365 → устанавливается 365

## 📈 ЛОГИКА РАБОТЫ

### Алгоритм проверки:

```
1. Пользователь открывает приложение
   ↓
2. Проверяется статус поиска (GET /scan-status)
   ↓
3. Если прошло >= 45 дней с последнего поиска:
   → Показывается напоминание 🔔
   → needs_reminder = true
   → reminder_message = "Рекомендуется проверить..."
   ↓
4. Пользователь видит напоминание
   ↓
5. Пользователь решает:
   - Нажать "Сканировать" → Выполняется поиск
   - Игнорировать → Напоминание появится снова через 45 дней
   ↓
6. Если пользователь включил авто-поиск:
   → Поиск выполняется автоматически каждые N дней
   → Напоминания не нужны
```

## 💡 ПРЕИМУЩЕСТВА

   - Можно включить автоматический поиск

   - Не нужно помнить о проверке
   - Напоминания напоминают, но не навязывают
   - Можно "забыть" о проблеме (с авто-поиском)
