## ⚠️ ПРОБЛЕМА

**Обнаружено расхождение:**

- ✅ **Файлы для App Store** (`20_full_privacy_policy.html`, `20_terms_of_service.html`) содержат **14 разделов** каждый
- ⚠️ **Файлы на сайте** (`landing/privacy.html`, `landing/terms.html`) содержат только **7 разделов** каждый

**Это означает:**
- На сайте размещена **упрощенная версия** политик (7 разделов)
- Для App Store нужна **полная версия** (14 разделов)
- **Нужно решить:** какую версию загружать на сервер для публичных URL?

## 🎯 РЕКОМЕНДАЦИИ

### Вариант 1: Использовать полную версию для App Store (РЕКОМЕНДУЕТСЯ)

**Плюсы:**
- ✅ Соответствие требованиям 152-ФЗ (полная политика)
- ✅ Соответствие требованиям Apple (детальная информация)
- ✅ Единообразие (одна версия везде)

**Минусы:**
- ⚠️ Длинный документ для пользователей сайта

**Действия:**
1. Загрузить `20_full_privacy_policy.html` на сервер как `privacy-policy.html`
2. Загрузить `20_terms_of_service.html` на сервер как `terms-of-service.html`
3. Обновить `landing/privacy.html` и `landing/terms.html` на полные версии (опционально)

---

### Вариант 2: Использовать разные версии

**Плюсы:**
- ✅ Короткая версия на сайте (удобнее для пользователей)
- ✅ Полная версия для App Store (соответствие требованиям)

**Минусы:**
- ⚠️ Две разные версии (нужно поддерживать обе)
- ⚠️ Может вызвать путаницу

**Действия:**
1. Загрузить `20_full_privacy_policy.html` на сервер как `privacy-policy.html` (для App Store)
2. Загрузить `20_terms_of_service.html` на сервер как `terms-of-service.html` (для App Store)
3. Оставить `landing/privacy.html` и `landing/terms.html` как есть (упрощенные версии)

---

## ✅ РЕКОМЕНДУЕМОЕ РЕШЕНИЕ

**Использовать полную версию (14 разделов) для публичных URL:**

1. **Загрузить на сервер:**
   - `20_full_privacy_policy.html` → `https://aladdin-ai.ru/privacy-policy.html`
   - `20_terms_of_service.html` → `https://aladdin-ai.ru/terms-of-service.html`

2. **Указать в App Store Connect:**
   - Privacy Policy URL: `https://aladdin-ai.ru/privacy-policy.html`
   - Terms of Service URL: `https://aladdin-ai.ru/terms-of-service.html`

3. **Опционально:** Обновить `landing/privacy.html` и `landing/terms.html` на полные версии для единообразия
