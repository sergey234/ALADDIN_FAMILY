## 🚀 ЗАПУСК СБОРКИ

### Способ 1: Через браузер (РЕКОМЕНДУЕТСЯ)

1. **Открыть GitHub Actions:**
   https://github.com/sergey234/ALADDIN_FAMILY/actions/workflows/appstore.yml

2. **Нажать "Run workflow":**
   - Справа вверху зелёная кнопка "Run workflow"
   - Выбрать ветку: `master`
   - Нажать "Run workflow"

3. **Дождаться запуска:**
   - Появится новый запуск в списке
   - Статус: 🟡 "In progress" (выполняется)

## 📋 ГДЕ СМОТРЕТЬ ЛОГИ

### После запуска workflow:

1. **Открыть список запусков:**
   https://github.com/sergey234/ALADDIN_FAMILY/actions/workflows/appstore.yml

2. **Найти последний запуск:**
   - Вверху списка будет последний запуск
   - Статус: 🟡 "In progress" или 🟢 "Success" или 🔴 "Failure"

3. **Открыть логи:**
   - Нажать на название запуска (например, "Build and Upload to App Store #123")
   - Откроется страница с деталями

4. **Просмотреть шаги:**
   - В левой панели список шагов:
     - ✅ Checkout code
     - ✅ Setup Xcode
     - ✅ Cache dependencies
     - ✅ Show Xcode version
     - ✅ **Setup Provisioning Profiles** ← ВАЖНО!
     - ✅ **Build Archive (with signing)** ← ВАЖНО!
     - ✅ List Archive Contents
     - ✅ Export IPA
     - ✅ Upload to App Store Connect
     - ✅ Upload IPA as artifact

5. **Открыть конкретный шаг:**
   - Нажать на название шага
   - Откроются логи этого шага

---

## 🔍 ЧТО ПРОВЕРИТЬ В ЛОГАХ

### Шаг "Setup Provisioning Profiles":

**Должно быть:**
```
✅ App provisioning profile installed
✅ Extension provisioning profile installed
📋 Installed provisioning profiles:
[список файлов .mobileprovision]
```

**Если ошибка:**
```
❌ PROVISIONING_PROFILE_APP secret is not set!
❌ PROVISIONING_PROFILE_EXTENSION secret is not set!
```
→ Секреты не добавлены или неправильно названы

---

### Шаг "Build Archive (with signing)":

**Должно быть:**
```
Building archive with manual signing...
Team ID: 6CJVBBUGSN
Bundle ID: family.aladdin.ios
** ARCHIVE SUCCEEDED **
```

**Если ошибка:**
```
error: No profiles for 'family.aladdin.ios' were found
```
→ Provisioning profiles не установлены правильно

```
error: CODE_SIGN_STYLE=Manual requires provisioning profile
```
→ Нужно проверить настройки signing

---

### Шаг "Export IPA":

**Должно быть:**
```
Exporting IPA...
IPA file: ./build/export/ALADDIN.ipa
✅ IPA file found
```

**Если ошибка:**
```
Error: IPA file not found!
```
→ Проблема с экспортом

## 📊 СТАТУСЫ WORKFLOW

### 🟡 In progress (выполняется):
- Workflow запущен и выполняется
- Обычно занимает 20-30 минут
- Обновляется в реальном времени

### 🟢 Success (успешно):
- Все шаги выполнены успешно
- Archive создан
- IPA файл готов
- Можно скачать из Artifacts

### 🔴 Failure (ошибка):
- Один из шагов завершился с ошибкой
- Нужно посмотреть логи шага с ошибкой
- Исправить проблему и запустить снова

## 📥 ГДЕ СКАЧАТЬ РЕЗУЛЬТАТ

### После успешной сборки:

1. **Открыть страницу запуска:**
   - Нажать на успешный запуск (🟢 Success)

2. **Найти раздел "Artifacts":**
   - Внизу страницы
   - Должен быть артефакт: `ALADDIN-IPA`

3. **Скачать IPA:**
   - Нажать на `ALADDIN-IPA`
   - Скачать архив
   - Внутри будет `.ipa` файл
