## 📋 КОНКРЕТНЫЙ ПЛАН

### Шаг 1: Получить Provisioning Profiles

**Локально в Xcode:**
1. Открыть проект
2. Выбрать target "ALADDIN"
3. Signing & Capabilities → выбрать Team
4. Xcode автоматически создаст profiles
5. Проверить, что profiles созданы

**Где найти profiles:**
```
~/Library/MobileDevice/Provisioning Profiles/
```

### Шаг 2: Добавить в GitHub Secrets

**Вариант A: Через fastlane match (рекомендуется)**
- Управление profiles через Git
- Автоматическая синхронизация

**Вариант B: Вручную**
- Экспортировать profiles
- Добавить в GitHub Secrets
- Использовать в workflow

### Шаг 3: Обновить Workflow

**Использовать готовые profiles:**
- Указать путь к profiles
- Использовать для подписи
- Собрать с правильной подписью
