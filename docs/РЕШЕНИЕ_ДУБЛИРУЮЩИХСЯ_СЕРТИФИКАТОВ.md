# ✅ РЕШЕНИЕ: Дублирующиеся сертификаты в профиле

**Дата:** 2 декабря 2024  
**Проблема:** В профиле "ALADDIN App Store Distribution" есть **2 сертификата** с одинаковым именем "SERGEY KHLYSTOV(Distribution)"

---

## 🔍 ПРОБЛЕМА

**В профиле два сертификата:**
- SERGEY KHLYSTOV(Distribution) - For use in Xcode 11 or later - Nov 29, 2026
- SERGEY KHLYSTOV(Distribution) - For use in Xcode 11 or later - Nov 29, 2026

**Xcode не может определить, какой сертификат использовать**, даже если они имеют одинаковое имя. Xcode проверяет сертификаты по **fingerprint (SHA-1)**, и если fingerprint сертификата в keychain не совпадает с fingerprint сертификата в профиле, возникает ошибка.

---

## ✅ РЕШЕНИЕ 1: Использовать только тип сертификата (РЕАЛИЗОВАНО)

**Изменено:**
- `CODE_SIGN_IDENTITY = "Apple Distribution: SERGEY KHLYSTOV (***)"` 
- → `CODE_SIGN_IDENTITY = "Apple Distribution"`

**Почему это работает:**
- Xcode будет искать любой сертификат типа "Apple Distribution" в keychain
- Если в профиле есть сертификат этого типа, Xcode использует его
- Это позволяет Xcode автоматически выбрать правильный сертификат из профиля

**Где изменено:**
- `fastlane/Fastfile` - все вхождения `CODE_SIGN_IDENTITY` изменены на `Apple Distribution`

---

## ✅ РЕШЕНИЕ 2: Удалить дублирующийся сертификат из профиля

1. **Зайдите в Apple Developer Portal:**
   - https://developer.apple.com/account/resources/profiles/list

2. **Откройте профиль "ALADDIN App Store Distribution"**

3. **Проверьте сертификаты:**
   - Если есть два одинаковых сертификата, один из них может быть устаревшим
   - Проверьте даты создания/истечения

4. **Удалите устаревший сертификат:**
   - Нажмите "Edit"
   - Убедитесь, что выбран только один актуальный сертификат
   - Сохраните изменения

5. **Скачайте обновленный профиль и обновите GitHub Secrets**

---

## ✅ РЕШЕНИЕ 3: Использовать fingerprint сертификата

Если Решение 1 не работает, можно использовать fingerprint:

1. **Извлечь fingerprint из сертификата в keychain:**
   ```bash
   security find-identity -v -p codesigning | grep "Apple Distribution"
   ```

2. **Использовать fingerprint в CODE_SIGN_IDENTITY:**
   ```bash
   CODE_SIGN_IDENTITY="88C0EF8CCCE24295357FB26474EB76E9F5F925FB"
   ```
