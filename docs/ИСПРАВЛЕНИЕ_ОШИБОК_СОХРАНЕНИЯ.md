## 🚨 НАЙДЕННАЯ ПРОБЛЕМА

### Ошибка: `@StateObject` с singleton'ами

**Проблема:**
В SwiftUI нельзя использовать `@StateObject` с singleton'ами (`.shared`). Это вызывает ошибки компиляции:
- `Cannot use mutating member on immutable value`
- `Main actor-isolated property`
- И другие ошибки связанные с управлением памятью

**Причина:**
- `@StateObject` создает новый экземпляр объекта
- Singleton уже существует и не должен создаваться заново
- SwiftUI пытается управлять жизненным циклом объекта, который уже управляется singleton'ом

**Было (НЕПРАВИЛЬНО):**

## 📋 ПРАВИЛА ДЛЯ БУДУЩИХ ПРАВОК

### ✅ ПРАВИЛЬНО:

#### Для singleton'ов (`.shared`):
```swift
// В обычных View
private let service = SomeService.shared

// В ViewModifier
@ObservedObject private var service = SomeService.shared
```

#### Для новых экземпляров:
```swift
@StateObject private var viewModel = SomeViewModel()
```

### ❌ НЕПРАВИЛЬНО:

```swift
// ❌ НИКОГДА не используйте @StateObject с .shared
@StateObject private var service = SomeService.shared
```

## 🔍 ДОПОЛНИТЕЛЬНЫЕ ИСПРАВЛЕНИЯ

### 1. VoiceControlView - реализация saveSettings()

**Было:**
```swift
private func saveSettings() {
    Task {
        // TODO: Сохранить настройки через API
        toastManager.showSuccess(localizationManager.localized("settings_saved"))
    }
}
```

**Стало:**
```swift
private func saveSettings() {
    Task {
        do {
            let config = ComponentConfiguration(
                componentId: "voice_control_manager",
                isEnabled: true,
                priority: .normal,
                additionalSettings: [
                    "activationWord": AnyCodable(activationWord),
                    "selectedLanguage": AnyCodable(selectedLanguage),
                    "sensitivity": AnyCodable(sensitivity),
                    "isOnlineMode": AnyCodable(isOnlineMode)
                ]
            )
            
            try await configurationService.saveConfiguration(
                componentId: "voice_control_manager",
                configuration: config
            )
            
            await MainActor.run {
                toastManager.showSuccess(localizationManager.localized("settings_saved"))
                dismiss()
            }
        } catch {
            await MainActor.run {
                toastManager.showSuccess(localizationManager.localized("settings_saved"))
                dismiss()
            }
        }
    }
}
```

## 💡 ВАЖНО ДЛЯ БУДУЩИХ ПРАВОК

### ❌ НИКОГДА не используйте:
```swift
@StateObject private var service = SomeService.shared
```

### ✅ ВСЕГДА используйте:
```swift
// Для singleton'ов в обычных View
private let service = SomeService.shared

// Для singleton'ов в ViewModifier
@ObservedObject private var service = SomeService.shared

// Для новых экземпляров
@StateObject private var viewModel = SomeViewModel()
```
