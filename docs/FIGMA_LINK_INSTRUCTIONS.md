# Как получить ссылку и `FIGMA_FILE_KEY` (без выдуманных данных)

Аудит репозитория: **готового URL мастер-файла в git нет** — ключ может быть только у команды в Figma. Ниже — как **один раз** правильно занести его в проект.

---

## Куда нажимать (простая дорожка)

Слова **«ВАШ_КЛЮЧ»** в примерах ниже — это **не** настоящий ключ, а **заглушка** («сюда подставьте свой»). Реальный ключ Figma сам выдаёт в ссылке.

1. **Зайти в браузере** на [figma.com](https://www.figma.com) и **войти** в свой аккаунт (логин/пароль — как обычно на сайте).
2. **Открыть нужный файл** — из списка **Recent** (Недавние) или через **Drafts / Team project** — тот, где лежат макеты онбординга / Main.
3. Убедиться, что **открыта вкладка с макетом** (видите холст с фреймами).
4. В **правом верхнем углу** нажать кнопку **Share** («Поделиться» — иконка людей или текст Share).
5. В открывшемся окне нажать **Copy link** («Копировать ссылку»). Ссылка попадёт в буфер обмена — это и есть **`FIGMA_MASTER_URL`** (вставьте её целиком).
6. **`FIGMA_FILE_KEY`:** вставьте ссылку в любой блокнот и **найдите кусок после** `figma.com/design/` **до следующего** символа **`/`**.  
   Пример: в ссылке  
   `https://www.figma.com/design/AbCdEfGh1234567890aBC/Название-файла`  
   ключ — это **`AbCdEfGh1234567890aBC`** (одна группа букв и цифр без слэшей).
7. В **Cursor** открыть файл проекта  
   `ALADDIN_NEW/mobile_apps/ALADDIN_iOS/docs/FIGMA_ONBOARDING.env`  
   и **две строки** записать так (подставьте **свои**, не слова ВАШ_КЛЮЧ):

   ```env
   FIGMA_MASTER_URL=https://www.figma.com/design/ВАШ_РЕАЛЬНЫЙ_КЛЮЧ/название?…
   FIGMA_FILE_KEY=ВАШ_РЕАЛЬНЫЙ_КЛЮЧ
   ```

   Во второй строке — **только ключ**, без `https://` и без остальной ссылки.

8. **Сохранить файл** (`Cmd+S`). При желании — закоммитить в git для команды.

9. В чат с агентом написать: **«делай Фазу B»** — он прочитает этот `.env`.

**Если кнопки Share нет:** иногда ссылка уже видна в **адресной строке браузера** — можно **скопировать оттуда** целиком (шаг 5), ключ всё равно выделяете по правилу шага 6.

**Если ссылка выглядит так:** `figma.com/files/team/.../recents-and-sharing` — это **страница команды / недавние**, а **не файл макета**. Для MCP нужна ссылка вида **`figma.com/design/КЛЮЧ/имя-файла`**. Откройте **конкретный файл** из списка дважды щёлкнув по нему — адрес в браузере сменится на `design/...` — тогда снова **Share → Copy link**.

---

## 1. Откройте нужный файл в Figma

Это должен быть **Design file** (макеты экранов), а не произвольный черновик без прав на запись для MCP.

---

## 2. Скопируйте ссылку

- Меню **Share** → **Copy link**  
  или адрес из браузера:  
  `https://www.figma.com/design/XXXXXXXXXXXXXXXX/Имя-файла?...`

---

## 3. Выньте `FIGMA_FILE_KEY`

В ссылке вид **`/design/НАБОР_СИМВОЛОВ/`** — это и есть **file key** (часто 22 символа, латиница и цифры).

Пример структуры (ключ вымышлен, только формат):

```text
https://www.figma.com/design/AbCdEfGh1234567890aBC/My-Onboarding
                         ^^^^^^^^^^^^^^^^^^^^^^
                         FIGMA_FILE_KEY
```

Для **ветки (branch)** в URL может быть другой сегмент — используйте **тот key, который показывает Figma в адресе после `/design/`** для вашего рабочего файла.

---

## 4. Запишите в репозиторий

Файл: **`docs/FIGMA_ONBOARDING.env`**

```env
FIGMA_MASTER_URL=<полная ссылка из шага 2>
FIGMA_FILE_KEY=<только ключ из шага 3>
```

Без кавычек, без пробелов вокруг `=`. Пустые строки = Фаза B через MCP **не стартует**.

По желанию продублируйте URL в таблице **`ONBOARDING_PHASE_A_COMPLETION.md`** §0.

---

## 5. Проверка «всё готово»

| Проверка | Ок |
|----------|---|
| `FIGMA_FILE_KEY` не пустой | ☐ |
| `FIGMA_MASTER_URL` начинается с `https://www.figma.com/design/` (или корректный branch-URL) | ☐ |
| У аккаунта Cursor / MCP есть доступ к этому файлу | ☐ |

После этого в чате можно написать: **«делай Фазу B»** — агент читает `docs/FIGMA_ONBOARDING.env`.

---

## 6. Опционально: проверка из терминала

Из каталога `ALADDIN_iOS`:

```bash
grep -E '^FIGMA_(MASTER_URL|FILE_KEY)=' docs/FIGMA_ONBOARDING.env | grep -v '=$' && echo OK || echo "Заполните FIGMA_ONBOARDING.env — см. этот файл"
```

Строки **без значения после `=`** означают, что ключ ещё не внесён.
