### ✅ Хеширование данных

**Реализовано:**
- ✅ SHA-256 хеширование СНИЛС
- ✅ SHA-256 хеширование паспортных данных
- ✅ Хранение только хешей, не исходных данных

**Код:**
```python
def _hash_snils(self, snils: str) -> str:
    """SHA-256 хеш СНИЛС"""
    return hashlib.sha256(snils.encode()).hexdigest()

def _hash_passport(self, series: str, number: str) -> str:
    """SHA-256 хеш паспортных данных"""
    combined = f"{series}:{number}"
    return hashlib.sha256(combined.encode()).hexdigest()
```

**Реализовано:**
- ✅ In-memory кэш для результатов проверок
- ✅ TTL (Time To Live) из конфигурации (по умолчанию 24 часа)
- ✅ Кэширование кредитных отчетов (НБКИ и ОКБ)

**Проверка:**
