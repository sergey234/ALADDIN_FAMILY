## 🧪 ТЕСТОВЫЕ СЦЕНАРИИ

### **1. Нормальная работа (нет аварии)**
- Нормальные данные акселерометра (G-сила < 3.0)
- Ожидаемый результат: авария не обнаружена

### **2. Обнаружение аварии**
- Высокая G-сила (>3.0G)
- Разные уровни серьезности (LOW, MEDIUM, HIGH, CRITICAL)
- Ожидаемый результат: авария обнаружена, определен уровень серьезности

### **3. Фильтр ложных срабатываний**
- Симуляция падения телефона (высокая G-сила, но короткая)
- Ожидаемый результат: фильтр отличает падение от аварии

### **4. Приоритет источников данных**
- GPS/ГЛОНАСС скорость (основной источник)
- Вычисление скорости из акселерометра (запасной)
- Геозона для местоположения (запасной)
- Ожидаемый результат: правильный приоритет источников

### **5. Полный сценарий аварии**
1. Запуск мониторинга
2. Нормальное движение (5 измерений)
3. Авария (высокая G-сила)
4. Проверка обнаружения
5. Проверка истории
6. Проверка статуса

### **6. Множественные пользователи**
- Одновременный мониторинг нескольких пользователей
- Ожидаемый результат: данные не смешиваются
