## 🆔 Identity Theft Protection (Защита от кражи личности)

### 11.1. Описание сервиса

**Identity Theft Protection** - это дополнительный сервис, предоставляемый ALADDIN для защиты ваших персональных данных от мошенников.

**Функциональность:**
- Мониторинг СНИЛС на подозрительную активность
- Мониторинг кредитных отчетов через НБКИ и ОКБ
- Проверка данных в базе мошенников
- Обнаружение признаков кражи личности
- Предоставление инструкций по защите (кредитный замок)

### 11.2. Согласие на обработку персональных данных

**Использование сервиса Identity Theft Protection требует вашего явного согласия на обработку персональных данных.**

**Какие данные обрабатываются:**
- СНИЛС (хранится только SHA-256 хеш)
- Паспортные данные (хранятся только SHA-256 хеши)
- Информация о кредитной истории (через НБКИ/ОКБ при наличии согласия)

**Как предоставить согласие:**
- Через мобильное приложение iOS в разделе Identity Theft Protection
- Через API endpoint `/api/identity-theft/consent`

**Срок действия согласия:**
- До 10 лет с момента предоставления
- Или до момента отзыва согласия

### 11.3. Отзыв согласия

**Вы можете отозвать согласие в любой момент:**
- Через мобильное приложение
- Через API endpoint `/api/identity-theft/revoke-consent`
- Через службу поддержки

**При отзыве согласия:**
- Все ваши персональные данные удаляются в течение 24 часов
- Мониторинг прекращается немедленно
- Восстановление данных невозможно

**Подробная инструкция:** См. `docs/ИНСТРУКЦИЯ_ОТЗЫВА_СОГЛАСИЯ_152ФЗ.md`

### 11.4. Безопасность данных

**Меры безопасности:**
- ✅ SHA-256 хеширование всех персональных данных
- ✅ Хранение только хешей (не исходных данных)
- ✅ Минимизация данных
- ✅ Логирование всех операций с метками [152-ФЗ]
- ✅ Автоматическое удаление при отзыве согласия

**Мы НЕ храним:**
- ❌ Исходные номера СНИЛС
- ❌ Исходные паспортные данные
- ❌ Детали кредитных договоров

### 11.5. Передача данных третьим лицам

**Кредитные бюро (НБКИ, ОКБ):**
- Данные передаются только с вашего явного согласия
- Передается только хеш СНИЛС (не исходный номер)
- Используется только для получения кредитного отчета

**Мы НЕ передаем данные:**
- ❌ Рекламным агентствам
- ❌ Маркетинговым компаниям
- ❌ Третьим лицам для продажи или аренды

### 11.6. Ваши права (152-ФЗ)

При использовании Identity Theft Protection вы имеете право:

- ✅ На доступ к вашим данным
- ✅ На исправление данных
- ✅ На удаление данных
- ✅ На ограничение обработки
- ✅ На отзыв согласия в любой момент
- ✅ На обжалование в Роскомнадзор

**Подробная информация:** См. `docs/ПРАВА_ПОЛЬЗОВАТЕЛЯ_152ФЗ.md`

### 11.7. Ответственность

**ALADDIN:**
- Обеспечивает безопасность обработки данных согласно 152-ФЗ
- Удаляет данные при отзыве согласия
- Не несет ответственности за действия третьих лиц (НБКИ, ОКБ)

**Пользователь:**
- Обязан предоставлять точные данные
- Несет ответственность за конфиденциальность своих учетных данных
- Может отозвать согласие в любой момент

### 11.8. Контакты

**Вопросы по Identity Theft Protection:**
