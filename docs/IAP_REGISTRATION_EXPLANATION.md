# 💳 IAP Регистрация: Зачем это нужно?

**Дата:** 19 ноября 2025  
**Вопрос:** Нужна ли регистрация IAP для не-российских регионов?

---

## 📊 ТЕКУЩАЯ СИТУАЦИЯ

### Что у вас сейчас:

1. **В России:**
   - ✅ Оплата через сайт (QR/СБП/карты)
   - ✅ IAP недоступен (ограничения Apple)
   - ✅ Кнопка "Оформить на сайте" → переход на `https://aladdin-ai.ru/`

2. **За границей (не-российские регионы):**
   - ⚠️ **Сейчас:** Все пользователи тоже идут на сайт (из-за `useAlternativePayments = true`)
   - ⚠️ **Проблема:** Зарубежные пользователи не могут оплатить через App Store IAP

---

## 🤔 ЗАЧЕМ НУЖНА IAP РЕГИСТРАЦИЯ?

### ✅ ПРЕИМУЩЕСТВА (если регистрируете IAP):

1. **Удобство для зарубежных пользователей:**
   - Оплата прямо в приложении (не нужно переходить на сайт)
   - Использование Apple ID и сохранённых карт
   - Автоматическое продление подписки
   - Стандартный UX для iOS пользователей

2. **Соответствие ожиданиям пользователей:**
   - Зарубежные пользователи привыкли к IAP
   - Переход на сайт может показаться подозрительным
   - Меньше шагов = больше конверсий

3. **Международное расширение:**
   - Готовность к запуску в других странах
   - Поддержка разных валют автоматически
   - Локализация цен по регионам

4. **Соответствие App Store Guidelines:**
   - Для цифрового контента/подписок рекомендуется IAP
   - Меньше вопросов от ревьюеров

---

## ❌ НЕ НУЖНО (если фокус только на Россию):

1. **Если вы НЕ планируете:**
   - Запуск в других странах
   - Поддержку зарубежных пользователей
   - Международное расширение

2. **Текущая реализация работает:**
   - Все пользователи идут на сайт
   - Оплата работает через сайт
   - Для России это оптимально

---

## 📋 ЧТО НУЖНО СДЕЛАТЬ (если регистрируете IAP):

### В App Store Connect:

1. **Создать Subscription Group:**
   - Название: "ALADDIN Subscriptions"
   - Описание: "Family protection subscriptions"

2. **Зарегистрировать тарифы:**
   - Personal (1, 3, 6, 12 месяцев)
   - Family (1, 3, 6, 12 месяцев)
   - Premium (1, 3, 6, 12 месяцев)

3. **Установить цены:**
   - Для каждого региона (USD, EUR, GBP и т.д.)
   - Apple автоматически конвертирует валюты

4. **Настроить Product IDs:**
   - Например: `family.aladdin.ios.personal.1month`
   - Формат: `bundleId.tariff.period`

### В коде приложения:

1. **Обновить `AppConfig.swift`:**
   ```swift
   static var useAlternativePayments: Bool {
       #if APP_STORE_BUILD
       // В App Store билде: Россия → сайт, остальные → IAP
       return isRussianRegion
       #else
       // В других билдах: всегда сайт
       return true
       #endif
   }
   ```

2. **Проверить `StoreManager.swift`:**
   - Убедиться, что IAP логика работает
   - Product IDs соответствуют зарегистрированным в App Store Connect

3. **Обновить `TariffsScreen.swift`:**
   - Для не-российских регионов показывать "Купить через App Store"
   - Для России — "Оформить на сайте"
