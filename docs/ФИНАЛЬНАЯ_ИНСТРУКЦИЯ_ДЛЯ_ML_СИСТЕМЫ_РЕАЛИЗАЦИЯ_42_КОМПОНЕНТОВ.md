---

## 📊 ОБЩАЯ ИНФОРМАЦИЯ

### ✅ ЦЕЛЬ ЗАДАЧИ:

Интегрировать 42 компонента (19 агентов, 15 менеджеров, 8 ботов) в существующее мобильное приложение ALADDIN iOS без создания новых экранов, используя только переключатели и расширение существующих экранов.

### ✅ КЛЮЧЕВОЙ ПРИНЦИП:

**НЕ СОЗДАВАТЬ НОВЫЕ ЭКРАНЫ!** Использовать существующие экраны и добавлять переключатели в существующие разделы.

### ⚠️ ВАЖНО: НЕ ВСЕ КОМПОНЕНТЫ ТРЕБУЮТ ТОЛЬКО ТУМБЛЕР!

**28 из 42 компонентов требуют обязательных дополнительных настроек:**
- Тумблер + кнопка "Настройки" → модальное окно с формами
- Тумблер + кнопка "Генератор" → модальное окно для генератора паролей
- NavigationLink → отдельный View с настройками

**См. раздел "🎛️ ДЕТАЛЬНЫЕ ТРЕБОВАНИЯ К UI: ТУМБЛЕР ИЛИ НАСТРОЙКИ?" для полной информации.**
