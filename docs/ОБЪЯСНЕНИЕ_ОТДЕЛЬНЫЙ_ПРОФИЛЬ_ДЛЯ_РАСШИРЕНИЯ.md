# 📖 ОБЪЯСНЕНИЕ: Почему нужен отдельный профиль для расширения

## 🎯 Простыми словами

### Что такое Provisioning Profile?

**Provisioning Profile** (профиль подготовки) — это как **"пропуск"** для вашего приложения, который говорит Apple:
- ✅ "Это приложение создано вами"
- ✅ "Оно может работать на iPhone/iPad"
- ✅ "Его можно загрузить в App Store"

Без этого "пропуска" Apple не позволит установить приложение на устройство или отправить в App Store.

---

## 🔍 Почему для расширения нужен ОТДЕЛЬНЫЙ профиль?

### Аналогия из жизни:

Представьте, что вы строите **дом** (основное приложение) и **гараж** (расширение):

1. **Дом** имеет свой адрес: `family.aladdin.ios`
   - Для дома нужен свой "пропуск" (provisioning profile)

2. **Гараж** имеет свой адрес: `family.aladdin.ios.ALADDINContentBlocker`
   - Для гаража нужен **ОТДЕЛЬНЫЙ** "пропуск" (provisioning profile)

**Почему отдельный?**
- Гараж — это отдельное строение, хоть и рядом с домом
- У него свой адрес (bundle ID)
- Apple требует отдельный "пропуск" для каждого адреса

---

## 📱 В технических терминах:

### Основное приложение:
- **Bundle ID**: `family.aladdin.ios`
- **Provisioning Profile**: "ALADDIN App Store Distribution"
- **Что делает**: Это само приложение ALADDIN

### Content Blocker Extension:
- **Bundle ID**: `family.aladdin.ios.ALADDINContentBlocker`
- **Provisioning Profile**: "ALADDINContentBlocker App Store Distribution" (нужно создать!)
- **Что делает**: Это расширение для Safari, которое блокирует контент

---

## ❌ Что будет, если НЕ создать отдельный профиль?

**Ошибка при сборке:**
```
error: Provisioning profile "ALADDIN App Store Distribution" 
has app ID "family.aladdin.ios", which does not match 
the bundle ID "family.aladdin.ios.ALADDINContentBlocker".
```

**Простыми словами:**
- Apple видит, что вы пытаетесь использовать "пропуск" для дома (`family.aladdin.ios`)
- Но пытаетесь применить его к гаражу (`family.aladdin.ios.ALADDINContentBlocker`)
- Apple говорит: "Стоп! У гаража другой адрес, нужен другой пропуск!"

---

## ✅ Решение:

1. **Создать отдельный App ID** для расширения:
   - `family.aladdin.ios.ALADDINContentBlocker`

2. **Создать отдельный Provisioning Profile** для этого App ID:
   - "ALADDINContentBlocker App Store Distribution"

3. **Добавить оба профиля в GitHub Secrets**:
   - `PROVISIONING_PROFILE_APP` — для основного приложения
   - `PROVISIONING_PROFILE_EXTENSION` — для расширения

---

## 🎬 Итоговая аналогия:

**Представьте поездку в другую страну:**

- **Основное приложение** = ваш паспорт
- **Расширение** = виза для определенной цели (например, рабочая виза)

У вас есть паспорт, но для работы нужна **отдельная виза**. Без визы вас не пустят работать, даже если у вас есть паспорт.

Точно так же:
- У вас есть профиль для основного приложения
- Но для расширения нужен **отдельный профиль**
- Без него Apple не позволит собрать приложение с расширением

---

## 📋 Что нужно сделать:

1. ✅ Создать App ID для расширения в Apple Developer Portal
2. ✅ Создать Provisioning Profile для этого App ID
3. ✅ Скачать профиль
4. ✅ Извлечь UUID из профиля
5. ✅ Закодировать профиль в base64
6. ✅ Добавить в GitHub Secrets:
   - `PROVISIONING_PROFILE_EXTENSION_UUID` (UUID)
   - `PROVISIONING_PROFILE_EXTENSION` (base64)

После этого сборка пройдет успешно! 🎉
