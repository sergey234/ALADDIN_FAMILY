## 📊 АРХИТЕКТУРА ОБЩЕГО РОУТЕРА

### **Общий роутер:** `/api/components/`
- ✅ `GET /api/components/status/{componentId}` - получить статус компонента
- ✅ `POST /api/components/enable/{componentId}` - включить компонент
- ✅ `POST /api/components/disable/{componentId}` - выключить компонент

### **Специфичные роутеры:** Используются только для бизнес-данных
- `crash_detection_router.py` - для алертов о ДТП

- `parental_control_router.py` - для статистики родительского контроля
- `subscription_sync_router.py` - для синхронизации подписок
- `metrics_router.py` - для метрик аналитики

✅ **Архитектура корректна:**
- Общий роутер (`/api/components/`) - для статусов и конфигураций
