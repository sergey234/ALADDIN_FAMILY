## ⚠️ ИСПРАВЛЕНИЕ

### Проблема:
В `ComponentToggleCard` тумблер изменял `isEnabled` через Binding, но `onToggle` callback не вызывался автоматически.

### Решение:
Добавлен кастомный Binding, который вызывает `onToggle()` при изменении значения:

```swift
ALADDINToggle(isOn: Binding(
    get: { isEnabled },
    set: { newValue in
        isEnabled = newValue
        onToggle()
    }
))
```

Теперь при каждом изменении тумблера:
1. ✅ Обновляется `isEnabled` через Binding
2. ✅ Вызывается `onToggle()` callback
3. ✅ ViewModel вызывает `toggleComponent()`
4. ✅ Состояние сохраняется на сервер через `ComponentStatusService.updateStatus()`
5. ✅ Состояние сохраняется в кэш
