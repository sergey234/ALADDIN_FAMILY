# Единорог Companion — метод «6 шляп» (согласование v1)

**Дата:** 2026-05-27 · **Аудитория:** child (основной), teen опционально  
**Artboard:** 360×480 pt · **Стиль:** мультяшный 2D, **тот же cinematic-light** что OB, но **проще формы**

---

## Как понял задачу (кратко)

- **Аладдин** и **Джин** — **готовые** hero PNG из онбординга (01 и 04/06/07), только вырезка героя.  
- **Единорог** — **нет** в OB; нужен **новый мультяшный** друг, чтобы вы **одобрили облик**, потом 12 эмоций и Rive.  
- На всех макетах Companion: **без текста/кнопок/UI** — только персонаж.

---

## ⚪ Белая шляпа — факты

| Факт | Следствие |
|------|-----------|
| В онбординге нет «лошади с рогом» | Не копируем OB_05 (там космический страж — ближе к **джину**) |
| child видит только `unicorn` | Должен быть **мягкий, PG, не страшный** |
| На Hub круг **96 pt**, на «Главное» rect **~56%** | Крупная голова, читаемые глаза/рот (MIMIC-Q1) |
| 12 эмоций CX.4 | Один базовый силуэт + меняются брови/рот/уши/хвост |
| Конкуренты в приложении | Рядом **реалистичный** Аладдин и **светящийся** Джин — единорог = **контраст «милый мульт»** |

## 🟢 Зелёная шляпа — образ v1 (предложение PO)

### Силуэт

```
     ✦ рог (золото, 8–12% высоты)
    ( ˆˆ )  уши конус + розовый внутри
   ◉     ◉  глаза: большие, тёмно-фиолетовые зрачки, белый блик
    ‿‿      рот idle: мягкая улыбка
   ╭───╮
  │ fluff │  тело: кремово-белое, овал
  │ mane  │  грива: лавандово-розовая, 3 локона
   ╰∪∪╯   ноги: короткие, розовые копыта
     ★      хвост: пучок гривы (happy — чуть выше)
```

### Палитра

| Элемент | Цвет |
|---------|------|
| Тело | `#FFF8FC` → `#F3E8FF` градиент |
| Грива/хвост | `#C9A0FF` · `#E8B4FF` |
| Рог | `#F5D76E` + блик `#FFFACD` |
| Глаза | радужка `#6B4C9A`, блик белый |
| Копыта | `#FFB8D0` |
| Фон сцены (Companion) | мягкий `#EDE7FF` → `#D4C4FF` (без текста) |

### Пропорции (360×480)

| Зона | % высоты |
|------|----------|
| Голова+рог | 0–42% |
| Тело | 38–78% |
| Ноги | 72–92% |
| Воздух снизу (для субтитра iOS) | 8% — **пусто**, без текста на арте |

### Стиль линии

- **Без** чёрного контура Disney-thick: мягкая тень `blur 8`, лёгкий rim-light как у OB_01.  
- Текстура: лёгкий **fur noise** 5% (не фото-реализм).  
- **Не** My Little Pony копия — свой ALADDIN: золото + индиго-акценты бренда.

### 12 эмоций (кратко)

| Эмоция | Лицо/тело |
|--------|-----------|
| idle | лёгкая улыбка, уши нейтрально |
| listening | уши «настороже», глаза чуть шире |
| thinking | глаза вверх, рот «hm» |
| happy | улыбка шире, хвост выше |
| playful | подмигивание + ✨ (1–2 звезды) |
| sad | уши вниз, рот дуга вниз, **без** ✨ |
| comfort | глаза мягче, лёгкий наклон головы |
| celebrate | глаза-дуги, рог ярче |
| curious | голова наклон, одно ухо |
| nostalgic | полуусмешка, глаза в сторону |
| excited | прыжок 5% scale, грива «взъерошена» |
| alert | уши вверх, глаза круглее, без страха |
