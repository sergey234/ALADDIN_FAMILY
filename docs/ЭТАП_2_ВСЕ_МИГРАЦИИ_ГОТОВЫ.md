## 📝 ИНСТРУКЦИЯ ПО ПРИМЕНЕНИЮ

### **ВАРИАНТ 1: Применить все миграции сразу**

```bash
# 1. Подключиться к серверу
ssh root@149.154.65.180

# 2. Перейти в директорию проекта
cd /opt/aladdin-backend

# 3. Создать backup БД (ОБЯЗАТЕЛЬНО!)
pg_dump -U postgres -d aladdin_db > backup_etap2_$(date +%Y%m%d_%H%M%S).sql

# 4. Загрузить все миграции на сервер (через SFTP или scp)
# Файлы:
# - docs/server/migrations/create_crash_detection_alerts_table.sql
# - docs/server/migrations/create_roadside_assistance_requests_table.sql
# - docs/server/migrations/create_parental_control_tables.sql
# - docs/server/migrations/create_analytics_metrics_table.sql
# - docs/server/migrations/create_all_component_data_tables.sql

# 5. Применить все миграции по отдельности
psql -U postgres -d aladdin_db -f docs/server/migrations/create_crash_detection_alerts_table.sql
psql -U postgres -d aladdin_db -f docs/server/migrations/create_roadside_assistance_requests_table.sql
psql -U postgres -d aladdin_db -f docs/server/migrations/create_parental_control_tables.sql
psql -U postgres -d aladdin_db -f docs/server/migrations/create_analytics_metrics_table.sql

# 6. Проверить создание всех таблиц
psql -U postgres -d aladdin_db << EOF
\dt crash_detection_alerts
\dt roadside_assistance_requests
\dt parental_control_stats
\dt parental_bypass_stats
\dt analytics_metrics
EOF
```
