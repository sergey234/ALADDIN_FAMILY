## 🛠️ МЕТОДЫ УДАЛЕНИЯ ДАННЫХ

### 1. Opt-Out Формы
- Большинство сайтов имеют форму на странице `/opt-out` или `/remove-my-info`
- Требуется: Имя, адрес, email для подтверждения
- Время обработки: 24-48 часов

### 2. GDPR Запросы (для Европы)
- Отправка email с запросом на удаление
- Требуется: Идентификация личности
- Время обработки: 30 дней (по закону)

### 3. API Удаления (редко)
- Некоторые сайты предоставляют API
- Требуется: API ключ, техническая интеграция

### 4. Email Запросы
- Отправка email на `privacy@`, `support@` или `dpo@`
- Требуется: Описание данных для удаления

### 5. Удаление через родительские компании
- Некоторые компании контролируют несколько сайтов
- Пример: PeopleConnect контролирует 5+ сайтов
- Можно удалить с всех сайтов одной формой

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Повторное появление данных:**
   - Данные могут появиться снова через несколько месяцев
   - Новые публичные записи могут быть добавлены автоматически
   - Необходимо периодически проверять (каждые 3-6 месяцев)

2. **Публичные записи:**
   - Некоторые данные из публичных записей (суды, регистрации) нельзя удалить
   - Можно только "подавить" отображение на сайте

3. **Юридические требования:**
   - **GDPR (Европа):** Право на удаление данных
   - **152-ФЗ (Россия):** Право на удаление персональных данных
   - **CCPA (Калифорния):** Право на удаление данных

4. **Время обработки:**
   - Opt-out формы: 24-48 часов
   - GDPR запросы: до 30 дней
   - Email запросы: 7-14 дней

5. **Подтверждение удаления:**
   - Всегда проверяйте через 1-2 недели
   - Используйте инкогнито режим браузера
   - Проверяйте разные варианты имени
