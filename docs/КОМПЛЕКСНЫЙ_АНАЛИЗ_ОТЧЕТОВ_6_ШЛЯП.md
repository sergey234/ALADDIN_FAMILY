## 🔴 КРАСНАЯ ШЛЯПА: ЭМОЦИИ И ЧУВСТВА

### Потенциальные проблемы:

#### **1. Перегрузка информацией:**
- ❌ Пользователь может быть перегружен большим количеством отчетов
- ❌ Слишком много модальных окон может утомлять

#### **2. Сложность навигации:**
- ❌ Если отчеты будут в отдельных экранах - сложнее найти нужное
- ❌ Если все в модальных окнах - может быть неудобно переключаться

#### **3. Выбор детей:**
- ❌ Родитель может забыть, для какого ребенка смотрит статистику
- ❌ Нет визуального индикатора выбранного ребенка

#### **4. Производительность:**
- ❌ Загрузка отчетов для всех детей может быть медленной
- ❌ Большие объемы данных могут замедлить приложение

---

## ⚫ ЧЕРНАЯ ШЛЯПА: КРИТИКА И РИСКИ

### Критические риски:

#### **1. Навигация:**
- ❌ **РИСК:** Если использовать отдельные экраны - нужно добавлять в NavigationManager
- ❌ **РИСК:** Если использовать модальные окна - может быть неудобно для длинных отчетов
- ✅ **РЕШЕНИЕ:** Гибридный подход - модальные окна для кратких отчетов, отдельный экран для детальных (Отчеты о вождении)

#### **2. Сохранение состояния:**
- ❌ **РИСК:** Выбранный пользователь/ребенок не сохраняется между сессиями
- ❌ **РИСК:** Фильтры в отчетах не сохраняются
- ✅ **РЕШЕНИЕ:** Использовать @AppStorage для выбранного пользователя, UserDefaults для фильтров

#### **3. Производительность:**
- ❌ **РИСК:** Загрузка отчетов для всех детей одновременно
- ❌ **РИСК:** Большие объемы данных в модальных окнах
- ✅ **РЕШЕНИЕ:** Ленивая загрузка, загружать только при открытии модального окна

#### **4. UI/UX:**
- ❌ **РИСК:** Модальные окна могут быть слишком маленькими для графиков
- ❌ **РИСК:** Нет индикатора загрузки в модальных окнах
- ✅ **РЕШЕНИЕ:** Использовать ScrollView, добавить ProgressView

#### **5. Взаимосвязи:**
- ❌ **РИСК:** Отчеты не связаны с общей аналитикой
- ❌ **РИСК:** Нет перехода из уведомлений в отчеты
- ✅ **РЕШЕНИЕ:** Добавить deep links, связать с уведомлениями

struct ComponentReportCard: View {

    let icon: String

                        .fill(color.opacity(0.2))
                        .frame(width: 50, height: 50)

                    if let count = badgeCount, count > 0 {

                            .font(.caption2)

                            .padding(4)
                            .background(Color.dangerRed)
                            .clipShape(Circle())
                            .offset(x: 18, y: -18)
                    }
                }
                
                // Информация
                VStack(alignment: .leading, spacing: Spacing.xs) {
                    Text(title)
                        .font(.bodyBold)
                        .foregroundColor(.textPrimary)
                    
                    // Метрики (максимум 2)
                    ForEach(Array(metrics.prefix(2)), id: \.0) { key, value in
                        HStack(spacing: Spacing.xs) {
                            Text(key)
                                .font(.caption)
                                .foregroundColor(.textSecondary)
                            Text(value)
                                .font(.captionBold)
                                .foregroundColor(.textPrimary)
                        }
                    }
                }
                
                Spacer()
                
                // Стрелка

            }

### Селектор пользователя:

```swift
struct UserSelectorView: View {
    @Binding var selectedUserId: String?
    let users: [UserOption]
    let currentUserId: String
    @EnvironmentObject private var localizationManager: LocalizationManager
    
    struct UserOption: Identifiable {
        let id: String
        let name: String
        let role: String
        let avatar: String?
    }
    
    var body: some View {
        VStack(alignment: .leading, spacing: Spacing.s) {
            Text(localizationManager.localized("reports_select_user"))
                .font(.body)
                .foregroundColor(.textSecondary)
            
            ScrollView(.horizontal, showsIndicators: false) {
                HStack(spacing: Spacing.s) {
                    // "Я" (текущий пользователь)
                    UserChip(
                        id: currentUserId,
                        name: localizationManager.localized("reports_current_user"),
                        icon: "person.fill",
                        isSelected: selectedUserId == currentUserId || selectedUserId == nil,
                        onTap: { selectedUserId = currentUserId }
                    )
                    
                    // Другие пользователи
                    ForEach(users) { user in
                        UserChip(
                            id: user.id,
                            name: user.name,
                            icon: user.avatar ?? "person.fill",
                            isSelected: selectedUserId == user.id,
                            onTap: { selectedUserId = user.id }
                        )
                    }
                }
                .padding(.horizontal, Spacing.screenPadding)
            }
        }
    }
}

struct UserChip: View {
    let id: String
    let name: String
    let icon: String
    let isSelected: Bool
    let onTap: () -> Void
    
    var body: some View {
        Button(action: onTap) {
            HStack(spacing: Spacing.xs) {
                Image(systemName: icon)
                    .font(.caption)
                
                Text(name)
                    .font(.body)
            }
            .foregroundColor(isSelected ? .white : .textPrimary)
            .padding(.horizontal, Spacing.m)
            .padding(.vertical, Spacing.s)
            .background(
                Capsule()
                    .fill(isSelected ? Color.primaryBlue : Color.backgroundMedium)
            )
        }
    }
}
```
