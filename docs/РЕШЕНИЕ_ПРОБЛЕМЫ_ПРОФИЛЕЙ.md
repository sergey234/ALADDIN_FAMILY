# 🔧 РЕШЕНИЕ ПРОБЛЕМЫ С ПРОФИЛЯМИ

## 🚨 ТЕКУЩАЯ ПРОБЛЕМА

**Ошибки:**
1. `Provisioning profile "ALADDIN App Store Distribution" doesn't include signing certificate "Apple Distribution: SERGEY KHLYSTOV (***)"`
2. Для Extension используется профиль приложения вместо Extension профиля

**Причина:**
Профили были созданы с другим сертификатом или не были правильно связаны с текущим сертификатом в Apple Developer Portal.

---

## ✅ РЕШЕНИЕ: Пересоздать профили

### ШАГ 1: Удалить старые профили в Developer Portal

1. Откройте https://developer.apple.com/account/resources/profiles/list
2. Найдите профили:
   - `ALADDIN App Store Distribution` (UUID: `de134a6b-7135-4f75-bc3b-4a68fd753f7c`)
   - `ALADDIN PacketTunnel App Store Distribution` (UUID: `c0a22622-4b23-4be3-b18d-b744dbf8e6ce`)
3. Удалите их (Revoke)

### ШАГ 2: Создать новые профили

#### Профиль для основного приложения:

1. Нажмите **"+"** (Create a new profile)
2. Выберите **"App Store"** → Continue
3. Выберите **App ID**: `family.aladdin.ios`
4. Выберите **Certificate**: `Apple Distribution: SERGEY KHLYSTOV (***)`
5. Название: `ALADDIN App Store Distribution`
6. Download профиль

#### Профиль для Extension:

1. Нажмите **"+"** (Create a new profile)
2. Выберите **"App Store"** → Continue
3. Выберите **App ID**: `family.aladdin.ios.packetTunnel`
4. Выберите **Certificate**: `Apple Distribution: SERGEY KHLYSTOV (***)`
5. Название: `ALADDIN PacketTunnel App Store Distribution`
6. Download профиль

### ШАГ 3: Обновить GitHub Secrets

1. Откройте https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions
2. Обновите секреты:
   - `PROVISIONING_PROFILE_APP` - закодировать новый профиль приложения в base64
   - `PROVISIONING_PROFILE_EXTENSION` - закодировать новый профиль Extension в base64

**Как закодировать:**
```bash
base64 -i "ALADDIN_App_Store_Distribution.mobileprovision" | pbcopy
# Вставить в PROVISIONING_PROFILE_APP

base64 -i "ALADDIN_PacketTunnel_App_Store_Distribution.mobileprovision" | pbcopy
# Вставить в PROVISIONING_PROFILE_EXTENSION
```

## 🔄 АЛЬТЕРНАТИВНОЕ РЕШЕНИЕ: Использовать Automatic Signing с API ключами

Если пересоздание профилей не подходит, можно использовать Automatic signing с App Store Connect API:

1. Убедитесь, что настроены секреты:
   - `APP_STORE_CONNECT_API_KEY`
   - `APP_STORE_CONNECT_ISSUER_ID`
   - `APP_STORE_CONNECT_API_KEY_ID`

2. Xcode автоматически создаст/обновит профили через API

---

## 📝 ПРИМЕЧАНИЕ

**xcconfig файл** - это просто способ явно указать Xcode, какие профили использовать. Но он **НЕ МОЖЕТ** исправить проблему, если профили не связаны с сертификатом.

**Основная проблема** - это несоответствие между профилями и сертификатом в Apple Developer Portal, а не настройки Xcode.
