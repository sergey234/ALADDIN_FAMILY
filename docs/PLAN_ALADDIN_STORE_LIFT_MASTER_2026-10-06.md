## 10. Flowsint (OSINT) vs ALADDIN · 2026-10-07

**Ссылка:** https://github.com/reconurge/flowsint · сайт flowsint.io · ~9.4k★ · Apache-2.0 · ETHICS.md  
**Что это:** Docker OSINT-платформа (graph Neo4j): ник/email/телефон/кошелёк → связанные аккаунты, breaches, схема. Данные **локально на ПК** (аналитики/журналисты), не семейное iOS-приложение.

### Вердикт для мобильного ALADDIN

| | Решение |
|--|---------|
| Вшить Flowsint / Docker / Maigret «пробить кого угодно» | **SKIP** — слежка, App Review, 152-ФЗ, бренд семьи |
| Идея «мой цифровой след в одном месте» | **ADAPT** — только **свои** / член семьи с согласием |
| Уже наш путь | Privacy Hub + Dark Web (пароль HIBP ✓; email HIBP по ключу) + Академия + `priv-01` brokers |

### Наилучший способ (не клон Flowsint) · **без нового экрана**

**Вердикт 2026-10-07:** отдельный экран «Мой след» **не нужен**. Уже есть:

| Уже есть | Где в приложении |
|----------|------------------|
| Privacy Hub (3 вкладки) | `PrivacyHubScreen` · Dark Web / Очистка / Локация |
| Панель Dark Web + список утечек | `PrivacyHubDarkWebPanel` |
| Форма проверки | sheet `DarkWebDataInputView` |
| Модалка Dark Web | `DarkWebMonitoringModal` (Аналитика) |
| Вход «утечки данных» | Threat category `dataLeaks` → `navigateToPrivacyHub` |
| Пароли (генератор/проверка) | Защита сети → `password_security_agent` |
| Уроки | Академия / Young Defender (deepfake есть) |

**Как улучшить правильно-просто (внутри существующих страниц):**
