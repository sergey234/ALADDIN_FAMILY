## 2. Финальное заключение

**Ещё одно «приложение безопасности» из топов не нужно.** Нужно дожать щит на том, что уже открывается.

Брать **18 рабочих кусков** (волны A–E ниже).  
Не брать: Notion, Tasks, календарь, клавиатуру, хабы Tuya/eero/AT&T, шпионский GPS, скрытую запись, CapCut/Canva/селфи, браузеры, Photomath/Gauth, character.ai/Emochi/Suno, Meituan, 11 клонов чата.

**После второго прохода добавлено то, что раньше выпало:**

1. Кнопка **«Я в порядке»** (Find Phone) — это не геозона. Геозона сама пушит; кнопка — человек нажал.  
2. **Siri / Ярлык «проверь ссылку»** — у нас уже App Intent на журнал голоса, на антифейк — нет.

**После аудита второй ИИ (GO LIFT ADD 2026-10-06) добавлено 4 UX-приёма Bark/Life360/Family Link:**

3. **`fsl-14`** — недельный дайджест: N проверок, M тревог, школьные прибытия (без чтения чатов).  
4. **`fsl-15`** — мягкий статус на карточке: заряд + «был в сети / нажал „я в порядке“» (не GPS 24/7).  
5. **`fsl-16`** — виджет Home Screen «Проверить ссылку» → Hub.  
6. **`gai-07`** — один урок Академии: «лицо на фото могут подделать» (угроза FaceApp/Remini, не генератор).

**Antifake Hub сейчас:** вкладки text · audio · video · call. **Документа нет** → `fsl-01`. API `/api/antifake/check/document` и `AntifakeMediaCheckView(.document)` уже есть. Share Extension — только URL/текст → `fsl-02`.

**Не новый id:** CTA «перед переводом» на главной — дыра **`fws-03`** (в коде в основном на экране 60+), чинить через Wellness, не плодить `fsl-17`.

**`gai-01`:** UI `verdict.sources` уже есть; задача = сервер стабильно отдаёт sources + честный empty state (связь с `fws-04`), не рисовать второй блок.

Не в этот план: Watch, CarPlay, Android, Live Caller ID (`af-H-03` / `eld-h03`), живой психолог, Tuya-хаб, генерация песен, решатель домашки, скрытый трек, клавиатура, второй чат.

Кодовое слово, буфер, SOS, экран после звонка 60+ (`eld-*`) — **уже другие списки**, сюда не тащить.
