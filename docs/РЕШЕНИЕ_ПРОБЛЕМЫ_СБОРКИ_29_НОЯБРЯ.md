### ШАГ 3: Проверка Provisioning Profiles

**Проблема:** Provisioning profiles, которые вы добавили, являются автоматически управляемыми (Xcode managed).

**Решение:**

1. **Если используете автоматическую подпись** → профили будут созданы автоматически
2. **Если используете ручную подпись** → нужны ручные (manually managed) профили

**Как получить ручные профили:**

1. Откройте: https://developer.apple.com/account/resources/profiles/list
2. Создайте новый профиль:
   - **App Store Distribution** для `family.aladdin.ios`
   - **App Store Distribution** для `family.aladdin.ios.packetTunnel` (с Network Extensions)
3. Скачайте профили
4. Закодируйте в base64
5. Обновите секреты `PROVISIONING_PROFILE_APP` и `PROVISIONING_PROFILE_EXTENSION`
