### Реализованные методы:

#### Основные методы мониторинга:

1. ✅ **`monitor_snils(snils: str, user_id: str)`**
   - Валидация СНИЛС
   - Хеширование для безопасного хранения (SHA-256)
   - Проверка в базе мошенников
   - Проверка согласия пользователя (152-ФЗ)
   - Расчет риска

2. ✅ **`monitor_credit_report(user_id: str)`**
   - Проверка согласия пользователя
   - Проверка через НБКИ (заглушка для будущей интеграции)
   - Проверка через ОКБ (заглушка для будущей интеграции)
   - Анализ изменений в кредитном отчете
   - Расчет риска

3. ✅ **`check_fraud_database(snils, passport_series, passport_number)`**
   - Поиск по СНИЛС (по хешу)
   - Поиск по паспортным данным (по хешу)
   - Возвращает список совпадений

4. ✅ **`detect_identity_theft(user_id: str, snils: Optional[str])`**
   - Сбор всех индикаторов
   - Расчет общего риска
   - Генерация алертов
   - Интеграция с ThreatEventBus

#### Методы управления:

5. ✅ **`get_monitoring_status(user_id: Optional[str])`**
   - Получение статуса мониторинга для пользователя или всех

6. ✅ **`stop_monitoring(user_id: str)`**
   - Остановка мониторинга для пользователя

#### Методы 152-ФЗ:

7. ✅ **`give_consent(user_id: str, consent_types: Dict[str, bool], expires_days: int)`**
   - Предоставление согласия на обработку данных
   - Сохранение согласия с датой истечения

8. ✅ **`revoke_consent(user_id: str)`**
   - Отзыв согласия
   - Автоматическое удаление данных пользователя

9. ✅ **`get_alerts(user_id: Optional[str])`**
   - Получение алертов для пользователя или всех

#### Методы ThreatMonitoringInterface:

10. ✅ **`collect_threats()`** - Сбор угроз
11. ✅ **`analyze_threats(threats)`** - Анализ угроз
12. ✅ **`send_alert(alert)`** - Отправка алерта
13. ✅ **`receive_threat_event(event)`** - Получение события
