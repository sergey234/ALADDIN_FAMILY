## ⚠️ ПРОБЛЕМА

### **Что происходит сейчас:**

1. ✅ Когда пользователь открывает **детальные экраны** (Dark Web, Identity Theft и т.д.) → обработка unauthorized **ЕСТЬ**
2. ❌ Когда пользователь **переключает компоненты** на основном экране AdvancedProtectionSettingsScreen → обработки unauthorized **НЕТ**

### **Пример проблемы:**

```
Пользователь → Открывает "Расширенные настройки"
              → Переключает "Telegram Security" 
              → Сервер возвращает 401 Unauthorized
              → ❌ Пользователь видит непонятную ошибку
              → ❌ Не перенаправляется на экран входа
```
