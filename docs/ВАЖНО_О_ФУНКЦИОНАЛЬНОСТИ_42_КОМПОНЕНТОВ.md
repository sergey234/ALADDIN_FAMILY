Для того, чтобы мобильное приложение могло управлять компонентами, на сервере должны быть реализованы:

```

POST /components/enable/{componentId}         - Включить компонент

POST /components/configuration/{componentId} - Обновить настройки
GET  /components/configuration/{componentId} - Получить настройки
```
