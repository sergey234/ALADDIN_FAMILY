## 🎯 ЦЕЛЬ ПРОЕКТА

Реализовать систему отчетов для 7 компонентов защиты в мобильном приложении ALADDIN iOS:
1. Отчеты о вождении (Driving Reports)
2. Мониторинг Dark Web
3. Защита кражи личности (Identity Theft Protection)
4. Пузырь местоположения (Location Bubble)
5. Очистка данных (Data Cleanup)
6. Блокировка трекеров (Anti Tracker)
7. AI категоризация контента (AI Categories)

**Особое требование:** Поддержка систем позиционирования GPS/ГЛОНАСС/Galileo/BeiDou с автоматическим выбором на основе региона пользователя (в России используется ГЛОНАСС).

#### 1.2. ComponentReportCard
**Файл:** `Shared/Components/ComponentReportCard.swift`

**Что это:**
Универсальный компонент для отображения краткой статистики компонента в Аналитике.

**Параметры:**
- `componentId: String` - ID компонента
- `icon: String` - Эмодзи иконка (🚗, 🌑, 🛡️, и т.д.)
- `title: String` - Название компонента
- `metrics: [(String, String)]` - Массив метрик (ключ, значение), максимум 2
- `color: Color` - Цвет для фона иконки
- `badgeCount: Int?` - Количество новых событий (для Badge)
- `onTap: () -> Void` - Обработчик нажатия

**Особенности:**
- Badge отображается только если `badgeCount > 0`
- Анимация нажатия с `spring` эффектом
- Полная поддержка Accessibility (VoiceOver)
- Адаптивный дизайн

**Использование:**
```swift
ComponentReportCard(
    componentId: "driving_reports_agent",
    icon: "🚗",
    title: "Отчеты о вождении",
    metrics: [
        ("Поездок", "12"),
        ("Безопасность", "8.5/10")
    ],
    color: .primaryBlue,
    badgeCount: 3,
    onTap: { showDrivingReportsModal = true }
)
```

#### 1.3. UserSelectorView
**Файл:** `Shared/Components/UserSelectorView.swift`

**Что это:**
Горизонтальный селектор для выбора пользователя/ребенка для просмотра отчетов.

**Параметры:**
- `selectedUserId: Binding<String?>` - Выбранный пользователь
- `users: [UserOption]` - Список пользователей (дети)
- `currentUserId: String` - ID текущего пользователя
- `showCurrentUser: Bool` - Показывать ли "Я" (текущий пользователь)

**Структура UserOption:**
```swift
struct UserOption: Identifiable {
    let id: String
    let name: String
    let role: String // "parent", "child", "teenager", "elderly"
    let avatar: String?
}
```

**Особенности:**
- Горизонтальный ScrollView
- Визуальный индикатор выбранного пользователя (подсветка)
- Автоматические иконки на основе роли
- Сохранение выбора в `@AppStorage`

**Использование:**
```swift
UserSelectorView(
    selectedUserId: $selectedUserId,
    users: children,
    currentUserId: "current",
    showCurrentUser: true
)
```

### 2. МОДЕЛИ ДАННЫХ

#### 2.1. ComponentReportsModels.swift
**Файл:** `Core/Models/ComponentReportsModels.swift`

**Структура моделей:**

##### 2.1.1. Driving Reports
- `DrivingReport` - Отчет о поездке
  - `id`, `userId`, `userName`
  - `startTime`, `endTime`, `startLocation`, `endLocation`
  - `distance`, `duration`, `averageSpeed`, `maxSpeed`
  - `safetyScore` (0-10)
  - `events: [DrivingEvent]` - События (торможение, ускорение, поворот)
  - `violations: [DrivingViolation]` - Нарушения
  - `positioningSystem: String?` - Система позиционирования

- `DrivingStats` - Статистика вождения
  - `totalTrips`, `totalDistance`, `totalDuration`
  - `averageSafetyScore`, `violationsCount`
  - `period`, `positioningSystem`

##### 2.1.2. Dark Web Monitoring
- `DarkWebLeak` - Утечка данных
  - `id`, `dataType` (email, password, phone, bank, passport, snils)
  - `value` (замаскированное), `fullValue` (полное, для отображения)
  - `leakDate`, `discoveryDate`, `source`
  - `severity` (critical, high, medium, low)
  - `status` (new, in_progress, resolved, ignored)
  - `recommendations: [String]`

- `DarkWebStats` - Статистика
  - `totalLeaks`, `newLeaks`, `resolvedLeaks`, `criticalLeaks`
  - `lastScanDate`

##### 2.1.3. Identity Theft Protection
- `IdentityTheftAttempt` - Попытка кражи
  - `id`, `dataType` (passport, snils, bank, other)
  - `requestSource`, `timestamp`
  - `action` (blocked, allowed, suspicious, requires_review)
  - `severity` (critical, high, medium, low)
  - `details: String?`

- `IdentityTheftStats` - Статистика
  - `totalAttempts`, `blockedAttempts`, `suspiciousActivities`
  - `byDataType: [String: Int]`

##### 2.1.4. Privacy Reports
**Location Bubble:**
- `LocationRequest` - Запрос местоположения
  - `id`, `appName`, `timestamp`
  - `action` (blocked, allowed, modified)
  - `accuracy: LocationAccuracy?` (high, medium, low)

- `LocationStats` - Статистика
  - `blockedRequests`, `allowedRequests`, `modifiedRequests`
  - `currentAccuracy`

**Data Cleanup:**
- `DataCleanupRecord` - Запись очистки
  - `id`, `cleanupDate`, `freedSpace` (байты)
  - `categories: [CleanupCategory]`

- `DataCleanupStats` - Статистика
  - `totalFreed`, `lastCleanupDate`, `cleanupsCount`
  - `byCategory: [String: Int64]`

**Anti Tracker:**
- `TrackerBlock` - Заблокированный трекер
  - `id`, `trackerName`, `blockedCount`, `lastBlocked`

- `AntiTrackerStats` - Статистика
  - `totalBlocked`, `blockedThisWeek`, `effectiveness` (0-100%)
  - `topTrackers: [TrackerBlock]`

##### 2.1.5. AI Categories
- `AICategoryReport` - Отчет по категории
  - `id`, `childId?`, `childName?`
  - `category: ContentCategory` (education, games, entertainment, adult, violence, other)
  - `sitesCount`, `blockedCount`

- `AICategoriesStats` - Статистика
  - `totalCategorized`, `totalBlocked`, `accuracy` (0-100%)
  - `byCategory: [String: Int]`
  - `blockedByCategory: [String: Int]`

**Все модели:**
- Реализуют `Codable` для работы с API
- Реализуют `Identifiable` где нужно (для SwiftUI списков)
- Имеют computed properties для форматирования (например, `formattedDistance`, `formattedSafetyScore`)

### 3. СЕРВИСЫ

#### 3.1. PositioningSystemService
**Файл:** `Core/Services/PositioningSystemService.swift`

**Что делает:**
- Определяет регион пользователя
- Автоматически выбирает систему позиционирования на основе региона
- Сохраняет выбор пользователя
- Предоставляет информацию о текущей системе

**Enum PositioningSystem:**
```swift
enum PositioningSystem: String, CaseIterable, Codable {
    case gps = "GPS"
    case glonass = "GLONASS"
    case galileo = "Galileo"
    case beidou = "BeiDou"
    case auto = "Auto"
}
```

**Маппинг регионов:**
- Россия и СНГ → ГЛОНАСС
- Европа → Galileo
- Китай → BeiDou
- Остальные → GPS

**Методы:**
- `determineSystemByRegion() -> PositioningSystem` - Автоматический выбор
- `saveSelectedSystem(_ system: PositioningSystem)` - Сохранение выбора
- `loadSelectedSystem()` - Загрузка сохраненного выбора
- `updateCurrentSystem()` - Обновление текущей системы

**Использование:**
```swift
@StateObject private var positioningService = PositioningSystemService.shared
// Текущая система: positioningService.currentSystem
// Выбранная система: positioningService.selectedSystem
```

func loadReports(userId: String?, period: String) async {
    isLoading = true
    errorMessage = nil
    defer { isLoading = false }
    
    do {
        // Загрузить через API
        let response = try await apiService.getDrivingReports(
            userId: userId,
            period: period
        )

        self.reports = response.reports

    }
}
