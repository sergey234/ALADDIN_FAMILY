# ✅ ЧТО ДЕЛАТЬ ПОСЛЕ СОЗДАНИЯ ПРИЛОЖЕНИЯ В APP STORE CONNECT

**Приложение "ALADDIN X AI" создано! Что дальше?**

---

## 🎯 СЛЕДУЮЩИЕ ШАГИ

### Шаг 1: Загрузить билд (15-30 минут)

**Вариант A: Через Transporter (РЕКОМЕНДУЕТСЯ)**

1. **Скачать Transporter** (если нет):
   - Откройте App Store на Mac
   - Найдите "Transporter"
   - Установите

2. **Экспортировать билд из Xcode:**
   - Откройте Xcode
   - Меню: **Window → Organizer**
   - Выберите ваш Archive
   - Нажмите **"Distribute App"**
   - Выберите **"App Store Connect"**
   - Нажмите **"Next"**
   - Выберите **"Export"** (не Upload!)
   - Сохраните .ipa файл

3. **Загрузить через Transporter:**
   - Откройте Transporter
   - Перетащите .ipa файл в Transporter
   - Нажмите **"Deliver"**
   - Дождитесь загрузки (10-20 минут)

**Вариант B: Через Xcode (если не работает Transporter)**

1. В Organizer выберите Archive
2. Нажмите **"Distribute App"**
3. Выберите **"App Store Connect"**
4. Выберите **"Upload"** (не Export!)
5. Выберите ваше приложение "ALADDIN X AI"
6. Нажмите **"Upload"**
7. Дождитесь загрузки

---

### Шаг 2: Дождаться обработки билда (10-30 минут)

1. В App Store Connect перейдите в ваше приложение
2. Перейдите в раздел **"TestFlight"** или **"App Store"**
3. Найдите секцию **"Build"**
4. Дождитесь, пока билд обработается
5. Статус изменится на **"Ready to Submit"**

---

### Шаг 3: Заполнить метаданные (2-4 часа)

#### 3.1. App Information

1. Перейдите в раздел **"App Store"** (слева)
2. Найдите **"App Information"**
3. Заполните:
   - **Subtitle (RU):** `Защита семьи 24/7`
   - **Subtitle (EN):** `Family Protection 24/7`
   - **Category 1:** Security (Безопасность)
   - **Category 2:** Utilities (Утилиты)
   - **Age Rating:** 4+ (или соответствующий)

#### 3.2. Описание приложения

1. В разделе **"App Store"** выберите **"Russian"**
2. Откройте файл: `docs/APP_STORE_DESCRIPTION.md`
3. Скопируйте раздел **"ОПИСАНИЕ (RU)"**
4. Вставьте в поле **"Description"**
5. То же самое для **"English"**

#### 3.3. Ключевые слова

1. **Russian:**
   - `безопасность, защита, VPN, родительский контроль, антивирус`

2. **English:**
   - `security, protection, VPN, parental control, antivirus`

#### 3.4. Скриншоты

1. Загрузите **8 скриншотов** для iPhone 6.5"
2. Загрузите **8 скриншотов** для iPhone 6.7"
3. Убедитесь, что они в правильном порядке

#### 3.5. Иконка

1. Загрузите иконку **1024x1024 PNG**

#### 3.6. URLs

1. **Privacy Policy:** `https://aladdin-ai.ru/privacy`
2. **Terms of Service:** `https://aladdin-ai.ru/terms`
3. **Support:** `https://aladdin-ai.ru/support`

#### 3.7. Review Notes

1. Откройте файл: `docs/AppStore/APP_STORE_REVIEW_NOTES.md`
2. Скопируйте весь текст
3. Вставьте в **"App Review Information → Notes"**
4. Убедитесь, что указан тестовый код: **ALDN-TEST-1234**

---

### Шаг 4: Финальная проверка (30 минут)

1. Проверьте все метаданные
2. Проверьте Review Notes
3. Проверьте, что билд загружен и обработан

---

### Шаг 5: Submit for Review (10 минут)

1. В разделе **"App Store"** → **"Version"**
2. Найдите секцию **"Build"**
3. Нажмите **"+"** или **"Select a build"**
4. Выберите ваш загруженный билд
5. Внизу нажмите **"Submit for Review"**
6. Подтвердите отправку
