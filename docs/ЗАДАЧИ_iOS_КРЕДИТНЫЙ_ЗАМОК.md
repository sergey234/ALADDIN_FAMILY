## ✅ ЧТО НУЖНО РЕАЛИЗОВАТЬ В iOS

### 1. Экран инструкций по кредитному замку

**Где:** В `IdentityTheftProtectionScreen.swift`  
**Когда показывать:** 
- Когда обнаружена проблема (данные в базе мошенников)
- По запросу пользователя (кнопка "Как заморозить кредитную историю?")

### 2. Содержимое экрана

#### Заголовок и описание:
```
🔒 Кредитный замок

Кредитный замок - это способ защитить себя от мошенников.
Если кредитная история заморожена, никто не может получить
кредит на ваше имя без вашего разрешения.
```

#### Как работает заморозка (объяснение):
```
📋 Как это работает:

1. Вы обращаетесь в НБКИ/ОКБ (с паспортом)
2. Подаете заявление на заморозку
3. Бюро устанавливает флаг "заморожено" в базе
4. Когда банк запрашивает историю → бюро отказывает в доступе
5. Банк не может получить историю → не может выдать кредит
```

#### Пошаговые инструкции:

**Шаг 1: Заморозка в НБКИ**
```
1️⃣ НАЦИОНАЛЬНОЕ БЮРО КРЕДИТНЫХ ИСТОРИЙ (НБКИ)

📋 Что делать:
• Обратиться в НБКИ лично (с паспортом)
• Или через личный кабинет на сайте
• Подать заявление на заморозку кредитной истории

🔗 Сайт: https://www.nbki.ru
📞 Контакты: (указать телефон)
💰 Стоимость: Бесплатно
⏱️ Срок: 1-2 рабочих дня

[Открыть сайт НБКИ]
```

**Шаг 2: Заморозка в ОКБ**
```
2️⃣ ОБЪЕДИНЕННОЕ КРЕДИТНОЕ БЮРО (ОКБ)

📋 Что делать:
• Обратиться в ОКБ лично (с паспортом)
• Или через личный кабинет на сайте
• Подать заявление на заморозку кредитной истории

🔗 Сайт: https://www.okb.ru
📞 Контакты: (указать телефон)
💰 Стоимость: Бесплатно
⏱️ Срок: 1-2 рабочих дня

[Открыть сайт ОКБ]
```

**Шаг 3: Подтверждение**
```
3️⃣ ПОДТВЕРЖДЕНИЕ

После заморозки:
✅ Новые кредиты будут невозможны без вашего разрешения
✅ Мошенники не смогут взять кредит на ваше имя
✅ Вы можете временно разблокировать, когда нужен кредит
```

#### Преимущества:
```
✅ ПРЕИМУЩЕСТВА:

• Защита от мошенников - они не могут взять кредит
• Бесплатно - заморозка и разблокировка бесплатны
• Без ограничений - можно разблокировать в любой момент
• Эффективно - работает сразу после заморозки
```

#### Важные заметки:
```
⚠️ ВАЖНО:

• Рекомендуется заморозить в ОБОИХ бюро (НБКИ и ОКБ)
• Для получения кредита нужно будет временно разблокировать
• Разблокировка занимает 1-2 рабочих дня
• Заморозка работает через бюро - банки получают отказ от бюро
```
