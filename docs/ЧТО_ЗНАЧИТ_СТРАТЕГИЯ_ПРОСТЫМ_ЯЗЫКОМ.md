### Шаг 1: Получить Provisioning Profiles (локально)

**В Xcode:**

#### 1. Открыть проект
- ✅ Открыть `ALADDIN.xcodeproj` или `ALADDIN.xcworkspace`

**Простыми словами:**
- Это как открыть документ в Word
- Открываем проект в Xcode

---

#### 2. Выбрать target "ALADDIN"
- ✅ В левой панели выбрать проект
- ✅ Выбрать target "ALADDIN"

**Простыми словами:**
- Это как выбрать нужный документ
- Выбираем основное приложение

---

#### 3. Signing & Capabilities → Team 6CJVBBUGSN
- ✅ Перейти на вкладку "Signing & Capabilities"
- ✅ Выбрать Team: `6CJVBBUGSN`
- ✅ Поставить галочку "Automatically manage signing"

**Простыми словами:**
- Это как выбрать компанию для подписи
- Xcode автоматически создаст "ключи"

---

#### 4. "Automatically manage signing" — Xcode создаст profiles
- ✅ Xcode автоматически создаст provisioning profiles
- ✅ Они появятся в `~/Library/MobileDevice/Provisioning Profiles/`

**Простыми словами:**
- Это как автоматически получить ключи
- Xcode создаст "ключи" для подписи

---

#### 5. То же для "ALADDINPacketTunnel"
- ✅ Выбрать target "ALADDINPacketTunnel"
- ✅ Повторить те же шаги

**Простыми словами:**
- Это как получить ключи для второй двери
- Нужны "ключи" и для Network Extension

---

### Шаг 2: Добавить в GitHub Secrets

**Экспортировать profiles и добавить в GitHub Secrets.**

**Простыми словами:**
- Это как скопировать ключи и положить в сейф
- Добавляем "ключи" в GitHub, чтобы использовать их при сборке

**Как сделать:**
1. Найти profiles в `~/Library/MobileDevice/Provisioning Profiles/`
2. Закодировать в base64
3. Добавить в GitHub Secrets как `PROVISIONING_PROFILE_APP` и `PROVISIONING_PROFILE_EXTENSION`

---

### Шаг 3: Обновить Workflow

**Использовать готовые profiles для подписи на GitHub Actions.**

**Простыми словами:**
