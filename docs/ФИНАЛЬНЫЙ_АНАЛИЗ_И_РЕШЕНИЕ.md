## 🎯 ПРИЧИНА ПРОБЛЕМЫ

### **Кэширование в мобильном приложении (URLSession)**

**Найдено в `NetworkManager.swift`:**
1. Строка 200: `config.requestCachePolicy = .returnCacheDataElseLoad` ❌
   - Использует кэш, если данные есть в кэше!
   
2. Строка 189-193: Создается `URLCache` с кэшированием
   - 10MB memory, 50MB disk
   
3. В запросах не установлены заголовки `Cache-Control: no-cache`
   - URLSession использует кэш по умолчанию

---

## ✅ РЕШЕНИЕ

### **1. Изменена политика кэширования URLSession:**

**Было:**
```swift
config.requestCachePolicy = .returnCacheDataElseLoad
```

**Стало:**
```swift
config.requestCachePolicy = .reloadIgnoringLocalCacheData
```

### **2. Добавлены заголовки в каждый запрос:**

**Для всех методов (GET, POST, PUT, DELETE, PATCH):**
```swift
request.cachePolicy = .reloadIgnoringLocalCacheData
request.setValue("no-cache", forHTTPHeaderField: "Cache-Control")
request.setValue("no-cache", forHTTPHeaderField: "Pragma")
```

### **3. Отключено кэширование Nginx:**

**В `/etc/nginx/sites-enabled/aladdin-ai.ru`:**
- ✅ `proxy_cache off`
- ✅ `proxy_no_cache 1`
- ✅ `proxy_cache_bypass 1`
- ✅ Заголовки `Cache-Control: no-cache`
