# 📱 ПОДРОБНАЯ ИНСТРУКЦИЯ: Собрать Archive для App Store БЕЗ телефона

**Дата:** 27 ноября 2025  
**Для:** Xcode 13.2.1, iOS 16.7.11 не поддерживается  
**Решение:** Собрать для "Any iOS Device" без подключённого устройства

---

## 🎯 ЧТО МЫ ДЕЛАЕМ

Собираем Archive для App Store **БЕЗ подключения физического iPhone**. Это возможно, потому что для Distribution (App Store) не требуется зарегистрированное устройство.

---

## ✅ ПРЕДВАРИТЕЛЬНЫЕ ТРЕБОВАНИЯ

Перед началом убедитесь, что:

1. ✅ **Xcode установлен** (версия 13.2.1 или любая)
2. ✅ **Проект ALADDIN открыт** в Xcode
3. ✅ **Apple ID авторизован** в Xcode (Settings → Accounts)
4. ✅ **Apple Developer Program оплачен** ($99/год)
5. ✅ **Team ID настроен** (`6CJVBBUGSN`)

---

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ

### **ШАГ 1: Отключить все устройства от Mac** (30 секунд)

1. **Отключите все iPhone/iPad** от Mac:
   - Отсоедините USB-кабели
   - Убедитесь, что в Xcode нет подключённых устройств

2. **Закройте окно "Devices and Simulators"** (если открыто):
   - Нажмите красный крестик в левом верхнем углу окна
   - Или нажмите `Esc`

**Зачем это нужно:**
- Чтобы Xcode не пытался использовать физическое устройство
- Чтобы избежать ошибок с версией iOS

---

### **ШАГ 2: Открыть проект в Xcode** (1 минута)

1. **Откройте Xcode** (если ещё не открыт)

2. **Откройте проект:**
   - **File → Open** (или нажмите `⌘ + O`)
   - Найдите папку с проектом `ALADDIN_iOS`
   - Выберите файл `ALADDIN.xcodeproj`
   - Нажмите **"Open"**

3. **Дождитесь загрузки проекта:**
   - Xcode загрузит проект (10-30 секунд)
   - В левой панели появится структура проекта

---

### **ШАГ 3: Проверить авторизацию Apple ID** (1 минута)

1. **Откройте настройки Xcode:**
   - **Xcode → Settings** (или нажмите `⌘ + ,`)
   - Или **Xcode → Preferences** (в старых версиях)

2. **Перейдите на вкладку "Accounts":**
   - В верхней панели нажмите **"Accounts"**

3. **Проверьте список аккаунтов:**
   - Должен быть ваш **Apple ID** (email)
   - Рядом должно быть написано **"Personal Team"** или **Team ID** (`6CJVBBUGSN`)

4. **Если Apple ID нет:**
   - Нажмите кнопку **"+"** (внизу слева)
   - Выберите **"Apple ID"**
   - Введите ваш **email** и **пароль**
   - Нажмите **"Sign In"**

5. **Если Apple ID есть, но Team не выбран:**
   - Выберите ваш Apple ID в списке
   - Нажмите **"View Details..."**
   - Проверьте, что Team ID правильный (`6CJVBBUGSN`)

6. **Закройте окно Settings** (нажмите красный крестик)

---

### **ШАГ 4: Настроить подпись (Signing)** (2 минуты)

1. **Выберите проект в навигаторе:**
   - В левой панели Xcode найдите **"ALADDIN"** (синяя иконка вверху)
   - **Кликните один раз** на "ALADDIN"

2. **Выберите target "ALADDIN":**
   - В центральной панели, под **"PROJECT"**, найдите **"TARGETS"**
   - Под "TARGETS" найдите **"ALADDIN"**
   - **Кликните один раз** на "ALADDIN"

3. **Перейдите на вкладку "Signing & Capabilities":**
   - В верхней панели центральной области найдите вкладки:
     - General
     - Signing & Capabilities ← **НАЖМИТЕ СЮДА**
     - Build Settings
     - и т.д.

4. **Настройте подпись для target "ALADDIN":**
   - Найдите раздел **"Signing"**
   - ✅ **Отметьте галочку** "Automatically manage signing"
   - В выпадающем списке **"Team"** выберите ваш Apple ID
     - Должно быть написано что-то вроде: `Your Name (6CJVBBUGSN)`
     - Или просто `6CJVBBUGSN`

5. **Проверьте Bundle Identifier:**
   - Должно быть: `family.aladdin.ios`
   - Если другое — исправьте

6. **Настройте подпись для target "ALADDINPacketTunnel":**
   - В левой панели, под "TARGETS", найдите **"ALADDINPacketTunnel"**
   - **Кликните один раз** на "ALADDINPacketTunnel"
   - Перейдите на вкладку **"Signing & Capabilities"**
   - ✅ **Отметьте галочку** "Automatically manage signing"
   - В выпадающем списке **"Team"** выберите тот же Apple ID
   - Проверьте Bundle Identifier: `family.aladdin.ios.packetTunnel`

7. **Если появились ошибки подписи:**
   - Подождите 10-20 секунд — Xcode может автоматически создать профили
   - Если ошибки остались — см. раздел "Решение проблем" ниже

---

### **ШАГ 5: Выбрать "Any iOS Device (arm64)"** (30 секунд)

**Это самый важный шаг!**

1. **Найдите выпадающий список устройств:**
   - В **верхней панели Xcode**, слева от кнопок Run/Stop
   - Вы увидите что-то вроде:
     ```
     [▶️] [ALADDIN ▾] [iPhone 13 ▾]
     ```
     Где `[iPhone 13 ▾]` — это выпадающий список устройств

2. **Нажмите на выпадающий список устройств:**
   - Кликните на `[iPhone 13 ▾]` (или что там написано)

3. **Выберите "Any iOS Device (arm64)":**
   - В выпадающем списке найдите раздел **"iOS Device"**
   - Внутри этого раздела найдите **"Any iOS Device (arm64)"**
   - **Кликните на "Any iOS Device (arm64)"**

   **Как это выглядит:**
   ```
   iOS Device
     ├─ Any iOS Device (arm64) ← ВЫБЕРИТЕ ЭТО
     ├─ iPhone (если подключён)
     └─ iPad (если подключён)
   
   iOS Simulator
     ├─ iPhone 13
     ├─ iPhone 12
     └─ ...
   ```

4. **Проверьте, что выбрано правильно:**
   - В верхней панели должно быть написано: `[Any iOS Device (arm64) ▾]`
   - **НЕ должно быть:**
     - ❌ `[iPhone 13 ▾]` (физическое устройство)
     - ❌ `[iPhone 13 Simulator ▾]` (симулятор)
   - ✅ **Должно быть:** `[Any iOS Device (arm64) ▾]`

---

### **ШАГ 6: Очистить проект** (1 минута)

1. **Очистите Build Folder:**
   - В меню Xcode: **Product → Clean Build Folder**
   - Или нажмите горячую клавишу: `Shift + ⌘ + K`

2. **Дождитесь завершения:**
   - В нижней панели Xcode появится сообщение "Clean Succeeded"
   - Это займёт 10-30 секунд

**Зачем это нужно:**
- Удаляет старые файлы сборки
- Избегает проблем с кэшем
- Гарантирует чистую сборку

---

### **ШАГ 7: Собрать проект (Build)** (2-5 минут)

1. **Соберите проект:**
   - В меню Xcode: **Product → Build**
   - Или нажмите горячую клавишу: `⌘ + B`

2. **Дождитесь завершения сборки:**
   - В нижней панели Xcode появится прогресс
   - Должно появиться сообщение **"Build Succeeded"** ✅
   - Если есть ошибки — исправьте их перед продолжением

3. **Проверьте, что нет ошибок:**
   - В нижней панели Xcode не должно быть красных крестиков
   - Если есть ошибки — см. раздел "Решение проблем"

**Зачем это нужно:**
- Проверяет, что проект компилируется без ошибок
- Убеждается, что подпись настроена правильно
- Готовит проект к созданию Archive

---

### **ШАГ 8: Создать Archive** (5-15 минут)

1. **Создайте Archive:**
   - В меню Xcode: **Product → Archive**
   - Или используйте горячую клавишу: `⌘ + B` (после выбора "Any iOS Device")

2. **Дождитесь завершения:**
   - В нижней панели Xcode появится прогресс сборки
   - Это займёт **5-15 минут** (в зависимости от размера проекта)
   - Вы увидите сообщения типа:
     ```
     Building...
     Compiling...
     Linking...
     ```

3. **После завершения:**
   - Откроется окно **Organizer** с вашим архивом
   - В списке архивов появится новый архив с текущей датой и временем
   - Рядом с архивом будет зелёная галочка ✅

4. **Если появилась ошибка:**
   - См. раздел "Решение проблем" ниже
   - Чаще всего это ошибки подписи или provisioning profiles

---

### **ШАГ 9: Экспортировать IPA** (2-3 минуты)

1. **В окне Organizer выберите ваш архив:**
   - Кликните один раз на самый свежий архив (верхний в списке)

2. **Нажмите "Distribute App":**
   - В правой части окна Organizer найдите кнопку **"Distribute App"**
   - **Кликните на неё**

3. **Выберите метод распространения:**
   - Появится окно с вариантами:
     - App Store Connect
     - Ad Hoc
     - Enterprise
     - Development
   - **Выберите "App Store Connect"**
   - Нажмите **"Next"**

4. **Выберите опции распространения:**
   - Появится окно с опциями:
     - ✅ **"Upload your app's symbols"** (если есть) — оставьте включённым
     - ✅ **"Manage Version and Build Number"** — можно включить
   - Нажмите **"Next"**

5. **Проверьте информацию:**
   - Появится окно с информацией о подписи
   - Проверьте, что Team правильный (`6CJVBBUGSN`)
   - Нажмите **"Next"**

6. **Начните загрузку:**
   - Появится окно с прогрессом
   - Нажмите **"Upload"**
   - Дождитесь завершения загрузки (2-5 минут)

7. **После завершения:**
   - Появится сообщение **"Upload Succeeded"** ✅
   - Нажмите **"Done"**

---

### **ШАГ 10: Проверить в App Store Connect** (1 минута)

1. **Откройте App Store Connect:**
   - Зайдите на: https://appstoreconnect.apple.com
   - Войдите в ваш Apple ID

2. **Найдите ваше приложение:**
   - **My Apps → ALADDIN**

3. **Проверьте билд:**
   - Перейдите на вкладку **"TestFlight"** (или **"App Store" → "Versions"**)
   - Проверьте, что билд появился в списке
   - Статус может быть "Processing" (обработка) — это нормально

4. **Дождитесь обработки:**
   - Обработка билда занимает **10-30 минут**
   - После обработки статус изменится на "Ready to Submit"

## ⚠️ РЕШЕНИЕ ПРОБЛЕМ

### **Проблема 1: "No profiles for 'family.aladdin.ios' were found"**

**Причина:** Apple требует хотя бы одно зарегистрированное устройство для создания Development Provisioning Profile.

**Решение:**

#### **Вариант A: Зарегистрировать устройство вручную через Apple Developer Portal**

1. **Зайдите на:** https://developer.apple.com/account/resources/devices/list
2. **Нажмите "+"** (добавить устройство)
3. **Введите:**
   - **Name:** любое имя (например, "Test Device" или "Virtual Device")
   - **UDID:** можно взять из Xcode → Window → Devices and Simulators (если устройство подключено)
     - Или используйте любой UDID (для Development профиля это не критично)
     - Формат UDID: `12345678-1234-1234-1234-123456789ABC`
4. **Нажмите "Continue"** → **"Register"**
5. **Вернитесь в Xcode:**
   - Xcode → Settings → Accounts
   - Выберите ваш Apple ID
   - Нажмите **"Download Manual Profiles"** (или кнопку обновления)
6. **Попробуйте Archive снова**

#### **Вариант B: Использовать Distribution Profile**

1. **В Xcode:** Signing & Capabilities
2. **Снимите галочку** "Automatically manage signing"
3. **Выберите "Manual"** в разделе Signing
4. **Выберите Distribution Profile** (если есть)
   - Если нет — создайте на developer.apple.com
5. **Попробуйте Archive**

---

### **Проблема 2: "No signing certificate"**

**Решение:**

1. **Зайдите на:** https://developer.apple.com/account/resources/certificates/list
2. **Проверьте, есть ли Distribution Certificate:**
   - Должен быть сертификат типа **"Apple Distribution"**
3. **Если нет — создайте:**
   - Нажмите **"+"**
   - Выберите **"Apple Distribution"**
   - Следуйте инструкциям (нужно будет создать CSR в Keychain Access)
4. **Вернитесь в Xcode:**
   - Xcode → Settings → Accounts
   - Выберите ваш Apple ID
   - Нажмите **"Download Manual Profiles"**

---

### **Проблема 3: Archive не создаётся или кнопка неактивна**

**Решение:**

1. **Проверьте, что выбрано "Any iOS Device (arm64)":**
   - В верхней панели должно быть: `[Any iOS Device (arm64) ▾]`
   - Если нет — выберите его

2. **Проверьте, что нет ошибок компиляции:**
   - Product → Build (`⌘ + B`)
   - Должно быть "Build Succeeded"
   - Если есть ошибки — исправьте их

3. **Очистите проект:**
   - Product → Clean Build Folder (`Shift + ⌘ + K`)
   - Попробуйте Archive снова

---

### **Проблема 4: "Bundle ID not found"**

**Решение:**

1. **Зайдите на:** https://developer.apple.com/account/resources/identifiers/list
2. **Проверьте, зарегистрирован ли Bundle ID:**
   - Должен быть `family.aladdin.ios`
   - И `family.aladdin.ios.packetTunnel`
3. **Если нет — создайте:**
   - Нажмите **"+"**
   - Выберите **"App IDs"**
   - Введите Bundle ID: `family.aladdin.ios`
   - Включите необходимые Capabilities (Personal VPN, Network Extensions)
   - Нажмите **"Continue"** → **"Register"**
4. **Повторите для `family.aladdin.ios.packetTunnel`**

---

### **Проблема 5: "Xcode will continue when iPhone is unlocked"**

**Решение:**

1. **Отключите все iPhone от Mac** (отсоедините кабели)
2. **Выберите "Any iOS Device (arm64)"** в Xcode
3. **Попробуйте Archive снова**
