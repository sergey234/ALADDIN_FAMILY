## 🎯 ПРОБЛЕМА

При обновлении токена через `refreshToken()` или `registerDeviceAnonymously()` нужно **сохранить информацию о тарифе**:
- `subscriptionLevel` (trial, free, personal, family, premium)
- `trialInfo` (даты начала/окончания trial)
- `limits` (лимиты функций)
- `components` (доступные компоненты)

**Вопрос:** Нужно ли согласовывать токен с тарифами? Как это сделать комфортно?

## 📊 ТЕКУЩАЯ АРХИТЕКТУРА

### **1. Структура JWT токена:**

```swift
struct JWTToken: Codable, Equatable {
    let token: String                    // Access token
    let deviceId: String                 // Device ID
    let subscriptionLevel: SubscriptionLevel  // ✅ ТАРИФ
    let trialInfo: TrialInfo?            // ✅ TRIAL ИНФОРМАЦИЯ
    let expiresAt: Date                  // Срок действия токена
    let issuedAt: Date                   // Дата выдачи
    let issuer: String                   // Кто выдал
    let limits: SubscriptionLimits      // ✅ ЛИМИТЫ ТАРИФА
    let components: [String]             // ✅ ДОСТУПНЫЕ КОМПОНЕНТЫ
}
```

### **2. Тарифы (5 уровней):**

```
1. TRIAL (14 дней) - 114 функций (80%)
2. FREE (0₽) - 26 функций (18%)
3. PERSONAL (100₽) - 69 функций (49%)
4. FAMILY (290₽) - 128 функций (90%)
5. PREMIUM (490₽) - 142 функции (100%) + 42 компонента
```

### **3. Как работает сейчас:**

#### **При регистрации устройства (`registerDeviceAnonymously`):**

## ⚠️ ПРОБЛЕМЫ ТЕКУЩЕЙ РЕАЛИЗАЦИИ

### **Проблема #1: Потеря тарифа при перерегистрации**

**Сценарий:**
1. Пользователь купил тариф PERSONAL (100₽/месяц)
2. Токен истекает
3. `TokenHealthMonitor` вызывает `registerDeviceAnonymously()`
4. Сервер создает новое устройство с тарифом FREE (по умолчанию)
5. ❌ **Пользователь теряет купленный тариф!**

**Причина:**
- `registerDeviceAnonymously()` создает новое устройство
- Новое устройство получает тариф по умолчанию (FREE)
- Информация о купленном тарифе не передается

---

### **Проблема #2: Потеря trial информации**

**Сценарий:**
1. Пользователь в trial периоде (осталось 10 дней)
2. Токен истекает
3. `registerDeviceAnonymously()` создает новое устройство
4. ❌ **Trial информация теряется, пользователь не может использовать trial**

**Причина:**
- Trial привязан к устройству
- Новое устройство = новый trial (если еще не использован)
- Или потеря trial, если уже использован

---

### **Проблема #3: RefreshToken не сохраняет тариф**

**Сценарий:**
1. Пользователь с тарифом PREMIUM
2. `refreshToken()` обновляет access_token
3. ❌ **Если refresh_token не содержит информацию о тарифе - тариф может потеряться**

**Причина:**
- `RefreshTokenResponse` содержит только `access_token` и `refresh_token`
- Информация о тарифе должна быть в новом access_token (JWT payload)
- Нужно декодировать JWT и извлечь информацию о тарифе

## ✅ РЕШЕНИЕ: СОГЛАСОВАНИЕ ТОКЕНА С ТАРИФАМИ

### **Вариант #1: RefreshToken сохраняет тариф (РЕКОМЕНДУЕТСЯ)**

**Логика:**
1. При `refreshToken()` новый access_token содержит информацию о тарифе в JWT payload
2. Декодируем JWT и извлекаем `subscriptionLevel`, `trialInfo`, `limits`
3. Сохраняем в `SubscriptionManager` с сохранением тарифа

**Преимущества:**
- ✅ Тариф сохраняется при обновлении
- ✅ Trial информация сохраняется
- ✅ Быстро (один запрос)
- ✅ Стандартный OAuth 2.0 подход

**Недостатки:**
- ⚠️ Нужно декодировать JWT на клиенте
- ⚠️ Зависит от сервера (должен включать тариф в JWT)

---

### **Вариант #2: Fallback сохраняет тариф**

**Логика:**
1. При `registerDeviceAnonymously()` проверяем текущий тариф
2. Если тариф не FREE - запрашиваем тариф с сервера
3. Сохраняем тариф в новом токене

**Преимущества:**
- ✅ Работает даже если refreshToken не содержит тариф
- ✅ Надежно (fallback всегда работает)

**Недостатки:**
- ⚠️ Дополнительный запрос к серверу
- ⚠️ Медленнее

---

### **Вариант #3: Гибридный подход (ЛУЧШИЙ)**

**Логика:**
1. **Сначала пробуем `refreshToken()`:**
   - Декодируем JWT и извлекаем тариф
   - Если тариф есть - сохраняем
   - Если тарифа нет - запрашиваем с сервера

2. **Если refreshToken не работает - fallback:**
   - Проверяем текущий тариф в `SubscriptionManager`
   - Если тариф не FREE - запрашиваем с сервера
   - Сохраняем тариф в новом токене

**Преимущества:**
- ✅ Максимальная надежность
- ✅ Тариф всегда сохраняется
- ✅ Быстро в большинстве случаев
- ✅ Работает даже при ошибках

**Недостатки:**
- ⚠️ Сложнее реализация
- ⚠️ Нужно декодировать JWT

## 🔧 РЕАЛИЗАЦИЯ: ГИБРИДНЫЙ ПОДХОД

### **ШАГ 1: Декодирование JWT для извлечения тарифа**

```swift
/// Декодировать JWT и извлечь информацию о тарифе
private func extractSubscriptionFromJWT(_ token: String) -> (SubscriptionLevel, TrialInfo?, SubscriptionLimits, [String])? {
    // Декодируем JWT payload
    let parts = token.split(separator: ".")
    guard parts.count == 3 else { return nil }
    
    // Декодируем payload (base64)
    guard let payloadData = Data(base64Encoded: String(parts[1]), options: .ignoreUnknownCharacters),
          let payload = try? JSONDecoder().decode(JWTPayload.self, from: payloadData) else {
        return nil
    }
    
    // Извлекаем информацию о тарифе
    let subscriptionLevel = SubscriptionLevel(rawValue: payload.subscription.level) ?? .free
    let trialInfo = payload.subscription.trialInfo
    let limits = payload.subscription.limits
    let components = payload.subscription.components
    
    return (subscriptionLevel, trialInfo, limits, components)
}
```

### **ШАГ 2: Сохранение тарифа при обновлении токена**

```swift
/// Сохранить новый токен с сохранением тарифа
private func saveNewToken(_ response: RefreshTokenResponse, preserveSubscription: Bool = true) async {
    logger.business("💾 DEFENSIVE JWT: Сохранение нового токена")
    
    // 1. Сохраняем access_token в AppConfig
    AppConfig.authToken = response.access_token
    
    // 2. Декодируем JWT и извлекаем тариф
    if preserveSubscription {
        if let (level, trialInfo, limits, components) = extractSubscriptionFromJWT(response.access_token) {
            // ✅ ТАРИФ НАЙДЕН В JWT - сохраняем
            let expiresAt = Date().addingTimeInterval(response.expires_in ?? 86400)
            let jwtToken = JWTToken(
                token: response.access_token,
                deviceId: currentToken?.deviceId ?? UIDevice.current.identifierForVendor?.uuidString ?? "",
                subscriptionLevel: level,  // ✅ СОХРАНЯЕМ ТАРИФ
                trialInfo: trialInfo,       // ✅ СОХРАНЯЕМ TRIAL
                expiresAt: expiresAt,
                issuedAt: Date(),
                issuer: "aladdin_server",
                limits: limits,            // ✅ СОХРАНЯЕМ ЛИМИТЫ
                components: components     // ✅ СОХРАНЯЕМ КОМПОНЕНТЫ
            )
            await SubscriptionManager.shared.storeToken(jwtToken)
            logger.business("✅ DEFENSIVE JWT: Токен сохранен с тарифом: \(level)")
        } else {
            // ⚠️ ТАРИФ НЕ НАЙДЕН В JWT - запрашиваем с сервера
            await fetchSubscriptionFromServer()
        }
    }
}
```

### **ШАГ 3: Запрос тарифа с сервера (fallback)**

```swift
/// Запросить информацию о тарифе с сервера
private func fetchSubscriptionFromServer() async {
    logger.business("🔄 DEFENSIVE JWT: Запрос тарифа с сервера")
    
    // Запрашиваем статус подписки
    APIService.shared.getSubscriptionStatus { result in
        switch result {
        case .success(let status):
            // Обновляем тариф в SubscriptionManager
            await SubscriptionManager.shared.updateSubscriptionStatus(status)
            logger.business("✅ DEFENSIVE JWT: Тариф обновлен с сервера: \(status.level)")
        case .failure(let error):
            logger.error("❌ DEFENSIVE JWT: Ошибка запроса тарифа: \(error)")
            // Используем текущий тариф из SubscriptionManager
            logger.business("⚠️ DEFENSIVE JWT: Используем текущий тариф из локального хранилища")
        }
    }
}
```

### **ШАГ 4: Сохранение тарифа при fallback**

```swift
/// Fallback: registerDeviceAnonymously с сохранением тарифа
private func performEmergencyReRegistration() async {
    logger.business("🚑 DEFENSIVE JWT: Экстренная перерегистрация с сохранением тарифа")
    
    // 1. Сохраняем текущий тариф
    let currentLevel = await SubscriptionManager.shared.getCurrentLevel()
    let currentTrial = await SubscriptionManager.shared.trialStatus
    
    // 2. Выполняем перерегистрацию
    do {
        try await SubscriptionManager.shared.registerDeviceAnonymously()
        
        // 3. Проверяем, сохранился ли тариф
        let newLevel = await SubscriptionManager.shared.getCurrentLevel()
        
        if newLevel != currentLevel && currentLevel != .free {
            // ⚠️ ТАРИФ ИЗМЕНИЛСЯ - запрашиваем с сервера
            logger.business("⚠️ DEFENSIVE JWT: Тариф изменился после перерегистрации, запрашиваем с сервера")
            await fetchSubscriptionFromServer()
        } else {
            logger.business("✅ DEFENSIVE JWT: Тариф сохранен: \(currentLevel)")
        }
    } catch {
        logger.error("❌ DEFENSIVE JWT: Ошибка перерегистрации: \(error)")
    }
}
```
