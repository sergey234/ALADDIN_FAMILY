#### **Задача 1.1: Создать метод `refreshTokenWithRetry()`**

**Файл:** `Core/Managers/TokenHealthMonitor.swift`

**Что делает:**
- Вызывает `APIService.refreshToken()` с обработкой ошибок
- Возвращает `RefreshTokenResponse` или выбрасывает ошибку

**Код:**
```swift
/// Обновить токен через refresh_token с обработкой ошибок
private func refreshTokenWithRetry(refreshToken: String, attempt: Int) async throws -> RefreshTokenResponse {
    logger.business("🔄 DEFENSIVE JWT: Попытка \(attempt): обновление через refresh_token")
    
    return try await withCheckedThrowingContinuation { (continuation: CheckedContinuation<RefreshTokenResponse, Error>) in
        APIService.shared.refreshToken(refreshToken: refreshToken) { result in
            continuation.resume(with: result)
        }
    }
}
```

**Критерии готовности:**
- ✅ Метод создан
- ✅ Обрабатывает ошибки
- ✅ Логирует попытки

#### **Задача 1.2: Создать метод `saveNewToken()`**

**Файл:** `Core/Managers/TokenHealthMonitor.swift`

**Что делает:**
- Сохраняет новый access_token в `AppConfig.authToken`
- Сохраняет новый refresh_token в Keychain (если получен)
- Обновляет токен в `SubscriptionManager`
- Перезапускает мониторинг

**Код:**
```swift
/// Сохранить новый токен во все хранилища
private func saveNewToken(_ response: RefreshTokenResponse) async {
    logger.business("💾 DEFENSIVE JWT: Сохранение нового токена")
    
    // 1. Сохраняем access_token в AppConfig (для всех API запросов)
    AppConfig.authToken = response.access_token
    logger.business("✅ DEFENSIVE JWT: Access token сохранен в AppConfig.authToken")
    
    // 2. Сохраняем refresh_token в Keychain (если получен)
    if let newRefreshToken = response.refresh_token, !newRefreshToken.isEmpty {
        KeychainManager.shared.save(newRefreshToken, forKey: .refreshToken)
        logger.business("✅ DEFENSIVE JWT: Refresh token сохранен в Keychain")
    }
    
    // 3. Обновляем токен в SubscriptionManager
    if let currentToken = await SubscriptionManager.shared.currentToken {
        let expiresAt = Date().addingTimeInterval(response.expires_in ?? 86400) // 24 часа по умолчанию
        let updatedToken = JWTToken(
            token: response.access_token,
            deviceId: currentToken.deviceId,
            subscriptionLevel: currentToken.subscriptionLevel,
            trialInfo: currentToken.trialInfo,
            expiresAt: expiresAt,
            issuedAt: Date(),
            issuer: currentToken.issuer,
            limits: currentToken.limits
        )
        await SubscriptionManager.shared.storeToken(updatedToken)
        logger.business("✅ DEFENSIVE JWT: Токен обновлен в SubscriptionManager")
    }
    
    // 4. Перезапускаем мониторинг для нового токена
    TokenHealthMonitor.shared.startMonitoring()
    logger.business("✅ DEFENSIVE JWT: Мониторинг перезапущен")
}
```

**Критерии готовности:**
- ✅ Метод создан
- ✅ Сохраняет токен во все хранилища
- ✅ Перезапускает мониторинг

### **ЭТАП 2: Реализация умного гибрида**

#### **Задача 2.1: Обновить метод `performProactiveRefresh()`**

**Файл:** `Core/Managers/TokenHealthMonitor.swift`

**Что делает:**
- Реализует логику умного гибрида
- Пробует refreshToken() с retry
- Использует fallback при необходимости

**Код:**
```swift
private func performProactiveRefresh() async {
    logger.business("🔄 DEFENSIVE JWT: Executing smart hybrid token refresh")
    
    // ШАГ 1: Пробуем refreshToken() с retry
    if let refreshToken = KeychainManager.shared.loadString(forKey: .refreshToken),
       !refreshToken.isEmpty {
        logger.business("🔄 DEFENSIVE JWT: Refresh token найден, пробуем обновление")
        
        // Попытка 1
        do {
            let response = try await refreshTokenWithRetry(refreshToken: refreshToken, attempt: 1)
            await saveNewToken(response)
            logger.business("✅ DEFENSIVE JWT: Токен успешно обновлен через refresh_token (попытка 1)")
            return // Успех!
        } catch {
            logger.business("⚠️ DEFENSIVE JWT: Попытка 1 не удалась: \(error.localizedDescription)")
            logger.business("🔄 DEFENSIVE JWT: Выполняем retry (попытка 2) через 2 секунды...")
            
            // Попытка 2 (retry с задержкой)
            do {
                try await Task.sleep(nanoseconds: 2_000_000_000) // 2 секунды
                let response = try await refreshTokenWithRetry(refreshToken: refreshToken, attempt: 2)
                await saveNewToken(response)
                logger.business("✅ DEFENSIVE JWT: Токен успешно обновлен через refresh_token (попытка 2)")
                return // Успех!
            } catch {
                logger.business("⚠️ DEFENSIVE JWT: Попытка 2 не удалась: \(error.localizedDescription)")
                logger.business("🔄 DEFENSIVE JWT: Обе попытки не удались, используем fallback")
            }
        }
    } else {
        logger.business("⚠️ DEFENSIVE JWT: Refresh token не найден, используем fallback")
    }
    
    // ШАГ 2: Fallback - registerDeviceAnonymously()
    logger.business("🔄 DEFENSIVE JWT: Используем перерегистрацию устройства как fallback")
    await performEmergencyReRegistration()
}
```

**Критерии готовности:**
- ✅ Логика умного гибрида реализована
- ✅ Retry работает (2 попытки)
- ✅ Fallback работает
- ✅ Логирование всех шагов

### **Обработка ошибок:**

**Типы ошибок:**
1. **NetworkError.unauthorized** - refresh_token истек или невалиден
2. **NetworkError.timeout** - таймаут запроса
3. **NetworkError.noConnection** - нет интернета
4. **NetworkError.serverError** - ошибка сервера

**Логика обработки:**
- Все ошибки логируются
- При любой ошибке используется fallback
- Пользователь не видит ошибок (бесшовное обновление)
