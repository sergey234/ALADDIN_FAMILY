### **Симптом 1: Таймаут при подключении**
```
❌ [JWT-014] Ошибка получения токена: HTTPSConnectionPool(host='aladdin-ai.ru', port=443): Read timed out. (read timeout=60)
```

**Причина:**
- После перезапуска gunicorn сервер может еще не быть готов принимать запросы
- Возможны проблемы с сетью/SSL
- Сервер может быть перегружен

**Решение:**
- Подождать 1-2 минуты после перезапуска
- Проверить доступность сервера
- Проверить логи сервера

## 🔍 АНАЛИЗ ПРОБЛЕМЫ

### **Почему все еще 401 ошибки?**

**Возможные причины:**

1. **Сервер не полностью перезапустился**
   - Gunicorn перезапущен, но процессы еще не готовы
   - Старый код все еще в памяти

2. **Токен создается с другим секретом**
   - Нужно проверить где создается токен (`auth_router.py`)
   - Возможно используется старый секрет

3. **Кэширование**
   - Python может кэшировать модули
   - Требуется полный перезапуск

4. **Проблемы с конкретными роутерами**
   - Components router
   - Analytics router (уже исправлен, но может быть кэш)
   - Protection router
   - Family router
   - Referral router

### **ШАГ 2: Полный перезапуск сервера**

```bash
# Остановить все процессы
pkill -f gunicorn
pkill -f uvicorn

# Подождать 5 секунд
sleep 5

# Запустить заново
cd /opt/aladdin-backend
source venv/bin/activate
gunicorn --config gunicorn.conf.py --bind 0.0.0.0:8002 --log-level info --access-logfile /opt/aladdin-backend/logs/access.log --error-logfile /opt/aladdin-backend/logs/error.log main:app
```

