```python

    "emergency_api_url": "https://api.112.ru/emergency/call",  # URL API 112
    "emergency_api_key": "your-api-key",  # API ключ (если требуется)

}
```

**Режимы работы:**
1. **Режим логирования (по умолчанию):**
   - Логирует вызов экстренной службы
   - Не требует доступа к API
   - Подходит для разработки и тестирования

2. **Режим реального API:**
   - Отправляет HTTP POST запрос в API 112
   - Требует `emergency_api_enabled=True` и `emergency_api_url`
   - Обрабатывает ответ API
   - Обрабатывает ошибки и таймауты
