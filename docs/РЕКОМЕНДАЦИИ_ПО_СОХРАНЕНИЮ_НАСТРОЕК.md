## 🎯 ОБЩАЯ СТРАТЕГИЯ

### Принцип "Локально + Синхронизация"

1. **Локальное сохранение (мгновенно)**
   - Использовать `@AppStorage` для простых типов (Bool, String, Int, Double)
   - Использовать `UserDefaults` для сложных структур (массивы, словари)
   - Сохранять при каждом изменении

2. **Синхронизация с сервером (в фоне)**
   - Использовать `ComponentConfigurationService` для сохранения на сервере
   - Не блокировать UI при сохранении
   - Обрабатывать ошибки gracefully

3. **Загрузка при открытии**
   - Сначала загружать из локального хранилища (быстро)
   - Затем синхронизировать с сервером (если доступно)
   - Применять настройки из сервера, если они новее

## 📝 ПАТТЕРН РЕАЛИЗАЦИИ

### Для модальных окон настроек:

```swift
struct ComponentSettingsModal: View {
    let componentId: String
    @Binding var isPresented: Bool
    
    // ✅ Использовать @AppStorage для каждого параметра
    @AppStorage("component_\(componentId)_setting1") private var setting1: Bool = false
    @AppStorage("component_\(componentId)_setting2") private var setting2: Bool = true
    @AppStorage("component_\(componentId)_setting3") private var setting3: String = "medium"
    
    @StateObject private var configurationService = ComponentConfigurationService.shared
    @StateObject private var toastManager = ToastManager.shared
    
    var body: some View {
        // ... UI ...
        .onAppear {
            loadSettings()
        }
    }
    
    // ✅ Загрузка настроек при открытии
    private func loadSettings() {
        // Настройки уже загружены через @AppStorage
        // Но можно синхронизировать с сервером
        Task {
            do {
                let config = try await configurationService.getConfiguration(for: componentId)
                // Применить настройки из сервера, если они есть
                if let serverSetting1 = config.settings["setting1"] as? Bool {
                    setting1 = serverSetting1
                }
            } catch {
                // Использовать локальные настройки (@AppStorage)
            }
        }
    }
    
    // ✅ Сохранение настроек
    private func saveSettings() {
        Task {
            do {
                // 1. Создать конфигурацию
                let config = ComponentConfiguration(
                    componentId: componentId,
                    settings: [
                        "setting1": setting1,
                        "setting2": setting2,
                        "setting3": setting3
                    ]
                )
                
                // 2. Сохранить через сервис (синхронизация с сервером)
                try await configurationService.saveConfiguration(
                    componentId: componentId,
                    configuration: config
                )
                
                // 3. Показать успех
                await MainActor.run {
                    toastManager.showSuccess("Настройки сохранены")
                    isPresented = false
                }
            } catch {
                // Настройки уже сохранены локально через @AppStorage
                // Показать предупреждение, но не ошибку
                await MainActor.run {
                    toastManager.showSuccess("Настройки сохранены локально")
                    isPresented = false
                }
            }
        }
    }
}
```

// ✅ Для Set<String> использовать UserDefaults
@State private var selectedRegions: Set<String> = []

// Загружать/сохранять через UserDefaults
private func loadRegions() {
    if let data = UserDefaults.standard.data(forKey: "component_child_protection_selected_regions"),
       let regions = try? JSONDecoder().decode(Set<String>.self, from: data) {
        selectedRegions = regions
    }
}

private func saveRegions() {
    if let data = try? JSONEncoder().encode(selectedRegions) {
        UserDefaults.standard.set(data, forKey: "component_child_protection_selected_regions")
    }
}

    // Сохранить регионы

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### 1. @AppStorage не работает с динамическими ключами

**Проблема:**
```swift
// ❌ НЕ РАБОТАЕТ
@AppStorage("component_\(componentId)_setting") private var setting: Bool = false
```

**Решение:**
```swift
// ✅ РАБОТАЕТ - использовать конкретный ключ
@AppStorage("component_phishing_protection_agent_block_suspicious_links") 
private var blockSuspiciousLinks: Bool = true

// ИЛИ использовать UserDefaults напрямую
private var setting: Bool {
    get {
        UserDefaults.standard.bool(forKey: "component_\(componentId)_setting")
    }
    set {
        UserDefaults.standard.set(newValue, forKey: "component_\(componentId)_setting")
    }
}
```

### 2. Для сложных типов (Set, Array, Dictionary)

**Использовать UserDefaults с JSON encoding:**
```swift
// Сохранение
if let data = try? JSONEncoder().encode(selectedRegions) {
    UserDefaults.standard.set(data, forKey: "key")
}

// Загрузка
if let data = UserDefaults.standard.data(forKey: "key"),
   let regions = try? JSONDecoder().decode(Set<String>.self, from: data) {
    selectedRegions = regions
}
```

### 3. Синхронизация с сервером

**Не блокировать UI:**
- Сохранять локально сразу
- Синхронизировать в фоне
- Не показывать ошибку, если синхронизация не удалась (настройки сохранены локально)
