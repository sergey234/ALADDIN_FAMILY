# 🎯 ГДЕ НАЖАТЬ "RUN WORKFLOW" - ПОШАГОВАЯ ИНСТРУКЦИЯ

**Цель:** Найти и нажать кнопку "Run workflow" в GitHub Actions

---

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ С КАРТИНКОЙ

### Шаг 1: Открыть страницу workflow

1. **Откройте браузер**
2. **Перейдите по ссылке:**
   - https://github.com/sergey234/ALADDIN_FAMILY/actions/workflows/build-only.yml

### Шаг 2: Найти кнопку "Run workflow"

**Где искать:**
- **Справа вверху** страницы
- **Над списком** запущенных workflows
- **Большая синяя/зелёная кнопка** с текстом "Run workflow"

**Как выглядит:**
```
┌─────────────────────────────────────────┐
│  Build Only (No Upload)                  │
│                                           │
│  [Run workflow]  ← ВОТ ЭТА КНОПКА!      │
│                                           │
│  All workflow runs                        │
│  ─────────────────────────────────────   │
│  (список запусков)                        │
└─────────────────────────────────────────┘
```

### Шаг 3: Нажать кнопку

1. **Найдите кнопку** "Run workflow" (справа вверху)
2. **Нажмите на неё**
3. **Откроется выпадающее меню**

### Шаг 4: Выбрать ветку

1. **В выпадающем меню** найдите поле "Use workflow from"
2. **Выберите ветку:** `master` (или `main`)
3. **Нажмите зелёную кнопку** "Run workflow" (внизу меню)

---

## 🎯 АЛЬТЕРНАТИВНЫЙ СПОСОБ: ЧЕРЕЗ СПИСОК ACTIONS

### Если кнопки нет на странице workflow:

1. **Откройте:** https://github.com/sergey234/ALADDIN_FAMILY/actions

2. **Найдите workflow в списке:**
   - В левой панели "All workflows"
   - Найдите "Build Only (No Upload)"
   - **Нажмите на название** workflow

3. **На странице workflow:**
   - Справа вверху будет кнопка "Run workflow"
   - Нажмите на неё

## 🔍 ЕСЛИ КНОПКИ НЕТ

### Возможные причины:

1. **Workflow ещё не появился:**
   - ⏳ Подождите 2-3 минуты
   - 🔄 Обновите страницу (F5)

2. **Нет прав на запуск:**
   - ✅ Убедитесь, что вы вошли в GitHub
   - ✅ Убедитесь, что у вас есть права на репозиторий

3. **Workflow отключен:**
   - ✅ Проверьте настройки репозитория: Settings → Actions → General
