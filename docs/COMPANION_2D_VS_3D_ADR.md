# ADR — Companion: 2D Rive (не настоящий 3D)

**Статус:** ✅ принято продуктом **2026-05-26**  
**Контекст:** HERO-3-07, сравнение с Grok Companions (Ani)  
**Связано:** [COMPANION_HEROES_3_FIGMA_RIVE_PLAN.md](./COMPANION_HEROES_3_FIGMA_RIVE_PLAN.md) · [COMPANION_RIVE_EXPORT_CHECKLIST.md](./COMPANION_RIVE_EXPORT_CHECKLIST.md)

## Решение (одна строка)

**Живой 2D-друг в стиле онбординга (OB_01 / OB_02 / OB_05)** — анимация **Rive** (`.riv` ×3), UX как Grok: **~56% прямоугольная full-body сцена + субтитр**; качество = **12 эмоций + lip-sync**, не объём 3D-модели.

**Не делаем** настоящий 3D (SceneKit / USDZ / Unity) в Family Companion в этом релизе.

---

## Продуктовая цель

| | ALADDIN Companion | Grok Ani (референс UX) |
|--|-------------------|-------------------------|
| Роль | Семейный хранитель / друг (PG) | Взрослый companion 18+ |
| Визуал | **2D** как OB_00–07 | **3D** персонаж |
| Экран | 56% сцена + субтитр | Крупный персонаж + узкий диалог |
| Эмоции | 12 + фазы listening/thinking/speaking | Контекстные клипы |
| Метрика успеха | Доверие родителя, ясные эмоции, узнаваемый бренд | Привязанность, «вау», premium |

## Что такое «2D Rive» vs «настоящий 3D»

| | **2D Rive** | **Настоящий 3D** |
|--|-------------|------------------|
| На экране | Иллюстрация / вектор с костями в плоскости | Объёмная модель, камера, свет |
| Файл | `.riv` (&lt;500 KB) | Модель + текстуры (МБ) |
| Пайплайн | Figma → Rive → `RiveRuntime` | Blender/Maya → движок |
| Онбординг | **Тот же стиль** PNG/Lottie | Новый визуальный язык |

## Почему Grok выбрал 3D (контекст, не наше решение)

1. Аудитория **18+ / SuperGrok**, companion как эмоциональный premium-продукт.  
2. Дифференциация от «плоского чата».  
3. Партнёр **Animation Inc.** — готовые 3D motion + AI выбор клипа.  
4. Монетизация: affection, DLC-наряды, тело/костюмы.  
5. Нет необходимости совпадать с **2D** онбордингом другого продукта.

---

## Заключение специалиста

Для **продакшена ALADDIN** оптимален **2D Rive**: единый бренд с онбордингом, PG/семья, три героя, предсказуемый IPA, ясные эмоции на сцене Grok-layout. Настоящий 3D улучшил бы «присутствие» для взрослого dating-style companion, но **ухудшил бы** целостность продукта, доверие родителей и стоимость владения.
