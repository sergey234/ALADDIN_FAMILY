# 🚨 ОШИБКА: НЕТ СЕРТИФИКАТА ПОДПИСИ

## ❌ ОШИБКА

```
No signing certificate "iOS Distribution" found: 
No "iOS Distribution" signing certificate matching team ID "***" with a private key was found.
```

## 🔍 ПРИЧИНА

На GitHub Actions runner нет сертификата подписи для подписания приложения.

## ✅ РЕШЕНИЕ (2 ВАРИАНТА)

### ВАРИАНТ 1: Добавить сертификат в GitHub Secrets (РЕКОМЕНДУЕТСЯ)

1. **Экспортировать сертификат** из Keychain в .p12 формат
2. **Закодировать** в base64
3. **Добавить** в GitHub Secrets:
   - `IOS_DISTRIBUTION_CERTIFICATE` (base64 содержимое .p12)
   - `IOS_DISTRIBUTION_CERTIFICATE_PASSWORD` (пароль от .p12)

📖 **Подробная инструкция:** `docs/КАК_ДОБАВИТЬ_СЕРТИФИКАТ_ПОДПИСИ.md`

### ВАРИАНТ 2: Использовать автоматическую подпись

Если сертификат не добавлен, workflow автоматически переключится на автоматическую подпись с `-allowProvisioningUpdates`.

**Требования:**
- ✅ App Store Connect API ключи настроены
- ✅ Provisioning profiles настроены

---

## 🔧 ИСПРАВЛЕНИЕ В WORKFLOW

Workflow уже обновлен для поддержки обоих вариантов:

1. **Если сертификат есть** → использует Manual signing
2. **Если сертификата нет** → использует Automatic signing с `-allowProvisioningUpdates`

---

## 📋 СЛЕДУЮЩИЕ ШАГИ

1. **Выберите вариант:**
   - Вариант 1: Добавить сертификат (более надежно)
   - Вариант 2: Использовать автоматическую подпись (проще)

2. **Запустите workflow снова**

3. **Проверьте логи** на наличие ошибок

---

## ⚠️ ДОПОЛНИТЕЛЬНЫЕ ОШИБКИ

Если вы видите другие ошибки:

- **"Provisioning profile is Xcode managed"** → Нужны ручные (manually managed) профили
- **"Team ID mismatch"** → Проверьте `APPLE_TEAM_ID` в секретах
- **"Profile doesn't support Network Extensions"** → Проверьте, что extension profile включает нужные entitlements
