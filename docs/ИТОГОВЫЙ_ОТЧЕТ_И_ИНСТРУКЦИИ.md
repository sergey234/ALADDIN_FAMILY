### **ШАГ 4: Выполнить ЭТАП 6.4 - Проверка соответствия тарифам**

**Требуется доступ к базе данных:**

```bash
# На сервере
cd /opt/aladdin-backend

# Подключиться к PostgreSQL
psql -U postgres -d aladdin_db

# Выполнить SQL запрос для проверки функций по тарифам
SELECT 
    tariff_type,
    COUNT(DISTINCT component_id) as functions_count
FROM component_status
WHERE is_enabled = true
GROUP BY tariff_type;

# Ожидаемые результаты:
# FREE: 26 функций
# PERSONAL: 69 функций
# FAMILY: 124 функции
# PREMIUM: 138 функций
```
