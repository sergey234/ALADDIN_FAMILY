## 🔗 СВЯЗИ УВЕДОМЛЕНИЙ С ФУНКЦИЯМИ

### 1. **Уведомления безопасности** (`.security`)

#### `sendThreatBlockedNotification()`
- **Тип:** `threat_blocked`
- **Категория:** `.security`
- **Подключено к:**
  - Компоненты защиты от угроз (NetworkProtectionScreen):
    - `phishing_protection_agent` - защита от фишинга
    - `malware_detection_agent` - обнаружение вредоносного ПО
    - `network_security_agent` - сетевая безопасность
  - **138 функций безопасности:**
    - Блокировка фишинговых сайтов
    - Обнаружение вредоносного ПО
    - Блокировка небезопасных сетей
    - Firewall
    - Защита от отслеживания

#### `sendSuspiciousActivityNotification()`
- **Тип:** `suspicious_activity`
- **Категория:** `.security`
- **Подключено к:**
  - Компоненты мониторинга:
    - `incident_response_agent` - автоматическая система защиты
    - `mobile_security_agent` - мобильная безопасность
  - **138 функций безопасности:**
    - Мониторинг подозрительной активности
    - Обнаружение аномалий
    - Детекция обхода защиты

### 2. **Семейные уведомления** (`.family`)

#### `sendFamilyMemberAddedNotification()`
- **Тип:** `family_member_added`
- **Категория:** `.family`
- **Подключено к:**
  - Компонент: `family_notification_manager`
  - Функция: Добавление участника семьи

#### **FamilyNotificationSettingsModal** (колокольчик 🔔)
- **3 темы уведомлений:**
  1. **`security`** - Безопасность
     - Приоритет: 1 (высший)
     - Подключено к:
       - Все уведомления категории `.security`
       - `sendThreatBlockedNotification()`
       - `sendSuspiciousActivityNotification()`
  
  2. **`activity`** - Активность
     - Приоритет: 2 (средний)
     - Подключено к:
       - Активность детей (родительский контроль)
       - Мониторинг использования устройств
       - Отчёты о активности
  
  3. **`rewards`** - Награды
     - Приоритет: 3 (низкий)
     - Подключено к:
       - Система наград (единороги)
       - Достижения
       - Турниры

## ⚠️ АНАЛИЗ НА ДУБЛИ И НАКЛАДКИ

### ✅ НЕТ ДУБЛЕЙ:

1. **Категории уведомлений разделены:**
   - `.security` - только угрозы и безопасность
   - `.family` - только семейные события
   - `.networkProtection` - только защита сети
   - `.ai` - только AI сообщения

2. **Темы в FamilyNotificationSettingsModal:**
   - `security` - фильтрует уведомления категории `.security`
   - `activity` - фильтрует активность (не дублирует security)
   - `rewards` - фильтрует награды (не дублирует security/activity)

3. **Типы уведомлений уникальны:**
   - `threat_blocked` - только для заблокированных угроз
   - `suspicious_activity` - только для подозрительной активности
   - `family_member_added` - только для добавления членов семьи
   - `network_protection_connected` - только для подключения защиты сети
   - `ai_message` - только для AI сообщений

### ✅ НЕТ НАКЛАДОК:

1. **Уведомления из NotificationManager:**
   - Используются для **локальных** уведомлений (внутри приложения)
   - Отправляются при событиях безопасности

2. **Уведомления из FamilyNotificationSettingsModal:**
   - Используются для **настройки** каналов доставки (Push, Email, SMS)
   - Настраивают **частоту** и **приоритеты** тем
   - Не дублируют NotificationManager, а **дополняют** его

3. **Связь с 42 компонентами:**
   - Каждый компонент может отправлять уведомления через NotificationManager
   - FamilyNotificationSettingsModal **настраивает**, как эти уведомления доставляются
   - **Нет конфликтов** - разные уровни системы

4. **Связь с 138 функциями безопасности:**
   - Каждая функция может триггерить уведомление через NotificationManager
   - FamilyNotificationSettingsModal **фильтрует** и **приоритизирует** эти уведомления
   - **Нет накладок** - функции отправляют, настройки управляют доставкой
