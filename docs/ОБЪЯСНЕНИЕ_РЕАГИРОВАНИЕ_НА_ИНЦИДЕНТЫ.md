## 📋 ЧТО ТАКОЕ "РЕАГИРОВАНИЕ НА ИНЦИДЕНТЫ"?

### Простыми словами:

**"Реагирование на инциденты"** — это автоматическая система защиты, которая:

1. **Обнаруживает угрозы** — когда приложение находит опасность (вирус, фишинг, вредоносный сайт)
2. **Автоматически блокирует** — сразу же останавливает угрозу без вашего участия
3. **Уведомляет вас** — отправляет сообщение о том, что произошло
4. **Записывает в историю** — сохраняет информацию для отчетов

### Примеры работы:

**Пример 1: Вредоносный сайт**
- Ребенок пытается зайти на опасный сайт
- Система **автоматически** блокирует доступ
- Родитель получает уведомление: "Заблокирован вредоносный сайт"

**Пример 2: Фишинг**
- Кто-то пытается украсть пароль через поддельный сайт
- Система **автоматически** предупреждает и блокирует
- Родитель получает уведомление: "Обнаружена попытка фишинга"

**Пример 3: Вирус**
- На устройство пытается проникнуть вирус
- Система **автоматически** останавливает заражение
- Родитель получает уведомление: "Заблокирован вирус"

## 📍 ГДЕ НАХОДИТСЯ "РЕАГИРОВАНИЕ НА ИНЦИДЕНТЫ"?

### ❌ НЕ в родительском контроле!

**"Реагирование на инциденты"** находится в разделе:

**Главное меню → "ALADDIN Protection" → Раздел "Реагирование на инциденты"**

**Файл:** `Screens/03_NetworkProtectionScreen.swift`  
**Строки:** 248-264

```swift
// Раздел 3: Реагирование на инциденты
SettingsAccordion(
    icon: "🚨",
    title: localizationManager.localized("component.incident_response.title"),
    subtitle: localizationManager.localized("component.incident_response.subtitle"),
    isExpanded: $incidentResponseExpanded
) {
    SecurityFeatureRow(
        componentId: "incident_response_agent",
        title: localizationManager.localized("component.incident_response_agent.title"),
        description: localizationManager.localized("component.incident_response_agent.desc"),
        isEnabled: $viewModel.incidentResponseEnabled,
        hasSettings: true,
        onToggle: { viewModel.toggleIncidentResponse() },
        onSettingsTap: { showIncidentResponseSettings = true }
    )
}
```

### ✅ Структура ParentalControlScreen:

**Файл:** `Screens/07_ParentalControlScreen.swift`

### 1. **7 карточек родительского контроля** (строки 398-493):

1. **🔒 Фильтрация контента** — блокирует опасный контент для детей

4. **📍 Геолокация** — показывает где находится ребенок

7. **🚨 Защита от обхода** — блокирует попытки обойти защиту
