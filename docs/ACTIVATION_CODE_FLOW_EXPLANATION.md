## ✅ ПРАВИЛЬНЫЙ FLOW РАБОТЫ

### Шаг 1: Пользователь нажимает "Оплатить" на сайте
- Заполняет форму: тариф, alias, PIN, способ оплаты
- Нажимает "Перейти к оплате"
- Сайт отправляет запрос: `POST /api/payments/create`

### Шаг 2: Создание платежа
- Сервер создает запись в таблице `payments` (status: pending)
- Возвращает `paymentId`
- Пользователь перенаправляется на страницу оплаты банка

### Шаг 3: Оплата в банке
- Пользователь оплачивает в приложении банка или на сайте банка
- Банк обрабатывает платеж

### Шаг 4: Подтверждение платежа
- Банк отправляет webhook → `POST /api/payments/confirm`
- Сервер:
  - Обновляет статус на "paid"
  - **Генерирует код активации** (ALDN-XXXX-XXXX-XXXX)
  - Сохраняет код в таблице `activation_codes`
  - Обрабатывает реферальную программу (если есть)

### Шаг 5: Отображение кода на сайте
- Пользователь возвращается на `success.html?paymentId=...`
- Страница проверяет статус: `GET /api/payments/status/{payment_id}`
- Если статус "paid" и есть `activationCode`:
  - ✅ Показывается код активации
  - Кнопка "Копировать код"
  - Кнопка "Открыть приложение"

### Шаг 6: Активация в приложении
- Пользователь копирует код
- Открывает приложение ALADDIN AI
- Переходит в "Ввести код активации"
- Вводит код: `ALDN-XXXX-XXXX-XXXX`
- Подписка активируется! 🎉

## 🔍 ЧТО ПРОИСХОДИТ СЕЙЧАС

### Текущая ситуация:
1. ✅ Пользователь нажал "Оплатить"
2. ✅ Платеж создан (status: pending)
3. ⏳ Пользователь видит "Оплата обрабатывается"
4. ❌ Код активации еще НЕ сгенерирован (платеж не подтвержден)

### Почему код не появился:
- Платеж еще не подтвержден банком
- Код генерируется только после подтверждения (`POST /api/payments/confirm`)
- Страница `success.html` проверяет статус каждые 3 секунды

## ⏰ КОГДА ПОЯВИТСЯ КОД

### Автоматическое подтверждение (QR/СБП, карты):
- **Обычно:** 1-3 минуты после оплаты
- Банк автоматически отправляет подтверждение
- Сервер генерирует код
- Страница автоматически обновляется и показывает код

### Ручной перевод (manual_transfer):
- **Обычно:** 5-10 минут после перевода
- Администратор проверяет перевод вручную
- Подтверждает платеж
- Код генерируется

## ✅ ЧТО СДЕЛАНО

### 1. Добавлена таблица `activation_codes`
- Хранит коды активации
- Формат: ALDN-XXXX-XXXX-XXXX
- Срок действия: 30 дней

### 2. Генерация кода при подтверждении
- Функция `generate_activation_code()`
- Вызывается в `POST /api/payments/confirm`
- Код сохраняется в БД

### 3. Возврат кода в статусе
- `GET /api/payments/status/{payment_id}` возвращает `activationCode`
- Страница `success.html` получает код и показывает его

### 4. Восстановление кода
- `POST /api/payments/recover` - по user_alias
- `POST /api/activation/retrieve` - алиас для success.html
