- ❌ НЕ добавлять импорт после использования

### 2. ✅ Logger vs print
- В блоке try/except использовать `print()` вместо `logger`
- ❌ НЕ использовать `logger` если он не определен

- В Pydantic моделях использовать `str` с валидацией
