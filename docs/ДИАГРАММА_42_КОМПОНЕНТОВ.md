## 🎯 КАК НАЙТИ КАЖДУЮ СТРАНИЦУ

### 1️⃣ ALADDIN Protection (10 компонентов)
**Путь:** Главное меню → "ALADDIN Protection"  
**Что внутри:**
- Экстренная помощь (4 компонента)
- Защита от угроз (4 компонента с настройками)
- Реагирование (1 компонент)
- Пароли (1 компонент)

### 2️⃣ Родительский контроль (5 компонентов)
**Путь:** Главное меню → "Родительский контроль"  
**Что внутри:**
- Фильтрация контента
- Управление временем экрана
- Блокировка приложений
- Отслеживание местоположения
- Безопасный поиск

### 3️⃣ Расширенные настройки (13 компонентов)
**Путь:** Настройки → "Расширенные настройки"  
**Что внутри:**
- Защита в мессенджерах (6 компонентов)
- Приватность (4 компонента)
- Мониторинг (3 компонента)

### 4️⃣ Настройки (5 компонентов)
**Путь:** Главное меню → "Настройки"  
**Что внутри:**
- Экстренные контакты
- Экстренные уведомления
- Голосовое управление
- Защита детей (РФ)
- Защита данных (152-ФЗ)

### 5️⃣ Улучшения (9 компонентов)
**Путь:** Разные экраны  
**Что внутри:**
- Семейные уведомления (Family)
- Умные уведомления (Notifications)
- Детский интерфейс (Child Interface)
- Интерфейс для пожилых (Elderly Interface)
- Управление подпиской (Tariffs)
- Реферальная программа (Referral)
- QR платежи (Payment QR)
- Аналитика (Analytics)
- Отчеты (Reports)
