## 📋 ДОСТУПНЫЕ ENDPOINTS

После перезапуска backend доступны:

1. **GET** `/api/darkweb/health` - Health check (без авторизации)
2. **POST** `/api/darkweb/check` - Проверка email на утечки
3. **POST** `/api/darkweb/start-monitoring` - Запуск мониторинга
4. **POST** `/api/darkweb/stop-monitoring` - Остановка мониторинга
5. **GET** `/api/darkweb/status` - Статус мониторинга
6. **GET** `/api/darkweb/breaches` - Список найденных утечек
