## 📝 ПОШАГОВАЯ ИНСТРУКЦИЯ

### **ШАГ 3.1: Проверить текущий статус сервера**

```bash
# Проверить, как запущен сервер
systemctl status aladdin-backend

# Или если используется pm2
pm2 list

# Или если запущен вручную
ps aux | grep python | grep main.py
```

---

### **ШАГ 3.2: Проверить логи перед перезапуском**

```bash
# Если используется systemd
journalctl -u aladdin-backend -n 50 --no-pager

# Или если логи в файле
tail -n 50 /opt/aladdin-backend/logs/app.log
```

---

### **ШАГ 3.3: Перезапустить сервер**

**ВАРИАНТ 1: Если используется systemd**

```bash
systemctl restart aladdin-backend
systemctl status aladdin-backend
```

---

**ВАРИАНТ 2: Если используется pm2**

```bash
pm2 restart aladdin-backend
pm2 status
pm2 logs aladdin-backend --lines 50
```

---

**ВАРИАНТ 3: Если запущен вручную**

```bash
# Найти процесс
ps aux | grep "python.*main.py" | grep -v grep

# Убить процесс (заменить PID на реальный)
kill -9 <PID>

# Запустить заново
cd /opt/aladdin-backend
nohup python3 main.py > logs/app.log 2>&1 &
```

---

### **ШАГ 3.4: Проверить, что сервер запустился**

```bash
# Проверить статус

# Или

ps aux | grep python | grep main.py
```

---

### **ШАГ 3.5: Проверить логи после перезапуска**

```bash
# Если используется systemd
journalctl -u aladdin-backend -n 100 --no-pager

# Или если логи в файле
tail -n 100 /opt/aladdin-backend/logs/app.log

# Проверить на наличие ошибок
tail -n 100 /opt/aladdin-backend/logs/app.log | grep -i error
```

---

### **ШАГ 3.6: Проверить, что роутеры загружены**

```bash
# Проверить логи на наличие сообщений о загрузке роутеров
tail -n 200 /opt/aladdin-backend/logs/app.log | grep -i "router\|crash\|roadside\|parental\|subscription\|metrics"
```

**Ожидаемые сообщения:**
- "✅ Роутер Crash Detection подключен"
- "✅ Роутер Roadside Assistance подключен"
- "✅ Роутер Parental Control подключен"
- "✅ Роутер Subscription подключен"
- "✅ Роутер Metrics подключен"

## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### **Проблема 1: Сервер не запускается**

**Решение:**
```bash
# Проверить детальные ошибки
journalctl -u aladdin-backend -n 200 --no-pager

# Или
tail -n 200 /opt/aladdin-backend/logs/app.log

# Проверить синтаксис main.py
python3 -m py_compile /opt/aladdin-backend/main.py

# Попробовать запустить вручную для детальных ошибок
cd /opt/aladdin-backend
python3 main.py
```

---

### **Проблема 2: Ошибки импорта в роутерах**

**Решение:**
```bash
# Проверить, что все зависимости установлены
pip3 list | grep -i fastapi
pip3 list | grep -i sqlalchemy

# Проверить структуру проекта
ls -la /opt/aladdin-backend/app/database/
ls -la /opt/aladdin-backend/app/auth/
```

---

### **Проблема 3: Порт уже занят**

**Решение:**
```bash
# Проверить, какой процесс использует порт
lsof -i :8002
lsof -i :8000

# Если нужно, убить процесс
kill -9 <PID>
```
