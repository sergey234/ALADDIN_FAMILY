# Чеклист Figma: 8 экранов онбординга + герой Main + полный Main

## Что это и зачем (простыми словами)

**Чеклист** — это список «что положить в каждый фрейм», чтобы в Figma **ничего не забыть**: отступы, зоны, имена под экспорт в Xcode.

**Зачем:** когда дизайн готов по чеклисту, разработчик **не гадает** — он копирует размеры и имена (`OnboardingHero_00` … `MainHero_ambient`) из одного места. Меньше ошибок, быстрее Фаза C (код).

**Связь с планом:** это шаг **Фазы B** после Фазы A (цифры уже в `ONBOARDING_MAIN_HERO_HANDOFF.md` §1.4–1.7 и в `ONBOARDING_WCAG_MEASUREMENTS.md`).

**Мастер-план реализации (TODO ↔ шаги ↔ все файлы):** **`ONBOARDING_MASTER_IMPLEMENTATION_PLAN.md`**.

**Приёмка каждой страницы (обязательно перед OB_N+1):** **`ONBOARDING_FIGMA_PAGE_QA_ALGORITHM.md`** — §A–F, **§E-IMG** (масштаб/кадр растра), §SIM; шлюз **G1–G10** в мастер-плане §4.1; статус — таблица §J (колонка **«Продукт»**).

## Общие правила для всех восьми фреймов карусели

1. **Размер фрейма:** **393 × 852** pt (или ваш эталон — тогда пропишите в комментарии к файлу).  
2. **Три зоны по вертикали (смысл, не обязательно три слоя):**  
   - сверху **~60%** — картинка/герой и фон сюжета;  
   - ниже — **карточка** с заголовком и текстом (**~40%** зоны текста **над** нижней полосой);  
   - снизу зарезервировать **~160–200 pt** + home indicator — место под **точки страниц и кнопки** (в приложении они не внутри карточки слайда).  
3. **Текст сюжета** — только в текстовых слоях Figma (как «пример»), в **экспортируемую картинку героя** сюжетный текст **не** класть.  
4. **Имя группы/фрейма для вырезки героя** в Xcode должно совпасть с каноном: `OnboardingHero_00` … `OnboardingHero_07`.  
5. **Контраст:** карточка + цвет текста — проверить по `ONBOARDING_WCAG_MEASUREMENTS.md` (минимум **4.5:1** для обычного описания).
6. **Текст в макете = как в Swift** (пример для согласования): те же фразы, что `languageStepTitle` / список языков / `onboarding_page*_*`; не подменять «улучшенным» копирайтом без смены ключей в приложении. Отступы живого UI — **эталон код** (`14_OnboardingScreen.swift`); Figma не переопределяет продакшен. См. **`docs/ONBOARDING_MAIN_HERO_HANDOFF.md` §1.8**.
7. **Растр героя:** перед upload собрать `OnboardingHero_0N_figma_zone_361x460.png`; не закрывать страницу при «далеком» FIT или обрезанном FILL — см. **§E-IMG** в QA-алгоритме.

## OB_00 — 100% (оригинал = приложение + экспорт героя)

**Цель макета:** один фрейм `OB_00_Language_393x852` (393×852), визуально совпадающий с **`languageStepView` + общим chrome** из `14_OnboardingScreen.swift`, плюс **группа для вырезки** финального арта **`OnboardingHero_00`** (в Xcode то же имя). Тексты в Figma = как в коде (§1.8 handoff).

### Чеклист слоёв (внутри `OB_00_Language_393x852`)

| # | Имя слоя | Содержание |
|---|-----------|------------|
| 1 | **`OnboardingHero_00`** | **Группа/фрейм экспорта** (не сюжетный текст). Заменяет однотонный прямоугольник: внутри — финальный растр/Lottie **или** временный векторный «лампа + золотое свечение» на фоне градиента (индиго/ночь), без подписей на картинке. Размер зоны **~361×460**, позиция **x=16 y=24** (как была заглушка `HERO_OnboardingHero_00`). |
| 2 | **`ICON_globe_emoji`** | Символ **🌐**, ~56pt, по центру по горизонтали, **под** зоной героя, **над** заголовком (как `languageStepGlobe`). |
| 3 | **`TITLE_lang_step`** | Текст **«Язык приложения»** (для макета RU; EN при необходимости — отдельный вариант компонента), 22pt **Bold**, белый, по центру, `padding` по горизонтали как в приложении. |
| 4 | **`ROW_lang_RU`** | Карточка: 🇷🇺 **Русский**, состояние **выбрано** — обводка **`#2E5BFF`** (как `Color.primaryBlue` в `Shared/Styles/Colors.swift`), фон белый ~22% opacity, справа иконка **checkmark.circle.fill** (не буква «✓»): круг **#2E5BFF** + белая галочка, **24×24**. |
| 5 | **`ROW_lang_EN`** | То же для 🇬🇧 **English**, состояние **не выбрано** — обводка белая ~20% opacity, без иконки галочки. |

| 7 | **`GUIDE_CHROME_RESERVE`** *(опционально)* | Пунктирный прямоугольник **снизу** фрейма, высота **~160–200 pt**, без экспорта: резерв под индикаторы и CTA + home indicator. |

### Иконка галочки (как iOS), цвет бренда

В Figma: **Plugins → не обязательны** — можно **Paste SVG** как вектор. Параметры под `primaryBlue`:

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none">
  <circle cx="12" cy="12" r="11" fill="#2E5BFF"/>
  <path d="M7 12l3 3 7-7" stroke="white" stroke-width="2.2" stroke-linecap="round" stroke-linejoin="round"/>
</svg>
```

Вставить внутрь **`ROW_lang_RU`** справа вместо текстового «✓»; выравнивание по центру по вертикали ряда.

### Финальный арт `OnboardingHero_00`

- В репозитории ассета может ещё не быть — это **Фаза C** (каталог + `HeroAmbientPresentation` уже ждут имя **`OnboardingHero_00`**).
- В Figma слой **`OnboardingHero_00`** должен быть **единым блоком для экспорта** @2x/@3x (или отдельный Lottie по пайплайну), **без** заголовков/описаний внутри растра.

### Если Cursor / MCP Figma временно недоступен (лимит)

Доработки **вручную в Figma** по таблице выше **или** повторить вызов `use_figma` позже: скрипт должен (1) удалить старый прямоугольник-заглушку, (2) создать группу **`OnboardingHero_00`** с градиентом + простой силуэт лампы, (3) в рядах **RU/EN** заменить текстовую галочку на SVG выше, (4) добавить **`GUIDE_CHROME_RESERVE`**. Идентификаторы узлов в файле могут отличаться — ориентироваться по **именам слоёв**.

## После расстановки фреймов

1. Прогнать **контраст** текста на карточке на каждом из восьми фонов (и шаг 0).  
2. Выставить **стили** цветов (индиго/золото + акценты сюжета) из `ONBOARDING_MAIN_HERO_HANDOFF.md` §2 / §4.  
3. Таблица «имя в Figma → имя в Asset Catalog» — если в Figma длиннее (`OnboardingHero_01_family` и т.д.), **одна строка** на переименование при экспорте.  
4. Сообщить разработке: **готово к Фазе C** — тогда правки в `14_OnboardingScreen.swift` / ассетах идут по макету.
