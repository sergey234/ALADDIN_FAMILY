## 📊 ВСЕ 12 ФУНКЦИЙ DARK WEB MONITORING

### Функции проверки утечек:

1. ✅ **`check_email_breach`** - Комплексная проверка email через все источники (HIBP, BreachDirectory, российские базы)

2. ✅ **`check_email_breach_hibp`** - Проверка через Have I Been Pwned API с k-анонимностью

3. ✅ **`check_email_breach_breachdirectory`** - Проверка через BreachDirectory API

4. ✅ **`check_email_breach_russian`** - Проверка через российские базы утечек

5. ✅ **`check_phone_breach`** - Проверка номера телефона на утечки

### Функции мониторинга:

6. ✅ **`monitor_user_data`** - Мониторинг данных пользователя (email и/или телефон)

7. ✅ **`start_monitoring`** - Запуск автоматического мониторинга данных пользователя

8. ✅ **`stop_monitoring`** - Остановка автоматического мониторинга

9. ✅ **`get_monitoring_status`** - Получение статуса мониторинга

### Функции ThreatMonitoringInterface:

10. ✅ **`collect_threats`** - Сбор угроз (утечек данных) из всех активных мониторингов

11. ✅ **`analyze_threats`** - Анализ собранных угроз с рекомендациями

12. ✅ **`send_alert`** - Отправка уведомления об утечке данных

**Все 12 функций зарегистрированы в SFM!** ✅
