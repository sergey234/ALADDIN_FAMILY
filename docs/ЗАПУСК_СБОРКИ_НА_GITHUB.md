## 🎯 ЗАПУСК СБОРКИ

### Шаг 1: Открыть GitHub Actions

1. **Откройте браузер**
2. **Перейдите:** https://github.com/sergey234/ALADDIN_FAMILY/actions

### Шаг 2: Найти workflow "Build Only"

1. **В левой панели** найдите раздел "All workflows"
2. **Найдите** "Build Only (No Upload)" в списке
3. **Если его нет:**
   - Подождите 1-2 минуты
   - Обновите страницу (F5 или Cmd+R)

### Шаг 3: Запустить сборку

1. **Нажмите на** "Build Only (No Upload)" в списке workflows
2. **Справа вверху** нажмите кнопку **"Run workflow"**
3. **Выберите ветку:**
   - Выберите `master` из выпадающего списка
4. **Нажмите зелёную кнопку** **"Run workflow"**

### Шаг 4: Дождаться завершения

1. **Дождитесь завершения** (10-20 минут)
2. **Проверьте результат:**
   - ✅ Зелёная галочка = сборка успешна
   - ❌ Красный крестик = есть ошибки
