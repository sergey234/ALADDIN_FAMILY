## 🔍 ДЕТАЛЬНЫЙ АНАЛИЗ КАЖДОЙ ПРОБЛЕМЫ

### 1️⃣ ПРОБЛЕМА: WhatsApp/Telegram/VK - Краш или ничего не происходит

#### ❌ Проблемы в коде:

**Файл:** `Screens/21_ReferralScreen.swift`, строки 912-976

**Проблема 1: Неправильное кодирование URL**
```swift
let message = referralText.addingPercentEncoding(withAllowedCharacters: .urlQueryAllowed) ?? ""
```
- `referralText` может содержать символы, которые не кодируются правильно
- Может привести к невалидному URL и крашу

**Проблема 2: canOpenURL требует правильной схемы**
```swift
if let whatsappURL = URL(string: "whatsapp://send?text=\(message)"),
   UIApplication.shared.canOpenURL(whatsappURL) {
```
- `canOpenURL` может вернуть `false` если схема не зарегистрирована в `Info.plist`
- Нужны правильные схемы: `whatsapp`, `tg`, `vk`

**Проблема 3: Открытие URL на главном потоке без защиты**
```swift
UIApplication.shared.open(url, options: [:]) { success in
```
- Если URL невалидный, может вызвать краш
- Нет проверки на пустой `referralCode`

**Проблема 4: Telegram и VK схемы неправильные**
- Telegram: используется `tg://msg?text=` но правильнее `tg://msg_url?url=`
- VK: используется `vk://share?url=` но может не работать на всех версиях

#### ✅ Решение:

1. Добавить правильное кодирование URL с учетом всех символов
2. Добавить проверку на пустой `referralCode`
3. Использовать правильные схемы для мессенджеров
4. Добавить обработку ошибок с fallback на ShareSheet
5. Обернуть вызовы в `DispatchQueue.main.async`

### 2️⃣ ПРОБЛЕМА: ShareSheet - Краш или не открывается

#### ❌ Проблемы в коде:

**Файл:** `Shared/Components/ShareSheet.swift`, строки 1-13

**Проблема 1: Отсутствие презентации на правильном view controller**
```swift
func makeUIViewController(context: Context) -> UIActivityViewController {
    UIActivityViewController(activityItems: activityItems, applicationActivities: nil)
}
```
- Не установлен `popoverPresentationController` для iPad
- Может крашиться на iPad без правильного anchor point

**Проблема 2: Нет обработки пустого массива activityItems**
- Если `activityItems` пустой, может вызвать краш

**Проблема 3: В ReferralScreen нет правильной привязки**
```swift
.sheet(isPresented: $showShareSheet) {
    ShareSheet(activityItems: [referralText])
}
```
- `referralText` может быть пустой строкой
- Нет проверки на пустой массив

#### ✅ Решение:

1. Добавить `popoverPresentationController` для iPad
2. Добавить проверку на пустой массив `activityItems`
3. Использовать правильный anchor point для popover
4. Добавить проверку на пустой `referralText` в ReferralScreen
