## 📦 РАЗМЕР АРХИВА (.xcarchive)

### Что включает архив:
1. **Скомпилированный бинарник** (`.app` файл)
2. **dSYM файлы** (символы для отладки) - обычно 50-200% от размера бинарника
3. **Ресурсы** (изображения, шрифты) - 21 MB
4. **Метаданные** (Info.plist, embedded.mobileprovision)
5. **Swift runtime библиотеки** (если не включены в бинарник)

### Типичный размер .xcarchive:
**Для вашего проекта:**
- **Минимальный размер:** ~50-80 MB
- **Типичный размер:** ~100-150 MB
- **Максимальный размер:** ~200-300 MB (с полными символами)

**Формула:**
```
Размер архива = Размер бинарника + dSYM + Ресурсы + Метаданные
             = (10-30 MB) + (15-60 MB) + (21 MB) + (1-2 MB)
             ≈ 50-120 MB
```

## 📱 РАЗМЕР IPA ФАЙЛА

### Что включает IPA:
1. **Скомпилированный бинарник** (`.app` файл) - сжатый
2. **Ресурсы** (изображения, шрифты) - сжатые
3. **Метаданные** (Info.plist, embedded.mobileprovision)
4. **Swift runtime** (если не включен в бинарник)

### Типичный размер IPA:
**Для вашего проекта:**
- **Минимальный размер:** ~30-50 MB
- **Типичный размер:** ~60-100 MB
- **Максимальный размер:** ~150-200 MB

**Формула:**
```
Размер IPA = Размер бинарника (сжатый) + Ресурсы (сжатые) + Метаданные
           = (8-20 MB) + (15-18 MB) + (1-2 MB)
           ≈ 30-100 MB
```

**Важно:** IPA обычно на 30-50% меньше, чем архив, из-за сжатия и отсутствия dSYM.

## 📥 ГДЕ НАЙТИ РАЗМЕР В GITHUB ACTIONS

### 1. В логах workflow:
После шага "Export IPA" будет указан путь к IPA файлу:
```
IPA file: ./build/export/ALADDIN.ipa
```

### 2. В артефактах:
Workflow загружает IPA как артефакт:
```yaml
- name: Upload IPA as artifact
  uses: actions/upload-artifact@v4
  with:
    name: ALADDIN-IPA
    path: ${{ env.IPA_FILE_PATH }}
```

**Размер артефакта можно увидеть:**
- В GitHub Actions → Workflow run → Artifacts
- Там будет указан размер файла

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Размер архива > Размер исходного кода** - это нормально, так как включает:
   - Скомпилированный бинарник
   - Символы отладки (dSYM)
   - Ресурсы
   - Runtime библиотеки

2. **Размер IPA < Размер архива** - IPA сжатый и без dSYM

3. **Размер зависит от:**
   - Оптимизации компиляции (Release vs Debug)
   - Включения символов отладки
   - Размера ресурсов
   - Swift runtime (встроенный или внешний)
