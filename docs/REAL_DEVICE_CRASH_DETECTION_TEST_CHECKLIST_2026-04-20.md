# Real Device Crash Detection Test Checklist (2026-04-20)

Цель: отдельная проверка Crash Detection на реальном устройстве с датчиками и разрешением геолокации.

## Preconditions

- Реальное iPhone-устройство (не Simulator), где доступен акселерометр.
- Включены системные Location Services.
- Для приложения ALADDIN выдано разрешение геолокации `Always`.
- Устройство имеет интернет-доступ к `https://aladdin-ai.ru`.
- Пользователь авторизован (валидный JWT в приложении).

## Test Steps

1. Открыть экран `Защита сети` (`NetworkProtectionScreen`).
2. Убедиться, что нет предупреждения `Crash Detection недоступен на этом устройстве`.
3. Включить тумблер `Crash Detection`.
4. Проверить, что нет ошибки `Акселерометр недоступен`.
5. Нажать debug-кнопку `Симулировать аварию` (в debug-сборке).
6. Подтвердить, что сценарий фиксируется без ошибок по сенсорам/гео.
7. Выключить `Crash Detection`, затем включить снова.
8. Повторно убедиться в стабильной работе тумблера и отсутствии ошибок.

## Expected Results

- Тумблер `Crash Detection` корректно включается/выключается.
- Нет сообщений об отсутствии акселерометра на реальном девайсе.
- Нет сообщений об отсутствии местоположения при корректно выданных правах.
- Серверные запросы по компоненту возвращают `HTTP 200`.
- В логах нет повторяющихся ошибок запуска мониторинга.

## Fail Criteria

- Появляется предупреждение `Crash Detection недоступен...` на реальном устройстве.
- Тумблер возвращается в исходное состояние с ошибкой запуска.
- Нет доступа к местоположению при корректной конфигурации прав.
- Серверные запросы для `crash_detection_agent` неуспешны.
