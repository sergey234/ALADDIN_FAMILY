# Voice Safety Log — ручная проверка P0 (C1+coach)

Сборка: **вы в Xcode**. Ниже — куда нажать и что сказать.

## Важно: как говорить «ссылка»

Пользователь **не** диктует `https://…`.

**Правильный сценарий:**
1. Скопировать подозрительную ссылку (в Safari / Telegram / WhatsApp — «Копировать»).
2. В ALADDIN открыть голосовые заметки.
3. Сказать коротко: **«ссылка»** или **«проверка»** или **«проверь ссылку»**.
4. Окно голосовых заметок закроется → откроется **Antifake** с уже подставленной скопированной ссылкой (если она безопасна для вставки).

Если в буфере пусто — Antifake всё равно откроется, ссылку можно вставить кнопкой «Из буфера».

## Куда нажимать

### A. Голос → проверка ссылки
1. Xcode → Run на симулятор / iPhone.  
2. **Настройки** (или **Удобный режим**) → пункт **Голосовые заметки** / Voice Notes.  
3. Увидите жёлтую подсказку про «ссылка / проверка» — можно нажать **Понятно**.  
4. В Safari скопируйте любую ссылку, например `https://example.com/?utm_source=test`.  
5. Вернитесь в Voice Notes → микрофон → скажите **«ссылка»** → Стоп/сохранить.  
6. Дождитесь распознавания речи.  
7. Ожидание: sheet закрылся → экран **Antifake** → поле URL заполнено (без лишнего `utm_`, если сработала очистка).

### B. Обычная фраза (не должна открывать Antifake)
1. В Voice Notes скажите: **«Сегодня проверка дома прошла нормально»**.  
2. Ожидание: заметка сохранена, Antifake **не** открылся.

### C. Дневник
1. Скажите: **«идея добавить напоминание бабушке»** или **«не забыть купить молоко»**.  
2. Ожидание: заметка с тегом, Antifake не открывается.

### D. Буфер в Antifake напрямую
1. Откройте **Antifake** с главной / меню.  
2. Скопируйте ссылку с `utm_` → кнопка вставки из буфера.  
3. Ожидание: ссылка подставилась, tracking-параметры срезаны.  
4. Скопируйте что-то вроде `sk-xxxx…` или `Bearer eyJ…` → вставка.  
5. Ожидание: сообщение, что секрет **не** вставляем.

### E. Share (если есть Share Extension)
1. В Safari Share → ALADDIN / Antifake.  
2. Ожидание: тот же безопасный путь (не сырой секрет).

- [ ] A8 RU: ссылка/проверка; EN: link/check

- [ ] A10 «…проверка дома…» ≠ intent  
- [ ] A11 Share/paste через safety
