# Antifake QA sign-off attachments (R-02)

Store device QA evidence here before external TestFlight / App Store submit.

## Naming

```
{build}_{check_id}_{YYYYMMDD}.{png|jpg}
```

Examples:
- `233_01_extension_on_20260615.png` — Settings → Phone → ALADDIN ON
- `233_02_sync_n113_20260615.png` — Hub «Синхронизировано 113 номеров»
- `233_03_incoming_label_20260615.jpg` — call screen with QA number label

## Checklist

Fill `ANTIFAKE_QA_SIGNOFF.md` and copy completed rows into `signoff_record.json` when done.
