| Метрика | Что означает | Источник правды |
|--------|----------------|-----------------|
| **178** | Задачи **NEXT / execution dashboard** (треки A/B, фазы 0–9 в дашборде) | `docs/EXECUTION_AND_LOCALIZATION_DASHBOARD.md` + `NEXT_VERSION_IMPLEMENTATION_PLAN.md` |

## 4) P3 — трек **вне кода** (не смешивать со sprint velocity)

Эти пункты из `GAP_CLOSURE` **не** закрываются merge PR в iOS. У них отдельный контур SLA и владельцы.

| ID | Пробел (из gap) | Владелец (заполнить) | Целевая дата (заполнить) | Артефакт готовности |
|----|-----------------|----------------------|---------------------------|---------------------|
| G19 | UX с реальными детьми (полевые сессии) | | | Протокол + отчёт |
| G21 | COPPA legal sign-off | | | Подписанный пакет / тикет legal |
| G22 | Внешний security/privacy аудит | | | Отчёт аудитора |
| G23 | Family Sharing security pack | | | Evidence pack |

**Правило для ML/инженеров:** не брать G19/G21+ в спринт как «ещё одну задачу на пятницу»; синхронизация с владельцем и датой в этой таблице.
