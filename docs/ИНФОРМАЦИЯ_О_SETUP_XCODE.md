## 👤 КТО ТАКОЙ MAXIM LOBANOV

**Максим Лобанов** - разработчик, создавший популярный GitHub Action под названием `setup-xcode`.

Этот инструмент позволяет настраивать определённую версию Xcode в рабочих процессах GitHub Actions для сборки и тестирования iOS-приложений.

---

## 🔧 ЧТО ДЕЛАЕТ ЭТОТ ACTION

### Функции:

- ✅ Устанавливает нужную версию Xcode в GitHub Actions
- ✅ Позволяет выбрать конкретную версию (например, 16.2.0)
- ✅ Автоматически настраивает окружение для сборки iOS приложений
- ✅ Настраивает правильные пути и переменные окружения

### Пример использования:

```yaml
- name: Setup Xcode
  uses: maxim-lobanov/setup-xcode@v1
  with:
    xcode-version: '16.2.0'
```
