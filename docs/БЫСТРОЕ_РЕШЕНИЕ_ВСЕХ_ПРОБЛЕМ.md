### ШАГ 2: Выбрать вариант

#### ВАРИАНТ A: Ручная подпись

**Если у вас есть сертификат в Keychain:**

1. Экспортируйте сертификат:
   - Keychain Access → My Certificates
   - Найдите "Apple Distribution" или "iPhone Distribution"
   - Правый клик → Export... → .p12 формат
   - Введите пароль

2. Закодируйте в base64:
   ```bash
   base64 -i certificate.p12 | tr -d '\n' > certificate_base64.txt
   ```

3. Добавьте в GitHub Secrets:
   - `IOS_DISTRIBUTION_CERTIFICATE` = содержимое `certificate_base64.txt`
   - `IOS_DISTRIBUTION_CERTIFICATE_PASSWORD` = пароль от .p12

#### ВАРИАНТ B: Автоматическая подпись (РЕКОМЕНДУЕТСЯ)

**Если у вас НЕТ сертификата:**

1. Создайте App Store Connect API ключ:
   - https://appstoreconnect.apple.com/access/api
   - Keys → Generate API Key
   - Скачайте .p8 файл
   - Запомните Key ID и Issuer ID

2. Добавьте в GitHub Secrets:
   - `APP_STORE_CONNECT_API_KEY` = содержимое .p8 файла
   - `APP_STORE_CONNECT_ISSUER_ID` = Issuer ID (UUID)
   - `APP_STORE_CONNECT_API_KEY_ID` = Key ID

📖 **Подробная инструкция:** `docs/КАК_ДОБАВИТЬ_СЕКРЕТЫ_В_GITHUB.md`
