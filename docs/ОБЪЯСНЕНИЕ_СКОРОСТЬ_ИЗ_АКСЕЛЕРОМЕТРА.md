# 📚 ОБЪЯСНЕНИЕ: Скорость из акселерометра (простыми словами)

**Дата:** 12 декабря 2025

---

## 🚗 ЧТО ТАКОЕ СКОРОСТЬ ИЗ АКСЕЛЕРОМЕТРА?

### **Простыми словами:**

**Акселерометр** - это датчик, который измеряет **ускорение** (как быстро меняется скорость).

**Пример из жизни:**
- Вы едете в машине и нажимаете на газ → машина ускоряется
- Акселерометр чувствует это ускорение
- Если мы знаем ускорение и время, можем вычислить скорость

---

## 🔢 КАК ЭТО РАБОТАЕТ (математика)

### **Формула:**
```
Скорость = Старая скорость + Ускорение × Время
```

**Пример:**
1. Вы стоите (скорость = 0 км/ч)
2. Нажимаете газ, ускорение = 2 м/с²
3. Через 1 секунду: скорость = 0 + 2 × 1 = 2 м/с = 7.2 км/ч
4. Через 2 секунды: скорость = 2 + 2 × 1 = 4 м/с = 14.4 км/ч
5. И так далее...

---

## ⚠️ ПРОБЛЕМА: Накопление ошибки

**Что происходит:**
- Каждое измерение добавляет небольшую ошибку
- Ошибки накапливаются со временем
- Через 10-20 секунд скорость может быть неточной

**Пример:**
- Реальная скорость: 60 км/ч
- Через 10 сек вычисленная: 58 км/ч (ошибка -2 км/ч)
- Через 30 сек вычисленная: 55 км/ч (ошибка -5 км/ч)

---

## ✅ РЕШЕНИЕ: GPS/ГЛОНАСС (лучше!)

**В России работают:**
- ✅ **GPS** (американская система)
- ✅ **ГЛОНАСС** (российская система)
- ✅ **BeiDou** (китайская система, частично)

**Преимущества GPS/ГЛОНАСС:**
- ✅ Точная скорость (из спутников)
- ✅ Точное местоположение
- ✅ Нет накопления ошибки
- ✅ Работает постоянно

---

## 🎯 КАК ИСПОЛЬЗОВАТЬ В АГЕНТЕ

### **Приоритет источников данных:**

1. **GPS/ГЛОНАСС (предпочтительно):**
   - Точная скорость
   - Точное местоположение
   - Используется если доступно

2. **Акселерометр (запасной вариант):**
   - Используется ТОЛЬКО если GPS недоступен
   - Вычисление скорости из ускорения
   - Менее точное, но работает

## 📱 iOS ПРИЛОЖЕНИЕ

### **CoreLocation может дать:**

```swift
import CoreLocation

// Точная скорость из GPS/ГЛОНАСС
locationManager.startUpdatingLocation()
let speed = location.speed  // м/с
let speedKmh = speed * 3.6  // км/ч

// Точное местоположение
let latitude = location.coordinate.latitude
let longitude = location.coordinate.longitude
```

**Разрешения:**
- `NSLocationWhenInUseUsageDescription` - для использования в приложении
- `NSLocationAlwaysUsageDescription` - для фонового режима

## ✅ ВЫВОД

**Скорость из акселерометра** = вычисление скорости путем сложения ускорений за время.

**Но лучше использовать GPS/ГЛОНАСС** - они работают в России и дают точные данные!

**В агенте:** GPS/ГЛОНАСС - основной источник, акселерометр - запасной вариант.
