#### 1.2 ToastManager - отсутствующие методы
**Количество:** ~15 ошибок  
**Файлы:**
- `ViewModels/NetworkProtectionViewModel.swift`
- `ViewModels/ProtectionSettingsViewModel.swift`
- `ViewModels/ParentalControlViewModel.swift`
- `Screens/Views/EmergencyContactsView.swift`
- `Screens/Views/EmergencyNotificationsView.swift`
- `Screens/Views/VoiceControlView.swift`
- `Screens/Views/ComplianceView.swift`
- `Shared/Components/Modals/FamilyNotificationSettingsModal.swift`
- `Shared/Components/Modals/AnalyticsSettingsModal.swift`

**Проблема:**
```swift
// Используется:
toastManager.showSuccess("Сообщение")
toastManager.showError("Ошибка")

// Но существует только:
toastManager.show(message: String, type: Toast.ToastType)
```

**Решение:**
Добавить методы в `Shared/Components/Toast.swift`:
```swift
func showSuccess(_ message: String) {
    show(message: message, type: .success)
}

func showError(_ message: String) {
    show(message: message, type: .error)
}
```

**Приоритет:** 🔴 КРИТИЧЕСКИЙ  
**Время:** 2 минуты
