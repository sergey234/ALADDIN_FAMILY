## 🔔 Система уведомлений

### Интеграция с ThreatEventBus

Все уведомления о согласиях генерируются через `ThreatEventBus`:

```python
if self.event_bus:
    notification_event = ThreatEvent(
        event_id=f"consent_{action}_{user_id}_{timestamp}",
        agent_name=self.__class__.__name__,
        threat_type="consent_management",
        severity="info|warning|low",
        source="identity_theft_protection",
        target=user_id,
        timestamp=datetime.now().isoformat(),
        description="...",
        metadata={...}
    )
    self.event_bus.publish(notification_event)
```

### Типы событий согласий:

1. **`consent_granted`** - Согласие предоставлено
2. **`consent_revoked`** - Согласие отозвано
3. **`consent_expired`** - Согласие истекло
4. **`consent_expiring_soon`** - Согласие скоро истечет (за 7 дней)
