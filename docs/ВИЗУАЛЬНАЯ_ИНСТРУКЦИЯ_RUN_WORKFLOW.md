## 🎯 ПОШАГОВАЯ ИНСТРУКЦИЯ

### Шаг 1: Открыть страницу

1. **Откройте браузер**
2. **Введите в адресную строку:**
   ```
   https://github.com/sergey234/ALADDIN_FAMILY/actions/workflows/build-only.yml
   ```
3. **Нажмите Enter**

### Шаг 2: Найти кнопку

1. **Посмотрите в правый верхний угол** страницы
2. **Найдите большую кнопку** с текстом "Run workflow"
3. **Кнопка должна быть:**
   - Синего или зелёного цвета
   - С белым текстом "Run workflow"
   - Справа вверху страницы

### Шаг 3: Нажать кнопку

1. **Нажмите на кнопку** "Run workflow"
2. **Откроется выпадающее меню** (модальное окно)

### Шаг 4: Выбрать ветку и запустить

1. **В открывшемся меню:**
   - Найдите поле "Use workflow from"
   - Выберите ветку: `master` (из выпадающего списка)
   
2. **Внизу меню:**
   - Найдите зелёную кнопку "Run workflow"
   - Нажмите на неё

3. **Workflow запустится:**
   - Вы увидите новый запуск в списке
   - Статус будет "Queued" → "In progress" → "Success" или "Failure"

   - Если файл открывается — workflow существует
