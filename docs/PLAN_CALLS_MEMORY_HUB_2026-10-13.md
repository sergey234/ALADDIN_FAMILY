## 0. Одной фразой

МТС **пишет линию на стороне оператора**.  
ALADDIN на iPhone **не может** так же. Мы делаем лучший возможный продукт в правилах Apple: **одно место «Звонки»** + **подготовка до звонка** + **честная запись через Диктофон (динамик)** где техника позволяет + **после звонка — суть / antifake / семья**.

## 1. Было → Стало (простым языком)

### Было (сейчас)

- После звонка ALADDIN может напомнить: «проверьте запись» — но **сам разговор не запоминает**.
- Проверка записи — во вкладке Antifake «Звонок» (мошенники), отдельно от «о чём договорились».
- Диктофон умеет аудио + текст + выжимку, но это **общие заметки**, не раздел «Звонки».
- Call Assistant — ручные поля «зачем звоню / что сказали / что решили», спрятаны внутри Диктофона.
- Call Filter — метки на входящих (safety), не память договора.
- Companion: запись разговора **осознанно отменена** (X-01).

Итог для пользователя: фраза «а о чём мы договаривались?» всё ещё жива — нужно самому писать или помнить, куда тыкнул.

### Стало (после реализации)

1. В приложении появляется раздел **«Звонки»** — одна лента: все памятки, записи, выжимки и (по желанию) проверки antifake.
2. **До звонка** ALADDIN предлагает: «Подготовить звонок» → цель + согласие + режим записи.
3. Если пользователь согласен **записать**, ALADDIN открывает **Диктофон в режиме «Звонок»**, объясняет: *включите динамик / громкую связь*, нажимает «Начать», затем пользователь звонит как обычно.
4. После окончания звонка (CallKit) ALADDIN:
   - останавливает запись (если шла),
   - делает транскрипт + короткую выжимку («договорились / сумма / следующий шаг / риски»),
   - кладёт карточку в «Звонки»,
   - предлагает: «Проверить на мошенников?» (существующий antifake) — одной кнопкой.
5. Доступ в **пробном периоде 14 дней** и на **Family/Premium** — без отдельного «30 дней как МТС» и без обещания «пишем линию оператора».
6. Фраза «а о чём мы там договаривались?» закрывается поиском по разделу «Звонки».

**Честный дисклеймер в продукте (обязателен):**  
«ALADDIN записывает звук с микрофона телефона при громкой связи. Это не запись линии оператора, как у МТС. Собеседника лучше предупредить.»

## 2. Ответ на вопрос: «Можно ли до звонка предложить записать в Диктофон?»

### Да — и это лучший путь на iOS

| Вариант | Что видит пользователь | Реальность техники | Вердикт |
|---------|------------------------|--------------------|---------|
| **A. Подготовка до звонка (канон)** | В ALADDIN: «Готовлюсь к звонку» → согласие → «Начать запись» → Диктофон пишет → пользователь открывает Телефон / контакты и звонит, **динамик вкл.** | Запись мика начинается **до** захвата аудиосессии Phone. На части устройств запись **продолжается** рядом с звонком (mix); на части — **прерывается** CallKit (у нас уже autosave при interruption). | **Рекомендуем как основной UX** + fallback |
| **B. Уведомление во время звонка** | Push: «Записать суть после звонка» / «Открыть Диктофон» | Нельзя нарисовать UI поверх Phone.app. Во время активного PSTN запись мика часто **недоступна**. | Только soft-CTA, не обещать запись «прямо сейчас» |
| **C. После звонка** | «Сохранить, о чём договорились» голосом или текстом + optional antifake | Всегда работает | **Обязательный fallback** |
| **D. «Как МТС — само»** | Звонит как обычно, линия пишется сама | Нужен оператор / недоступно third-party iOS | **Не обещать** |

### Как сделать «наилучшим образом» (продуктовый канон)

```text
[В ALADDIN] Подготовить звонок
   → цель (опционально)
   → переключатель «Записать разговор (с динамика)»
   → экран согласия (1 раз + чекбокс)
   → кнопка «Начать запись и позвонить»
        → старт Voice Notes (tag: call_session)
        → deep link / share sheet / «Открыть Телефон» + подсказка «включите динамик»
[Звонок идёт]
   → Live Activity / Dynamic Island (если доступно): «ALADDIN пишет…»
   → если аудиосессия упала → local push: «Запись остановилась. После звонка сохраните суть»
[Звонок закончился — CallKit]
   → stop + STT + structured summary
   → карточка в «Звонки»
   → 2 кнопки: «Готово» | «Проверить на мошенников»
```

**Не делать:** тихую запись без явного старта; заявление «как оператор МТС»; запись без предупреждения о согласии собеседника.

## 3. Архитектура продукта

### 3.1 Раздел «Звонки» (новый хаб)

**Вход:**
- Main / Family shield / Settings рядом с Диктофоном  
- Deep link: `aladdin://calls` · `aladdin://calls/prep` · `aladdin://calls/{id}`  
- Post-call notification → `aladdin://calls/after`

**Вкладки / сегменты ленты:**
1. **Все** — единая хронология  
2. **Память** — аудио + транскрипт + выжимка (Voice Notes с `call_*` тегами)  
3. **Безопасность** — antifake verdicts по звонкам  
4. **Метки** — статус Call Directory (короткая карточка → настройки)

**Карточка звонка (CallSession):**
- дата/время, длительность записи (если была)  
- цель (до)  
- аудио ▶  
- транскрипт (сворачиваемый)  
- выжимка: Договорились / Суммы / Следующий шаг / Риски  
- статус antifake: нет / uncertain / likely_fake / likely_real  
- теги, поиск, шаринг (без сырого аудио по умолчанию в семью)

### 3.2 Модель данных (локально first)

```text
CallSession
  id, createdAt, endedAt?
  goal: String?
  mode: prepOnly | micRecord | postOnly | antifakeOnly
  audioPath?: String          // VoiceNotesStore
  transcript?: String
  summaryStructured?: {
    agreements, amounts, nextStep, risks, freeText
  }
  antifakeCheckId?: String
  consentVersion: String
  source: userPrep | postCallPush | importFile | callAssistant
```

- Хранение: расширение `VoiceNotesStore` **или** новый `CallSessionsStore` с ссылкой на audioPath (предпочтительно отдельный store + миграция тегов `call_assistant` / `call_session`).  
- Синхронизация на сервер: **по умолчанию выкл.** (как Voice Notes compliance). Opt-in Family share — только summary, не аудио.

### 3.3 Сервисы (переиспользовать)

| Уже есть | Роль в плане |
|----------|--------------|
| `VoiceNotesRecorderService` | Запись m4a |
| `VoiceNotesTranscriptionService` | STT |
| summary в VoiceNotes VM | База → заменить/дополнить structured call summary |
| `AntifakeCallObserverService` | Конец звонка → after-flow |
| `AntifakeCallTabView` + analyze API | Ветка «Безопасность» |
| `VoiceAudioSessionCoordinator` | Mutex с AI / Family voice |
| Call Assistant UI в VoiceNotes | Перенести/поднять в «Звонки» → Prep |

### 3.4 Технический риск записи во время PSTN (обязательный spike)

**GATES spike (до большого UI):**
1. iPhone A (актуальный iOS): старт Диктофона → динамик → исходящий звонок → 60 с речи → конец → файл целый?  
2. То же для входящего.  
3. Если interruption: autosave срабатывает? Длина файла?  
4. Матрица: 2–3 модели × 2 версии iOS.

**Исход spike → режим продукта:**
- **Green:** mic+speaker работает ≥70% сессий → режим «Запись с динамика» включён по умолчанию в Prep.  
- **Yellow:** часто рвётся → Prep предлагает запись, но после обрыва — обязательный after-flow «надиктуйте 30 сек сути».  
- **Red:** почти всегда рвётся → не продаём «запись во время звонка»; продаём Prep + after voice memo + import файла (Android-диктофон / гарнитура).

План UI пишется так, чтобы **все три** исхода spike не ломали продукт.

## 4. UX пошагово (мелочи)

### 4.1 Первый запуск «Звонки»

1. Экран: «Как ALADDIN запоминает звонки» (3 буллета + отличие от МТС одной строкой).  
2. Согласие на запись мика + предупреждение собеседника.  
3. Mic + Speech permission (существующие алерты Диктофона).  
4. Пояснение: доступно в пробном периоде 14 дней и на Family/Premium.

### 4.2 До звонка — «Подготовить»

Поля:
- Зачем звоню (placeholder как сейчас)  
- Кому (текст, **не** читать Contacts без permission; опционально)  
- Toggle: Записать с динамика  
- Toggle: После звонка предложить проверку antifake (default ON для Family/Premium policy)

CTA primary: **«Начать»**  
Secondary: **«Только заметка после»** (без записи)

Если запись ON:
- полноэкранный coachmark: «1) Нажмите Старт 2) Включите динамик 3) Позвоните»  
- кнопка «Открыть Телефон»

### 4.3 Во время звонка

- Не лезем в Phone UI.  
- Если запись жива: Dynamic Island / Local Activity «Идёт запись ALADDIN» + Stop.  
- Если interruption: один push (cooldown 15 мин, как antifake policy): «Запись прервалась. Сохраните суть после звонка».

### 4.4 После звонка

Единый after-sheet (замена разрозненных баннеров):

```text
Разговор завершён
[если есть аудио] Обрабатываем… → Выжимка готова
[если нет аудио]  Надиктуйте 30 секунд / Напишите суть
[ ] Проверить на мошенников (Antifake)
Сохранить в «Звонки»
```

Structured summary prompt (локально или Hermes opt-in):
- О чём договорились  
- Цифры / суммы / даты  
- Что сделать дальше  
- Красные флаги (пароль, перевод, «сотрудник банка») → если флаги — soft-CTA в antifake

### 4.5 Лента и поиск

- Поиск по транскрипту / выжимке / цели  
- Фильтр «с аудио» / «только текст» / «с риском antifake»  
- Свайп: удалить (soft 24h как family chat policy, если уже есть паттерн)  
- Share: текст выжимки; аудио — только явным export

### 4.6 Семья (дифференциатор vs МТС)

- Родитель / опекун: опциональный алерт «близкий сохранил звонок с флагом риска» (без полного транскрипта по умолчанию).  
- Elderly flow: не заменять текущий full-screen «просили деньги/код»; **встроить** кнопку «Сохранить в Звонки» после.

### 4.7 Доступ (триал 14 дней — канон ALADDIN)

- **Нет** отдельного trial «память звонков на 30 дней».  
- Доступ = `Family` / `Premium` **или** активный **subscription trial 14 дней** (существующий тарифный триал).  
- Free без триала: хаб «Звонки» показывает paywall / CTA тарифов (как antifake Hub).  
- Copy везде: «в пробном периоде и на Family/Premium» — **не** «30 дней как МТС».  
- Не смешивать с VPN trial без явного ТЗ.

## 10. Критерии «наилучшим образом»

Продукт считается отличным, если:
1. Пользователь **за 2 тапа** до звонка может включить память.  
2. Даже при обрыве записи он **всё равно** получает карточку «о чём договорились».  
3. Safety (antifake + elderly) и Memory живут в **одном** разделе, не конкурируют.  
4. Copy честный — доверие семьи > хайп «как МТС».  
5. Local-first, удаление лёгкое, trial понятный.
