## 🔍 НАГРУЗОЧНОЕ ТЕСТИРОВАНИЕ БЕЗ ПОЛЬЗОВАТЕЛЕЙ

### ❌ S4-05: Нагрузочное тестирование (1,000 пользователей)

**Как сделать без пользователей:**

**Инструменты:**
1. **Apache Bench (ab)** - простой, уже установлен на macOS
2. **wrk** - быстрый, нужно установить
3. **Locust** - Python инструмент с веб-интерфейсом
4. **k6** - современный инструмент

**Пример с Apache Bench:**
```bash
# 1,000 пользователей, 100 одновременных запросов, 10 запросов на пользователя
ab -n 10000 -c 100 https://aladdin-ai.ru/api/health
```

**Пример с wrk:**
```bash
# 1,000 пользователей, 100 потоков, 30 секунд
wrk -t 100 -c 1000 -d 30s https://aladdin-ai.ru/api/health
```

**Пример с Locust:**
```python
# Создать файл locustfile.py
from locust import HttpUser, task, between

class APIUser(HttpUser):
    wait_time = between(1, 3)
    
    @task
    def health_check(self):
        self.client.get("/api/health")
    
    @task(3)
    def get_family(self):
        self.client.get("/api/family/members")
```

**Запуск:**
```bash
pip install locust
locust -f locustfile.py --users 1000 --spawn-rate 100
```

**Что тестировать:**
- Время ответа
- Количество запросов в секунду (RPS)
- Процент ошибок
- Использование CPU, RAM
- Пропускная способность

**Время:** 2-3 часа

### ❌ S4-07: Нагрузочное тестирование (10,000 пользователей)

**Как сделать:**
- Использовать распределенное тестирование
- Запустить несколько инстансов инструмента
- Использовать более мощные инструменты (k6, JMeter)

**Пример с k6:**
```javascript
import http from 'k6/http';
import { check } from 'k6';

export let options = {
  stages: [
    { duration: '30s', target: 1000 },
    { duration: '1m', target: 5000 },
    { duration: '1m', target: 10000 },
    { duration: '30s', target: 0 },
  ],
};

export default function () {
  let res = http.get('https://aladdin-ai.ru/api/health');
  check(res, { 'status was 200': (r) => r.status == 200 });
}
```

**Время:** 4-5 часов
