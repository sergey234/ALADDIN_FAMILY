## 🔴 КРИТИЧЕСКИЕ ПРОВЕРКИ (ДОБАВЛЕНЫ)

Для каждой функции при интеграции router в `main.py` теперь проверяется:

### 1. ✅ Импорты ПЕРЕД использованием
- ❌ **Было:** Импорт router после блока try/except → `NameError: name 'dark_web_router' is not defined`
- ✅ **Правильно:** Импорт ПЕРЕД блоком try/except

### 2. ✅ Logger vs print
- ❌ **Было:** `logger.info()` когда logger не определен → `NameError: name 'logger' is not defined`
- ✅ **Правильно:** Использовать `print()` в блоке try/except

### 3. ✅ EmailStr vs str
- ❌ **Было:** `EmailStr` требует пакет `email-validator` → `ImportError: email-validator is not installed`
- ✅ **Правильно:** Использовать `str` с валидацией через `@validator`

### 4. ✅ Отступы в `if __name__`
- ❌ **Было:** Неправильные отступы → `IndentationError: unexpected indent`
- ✅ **Правильно:** Все строки с отступом 4 пробела

### 5. ✅ Перезапуск backend
- ❌ **Было:** Старый процесс занимает порт, новый не может запуститься
- ✅ **Правильно:** Остановить старый, перезапустить через systemd

- ✅ Backend код готов и правильный
- ✅ Router добавлен в `main.py`
- ✅ Router регистрируется успешно при импорте
- ❌ **НО:** Старый процесс backend запущен со старой версией `main.py` (без нашего router)
- ❌ Новый процесс не может запуститься, потому что порт 8000 занят старым процессом

### Решение:
```bash
# 1. Найти старый процесс
ps aux | grep uvicorn | grep main

# 2. Остановить старый процесс
kill <PID>
# или
systemctl stop aladdin-backend

# 3. Перезапустить backend
systemctl restart aladdin-backend

# 4. Проверить health check
curl http://localhost:8000/api/darkweb/health
```
