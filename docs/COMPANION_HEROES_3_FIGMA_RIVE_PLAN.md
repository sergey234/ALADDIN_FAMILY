## 2.1 Стили речи × 3 героя — метод «6 шляп» (утверждено)

> **Продуктовое решение:** у каждого героя свой **базовый голос**; семейный preset и возраст **накладываются сверху**.  
> **Джин** — герой с **максимальной долей шуток** (≈2× чаще, чем у Единорога; ≈3× чаще, чем у человека-Аладдина).  
> **Сарказм над человеком** — запрещён везде; **лёгкая ирония / каламбур** — только **genie + teen/parent**, PG-13.

### Белая шляпа (факты — что в коде сейчас)

| Слой | Где | Сейчас |
|------|-----|--------|
| База героя | `companion_persona.companion_system_base()` | Только **unicorn** vs **всё остальное = aladdin**; `genie` нет |
| Семейный preset | `PERSONALITY_PRESET_HINTS` | `friendly` · `calm` · `playful` · `mentor` — **общие для всех** |
| Возраст | `AGE_BAND_PERSONA_ADDON` | child / teen / parent / senior |
| Момент | `companion_intent_router` | `playful` → hint «лёгкий PG-юмор»; **без учёта героя** |
| TTS | `CompanionSpeechOutput.swift` | rate/pitch по **preset**, не по `character_id` |
| Запреты | `playful` preset | «**без сарказма**»; NSFW/флирт в `_COMMON_RULES` |

### Красная шляпа (эмоции пользователя)

| Аудитория | Ожидание от голоса |
|-----------|-------------------|
| Ребёнок + Единорог | Смех «как с другом», без едкости; шутки про единорогов, игры, школу |
| Подросток + Джин | Магия, мемы, **больше остроумия**; иногда ирония «как в сказке», не насмешка |
| Родитель + Аладдин-человек | Спокойный наставник; юмор редко, по запросу |
| 60+ + Аладдин | Тепло, неторопливо; **nostalgic** важнее шуток |

### Чёрная шляпа (риски)

| Риск | Митигация |
|------|-----------|
| Child + genie + witty | **age_policy:** child → только `unicorn`; genie скрыт в Hub |
| Сарказм / буллинг маскируется под юмор | Правило: не высмеивать пользователя, внешность, семью; этика L1–L3 |
| Ирония у teen → обида | Только мягкая; при `sad`/`comfort_needed` — **ноль шуток** |
| Слишком много шуток при кризисе | Intent: crisis **до** playful; genie humor density = 0 при L3 |
| Родитель выбрал `playful` + genie → двойной юмор | Cap: не больше **1 шутки/анекдота на ответ** (кроме явного «расскажи 5 шуток») |

### Жёлтая шляпа (выгода)

- Три узнаваемых «голоса» без трёх приложений.
- Джин = дифференциатор для teen («магический друг с юмором»).
- Preset `witty` даёт взрослым контроль без ломки child-safe `playful`.
- TTS + Rive `playful` синхронны с текстом.

### Зелёная шляпа (идеи — принято в roadmap)

1. Preset **`witty`** — «сказочный юмор, каламбуры, лёгкая ирония PG-13, без сарказма над человеком».
2. **`CHARACTER_DEFAULT_PRESET`** при первом выборе героя (если семья не меняла preset).
3. **`humor_density`** в intent hint: `low` | `medium` | `high` по `character_id`.
4. Genie-only фразы в Rive: `playful` / `excited` чаще на аватаре при humor intent.
5. P2-16 trust: баллы за уместный юмор (не только security).

## 2.2 Движение × 3 героя — метод «6 шляп» (утверждено)

> **Продуктовое решение:** во время диалога герой проходит **фазы** (listening → thinking → speaking) и **эмоции контента** (happy, sad, playful…).  
> Один язык — input Rive **`emotion`** (строка, 12 значений). **Три `.riv`** — разная **хореография**, не разные имена state.  
> **Lip-sync MVP:** цикл `speaking` + input **`mouth_open`** (0…1) от TTS; production — viseme позже (не HERO-3).

### Белая шляпа (факты — что в коде сейчас)

| Компонент | Где | Сейчас |
|-----------|-----|--------|
| Фазы диалога | `CompanionConversationScreen.swift` | `listening` → `thinking` → `speaking` / emotion из BE |
| 12 эмоций | `CompanionHeroEmotion`, `companion_emotions.py` | ✅ синхрон имен |
| Rive bridge | `CompanionHeroRiveHost.swift` | `setInput("emotion", value:)` |
| Fallback motion | `CompanionHeroAnimatedView.swift` | bob, pulse, tilt, overlays; **`lipSyncPhase` не двигает рот** |
| Lip-sync | `lipSyncPhase` + TTS | флаг при `speaking`, без привязки к аудио |
| Production `.riv` | `Resources/Companion/` | placeholder; **genie.riv** нет |

### Красная шляпа (эмоции пользователя)

| Момент | Ожидание движения |
|--------|-------------------|
| Ребёнок говорит | Герой **внимательно слушает** (listening), без пугающих жестов |
| Ждёт ответ | **Думает** (thinking) — не «завис», а живой |
| Ответ + голос | **Говорит** (speaking), рот/лицо синхронно с TTS |
| Шутка | **playful** — оживление, не статичное speaking |
| Грусть | **comfort/sad** — мягко, **без** прыжков и искр |
| Угроза | **alert** — серьёзно, стабильная поза |

### Чёрная шляпа (риски)

| Риск | Митигация |
|------|-----------|
| 12 state в Rive неразличимы на 96pt | MOTION-Q + D10; минимум 4px разница бровей/рта |
| Дёргание при stream (emotion меняется каждый chunk) | Debounce смены emotion: **≥ 400 ms** или только на `done` SSE |
| speaking без TTS (только текст) | speaking **1.2 s** min, затем emotion из BE |
| Три героя выглядят одинаково | §2.2 матрица «акцент движения» + отдельные .riv |
| Lip-sync лагает | MVP: `mouth_open` синус от `isSpeaking`; не viseme в HERO-3 |

### Жёлтая шляпа (выгода)

- Один SM input `emotion` — проще BE/iOS/QA.
- Фазы диалога узнаваемы без чтения текста (accessibility).
- Genie: дым/искры при speaking — бренд OB_02–07.

### Зелёная шляпа (принято в roadmap)

1. **Motion Spec** (таблица ниже) — DoD для Figma + Rive (**HERO-3-17**).
2. **Диалоговый таймлайн** — единый для text/stream/voice (**HERO-3-18**).
3. **Lip-sync MVP** — `mouth_open` + procedural рот (**HERO-3-19**).
4. Опционально P2: Rive input `blink` random idle.

### Диалоговый таймлайн (единый для text / stream / voice)

```
                    ┌─────────┐
         Hub        │  idle   │ loop, лёгкое дыхание
                    └────┬────┘
                         │ открыт чат
                    ┌────▼────┐
                    │  idle   │ ждёт ввод
                    └────┬────┘
          mic tap        │         send text
     ┌───────────────────┼───────────────────┐
     ▼                   │                   ▼
┌──────────┐              │            ┌──────────┐
│listening │              │            │ thinking │
└────┬─────┘              │            └────┬─────┘
     │ STT / send         │                 │ SSE meta.emotion / response
     └──────────►┌────────▼────────┐◄────────┘
                 │    thinking     │
                 └────────┬────────┘
                          │ первая реплика ассистента + TTS
                 ┌────────▼────────┐
                 │    speaking     │ + mouth_open (TTS)
                 └────────┬────────┘
                          │ TTS end / stream done
                 ┌────────▼────────┐
                 │ happy / playful │  ← emotion из BE (не listening/speaking)
                 │ / sad / alert…  │
                 └─────────────────┘
```

| Событие iOS | `heroEmotion` | Rive `emotion` | Примечание |
|-------------|---------------|----------------|------------|
| Экран чата, нет активности | `idle` | `idle` | Hub: то же |
| Tap mic, запись | `listening` | `listening` | Кольцо/уши «слушаю» |
| Отправка / конец STT | `thinking` | `thinking` | До первого ответа |
| Stream chunk с `emotion` | BE value | то же | Debounce 400 ms |
| Ответ + `speechOutput.speak` | `speaking` → затем BE | `speaking` → … | `lipSyncPhase=1` |
| TTS `didFinish` | BE или `happy` | то же | `lipSyncPhase=0` |
| Ошибка / нет mic | `alert` | `alert` | |

**Правило:** `listening` / `thinking` / `speaking` — **фазы UI**; `happy`, `sad`, `playful`… — **контент** после реплики. Фазы **не смешать** в одном кадре (не `speaking`+`sad` одновременно в Rive — сначала speaking, потом sad).

**Переходы Rive (рекомендация):** cross-fade **200–300 ms**; `idle` ↔ остальные; `listening` ↔ `thinking` **150 ms**.

### Motion Spec — 12 state × что рисовать (DoD Figma/Rive)

Колонки для **каждого** героя (3× таблица в Figma `00_Spec/Motion`).

| `emotion` | Loop | Тело / поза | Глаза | Рот / рот | Длительность loop |
|-----------|------|-------------|-------|-----------|-------------------|
| **idle** | да | дыхание ±2px | мягкий взгляд | нейтраль | 2.0 s |
| **listening** | да | наклон к пользователю 3–5° | внимание, реже моргание | закрыт / лёгкая улыбка | 1.5 s |
