## 📋 СТРУКТУРА КАРТОЧКИ

Каждая карточка содержит:
- **Иконка** (emoji)
- **Название** (title) - локализовано
- **Статус** (status) - локализовано, может быть динамическим
- **Метрика** (metric) - локализовано, может быть динамическим
- **Цвет** (color) - для фона и границы

---

## 🔍 ДОПОЛНИТЕЛЬНАЯ ИНФОРМАЦИЯ

### Функция создания карточки:
```swift
gameCardButton(
    icon: String,
    title: String,
    status: String,
    metric: String,
    color: Color,
    destination: NavigationManager.ALADDINScreen
)
```

### Внутренняя структура карточки:
1. Иконка (emoji) - большой размер
2. Статус (status) - маленький текст сверху
3. Название (title) - жирный текст по центру
4. Метрика (metric) - маленький текст снизу
