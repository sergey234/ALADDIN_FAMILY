## 🔍 КАК РАБОТАЕТ КРЕДИТНЫЙ ЗАМОК В РОССИИ?

### Система кредитных бюро:

**Основные бюро:**
1. **НБКИ** (Национальное бюро кредитных историй) - крупнейшее
2. **ОКБ** (Объединенное кредитное бюро) - второе по размеру
3. **Другие** - есть еще несколько мелких бюро

### Как банки получают кредитную историю:

```
Банк → Запрос кредитной истории → НБКИ/ОКБ → Проверка статуса
                                                ↓
                                    ЗАМОРОЖЕНА? 
                                    ↓           ↓
                                   ДА          НЕТ
                                    ↓           ↓
                              Отказ в доступе  Возврат истории
                                    ↓
                            Банк не может выдать кредит
```

### Что делает заморозка:

1. **Бюро устанавливает флаг "заморожено"**
   - В базе данных бюро
   - Для конкретного пользователя

2. **Банк запрашивает кредитную историю**
   - Отправляет запрос в НБКИ/ОКБ

3. **Бюро проверяет флаг**
   - Если заморожено → отказывает в доступе
   - Если не заморожено → возвращает историю

4. **Банк получает ответ**
   - Если отказано → не может выдать кредит
   - Если история получена → может выдать кредит
