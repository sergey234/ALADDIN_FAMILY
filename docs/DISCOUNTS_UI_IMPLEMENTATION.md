## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Функция расчета цены:

```swift
private func calculatePrice(for tariff: TariffType, periodMonths: Int) -> (finalPrice: Int, originalPrice: Int, discountPercent: Int?, monthlyPrice: Int, savings: Int?) {
    let basePrice = getBaseMonthlyPrice(for: tariff)
    
    if periodMonths == 1 {
        return (basePrice, basePrice, nil, basePrice, nil)
    }
    
    let originalPrice = basePrice * periodMonths
    let discountPercent: Int
    switch periodMonths {
    case 3: discountPercent = 10
    case 6: discountPercent = 15
    case 12: discountPercent = 20
    default: discountPercent = 0
    }
    
    let discount = Int(Double(originalPrice) * Double(discountPercent) / 100.0)
    var finalPrice = originalPrice - discount
    
    // Специальная обработка для BASIC 12 месяцев (экономия должна быть 700₽)
    if tariff == .personal && periodMonths == 12 {
        finalPrice = 2780  // 3480 - 700 = 2780
    }
    
    let monthlyPrice = finalPrice / periodMonths
    let savings = originalPrice - finalPrice
    
    return (finalPrice, originalPrice, discountPercent, monthlyPrice, savings)
}
```

## 📱 КАК РАБОТАЕТ

1. **Пользователь открывает экран тарифов**
   - Видит карточки тарифов
   - Для платных тарифов (PERSONAL, FAMILY, PREMIUM) видит сегментированный контрол
   - По умолчанию выбран период "1 месяц"

2. **Пользователь выбирает период (например, 12 месяцев)**
   - UI обновляется автоматически
   - Показывается зачеркнутая цена: ~~3480₽~~
   - Показывается итоговая цена: **2780₽**
   - Показывается бейдж скидки: **-20%**
   - Показывается цена за месяц: **232₽/месяц**
   - Показывается экономия: **Экономия 700₽** (зеленым)

3. **Пользователь нажимает "Выбрать тариф"**
   - Создается объект `Tariff` с выбранным периодом и ценой
   - Переход на экран QR-оплаты (или IAP)
   - Передается итоговая цена с учетом скидки
