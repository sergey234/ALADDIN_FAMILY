# Phase 0 — Spike: запись с динамика во время SIM-звонка

**Цель:** понять, держится ли Диктофон ALADDIN, пока идёт обычный телефонный звонок.  
**GO:** вариант 1 · 2026-10-13  
**Результат писать в DEBUG хаба «Звонки»** (кнопки green/yellow/red) или сюда вручную.

## Как прогнать (5–10 мин)

1. Settings → **Звонки** → «Подготовить звонок».
2. Включи «Записать с динамика», согласие, **Начать и открыть Телефон**.
3. Включи **громкую связь**, позвони на второй телефон / автоответчик (~60 сек говори).
4. Положи трубку.
5. Вернись в ALADDIN.

## Оценка

| Итог | Критерий | Что ставим |
|------|----------|------------|
| **Green** | Файл записи ≥ ~40 с, слышна речь собеседника (хоть тихо) | `green` |
| **Yellow** | Запись оборвалась, но после звонка after-sheet помог сохранить суть | `yellow` |
| **Red** | Мик во время звонка почти никогда не пишет | `red` → продаём Prep + after, без «записи во время» |
