## 🔄 ПЕРЕКЛЮЧЕНИЕ MOCK/REAL

### Включить Mock API:

```swift
AppConfig.useMockAPI = true
// Перезапустить приложение
```

### Выключить Mock API:

```swift
AppConfig.useMockAPI = false
// Перезапустить приложение
```

### Проверить текущий статус:

```swift
print("Mock API: \(AppConfig.useMockAPI ? "ВКЛЮЧЕН" : "ВЫКЛЮЧЕН")")
```

## 🐛 ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### Проблема 1: Mock API не работает

**Решение:**
1. Проверить, что `AppConfig.useMockAPI == true`
2. Перезапустить приложение
3. Проверить, что в DEBUG режиме

### Проблема 2: Данные не загружаются

**Решение:**
1. Проверить консоль на ошибки
2. Убедиться, что MockAPIService.swift в проекте
3. Проверить, что методы переопределены правильно

### Проблема 3: Задержка слишком долгая

**Решение:**
- Задержка симулируется случайно (0.5-1.5 сек)
