### **1. Индикатор источника данных в UI:**

- Должен показывать "Нет данных" (⚪) для нового пользователя

### **2. Детали по угрозам:**
- Не должно быть бесконечной загрузки
- Должно быть сообщение "Нет данных об угрозах" (если данных нет)

- Откройте Xcode → View → Debug Area → Activate Console
- Должны быть DEBUG print statements:
  - `📊 RemoteAnalyticsService: fetchSummary - начинаем запрос к API`
  - `📊 RemoteAnalyticsService: fetchSummary - получен ответ от API`
  - `📊 RemoteAnalyticsService: fetchSummary - успех` или `API failed`
