# ✅ ИСПРАВЛЕНИЕ: Убрана страница загрузки перед онбордингом

## 🎯 ПРОБЛЕМА РЕШЕНА

**Версия:** BUILD 90  
**Статус:** ✅ ИСПРАВЛЕНО

---

## 🔍 ЧТО БЫЛО

### **Проблема:**
- При первом запуске приложения показывалась страница загрузки с единорогом (`AppLoadingView`)
- Затем показывался онбординг
- Пользователь видел две страницы подряд

### **Причина:**
- `NavigationManager` инициализировался с `currentScreen = .loading` по умолчанию
- Только в `onAppear` вызывался `initializeNavigation()` который менял на `.onboarding`
- Между созданием View и `onAppear` была задержка

---

## ✅ ЧТО ИСПРАВЛЕНО

### **Изменения в `NavigationManager.swift`:**

**БЫЛО:**
```swift
@Published var currentScreen: ALADDINScreen = .loading  // По умолчанию
```

**СТАЛО:**
```swift
@Published var currentScreen: ALADDINScreen

init() {
    // Проверяем онбординг сразу при инициализации
    let onboardingDone = UserDefaults.standard.bool(forKey: AppConfig.UserDefaultsKeys.hasCompletedOnboarding)
    if onboardingDone {
        self.currentScreen = .main
    } else {
        self.currentScreen = .onboarding  // Сразу онбординг, без страницы загрузки
    }
}
```
