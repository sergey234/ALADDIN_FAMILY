# 📋 РАЗНИЦА МЕЖДУ СХЕМАМИ: ALADDIN, ALADDIN 1, ALADDINContentBlocker

## 🔍 Анализ схем

После проверки файлов схем, вот что я обнаружил:

---

## 1. **ALADDIN** ✅ (РЕКОМЕНДУЕТСЯ)

### Что это:
- **Основная схема для разработки**
- Запускает основное приложение `ALADDIN.app`

### Характеристики:
- ✅ **Build Configuration:** `Debug` (для разработки)
- ✅ **Включает тесты:** `ALADDINUnitTests` и `ALADDINUITests`
- ✅ **Подходит для:** Разработки, отладки, тестирования
- ✅ **Можно запускать на устройстве:** Да

### Когда использовать:
- **Для разработки** — основная схема
- **Для отладки** — видите все логи
- **Для тестирования** — запускаются unit и UI тесты
- **Для просмотра логов NetworkManager** — используйте эту схему

---

## 2. **ALADDIN 1** ⚠️ (ДУБЛИКАТ/СПЕЦИАЛЬНАЯ)

### Что это:
- **Упрощенная схема** (похоже на дубликат)
- Запускает основное приложение `ALADDIN.app`

### Характеристики:
- ⚠️ **Build Configuration:** `Release` (для запуска!)
- ⚠️ **НЕ включает тесты** — тесты отключены
- ⚠️ **Кастомный LLDB init файл** — специальная настройка отладчика
- ⚠️ **Подходит для:** Релиза, финального тестирования

### Когда использовать:
- **Для финального тестирования** перед релизом
- **Для проверки Release сборки** — как будет работать в продакшене
- **НЕ для разработки** — логи могут быть ограничены

### ⚠️ Внимание:
- Это похоже на дубликат схемы `ALADDIN`
- Возможно, создана для специальных целей
- **Рекомендуется использовать `ALADDIN` для разработки**

---

## 3. **ALADDINContentBlocker** ❌ (РАСШИРЕНИЕ)

### Что это:
- **Схема для расширения Content Blocker**
- Запускает расширение `ALADDINContentBlocker.appex`
- Также включает основное приложение `ALADDIN.app`

### Характеристики:
- ❌ **wasCreatedForAppExtension = "YES"** — это расширение
- ❌ **НЕЛЬЗЯ запускать отдельно** — расширения не запускаются сами по себе
- ❌ **Запускается автоматически** вместе с основным приложением

### Когда использовать:
- **НЕ используйте для запуска приложения**
- Расширение запускается автоматически, когда основное приложение использует Content Blocker
- **Только для отладки расширения** (редко)

### ⚠️ Внимание:
- Если выбрать эту схему, появится ошибка:
  ```
  The run destination iPhone is not valid for Running the scheme 'ALADDINContentBlocker'
  ```
- **НЕ выбирайте эту схему для обычного запуска**

## 🎯 Рекомендации

### Для разработки и просмотра логов:
```
✅ Используйте: ALADDIN
```

**Почему:**
- Debug конфигурация — видите все логи
- Включает тесты — можете запускать тесты
- Оптимально для разработки

### Для финального тестирования:
```
⚠️ Можно использовать: ALADDIN 1
```

**Почему:**
- Release конфигурация — как в продакшене
- Проверка финальной сборки

### НЕ используйте:
```
❌ ALADDINContentBlocker
```

**Почему:**
- Это расширение, не приложение
- Нельзя запускать отдельно

---

## 💡 Что делать с "ALADDIN 1"?

### Вариант 1: Оставить как есть
- Использовать для финального тестирования
- Не мешает основной разработке

### Вариант 2: Удалить (если не нужна)
- Если это дубликат и не используется
- Можно удалить через Xcode: Scheme → Manage Schemes → удалить "ALADDIN 1"

### Вариант 3: Переименовать
- Переименовать в "ALADDIN Release" для ясности
- Xcode → Scheme → Manage Schemes → переименовать

## 📌 Итог

**Для вашей задачи (просмотр логов NetworkManager):**

1. ✅ **Выберите схему `ALADDIN`**
2. ✅ **Выберите ваше устройство**
3. ✅ **Запустите приложение (Cmd + R)**
4. ✅ **Откройте Debug Console (Shift + Cmd + Y)**
5. ✅ **Примените фильтр: `subsystem:com.aladdin.network`**

**Не используйте:**
- ❌ `ALADDIN 1` — для разработки (Release конфигурация)
- ❌ `ALADDINContentBlocker` — это расширение, не приложение
