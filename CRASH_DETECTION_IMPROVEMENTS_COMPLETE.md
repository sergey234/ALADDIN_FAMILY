### 2. 🔋 Оптимизация батареи (>50km/h)
**Реализовано в CrashDetectionManager:**

#### Новые методы:
```swift
// Мониторинг скорости для активации датчиков
private func startSpeedMonitoring()
private func stopSpeedMonitoring()
private func getCurrentSpeedKmh() async throws -> Double

// Порог скорости
private let speedThreshold: Double = 50.0 // km/h
```

#### Логика работы:
- **При скорости < 50 km/h:** Датчики ОТКЛЮЧЕНЫ (экономия батареи)
- **При скорости > 50 km/h:** Датчики ВКЛЮЧЕНЫ (мониторинг аварий)
- **Проверка скорости:** Каждые 5 секунд

**Результат:** Значительная экономия батареи при городской езде

---

### 3. ⚙️ Настройки чувствительности (Low/Medium/High)
**Добавлен enum CrashDetectionSensitivity:**
```swift
enum CrashDetectionSensitivity: String, Codable, CaseIterable {
    case low = "low"       // G > 4.0 (надежнее, но может пропустить)
    case medium = "medium" // G > 3.0 (баланс)
    case high = "high"     // G > 2.0 (чувствительнее, больше ложных)
}
```

#### Новые методы управления:
```swift
func setSensitivity(_ sensitivity: CrashDetectionSensitivity)
func getSensitivity() -> CrashDetectionSensitivity
func getCurrentGForceThreshold() -> Double
```

**Результат:** Пользователи могут настроить чувствительность под свои нужды
