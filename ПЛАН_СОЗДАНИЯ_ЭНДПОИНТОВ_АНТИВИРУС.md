## 🔧 SFM ФУНКЦИИ

### 1. ФУНКЦИЯ: `get_malware_threats`

**Параметры:**
- `status` (optional): Фильтр по статусу

**Возвращает:**
- Список угроз пользователя
- Статистику (total, active, quarantined, resolved)

**Реализация:**
```python
def get_malware_threats(status: str = None) -> dict:
    """Получить список угроз пользователя"""
    # Получить user_id из JWT токена
    user_id = get_current_user_id()
    
    # Запрос к базе данных
    query = "SELECT * FROM threats WHERE user_id = %s"
    params = [user_id]
    
    if status:
        query += " AND status = %s"
        params.append(status)
    
    threats = db.execute(query, params)
    
    # Подсчет статистики
    total = len(threats)
    active = sum(1 for t in threats if t["status"] == "active")
    quarantined = sum(1 for t in threats if t["status"] == "quarantined")
    resolved = sum(1 for t in threats if t["status"] == "resolved")
    
    return {
        "threats": threats,
        "total": total,
        "active": active,
        "quarantined": quarantined,
        "resolved": resolved
    }
```

### 2. ФУНКЦИЯ: `quarantine_file_action`

**Параметры:**
- `threatId`: ID угрозы
- `action`: Действие (`quarantine`, `restore`, `remove`)
- `filePath`: Путь к файлу (optional)

**Возвращает:**
- Результат действия
- Обновленную информацию об угрозе

**Реализация:**
```python
def quarantine_file_action(threat_id: str, action: str, file_path: str = None) -> dict:
    """Выполнить действие с файлом в карантине"""
    user_id = get_current_user_id()
    
    # Получить угрозу из базы данных
    threat = db.execute(
        "SELECT * FROM threats WHERE id = %s AND user_id = %s",
        [threat_id, user_id]
    )
    
    if not threat:
        return {"success": False, "error": "Угроза не найдена"}
    
    # Выполнить действие
    if action == "quarantine":
        # Поместить в карантин
        db.execute(
            "UPDATE threats SET status = 'quarantined', quarantined_at = NOW() WHERE id = %s",
            [threat_id]
        )
        message = "Файл помещен в карантин"
        
    elif action == "restore":
        # Восстановить из карантина
        db.execute(
            "UPDATE threats SET status = 'active', quarantined_at = NULL WHERE id = %s",
            [threat_id]
        )
        message = "Файл восстановлен из карантина"
        
    elif action == "remove":
        # Удалить навсегда
        db.execute("DELETE FROM threats WHERE id = %s", [threat_id])
        message = "Файл удален навсегда"
        
    else:
        return {"success": False, "error": "Неизвестное действие"}
    
    # Получить обновленную угрозу
    updated_threat = db.execute(
        "SELECT * FROM threats WHERE id = %s",
        [threat_id]
    )
    
    return {
        "success": True,
        "message": message,
        "threat": updated_threat[0] if updated_threat else None
    }
```

## 📊 БАЗА ДАННЫХ

### Таблица `threats`:

```sql
CREATE TABLE threats (
    id VARCHAR(255) PRIMARY KEY,
    user_id VARCHAR(255) NOT NULL,
    name VARCHAR(255) NOT NULL,
    type VARCHAR(50) NOT NULL,
    severity VARCHAR(20) NOT NULL,
    confidence DECIMAL(3,2) NOT NULL,
    file_path TEXT,
    file_size BIGINT,
    detected_at TIMESTAMP NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    quarantine_path TEXT,
    quarantined_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_status (user_id, status),
    INDEX idx_detected_at (detected_at)
);
```
