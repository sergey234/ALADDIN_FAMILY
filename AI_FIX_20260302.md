# 🔧 AI Assistant 404 Fix - 02.03.2026

## Проблема
AI Assistant возвращал 404 Not Found из-за дублирования сегмента `/api` в URL запроса.

**Лог ошибки:**
```
POST https://aladdin-ai.ru/api/api/ai/assistant/chat → 404
```

## Причина
В `AppConfig.swift` поле `apiBaseURL` содержало `/api` в конце:
```swift
return "https://aladdin-ai.ru/api"  // ❌ Дублирует /api
```

Endpoints тоже начинались с `/api/...`:
```swift
static let aiAssistantChat = "/api/ai/assistant/chat"
```

Итоговый URL: `"https://aladdin-ai.ru/api" + "/api/ai/assistant/chat"` = `https://aladdin-ai.ru/api/api/ai/assistant/chat`

## Исправление
Убрали `/api` из `apiBaseURL`, оставив каноничное состояние (scheme + host):
```swift
return "https://aladdin-ai.ru"  // ✅ Правильно
```
