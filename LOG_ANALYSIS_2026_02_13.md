## 🔧 ЧТО НУЖНО ИСПРАВИТЬ:

### **1. Перезагрузка профиля после авторизации** ⚠️

**Проблема:**
- Профиль загружается при инициализации `UserProfileManager` (до авторизации)
- После авторизации профиль не перезагружается

**Решение:**
- Добавить уведомление о успешной авторизации
- Перезагрузить профиль при получении токена

**Код:**
```swift
// В FamilyRegistrationViewModel после сохранения токенов
NotificationCenter.default.post(name: NSNotification.Name("UserDidLogin"), object: nil)

// В UserProfileManager
NotificationCenter.default.addObserver(
    self,
    selector: #selector(handleUserDidLogin),
    name: NSNotification.Name("UserDidLogin"),
    object: nil
)

@objc private func handleUserDidLogin() {
    loadProfile()
}
```
