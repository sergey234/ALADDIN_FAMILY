### **1. СУЩЕСТВОВАНИЕ И СТРУКТУРА**

#### **1.1. Функция существует?**
- **Команда:** `grep -r "def function_name" /opt/aladdin-backend/`
- **Проверяем:**
  - Есть ли функция в коде?
  - Где она находится?
  - Какие параметры принимает?
  - Что возвращает?

**Пример:**
```bash
# Проверка функции create_family
sshpass -p 'Sergio675' ssh root@149.154.65.180 \
  "cd /opt/aladdin-backend && grep -r 'def create_family' security/ app/"
```

**Результат:**
- ✅ Функция найдена в `security/family/family_registration.py`
- ✅ Принимает: role, age_group, personal_letter, device_type
- ✅ Возвращает: dict с family_id, recovery_code, members

---

#### **1.2. FastAPI endpoint добавлен?**
- **Команда:** `grep -r "@router\.(get|post|put|delete).*path" /opt/aladdin-backend/`
- **Проверяем:**
  - Есть ли декоратор `@router.get/post/put/delete`?
  - Правильный ли путь endpoint'а?
  - Есть ли модели запроса/ответа (Pydantic)?

**Пример:**
```bash
# Проверка endpoint /api/family/create
sshpass -p 'Sergio675' ssh root@149.154.65.180 \
  "cd /opt/aladdin-backend && grep -r '@router.post.*create' app/routers/"
```

**Результат:**
- ❌ Endpoint не найден в `app/routers/family.py`
- ⚠️ Нужно добавить `@router.post("/create")`

---

#### **1.3. Роутер подключен в main.py?**
- **Команда:** `grep "include_router.*router_name" /opt/aladdin-backend/main.py`
- **Проверяем:**
  - Есть ли импорт роутера?
  - Есть ли `app.include_router()`?
  - Правильный ли prefix?

**Пример:**
```bash
# Проверка подключения family router
sshpass -p 'Sergio675' ssh root@149.154.65.180 \
  "cd /opt/aladdin-backend && grep -E 'family|include_router.*family' main.py"
```

**Результат:**
- ✅ Роутер импортирован: `from app.routers import family`
- ✅ Роутер подключен: `app.include_router(family.router)`
- ✅ Prefix: `/api/family`

### **3. ЛОГИКА РАБОТЫ**

#### **3.1. Валидация входных данных**
- **Проверяем:**
  - Валидация типов данных (str, int, bool, и т.д.)
  - Валидация обязательных полей
  - Валидация диапазонов значений
  - Валидация форматов (email, UUID, и т.д.)

**Пример для POST /api/family/create:**
```python
# Ожидаемая валидация:
class CreateFamilyRequest(BaseModel):
    role: str  # Должен быть один из: "parent", "child", "elderly"
    age_group: str  # Должен быть один из: "Adult (18-64)", "Child (0-17)", "Elderly (65+)"
    personal_letter: str  # Должен быть одна буква
    device_type: str  # Должен быть: "iOS", "Android", и т.д.
```

**Тесты:**
- ✅ Правильные данные → 200/201
- ❌ Неправильный role → 422 (Validation Error)
- ❌ Отсутствует обязательное поле → 422
- ❌ Неправильный тип данных → 422

---

#### **3.2. Авторизация**
- **Проверяем:**
  - Требуется ли авторизация?
  - Проверка токена доступа
  - Проверка прав доступа (только свой userId или родитель)

**Пример:**
```bash
# Тест без авторизации
curl -X GET "http://149.154.65.180:8002/api/family/stats"
# Ожидаемый результат: 401 Unauthorized

# Тест с авторизацией
TOKEN="your_token_here"
curl -X GET "http://149.154.65.180:8002/api/family/stats" \
  -H "Authorization: Bearer ${TOKEN}"
# Ожидаемый результат: 200 OK с данными
```

---

#### **3.3. Бизнес-логика**
- **Проверяем:**
  - Правильность обработки данных
  - Работа с БД (чтение/запись)
  - Формирование ответа
  - Атомарность операций (для изменений)

**Пример для POST /api/family/create:**
```python
# Ожидаемая логика:
1. Валидация входных данных
2. Генерация family_id (уникальный)
3. Генерация recovery_code (уникальный)
4. Создание записи в БД
5. Создание первого члена семьи
6. Возврат family_id, recovery_code, members
```

**Тесты:**
- ✅ Создание семьи → возвращает family_id и recovery_code
- ✅ Два запроса → два разных family_id
- ❌ Ошибка БД → 500 Internal Server Error

---

#### **3.4. Обработка ошибок**
- **Проверяем:**
  - Обработка 404 (ресурс не найден)
  - Обработка 403 (недостаточно прав)
  - Обработка 500 (внутренняя ошибка)
  - Обработка сетевых ошибок
  - Обработка ошибок БД

**Пример:**
```bash
# Тест несуществующего ресурса
curl -X GET "http://149.154.65.180:8002/api/family/999999" \
  -H "Authorization: Bearer ${TOKEN}"
# Ожидаемый результат: 404 Not Found

# Тест недостаточных прав
curl -X DELETE "http://149.154.65.180:8002/api/family/OTHER_USER_ID" \
  -H "Authorization: Bearer ${TOKEN}"
# Ожидаемый результат: 403 Forbidden
```
