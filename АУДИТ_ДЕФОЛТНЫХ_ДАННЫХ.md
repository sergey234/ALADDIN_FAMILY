## 📝 РЕКОМЕНДАЦИИ

### **Общие правила:**

1. **Участники семьи:**
   - Всегда загружать из `family_members_list` (UserDefaults)
   - Синхронизировать между всеми экранами через `NotificationCenter`
   - Никогда не использовать дефолтные "Мама", "Папа", "Бабушка"

2. **История чатов/сообщений:**
   - Загружать из UserDefaults/API
   - Показывать пустое состояние, если нет истории
   - Можно оставить только приветственное сообщение

3. **Пользовательские данные:**
   - Лекарства, записи к врачу, контакты → UserDefaults
   - Всегда проверять наличие данных перед отображением

4. **Статические данные:**
   - FAQ, списки для выбора (роли, отношения) → можно оставить
   - Это не пользовательские данные
