### **ШАГ 1: АВТОМАТИЧЕСКАЯ РЕГИСТРАЦИЯ РОУТЕРА**

**Цель:** Автоматически найти и обновить API Gateway файл

**Алгоритм действий:**
1. Найти файл `api_gateway_complete_full.py` на сервере `/opt/aladdin-backend/`
2. Проверить наличие импорта `crash_detection_router`
3. Если импорт отсутствует - добавить строку:
   ```
   from security.api.routers.crash_detection_router import router as crash_detection_router
   ```
4. Проверить наличие регистрации роутера
5. Если регистрация отсутствует - добавить строку:
   ```
   app.include_router(crash_detection_router)
   ```
6. Сохранить изменения в файле

### **ШАГ 2: АВТОМАТИЧЕСКИЙ ПЕРЕЗАПУСК СЕРВЕРА**

**Цель:** Безопасно перезапустить сервер с новыми изменениями

**Алгоритм действий:**
1. Найти PID процесса uvicorn: `ps aux | grep uvicorn | grep api_gateway`
2. Отправить сигнал SIGTERM процессу
3. Подождать 3 секунды завершения
4. Запустить новый процесс: `uvicorn api_gateway_complete_full:app --host 0.0.0.0 --port 8002 --reload`
5. Проверить что порт 8002 слушает: `netstat -tlnp | grep 8002`
