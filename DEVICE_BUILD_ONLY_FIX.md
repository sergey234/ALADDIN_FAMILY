# 🔧 РЕШЕНИЕ: "A build only device cannot be used to run this target"

## ❌ Проблема
При попытке запустить приложение на реальном устройстве появляется ошибка:
```
A build only device cannot be used to run this target.
Please select an available device or choose a simulated device as the destination.
```

---

## 🔍 Причины

1. **Устройство не доверяет компьютеру**
2. **Не настроена команда разработчика (Team) в Xcode**
3. **Устройство не разблокировано**
4. **Не включена автоматическая подпись (Automatic Signing)**

---

## ✅ РЕШЕНИЕ: Пошаговая инструкция

### Шаг 1: Настройка устройства

#### 1.1. Разблокируйте устройство
- Разблокируйте iPhone/iPad
- Убедитесь, что устройство не заблокировано

#### 1.2. Доверьтесь компьютеру
- На устройстве появится запрос: **"Доверять этому компьютеру?"**
- Нажмите **"Доверять"**
- Введите пароль устройства, если потребуется

#### 1.3. Проверьте настройки устройства
- Если запрос не появился:
  - Перейдите: **Настройки → Основные → Переместить или скопировать данные**
  - Или: **Настройки → Основные → Управление устройством**
  - Найдите ваш компьютер → нажмите **"Доверять"**

---

### Шаг 2: Настройка Xcode

#### 2.1. Откройте проект
- Откройте `ALADDIN.xcodeproj` в Xcode
- Выберите проект **ALADDIN** в левой панели (синяя иконка вверху)

#### 2.2. Выберите Target
- В центральной панели выберите **Target "ALADDIN"** (не проект, а target)
- Перейдите на вкладку **"Signing & Capabilities"**

#### 2.3. Настройте Signing

**Что нужно сделать:**

1. **Включите "Automatically manage signing"**
   - ✅ Поставьте галочку **"Automatically manage signing"**

2. **Выберите Team**
   - В выпадающем списке **"Team"** выберите вашу команду разработчика
   - Если команды нет:
     - Нажмите **"Add Account..."**
     - Введите ваш Apple ID
     - Или зарегистрируйтесь в Apple Developer Program

3. **Проверьте Bundle Identifier**
   - Должно быть: `family.aladdin.ios`
   - Если отличается, измените на `family.aladdin.ios`

4. **Проверьте Provisioning Profile**
   - Должно быть: **"Xcode Managed Profile"** или **"Automatic"**
   - Xcode создаст профиль автоматически

---

### Шаг 3: Добавление Apple ID в Xcode (если команды нет)

#### 3.1. Откройте настройки аккаунтов
- **Xcode → Preferences** (или **Xcode → Settings**)
- Перейдите на вкладку **"Accounts"**

#### 3.2. Добавьте Apple ID
- Нажмите кнопку **"+"** (плюс) внизу слева
- Выберите **"Apple ID"**
- Введите ваш Apple ID и пароль
- Нажмите **"Sign In"**

#### 3.3. Вернитесь к Signing
- Вернитесь в **Signing & Capabilities**
- Теперь в списке **"Team"** должна появиться ваша команда
- Выберите её

---

### Шаг 4: Проверка устройства

#### 4.1. Переподключите устройство
- Отключите устройство от Mac
- Подключите снова
- Разблокируйте устройство

#### 4.2. Проверьте статус устройства
- В Xcode в списке устройств должно быть:
  - ✅ **"iPhone"** или **"iPad"** (имя устройства)
  - ✅ Статус: **"Ready"** или **"Available"**
  - ❌ НЕ должно быть: **"Build Only"** или **"Unavailable"**

---

### Шаг 5: Запуск приложения

#### 5.1. Выберите устройство
- В верхней панели Xcode выберите ваше устройство из списка
- Убедитесь, что выбрано реальное устройство, а не симулятор

#### 5.2. Запустите приложение
- Нажмите кнопку **▶️ (Play)** или **Cmd + R**
- Если появится запрос на устройстве:
  - **"Доверять разработчику?"** → **"Доверять"**
  - Перейдите: **Настройки → Основные → Управление устройством**
  - Найдите ваш Apple ID → нажмите **"Доверять"**

---

## 🔍 Альтернативные решения

### Решение 1: Использовать симулятор (временно)

Если нужно быстро протестировать:
1. В списке устройств выберите симулятор (например, "iPhone 13")
2. Запустите приложение (Cmd + R)
3. Логи будут видны в Debug Console

**⚠️ Ограничение:** Логи на симуляторе могут отличаться от реального устройства

---

### Решение 2: Проверить статус устройства в Xcode

1. **Window → Devices and Simulators**
2. Выберите ваше устройство
3. Проверьте статус:
   - ✅ **"Ready"** — устройство готово
   - ❌ **"Build Only"** — устройство не настроено
   - ❌ **"Unavailable"** — устройство недоступно

---

### Решение 3: Перезапустить Xcode

1. Закройте Xcode полностью
2. Отключите устройство
3. Перезапустите Xcode
4. Подключите устройство снова
5. Разблокируйте устройство

---

## ⚠️ Частые проблемы

### Проблема 1: "No devices available"

**Решение:**
- Проверьте USB кабель
- Разблокируйте устройство
- Перезапустите Xcode
- Проверьте, что устройство доверяет компьютеру

---

### Проблема 2: "No signing certificate found"

**Решение:**
1. **Signing & Capabilities** → **Team** → выберите команду
2. Включите **"Automatically manage signing"**
3. Xcode создаст сертификат автоматически

---

### Проблема 3: "Provisioning profile not found"

**Решение:**
1. **Signing & Capabilities** → включите **"Automatically manage signing"**
2. Выберите **Team**
3. Xcode создаст профиль автоматически

---

### Проблема 4: Устройство все еще "Build Only"

**Решение:**
1. Отключите устройство
2. На устройстве: **Настройки → Основные → Сброс → Сбросить настройки сети** (опционально)
3. Подключите устройство снова
4. Разблокируйте устройство
5. Доверьтесь компьютеру
6. В Xcode: **Product → Clean Build Folder** (Shift + Cmd + K)
7. Попробуйте запустить снова

---

## 📋 Чеклист

Проверьте все пункты:

- [ ] Устройство разблокировано
- [ ] Устройство доверяет компьютеру
- [ ] Apple ID добавлен в Xcode (Preferences → Accounts)
- [ ] Team выбрана в Signing & Capabilities
- [ ] "Automatically manage signing" включено
- [ ] Bundle Identifier: `family.aladdin.ios`
- [ ] Устройство видно в Xcode со статусом "Ready"
- [ ] Выбрано реальное устройство (не симулятор)

| Проблема | Решение |
|----------|---------|

| Нет команды | Добавьте Apple ID в Xcode → Preferences → Accounts |

## 💡 Советы

1. **Всегда разблокируйте устройство** перед подключением
2. **Используйте оригинальный USB кабель** Apple
3. **Доверьтесь компьютеру** при первом подключении
4. **Включите "Automatically manage signing"** — это упростит работу
5. **Используйте симулятор** для быстрого тестирования, если устройство недоступно
