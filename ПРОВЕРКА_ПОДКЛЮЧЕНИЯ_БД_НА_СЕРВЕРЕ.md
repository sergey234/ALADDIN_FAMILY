## ⚠️ ВАЖНО: ПРОВЕРКА НА СЕРВЕРЕ

### **Что нужно проверить на сервере:**

#### **1. PostgreSQL установлен и запущен:**
```bash
# Проверка
psql -U aladdin_user -d aladdin_db -c "SELECT version();"
```

#### **2. Таблица `driving_reports` существует:**
```sql
-- Проверка
SELECT * FROM information_schema.tables 
WHERE table_name = 'driving_reports';
```

**Если таблицы нет - создать:**
```sql
CREATE TABLE IF NOT EXISTS driving_reports (
    id VARCHAR(255) PRIMARY KEY,
    user_id VARCHAR(255),
    user_name VARCHAR(255),
    start_time TIMESTAMP,
    end_time TIMESTAMP,
    start_location VARCHAR(255),
    end_location VARCHAR(255),
    distance FLOAT,
    duration FLOAT,
    average_speed FLOAT,
    max_speed FLOAT,
    safety_score FLOAT,
    events JSONB,
    violations JSONB,
    positioning_system VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Индексы для быстрого поиска
CREATE INDEX IF NOT EXISTS idx_driving_reports_user_id ON driving_reports(user_id);
CREATE INDEX IF NOT EXISTS idx_driving_reports_start_time ON driving_reports(start_time);
```

#### **3. Переменная окружения `DATABASE_URL` настроена:**
```bash
# На сервере должно быть:
export DATABASE_URL="postgresql://aladdin_user:AladdinSecure2024!@localhost:5432/aladdin_db"

# Или в .env файле:
DATABASE_URL=postgresql://aladdin_user:AladdinSecure2024!@localhost:5432/aladdin_db
```

#### **4. Подключение работает:**
```python
# Тест подключения
from app.database.database import engine
from sqlalchemy import text

with engine.connect() as conn:
    result = conn.execute(text("SELECT 1"))
    print("✅ БД подключена!")
```
