## 🔍 ПРИЧИНЫ ДУБЛИРОВАНИЯ

### 1. ✅ NavigationLink создает View дважды (НАИБОЛЕЕ ВЕРОЯТНО)

**Механизм:**
- `NavigationLink` может создавать destination View **дважды**:
  - Первый раз при подготовке навигации
  - Второй раз при фактическом переходе
- Это **нормальное поведение** SwiftUI для оптимизации

**Вероятность:** 70%  
**Критичность:** 🟢 Низкая (нормальное поведение)

---

### 2. ⚠️ Обновление @EnvironmentObject вызывает пересоздание

**Механизм:**
- Если `navigationManager` или `localizationManager` обновляются
- SwiftUI пересоздает View для применения изменений
- Это может происходить при инициализации View

**Вероятность:** 20%  
**Критичность:** 🟡 Средняя (может указывать на проблему)

**Проверка:**
```swift
// В SettingsScreen:
@EnvironmentObject private var navigationManager: NavigationManager
@EnvironmentObject private var localizationManager: LocalizationManager
```

---

### 3. ⚠️ testLogger вызывается при каждом создании struct

**Механизм:**
- `testLogger` - это computed property типа `Void`
- Выполняется **при каждом создании struct**
- Это может создавать впечатление двойного создания

**Вероятность:** 10%  
**Критичность:** 🟢 Низкая (только логирование)

**Проблема:**
- `testLogger` вызывается при каждом создании struct
- Это может быть избыточным для production
