### 🔴 Ошибка компиляции:
```

```

**Причина:** Файл `QuarantineManager.swift` может быть не подключен к target проекта или есть проблема с модулями.

**Решение:** 
1. Проверить в Xcode, что файл `Core/Antivirus/QuarantineManager.swift` подключен к target "ALADDIN"
2. Убедиться, что нет конфликтов имен
3. Возможно, нужно добавить явный import (хотя обычно не требуется для файлов в том же модуле)

**Временное решение:** Использованы локальные переменные `@State` вместо прямого использования `QuarantineStats`

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Используемые компоненты:
- `AntivirusManager.shared` - основной менеджер антивируса
- `QuarantineManager.shared` - менеджер карантина (требует проверки подключения к target)
- `VisualLogger.shared` - логирование в UI
- `@AppStorage` - для быстрых настроек

### Структуры данных:
- `ScanHistoryItem` - локальная структура для истории сканирований
- `QuarantineStats` - структура статистики карантина (из QuarantineManager)

### Функции:
- `formatScanCount()` - форматирование количества проверенных файлов
- `formatLastScan()` - форматирование времени последнего сканирования
- `formatScanDate()` - форматирование даты сканирования
- `formatBytes()` - форматирование размера карантина
- `loadQuarantineStats()` - загрузка статистики карантина
- `performQuickScan()` - выполнение быстрого сканирования
