### **ШАГ 3: ПРОВЕРИТЬ GRACEFUL DEGRADATION**

#### **3.1. Что проверяем:**

Graceful degradation означает, что если таблицы в БД отсутствуют, endpoints должны:
- ✅ Возвращать HTTP 200 (успех)
- ✅ Возвращать пустые данные (статистика = 0, списки = [])
- ❌ НЕ возвращать ошибки 500 или исключения

---

#### **3.2. Как проверить:**

**Вариант 1: Временно удалить таблицы**

```sql
-- ВНИМАНИЕ: Только для тестирования!
DROP TABLE IF EXISTS dark_web_leaks CASCADE;
DROP TABLE IF EXISTS dark_web_scans CASCADE;
DROP TABLE IF EXISTS identity_theft_attempts CASCADE;
DROP TABLE IF EXISTS location_requests CASCADE;
DROP TABLE IF EXISTS data_cleanup_records CASCADE;
DROP TABLE IF EXISTS tracker_blocks CASCADE;
DROP TABLE IF EXISTS ai_category_reports CASCADE;
```

**Затем протестировать endpoints - они должны вернуть пустые данные без ошибок.**

**Вариант 2: Использовать скрипт test_endpoints.py**

Скрипт автоматически проверяет graceful degradation.
