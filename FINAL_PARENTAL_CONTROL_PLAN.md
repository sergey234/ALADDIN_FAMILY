# 📋 ФИНАЛЬНЫЙ ПЛАН: Родительский контроль - все требования

## ✅ ОТВЕТЫ НА ВСЕ ВОПРОСЫ

### 1. **Сколько детей?**
- ✅ **3 ребёнка** - значит Picker нужен обязательно!

### 2. **Автоматические правила**
- ✅ **Можно отключить** - будет toggle для включения/выключения
- ✅ **Учитывают возраст ребёнка:**
  - **1-6 лет:** Блокировка всего, кроме детского контента (YouTube Kids, мультики 0+)
  - **7-13 лет:** Блокировка опасного контента, разрешён детский YouTube, мультики до 12+
  - **14-17 лет:** Блокировка только взрослого контента, разрешён обычный YouTube с фильтрами
  - **18+:** Без ограничений (для взрослых)

- ✅ **Что фильтруется:**
  - YouTube (автоматический переход на YouTube Kids для 1-6 лет)
  - Мультики (фильтрация по возрасту)
  - Приложения (блокировка нежелательных)
  - Веб-сайты (фильтрация по категориям)

### 3. **Геймификация - переход из карточки "Вознаграждение ребёнка"**
- ✅ **НЕ из шестиренки настроек!**
- ✅ **Из карточки "Вознаграждение ребёнка"** (под родительским контролем)
- ✅ **Отдельный экран** - код геймификации НЕ в `FamilyScreen`
- ✅ **Структура:** `FamilyScreen` → карточка вознаграждения → `GamesParentalControlScreen`

### 4. **Карточка "Участники семьи" - динамическое расширение**
- ✅ **Расширяется автоматически** в зависимости от количества членов семьи
- ✅ **Пополняется из:** кнопка "Добавить участника" → модал добавления
- ✅ **Пример:** 3 ребёнка + мама + папа + бабушка + дедушка = 8 карточек
- ✅ **Сетка адаптируется:** 2 колонки, автоматическое размещение

  - Приложения → без игр с рейтингом 18+
  
- **14-17 лет:**
  - YouTube → обычный с фильтрами
  - Мультики → все кроме 18+
  - Приложения → без явного взрослого контента

### **4. Динамическая карточка "Участники семьи"**

**Проблема:** Сейчас хардкод - 4 карточки (Папа, Мама, Маша, Бабушка)

**Решение:** Динамический список из ViewModel или State

**Структура:**
```swift
@State private var familyMembers: [FamilyMember] = []

struct FamilyMember: Identifiable {
    let id: UUID
    let name: String
    let role: FamilyMemberCard.FamilyRole
    let avatar: String
    let status: FamilyMemberCard.ProtectionStatus
    let threatsBlocked: Int
    let lastActive: String
}

// Инициализация (mock-данные, позже из API)
private func loadFamilyMembers() {
    familyMembers = [
        FamilyMember(name: "Папа", role: .parent, avatar: "👨", ...),
        FamilyMember(name: "Мама", role: .parent, avatar: "👩", ...),
        FamilyMember(name: "Маша", role: .child, avatar: "👧", ...),
        FamilyMember(name: "Паша", role: .child, avatar: "👦", ...),
        FamilyMember(name: "Ваня", role: .child, avatar: "🧒", ...),
        FamilyMember(name: "Бабушка", role: .elderly, avatar: "👵", ...),
        FamilyMember(name: "Дедушка", role: .elderly, avatar: "👴", ...)
    ]
}
```

**Отображение:**
```swift
LazyVGrid(columns: Array(repeating: GridItem(.flexible()), count: 2), spacing: 8) {
    ForEach(familyMembers) { member in
        FamilyMemberCard(
            name: member.name,
            role: member.role,
            avatar: member.avatar,
            status: member.status,
            threatsBlocked: member.threatsBlocked,
            lastActive: member.lastActive,
            action: {
                navigateToMemberScreen(role: member.role)
            }
        )
    }
}
```

**Пополнение:**
- Кнопка "Добавить участника" → `AddMemberOptionsModal`
- В модале: сканирование QR, ввод кода, ручной ввод
- После добавления → обновление `familyMembers` → автоматическое отображение
