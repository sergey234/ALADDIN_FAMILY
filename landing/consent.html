3. Персональные данные

Обработке подлежат следующие персональные данные:

  • Alias (псевдоним пользователя) — создаётся пользователем при оплате подписки, используется для идентификации заказа и восстановления кода активации
  • PIN-код — создаётся пользователем при оплате, используется вместе с alias для восстановления кода активации
  • IP-адрес — фиксируется при оформлении заказа для обеспечения безопасности и предотвращения мошенничества
  • Данные об оплате — сумма, тариф, период подписки, статус платежа, идентификатор транзакции
  • Код активации — сгенерированный код для активации подписки в приложении
  • Данные устройства — familyId, deviceId (при активации кода в приложении)
  • Email (если указан) — используется для связи с пользователем и отправки уведомлений
  • Телефон (если указан) — используется для связи с пользователем

Персональные данные обрабатываются с использованием автоматизированных средств (приложение, сервер, база данных). Данные хранятся на серверах компании для обеспечения работы сервиса, обработки платежей и активации подписки.
