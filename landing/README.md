# ALADDIN Landing & Payment Form

Самописный лендинг для внешней оплаты подписок ALADDIN AI с поддержкой alias + PIN и прямых интеграций с банками.

## Структура

- `index.html` — разметка всех блоков (Hero, тарифы, «Как работает», форма, отзывы, FAQ, секция банков).
- `styles.css` — тема из раздела 12 плана (градиенты, золотые акценты, адаптив).
- `cms/` — данные, которые можно править без касания к разметке:
  - `hero.json` — показатели (семьи, устройства, угрозы).
  - `tariffs.json` — названия тарифов, цены, функции.
  - `methods.json` — список доступных методов оплаты (QR/СБП, карты Сбер/Тинькофф/Альфа/ВТБ/Газпромбанк/ПСБ и т.д., SberPay/Tinkoff Pay, прямой перевод). Используется в select в форме.
  - `banks.json` — топ‑21 банк РФ и поддерживаемые каналы (для секции «Способы оплаты и банки»).
  - `testimonials.json`, `faq.json` — отзывы и FAQ (взяты из `docs/legal/help_faq.md`).
- Форма (`paymentForm`) отправляет данные на `/api/payments/create` (backend FastAPI).

## Локальный запуск

```bash
cd landing
python3 -m http.server 8080
# открыть http://127.0.0.1:8080
```

Для production-деплоя можно использовать любой статический хостинг (Netlify, Vercel, Nginx, S3). Настройте окружение так, чтобы домен лендинга имел доступ к backend `payment_service` (см. ниже).

## Интеграция с backend

- `payment_service` (FastAPI) предоставляет:
  - `POST /api/payments/create` — создание платежа (валидирует `tariffId`, `paymentMethod`, alias+PIN). Требует заголовок `X-API-Key`.
  - `POST /api/payments/confirm` — webhook банков.
  - `/api/activation/retrieve|verify|activate` — получение и погашение кодов.
  - `GET /api/payment-methods` — список методов (аналог `cms/methods.json`, для дальнейшей синхронизации).
- В проде можно либо продолжать использовать статические JSON, либо переключить лендинг на `GET /api/payment-methods`/`/payment-methods` через fetch.

## Настройка методов и банков

- Чтобы добавить/убрать банк или канал, отредактируйте `cms/banks.json` (визуальная секция) и `cms/methods.json` (варианты формы). Старайтесь держать их в синхронизации с `payment_service/app/payment_methods.py`, чтобы backend принимал те же `id`.
- Для резервного прямого перевода в интерфейсе показываем ссылку на реквизиты (добавьте отдельную страницу/модалку при необходимости). Backend принимает `paymentMethod = "manual_transfer"`.

## Дизайн и адаптив

Все блоки построены на CSS Grid/Flex. Для кастомизации:
- Цвета → переменные в `:root`.
- Градиенты и тени → секция `pay-form`, `hero`.
- Стили баннеров/карт → `.bank-card`, `.payment-methods`.

## Дальнейшие шаги

- Подключить реальные логику QR/СБП, SberPay/Tinkoff Pay (через встраиваемые кнопки или переадресацию на банковские ссылочные страницы).
- Добавить якорные ссылки (`Оплатить`, `Методы`) в шапке.
- Интегрировать проверку `GET /api/payment-methods`, чтобы не дублировать `methods.json`.
