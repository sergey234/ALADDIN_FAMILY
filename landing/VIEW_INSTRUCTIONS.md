## 🚀 Как запустить локально

### Вариант 1: Python (рекомендуется)
```bash
cd landing
python3 -m http.server 8080
```
Затем откройте в браузере: **http://127.0.0.1:8080**

### Вариант 2: Node.js (если установлен)
```bash
cd landing
npx http-server -p 8080
```

### Вариант 3: PHP (если установлен)
```bash
cd landing
php -S 127.0.0.1:8080
```

## ⚠️ Что работает, а что нет

### ✅ Работает:
- Все HTML страницы открываются
- CSS стили применяются
- CMS данные загружаются через JavaScript
- Форма валидирует поля (alias, PIN, тариф)
- Ссылки между страницами работают

### ⚠️ Требует backend:
- **Форма оплаты** (`POST /api/payments/create`) — нужен запущенный `payment_service`
- **Восстановление кода** — требует backend API
- **Реальные платёжные виджеты** — нужны API ключи от банков

### 🔧 Для полной работы нужно:
1. Запустить backend: `cd payment_service && python3 -m uvicorn main:app --reload`
2. Настроить CORS в backend для `http://127.0.0.1:8080`
3. Получить API ключи от банков для реальных платежей
