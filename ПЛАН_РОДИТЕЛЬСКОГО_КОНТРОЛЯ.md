## 🎯 ЧТО БУДЕТ РЕАЛИЗОВАНО

### ✅ **ЗАДАЧА 1: Детальные отчёты (ParentalControlReportsManager.swift)**

**Что создам:**
- Новый файл: `Core/Managers/ParentalControlReportsManager.swift`
- Класс для управления всеми отчётами родительского контроля

**Функциональность:**

1. **Ежедневные отчёты** (`getDailyReport`)
   - Общее время использования экрана
   - Использование по приложениям (Instagram: 18мин/30мин)
   - Использование по сайтам
   - Количество заблокированных сайтов
   - Количество заблокированных угроз
   - График активности по часам

2. **Еженедельные отчёты** (`getWeeklyReport`)
   - Сводка за неделю
   - Среднее время использования в день
   - Топ приложений за неделю
   - Топ сайтов за неделю
   - Тренды использования

3. **Ежемесячные отчёты** (`getMonthlyReport`)
   - Полная статистика за месяц
   - Еженедельные сводки
   - Топ приложения и сайты
   - Анализ трендов

4. **Экспорт отчётов**
   - Экспорт в PDF (`exportReportToPDF`)
   - Экспорт в CSV (`exportReportToCSV`)
   - Возможность отправить по email

**Модели данных:**
```swift
struct DailyReport {
    let date: Date
    let totalScreenTime: TimeInterval
    let appsUsage: [AppUsage]
    let websitesBlocked: Int
    let threatsBlocked: Int
}

struct AppUsage {
    let appName: String
    let timeSpent: TimeInterval
    let limit: TimeInterval
}
```

### ✅ **ЗАДАЧА 2: Статистика использования**

**Что добавлю в `ParentalControlManager.swift`:**

1. **Статистика по приложениям** (`getAppUsageStatistics`)
   - Время использования каждого приложения
   - Количество сессий
   - Лимит времени для каждого приложения
   - Процент использования лимита
   - Пример: "Instagram: 18мин / 30мин (60%)"

2. **Статистика по сайтам** (`getWebsiteUsageStatistics`)
   - Количество посещений каждого сайта
   - Время на каждом сайте
   - Статус блокировки (заблокирован/разрешён)
   - Топ посещаемых сайтов

3. **Графики активности** (`getActivityCharts`)
   - Почасовая активность (24 часа)
   - Дневная активность (7 дней)
   - Визуализация данных для UI

**Модели данных:**
```swift
struct AppUsageStatistics {
    let appName: String
    let timeSpent: TimeInterval
    let sessions: Int
    let limit: TimeInterval
}

struct WebsiteUsageStatistics {
    let website: String
    let visits: Int
    let timeSpent: TimeInterval
    let isBlocked: Bool
}

struct ActivityCharts {
    let hourlyActivity: [HourlyActivity]  // 24 часа
    let dailyActivity: [DailyActivity]    // 7 дней
}
```

### ✅ **ЗАДАЧА 3: Гибкие настройки**

**Что добавлю в `ParentalControlManager.swift`:**

1. **Настройки по возрасту** (`applyAgeBasedSettings`)
   - **Дошкольники (0-6 лет):**
     - Строгие ограничения
     - Блокировка всех сайтов кроме разрешённых
     - Блокировка всех приложений кроме разрешённых
     - SafeSearch включён
     - Лимит: 1 час в день
     - Время сна: 20:00 - 07:00
   
   - **Младшие школьники (6-13 лет):**
     - Умеренные ограничения
     - Блокировка сайтов включена
     - Блокировка приложений выключена
     - SafeSearch включён
     - Лимит: 2 часа в день
     - Время сна: 21:00 - 07:00
   
   - **Подростки (13-18 лет):**
     - Мягкие ограничения
     - Блокировка сайтов выключена
     - Блокировка приложений выключена
     - SafeSearch включён
     - Лимит: 3 часа в день
     - Время сна: 22:00 - 07:00

2. **Настройки по приложениям** (`applyAppBasedSettings`)
   - Индивидуальные лимиты для каждого приложения
   - Блокировка конкретных приложений
   - Пример: "Instagram: 30 мин, TikTok: 20 мин"

**Модели данных:**
```swift
struct AppSetting {
    let appName: String
    let isBlocked: Bool
    let timeLimit: TimeInterval?
}
```

## 🎯 КОНКРЕТНЫЕ МЕТОДЫ
