### **2. Обработка Unauthorized**

#### **Проблема:**
Во всех ViewModels отсутствовала явная обработка ошибки `NetworkError.unauthorized`.

#### **Решение:**
Добавлена обработка во всех ViewModels:

**Шаблон обработки:**

```swift
// В начале метода loadData()
guard AppConfig.authToken != nil else {
    self.errorMessage = LocalizationManager.shared.localizedString(for: "error_unauthorized")
    return
}

// В catch блоке
catch let error as NetworkError {
    if case .unauthorized = error {
        self.errorMessage = LocalizationManager.shared.localizedString(for: "error_unauthorized")
    } else {
        self.errorMessage = error.localizedDescription
    }
}
```
