# 📋 ВСЕ СКРИПТЫ ДЛЯ РАЗВЕРТЫВАНИЯ ALADDIN

## 🎯 Рекомендуемые скрипты (попробуйте в этом порядке):

### 1. `Deploy_ALADDIN.command` ⭐ ЛУЧШИЙ ДЛЯ macOS
- **Запуск:** Двойной клик на файл
- **Описание:** Автоматически откроет терминал и выполнит развертывание
- **Требования:** sshpass или expect

### 2. `deploy_inline.sh` ⭐ РЕКОМЕНДУЕТСЯ
- **Запуск:** `chmod +x deploy_inline.sh && ./deploy_inline.sh`
- **Описание:** Использует inline expect команды
- **Требования:** expect

### 3. `deploy_api_gateway_final.exp` ⭐ ПОЛНЫЙ
- **Запуск:** `chmod +x deploy_api_gateway_final.exp && ./deploy_api_gateway_final.exp`
- **Описание:** Самый полный скрипт с проверками
- **Требования:** expect

### 4. `deploy_auto.sh` ⭐ АВТОМАТИЧЕСКИЙ
- **Запуск:** `chmod +x deploy_auto.sh && ./deploy_auto.sh`
- **Описание:** Автоматически выбирает лучший метод
- **Требования:** sshpass, expect или python3
