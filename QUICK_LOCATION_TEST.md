3. Запустить приложение: `Cmd + R`

### Шаг 3: Проверка LocationManager (1 минута)

**В консоли Xcode ищите:**
```
📍 LocationManager: Инициализирован
📍 LocationManager: Геолокация доступна: true
📍 LocationManager: Статус разрешения: ...
```

**Если видите эти строки:** ✅ LocationManager работает

---

### Шаг 4: Проверка разрешения (1 минута)

1. Перейти: **Семья → Геозона**
2. Должен появиться запрос разрешения
3. Выбрать: **"Always"**
4. Проверить в консоли: `📍 LocationManager: Изменение статуса разрешения: Всегда`

**Если запрос появился:** ✅ Разрешение работает

---

### Шаг 5: Проверка Significant-Change (30 секунд)

**В консоли ищите:**
```
📍 LocationManager: Запуск Significant-Change Location Service
```

**Если видите:** ✅ Significant-Change запущен

**Проверить статус:**
- В коде: `LocationManager.shared.isMonitoringSignificantChanges` должно быть `true`

---

### Шаг 6: Проверка геозон (2 минуты)

1. Перейти: **Семья → Геозона → Настроить геозоны**
2. Нажать: **"Добавить"**
3. Ввести:
   - Название: "Дом"
   - Адрес: "ул. Ленина, 42"
   - Радиус: 100м
4. Нажать: **"Добавить"**

**В консоли ищите:**
```
✅ LocationManager: Начало мониторинга геозоны 'Дом'
```

**Если видите:** ✅ Геозона добавлена

**Проверить лимит:**
- Попытаться добавить 21-ю геозону
- Должна появиться ошибка: "Достигнут лимит геозон (20)"

**Проверить минимум:**
- Попытаться добавить геозону с радиусом 50м
- Должна появиться ошибка: "Радиус 50 метров слишком мал. Минимум: 100 метров"

## 🐛 ЧАСТЫЕ ПРОБЛЕМЫ

### Проблема 1: Нет запроса разрешения

**Решение:**
- Проверить Info.plist (должны быть ключи NSLocation*)
- Проверить, что LocationManager.shared.requestAuthorization() вызывается

### Проблема 2: Геозона не добавляется

**Решение:**
- Проверить разрешение (должно быть Always)
- Проверить лимит (максимум 20 геозон)
- Проверить радиус (минимум 100 метров)

### Проблема 3: Нет событий геозон

**Решение:**
- Проверить, что разрешение Always
- Проверить, что геозона создана правильно
- Проверить координаты (должны быть валидными)
