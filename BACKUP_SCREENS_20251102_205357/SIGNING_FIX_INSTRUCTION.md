# 🔧 ИНСТРУКЦИЯ: Как исправить ошибку Signing

## 🚨 ПРОБЛЕМА

**Ошибка:**
```
Signing for "ALADDIN" requires a development team.
```

**Причина:**
В `project.pbxproj` есть:
```swift
DEVELOPMENT_TEAM = "";
```
Но нет указания на команду разработчика.

## ✅ РЕШЕНИЕ: ДВА ВАРИАНТА

### 🔵 ВАРИАНТ 1: Для симулятора (БЕЗ АВТОМАТИЧЕСКОЙ ПОДПИСИ)

**В Xcode:**
1. Открыть проект `ALADDIN.xcodeproj`
2. Выбрать **ALADDIN** (левый верхний угол)
3. Выбрать **ALADDIN** target (под PROJECT)
4. Перейти во вкладку **Signing & Capabilities**
5. **СНЯТЬ** галочку "Automatically manage signing"
6. Сохранить проект (⌘S)

### 🟢 ВАРИАНТ 2: Для реального устройства (С АВТОМАТИЧЕСКОЙ ПОДПИСЬЮ)

**В Xcode:**
1. Открыть проект `ALADDIN.xcodeproj`
2. Выбрать **ALADDIN** (левый верхний угол)
3. Выбрать **ALADDIN** target (под PROJECT)
4. Перейти во вкладку **Signing & Capabilities**
5. **ОСТАВИТЬ** галочку "Automatically manage signing"
6. В выпадающем списке **Team** выбрать вашу Apple ID
   - Если нет аккаунта: Xcode → Settings → Accounts → + (добавить Apple ID)
7. Сохранить проект (⌘S)

## 🎯 РЕКОМЕНДАЦИЯ ДЛЯ СИМУЛЯТОРА

**Используйте ВАРИАНТ 1:**
- Не требует Apple ID
- Не требует оплаты ($99/год для разработчиков)
- Работает только на симуляторе
- Нельзя установить на реальное устройство

## 📝 ПОШАГОВАЯ ИНСТРУКЦИЯ (ВАРИАНТ 1)

### ШАГ 1: Открыть Xcode
```bash
open ALADDIN.xcodeproj
```

### ШАГ 2: Найти настройки
В Xcode:
1. Слева вверху выбрать **ALADDIN** (или "ALADDIN" в списке проектов)
2. В средней панели выбрать **TARGETS** → **ALADDIN**
3. Сверху открыть вкладку **Signing & Capabilities**

### ШАГ 3: Отключить автоматическую подпись
1. Найти секцию "Signing"
2. **СНЯТЬ** галочку "Automatically manage signing"
3. Может появиться предупреждение - нажать "Disable"

### ШАГ 4: Сохранить
Нажать **⌘S** (Cmd + S)

### ШАГ 5: Собрать проект
1. **Product → Clean Build Folder** (⇧⌘K)
2. **Product → Build** (⌘B)
3. **Product → Run** (⌘R)

## ✅ РЕЗУЛЬТАТ

После выполнения этих действий:
- ✅ Ошибка Signing исчезнет
- ✅ Проект будет собираться для симулятора
- ✅ Приложение запустится на симуляторе

## 🚨 ВАЖНО

**Отключение автоматической подписи означает:**
- ❌ Нельзя установить на реальное iOS устройство
- ❌ Нельзя загрузить в App Store
- ✅ Можно только тестировать на симуляторе

**Если нужна установка на реальное устройство:**
Используйте ВАРИАНТ 2 (с Apple ID и автоматической подписью).
