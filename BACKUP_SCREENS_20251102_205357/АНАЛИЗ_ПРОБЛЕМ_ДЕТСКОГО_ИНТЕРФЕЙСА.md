### ПРОБЛЕМА 1: "Воспитание ребенка" видно детям в ChildRewardsScreen

**Где проблема:**
- Файл: `Screens/ChildRewardsScreen.swift`
- Строки: 110-118
- Код:
```swift
if isCurrentUserParent() {
    parentQuickActions  // Показывает "Воспитание ребенка"
}
if !isCurrentUserParent() {
    childRewardsHistoryView  // История для детей
}
```

**Причина:**
- Возможно роль установлена как "Parent" при тестировании
- Или проверка `isCurrentUserParent()` возвращает неправильный результат
- Или SwiftUI кэширует старое состояние

**Решение:**
1. Добавить явную проверку роли при входе в ChildRewardsScreen
2. Добавить логирование для диагностики
3. Убедиться, что роль правильно определяется

### ПРОБЛЕМА 2: Кнопка настроек в ChildRewardsScreen ведет на родительский контроль

**Где проблема:**
- Файл: `Screens/ChildRewardsScreen.swift`
- Строки: 254-268
- Код:
```swift
if isCurrentUserParent() {
    Button(action: {
        navigationManager.navigateTo(.gamesParentalControl)  // ❌ Это родительский контроль!
    }) {
        Image(systemName: "gearshape.fill")
    }
}
```

**Проблема:**
- Даже если проверка `isCurrentUserParent()` правильная, кнопка ведет на `gamesParentalControl` - это меню родительского контроля
- Дети НЕ должны видеть эту кнопку вообще

**Решение:**
1. Убрать кнопку настроек для детей полностью
2. Или сделать её, чтобы открывала детские настройки (не родительский контроль)
3. Проверить, что кнопка не видна детям
