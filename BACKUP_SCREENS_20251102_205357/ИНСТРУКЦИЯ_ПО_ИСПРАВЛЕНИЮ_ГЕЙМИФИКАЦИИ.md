**Проблема:** `current_user_role` не установлен или установлен неправильно.

**Проверка:**

### ШАГ 6: Проверка синхронизации баланса

**Проблема:** `actualBalance` может не обновляться.

**Файл:** `Screens/07_ParentalControlScreen.swift`

**Изменить `actualBalance` (строка 42-44) на `@State`:**
```swift
// БЫЛО:
private var actualBalance: Int {
    UserDefaults.standard.integer(forKey: "child_unicorn_balance")
}

// СТАЛО:
@State private var actualBalance: Int = 0

// И добавить в onAppear:
.onAppear {
    loadParentalControlStats()
    actualBalance = UserDefaults.standard.integer(forKey: "child_unicorn_balance")
    
    // Подписка на изменения
    NotificationCenter.default.addObserver(
        forName: UserDefaults.didChangeNotification,
        object: nil,
        queue: .main
    ) { _ in
        actualBalance = UserDefaults.standard.integer(forKey: "child_unicorn_balance")
    }
}
```

## 🚨 КРИТИЧЕСКИЕ МОМЕНТЫ ДЛЯ ВНИМАНИЯ

### 1. SwiftUI View Builder ограничения
В SwiftUI нельзя использовать `let` внутри `VStack` или других контейнеров напрямую. Если нужно использовать вычисляемое значение:
```swift
// ❌ НЕПРАВИЛЬНО:
VStack {
    let operations = getRecentOperations()
    // ...
}

// ✅ ПРАВИЛЬНО:
if getRecentOperations().isEmpty {
    // пустое состояние
} else {
    ForEach(getRecentOperations().prefix(10)) { ... }
}
```

### 2. @AppStorage синхронизация
`@AppStorage` может не обновляться мгновенно при изменении `UserDefaults` из другого места. Для принудительного обновления:
```swift
// Использовать NotificationCenter
NotificationCenter.default.post(name: UserDefaults.didChangeNotification, object: nil)
```

### 3. NavigationManager и environmentObject
Убедиться, что `NavigationManager` передаётся через `.environmentObject()` во все необходимые View:
```swift
.environmentObject(navigationManager)
```
