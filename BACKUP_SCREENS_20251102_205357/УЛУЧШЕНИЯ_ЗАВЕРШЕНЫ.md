### 3. ✅ Адаптивный Polling
```swift
private func getAdaptiveInterval(baseMinutes: TimeInterval) -> TimeInterval {
    let hour = Calendar.current.component(.hour, from: Date())
    
    // Ночь: 0-6 утра - увеличиваем интервал в 2 раза
    if hour >= 0 && hour < 6 {
        return baseMinutes * 2
    }
    
    // День: 8-22 часа - обычный интервал
    if hour >= 8 && hour < 22 {
        return baseMinutes
    }
    
    // Остальное время - немного больше
    return baseMinutes * 1.5
}
```

**Что делает:**
- Ночью (0-6): Интервалы в 2 раза больше ✅
- Днём (8-22): Обычные интервалы ✅
- Остальное: Интервалы в 1.5 раза больше ✅

**Пример:**
- VPN Check: 15 мин → 30 мин ночью ✅
- Family: 30 мин → 60 мин ночью ✅

### 4. ✅ Battery Saver Mode
```swift
private func getBatterySaverInterval(baseMinutes: TimeInterval) -> TimeInterval {
    let batteryLevel = getBatteryLevel()
    
    // Если батарея <20% - увеличиваем интервал в 3 раза
    if batteryLevel < 20 {
        logger.info("🔋 Battery Saver Mode activated (<\(batteryLevel)%)")
        return baseMinutes * 3
    }
    
    // Если батарея <50% - увеличиваем интервал в 1.5 раза
    if batteryLevel < 50 {
        return baseMinutes * 1.5
    }
    
    return baseMinutes
}
```

**Что делает:**
- Батарея <20%: Интервалы в 3 раза больше ✅
- Батарея <50%: Интервалы в 1.5 раза больше ✅
- Батарея >50%: Обычные интервалы ✅

**Пример:**
- VPN Check: 15 мин → 45 мин при <20% ✅
- Family: 30 мин → 90 мин при <20% ✅
