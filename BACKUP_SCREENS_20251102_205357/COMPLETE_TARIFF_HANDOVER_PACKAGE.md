## 🚨 КРАТКАЯ СВОДКА ПРОБЛЕМЫ

### **Две критические проблемы:**

#### **ПРОБЛЕМА #1: Тарифы не работают (краш/не реагируют)**

**Симптом:** При нажатии на тариф приложение крашится или не открывает экран оплаты.

**Местоположение:** `Screens/10_TariffsScreen.swift`, функция `tariffCard()`, Button action (строки 240-298)

**Причины:**
- Tariff объект создаётся с потенциально пустыми полями
- Sheet открывается до того, как `selectedTariffForPayment` установлен
- Нет проверки валидности перед использованием

#### **ПРОБЛЕМА #2: Навигация Тарифы → Профиль → Тарифы не работает**

**Симптом:** Из тарифов открывается профиль, но стрелка назад не возвращает в тарифы.

**Местоположение:** 
- `Screens/11_ProfileScreen.swift`, навигация назад (строки 35-44)
- `Shared/Components/Navigation/ALADDINNavigationBar.swift`, кнопка профиля (строка 153)
- `Core/Navigation/NavigationManager.swift`, методы navigateTo/goBack

**Причины:**
- NavigationManager использует `DispatchQueue.main.async`, что создаёт race condition
- Стек навигации может не обновляться вовремя
- `canGoBack` возвращает `false` когда должен возвращать `true`

## 🔍 ДЕТАЛЬНЫЙ АНАЛИЗ

### **Архитектура навигации:**

```
MainScreen
    ↓ (NavigationLink)
TariffsScreen
    ↓ (ALADDINNavigationBar кнопка → navigationManager.navigateTo(.profile))
ProfileScreen
    ↓ (стрелка назад → navigationManager.goBack() или dismiss())
```

**Проблема:** Смешивание NavigationLink (SwiftUI) и NavigationManager (кастомный менеджер).

### **Архитектура оплаты:**

```
Пользователь нажимает тариф
    ↓
Создание Tariff объекта
    ├─ Из StoreKit (если загружены продукты)
    └─ Новый объект (для QR оплаты)
    ↓
Проверка AppConfig.useAlternativePayments
    ├─ true (RU) → selectedTariffForPayment = tariffObj
    │              showPaymentQRScreen = true
    │              → Sheet с PaymentQRScreen
    └─ false → Task { await purchaseSelectedTariff() }
               → IAP через App Store
```

**Проблема:** Нет гарантии, что `tariffObj` валиден и `selectedTariffForPayment` установлен перед открытием sheet.
