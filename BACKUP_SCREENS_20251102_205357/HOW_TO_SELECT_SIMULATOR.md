# 📱 КАК ВЫБРАТЬ СИМУЛЯТОР В XCODE

## 🎯 **ПОШАГОВАЯ ИНСТРУКЦИЯ:**

### **ШАГ 1: Найдите строку с устройством**
В Xcode, вверху экрана, вы увидите:
```
ALADDIN > iPhone (или название вашего устройства)
```

### **ШАГ 2: Нажмите на "iPhone"**
Нажмите на название устройства (iPhone/ваше устройство)

### **ШАГ 3: Выберите "iOS Simulator"**
Откроется меню с выбором:
- **iOS Simulator** ← ВЫБЕРИТЕ ЭТО!
  - iPhone 15
  - iPhone 15 Pro
  - iPhone 14
  - iPad
  - и т.д.

### **ШАГ 4: Выберите симулятор**
Например: "iPhone 15" или "iPhone 15 Pro"

### **ШАГ 5: Нажмите Run (▶️)**
Приложение запустится в симуляторе!

---

## 🖼️ **ГДЕ НАЙТИ:**

```
[▶️ Run] [⏹ Stop]  [ALADDIN]  [⚙️ Scheme]  [📱 iPhone] ← НАЖМИ СЮДА!

                                     [Choose Device...]
```

## ✅ **ПОСЛЕ ВЫБОРА:**

Строка изменится на:
```
ALADDIN > iPhone 15 (или другой симулятор)
```

Теперь можно нажимать Run (▶️)!
