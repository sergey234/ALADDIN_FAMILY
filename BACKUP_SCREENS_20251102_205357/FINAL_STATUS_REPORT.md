## 🔧 КАК ИСПРАВИТЬ SIGNING

### 📋 БЫСТРЫЙ СПОСОБ (для симулятора):

1. **В Xcode:**
   - Открыть **ALADDIN** (левый верхний угол)
   - Выбрать **ALADDIN** target
   - Перейти во вкладку **Signing & Capabilities**
   - **Снять галочку** "Automatically manage signing"
   - Нажать **⌘S** (сохранить)

2. **Собрать проект:**
   - **Product → Clean Build Folder** (⇧⌘K)
   - **Product → Build** (⌘B)
   - **Product → Run** (⌘R)

### ✅ РЕЗУЛЬТАТ
- Проект будет собираться без ошибок
- Приложение запустится на симуляторе
