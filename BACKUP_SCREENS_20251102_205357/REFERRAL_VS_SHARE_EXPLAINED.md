## 📱 "ПОДЕЛИТЬСЯ ПРИЛОЖЕНИЕМ" (Простой способ)

### Где находится:
**Настройки → Дополнительно → "Поделиться приложением"**

### Что это:
- Системное окно шаринга (ShareSheet)
- Открывается по нажатию кнопки
- Быстрый способ поделиться

### Что показывает:
```
┌─────────────────────────────────────┐
│  Поделиться                         │
├─────────────────────────────────────┤
│  WhatsApp                           │
│  Telegram                           │
│  Email                              │
│  Копировать                         │
└─────────────────────────────────────┘
```

### Текст для отправки:
```

Скачай приложение: https://aladdin.family

С тобой на защите! 🛡️
```
