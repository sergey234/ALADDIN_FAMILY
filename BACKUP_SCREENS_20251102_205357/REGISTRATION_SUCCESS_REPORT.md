## 🎯 КАК РАБОТАЕТ РЕГИСТРАЦИЯ:

### **На главном экране:**
```
ГЛАВНАЯ → Кнопка "Добавить члена семьи"
   ↓
Модальное окно: "Добавить участника"
   ↓
┌─────────────────────────────────┐
│ Выберите способ добавления      │
│                                 │
│ ① Создать новую семью          │
│ ② Сканировать QR-код            │
│ ③ Ввести код приглашения       │
│                                 │
│              [Отмена]           │
└─────────────────────────────────┘
```

### **Вариант 1: Создать новую семью**
```
1. Пользователь выбирает "Создать новую семью"
   ↓
2. Открывается MainScreenWithRegistration
   ↓
3. Показываются модальные окна:
   - RoleSelectionModal (выбор роли)
   - AgeGroupModal (выбор возраста)
   - LetterModal (выбор буквы)
   ↓
4. API: createFamily()
   ↓
5. Получение Recovery Code: FAM-A1B2-C3D4-E5F6
   ↓
6. RecoveryCodeModal (показать QR-код)
```

### **Вариант 2: Ввести код приглашения**
```
1. Пользователь выбирает "Ввести код приглашения"
   ↓
2. Открывается InvitationCodeInputModal
   ↓
3. Ввод кода: FAM-A1B2-C3D4-E5F6
   ↓
4. Валидация формата
   ↓
5. API: joinFamily(code)
   ↓
6. RoleSelectionModal
   ↓
7. Присоединение к семье
```

### **Вариант 3: Сканировать QR-код**
```
1. Пользователь выбирает "Сканировать QR-код"
   ↓
2. Открывается QRScannerModal
   ↓
3. Камера сканирует QR
   ↓
4. Распознавание: FAM_A1B2C3D4E5F6
   ↓
5. Автоматически → InvitationCodeInputModal
   ↓
6. Повтор: шаги 4-7 из Варианта 2
```
