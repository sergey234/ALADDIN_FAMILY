# ⚙️ АНАЛИЗ: Настройки родительского контроля

## 🔍 ТЕКУЩАЯ СИТУАЦИЯ

### Проблема:
- На `FamilyScreen` есть кнопка с шестиренкой (строка 308)
- При нажатии переходит на `ParentalControlScreen`
- `ParentalControlScreen` - это **дубликат** функционала с `FamilyScreen`
- Оба экрана показывают те же карточки и модалы

### Различия:
- `ParentalControlScreen` имеет **выбор ребёнка** (`selectedChild`)
- Всё остальное идентично

---

## 💡 ВАРИАНТЫ РЕШЕНИЯ

### **Вариант 1: Убрать кнопку совсем** ❌ НЕ РЕКОМЕНДУЮ
**Почему нет:**
- Нет доступа к расширенным настройкам
- Нет выбора ребёнка (если несколько детей)

---

### **Вариант 2: Модал с настройками** ⭐ РЕКОМЕНДУЮ
**Что делать:**
- Кнопка открывает **модал** с расширенными настройками
- В модале: выбор ребёнка + общие настройки

**Преимущества:**
- Быстрый доступ
- Не покидаем `FamilyScreen`
- Вся функциональность на месте

---

### **Вариант 3: Расширенный экран настроек**
**Что делать:**
- Создать новый экран `ParentalControlSettingsScreen`
- Перейти туда при нажатии на кнопку

**Преимущества:**
- Больше места для настроек
- Полноценная навигация

---

## 🎯 ЧТО ДОЛЖНО БЫТЬ В НАСТРОЙКАХ

### **1. Выбор ребёнка** (если несколько детей)
- Picker с выбором: "Маша", "Паша", "Ваня"
- Для каждого ребёнка - свои настройки
- Переключение между детьми

### **2. Общие настройки уведомлений**
- 🔔 Уведомления о блокировках
- ⏱️ Уведомления о превышении времени
- 📍 Уведомления о геолокации
- ⚠️ Уведомления об угрозах
- ✋ Уведомления о запросах доступа

### **3. Автоматические правила**
- 🌙 Автоматическая блокировка в ночное время
- 📅 Правила по дням недели
- 🎓 Правила по школьным дням
- 🏖️ Правила по каникулам

### **4. Уровни защиты по возрастам**
- 👶 5-8 лет: максимальная защита
- 🧒 9-12 лет: средняя защита
- 👦 13-15 лет: умеренная защита
- 🧑 16+ лет: базовая защита

### **5. Настройки геймификации** 🦄
- Включить/выключить систему единорогов
- Настройки вознаграждений
- Настройки турниров
- Частота наград

### **6. Геолокация**
- Точность определения местоположения
- Частота обновления
- Геозоны по умолчанию

### **7. Экспорт и резервное копирование**
- Экспорт данных
- Резервное копирование настроек
- Восстановление из резервной копии

### **8. Дополнительно**
- Язык интерфейса для ребёнка
- Временные зоны
- Синхронизация с другими устройствами
- История изменений настроек

---

## ⭐ РЕКОМЕНДУЕМОЕ РЕШЕНИЕ

### **Модал "Настройки родительского контроля"**

```
FamilyParentalControlSettingsModal:
├── Выбор ребёнка (Picker)
├── Общие уведомления (4 toggle)
├── Автоматические правила (кнопка "Настроить")
├── Уровень защиты (Slider или выбор)
├── Геймификация (кнопка "Настроить")
└── Дополнительно (кнопка "Открыть")
```
