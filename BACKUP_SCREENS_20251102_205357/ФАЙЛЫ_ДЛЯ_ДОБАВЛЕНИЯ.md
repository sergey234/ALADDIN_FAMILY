---

## ✅ Как добавить вручную:

1. Откройте Xcode
2. Наведите на нужную папку (например Core → Network)
3. Правая кнопка мыши → **"Add Files to ALADDIN..."**
4. Найдите файл в Finder
5. ✅ НЕ ставьте галочку "Copy items if needed" (файл уже в проекте!)
6. ✅ "Create groups" (создать группы)
7. ✅ Target Membership: **ALADDIN** (должна быть галочка)
8. Нажмите "Add"

### Или через Drag & Drop:
1. Откройте Finder
2. Найдите файл
3. Перетащите в нужную папку в Xcode
4. В диалоге:
   - ❌ НЕ ставим "Copy items if needed"
   - ✅ Group: нужная папка
   - ✅ Target Membership: ALADDIN
5. "Finish"

---

## 📝 Важно:
- Добавляйте по одному файлу
- После каждого добавления проверяйте что файл появился в Project Navigator
- Убедитесь что Target Membership включен
