## 🔧 ШАГИ ДОБАВЛЕНИЯ

### 1. Откройте файл
```
Core/Models/ProtectionFeature.swift
```

### 2. Найдите функцию `loadDefaultFeatures()`

### 3. Добавьте новую функцию в массив `features`:

```swift
ProtectionFeature(
    id: "unique_id",                    // Уникальный ID (латиница, нижний регистр)
    name: "Название функции",          // Название (отображается пользователю)
    icon: "system.icon.name",          // SF Symbols иконка
    description: "Описание функции",    // Описание (переносится только по словам)
    defaultLevels: [25, 50, 75, 100],  // На каких уровнях включается по умолчанию
    isEnabled: false                    // Начальное состояние (обычно false)
)
```

## 📝 ПРИМЕР ДОБАВЛЕНИЯ

### Пример: Добавить функцию "Защита от фишинга"

```swift
ProtectionFeature(
    id: "phishing_protection",
    name: "Защита от фишинга",
    icon: "exclamationmark.shield.fill",
    description: "Блокировка фишинговых сайтов и поддельных страниц",
    defaultLevels: [50, 75, 100],
    isEnabled: false
)
```

Добавьте этот код в массив `features` в функции `loadDefaultFeatures()`.

## 🎨 SF SYMBOLS ИКОНКИ

Используйте иконки из SF Symbols:
- `shield.fill` - защита
- `lock.fill` - блокировка
- `globe.badge.chevron.backward` - фильтрация
- `hand.raised.fill` - родительский контроль
- `chart.line.uptrend.xyaxis` - мониторинг
- `exclamationmark.triangle.fill` - угрозы
- `app.badge` - приложения
- `bell.badge.fill` - уведомления
- `eye.slash.fill` - блокировка рекламы
