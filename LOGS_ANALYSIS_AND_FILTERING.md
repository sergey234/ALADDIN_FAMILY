## 🎯 КАК ОТФИЛЬТРОВАТЬ ЛОГИ В XCODE CONSOLE

### Способ 1: Фильтр по процессу (САМЫЙ ПРОСТОЙ)

**Пошагово:**

1. **Откройте Console в Xcode:**
   - Нажмите **⌘⇧Y** (Command + Shift + Y)
   - Или: View → Debug Area → Activate Console

2. **Найдите панель фильтров:**
   - В консоли (внизу) найдите панель справа вверху
   - Там должны быть выпадающие списки

3. **Выберите фильтр по процессу:**
   - Найдите выпадающий список **"Process"** или **"Процесс"**
   - **Нажмите на список**
   - Выберите **"ALADDIN"** из списка

4. **Результат:**
   - В консоли останутся только логи процесса ALADDIN
   - Все системные логи (wifid, SpringBoard и т.д.) будут скрыты

---

### Способ 2: Фильтр по тексту (ДЛЯ НАШИХ ЛОГОВ)

**Пошагово:**

1. **Откройте Console** (⌘⇧Y)

2. **Найдите поле поиска:**
   - В консоли найдите поле поиска (обычно справа вверху)
   - Это может быть поле с иконкой лупы 🔍

3. **Введите фильтр:**
   - **Вариант 1:** `🔴` - все наши логи
   - **Вариант 2:** `ALADDIN` - все логи приложения
   - **Вариант 3:** `🔴 SETTINGS` - только логи Settings
   - **Вариант 4:** `family.aladdin.ios` - по bundle identifier

4. **Нажмите Enter**

5. **Результат:**
   - В консоли останутся только строки, содержащие введенный текст
   - Все остальные логи будут скрыты

---

### Способ 3: Комбинированный фильтр (САМЫЙ ТОЧНЫЙ)

**Пошагово:**

1. **Откройте Console** (⌘⇧Y)

2. **Настройте фильтр по процессу:**
   - В панели фильтров выберите **Process: ALADDIN**

3. **Добавьте текстовый фильтр:**
   - В поле поиска введите: `🔴`
   - Нажмите **Enter**

4. **Результат:**
   - Только логи процесса ALADDIN
   - Только наши логи с префиксом `🔴`
   - Все системные логи скрыты

## 🔍 ЧТО ДЕЛАТЬ, ЕСЛИ ЛОГОВ НЕТ

### Проблема: Логи `🔴 SETTINGS:` не появляются

**Возможные причины:**
1. Приложение крашится ДО того, как `onAppear` вызывается
2. Приложение не доходит до страницы Settings
3. Логи не записываются из-за краша

**Решение:**

### Вариант 1: Добавить логи раньше

Добавьте логи в самое начало `body`:

```swift
var body: some View {
    let _ = print("🔴 SETTINGS: body вычисляется - НАЧАЛО")
    settingsContent()
        .onAppear {
            print("🔴 SETTINGS: onAppear вызван")
            // ...
        }
}
```

### Вариант 2: Посмотреть Crash Report

1. В Xcode: **Window → Devices and Simulators** (⇧⌘2)
2. Выберите ваш iPhone
3. Нажмите **"View Device Logs"**
4. Найдите последний краш ALADDIN (обычно помечен красным)
5. **Дважды нажмите** на запись о краше
6. Откроется детальный crash report со стеком вызовов

### Вариант 3: Использовать системные логи

В ваших логах есть важная информация:
- `ReportCrash` - система создает crash report
- `Scene update failed` - ошибка обновления сцены
- `family.aladdin.ios` - bundle identifier приложения

Это может указывать на краш при создании/обновлении View.

## 📋 ИНСТРУКЦИЯ: КАК НАСТРОИТЬ ФИЛЬТРЫ В XCODE

### Шаг 1: Откройте Console

1. В консоли (внизу) найдите панель справа вверху
2. Там должны быть:
   - Выпадающий список **"Process"** (Процесс)
   - Поле поиска (с иконкой лупы 🔍)
   - Другие фильтры

### Шаг 3: Настройте фильтр по процессу

1. **Нажмите на выпадающий список "Process"**
2. В списке найдите **"ALADDIN"**
3. **Нажмите на "ALADDIN"**

**Результат:**
- В консоли останутся только логи процесса ALADDIN
- Все системные логи будут скрыты

### Шаг 4: Добавьте текстовый фильтр (опционально)

1. В поле поиска (с иконкой лупы) введите: `🔴`
2. Нажмите **Enter**

**Результат:**
- Только логи ALADDIN
- Только наши логи с префиксом `🔴`

### В ваших логах НЕТ наших логов!

1. **Посмотрите Crash Report:**
   - Window → Devices and Simulators (⇧⌘2)
   - View Device Logs
   - Найдите последний краш ALADDIN

2. **Добавьте логи раньше:**
   - В самое начало `body`
   - В `init()` View (если есть)

3. **Проверьте, доходит ли приложение до Settings:**
   - Добавьте логи на главном экране
   - Добавьте логи при нажатии на кнопку Settings
