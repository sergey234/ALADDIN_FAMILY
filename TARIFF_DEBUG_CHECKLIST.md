## ✅ ЧЕКЛИСТ ПРОВЕРКИ:

### 1. Проверка компиляции:
- [ ] Проект собирается без ошибок (BUILD SUCCEEDED)?
- [ ] Нет warnings в Xcode?

### 2. Проверка запуска приложения:
- [ ] Приложение запускается на симуляторе?
- [ ] Главный экран загружается?
- [ ] Экран тарифов открывается?

### 3. Проверка логов:
- [ ] Консоль открыта (⇧⌘Y)?
- [ ] Фильтр консоли пустой?
- [ ] В консоли есть ЛЮБЫЕ логи (не только наши)?

### 4. Проверка краша:
- [ ] После нажатия на тариф - приложение сразу закрывается?
- [ ] Или остается открытым, но не реагирует?
- [ ] Есть ли красный текст в консоли?

## 🎯 ВОЗМОЖНЫЕ ПРИЧИНЫ ЕСЛИ ЛОГОВ НЕТ:

### 1. Краш в SwiftUI до выполнения кода
**Симптом:** Нет ни одного лога вообще
**Причина:** SwiftUI пытается создать view структуру ДО выполнения button action
**Решение:** Использовать NavigationLink вместо sheet

### 2. Краш в инициализации статических свойств
**Симптом:** Краш при первом обращении к AppConfig
**Причина:** AppConfig.apiBaseURL может вызывать проблему
**Решение:** Обернуть в lazy static или проверку

### 3. Проблема с sheet binding
**Симптом:** Краш при изменении showPaymentQRScreen
**Причина:** SwiftUI не может создать view для sheet
**Решение:** Использовать fullScreenCover или NavigationLink

### 4. Симулятор не показывает логи
**Симптом:** Все работает, но логи не видны
**Причина:** Проблема с консолью Xcode
**Решение:** Перезапустить Xcode, использовать реальное устройство

```swift
// Откройте консоль и проверьте:

```

### Вариант B: Использовать NavigationLink вместо sheet
Заменить sheet на NavigationLink через NavigationManager

### Вариант C: Добавить Exception Breakpoint
1. Open Breakpoint Navigator (⌘8)
2. Кнопка "+" → Exception Breakpoint
3. Запустить приложение
4. Приложение остановится на точном месте краша
