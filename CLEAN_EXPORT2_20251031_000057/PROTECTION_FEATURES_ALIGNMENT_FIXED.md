## ➕ ДОБАВЛЕНИЕ НОВЫХ ФУНКЦИЙ

### ✅ ДА, можно добавлять новые функции!

**Как добавить:**
1. Откройте `Core/Models/ProtectionFeature.swift`
2. Найдите функцию `loadDefaultFeatures()`
3. Добавьте новую функцию в массив `features`:

```swift
ProtectionFeature(
    id: "new_feature_id",
    name: "Название функции",
    icon: "system.icon.name",
    description: "Описание функции",
    defaultLevels: [25, 50, 75, 100],
    isEnabled: false
)
```

**Результат:**
- ✅ Новая функция автоматически появится в списке
- ✅ Будет выровнена по левому краю
- ✅ Не будет переносов по слогам
- ✅ Получит переключатель автоматически

Подробная инструкция в: `HOW_TO_ADD_PROTECTION_FEATURES.md`
