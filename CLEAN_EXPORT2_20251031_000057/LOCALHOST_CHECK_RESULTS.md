### 2. Проверка подключения:

**Проверено:**
- `http://localhost:8000` → ❌ Connection refused (порт свободен)
- `http://localhost:8080` → ✅ Сервер отвечает (но неправильный endpoint)
- `http://192.168.0.101:8080` → ✅ Сервер доступен

**Вывод:** ✅ Backend доступен, но на порту 8080

---

### 3. IP адрес Mac:

**Найден:**
```
192.168.0.101
```

**Важно:** Для iOS симулятора нужно использовать IP адрес Mac, а не localhost!

---

## 🐛 НАЙДЕННЫЕ ПРОБЛЕМЫ

### Проблема 1: Неправильный порт в iOS

**iOS ожидает:** `localhost:8000`  
**Backend работает на:** `localhost:8080` (или `192.168.0.101:8080`)

**Исправлено:** Изменен URL в `AppConfig.swift` на `192.168.0.101:8080`

---

### Проблема 2: Использование localhost в симуляторе

**Проблема:** 
- В iOS симуляторе `localhost` = сам симулятор, НЕ ваш Mac
- Backend на Mac недоступен через `localhost` из симулятора

**Исправлено:** Используется IP адрес Mac: `192.168.0.101`

---

### Проблема 3: Возможен неправильный endpoint

**Проверка показала:**
- Сервер отвечает `501 Unsupported method ('POST')`
- Это может означать:
  - Endpoint `/api/payments/qr/create` не реализован
  - Или путь другой (например `/payments/qr/create` без `/api/`)
  - Или метод должен быть GET вместо POST

**Нужно проверить:** Какие endpoint доступны на вашем backend

---

## ✅ ЧТО СДЕЛАНО
