## ❌ **ПРОБЛЕМА: "Схема не настроена для тестирования"**

### **Что это означает:**
Схема `ALADDIN` в проекте настроена только для **сборки** (Build), но не для **тестирования** (Test). Это означает, что:

1. **Можно**: Собирать и запускать приложение
2. **Нельзя**: Запускать Unit Tests и UI Tests через схему

### **Причины:**
- В проекте нет настроенных тестовых таргетов
- Схема не включает тестовые конфигурации
- Отсутствуют тестовые файлы в схеме

## 🚀 **РЕШЕНИЯ ПРОБЛЕМЫ**

### **Вариант 1: Запуск без тестов (Рекомендуется)**
```bash
# Просто запустить приложение в симуляторе
xcodebuild -project ALADDIN.xcodeproj -scheme ALADDIN -destination 'platform=iOS Simulator,name=iPhone 13' -derivedDataPath ./build
```

### **Вариант 2: Настройка тестовой схемы**
1. Открыть проект в Xcode
2. Edit Scheme → Test → Add Test Target
3. Настроить тестовые таргеты

### **Вариант 3: Запуск через Xcode**
```bash
# Открыть проект в Xcode
open ALADDIN.xcodeproj
# Затем запустить через Xcode (⌘+R)
```
