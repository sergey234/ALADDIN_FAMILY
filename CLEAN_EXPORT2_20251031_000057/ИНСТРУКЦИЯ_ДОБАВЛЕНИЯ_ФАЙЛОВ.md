## 🎯 ПОРЯДОК ДОБАВЛЕНИЯ В XCODE:

### ШАГ 1: Открыть Xcode
1. Открыть проект `ALADDIN.xcodeproj`

### ШАГ 2: Найти нужную группу
1. В левой панели (Navigator) найти группу
2. Например: `Core` → `Security` для `SecurityManager.swift`

### ШАГ 3: Добавить файл
1. Правый клик на группу → `Add Files to "ALADDIN"...`
2. Выбрать файл
3. ✅ Отметить: **"Copy items if needed"** (если файл вне проекта)
4. ✅ Отметить: **"Create groups"**
5. ✅ Выбрать Target: **ALADDIN**
6. Нажать **"Add"**

### ШАГ 4: Проверить
1. Файл появился в Navigator
2. Файл добавлен в Build Phases → Compile Sources
