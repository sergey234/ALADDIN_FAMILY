# 🔍 АНАЛИЗ ПОТОКА ОПЛАТЫ ПО QR-КОДУ

## 📋 ТЕКУЩАЯ ЛОГИКА

### 1. Когда должен появляться QR код?

**✅ ПРАВИЛЬНО: При заходе на страницу, автоматически**

**Процесс:**
1. Пользователь нажимает "ОПЛАТИТЬ ЧЕРЕЗ QR" на экране тарифов
2. Открывается `PaymentQRScreen`
3. В `onAppear` автоматически вызывается:
   - `viewModel.createPayment()` - создание платежа и получение QR кода
   - `viewModel.startAutoCheck()` - запуск авто-проверки статуса каждые 30 секунд

**Текущая реализация:**
```swift
.onAppear {
    viewModel.createPayment()  // ✅ Вызывается сразу при заходе
    viewModel.startAutoCheck()
}
```

**Ожидаемое поведение:**
- Сразу при открытии страницы показывается "Загрузка QR-кода..."
- После получения ответа от сервера (обычно 1-3 секунды) показывается QR код
- QR код отображается сразу, пользователю не нужно ничего нажимать

---

### 2. Кто генерирует QR код?

**✅ Backend сервер генерирует QR код**

**Процесс генерации:**
1. **iOS приложение:** Отправляет POST запрос на `/api/payments/qr/create` с данными тарифа
   ```swift
   let request = CreateQRPaymentRequest(
       amount: amount,      // Сумма (например, 590.0)
       currency: "RUB",      // Валюта
       description: tariff.title,  // Описание
       tariffId: tariff.id   // ID тарифа
   )
   ```

2. **Backend сервер:**
   - Получает запрос
   - Создает платеж в системе
   - Генерирует QR код для оплаты (обычно это URL или base64 изображение)
   - Возвращает ответ:
     ```json
     {
       "paymentId": "abc123",
       "qrCode": "https://... или data:image/png;base64,...",
       "expiresAt": "2024-01-01T12:00:00Z"
     }
     ```

3. **iOS приложение:**
   - Получает ответ от сервера
   - Сохраняет `paymentId` и `qrCode`
   - Отображает QR код на экране

**Ответственность:**
- ❌ iOS НЕ генерирует QR код сам
- ✅ iOS только получает готовый QR код от backend
- ✅ Backend отвечает за генерацию QR кода через платежную систему (СБП, банк и т.д.)

### 3. Проблема с кнопкой "Проверить статус оплаты"

**Текущая реализация:**
```swift
func checkPaymentStatus() {
    guard let paymentId = paymentId else {
        errorMessage = "QR-код еще загружается..."
        showErrorAlert = true
        return
    }
    
    apiService.checkQRPaymentStatus(paymentId: paymentId) { result in
        // Обработка ответа
    }
}
```

**Возможные проблемы:**

1. **Кнопка disabled когда paymentId == nil**
   - ✅ Правильно - нельзя проверить статус без paymentId
   - НО: Кнопка может оставаться disabled даже после загрузки QR кода
   - **Решение:** Проверить что `paymentId` правильно сохраняется после `createPayment()`

2. **Ошибка в API запросе**
   - Endpoint: `/api/payments/qr/status/{paymentId}`
   - Если сервер не отвечает или возвращает ошибку → показывается alert
   - **Решение:** Улучшить логирование и обработку ошибок

3. **Нет визуальной обратной связи**
   - Когда пользователь нажимает кнопку, isLoading меняется на true
   - Кнопка показывает "Проверяем..." и ProgressView
   - ✅ Это правильно, но нужно проверить что isLoading правильно обновляется
