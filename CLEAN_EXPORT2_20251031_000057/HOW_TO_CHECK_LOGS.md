# 📊 КАК ПРОВЕРИТЬ ЛОГИ В XCODE - ПОШАГОВАЯ ИНСТРУКЦИЯ

## 🎯 ЦЕЛЬ
Найти место, где происходит краш при выборе тарифа, с помощью логов в Xcode.

---

## 📋 ШАГ 1: ОТКРЫТЬ КОНСОЛЬ В XCODE

### Вариант 1: Через меню
1. Запустите проект в Xcode (⌘R или кнопка ▶️)
2. Меню: **View → Show Debug Area** (или нажмите **⇧⌘Y**)
3. Консоль появится внизу окна Xcode

### Вариант 2: Через кнопку
1. Внизу окна Xcode найдите кнопку с **иконкой квадрата** (показать/скрыть Debug Area)
2. Нажмите на неё

---

## 📋 ШАГ 3: ЗАПУСТИТЬ ПРИЛОЖЕНИЕ И ПОВТОРИТЬ ДЕЙСТВИЕ

1. Запустите приложение (⌘R)
2. Дождитесь загрузки
3. Откройте экран тарифов
4. Нажмите на любой тариф (например, "СЕМЕЙНЫЙ")

## 📋 ШАГ 5: ФИЛЬТРАЦИЯ ЛОГОВ

Если логов слишком много, используйте фильтр:

1. Внизу консоли есть поле **"Filter"** или строка поиска
2. Введите туда: `🔍` или `✅` или `❌`
3. Будут показаны только наши логи

---

## 📋 ШАГ 6: ЕСЛИ ПРИЛОЖЕНИЕ КРАШИТСЯ

### Найти место краша:

1. **После краша** в консоли появится **красный блок** с ошибкой
2. Посмотрите на **стек вызовов** (stack trace) - это список методов где произошла ошибка
3. Найдите в стеке вызовов названия наших файлов:
   - `TariffsScreen.swift`
   - `PaymentQRScreen.swift`
   - `PaymentQRViewModel.swift`

### Пример стека вызовов:
```
Thread 1: Fatal error
0. PaymentQRScreen.init() at PaymentQRScreen.swift:52
1. TariffsScreen.body.getter at TariffsScreen.swift:145
2. ...
```

**→ Строка 52 в PaymentQRScreen.swift - вот где краш!**

---

## 📋 ШАГ 7: BREAKPOINTS (ТОЧКИ ОСТАНОВКИ)

Если хотите остановиться **до** краша:

1. Откройте файл `Screens/10_TariffsScreen.swift`
2. Найдите строку **277** (начало Button action)
3. Кликните **на серой полоске слева от номера строки**
4. Появится синяя точка (breakpoint)
5. Запустите приложение - оно остановится на этой строке
6. Нажимайте **F6** (Step Over) чтобы выполнять пошагово
7. Смотрите в консоль какие логи появляются

## 📋 ШАГ 8: ЧТО ПЕРЕДАТЬ МНЕ

Если проблема не решена, пришлите мне:

1. **Последние 20-30 строк логов перед крашем**
2. **Точное сообщение об ошибке** (красный текст)
3. **Номер строки где краш** (из стека вызовов)
4. **На каком сообщении останавливается** (последнее успешное сообщение)
