## 🔧 ИСПРАВЛЕННЫЕ ОШИБКИ:

### 1. ✅ Дублирование RewardOperation

**Проблема:**
- `RewardOperation` был определен дважды:
  - В `Shared/Models/RewardModels.swift` (оригинальное определение)
  - В `Screens/ChildRewardsScreen.swift` (временное определение)
- Ошибка: `invalid redeclaration of 'RewardOperation'`

**Исправление:**
- Удалено временное определение из `ChildRewardsScreen.swift`
- Оставлено только оригинальное определение в `RewardModels.swift`

**Файл:** `Screens/ChildRewardsScreen.swift` (строки 4-16)

---

### 2. ✅ CollapsibleSection - ошибки с @ViewBuilder

**Проблема:**
- `CollapsibleSection` не поддерживал условные операторы (`if-else`) в closure
- Ошибки:
  - `'RewardOperation' is ambiguous for type lookup in this context`
  - `initializer 'init(icon:title:subtitle:isExpanded:content:)' requires that 'EmptyCommands' conform to 'View'`
  - `closure containing control flow statement cannot be used with result builder 'CommandsBuilder'`

**Исправление:**
- Добавлен `@ViewBuilder` к параметру `content` в `init` методе `CollapsibleSection`
- Теперь поддерживаются условные операторы внутри closure

**Файл:** `Shared/Components/CollapsibleSection.swift` (строки 11-17)

**Изменения:**
```swift
// Было:
let content: () -> Content

// Стало:
init(icon: String, title: String, subtitle: String? = nil, isExpanded: Binding<Bool>, @ViewBuilder content: @escaping () -> Content) {
    // ...
}
```
