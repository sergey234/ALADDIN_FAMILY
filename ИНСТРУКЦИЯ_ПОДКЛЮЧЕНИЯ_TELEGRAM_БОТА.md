# 📱 ИНСТРУКЦИЯ: Подключение Telegram бота поддержки

**Бот:** [@aladdin_support_bot](https://t.me/aladdin_support_bot)  
**Статус:** ✅ Уже настроен и работает

---

## 🎯 КАК ЭТО РАБОТАЕТ

### В приложении:
1. Пользователь открывает **Настройки → Дополнительно → Помощь и поддержка**
2. Нажимает на кнопку **"Чат с поддержкой"**
3. Приложение автоматически открывает Telegram с ботом `@aladdin_support_bot`
4. Пользователь может сразу начать общаться с ботом

### Технические детали:
- Используется URL scheme: `https://t.me/aladdin_support_bot`
- При нажатии вызывается `UIApplication.shared.open(url)`
- iOS автоматически открывает Telegram (если установлен) или браузер
- Если Telegram установлен → открывается приложение с ботом
- Если Telegram не установлен → открывается веб-версия Telegram

### Где используется:
- `Screens/13_SupportScreen.swift` - экран поддержки
- При нажатии на кнопку "Чат с поддержкой" открывается этот URL

### ✅ УЖЕ СДЕЛАНО:
- Бот создан: `@aladdin_support_bot`

- Интеграция в приложении настроена

### 🔄 ДЛЯ РАБОТЫ БОТА В TELEGRAM:
1. **Настроить бота через BotFather:**
   - Откройте [@BotFather](https://t.me/BotFather) в Telegram
   - Отправьте `/mybots`
   - Выберите `@aladdin_support_bot`
   - Настройте команды, описание, фото

2. **Добавить команды бота:**
   - `/start` - приветствие
   - `/help` - помощь
   - `/faq` - часто задаваемые вопросы
   - `/contact` - контакты поддержки

3. **Настроить автоматические ответы:**
   - Приветствие при `/start`
   - Ответы на частые вопросы
   - Переключение на оператора (если нужно)

4. **Подключить к серверу (опционально):**
   - Если нужна интеграция с вашим сервером
   - Настроить webhook для получения сообщений
   - Обработка команд и сообщений
