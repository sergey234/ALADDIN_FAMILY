## 📅 Дата создания: $(date '+%Y-%m-%d %H:%M:%S')

## 📁 Структура резервных копий

Все резервные копии сохраняются в папках с префиксом `BACKUP_SCREENS_` и датой создания.

### Формат имени папки:
```
BACKUP_SCREENS_YYYYMMDD_HHMMSS
```

Например:
```
BACKUP_SCREENS_20250102_143052
```

---

## 📦 Что сохраняется:

### 1. Экраны (Screens/)
- Все файлы `*.swift` из папки `Screens/`
- Включая:
  - `RewardsModalView.swift`
  - `ChildRewardsScreen.swift`
  - `GamesParentalControlView.swift`
  - `02_FamilyScreen.swift`
  - И все остальные экраны

### 2. Документация (*.md)
- Все markdown файлы из корневой папки
- Включая:
  - `АРХИТЕКТУРА_ГЕЙМИФИКАЦИИ_И_НАГРАД.md`
  - `РЕШЕНИЕ_ПРОБЛЕМЫ_СЕКЦИИ_МАГАЗИНА.md`
  - И другие документы

### 3. Core/
- Модули из папки `Core/`
- Включая:
  - `Navigation/NavigationManager.swift`
  - И другие компоненты

### 4. Shared/
- Общие модели и компоненты
- Включая:
  - `Models/RewardModels.swift`
  - И другие модули

## ♻️ Восстановление из резервной копии:

⚠️ **ВНИМАНИЕ:** Восстановление перезапишет текущие файлы!

```bash
# 1. Найти нужную резервную копию
BACKUP_DIR="BACKUP_SCREENS_YYYYMMDD_HHMMSS"

# 2. Восстановить файлы
cp "$BACKUP_DIR"/*.swift Screens/
cp "$BACKUP_DIR"/*.md .
cp -r "$BACKUP_DIR/Core" .
cp -r "$BACKUP_DIR/Shared" .
```
