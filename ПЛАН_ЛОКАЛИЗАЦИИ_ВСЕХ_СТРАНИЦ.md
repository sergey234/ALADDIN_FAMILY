## 📚 СТРУКТУРА СЛОВАРЯ ПЕРЕВОДОВ

### Формат ключей:
- **Заголовки секций:** `{screen_name}_section_{name}`
- **Кнопки/пункты меню:** `{screen_name}_{item_name}`
- **Подзаголовки:** `{screen_name}_{item_name}_subtitle`
- **Описания:** `{screen_name}_{item_name}_description`

### Примеры:
```swift
// SettingsScreen
"settings_title" → "НАСТРОЙКИ" / "SETTINGS"
"settings_subtitle" → "Управление приложением" / "App Management"
"profile_section" → "ПРОФИЛЬ" / "PROFILE"
"privacy_policy" → "Политика конфиденциальности" / "Privacy Policy"
"privacy_policy_subtitle" → "Как мы защищаем ваши данные" / "How we protect your data"
```

## 📝 ПОШАГОВАЯ ИНСТРУКЦИЯ ДЛЯ КАЖДОЙ СТРАНИЦЫ

### Для каждой страницы выполнить следующие шаги:

#### ШАГ 1: Создать резервную копию
```bash
cp Screens/{ScreenName}.swift Screens/{ScreenName}.swift.backup_before_localization_$(date +%Y%m%d_%H%M%S)
```

#### ШАГ 2: Добавить LocalizationManager
```swift
@EnvironmentObject private var localizationManager: LocalizationManager
```

#### ШАГ 3: Найти все хардкоденые строки
Использовать поиск:
- `Text("...")` - прямые тексты
- `title: "..."` - заголовки
- `subtitle: "..."` - подзаголовки
- `.accessibilityLabel("...")` - accessibility labels (можно оставить на русском)

#### ШАГ 4: Создать список ключей для словаря
Для каждой строки создать ключ по формату:
- `{screen_name}_{text_description}`

Пример для MainScreen:
- `main_welcome` → "Добро пожаловать"
- `main_protection_status` → "Защита активна"
- `main_family_members` → "Члены семьи"

#### ШАГ 5: Добавить ключи в LocalizationManager.swift
В секцию `.russian` и `.english` (и другие языки):
```swift
.russian: [
    // ... существующие ключи
    // Новые ключи для {ScreenName}
    "{screen_name}_key1": "Русский текст",
    "{screen_name}_key2": "Другой русский текст",
],
.english: [
    // ... существующие ключи
    // Новые ключи для {ScreenName}
    "{screen_name}_key1": "English text",
    "{screen_name}_key2": "Another English text",
]
```

#### ШАГ 6: Заменить все строки на localized()
```swift
// Было:
Text("Добро пожаловать")

// Стало:
Text(localizationManager.localized("main_welcome"))
```

#### ШАГ 7: Добавить .id() для пересоздания View
В конце `body` или в `ZStack`:
```swift
.id("{screen_name}_lang_\(localizationManager.currentLanguage.rawValue)")
```

#### ШАГ 8: Подключить LocalizationManager в ALADDINApp.swift
Найти case для экрана и добавить:
```swift
case .{screenName}:
    AnyView({ScreenName}()
        .environmentObject(navigationManager)
        .environmentObject(localizationManager)) // ✅ Добавить
```

#### ШАГ 9: Проверить компиляцию
```bash
xcodebuild -project ALADDIN.xcodeproj -scheme ALADDIN -sdk iphonesimulator build
```

#### ШАГ 10: Протестировать
1. Запустить приложение
2. Переключить язык на английский
3. Проверить, что все тексты переведены

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Где находится словарь переводов:
`Core/Localization/LocalizationManager.swift` (строки 97-194)

### Где подключать LocalizationManager:
`ALADDINApp.swift` (case для каждого экрана)

### Как работает пересоздание View:
```swift
.id("{screen}_lang_\(localizationManager.currentLanguage.rawValue)")
```
При изменении языка меняется ID, SwiftUI пересоздаёт View, и все тексты обновляются.

### Формат ключей:
- Использовать snake_case: `main_welcome`, `family_members_count`
- Группировать по экранам: `{screen_name}_{item_name}`
- Добавлять суффиксы: `_subtitle`, `_description`, `_button`
