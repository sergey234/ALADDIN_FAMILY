## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Эндпоинты:
- `GET /api/protection/threats` - получить все угрозы
- `GET /api/protection/threats/{status}` - получить угрозы по статусу
- `POST /api/protection/quarantine/action` - выполнить действие с карантином

### Формат запроса для карантина:
```json
{
  "threatId": "string",
  "action": "quarantine|restore|remove",
  "filePath": "string (optional)"
}
```

### Формат ответа угроз:
```json
{
  "threats": [
    {
      "id": "string",
      "name": "string",
      "type": "string",
      "severity": "string",
      "confidence": 0.0,
      "filePath": "string",
      "fileSize": 0,
      "detectedAt": "ISO 8601 date",
      "status": "active|quarantined|resolved",
      "quarantinePath": "string",
      "quarantinedAt": "ISO 8601 date"
    }
  ],
  "total": 0,
  "active": 0,
  "quarantined": 0,
  "resolved": 0
}
```
