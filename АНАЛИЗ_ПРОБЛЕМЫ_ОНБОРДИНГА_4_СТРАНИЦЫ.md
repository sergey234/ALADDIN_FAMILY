# 🔍 АНАЛИЗ ПРОБЛЕМЫ: Онбординг меняется с 7 на 4 страницы

## ❌ ПРОБЛЕМА:
**Онбординг автоматически меняется с 7 страниц на 4 страницы, хотя мы ничего не делаем**

## 🔎 ВОЗМОЖНЫЕ ПРИЧИНЫ:

### 1. **OnboardingViewModel.swift имеет totalPages: 4**
**Файл:** `ViewModels/OnboardingViewModel.swift`
```swift
let totalPages: Int = 4  // ❌ Жёстко задано 4 страницы!
```

**Проблема:** Если `OnboardingScreen` использует `OnboardingViewModel`, то он может ограничивать количество страниц до 4.

**Решение:** Проверить, используется ли `OnboardingViewModel` в `14_OnboardingScreen.swift`

### 2. **Дублирующий файл OnboardingScreen**
**Возможные файлы:**
- `Screens/14_OnboardingScreen.swift` ✅ (7 страниц - правильный)
- `OnboardingScreen.swift` ❓ (может быть другой файл с 4 страницами)

**Проблема:** Если есть два файла с одинаковым именем структуры, Swift может использовать неправильный.

### 3. **Git или система контроля версий**
**Проблема:** Git может автоматически откатывать изменения при merge или rebase.

**Решение:** Проверить `.gitignore` и историю изменений

### 4. **Xcode кеш или DerivedData**
**Проблема:** Xcode может использовать старую версию файла из кеша.

**Решение:** Очистить DerivedData

### 5. **Автоматическое форматирование или линтер**
**Проблема:** Автоматические инструменты могут заменять файл на старую версию.

**Решение:** Проверить настройки форматирования

### 6. **Резервные копии перезаписывают основной файл**
**Проблема:** Скрипты или процессы могут копировать старые версии из BACKUP.

**Решение:** Проверить, нет ли автоматических скриптов копирования
