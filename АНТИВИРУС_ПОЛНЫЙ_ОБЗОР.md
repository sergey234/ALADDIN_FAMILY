# 🛡️ ПОЛНЫЙ ОБЗОР АНТИВИРУСА В ПРИЛОЖЕНИИ ALADDIN

## 📍 ГДЕ НАХОДИТСЯ АНТИВИРУС В ПРИЛОЖЕНИИ

### 1. **Главный экран (MainScreen)**
   - **Файл:** `Screens/01_MainScreen.swift`
   - **Расположение:** Карточка антивируса на главном экране
   - **Что показывает:**
     - Статус (Активен/Отключен)
     - Иконка антивируса
     - Название: "Антивирус Аладин"
     - Подзаголовок с описанием

### 2. **Экран защиты сети (NetworkProtectionScreen)**
   - **Файл:** `Screens/03_NetworkProtectionScreen.swift`
   - **Расположение:** Первая карточка сверху на экране "Защита ALADDIN"
   - **Что показывает:**
     - Переключатель включения/выключения антивируса
     - Статистика сканирования:
       - 🔍 Файлов проверено
       - ✅ Угроз найдено
       - 🔄 Последняя проверка
       - ⚡ Уровень защиты (100% / 0%)
     - **Кнопка "Сканировать"** - запускает быстрое сканирование
   - **Логирование:** Логи отображаются через `VisualLogger` с категорией "ANTIVIRUS"

### 3. **Настройки обнаружения вредоносного ПО**
   - **Файл:** `Screens/MalwareDetectionSettingsScreen.swift`
   - **Доступ:** Через настройки → Безопасность → Обнаружение вредоносного ПО
   - **Что показывает:**
     - Реальное время сканирования (вкл/выкл)
     - Сканирование загрузок (вкл/выкл)
     - Сканирование установленных приложений (вкл/выкл)
     - Карантин угроз (вкл/выкл)
     - Автоматическое удаление угроз (вкл/выкл)
     - Частота сканирования (ежечасно/ежедневно/еженедельно)
     - Кнопка быстрого сканирования

## 🔧 КОМПОНЕНТЫ И МЕНЕДЖЕРЫ

### 1. **AntivirusManager** (Основной менеджер)
   - **Файл:** `Core/Antivirus/AntivirusManager.swift`
   - **Функции:**
     - `quickMetadataCheck(fileURL:)` - быстрая проверка метаданных файла
     - `performFullScan(fileURL:)` - полное сканирование файла
     - `scanFiles(_ fileURLs:)` - пакетное сканирование файлов
     - `quarantineThreat(_:fileURL:)` - поместить угрозу в карантин ✅ ИСПРАВЛЕНО
     - `removeThreat(_:fileURL:)` - удалить угрозу ✅ ИСПРАВЛЕНО
   - **Состояние:**
     - `@Published var isScanning: Bool` - идет ли сканирование
     - `@Published var lastScanResult: ScanResult?` - результат последнего сканирования
     - `@Published var threatsDetected: [Threat]` - обнаруженные угрозы
     - `@Published var scanProgress: Double` - прогресс сканирования (0.0 - 1.0)

### 2. **QuarantineManager** (Менеджер карантина)
   - **Файл:** `Core/Antivirus/QuarantineManager.swift`
   - **Функции:**
     - `quarantineFile(from:threatName:threatType:severity:confidence:)` - поместить файл в карантин
     - `restoreFile(from:to:)` - восстановить файл из карантина
     - `permanentlyRemoveFile(_:)` - полностью удалить файл из карантина
     - `cleanupOldQuarantineFiles(daysOld:)` - очистить старые файлы (старше N дней)
     - `getQuarantineStats()` - получить статистику карантина
     - `syncQuarantineWithServer()` - синхронизировать карантин с сервером
   - **Хранилище:** `Documents/ALADDIN_Quarantine/`
   - **Метаданные:** `quarantine_metadata.json`

### 3. **MalwareSettingsViewModel** (ViewModel для настроек)
   - **Файл:** `ViewModels/MalwareSettingsViewModel.swift`
   - **Функции:**
     - `performQuickScan()` - выполнить быстрое сканирование
     - `scanFile(at:)` - сканировать конкретный файл
     - `handleThreat(_:action:fileURL:)` - обработать обнаруженную угрозу
     - `loadQuarantineStats()` - загрузить статистику карантина
     - `clearScanHistory()` - очистить историю сканирований
     - `loadAntivirusStats()` - загрузить статистику антивируса с сервера

## 🗂️ СТРУКТУРА ДАННЫХ

### ScanResult
```swift
struct ScanResult: Codable {
    let filePath: String
    let threatLevel: ThreatLevel  // clean, safe, suspicious, dangerous, checkingServer
    let detectedThreats: [Threat]
    let scanTime: Date
    let checksum: String?
}
```

### Threat
```swift
struct Threat: Codable {
    let id: String
    let name: String
    let type: String  // "virus", "malware", "adware", "spyware"
    let severity: String  // "low", "medium", "high", "critical"
    let description: String
    let confidence: Double
}
```

### QuarantinedFile
```swift
struct QuarantinedFile: Codable, Identifiable {
    let id: String
    let originalPath: String
    let originalName: String
    let quarantinePath: String
    let fileSize: Int64
    let threatName: String
    let threatType: String
    let severity: String
    let confidence: Double
    let quarantinedAt: Date
    let checksum: String?
    var status: String  // "quarantined", "restored", "removed"
}
```

## 🚀 КАК ИСПОЛЬЗОВАТЬ

### Запуск сканирования:
1. Откройте экран "Защита ALADDIN"
2. Найдите карточку "Антивирус"
3. Нажмите кнопку "Сканировать"
4. Следите за логами в окне логов

### Просмотр результатов:
1. Проверьте статистику в карточке антивируса
2. Откройте окно логов (если включено)
3. Проверьте настройки антивируса для истории сканирований

### Работа с карантином:
1. При обнаружении угрозы она автоматически помещается в карантин (если включено)
2. Файлы хранятся в `Documents/ALADDIN_Quarantine/`
3. Метаданные сохраняются в `quarantine_metadata.json`
4. Можно восстановить или удалить файлы через `QuarantineManager`

## 📝 ЗАМЕТКИ

- Логи антивируса отображаются в `VisualLogger` с категорией "ANTIVIRUS"

- Статистика обновляется автоматически после сканирования
- Прогресс сканирования отображается через `antivirusManager.scanProgress`
