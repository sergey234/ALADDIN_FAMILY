# План: приоритет оплаты по ссылке Ckassa (bc) и дальнейшее подключение авто-оплаты

## Цель

Сейчас основной сценарий для покупателя - **оплата по универсальной ссылке** `CKASSA_BC_UNIVERSAL_PAYMENT_URL` (произвольная сумма). Позже без смены логики заказов подключить **Ckassa Shop API** и **LAVA** для авто-статуса «Оплачен» по webhook.

## Фаза 1 (сделано в боте)

1. Задать в `.env` ссылку: `CKASSA_BC_UNIVERSAL_PAYMENT_URL=https://bc.ckassa.ru/...`
2. Для режима **только ссылка** (без кнопок счёта Shop API и LAVA): `CKASSA_BC_SOLO_CHECKOUT=true`
3. Покупатель видит:
   - сумму заказа;
   - чеклист: минимум **50 ₽** (настраивается `CKASSA_BC_DISPLAY_MIN_RUB`), одна оплата, **ID заказа**, код **ORDER{id}** в назначение, шаги по ссылке;
   - предупреждение, если сумма заказа ниже минимума;
   - кнопки: ссылка на оплату, «Я оплатил», при настройке - поддержка по заказу.
4. Оператор в ЛК Ckassa сверяет сумму, время и при наличии **ORDER…** в назначении; в боте жмёт «Оплачен».

## Фаза 2 (проверка на реальном платеже)

1. Тестовая оплата минимальной суммы по ссылке.
2. Убедиться в ЛК: попадает ли текст из «назначение» в выписку.
3. Если поля нет у части банков - оставить инструкцию и кнопку «Я оплатил» как сейчас.

## Фаза 3 (подключение авто-«Оплачен»)

1. В `.env`: `CKASSA_BC_SOLO_CHECKOUT=false`
2. Включить **Ckassa Shop API**: `CKASSA_ENABLED=true`, токены, `CKASSA_CALLBACK_PUBLIC_URL` на ваш webhook.
3. При необходимости настроить **LAVA**.
4. Покупатель увидит **несколько кнопок**: ссылка bc + счёт Ckassa + LAVA. Рекомендация в тексте бота: для **авто-статуса** удобнее счёт с фиксированной суммой; ссылка bc остаётся запасным путём.

## Закреп в канале

1. Админ в личке с ботом: команда **`/channel_checkout_pin`** (только для `ADMIN_IDS`).
2. Скопировать ответ или **переслать** в канал магазина → **закрепить** (бот должен быть админом канала с правом закреплять, либо закреп вручную админом канала).

Текст совпадает с логикой оплаты по ссылке bc (минимум 50 ₽, сумма, ORDER, один платёж, «Я оплатил», «Заказы»).

## Переменные окружения (кратко)

| Переменная | Назначение |
|------------|------------|
| `CKASSA_BC_UNIVERSAL_PAYMENT_URL` | Постоянная ссылка bc.ckassa.ru |
| `CKASSA_BC_SOLO_CHECKOUT` | `true` - только эта ссылка на шаге ₽; `false` - плюс API Ckassa/LAVA при настройке |
| `BC_PAYMENT_CLAIM_COOLDOWN_SECONDS` | Антиспам на «Я оплатил» |
| `SUPPORT_URL` / `SUPPORT_USERNAME` | Ссылка «Поддержка по заказу» с префиллом |

## Надёжность

- **Кто / за что** по заказу в боте всегда однозначны.
- **Факт денег** по ссылке bc без Shop API подтверждается **в ЛК** (и при желании по коду `ORDER{id}` в назначении).
- Полный автопай без ручной сверки по одной только bc-ссылке не гарантируется; он появляется при **счёте Shop API Ckassa** или **LAVA** с webhook.
