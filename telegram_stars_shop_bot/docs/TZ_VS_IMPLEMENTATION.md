# ТЗ → факт (краткая сводка, актуализация)

Одностранично: что просили в исходном ТЗ и что есть в **`telegram_stars_shop_bot`** сейчас.

| Пункт ТЗ | Что просили | Что сделано |
|-----------|-------------|-------------|
| **1. Цель** | Удобный бот-магазин: **Premium** (подарки 1/3/6/12 мес.), **Stars** пакетами | **AIMonkeyStars (@AiMonkeyStars_bot):** хаб `/menu`, каталог Stars/Premium/**подарки** (`gift_custom`), оформление заказа, профиль, поддержка, партнёрский блок |
| **2.1 Каталог Premium** | 3 / 6 / 12 мес. | В YAML **1, 3, 6, 12** мес.; в **меню бота** витрина Premium только **3 / 6 / 12** (`premium_1` с `hide_from_menu: true`; API и прямой `product_id` по-прежнему могут заказать 1 мес.) |
| **2.1 Каталог Stars** | 100, 300, 500, 1000, **2000+** | **100, 300, 500, 1000, 2000, 5000** — «2000+» закрыто пакетом 5000; новые строки в YAML |
| **2.1 Расширение каталога** | Легко добавлять товары | **Да:** правка `bot/products.yaml` + перезапуск бота (цены в USD) |
| **2.2 Цены** | Внутри **USD**, пользователю **RUB** по курсу | **Да:** `price_usd` → `USD_RUB_RATE` → ₽ в расчётах и текстах |
| **2.2 Опт Stars 5% от 500+** | Автоскидка от 500 ⭐ в позиции | **Да:** порог и % из `.env` (`STARS_WHOLESALE_THRESHOLD`, по умолчанию **500** и **5%**) |
| **2.2 Рефералка** | Скидка новым; вознаграждение пригласившему | **Да:** скидка до первого **выданного** заказа; комиссия рефереру с **первой выданной** покупки друга (дефолт 15% от ₽ заказа). Статистика: профиль, «Реф-ссылка», Partner `GET /v1/user/profile` |
| **2.3 Фиат** | RUB / UAH / BYN через **YooKassa / Lava / Robokassa** | **Только ₽** в расчётах и UX; **LAVA:** счёт + кнопка URL при `LAVA_*` + `LAVA_HOOK_URL`. **YooKassa/Robokassa:** нет отдельных модулей; есть **универсальный** `POST /v1/payments/provider-webhook` + ручная отметка «Оплачен» в админке |
| **2.3 Подсказки UAH/BYN** | Фиат в разных валютах | **Убрано из продукта** (задача `1-rub-only`); опционально только **USDT** как ориентир к сумме в ₽ |
| **2.3 Крипта** | USDT TRC20, TON | **Провайдеры:** Crypto Pay + xRocket Pay — только **USDT (TRC20)**, две кнопки при настройке обоих. **Прод-чеклист** (`shared/.env` + URL вебхуков + смоук): **`docs/CRYPTO_PAY_SPEC.md` §0**. **Ручной путь:** `CRYPTO_USDT_TRC20`, memo `ORDER{id}`; TON — по умолчанию в блоке (`CRYPTO_SHOW_TON_MANUAL`). **Вебхуки:** `POST …/crypto-pay-webhook`, `POST …/xrocket-webhook` → авто `paid` |
| **2.4 Выдача** | Критичный процесс | **Гибрид:** `paid` → (опц.) **авто iStar** `processing` + `fulfillment_provider_ref` → вебхук **`/v1/payments/istar-webhook`** → `completed` + рефка; сбой create → откат **`processing`→`paid`**, текст покупателю + поддержка. Ручной путь: админ **«В работе»** / **«Выдан»**; в карточке заказа — **«Только вручную»** / (супер) **«Снова авто»**, **«Сброс авто-полей»**, блок ref/ошибка; аудит `adm:ff*`. Тексты покупателю — **`buyer_order_notify.py`**. Смоук: **`docs/AUTO_FULFILL_SMOKE.md`**. **Идемпотентность:** `fulfillment_applied_at` + рефка без двойного `completed`. **Просрочка оплаты:** sweep → **`expired`** |
| **Операторы** | Разделение прав | **`SUPER_ADMIN_IDS`** (подмножество `ADMIN_IDS`): операторы без финансовых кнопок; аудит в **`admin_audit_log`** |

## Сверх ТЗ (кратко)

- **Partner API** (ключи, заказы, вебхуки, idempotency), **LAVA webhook**, **Crypto Pay / xRocket webhooks**, **реф. баланс**, **пополнение баланса**, **выкуп Stars**, **конкурсы партнёров**, **гейт канала**, **документы + FAQ в «Поддержка»**, **pytest**, отдельный деплой `/opt/aladdin-telegram-shop-bot`.
- **Операции после оплаты:** статусы **`refunded`** и **`payment_disputed`** (сторно/спор провайдера), только **супер-админ** в карточке заказа (`adm:refund`, `adm:disp`, `adm:dispok`); переходы в `bot/services/order_status.py`; уведомления покупателю в `buyer_order_notify.py`. Политика суммы в крипто-счёте — **`docs/CRYPTO_PAY_SPEC.md` §3**. Повторный счёт на тот же `order_id` — интервал **`PAYMENT_CHECKOUT_INVOICE_COOLDOWN_SECONDS`** (`shop.py` + `invoice_checkout_cooldown.py`). Ротация секретов — **`docs/SECRETS_AND_ROTATION_RUNBOOK.md`**. Rate limit и «зависшие paid» — **`docs/IMPLEMENTATION_PLAN_AND_TASKS.md`** и **`docs/EDGE_CASES.md`**. Полный выкат: **`docs/ML_SYSTEM_HANDOFF_FINAL.md`**.

## Заметки по эксплуатации

- LAVA: без заполненных **`LAVA_SHOP_ID`**, **`LAVA_SECRET_KEY`**, **`LAVA_HOOK_URL`** кнопки на LAVA **не** появятся — показывается текстовая заглушка по фиату.
- Юридические страницы по умолчанию — ссылки Telegraph в настройках; всё ведётся из **«Поддержка»**.
