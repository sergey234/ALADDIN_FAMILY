# ТЗ → факт (краткая сводка, актуализация)

Одностранично: что просили в исходном ТЗ и что есть в **`telegram_stars_shop_bot`** сейчас.

| Пункт ТЗ | Что просили | Что сделано |
|-----------|-------------|-------------|
| **1. Цель** | Удобный бот-магазин: **Premium** (подарки 1/3/6/12 мес.), **Stars** пакетами | Есть хаб `/menu`, каталог Stars/Premium/**подарки** (`gift_custom`), оформление заказа, профиль, поддержка, партнёрский блок |
| **2.1 Каталог Premium** | 3 / 6 / 12 мес. | **Есть 1, 3, 6, 12** мес. (`products.yaml`) — шире ТЗ |
| **2.1 Каталог Stars** | 100, 300, 500, 1000, **2000+** | **100, 300, 500, 1000, 2000, 5000** — «2000+» закрыто пакетом 5000; новые строки в YAML |
| **2.1 Расширение каталога** | Легко добавлять товары | **Да:** правка `bot/products.yaml` + перезапуск бота (цены в USD) |
| **2.2 Цены** | Внутри **USD**, пользователю **RUB** по курсу | **Да:** `price_usd` → `USD_RUB_RATE` → ₽ в расчётах и текстах |
| **2.2 Опт Stars 5% от 500+** | Автоскидка от 500 ⭐ в позиции | **Да:** порог и % из `.env` (`STARS_WHOLESALE_THRESHOLD`, по умолчанию **500** и **5%**) |
| **2.2 Рефералка** | Скидка новым | **Да:** скидка покупателю до первого **выданного** (`completed`) заказа; % из `.env` (дефолт 7%) |
| **2.3 Фиат** | RUB / UAH / BYN через **YooKassa / Lava / Robokassa** | **LAVA:** счёт + кнопка URL при `LAVA_*` + `LAVA_HOOK_URL`. **YooKassa/Robokassa:** нет отдельных модулей; есть **универсальный** `POST /v1/payments/provider-webhook` + ручная отметка «Оплачен» в админке |
| **2.3 Подсказки UAH/BYN** | Фиат в разных валютах | **Не отдельные шлюзы:** ориентиры в тексте через `DISPLAY_USD_UAH_RATE` / `DISPLAY_USD_BYN_RATE` + ₽ основной расчёт |
| **2.3 Крипта** | USDT TRC20, TON | **Да:** реквизиты из `.env`, memo `ORDER{id}`; админ сверяет вручную |
| **2.4 Выдача** | Критичный процесс | **Полуавтомат:** заказ `pending_payment` → (LAVA/webhook или вручную) **`paid`** → админ **«В работе»** → **«Выдан»**; уведомления админам; без прямого API Fragment в коде |

## Сверх ТЗ (кратко)

- **Partner API** (ключи, заказы, вебхуки, idempotency), **LAVA webhook**, **реф. баланс**, **пополнение баланса**, **выкуп Stars**, **конкурсы партнёров**, **гейт канала**, **документы + FAQ в «Поддержка»**, **pytest**, отдельный деплой `/opt/aladdin-telegram-shop-bot`.

## Заметки по эксплуатации

- LAVA: без заполненных **`LAVA_SHOP_ID`**, **`LAVA_SECRET_KEY`**, **`LAVA_HOOK_URL`** кнопки на LAVA **не** появятся — показывается текстовая заглушка по фиату.
- Юридические страницы по умолчанию — ссылки Telegraph в настройках; всё ведётся из **«Поддержка»**.
