# Хаб инструкций (vpn-38) — чертёг

**Полный текст** публикуется как markdown с VPN API: **`GET /v1/legal/vpn-instructions`** (файл в репозитории: `aladdin_shop_vpn_api/legal_docs/vpn-instructions.md`).

В боте задайте **`VPN_INSTRUCTIONS_URL`** на тот же URL, что и публичный хост, например:

`https://aladdin-ai.ru/v1/legal/vpn-instructions`

(подставьте свой домен, если отличается).

## Оглавление (якоря в markdown)

| Раздел | Содержание |
|--------|------------|
| Перед началом | Оплата, `.conf`, `/sub/`, fallback при UDP |
| iOS / iPadOS | WireGuard, OpenVPN запас |
| Android | WireGuard, OpenVPN |
| Windows / macOS / Linux | Клиенты |
| Android TV | Установка на ТВ |
| REALITY / VLESS | Подписка без ложных обещаний |
| Белые списки | Оговорка + поддержка |
| Проблемы | Чеклист |
