# 🔍 АНАЛИЗ ПРОБЛЕМЫ: НАГРАДЫ В РОДИТЕЛЬСКОМ ПРОФИЛЕ

## ❌ ПРОБЛЕМА

Пользователь сообщает:
- В родительском профиле награды показаны (1 час экранного времени, 30 минут перед сном, заказ пиццы, поход в кино, подарок)
- Они **закрашены** (видимо disabled/неактивны)
- **Не кликабельны**
- Непонятно где настройки управления наградами

## 🔍 ГДЕ МОГУТ БЫТЬ НАГРАДЫ

### 1. RewardsModalView (для родителей)
- Секция "🏪 Управление магазином наград"
- Кнопка "⚙️ Настроить" → открывает `ShopManagementModal`
- Там показывается список наград для **редактирования**, не для покупки

### 2. ShopManagementModal
- Показывает список наград для **редактирования**
- Toggle для включения/выключения
- Поле для изменения цены
- Кнопка редактирования (карандаш)
- **НО:** Награды здесь для управления, не для клика/покупки

### 3. ChildRewardsScreen (для детей)
- Показывает награды как **кликабельные кнопки** для покупки
- Это правильно - дети покупают, родители управляют

---

## 💡 ЧТО ДОЛЖНО БЫТЬ

### Для родителей:
1. **Список наград для просмотра/управления** (в `ShopManagementModal`)
2. **Возможность редактировать** награды (иконка, название, описание, цена)
3. **Включить/выключить** награды (Toggle)
4. **Добавить новые** награды

### Для детей:
1. **Список наград для покупки** (кликабельные кнопки)
2. **Возможность купить** награды

---

## 🎯 РЕШЕНИЕ

### Проблема 1: Награды не кликабельны в ShopManagementModal
**Это ПРАВИЛЬНО!** В `ShopManagementModal` награды должны быть для **редактирования**, не для покупки.
- Родители НЕ должны покупать награды
- Родители должны только **настраивать** список наград

### Проблема 2: Где настройки?
**Настройки должны быть в `RewardsModalView`:**
1. Открыть `RewardsModalView` (кнопка "Вознаграждение ребёнка" в FamilyScreen)
2. Найти секцию "🏪 Управление магазином наград"
3. Нажать кнопку "⚙️ Настроить"
4. Откроется `ShopManagementModal` с полным управлением

### Проблема 3: Награды закрашены
Возможные причины:
1. Награды disabled в UI (возможно Toggle выключен)
2. Награды показываются только для просмотра, не для действия
3. Стиль отображения делает их похожими на disabled
