# ✅ ИСПРАВЛЕНИЕ БЕСКОНЕЧНОЙ ЗАГРУЗКИ

## 🔴 ПРОБЛЕМА

**Симптомы:**
- Детали по угрозам показывают бесконечную загрузку (крутится круг)
- Все значения = 0 (угрозы, уровень защиты, компоненты)
- Нет надписей, только загрузка

**Причина:**
- В `threatBreakdown` проверяется только `threatCategories.isEmpty`
- Не проверяется `isLoading`
- Если данные загрузились, но `threatCategories` пустой (нормально для нового пользователя), все равно показывается ProgressView

---

## ✅ ИСПРАВЛЕНИЯ

### **1. Исправлена логика отображения угроз**

**Было:**
```swift
if viewModel.threatCategories.isEmpty {
    ProgressView()  // Показывается всегда, даже после загрузки!
}
```

**Стало:**
```swift
if viewModel.isLoading {
    ProgressView()  // Только во время загрузки
} else if viewModel.threatCategories.isEmpty {
    Text("Нет данных об угрозах")  // После загрузки показываем сообщение
} else {
    // Показываем список угроз
}
```

### **2. Добавлена гарантия установки isLoading = false**

- Убедились, что `isLoading = false` устанавливается в любом случае
- Добавлено логирование для отладки
