## 📋 ИНСТРУКЦИИ ДЛЯ XCODE

### **ШАГ 1: Добавить файл в проект**

1. Откройте проект в Xcode
2. Перейдите в `Core/Analytics/` в Project Navigator
3. Убедитесь, что файл `ComponentAnalyticsModels.swift` виден в проекте
4. Если файл НЕ виден:
   - Правый клик на папку `Core/Analytics/`
   - Выберите "Add Files to ALADDIN..."
   - Перейдите в `Core/Analytics/`
   - Выберите `ComponentAnalyticsModels.swift`
   - **ВАЖНО:** Убедитесь, что:
     - ✅ "Copy items if needed" **НЕ отмечен** (файл уже на месте)
     - ✅ "Add to targets: ALADDIN" **отмечен**
   - Нажмите "Add"

### **ШАГ 2: Проверить компиляцию**

1. Нажмите `Cmd + B` для сборки проекта
2. Если есть ошибки — проверьте, что файл добавлен в target
