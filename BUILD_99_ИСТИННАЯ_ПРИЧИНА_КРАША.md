## 🔍 ИСТИННАЯ ПРИЧИНА КРАША

### 🔴 ПРОБЛЕМА: `displayFormatter.string(from:)` вызывается в async функции, но может вызываться рекурсивно

**Анализ кода:**
```swift
// Screens/01_MainScreen.swift:991
let formattedText = Self.displayFormatter.string(from: date)
await MainActor.run {
    cachedExpirationText = formattedText
}
```

**Проблема:**
1. `displayFormatter.string(from:)` вызывается в async функции `updateExpirationTextCache()`
2. Эта функция вызывается из `.task {}` в `MainScreen`
3. Если `.task {}` вызывается многократно (что может происходить при определенных условиях)
4. Или если `displayFormatter.string(from:)` сам по себе вызывает рекурсию через ICU
5. Это может вызвать бесконечную рекурсию
