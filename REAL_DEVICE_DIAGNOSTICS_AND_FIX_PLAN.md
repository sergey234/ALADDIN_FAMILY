### Проблема 1: Ошибки скрываются (Вероятность: 90%)

**Найдено в коде:**

#### MainViewModel.swift:
```swift
// При ошибке показываются демо данные вместо ошибки

    // Показываем демо данные вместо API данных
```

- Ошибки скрываются

**Решение:**
- Добавить явную индикацию, что используются демо данные
- Логировать все ошибки API
- Показывать статус подключения

---

#### DevicesScreen.swift:
```swift
case .failure(let error):
```

## 📝 ОТВЕТЫ НА ВОПРОСЫ

### 1. Что такое "API Gateway роутинг"?

**Ответ:**
API Gateway роутинг - это механизм, который направляет запросы с разных путей к одной функции.

**Пример:**
```
/api/user/profile → get_user_profile()
/api/auth/profile → get_user_profile()  (тот же обработчик)
```

**Как проверить:**
- Посмотреть код API Gateway на сервере
- Убедиться, что оба пути обрабатываются

---

### 2. Что документировать?

**Ответ:**
Документировать все поддерживаемые пути для каждого эндпоинта.

**Пример:**
```markdown
## GET /api/auth/profile
**Алиасы:**
- `/api/user/profile` (для обратной совместимости)
- `/api/v1/auth/profile` (версионирование)

**Описание:** Получение профиля пользователя
```
