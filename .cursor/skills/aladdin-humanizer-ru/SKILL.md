# Aladdin Humanizer RU

Идея Asmadey `humanizer-ru` + `slop-monster`: живой русский для родителей.

## Когда

- Письмо / Notes для App Review  
- Онбординг OB_* тексты  
- Сообщения бота / алерты parental  

## Правила

1. Короткие предложения.  
2. Без «в современном мире», «комплексное решение», «обеспечивает».  
3. Конкретика: что делает родитель / ребёнок.  
4. Тон доверия, не маркетинг-слайд.  
5. Не менять факты и юридические обязательства.

## Выход

Дать **до/после** (2–3 абзаца) или правку строк в коде/доке.
