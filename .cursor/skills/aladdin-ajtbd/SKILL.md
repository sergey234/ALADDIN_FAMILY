# Aladdin AJTBD (parent job)

Идея Asmadey `AJTBD`: родитель «нанимает» ALADDIN на работу.

## Шаблон (заполнить)

1. **Работа:** когда ___ родитель хочет ___, чтобы ___.  
2. **Триггер:** что случилось (ссылка, голос, ночь, тревога).  
3. **Барьеры:** страх, время, непонятный UI, ложные срабатывания.  
4. **Критерии найма:** что должно произойти за <2 минут.  
5. **Acceptance:** 3 проверяемых пункта (см. также `aladdin-gates`).

## Пилот

Одна работа: «проверить ссылку / голосовой запрос» — не расползаться на весь продукт.
