# Aladdin Skill Creator

Идея Asmadey `skill-creator` — шаблон для своих skills.

## Шаблон SKILL.md

```markdown
---
name: aladdin-<short>
description: <one line, when to use>
---

## Links to SSOT
```

## Правила

- Thin: идеи Asmadey ок, слепой dump репо — нет.  
- Сначала песочница + `aladdin-skillspector` + GO.  
- Не конфликтовать с always-on ALADDIN rules.
