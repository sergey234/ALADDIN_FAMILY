# 📋 ШАБЛОН КОДА ДЛЯ ЗАМЕНЫ

## 🔄 ТОЧНЫЙ КОД ДЛЯ ПОИСКА И ЗАМЕНЫ

### ❌ КОД, КОТОРЫЙ НУЖНО НАЙТИ (удалить):

```swift
onBack: {
    // ✅ УМНАЯ ПРОВЕРКА: Используем NavigationManager если есть стек, иначе возврат на главный
    if navigationManager.canGoBack {
        navigationManager.goBack()
    } else {
        navigationManager.navigateToRoot(.main)
    }
}
```

### ✅ КОД, НА КОТОРЫЙ НУЖНО ЗАМЕНИТЬ (вставить):

```swift
onBack: {
    // ✅ ГИБРИДНЫЙ ПОДХОД: dismiss() как основной механизм + синхронизация NavigationManager
    // dismiss() - использует встроенный механизм SwiftUI, работает надёжно
    dismiss()
    
    // Дополнительно синхронизируем NavigationManager для корректной работы стека
    DispatchQueue.main.async {
        if navigationManager.canGoBack {
            navigationManager.goBack()
        }
    }
}
```

## ✅ НОВЫЙ КОД (для всех вариантов)

### Стандартный вариант:
```swift
onBack: {
    dismiss()
    DispatchQueue.main.async {
        if navigationManager.canGoBack {
            navigationManager.goBack()
        }
    }
}
```

### С комментариями (рекомендуется):

## 📋 ПРОВЕРКА ПЕРЕМЕННЫХ

### Убедиться, что в файле есть:

```swift
@Environment(\.dismiss) private var dismiss
@EnvironmentObject private var navigationManager: NavigationManager
```

### Если нет - добавить в начале struct/class:

```swift
struct MyScreen: View {
    @Environment(\.dismiss) private var dismiss  // ← Добавить если нет
    @EnvironmentObject private var navigationManager: NavigationManager  // ← Добавить если нет
    
    // остальной код...
}
```
