### 3. Что такое "API Gateway роутинг"?

**Ответ:**
API Gateway роутинг - это механизм на сервере, который направляет запросы с разных путей к одной функции.

**Пример:**
```python
# На сервере (API Gateway):
@app.get("/api/user/profile")   # Старый путь
@app.get("/api/auth/profile")   # Новый путь
async def get_user_profile():
    # Оба пути ведут к одной функции
    return await sfm_adapter.execute_function("get_user_profile", {})
```

**Как проверить:**
- Посмотреть код API Gateway на сервере
- Убедиться, что оба пути обрабатываются

**Для мобильного приложения:**
- Это не критично, если оба пути работают
- Можно оставить как есть
