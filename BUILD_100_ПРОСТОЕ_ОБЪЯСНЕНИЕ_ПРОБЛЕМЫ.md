## 🎯 МОЖЕТ ЛИ КРАШ ВЛИЯТЬ НА ВСЮ СТРАНИЦУ?

### ✅ ДА, может!

**Как это работает:**

1. **Пользователь нажимает на функцию:**
   - Например, открывает экран настроек
   - Или обновляет данные на главном экране
   - Или делает что-то, что требует форматирования даты

2. **Приложение пытается отформатировать дату:**
   - Вызывается `updateExpirationTextCache()`
   - Эта функция должна показать дату окончания подписки

3. **Начинается рекурсия:**
   - Функция вызывает сама себя бесконечно
   - Стек памяти переполняется
   - **Приложение крашится полностью**

4. **Результат:**
   - ❌ **Вся страница перестает работать**
   - ❌ **Приложение закрывается**
   - ❌ **Пользователь теряет все несохраненные данные**

## 🔍 ЧТО ТАКОЕ РЕКУРСИЯ? (ПРОСТЫМ ЯЗЫКОМ)

### Пример рекурсии:

**Представьте:**
- Вы хотите узнать время
- Но часы показывают время, только если вы знаете время
- Вы спрашиваете часы: "Какое время?"
- Часы отвечают: "Чтобы узнать время, нужно знать время"
- Вы снова спрашиваете: "Какое время?"
- Часы снова отвечают: "Чтобы узнать время, нужно знать время"
- И так **бесконечно**...

**Это и есть рекурсия!**

## 🐛 ЧТО ПРОИСХОДИТ В НАШЕМ КОДЕ?

### Проблема:

**Старый код (который вызывает рекурсию):**
```swift
// Когда нужно отформатировать дату:
let formattedText = Self.displayFormatter.string(from: date)

// Внутри displayFormatter:
// 1. Нужно узнать календарь → Calendar.current
// 2. Calendar.current читает из UserDefaults
// 3. UserDefaults может вызвать обновление View
// 4. View обновляется → снова вызывается форматирование
// 5. Снова Calendar.current → снова UserDefaults
// 6. И так бесконечно... → РЕКУРСИЯ!
```

**Почему это происходит:**
- `Calendar.current` читает настройки из `UserDefaults`
- `UserDefaults` может вызвать обновление View
- View обновляется → снова форматирование
- **Бесконечный цикл!**

## ✅ ЧТО МЫ СДЕЛАЛИ ПРАВИЛЬНО?

### Мы создали `DateFormatterService`:

**Новый код (который НЕ вызывает рекурсию):**
```swift
// Используем статический календарь (не Calendar.current):
private static let calendar: Calendar = {
    var cal = Calendar(identifier: .gregorian)
    cal.locale = Locale(identifier: "ru_RU")
    return cal  // Создан один раз, не читает из UserDefaults
}()

// Используем статический форматтер:
private static let displayFormatter: DateFormatter = {
    let formatter = DateFormatter()
    formatter.calendar = Self.calendar  // Используем статический календарь
    return formatter
}()
```

**Почему это работает:**
- Календарь создан **один раз** при запуске
- Он **не читает** из `UserDefaults` каждый раз
- Нет бесконечного цикла → **нет рекурсии!**

## ✅ ЧТО НУЖНО ИСПРАВИТЬ?

### 1. Заменить старый код на DateFormatterService

**БЫЛО (проблемный код):**
```swift
// Строки 1014-1029 в MainScreen.swift
var parsedDate = Self.isoFormatter.date(from: isoString)
if parsedDate == nil {
    parsedDate = Self.isoFormatterFallback.date(from: isoString)
}
guard let date = parsedDate else { ... }
let formattedText = await MainActor.run {
    Self.displayFormatter.string(from: date)  // ❌ Старый код

```

**СТАЛО (правильный код):**
```swift

    DateFormatterService.shared.formatExpirationDate(from: isoString)  // ✅ Новый код
}
```

**Зачем:**
- `DateFormatterService` использует статический календарь
- Не вызывает рекурсию
- Безопасно работает из background thread
