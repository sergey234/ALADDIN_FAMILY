## 📤 Как загрузить в App Store Connect

### Вариант 1: Через веб-интерфейс (Рекомендуется)

1. Откройте [App Store Connect](https://appstoreconnect.apple.com/)
2. Перейдите в раздел **"Мои приложения"**
3. Выберите приложение **ALADDIN**
4. Перейдите на вкладку **"App Store"**
5. Выберите версию приложения
6. Прокрутите до раздела **"Скриншоты"**
7. Нажмите **"Добавить скриншот"** для iPhone 6.5"
8. Загрузите файл: `iPhone_6.5_main_screenshot.png`
9. Нажмите **"Сохранить"**

### Вариант 2: Через Xcode

1. Откройте проект в Xcode
2. Выберите **Product > Archive**
3. После создания архива нажмите **"Distribute App"**
4. Выберите **"App Store Connect"**
5. Следуйте инструкциям
6. В разделе скриншотов добавьте нужные изображения
