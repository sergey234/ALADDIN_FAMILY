# ✅ РЕШЕНИЕ: Секция "Управление магазином наград" не видна

## 🔍 ПРОБЛЕМА

Пользователь не видит секцию "🏪 Управление магазином наград" в RewardsModalView:
- Открывает карточку "Вознаграждение ребёнка" в FamilyScreen
- Прокручивает вниз
- Видит только "Доступные награды" и список
- **НЕТ секции с иконкой 🏪**

---

## ❌ ПРИЧИНА

**Карточка "Вознаграждение ребёнка" в FamilyScreen вела на `ChildRewardsScreen` вместо `RewardsModalView`!**

```swift
// ❌ БЫЛО (неправильно):
Button(action: {
    navigationManager.navigateTo(.childRewards)  // Открывает ChildRewardsScreen
})
```

---

## ✅ ИСПРАВЛЕНИЕ

### 1. Изменена навигация в FamilyScreen
- **Для родителей:** Открывается `RewardsModalView` (модальное окно)
- **Для детей:** Открывается `ChildRewardsScreen` (экран)

```swift
// ✅ СТАЛО (правильно):
Button(action: {
    let role = UserDefaults.standard.string(forKey: "current_user_role") ?? ""
    if role == "Parent" {
        showRewardsModal = true  // RewardsModalView для родителей
    } else {
        navigationManager.navigateTo(.childRewards)  // ChildRewardsScreen для детей
    }
})
```

### 2. Добавлен sheet для RewardsModalView в FamilyScreen
```swift
.sheet(isPresented: $showRewardsModal) {
    RewardsModalView(
        unicornBalance: $unicornBalanceForRewards,
        weeklyRewarded: $weeklyRewarded,
        weeklyPunished: $weeklyPunished
    )
}
```

### 3. Добавлена диагностика в RewardsModalView
- Логирование роли пользователя
- Логирование видимости секции "Управление магазином"
- Проверка загрузки наград

---

## 📍 ГДЕ НАЙТИ СЕКЦИЮ "🏪 Управление магазином наград"

### Для РОДИТЕЛЕЙ:

1. **Откройте FamilyScreen**
2. **Нажмите на карточку "Вознаграждение ребёнка"**
3. **Откроется RewardsModalView** (модальное окно)
4. **Прокрутите вниз** до секции:
   ```
   🏪 Управление магазином наград
   Настройте награды, которые видят дети
   
   [⚙️ Настроить]  ← ЗОЛОТАЯ КНОПКА
   ```
5. **Нажмите "⚙️ Настроить"** → откроется ShopManagementModal

- ✅ Родители видят секцию "🏪 Управление магазином наград"
- ✅ Есть кнопка "⚙️ Настроить"
- ✅ При нажатии открывается ShopManagementModal
- ✅ Дети по-прежнему видят ChildRewardsScreen (магазин наград)

---

## 🔍 ДИАГНОСТИКА

Если секция всё ещё не видна, проверьте логи:
```
🔍 DEBUG RewardsModalView.onAppear:
   📋 Роль пользователя: 'Parent' или 'Child'
   👨‍👩‍👧 isUserParent = true/false
   🏪 shopRewards.count = количество наград
   ✅ Секция 'Управление магазином' будет ВИДНА/СКРЫТА
```

**Если `isUserParent = false`:**
- Проверьте, что роль установлена: `UserDefaults.standard.set("Parent", forKey: "current_user_role")`

**Если `shopRewards.count = 0`:**
- Награды загружаются в `.onAppear` - подождите секунду
