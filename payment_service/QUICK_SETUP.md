# ⚡ Быстрая настройка Manual Transfer

## Проблема
На странице оплаты видите:
- "⚠️ Номер карты не настроен"
- "Получатель: не указан"

## Решение (2 минуты)

### Шаг 1: Установите python-dotenv
```bash
cd payment_service
pip3 install python-dotenv
```

### Шаг 2: Создайте .env файл
```bash
cp .env.example .env
```

### Шаг 3: Отредактируйте .env
Откройте `.env` и замените:
```env
PAYMENT_CARD_NUMBER=2202 2083 0881 3410
# Оставьте пустым, чтобы не показывать ФИО
PAYMENT_CARD_HOLDER_NAME=
```
на ваши реальные данные (при желании используйте своё значение карты).

### Шаг 4: Перезапустите backend
```bash
# Остановите текущий процесс (Ctrl+C)
# Запустите заново:
python3 -m uvicorn main:app --reload --port 8000 --host 0.0.0.0
```

### Шаг 5: Проверьте
Создайте новый платёж с методом "Оплата на карту через СБП" - должны отображаться номер карты и имя получателя.

**Готово!** 🎉
