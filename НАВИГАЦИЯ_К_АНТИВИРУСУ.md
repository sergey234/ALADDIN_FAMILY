# 🗺️ ПОДРОБНАЯ НАВИГАЦИЯ К АНТИВИРУСУ В ПРИЛОЖЕНИИ ALADDIN

## 📍 ПУТЬ 1: ЭКРАН "ЗАЩИТА ALADDIN" (NetworkProtectionScreen)

### 🎯 Где находится статистика антивируса:

**Шаг 1:** Откройте приложение ALADDIN
- Приложение запускается на главном экране (MainScreen)

**Шаг 2:** Найдите карточку антивируса на главном экране
- На главном экране есть сетка карточек (2x2)
- **Карточка антивируса** находится в **верхнем левом углу**
- Иконка: 🛡️
- Статус: 🟢 (зеленый) если активен, 🔴 (красный) если отключен
- Название: "Антивирус Аладин"
- Описание: "Защита устройств"

**Шаг 3:** Нажмите на карточку антивируса
- Откроется экран **"Защита ALADDIN"** (NetworkProtectionScreen)

**Шаг 4:** Найдите карточку антивируса на экране "Защита ALADDIN"
- Это **первая карточка сверху** на экране
- Заголовок: "🛡️ Антивирус"
- Переключатель включения/выключения справа вверху

### 📊 Что показывает статистика в карточке антивируса:

1. **🔍 Файлов проверено** - количество проверенных файлов
   - Отображается через `formatScanCount()`
   - Показывает "1" если было сканирование, "0" если нет

2. **✅ Угроз найдено** - количество обнаруженных угроз
   - Отображается через `antivirusManager.threatsDetected.count`
   - Показывает реальное количество найденных угроз

3. **🔄 Последняя проверка** - время последнего сканирования
   - Отображается через `formatLastScan()`
   - Формат: "только что", "X мин назад", "X ч назад", "Никогда"

4. **⚡ Уровень защиты** - процент защиты
   - Показывает "100%" если антивирус включен
   - Показывает "0%" если антивирус отключен

5. **Кнопка "Сканировать"** - запускает быстрое сканирование
   - Синяя кнопка внизу карточки
   - При нажатии запускается `performQuickScan()`
   - Логи отображаются в окне логов (VisualLogger)

## 📍 ПУТЬ 2: НАСТРОЙКИ АНТИВИРУСА (MalwareDetectionSettingsScreen)

### ⚠️ ВАЖНО: В данный момент нет прямого пути к настройкам антивируса из экрана настроек!

**Текущая ситуация:**
- Экран `MalwareDetectionSettingsScreen` существует
- Но нет навигации к нему из `SettingsScreen`
- Нужно добавить ссылку в раздел "Безопасность" на экране настроек

### 🎯 Где ДОЛЖНЫ быть настройки антивируса:

**Планируемый путь:**
1. Откройте приложение ALADDIN
2. Перейдите в **Настройки** (SettingsScreen)
   - Можно через карточку "Настройки" на главном экране
   - Или через нижнее меню (если есть)
3. Найдите раздел **"Безопасность"** (Security Section)
4. В разделе "Безопасность" должна быть ссылка:
   - **"Обнаружение вредоносного ПО"** или **"Настройки антивируса"**
   - При нажатии откроется `MalwareDetectionSettingsScreen`

### 📋 Что показывает экран настроек антивируса:

#### Основные настройки:
1. **Сканирование в реальном времени** - включить/выключить
2. **Сканировать загрузки** - автоматическое сканирование загруженных файлов
3. **Сканировать установленные приложения** - проверка установленных приложений
4. **Карантин угроз** - автоматическое помещение угроз в карантин
5. **Автоматически удалять угрозы** - автоматическое удаление обнаруженных угроз

#### Частота сканирования:
- **Каждый час** (hourly)
- **Ежедневно** (daily) - по умолчанию
- **Еженедельно** (weekly)

#### Кнопка быстрого сканирования:
- **"Быстрое сканирование"** - запускает быстрое сканирование системы

## ⚠️ ОТСУТСТВУЮЩИЕ ФУНКЦИИ:

### 1. История сканирований
- **Статус:** ❌ НЕ ОТОБРАЖАЕТСЯ В UI
- **Данные:** Есть в `MalwareSettingsViewModel.scanHistory`
- **Где должна быть:** В настройках антивируса или на экране "Защита ALADDIN"
- **Что показывает:** Список всех выполненных сканирований с датами и результатами

### 2. Статистика карантина
- **Статус:** ❌ НЕ ОТОБРАЖАЕТСЯ В UI
- **Данные:** Есть в `MalwareSettingsViewModel.quarantineStats`
- **Где должна быть:** В настройках антивируса или отдельном экране карантина
- **Что показывает:**
  - Общее количество файлов в карантине
  - Активные файлы в карантине
  - Восстановленные файлы
  - Удаленные файлы
  - Размер карантина
  - Статистика по типам угроз
  - Статистика по уровню опасности
