### **Идеальная структура файла:**


### **Метрики качества:**

- **Файл должен выполнять одну задачу** (Single Responsibility Principle)
- **Легко найти нужный код** (не более 30 секунд поиска)
- **Быстрая компиляция** (<5 секунд для изменений)
- **Низкая связанность** (можно изменить без изменения других файлов)
