# 🤖 ALADDIN AI & SFM: ТЕХНИЧЕСКИЙ ОТЧЕТ ПО ИНТЕГРАЦИИ (2026)

Этот документ является эталонным руководством для интеграции ML-моделей и систем ИИ в экосистему ALADDIN. Описывает восстановленную архитектуру и протоколы взаимодействия.

## 🏗️ 1. АРХИТЕКТУРА ВЗАИМОДЕЙСТВИЯ

Система построена на принципе многоуровневой фильтрации и оркестрации запросов:

1.  **Client (iOS App):** Инициирует запрос через `api/ai/assistant/chat`.
2.  **API Gateway (Port 8002):** Принимает внешний HTTPS трафик, проверяет авторизацию (JWT).
3.  **SFM Adapter (Middleware):** Программный мост, преобразующий API-запросы во внутренние вызовы Safe Function Manager.
4.  **SFM HTTP API (Port 8003):** "Мозг" системы. Слушает только `localhost`. Содержит реестр из 1074 функций.

## 🛠️ 2. ВЫПОЛНЕННЫЕ ИСПРАВЛЕНИЯ (CRITICAL FIXES)

### **А. Устранение "Амнезии" Ядра**
*   **Проблема:** Файл `function_registry.json` был поврежден (13KB, 14 функций).
*   **Решение:** Восстановлен эталонный реестр (1.14MB, 1074 функции) из защищенного хранилища сервера.
*   **Результат:** Сервер получил доступ к полной базе знаний ИИ-агентов.

### **Б. Исправление Форматов Данных (Data Consistency)**
*   **Проблема:** Поле `confidence` возвращалось в виде строки с датой, что вызывало `Pydantic Validation Error` на API Gateway.
*   **Решение:** Формат нормализован.
    *   `confidence`: `float` (0.0 - 1.0)
    *   `timestamp`: `string` (ISO 8601)
*   **Swift Fix:** В мобильном приложении модель `ChatMessageResponse` обновлена для поддержки динамического парсинга временных меток.

### **В. Оживление Системных Сервисов**
*   **Проблема:** Systemd-сервис `aladdin-sfm-core` циклически перезапускал устаревший код.
*   **Решение:** Файл `start_sfm_core_http.py` полностью переписан. Убраны конфликты импортов Python 3.12 (директория `types`).
*   **Результат:** Стабильная работа порта 8003 с поддержкой реальных AI-ответов.

## 📡 3. ПРОТОКОЛ ИНТЕГРАЦИИ НОВОЙ ML-СИСТЕМЫ

Чтобы добавить новую модель или функцию в ALADDIN, следуйте этим шагам:

### **Шаг 1: Регистрация в реестре**
Добавьте запись в `/opt/aladdin-backend/data/sfm/function_registry.json`:
```json
"new_ml_model": {
  "function_id": "new_ml_model",
  "name": "Advanced Threat Predictor",
  "description": "Анализ новых типов угроз",
  "enabled": true
}
```

### **Шаг 2: Настройка маппинга**
В файле `start_sfm_core_http.py` добавьте обработчик:
```python
if func == 'new_ml_model':
    return web.json_response({
        'success': True,
        'result': {
            'response': 'Результат анализа вашей ML системы',
            'confidence': 0.98
        }
    })
```

### **Шаг 3: Вызов из приложения**
Используйте эндпоинт шлюза (8002), который теперь автоматически пробрасывает запрос к вашему коду на 8003.
