# 📱 ПОШАГОВАЯ ИНСТРУКЦИЯ: Просмотр логов NetworkManager в Xcode Debug Console

## 🎯 Цель
Просмотреть все логи API запросов и ошибок из `NetworkManager` на реальном устройстве через Xcode Debug Console.

---

## ✅ Шаг 1: Подготовка устройства

### 1.1. Подключите iPhone/iPad к Mac
- Используйте USB кабель
- Разблокируйте устройство
- Если появится запрос "Доверять этому компьютеру?" → нажмите **"Доверять"**
- Введите пароль устройства, если потребуется

### 1.2. Проверьте подключение
- В Xcode должно появиться устройство в списке устройств (см. Шаг 2.2)

---

## ✅ Шаг 2: Открытие проекта в Xcode

### 2.1. Откройте Xcode
- Запустите Xcode на Mac
- Если проект не открыт: **File → Open** → выберите папку `ALADDIN_iOS`
- Или откройте файл `ALADDIN.xcodeproj`

### 2.2. Выберите устройство
- В верхней панели Xcode найдите выпадающий список устройств (слева от кнопки "Play")
- Нажмите на него
- Выберите ваше подключенное устройство (например, "iPhone 13 Pro" или имя вашего устройства)
- **Важно:** Выберите реальное устройство, а не симулятор!

---

## ✅ Шаг 3: Настройка схемы (Scheme)

### 3.1. Выберите схему
- Рядом с выбором устройства есть выпадающий список схем
- Убедитесь, что выбрана схема **"ALADDIN"** (или ваша основная схема)

### 3.2. Проверьте конфигурацию
- Нажмите на схему → **Edit Scheme...**
- Убедитесь, что в разделе **Run** выбрана конфигурация **Debug** (не Release)
- Закройте окно настроек

---

## ✅ Шаг 4: Запуск приложения

### 4.1. Запустите приложение
- Нажмите кнопку **▶️ (Play)** в верхней панели Xcode
- Или нажмите **Cmd + R** (⌘ + R)
- Xcode начнет компиляцию проекта

### 4.2. Дождитесь установки
- Xcode скомпилирует проект и установит приложение на устройство
- На устройстве появится иконка приложения ALADDIN
- Приложение автоматически запустится

### 4.3. Разрешите установку (если потребуется)
- На устройстве может появиться запрос "Доверять разработчику?"
- Перейдите: **Настройки → Основные → Управление устройством**
- Найдите ваш Apple ID → нажмите **"Доверять"**

---

## ✅ Шаг 5: Открытие Debug Console

### 5.1. Найдите панель Debug Console
- В нижней части окна Xcode должна быть панель с консолью
- Если панель не видна:
  - Нажмите **View → Debug Area → Show Debug Area**
  - Или нажмите **Shift + Cmd + Y** (⇧ + ⌘ + Y)
  - Или нажмите кнопку в правом нижнем углу Xcode (иконка с консолью)

### 5.2. Переключитесь на вкладку Console
- В нижней панели должны быть вкладки: **Variables**, **Console**, **Breakpoints**
- Нажмите на вкладку **Console**
- Вы увидите логи приложения

---

## ✅ Шаг 6: Применение фильтра

### 6.1. Найдите поле поиска
- В правом верхнем углу панели Console есть поле поиска (лупа 🔍)
- Или нажмите **Cmd + F** (⌘ + F) для поиска

### 6.2. Введите фильтр
- В поле поиска введите:
  ```
  subsystem:com.aladdin.network
  ```
- Нажмите **Enter**

### 6.3. Проверьте результат
- Консоль должна отфильтровать логи
- Вы увидите только логи из `NetworkManager`:
  - `🌐 API Request: GET https://aladdin-ai.ru/api/...`
  - `❌ Network Error: ...`
  - `⚠️ HTTP Error: 404 - ...`
  - `✅ Token refreshed: ...`

---

## ✅ Шаг 7: Использование приложения

### 7.1. Взаимодействуйте с приложением
- Откройте экраны, которые делают API запросы
- Например:
  - Главный экран (загрузка дашборда)
  - Настройки (загрузка профиля)
  - Любой экран с данными из API

### 7.2. Наблюдайте за логами
- В Debug Console будут появляться новые логи в реальном времени
- Каждый API запрос будет логироваться
- Ошибки будут отображаться с префиксом `❌`

---

## 🎯 Полезные команды и настройки

### Очистка консоли
- **Cmd + K** (⌘ + K) — очистить консоль
- Или кнопка "Clear" в правом верхнем углу консоли

### Поиск в логах
- **Cmd + F** (⌘ + F) — открыть поиск
- **Cmd + G** (⌘ + G) — следующее совпадение
- **Shift + Cmd + G** (⇧ + ⌘ + G) — предыдущее совпадение

### Копирование логов
- Выделите нужные строки
- **Cmd + C** (⌘ + C) — скопировать
- Вставьте в текстовый файл для анализа

### Экспорт логов
- Выделите логи
- Правый клик → **Copy**
- Или **Cmd + C**
- Вставьте в файл

## ⚠️ Возможные проблемы и решения

### Проблема 1: Устройство не видно в Xcode
**Решение:**
- Проверьте USB кабель
- Разблокируйте устройство
- Перезапустите Xcode
- Проверьте, что устройство доверяет компьютеру (Настройки → Основные → Управление устройством)

### Проблема 2: Приложение не запускается
**Решение:**
- Проверьте, что выбрана правильная схема (ALADDIN)
- Проверьте, что устройство разблокировано
- Проверьте сертификаты разработчика (если требуется)

### Проблема 3: Логи не появляются
**Решение:**
- Убедитесь, что приложение запущено через Xcode (не просто открыто на устройстве)
- Проверьте, что фильтр введен правильно: `subsystem:com.aladdin.network`
- Попробуйте убрать фильтр и посмотреть все логи
- Убедитесь, что приложение делает API запросы (откройте экраны с данными)

### Проблема 4: Консоль не видна
**Решение:**
- **View → Debug Area → Show Debug Area**
- Или **Shift + Cmd + Y** (⇧ + ⌘ + Y)
- Или нажмите кнопку в правом нижнем углу Xcode

### Проблема 5: Фильтр не работает
**Решение:**
- Проверьте правильность написания: `subsystem:com.aladdin.network` (без пробелов)
- Попробуйте перезапустить приложение (Cmd + R)
- Попробуйте очистить консоль (Cmd + K) и применить фильтр снова
