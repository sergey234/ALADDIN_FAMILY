## 🔍 ПРИЧИНЫ МНОЖЕСТВЕННЫХ ПЕРЕРИСОВОК

### 1. ✅ НЕ onChange наблюдатели:
- **Нет логов** `🟡 SETTINGS: onChange ...`
- **Вывод:** `onChange` наблюдатели **НЕ вызывают** перерисовки

### 2. ✅ НЕ @State переменные:
- Все `@State` переменные **одинаковые** во всех перерисовках
- **Вывод:** `@State` переменные **НЕ изменяются**

### 3. ⚠️ Возможные причины:

#### A. SwiftUI оптимизация/валидация:
- SwiftUI может перерисовывать View для валидации
- Это нормальное поведение SwiftUI
- **Влияние:** Минимальное на производительность

#### B. @StateObject менеджеры:
- `@StateObject` менеджеры могут иметь `@Published` свойства
- `@Published` свойства могут вызывать обновления даже если значения не изменились
- **Влияние:** Может вызывать лишние перерисовки

#### C. Task в initializeNotifications():
- `Task { await notificationManager.requestAuthorization() }` может вызывать обновления
- После завершения Task может быть обновление через `@Published` свойства
- **Наблюдение:** После #5 появляется `🔔 Разрешение на уведомления получено`
- **Вывод:** Task завершился и мог вызвать обновление

#### D. EnvironmentObject:
- `localizationManager` может иметь `@Published` свойства
- Изменения в `localizationManager` могут вызывать обновления
- **Влияние:** Может вызывать перерисовки
