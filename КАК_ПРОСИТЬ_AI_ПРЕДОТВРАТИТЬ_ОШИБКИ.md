- "Проверь синхронизацию словарей - убедись, что все ключи есть в обоих словарях. Покажи список ключей, которые есть только в одном словаре."

## 📋 ТОЧНЫЕ ФРАЗЫ ДЛЯ ПРОВЕРКИ

### Фраза 1: Проверка после локализации экрана
```
"После локализации [название экрана] проверь детально:
1. Извлеки все используемые ключи из файла
2. Проверь каждый ключ на наличие в .russian словаре
3. Проверь каждый ключ на наличие в .english словаре
4. Покажи список всех отсутствующих ключей
5. Если ключи отсутствуют - найди их в бэкапах и добавь в оба словаря"
```

### Фраза 2: Проверка синхронизации словарей
```
"Проверь синхронизацию словарей:
1. Подсчитай количество ключей в .russian словаре
2. Подсчитай количество ключей в .english словаре
3. Найди ключи, которые есть только в одном словаре
4. Покажи список всех несинхронизированных ключей"
```

### Фраза 3: Проверка всех экранов
```
"Проверь все экраны на отсутствующие ключи:
1. Для каждого экрана извлеки все используемые ключи
2. Проверь каждый ключ на наличие в обоих словарях
3. Составь список всех отсутствующих ключей по экранам
4. Покажи детальный отчет с указанием файла и ключа"
```

### Фраза 4: Проверка бэкапов
```
"Проверь бэкапы на наличие русских строк для всех отсутствующих ключей:
1. Найди бэкап файла для каждого экрана
2. Для каждого отсутствующего ключа найди русскую строку в бэкапе
3. Сопоставь ключи с русскими строками
4. Покажи список ключей с соответствующими русскими строками"
```

### Фраза 5: Финальная проверка
```
"Выполни финальную проверку локализации:
1. Проверь все 22 экрана на отсутствующие ключи
2. Проверь синхронизацию словарей
3. Проверь, что все ключи есть в обоих словарях
4. Покажи детальный отчет с указанием всех проблем"
```

## 🚨 КРИТИЧЕСКИЕ ФРАЗЫ ДЛЯ ИЗБЕЖАНИЯ ОШИБОК

### Фраза для предотвращения ошибки добавления:
```
"ВАЖНО: При добавлении ключей в словарь:
1. ВСЕГДА добавляй ключ в оба словаря одновременно (.russian И .english)
2. ВСЕГДА проверяй наличие ключа после добавления
3. ВСЕГДА используй бэкапы для поиска русских строк
4. НИКОГДА не добавляй ключ только в один словарь"
```

### Фраза для проверки после каждого шага:
```
"После каждого шага локализации:
1. Проверь наличие всех ключей в обоих словарях
2. Проверь синхронизацию словарей
3. Покажи список всех отсутствующих ключей
4. Не переходи к следующему шагу, пока не исправишь все проблемы"
```

### Фраза для детальной проверки:
```
"Проверь детально, не полагаясь на общую статистику:
1. Проверь каждый конкретный ключ индивидуально
2. Не используй только подсчет общего количества ключей
3. Проверь наличие каждого ключа в обоих словарях
4. Покажи список всех отсутствующих ключей с указанием файла"
```

- Нет синтаксических ошибок"
```

```
"После исправления проблемы проверь:
- Проблема действительно исправлена
- Все ключи добавлены в оба словаря
- Синхронизация словарей восстановлена
- Нет новых проблем"
