### Если логи показывают переход, но экран не меняется:

**Возможные причины:**
1. SwiftUI не обновляет switch в ALADDINApp
2. NavigationView не перерисовывается
3. `.id()` модификатор не работает

## 🎯 СЛЕДУЮЩИЕ ШАГИ

### Если переход все еще не работает:

**Вариант 1:** Вернуться к `.parentalControl` (как было раньше)
```swift
case .parent:
    navigationManager.navigateTo(.parentalControl)
```

**Вариант 2:** Использовать `navigateToRoot` вместо `navigateTo`
```swift
case .parent:
    navigationManager.navigateToRoot(.profile)
```

**Вариант 3:** Принудительное обновление через изменение ID
```swift
// В ALADDINApp уже есть:
.id(navigationManager.currentScreen.rawValue)
```
