# 🤖 ИНСТРУКЦИЯ ДЛЯ ML МОДЕЛИ: ДОБАВЛЕНИЕ РУССКИХ ПЕРЕВОДОВ

**Цель задачи:** Добавить отсутствующие русские переводы в словарь локализации

---

## 🎯 ЧТО НУЖНО СДЕЛАТЬ

ML модель должна:
1. Извлечь русские строки из бэкапов экранов
2. Сопоставить их с ключами локализации из текущих файлов
3. Добавить пары `"ключ": "русский_перевод"` в файл `LocalizationManager.swift`

---

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ

### **ШАГ 1: Подготовка**

1. **Открыть файл словаря:**
   - Путь: `Core/Localization/LocalizationManager.swift`
   - Найти секцию: `.russian: [...]` (начинается примерно со строки 101)
   - Запомнить, где заканчивается секция (перед `.english: [...]`)

2. **Создать бэкап словаря:**
   - Скопировать файл `LocalizationManager.swift`
   - Сохранить как `LocalizationManager.swift.backup`
   - (На случай ошибки можно будет откатить)

---

### **ШАГ 2: Обработка одной страницы**

#### **Пример: MainScreen**

**2.1. Открыть бэкап страницы:**
- Путь: `BACKUPS/20251105_115303/Screens/01_MainScreen.swift`
- Найти все строки в формате:
  ```swift
  Text("русский текст")
  title: "русский текст"
  subtitle: "русский текст"
  label: "русский текст"
  ```

**2.2. Открыть текущий файл:**
- Путь: `Screens/01_MainScreen.swift`
- Найти все строки в формате:
  ```swift
  localizationManager.localized("ключ")
  ```

**2.3. Сопоставить:**

Пример сопоставления:
```
БЭКАП (прямая строка):              ТЕКУЩИЙ ФАЙЛ (ключ):              РЕЗУЛЬТАТ (для словаря):
─────────────────────────────────────────────────────────────────────────────────────────
Text("AI Защита семьи")     →      localized("main_ai_protection")  →  "main_ai_protection": "AI Защита семьи"
Text("Главная")             →      localized("main_tab_home")       →  "main_tab_home": "Главная"
Text("Защита")              →      localized("main_tab_protection")  →  "main_tab_protection": "Защита"
```

**2.4. Добавить в словарь:**

Найти в `LocalizationManager.swift` секцию `.russian: [...]` и добавить:
```swift
.russian: [
    // ... существующие ключи ...
    
    // Main Screen
    "main_ai_protection": "AI Защита семьи",
    "main_tab_home": "Главная",
    "main_tab_protection": "Защита",
    // ... и так далее для всех ключей MainScreen
],
```

**Важно:**
- Добавлять в правильном месте (внутри `.russian: [...]`)
- Сохранять форматирование (отступы, запятые)
- Не дублировать существующие ключи

---

### **ШАГ 3: Проверка синтаксиса**

После добавления переводов:

1. **Проверить скобки:**
   - Убедиться, что `[` открывается и `]` закрывается
   - Убедиться, что все фигурные скобки парные

2. **Проверить запятые:**
   - После каждого значения должна быть запятая (кроме последнего)
   - После последнего ключа в секции `.russian: [...]` запятая НЕ нужна

3. **Проверить кавычки:**
   - Ключ в двойных кавычках: `"ключ"`
   - Значение в двойных кавычках: `"значение"`
   - Если в значении есть кавычка, экранировать: `"Он сказал \"привет\""`

```

        - Сохранить в список: [(строка, контекст)]
   
   1.3. Открыть текущий файл: Screens/[имя_файла].swift
   1.4. Извлечь все ключи локализации:

        Для каждого ключа:
            - Найти соответствующую русскую строку по контексту

            - Создать пару: (ключ, русский_перевод)
   
   1.6. Добавить в словарь:
        - Открыть LocalizationManager.swift
        - Найти секцию .russian: [...]
        - Добавить все пары (ключ, русский_перевод)
        - Проверить синтаксис
```
