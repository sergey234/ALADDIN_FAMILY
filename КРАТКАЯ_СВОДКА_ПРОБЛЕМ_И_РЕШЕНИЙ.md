## 🔍 ДЕТАЛЬНЫЙ АНАЛИЗ ПРИЧИН

### Причина 1: Кэш Xcode / DerivedData
**Симптомы:** Изменения в коде есть, но в приложении видна старая версия.

**Решение:**
```bash
# 1. Закрыть Xcode
# 2. Выполнить:
rm -rf ~/Library/Developer/Xcode/DerivedData/ALADDIN-*

# 3. В Xcode: Product → Clean Build Folder (Shift+Cmd+K)
# 4. Пересобрать: Product → Build (Cmd+B)
```

### Причина 2: Файлы не добавлены в Target
**Симптомы:** Файлы существуют на диске, но Xcode их не компилирует.

**Решение:**
1. Открыть файл в Xcode Project Navigator
2. File Inspector → Target Membership
3. Убедиться, что галочка стоит на "ALADDIN"

### Причина 3: Роль пользователя не устанавливается
**Симптомы:** Проверки роли всегда возвращают `false`, даже для родителей.

**Диагностика:**
```swift
// Добавить в любой View для отладки:
print("🔍 Роль: \(UserDefaults.standard.string(forKey: "current_user_role") ?? "НЕТ")")
```

**Решение:**
- Проверить, где устанавливается роль при входе/регистрации
- Убедиться, что ключ правильный: `"current_user_role"`
- Убедиться, что значение: `"Parent"` (не `"parent"`, не `"Родитель"`)

### Причина 4: SwiftUI View Builder ограничения
**Симптомы:** Кнопки не отображаются, хотя код правильный.

**Проблема:** Использование `let` внутри `VStack` не работает в SwiftUI.

**Неправильно:**
```swift
VStack {
    let operations = getRecentOperations()
    if operations.isEmpty { ... }
}
```

**Правильно:**
```swift
if getRecentOperations().isEmpty {
    // пустое состояние
} else {
    ForEach(getRecentOperations()) { ... }
}
```

### Причина 5: @AppStorage не синхронизируется
**Симптомы:** Баланс единорогов не обновляется в реальном времени.

**Проблема:** `@AppStorage` может не обновляться автоматически при изменении через `UserDefaults.standard.set()`.

**Решение:**
```swift
// После изменения в UserDefaults:
NotificationCenter.default.post(name: UserDefaults.didChangeNotification, object: nil)
```
