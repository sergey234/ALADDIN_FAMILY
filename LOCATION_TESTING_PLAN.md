### 2.3 Проверка Region Monitoring

#### ✅ Проверка 5: Добавление геозоны

**Что проверить:**
- Геозона добавляется успешно
- Проверка лимита 20 геозон
- Проверка минимума 100 метров

**Как проверить:**
```swift
// Успешное добавление
let center = CLLocationCoordinate2D(latitude: 55.7558, longitude: 37.6173)
do {
    try LocationManager.shared.startMonitoring(identifier: "home", center: center, radius: 100)
    print("✅ Геозона добавлена")
} catch {
    print("❌ Ошибка: \(error)")
}

// Проверка лимита (попытка добавить 21-ю геозону)
for i in 1...21 {
    do {
        try LocationManager.shared.startMonitoring(
            identifier: "geofence_\(i)",
            center: center,
            radius: 100
        )
    } catch LocationManagerError.tooManyRegions(let maxAllowed) {
        print("✅ Лимит работает: максимум \(maxAllowed) геозон")
        break
    }
}

// Проверка минимума (попытка добавить геозону с радиусом 50м)
do {
    try LocationManager.shared.startMonitoring(identifier: "small", center: center, radius: 50)
} catch LocationManagerError.invalidRegion(let radius) {
    print("✅ Минимум работает: радиус \(radius) метров слишком мал")
}
```

**Ожидаемый результат:**
- Геозона добавляется успешно
- При превышении лимита: ошибка `tooManyRegions(maxAllowed: 20)`
- При радиусе < 100м: ошибка `invalidRegion(radius: 50)`

#### ✅ Проверка 6: События геозон

**Что проверить:**
- Уведомление при входе в геозону
- Уведомление при выходе из геозоны
- Координаты передаются правильно

**Как проверить:**
```swift
// Подписка на уведомления
NotificationCenter.default.addObserver(
    forName: .locationDidEnterRegion,
    object: nil,
    queue: .main
) { notification in
    if let region = notification.userInfo?["region"] as? CLRegion {
        print("✅ Вход в геозону: \(region.identifier)")
    }
}

NotificationCenter.default.addObserver(
    forName: .locationDidExitRegion,
    object: nil,
    queue: .main
) { notification in
    if let region = notification.userInfo?["region"] as? CLRegion {
        print("✅ Выход из геозоны: \(region.identifier)")
    }
}
```

**Тестирование:**
1. Создать геозону с центром в Москве
2. В симуляторе: Features → Location → Custom Location
3. Установить координаты внутри геозоны
4. Проверить уведомление о входе
5. Установить координаты вне геозоны
6. Проверить уведомление о выходе

## 5. ИНСТРУКЦИИ ПО ТЕСТИРОВАНИЮ

### 5.1 Тестирование в симуляторе

#### Настройка Location Services в симуляторе:

1. **Включить Location Services:**
   - Settings → Privacy → Location Services → ON

2. **Установить разрешение для приложения:**
   - Settings → Privacy → Location Services → ALADDIN → Always

3. **Изменить местоположение:**
   - Features → Location → Custom Location
   - Ввести координаты (например: 55.7558, 37.6173 для Москвы)

4. **Имитировать перемещение:**
   - Features → Location → Custom Location
   - Изменить координаты на 500+ метров
   - Проверить Significant-Change

#### Тестирование геозон:

1. **Создать геозону:**
   - Центр: 55.7558, 37.6173 (Москва)
   - Радиус: 100 метров

2. **Установить местоположение внутри геозоны:**
   - Features → Location → Custom Location
   - Координаты: 55.7558, 37.6173
   - Проверить уведомление о входе

3. **Установить местоположение вне геозоны:**
   - Координаты: 55.7500, 37.6100 (500+ метров)
   - Проверить уведомление о выходе

---

### 5.2 Тестирование на реальном устройстве

#### Настройка:

1. **Включить Location Services:**
   - Settings → Privacy → Location Services → ON

2. **Разрешить приложению:**
   - Settings → Privacy → Location Services → ALADDIN → Always

3. **Проверить GPS:**
   - Убедиться, что GPS включен
   - Убедиться, что устройство на улице (для лучшего сигнала)

#### Тестирование:

1. **Significant-Change:**
   - Пройти 500+ метров
   - Проверить уведомление в консоли

2. **Region Monitoring:**
   - Создать геозону вокруг текущего местоположения
   - Выйти из геозоны
   - Проверить уведомление о выходе
