# Integration QA (int-10)

Короткий чек-лист ручных сценариев для интеграции уведомлений, обхода, семейных карточек и родительских модалок.

## 1. Push обхода → уведомления

- Сымитировать или получить push о попытке обхода (prod/staging по вашей схеме).
- Открыть экран **Уведомления**: событие в списке, заголовок/подзаголовок ожидаемы.
- При необходимости: холодный старт приложения после push — запись не теряется, если была сохранена локально.

## 2. Bypass stats → карточка семьи / главная

- При успешном `getBypassStats` счётчики на главной и в семейном контексте соответствуют ответу API.
- Переключение выбранного ребёнка обновляет данные.

## 3. Офлайн → локальный fallback

- Отключить сеть (Airplane / firewall к API).
- Открыть **Отчёты** / участки с `getBypassStats`: при ошибке сети используется локальный агрегат (`localBypassAggregates`), приложение не падает.

## 4. Screen Time выключен

- На устройстве ребёнка отключить Screen Time / FamilyControls по политике теста.
- Убедиться в ожидаемом UX (подсказки, отсутствие краша, корректные состояния переключателей).

## 5. Мониторинг / Отчёты (int-12 / int-13)

- **Мониторинг**: `getParentalMonitoringDetail` заполняет сводку (сайты, приложения, контакты); тумблеры сообщений/скринов синхронизируются с сервером.
- **Отчёты**: подозрительная активность из detail; попытки обхода из `getBypassStats` + fallback.
- **Сеть на этом устройстве**: в модалках «Мониторинг» и «Отчёты» блок «Сеть и Safari на этом устройстве» показывает локальный Smart DNS и Safari CB; он **не** заменяет серверные данные по ребёнку.

## 6. Регрессия int-9

- Счётчик угроз на главной не смешивается с DNS/CB без подписей; строки Smart DNS / Safari CB обновляются при смене профиля/расширения.

## 7. Продуктовая линия P2 (локальный статус родителя)

- В модалках мониторинга/отчётов на семейном экране блок «Сеть и Safari на этом устройстве» относится к **телефону родителя**, а не к устройству ребёнка; есть поясняющий текст (ключ `family_modal_network_layers_p2_note`).

## 8. Аналитика vs главная / семья (p3-1)

- На экране **Аналитика** под индикатором источника данных видна подпись, что цифры считаются в контексте периода/фильтров отчётов и могут расходиться со «снимком» защиты на главной (`analytics_vs_home_family_hint`).

## 9. Подписи «обновлено» (p3-2)

- **Главная:** под семейным блоком при наличии времени последнего обновления — строка «Семья: обновлено …» (`main_family_last_refresh_caption`).
- **Уведомления:** при успешной синхронизации ленты — «Лента: обновлено …» (`notifications_feed_last_refresh_caption`).
