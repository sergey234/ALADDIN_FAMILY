# 🚨 АНАЛИЗ: Crash Detection & Roadside Assistance в ALADDIN

## ❓ ЧТО ЭТО ТАКОЕ?

### 1. 🚗 Crash Detection (Обнаружение аварий)
**Что делает:**
- Использует акселерометр и гироскоп телефона для обнаружения ДТП
- Анализирует G-силы (>3.0G) и резкие изменения скорости
- Автоматически вызывает экстренные службы (112)
- Отправляет точное местоположение

**Как работает:**
1. Постоянно мониторит датчики движения в фоне
2. При обнаружении удара (>3G) начинает 10-секундный обратный отсчет
3. Показывает модальное окно с предложением вызвать помощь
4. При подтверждении звонит в экстренные службы

**Тест симуляции аварии:**
- Это **тестовая кнопка** для демонстрации функционала
- **НЕ** реальная симуляция - просто показывает модальное окно
- Нужна только для тестирования интерфейса

### 2. 🚑 Roadside Assistance (Помощь на дороге)
**Что делает:**
- Вызов технической помощи при поломке автомобиля
- Буксировка, запуск двигателя, замена колеса
- Интеграция с партнерскими службами (типа Европлан, INGOSSTRAKH)
- Отслеживание статуса помощи в реальном времени

**Как работает:**
1. Пользователь нажимает кнопку "Помощь на дороге"
2. Приложение определяет местоположение
3. Создается запрос к партнерской службе
4. Пользователь получает статус и ETA
