# 🔧 РЕШЕНИЕ: "The run destination iPhone is not valid for Running the scheme 'ALADDINContentBlocker'"

## ❌ Проблема

При попытке запустить приложение появляется ошибка:
```
The run destination iPhone is not valid for Running the scheme 'ALADDINContentBlocker'.
Xcode doesn't support iPhone's iOS 26.1 (23B85).
```

**Причины:**
1. Выбрана неправильная схема — `ALADDINContentBlocker` (расширение) вместо `ALADDIN` (основное приложение)
2. Возможна проблема с версией iOS (26.1 не существует — последняя версия iOS 18.x)

---

## ✅ РЕШЕНИЕ: Выбор правильной схемы

### Шаг 1: Выберите правильную схему

#### 1.1. Найдите выпадающий список схем
- В верхней панели Xcode найдите выпадающий список **слева от кнопки Play (▶️)**
- Там должно быть написано что-то вроде: `ALADDINContentBlocker` или `ALADDIN`

#### 1.2. Выберите схему ALADDIN
- Нажмите на выпадающий список схем
- Выберите **`ALADDIN`** (не `ALADDINContentBlocker`!)
- Это основное приложение, которое можно запускать на устройстве

#### 1.3. Проверьте выбранную схему
- Убедитесь, что выбрано: **`ALADDIN`**
- НЕ должно быть: `ALADDINContentBlocker`, `ALADDINPacketTunnel`, или другие расширения

---

### Шаг 2: Проверка устройства

#### 2.1. Выберите устройство
- Рядом со схемой выберите ваше устройство из списка
- Убедитесь, что выбрано реальное устройство (не симулятор)

#### 2.2. Проверьте версию iOS
- Если ошибка все еще появляется с упоминанием iOS 26.1:
  - Это может быть ошибка отображения
  - Проверьте реальную версию iOS на устройстве: **Настройки → Основные → Об этом устройстве → Версия ПО**
  - Должно быть iOS 17.x или 18.x (не 26.1!)

---

### Шаг 3: Запуск приложения

#### 3.1. Запустите приложение
- После выбора правильной схемы `ALADDIN`
- Нажмите кнопку **▶️ (Play)** или **Cmd + R**

#### 3.2. Если ошибка сохраняется
- См. раздел "Дополнительные решения" ниже

---

## 🔍 Понимание схем (Schemes)

### Что такое схема?

**Схема (Scheme)** — это конфигурация, которая определяет:
- Какое приложение/расширение запускать
- Какие настройки использовать
- Куда устанавливать

### Доступные схемы в проекте:

1. **`ALADDIN`** ✅
   - **Основное приложение**
   - **Можно запускать на устройстве**
   - Используйте эту схему для тестирования

2. **`ALADDINContentBlocker`** ❌
   - **Расширение (Extension)**
   - **НЕЛЬЗЯ запускать отдельно**
   - Запускается автоматически вместе с основным приложением

3. **`ALADDINPacketTunnel`** ❌
   - **Расширение VPN**
   - **НЕЛЬЗЯ запускать отдельно**
   - Запускается автоматически при использовании VPN

## ⚠️ Дополнительные решения

### Решение 1: Обновить Xcode

Если проблема с версией iOS:
1. Проверьте версию Xcode: **Xcode → About Xcode**
2. Обновите Xcode до последней версии: **App Store → Обновления**
3. Или скачайте с developer.apple.com

---

### Решение 2: Проверить Deployment Target

1. Выберите проект **ALADDIN** в левой панели
2. Выберите Target **ALADDIN** (не проект!)
3. Перейдите на вкладку **"General"**
4. Проверьте **"Minimum Deployments"**:
   - iOS должна быть совместима с вашим устройством
   - Например, если устройство на iOS 17, Deployment Target должен быть ≤ 17

---

### Решение 3: Очистить проект

1. **Product → Clean Build Folder** (Shift + Cmd + K)
2. Закройте Xcode
3. Откройте проект снова
4. Выберите схему `ALADDIN`
5. Запустите приложение

---

### Решение 4: Проверить настройки схемы

1. Нажмите на схему `ALADDIN` → **Edit Scheme...**
2. Убедитесь, что в разделе **Run**:
   - **Build Configuration:** `Debug`
   - **Executable:** `ALADDIN.app`
3. Закройте окно настроек

---
