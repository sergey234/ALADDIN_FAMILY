## 🔧 КОМПЛЕКСНОЕ РЕШЕНИЕ (все проблемы сразу):

### Шаг 1: Принудительное обновление @State
```swift
private func addDebugLog(_ message: String) {
    let timestamp = DateFormatter.localizedString(from: Date(), dateStyle: .none, timeStyle: .medium)
    let logMessage = "\(timestamp): \(message)"
    
    // ✅ Принудительное обновление
    DispatchQueue.main.async {
        self.debugLogs.insert(logMessage, at: 0)
        if self.debugLogs.count > 20 {
            self.debugLogs.removeLast()
        }
        // ✅ Принудительное обновление UI
        self.objectWillChange.send() // Если FamilyScreen был бы ObservableObject
    }
}
```

### Шаг 2: Убрать Group, использовать AnyView
```swift
NavigationView {
    // ✅ Без Group - прямо switch

    case .main:
        AnyView(MainScreen().id("main"))
    case .family:
        AnyView(FamilyScreen().id("family"))
    // ... остальные cases
    }
}
```
