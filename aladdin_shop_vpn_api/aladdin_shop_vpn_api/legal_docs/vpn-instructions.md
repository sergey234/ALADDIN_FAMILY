# AiMonkeyVPN — как подключить (полная инструкция)

**Добро пожаловать.** Оплатите в боте → получите **файл для WireGuard** (часто автоматически в чат) → включите VPN.

Эта страница дублирует шаги из Telegram-бота **@AiMonkeyStars_bot** → **🌐 AiMonkeyVPN**. Документы: [Политика конфиденциальности](./vpn-data) · [Пользовательское соглашение](./vpn-terms) · [Правила (AUP)](./vpn-aup).

**Важно:** отдельного приложения «AiMonkeyVPN» в App Store / Google Play **нет**. Вы платите в боте, получаете **файл или QR** и подключаетесь через бесплатное приложение **WireGuard** (или запасной способ ниже).

> **Сейчас один сервер** (Россия). Список «стран» в боте — ориентир; для выхода в интернет «как из другой страны» понадобится отдельная нода (обновим канал новостей).

## Шаг 4. Импорт и включение VPN

### Вариант А — файл

1. Откройте файл из Telegram (документ `.conf`)
2. «Поделиться» → **WireGuard** (или «Открыть в…» → WireGuard)
3. В WireGuard появится профиль → переключатель **Вкл**
4. Вверху экрана — значок VPN

### Вариант Б — QR

1. WireGuard → **+** → **Сканировать QR-код**
2. Наведите на картинку из бота
3. Включите туннель

![Скриншот: импорт файла в WireGuard](https://aladdin-ai.ru/static/vpn-help/05-wireguard-import.png)
*Заглушка: WireGuard с импортированным профилем.*

## Дополнительно: другой способ на том же сервере

Если основной путь (файл/QR + WireGuard) не подходит для вашей сети:

| Способ | В боте | Приложение |
|--------|--------|------------|
| Запасная ссылка | **📋 Запасная ссылка** | **Happ** (рекомендуем, iPhone и Android); альтернативы Streisand, V2Box, v2rayNG — **один** способ, одна ссылка; не AiMonkey |
| OpenVPN | **🧱 OpenVPN (файл)** | **OpenVPN Connect** |

**Подключение:** файл или QR · **Дополнительно:** запасная ссылка в **Happ** (установить Happ → вставить одну ссылку из бота → включить VPN) или OpenVPN.
