## 1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки и защиты персональных данных пользователей сервиса VPN **«AiMonkeyVPN»** (далее — «Пользователь»).

1.2. Политика разработана с учётом законодательства **Республики Казахстан** (место регистрации Исполнителя), а также — для пользователей из Российской Федерации — Федерального закона № 152-ФЗ «О персональных данных» и иных применимых норм.

1.3. Используя сервис AiMonkeyVPN, включая Telegram-бота **[https://t.me/AiMonkeyStars_bot](https://t.me/AiMonkeyStars_bot)** (@AiMonkeyStars_bot), Пользователь подтверждает ознакомление с Политикой и согласие с условиями обработки данных, указанными ниже.

1.4. Общая политика магазина Telegram Stars / Premium в том же боте опубликована отдельно: `/v1/legal/privacy`.

## 2. Термины и определения

2.1. **«Персональные данные»** — любая информация, относящаяся к определённому или определяемому Пользователю.

2.2. **«Обработка данных»** — любые действия с данными (сбор, хранение, передача, удаление и т.п.).

2.3. **«Исполнитель»** — индивидуальный предприниматель, оказывающий услуги AiMonkeyVPN (реквизиты — в разделе 12).

2.4. **«Сервис»** — функционал VPN (в т.ч. WireGuard и иные способы подключения, указанные в боте), предоставляемый через Telegram-бота и связанную инфраструктуру.

## 3. Состав обрабатываемых данных

Сервис обрабатывает **минимально необходимый** перечень данных.

### 3.1. Технические и учётные данные

- **Telegram User ID** и **username** (если указан в Telegram);
- язык интерфейса Telegram (при наличии в API);
- сведения, необходимые для работы VPN: статус подписки, срок действия (`paid_until`), публичный ключ WireGuard, внутренний адрес туннеля, служебный token для выдачи конфигурации;
- данные о **факте** оплаты подписки в магазине бота (идентификатор заказа, сумма, статус) — **без** хранения полных платёжных реквизитов карты;
- время активации и окончания подписки;
- служебные логи API и фоновых задач (время запроса, код ответа, идентификатор операции) — **без** содержимого интернет-трафика и без секретов аутентификации (HMAC не логируется).

### 3.2. Информация, не собираемая Сервисом

**Важно:** AiMonkeyVPN придерживается политики **no-logs** в отношении пользовательской активности в сети.

Сервис **не собирает и не хранит**:

- историю посещений сайтов;
- содержимое интернет-трафика;
- IP-адреса посещённых ресурсов в привязке к активности Пользователя;
- DNS-запросы и их содержание;
- исходящее и входящее сетевое содержание.

Подключение выполняется через **стороннее** приложение (например, WireGuard); политики такого приложения определяются его разработчиком.

Обработка данных осуществляется исключительно для:

4.1. предоставления и сопровождения доступа к AiMonkeyVPN;

4.2. обработки оплат и активации тарифов через платёжные системы магазина;

4.3. технической поддержки и улучшения работы Сервиса;

4.4. обработки обращений Пользователей;

4.5. реферальной программы VPN (при участии);

4.6. обеспечения безопасности (ограничение злоупотреблений);

4.7. исполнения требований применимого законодательства.

Исполнитель **не использует** персональные данные для рекламы и **не продаёт** их третьим лицам в маркетинговых целях.
