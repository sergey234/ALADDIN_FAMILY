# Правила допустимого использования VPN (AUP), ALADDIN Shop

**Версия:** 1.0 (черновик). Согласуйте с юристом и фактическими логами/политикой хостера.

## Запрещено

1. **Несанкционированный доступ** к компьютерным системам, сетям и данным третьих лиц.
2. **Распространение вредоносного ПО**, фишинг, мошенничество, кража учётных данных.
3. **Спам**, массовая рассылка нежелательных сообщений, DDoS и иные атаки на доступность сервисов.
4. **Нарушение авторских прав** в массовом виде (торрент-хабы и т.п., если это запрещено применимым правом).
5. **Ретрансляция** VPN третьим лицам в коммерческих целях без отдельного договора с оператором.

## Разрешено

Обычное **личное** использование: защита трафика в публичных сетях, доступ к личным сервисам в рамках закона страны пребывания.

## Реакция

При сигналах злоупотреблений оператор вправе **немедленно отключить** доступ, зафиксировать причину и при необходимости передать сведения **уполномоченным органам** в объёме, предусмотренном законом.
