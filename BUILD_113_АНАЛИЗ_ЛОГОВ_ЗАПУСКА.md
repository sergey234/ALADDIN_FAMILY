## 🔴 ВСЕ ВОЗМОЖНЫЕ ПРИЧИНЫ

### ❌ **ПРИЧИНА #1: Приложение крашится при запуске**

**Симптомы:**
- Множественные запуски каждые 1-3 секунды
- Это типичный паттерн: краш → перезапуск → краш → перезапуск

**Вероятность:** 🔴 **95%** - это основная причина!

**Механизм:**
1. Приложение запускается
2. Происходит краш (возможно, при инициализации)
3. iOS автоматически перезапускает приложение
4. Краш повторяется
5. Цикл продолжается

---

### ❌ **ПРИЧИНА #2: ALADDINApp.onAppear вызывается многократно**

**Симптомы:**
- `VisualLogger.loadLogsAsync()` вызывается многократно
- `SubscriptionManager.initializeOnAppStart()` вызывается многократно
- Это может быть из-за пересоздания View

**Вероятность:** 🟡 **30%** - возможно, но менее вероятно

**Механизм:**
1. SwiftUI пересоздает View
2. `onAppear` вызывается снова
3. Инициализация происходит повторно
4. Это может вызвать проблемы

---

### ❌ **ПРИЧИНА #3: Нет защиты от повторных вызовов**

**Симптомы:**
- Нет флагов для предотвращения повторной инициализации
- Каждый вызов `onAppear` запускает инициализацию заново

**Вероятность:** 🟡 **50%** - возможно, но не основная причина

**Механизм:**
1. `onAppear` вызывается многократно
2. Нет проверки "уже инициализировано"
3. Инициализация происходит каждый раз
4. Это может вызвать проблемы
