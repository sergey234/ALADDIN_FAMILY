## 🔍 ПРИЧИНЫ РАЗНИЦЫ

### **1. Разница между кодом (245) и OpenAPI (235) = 10 endpoint'ов**

**Возможные причины:**

1. **Endpoint'ы требуют авторизацию и скрыты в OpenAPI:**
   - FastAPI может скрывать endpoint'ы с `include_in_schema=False`
   - Endpoint'ы с особыми требованиями безопасности

2. **Endpoint'ы не подключены к роутеру:**
   - Функция существует, но не добавлена в роутер
   - Роутер не подключен в main.py

3. **Внутренние endpoint'ы:**
   - Endpoint'ы только для внутреннего использования
   - Не должны быть в публичной документации

4. **Дубликаты или тестовые endpoint'ы:**
   - Тестовые endpoint'ы, которые не должны быть в OpenAPI
   - Дубликаты, которые были удалены

**Как проверить:**
- Найти все `@router.` декораторы в коде
- Сравнить с OpenAPI спецификацией
- Проверить, какие endpoint'ы не видны
