Contract for DELETE /api/user/delete (mobile ALADDIN iOS expects APIResponse<Bool>).

Canonical JSON body on HTTP 200:
{"success":true,"data":true,"message":"Account deleted","error":null}

Alternative: HTTP 204 with empty body (iOS treats as success).

Do NOT return SFM gateway envelope without success for real deletion, e.g.:
{"function":"delete_user_delete","result":"","version":"3.0.0-mock-real-protection"}
iOS maps mock-real-protection to a blocked deletion (gateway_envelope) until backend returns the canonical shape.
