### Шаг 1: Извлечение ключей из файла
```bash
# Найти все используемые ключи в файле
grep -o 'localizationManager\.localized("\([^"]*\)")' Screens/XX_Screen.swift | sed 's/localizationManager\.localized("\(.*\)")/\1/' | sort -u
```

**Что делать:**
- Извлечь все ключи из файла
- Сохранить список уникальных ключей
- Удалить дубликаты

### Шаг 2: Проверка наличия ключей в словарях
```bash
# Проверить каждый ключ на наличие в .russian
grep -c "\"ключ\":" Core/Localization/LocalizationManager.swift

# Проверить каждый ключ на наличие в .english
grep -c "\"ключ\":" Core/Localization/LocalizationManager.swift
```

**Что делать:**
- Проверить каждый ключ на наличие в .russian
- Проверить каждый ключ на наличие в .english
- Составить список отсутствующих ключей

### Шаг 3: Поиск русских строк в бэкапах
```bash
# Найти русские строки в бэкапе
grep -n "русская_строка" BACKUPS/20251105_115303/Screens/XX_Screen.swift
```

**Что делать:**
- Найти бэкап файла экрана
- Найти русские строки, соответствующие ключам
- Сопоставить ключи с русскими строками

### Шаг 4: Добавление ключей в словари
**Что делать:**
- Добавить ключ в .russian словарь (русский перевод из бэкапа)
- Добавить ключ в .english словарь (перевести на английский)
- Добавить в оба словаря одновременно

### Шаг 5: Проверка после добавления
