# 📱 О РУССКИХ И АНГЛИЙСКИХ НАЗВАНИЯХ В МЕНЮ НАВИГАЦИИ

## ✅ ДА, ВИЖУ ИХ!

В **Меню навигации** (Список экранов) отображаются **ДВА названия** для каждого экрана:

### **1. Русское название** (основное)
- Источник: `screen.displayName` 
- Примеры: "Семья", "VPN", "Аналитика", "Настройки"
- Отображается **крупным шрифтом** (14pt, semibold)

### **2. Английское название** (техническое)
- Источник: `screen.rawValue`
- Примеры: "02_FamilyScreen", "03_VPNScreen", "04_AnalyticsScreen"
- Отображается **мелким шрифтом** (10pt) под русским названием

---

## 📍 ГДЕ ЭТО ОТОБРАЖАЕТСЯ:

**Файл:** `Shared/Components/Navigation/ALADDINNavigationBar.swift`

**Код:**
```swift
// Строка 251-257
VStack(alignment: .leading, spacing: 2) {
    Text(screen.displayName)        // ← РУССКОЕ название (крупное)
        .font(.system(size: 14, weight: .semibold))
        .foregroundColor(isActive ? .orange : .white)
    
    Text(screen.rawValue)            // ← АНГЛИЙСКОЕ название (мелкое)
        .font(.system(size: 10))
        .foregroundColor(.white.opacity(0.6))
}
```

## 💡 ОТКУДА БЕРУТСЯ НАЗВАНИЯ:

### **Русские названия:**
Определены в `NavigationManager.ALADDINScreen.displayName` (строки 63-104)

### **Английские названия:**
Это `rawValue` из enum, который соответствует имени файла экрана

---

**Итого:** В меню показываются **оба названия** - русское для пользователя, английское для разработчиков! ✅
