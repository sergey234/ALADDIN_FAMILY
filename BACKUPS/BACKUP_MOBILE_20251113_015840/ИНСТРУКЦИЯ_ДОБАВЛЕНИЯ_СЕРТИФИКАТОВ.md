# 📋 ИНСТРУКЦИЯ: ДОБАВЛЕНИЕ СЕРТИФИКАТОВ В BUNDLE

**Дата:** 2025-11-06  
**Задача:** Добавить SSL сертификаты в Xcode проект для SSL Pinning

---

## 📍 РАСПОЛОЖЕНИЕ СЕРТИФИКАТОВ

Сертификаты находятся в папке:
```
ALADDIN/Certificates/
├── aladdin_cert.cer          (основной сертификат)
└── aladdin_cert_backup.cer  (резервный сертификат)
```

---

## ✅ ШАГИ ДОБАВЛЕНИЯ В XCODE

### **Шаг 1: Открыть Xcode проект**
1. Откройте файл `ALADDIN.xcodeproj` в Xcode

### **Шаг 2: Добавить сертификаты в проект**
1. В Finder перейдите в папку `ALADDIN/Certificates/`
2. Выделите оба файла сертификатов:
   - `aladdin_cert.cer`
   - `aladdin_cert_backup.cer`
3. Перетащите их в Xcode в папку проекта (например, в `ALADDIN/` или создайте папку `Certificates/`)

### **Шаг 3: Настроить Target Membership**
1. Выделите первый сертификат (`aladdin_cert.cer`)
2. В правой панели (File Inspector) найдите раздел "Target Membership"
3. Убедитесь, что галочка стоит напротив вашего Target (обычно `ALADDIN`)
4. Повторите для второго сертификата (`aladdin_cert_backup.cer`)

### **Шаг 4: Проверить добавление**
1. Убедитесь, что файлы видны в навигаторе проекта
2. Убедитесь, что они имеют правильный Target Membership
3. Запустите приложение и проверьте логи:
   - Должно появиться: `✅ SSL Pinning: Загружено 2 сертификатов`
   - Если видите: `⚠️ SSL Pinning: Сертификаты не найдены в Bundle!` - проверьте шаги выше

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Не удаляйте сертификаты из папки** `ALADDIN/Certificates/` - они нужны для резервного копирования
2. **Убедитесь, что сертификаты добавлены в Target Membership** - иначе они не попадут в Bundle
3. **После добавления пересоберите проект** (Clean Build Folder: Cmd+Shift+K, затем Build: Cmd+B)
4. **Fallback механизм:** Если сертификаты не найдены, используется стандартная проверка сертификата iOS
