### 2. ✅ Добавлен антивирус на VPN экран

**Файл:** `Screens/03_VPNScreen.swift`

**Новая секция:** `antivirusCard`

**Функционал:**
- 🛡️ Заголовок "Антивирус" со статусом "Активен"
- 📊 Статистика в сетке 4 колонки:
  - 🔍 **1,247** файлов проверено
  - ✅ **0** угроз найдено
  - 🔄 **2ч назад** последняя проверка
  - ⚡ **100%** защита
- ▶️ Кнопка "Запустить проверку"

**Расположение:** После "Быстрые действия" (Настройки, Статистика, Помощь)

**Новый компонент:** `AntivirusStatItem` - для отображения статистики антивируса
