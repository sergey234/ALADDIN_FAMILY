## 📝 КАК ДОБАВИТЬ В XCODE

### Шаг 1: Открыть Xcode
```
Откройте ALADDIN.xcodeproj в Xcode
```

### Шаг 2: Найти папку
```
В Project Navigator найдите:
Shared → Components → Cards
```

### Шаг 3: Добавить файлы
1. Правой кнопкой мыши на папку `Cards`
2. Выберите **"Add Files to ALADDIN..."**
3. Найдите и выберите:
   - `WelcomeCardForCreator.swift`
   - `AddMoreMemberCard.swift`
4. ✅ Убедитесь, что галочка **"Copy items if needed"** стоит
5. ✅ Убедитесь, что галочка **"Add to targets: ALADDIN"** стоит
6. Нажмите **"Add"**

### Шаг 4: Проверить
- Файлы должны появиться в Project Navigator
- Убедитесь, что они в правильной папке `Cards`
- Проект должен собираться без ошибок
