   **Проблема:**
   - Приложение падало с ошибкой `Fatal error: Dictionary literal contains duplicate keys` при запуске
   - В словаре `translations` в файле `Core/Localization/LocalizationManager.swift` были найдены дубликаты ключей внутри одного и того же языка
   - Swift не позволяет иметь дубликаты ключей в словаре - это вызывает фатальную ошибку во время выполнения
   
   **Найденные дубликаты:**
   - ❌ Русский словарь: дублированный блок ключей (строки 1088-1406) - **УДАЛЕН**
   - ❌ Русский словарь: дублированный блок ключей (строки 2000-2398) - **УДАЛЕН**
   - ❌ Английский словарь: дубликат ключа `vpn_protection` (строки 1654 и 1738) - **УДАЛЕН**
   - ❌ Английский словарь: дублированный блок ключей (строки 2399-2731) - **УДАЛЕН**
   
   **Решение:**
   - ✅ Удалены все дубликаты ключей из русского и английского словарей
   - ✅ Словарь `translations` сделан `lazy` для оптимизации производительности
   - ✅ Создан скрипт автоматической проверки: `scripts/check_localization_duplicates.py`
   - ✅ Создан файл с лучшими практиками: `LOCALIZATION_BEST_PRACTICES.md`
   - ✅ Проект успешно компилируется и запускается без ошибок
