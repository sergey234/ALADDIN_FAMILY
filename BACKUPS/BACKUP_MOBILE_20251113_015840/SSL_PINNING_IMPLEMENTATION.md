## 🛡️ **КАК ЭТО ЗАЩИЩАЕТ СЕМЬИ**

### **От Man-in-the-Middle атак:**
- Мошенники не могут перехватить трафик
- Поддельные сертификаты блокируются
- Все API запросы защищены

### **От подделки сертификатов:**
- Проверка сертификатов на соответствие
- Блокировка подозрительных соединений
- Логирование попыток атак

## 🔧 **ТЕХНИЧЕСКИЕ ДЕТАЛИ**

### **Основные компоненты:**

```swift
// SSL Pinning конфигурация
private let isSSLPinningEnabled: Bool
private let pinnedDomains: Set<String>
private var pinnedCertificates: [Data] = []

// Проверка сертификатов
private func validateServerCertificate(_ serverTrust: SecTrust, for host: String) -> Bool

// URLSessionDelegate
func urlSession(_ session: URLSession, didReceive challenge: URLAuthenticationChallenge, completionHandler: @escaping (URLSession.AuthChallengeDisposition, URLCredential?) -> Void)
```

### **Новые типы ошибок:**
- `sslPinningFailed` - SSL Pinning не удался
- `certificateValidationFailed` - Проверка сертификата не удалась
- `untrustedCertificate` - Недоверенный сертификат

## 🚀 **ИСПОЛЬЗОВАНИЕ**

### **Создание NetworkManager с SSL Pinning:**
```swift
// SSL Pinning включен (по умолчанию)
let networkManager = NetworkManager()

// SSL Pinning отключен (для тестирования)
let networkManager = NetworkManager(enableSSLPinning: false)
```

### **Добавление сертификатов:**
1. Поместите сертификаты в `Resources/Certificates/`
2. Назовите файлы как `aladdin_cert.cer`
3. Сертификаты автоматически загрузятся
