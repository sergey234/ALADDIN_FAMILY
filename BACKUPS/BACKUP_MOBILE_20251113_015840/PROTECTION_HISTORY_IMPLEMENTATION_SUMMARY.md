## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### ProtectionLevelHistoryManager
- Singleton паттерн для единого доступа к истории
- Сохранение в UserDefaults (JSON encoding)
- Методы:
  - `saveLevelChange()` - сохранение записи
  - `getHistoryForDays()` - получение истории за период
  - `getAverageLevel()` - средний уровень за период
  - `getWeeklyHistory()` / `getMonthlyHistory()` - удобные методы

### ProtectionLevelHistoryModal
- График на основе SwiftUI Path (без внешних зависимостей)
- Статистические карточки
- Список записей с цветовой индикацией уровня
- Picker для выбора периода

---

## 🎨 UI/UX

- График: линейный график с точками для каждой записи
- Статистика: 3 карточки (Средний, Максимум, Минимум)
- История: список с цветовыми индикаторами:
  - 🔴 0-25% - красный
  - 🟡 26-50% - жёлтый
