# 🔧 КАК СОЗДАТЬ EXCEPTION BREAKPOINT В XCODE

## 🎯 ЧТО ТАКОЕ EXCEPTION BREAKPOINT?

**Exception Breakpoint** - это специальная точка останова в Xcode, которая **автоматически останавливает выполнение программы**, когда происходит **любая ошибка** или **краш**.

Это самый эффективный способ найти точное место краша!

---

## 📱 ШАГ ЗА ШАГОМ:

### ШАГ 1: Открыть Breakpoint Navigator

**Способ A: Через меню**
1. В Xcode: **View → Navigators → Show Breakpoint Navigator**
2. Или просто нажмите **⌘8** (Command + 8)

**Способ B: Через боковую панель**
1. Посмотрите на левую сторону Xcode
2. Вверху есть иконки: 📁 (Project), 🔍 (Search), 🐛 (Breakpoint) и т.д.
3. Нажмите на иконку **🐛 Breakpoint Navigator** (6-я слева)

**Что вы увидите:**
```
┌─────────────────────────┐
│  Breakpoint Navigator   │  ← Левая панель
├─────────────────────────┤
│  (пусто или список)     │
│                         │
│  [+ ▼]                  │  ← Кнопка "+" внизу
└─────────────────────────┘
```

---

### ШАГ 2: Создать Exception Breakpoint

1. Внизу левой панели найдите кнопку **"+"** (плюс)
2. Нажмите на неё
3. Появится меню:
   ```
   ┌──────────────────────────┐
   │  + Symbolic Breakpoint    │
   │  + Exception Breakpoint   │  ← Выберите это!
   │  + Swift Error Breakpoint │
   └──────────────────────────┘
   ```
4. Выберите **"Exception Breakpoint"**

**Результат:**
- В списке появится новый breakpoint: **"All Exceptions"** или **"Exception"**

---

### ШАГ 3: Настроить Breakpoint (опционально)

1. **Правый клик** (или Control+клик) на созданный Exception Breakpoint
2. Выберите **"Edit Breakpoint..."**

**Окно настроек:**
```
┌─────────────────────────────────┐
│  Exception Breakpoint            │
├─────────────────────────────────┤
│  Exception:  [All ▼]            │
│     - All                        │
│     - Objective-C                │
│     - C++                        │
│                                  │
│  Break:                          │
│     ☑ On Throw                   │
│     ☑ On Catch                    │
│                                  │
│  Action:                         │
│     [None ▼]                     │
│                                  │
│  [Options...]                    │
│     ☐ Automatically continue... │
│                                  │
│  [Cancel]  [Done]                │
└─────────────────────────────────┘
```

**Рекомендуемые настройки:**
- ✅ **Exception:** `All` (показывает все ошибки)
- ✅ **Break:** `On Throw` (остановиться при выбрасывании ошибки)
- ☐ **Break:** `On Catch` (можно отключить)

Нажмите **"Done"**

---

### ШАГ 4: Активировать Breakpoint

1. Убедитесь что breakpoint **включен** (иконка должна быть **синяя**, не серая)
2. Если серая - кликните на неё чтобы включить

**Визуально:**
```
✅ Включен:  🔵 All Exceptions
❌ Выключен: ⚪ All Exceptions
```

---

### ШАГ 5: Запустить приложение

1. Запустите приложение: **⌘R** или кнопка ▶️
2. Откройте экран тарифов
3. Нажмите на тариф

**Что произойдет:**
- Приложение **ОСТАНОВИТСЯ** сразу при краше
- В Xcode появится зеленая стрелка → **это место краша!**
- Внизу Xcode будет показана информация об ошибке

---

### ШАГ 6: Найти место краша

**После остановки вы увидите:**

**В центре Xcode:**
```
┌──────────────────────────────────┐
│  PaymentQRViewModel.swift        │  ← Файл
│  140: let networkManager = ...   │  ← Строка краша
│        ↑                          │  ← Зеленая стрелка
│                                    │
│  Левая панель: Variables          │
│  • tariff = {...}                 │
│  • self = PaymentQRViewModel      │
└──────────────────────────────────┘
```

**Внизу Xcode (Debug Area):**
```
(lldb) Thread 1: EXC_BAD_ACCESS
или
(lldb) Fatal error: Unexpectedly found nil...
```

---

### ШАГ 7: Скопировать информацию

**Что записать:**

1. **Файл и строка:**
   ```
   PaymentQRViewModel.swift:140
   ```

2. **Код в этой строке:**
   ```
   let networkManager = NetworkManager()
   ```

3. **Сообщение об ошибке (внизу консоли):**
   ```
   Thread 1: EXC_BAD_ACCESS
   или
   Fatal error: ...
   ```

4. **Переменные (левая панель Variables):**
   - Какие переменные nil?
   - Какие значения странные?

---

## 📋 ЧТО ДЕЛАТЬ ЕСЛИ ПРИЛОЖЕНИЕ НЕ ОСТАНОВИЛОСЬ:

### Вариант 1: Проверить что breakpoint включен
- Иконка должна быть **синяя**, не серая

### Вариант 2: Перезапустить Xcode
- Иногда breakpoints не работают, пока не перезапустить

### Вариант 3: Использовать Symbolic Breakpoint
1. Кнопка "+" → "Symbolic Breakpoint"
2. В поле "Symbol" введите: `PaymentQRViewModel.init`
3. Это остановится на входе в метод

---

## ✅ БЫСТРАЯ ВЕРСИЯ (3 шага):

1. **⌘8** (открыть Breakpoint Navigator)
2. **"+"** → **"Exception Breakpoint"**
3. Запустить приложение и воспроизвести краш

**Готово!** Приложение остановится на месте краша.

---

## 🔍 АЛЬТЕРНАТИВА: Debug Console

Если breakpoint не работает, внизу Xcode (Debug Area) будет:
```
Message from debugger: Terminated due to signal 9
```

Это означает что краш произошел, но breakpoint его не поймал.

**Решение:** Используйте Symbolic Breakpoint на `PaymentQRViewModel.init` или `PaymentQRScreen.init`
