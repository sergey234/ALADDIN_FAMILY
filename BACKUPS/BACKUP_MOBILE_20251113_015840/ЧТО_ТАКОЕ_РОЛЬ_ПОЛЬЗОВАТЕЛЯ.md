# 📘 ЧТО ТАКОЕ РОЛЬ ПОЛЬЗОВАТЕЛЯ И ГДЕ ОНА УСТАНАВЛИВАЕТСЯ

## 🎯 ЧТО ЭТО ТАКОЕ?

**Роль пользователя** — это информация о том, кто использует приложение:
- 👨‍👩‍👧 **Parent** (Родитель) — может управлять настройками, награждать/наказывать детей
- 👶 **Child** (Ребёнок) — может видеть свой баланс единорогов, играть в игры
- 👵 **Grandparent** (Бабушка/Дедушка) — упрощённый интерфейс для пожилых

## 📍 ГДЕ ЭТО ХРАНИТСЯ?

Роль сохраняется в **UserDefaults** — это встроенное хранилище iOS для простых данных:

```swift
UserDefaults.standard.set("Parent", forKey: "current_user_role")
```

**Что это значит:**
- `UserDefaults.standard` — хранилище данных приложения
- `set("Parent", ...)` — сохраняем значение "Parent"
- `forKey: "current_user_role"` — ключ, по которому мы потом читаем роль

## 🔍 ГДЕ УСТАНАВЛИВАЕТСЯ РОЛЬ?

### ✅ АВТОМАТИЧЕСКИ при регистрации:

**Файл:** `ViewModels/FamilyRegistrationViewModel.swift`  
**Функция:** `createFamily()` (строка 192-200)

```swift
func createFamily() {
    guard let role = selectedRole,

    }
    
    // ✅ СОХРАНЯЕМ РОЛЬ ПОЛЬЗОВАТЕЛЯ
    saveUserRole(role)  // <-- ВОТ ЗДЕСЬ!
    
    // ... остальной код регистрации

```

**Что происходит:**
1. Пользователь регистрируется в приложении
2. Выбирает роль (Parent, Child, или Grandparent)
3. Роль **автоматически сохраняется** в UserDefaults
4. При следующем запуске приложения роль читается автоматически

## 🔧 КАК ПРОВЕРИТЬ/УСТАНОВИТЬ РОЛЬ ВРУЧНУЮ?

### Для тестирования можно установить роль вручную:

#### Способ 1: Через код (для разработчиков)

В любом View добавить в `.onAppear`:

```swift
.onAppear {
    // Проверяем текущую роль
    let currentRole = UserDefaults.standard.string(forKey: "current_user_role")
    print("🔍 Текущая роль: \(currentRole ?? "НЕ УСТАНОВЛЕНА")")
    
    // Если роль не установлена - устанавливаем для тестирования
    if currentRole == nil {
        UserDefaults.standard.set("Parent", forKey: "current_user_role")
        print("✅ Роль установлена в 'Parent' для тестирования")
    }
}
```

#### Способ 2: Через консоль Xcode (Debug)

В консоли Xcode (во время работы приложения) можно установить:

```swift
// В консоли Xcode (po = print object):
po UserDefaults.standard.set("Parent", forKey: "current_user_role")
```

## 🎯 ЗАЧЕМ ЭТО НУЖНО?

Роль используется для:

1. **Доступа к функциям:**
   - Только родители видят кнопки "Вознаградить"/"Наказать"
   - Только родители могут изменять настройки игр
   - Дети не могут изменять свой баланс единорогов напрямую

2. **Навигации:**
   - При запуске приложение проверяет роль и автоматически открывает нужный экран
   - Родители → ParentalControlScreen
   - Дети → ChildInterfaceScreen
   - Бабушки/Дедушки → ElderlyInterfaceScreen

3. **Безопасности:**
   - Предотвращает доступ детей к настройкам родительского контроля
   - Ограничивает возможность изменения баланса единорогов

## ⚠️ ЧТО ДЕЛАТЬ, ЕСЛИ РОЛЬ НЕ УСТАНОВЛЕНА?

### Проблема:
Если вы видите, что:
- Кнопки "Вознаградить"/"Наказать" не видны
- Дети могут изменять настройки
- Не работает проверка доступа

### Решение:

1. **Проверьте роль:**
   ```swift
   let role = UserDefaults.standard.string(forKey: "current_user_role")
   print("Роль: \(role ?? "НЕ УСТАНОВЛЕНА")")
   ```

2. **Установите роль для тестирования:**
   ```swift
   UserDefaults.standard.set("Parent", forKey: "current_user_role")
   ```

3. **Перезапустите приложение** (чтобы проверки роли сработали заново)

## 📝 ВАЖНЫЕ ЗАМЕЧАНИЯ:

1. **Значение должно быть точно:** `"Parent"` (с большой буквы), не `"parent"` или `"Родитель"`
2. **Роль сохраняется автоматически** при регистрации — обычно не нужно устанавливать вручную
3. **Для тестирования** можно временно установить роль вручную
4. **В продакшене** роль устанавливается только через процесс регистрации

## 🎯 ИТОГО:

**`UserDefaults.standard.set("Parent", forKey: "current_user_role")`** — это команда для сохранения роли пользователя в хранилище приложения. Она выполняется автоматически при регистрации, но для тестирования можно установить вручную.
