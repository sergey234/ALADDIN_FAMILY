В логах компиляции видно, что файл не присутствует в списке компилируемых файлов.

### Решение (В XCODE):

#### Шаг 1: Откройте Xcode
1. Откройте проект `ALADDIN.xcodeproj` в Xcode

#### Шаг 2: Найдите файл RewardModels.swift
1. В навигаторе проектов найдите файл: `Shared/Models/RewardModels.swift`
2. Если файла нет в навигаторе - добавьте его:
   - Правый клик на папку `Shared/Models/`
   - Выберите "Add Files to ALADDIN..."
   - Выберите `RewardModels.swift`
   - ✅ Убедитесь, что галочка "Copy items if needed" НЕ стоит (файл уже в проекте)
   - ✅ Убедитесь, что галочка "Add to targets: ALADDIN" СТОИТ
   - Нажмите "Add"

#### Шаг 3: Проверьте Target Membership
1. Выберите файл `RewardModels.swift` в навигаторе
2. В правой панели (File Inspector, первый таб) найдите "Target Membership"
3. ✅ Убедитесь, что галочка стоит напротив "ALADDIN"
4. Если галочки нет - поставьте её

#### Шаг 4: Проверьте Build Phases
1. Выберите проект в навигаторе (синяя иконка вверху)
2. Выберите Target "ALADDIN"
3. Перейдите на вкладку "Build Phases"
4. Разверните "Compile Sources"
5. ✅ Убедитесь, что `RewardModels.swift` есть в списке
6. Если нет - нажмите "+" и добавьте файл

#### Шаг 5: Clean и Build
1. В Xcode: **Product → Clean Build Folder** (Shift+Cmd+K)
2. Закройте Xcode
3. Откройте Xcode снова
4. **Product → Build** (Cmd+B)
