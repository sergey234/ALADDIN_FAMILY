## 🎨 Особенности реализации

### Accordion (раскрывающиеся элементы):
- ✨ Каждый элемент можно развернуть
- ▶️ Стрелка показывает состояние (▶️ раскрыт / ▾ свернут)
- ⚫ Переключатель внутри каждого элемента
- 🎭 Плавная анимация раскрытия/сворачивания

### Новый компонент: `BypassDetectionItem`
- Иконка и название детекции
- Кнопка для разворачивания
- Внутри: описание + переключатель
- Автоматическая анимация

### Функционал:
- ✅ Статистика блокировок
- ✅ 4 типа детекций
- ✅ Возможность отключить каждую детекцию
- ✅ Информация о провайдерах/браузерах

## 🔧 Технические детали

### Структура:
```swift
bypassProtectionCard
├── Header ("🚨 Защита от обхода")
├── Stats Grid (3 колонки: 0, 47, 100%)
└── BypassDetectionItem[4]
    ├── 🌐 Детекция VPN
    ├── 🕶️ Детекция Инкогнито
    ├── 🧅 Детекция Tor
    └── 🔀 Детекция Proxy
```

### Компоненты:
- `BypassDetectionItem` - элемент accordion
- `@State isExpanded` - состояние раскрытия
- `@State enabled` - состояние переключателя
- `Toggle()` - SwiftUI переключатель
