### 1. 🔄 Автоматическое добавление участников

**Вопрос:** Когда будут добавляться другие участники - они будут автоматически в эту карту добавляться?

**Ответ:** ✅ **ДА, автоматически!**

**Как это работает:**

1. **Добавление через модальное окно:**
   - Пользователь нажимает кнопку "➕ Добавить участника"
   - Открывается `AddMemberOptionsModal` с вариантами:
     - Сканировать QR-код
     - Ввести код приглашения
     - Создать новую семью

2. **Сохранение в UserDefaults:**
   - Когда новый участник регистрируется через `FamilyRegistrationViewModel`
   - Данные автоматически сохраняются в `family_members_list` (UserDefaults)
   - Отправляется уведомление `UserDefaults.didChangeNotification`

3. **Автоматическое обновление карточки:**
   - `FamilyScreen` слушает это уведомление (строка 505)
   - Автоматически вызывается `loadFamilyMembers()`
   - Список участников обновляется **без перезагрузки экрана**

```swift
.onReceive(NotificationCenter.default.publisher(for: UserDefaults.didChangeNotification)) { _ in
    // Обновляем список участников при изменении UserDefaults
    loadFamilyMembers()
}
```

**Итог:** Новый участник появляется в карточке **мгновенно** после добавления!

### 3. 🎯 Навигация при нажатии на карточку участника

**Вопрос:** При нажатии на свою карточку Родитель - я куда должен переходить? Какая логика?

**Ответ:** Логика навигации зависит от **роли участника**:

#### 📍 Текущая реализация (функция `navigateToMemberScreen`):

```swift
private func navigateToMemberScreen(role: FamilyMemberCard.FamilyRole) {
    switch role {
    case .parent:
        // Родитель → ProfileScreen (Профиль)
        navigationManager.navigateTo(.profile)
        
    case .child:
        // Ребёнок → ChildInterfaceScreen (Детский интерфейс)
        navigationManager.navigateTo(.childInterface)
        
    case .teenager:
        // Подросток → ChildInterfaceScreen (Упрощённый интерфейс)
        navigationManager.navigateTo(.childInterface)
        
    case .elderly:
        // Пожилой → ElderlyInterfaceScreen (Интерфейс для пожилых)
        navigationManager.navigateTo(.elderlyInterface)
    }
}
```

#### 🗺️ Карта навигации:

| Роль участника | Экран назначения | Что там? |
|---------------|------------------|----------|
| 👨‍💼 **Родитель** | `ProfileScreen` (11_ProfileScreen) | Профиль пользователя, настройки, реферальная программа |
| 👶 **Ребёнок** | `ChildInterfaceScreen` (08_ChildInterfaceScreen) | Упрощённый детский интерфейс, игры, единороги |
| 🧒 **Подросток** | `ChildInterfaceScreen` (08_ChildInterfaceScreen) | Упрощённый интерфейс (как для детей) |
| 👴 **Пожилой** | `ElderlyInterfaceScreen` (09_ElderlyInterfaceScreen) | Интерфейс для пожилых: лекарства, врачи, экстренная помощь |

## 🔄 ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

### Как работает автоматическое обновление:

```swift
// 1. Сохранение участника (FamilyRegistrationViewModel)
saveCreatorAsFamilyMember(role: FamilyRole, ageGroup: AgeGroup) {
    // Сохраняет в UserDefaults
    UserDefaults.standard.set(encoded, forKey: "family_members_list")
    
    // Отправляет уведомление
    NotificationCenter.default.post(
        name: UserDefaults.didChangeNotification, 
        object: nil
    )
}

// 2. Обновление в FamilyScreen
.onReceive(NotificationCenter.default.publisher(for: UserDefaults.didChangeNotification)) { _ in
    loadFamilyMembers() // Автоматически обновляет список
}
```
