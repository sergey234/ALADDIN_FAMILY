# 📋 ПЛАН ИСПРАВЛЕНИЯ: ДЕФОЛТНЫЕ УЧАСТНИКИ СЕМЬИ

## 🔍 ТЕКУЩАЯ ПРОБЛЕМА

**Файл:** `Screens/02_FamilyScreen.swift` (строки 16-21)

```swift
@State private var familyMembers: [FamilyMemberData] = [
    FamilyMemberData(name: "Папа", role: .parent, ...),
    FamilyMemberData(name: "Мама", role: .parent, ...),
    FamilyMemberData(name: "Маша", role: .child, ...),
    FamilyMemberData(name: "Бабушка", role: .elderly, ...)
]
```

**Проблема:** Новый пользователь видит 4 дефолтных участника, которые не существуют реально.

## 🎯 ЦЕЛЬ ИСПРАВЛЕНИЯ

✅ **Правильная логика:**
- Новый пользователь видит только себя или пустой список
- Участники появляются только после реальной регистрации
- Данные загружаются из `UserDefaults` или API

## 💾 ЛОГИКА ХРАНЕНИЯ ДАННЫХ

### **UserDefaults Keys:**

```swift
// Список участников семьи
"family_members_list" -> [FamilyMemberData] (JSON)

// Текущий пользователь
"current_user_role" -> "Parent" | "Child" | "Grandparent"
"current_user_name" -> "Имя пользователя"

// ID семьи
"family_id" -> "FAM_A1B2C3D4E5F6"
```

### **Функция загрузки участников:**

```swift
private func loadFamilyMembers() {
    // 1. Загрузить из UserDefaults
    if let savedData = UserDefaults.standard.data(forKey: "family_members_list"),
       let decoded = try? JSONDecoder().decode([FamilyMemberData].self, from: savedData) {
        familyMembers = decoded
        return
    }
    
    // 2. Если нет сохранённых данных - показать только текущего пользователя
    if let currentRole = UserDefaults.standard.string(forKey: "current_user_role"),
       let role = FamilyMemberCard.FamilyRole(rawValue: currentRole) {
        let userName = UserDefaults.standard.string(forKey: "current_user_name") ?? "Вы"
        
        familyMembers = [
            FamilyMemberData(
                name: userName,
                role: role,
                avatar: getAvatarForRole(role),
                status: .protected,
                threatsBlocked: 0,
                lastActive: "Сейчас"
            )
        ]
    } else {
        // 3. Если даже роли нет - пустой список
        familyMembers = []
    }
    
    print("✅ Загружено участников семьи: \(familyMembers.count)")
}
```

### **Функция сохранения участников:**

```swift
private func saveFamilyMembers() {
    if let encoded = try? JSONEncoder().encode(familyMembers) {
        UserDefaults.standard.set(encoded, forKey: "family_members_list")
        print("✅ Сохранено участников семьи: \(familyMembers.count)")
    }
}
```
