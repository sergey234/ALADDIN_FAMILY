## 🚀 КАК ЗАПУСТИТЬ ТЕСТЫ:

### Способ 1: Через Xcode (Рекомендуется)

1. **Откройте Xcode:**
   ```bash
   open ALADDIN.xcodeproj
   ```

2. **Выберите схему:**
   - Вверху Xcode выберите: `ALADDIN` (не симулятор)
   - Выберите симулятор: iPhone 15

3. **Запустите все тесты:**
   - Нажмите `Cmd+U` (Product → Test)
   - Или нажмите ▶️ около тестов слева

4. **Проверьте результаты:**
   - Все зеленые ✅ = тесты прошли
   - Красные ❌ = есть ошибки

---

### Способ 2: Через терминал

1. **Запустите Unit тесты:**
   ```bash
   xcodebuild test -project ALADDIN.xcodeproj -scheme ALADDIN -destination 'platform=iOS Simulator,name=iPhone 15' -only-testing:ALADDINTests
   ```

2. **Запустите UI тесты:**
   ```bash
   xcodebuild test -project ALADDIN.xcodeproj -scheme ALADDIN -destination 'platform=iOS Simulator,name=iPhone 15' -only-testing:ALADDINUITests
   ```
