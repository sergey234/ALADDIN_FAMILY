# 🔍 ПРОВЕРКА ВЫБРАННОГО УСТРОЙСТВА В XCODE

## 📱 **КУДА СМОТРЕТЬ:**

В Xcode, вверху экрана, есть список устройств:

```
[▶️] [ALADDIN ▾] [iPhone 13 ▾]
```

---

## ✅ **ЧТО ДЕЛАТЬ:**

### **Вариант 1: Выбрать iPhone 13 Simulator**

1. Нажмите на **"iPhone 13"** (или другое устройство)
2. В выпадающем списке выберите **"iPhone 13"** (должно быть написано "Simulator")
3. Нажмите **Run (▶️)**

---

### **Вариант 2: Скачать симулятор iPhone 13**

Если симулятора нет в списке:

1. В Xcode: **Xcode** → **Settings...** (или Preferences)
2. Вкладка **"Platforms"** или **"Components"**
3. Скачайте **iOS 17.X Simulator** (если нет)
4. После установки выберите его в списке устройств

---

### **Вариант 3: Создать новый симулятор**

1. В Xcode: **Window** → **Devices and Simulators**
2. Нажмите **"+"** внизу
3. Выберите:
   - **Device Type:** iPhone 13
   - **OS Version:** iOS 17.X
4. Нажмите **"Create"**
