# 🔍 АНАЛИЗ: Почему онбординг меняется с 7 на 4 страницы

## ✅ НАЙДЕННЫЕ ПРИЧИНЫ:

### 1. **OnboardingViewModel.swift имеет `totalPages: 4`**
**Файл:** `ViewModels/OnboardingViewModel.swift`
- ❌ Содержит `let totalPages: Int = 4`
- ✅ **НО:** Этот ViewModel НЕ используется в `14_OnboardingScreen.swift`
- ✅ Проверено: `OnboardingScreen` не использует `OnboardingViewModel`

**Вывод:** Это НЕ причина проблемы, но может вводить в заблуждение.

### 2. **Резервные копии с 4 страницами**
**Файлы:**
- `BACKUP_SCREENS_20251028_200516/14_OnboardingScreen.swift` - содержит 4 страницы
- `BACKUP_SCREENS_20251102_205357/14_OnboardingScreen.swift` - содержит 4 страницы

**Проблема:** Если какой-то процесс или скрипт автоматически копирует файлы из BACKUP, он может перезаписать основной файл.

### 3. **Git может автоматически откатывать**
**Возможные причины:**
- Git merge/rebase конфликты
- Автоматические скрипты Git hooks
- `.gitattributes` может влиять на файлы

### 4. **Xcode кеш (DerivedData)**
**Проблема:** Xcode может использовать старую версию файла из кеша.

### 5. **Автоматическое форматирование**
**Возможные инструменты:**
- SwiftFormat
- SwiftLint
- Автоформатирование в Xcode
