**Файл:** `Core/Navigation/NavigationManager.swift` (строка 222)

**Было:**
```swift

    // Использование self без weak может вызвать retain cycle
}
```

**Стало:**
```swift
DispatchQueue.main.asyncAfter(deadline: .now() + 0.05) { [weak self] in

    // Безопасное использование self
}
```

**Статус:** ✅ ИСПРАВЛЕНО
