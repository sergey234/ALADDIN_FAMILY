## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### **Редактирование:**

**Принцип работы:**
1. При нажатии на "✏️" запись сохраняется в `editingEntry` / `editingMedication` / `editingAppointment`
2. Поля формы заполняются данными из записи
3. При сохранении проверяется, есть ли `editingEntry`:
   - Если есть → обновляется существующая запись (по ID)
   - Если нет → добавляется новая запись

**Код:**
```swift
if let editing = editingEntry {
    // Обновляем существующую запись
    if let index = entries.firstIndex(where: { $0.id == editing.id }) {
        entries[index] = HealthEntry(id: editing.id, date: entryDate, text: entryText)
    }
} else {
    // Добавляем новую запись
    entries.append(HealthEntry(date: entryDate, text: entryText))
}
```

### **Удаление:**

**Принцип работы:**
1. При нажатии на "🗑️" запись удаляется из массива по ID
2. Данные автоматически сохраняются в UserDefaults

**Код:**
```swift
Button("🗑️") {
    entries.removeAll { $0.id == entry.id }
    onSave() // Сохраняем после удаления
}
```
