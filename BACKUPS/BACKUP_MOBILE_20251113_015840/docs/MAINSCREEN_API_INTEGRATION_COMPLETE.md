## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### API Endpoint:

```
GET /family/stats
```

### Response Model:

```swift
struct FamilyStatsResponse: Codable {
    let totalMembers: Int      // → familyMembers
    let totalDevices: Int       // → devicesProtected
    let totalThreats: Int       // → threatsBlocked
    let protectionLevel: Int    // (не используется пока)
}
```

### Логика работы:

1. **При инициализации ViewModel:**
   - Автоматически вызывает `loadDashboardData()`

2. **При открытии экрана (onAppear):**
   - Проверяет, прошло ли > 5 минут с последнего обновления
   - Если да — загружает данные из API
   - Если нет — пропускает (данные актуальны)

3. **При ошибке API:**
   - Сохраняет сообщение об ошибке в `errorMessage`
   - Использует дефолтные значения (fallback):
     - `familyMembers = 4`
     - `devicesProtected = 8`
     - `threatsBlocked = 47`

4. **Предотвращение дублирования:**
   - Проверка `isLoading` перед новым запросом
   - Логирование для отладки

## 🧪 ТЕСТИРОВАНИЕ

### Проверка работы:

1. **Откройте главный экран:**
   - Должна произойти загрузка данных из API
   - В консоли: `🔄 MainViewModel: Загружаем данные дашборда из API...`

2. **При успешной загрузке:**
   - В консоли: `✅ MainViewModel: Данные загружены успешно:`
   - Данные на карточке обновятся

3. **При ошибке API:**
   - В консоли: `❌ MainViewModel: Ошибка загрузки данных:`
   - Используются дефолтные значения

4. **Повторное открытие экрана:**
   - Если прошло < 5 минут — данные не обновляются
   - Если прошло > 5 минут — данные обновляются
