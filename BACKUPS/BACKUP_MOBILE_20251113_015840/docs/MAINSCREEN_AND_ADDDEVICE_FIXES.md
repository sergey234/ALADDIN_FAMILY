### 2. ✅ Исправлено зависание загрузки данных семьи

**Проблема:** На главном экране постоянно показывалось "Загрузка данных семьи..." и данные не обновлялись.

**Причина:** Если API не отвечает или отвечает медленно, `isLoading` остаётся `true` бесконечно.

**Решение:** Добавлен таймаут 5 секунд:
- Если запрос не успевает за 5 секунд, показываются fallback данные (4 члена, 8 устройств, 47 угроз)
- `isLoading` устанавливается в `false` после таймаута
- Показывается сообщение об ошибке: "Таймаут загрузки данных. Проверьте подключение к интернету."

**Файлы:**
- `ViewModels/MainViewModel.swift`

**Код:**
```swift
// ✅ ТАЙМАУТ: Если запрос не успевает за 5 секунд, показываем fallback данные
let timeoutWorkItem = DispatchWorkItem { [weak self] in
    // ... обработка таймаута
}
DispatchQueue.main.asyncAfter(deadline: .now() + 5.0, execute: timeoutWorkItem)
```

### 3. 📊 Почему показываются старые данные (4 члена, 8 устройств, 47 угроз)?

**Ответ:** Это **дефолтные значения (fallback)** в `MainViewModel.swift`:

```swift
@Published var familyMembers: Int = 4 // Дефолтное значение (fallback)
@Published var threatsBlocked: Int = 47 // Дефолтное значение (fallback)
@Published var devicesProtected: Int = 8 // Дефолтное значение (fallback)
```

**Когда показываются эти значения:**
1. ✅ При первой загрузке (до получения данных из API)
2. ✅ При ошибке API (сеть недоступна, сервер не отвечает)
3. ✅ При таймауте (запрос не успел за 5 секунд)

**Это нормально!** Приложение показывает fallback данные, чтобы пользователь видел интерфейс, даже если API недоступен.

**Чтобы увидеть реальные данные:**
- Убедитесь, что API сервер запущен и доступен
- Проверьте URL в `AppConfig.apiBaseURL`
- Проверьте подключение к интернету

### 4. 📱 Добавление устройства - работает ли это?

**Ответ:** ✅ **ДА, это РЕАЛЬНАЯ функция, не мок!**

**Как это работает:**
1. `AddDeviceView` использует `apiService.addDevice()` - это реальный API вызов
2. API endpoint: `POST /api/devices` (см. `AppConfig.Endpoint.devices`)
3. Отправляются данные: `name`, `type`, `owner`
4. При успехе показывается alert "Успех"
5. При ошибке показывается alert с описанием ошибки

**Файлы:**
- `Screens/20_DevicesScreen.swift` (AddDeviceView)
- `Core/Network/APIService.swift` (метод `addDevice`)

**Проверка:**
- Если API сервер не запущен или недоступен, будет ошибка при попытке добавить устройство
- Если API работает, устройство будет добавлено успешно
