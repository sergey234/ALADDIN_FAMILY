## 🟡 ЖЁЛТАЯ КАРТОЧКА "СЕМЬЯ"

### Что там написано:

1. **Заголовок:** "Семья" (или "ALADDIN FAMILY")
2. **Информация:**
   - "4 членов • 8 устройств" (количество членов семьи и устройств)
   - "Семейная защита активна" (статус защиты)
   - "47 угроз заблокировано" (количество заблокированных угроз)
3. **Кнопки:**
   - "Управление" (чёрная кнопка) — переход к управлению семьёй
   - "Добавить" (оранжевая кнопка с рамкой) — добавление нового члена семьи

---

## 🔄 ТУМБЛЕР ПЕРЕКЛЮЧЕНИЯ

### Для чего нужен:

**Тумблер** (`isFamilyProtectionEnabled`) — это переключатель для **включения/выключения семейной защиты**.

### Как работает:

- **Включено (ON):** Семейная защита активна — все члены семьи защищены
- **Выключено (OFF):** Семейная защита отключена — защита не работает

### Где находится:

- В правом верхнем углу жёлтой карточки "Семья"
- Визуально: оранжевый кружок справа = включено, чёрный кружок слева = выключено

### Технические детали:

```swift
@AppStorage("family_protection_enabled") private var isFamilyProtectionEnabled: Bool = true

Button(action: {
    isFamilyProtectionEnabled.toggle()
}) {
    // Тумблер UI
}
```

---

## 💡 ЗНАЧЕНИЕ

Тумблер позволяет пользователю быстро включить/выключить семейную защиту без перехода в настройки. Это удобно для временного отключения защиты (например, для тестирования или отладки).
