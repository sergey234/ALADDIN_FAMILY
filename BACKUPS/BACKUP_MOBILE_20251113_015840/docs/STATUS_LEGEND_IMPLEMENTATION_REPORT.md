**Файл:** `Components/ThreatProtectionCard.swift`

**Реализация:**

- Показывается под заголовком карточки, когда карточка развёрнута (`isExpanded == true`)
- Компактный текст (`.caption2`), цвет `.textTertiary`
- Плавная анимация появления/исчезновения

**Код:**
```swift
// ✅ ЛЕГЕНДА: Объяснение цветовых индикаторов
if isExpanded {
    Text(localizationManager.localized("protection_status_legend"))
        .font(.caption2)
        .foregroundColor(.textTertiary)
        .padding(.top, Spacing.xxs)
        .transition(.opacity.combined(with: .move(edge: .top)))
}
```

## 📊 ЛОГИКА РАБОТЫ ИНДИКАТОРОВ

### От чего зависят:

1. **Текущий тариф пользователя** (`TariffManager.shared.currentTariff`)
   - БАЗОВЫЙ, ПЕРСОНАЛЬНЫЙ, СЕМЕЙНЫЙ, ПРЕМИУМ

2. **Включена ли категория** (`ProtectionSettingsManager.shared.settings.isEnabled(category)`)
   - `true` / `false` для каждой категории

### Когда меняются:

- ✅ При покупке тарифа: 🔴 → 🟡 или 🟢 (если автоматически включается)
- ✅ При включении/выключении категории: 🟡 ↔ 🟢
- ✅ При понижении тарифа: 🟢/🟡 → 🔴 (если категория недоступна)

### Значение цветов:

| Цвет | Эмодзи | Доступна? | Включена? | Значение |
|------|--------|-----------|-----------|----------|
| 🔴 | 🔴 | ❌ Нет | ❌ | Нужен более высокий тариф |
| 🟡 | 🟡 | ✅ Да | ❌ | Доступна, но не включена |
| 🟢 | 🟢 | ✅ Да | ✅ | Доступна и включена (работает) |
