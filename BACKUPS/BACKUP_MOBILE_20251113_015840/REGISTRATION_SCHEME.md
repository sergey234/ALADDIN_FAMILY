# 📊 Схема регистрации ALADDIN

## 🎯 Процесс регистрации

### **Сценарий 1: Создатель семьи (Администратор)** 👨‍👩‍👧

```
📱 Главная → "Добавить члена семьи" → MainScreenWithRegistration

🔸 Шаг 1: Согласие (Consent)
   └─ "Даю согласие на обработку данных"

🔸 Шаг 2: Выбор роли
   └─ Родитель 👨‍👩‍👧 / Ребёнок 👶 / Дедушка/Бабушка 👴

🔸 Шаг 3: Выбор возраста
   └─ Малыш (0-3) / Ребёнок (4-12) / Подросток (13-17) 
   └─ Взрослый (18-64) / Пожилой (65+)

🔸 Шаг 4: Выбор буквы
   └─ A-Z (для идентификации)

🔸 Шаг 5: Создание семьи
   └─ API: POST /family/create
   
📊 РЕЗУЛЬТАТ:
   ✅ Family ID: FAM_A1B2C3D4E5F6
   ✅ Recovery Code: FAM-A1B2-C3D4-E5F6
   
📤 ЧТО ДЕЛАТЬ:
   1. Скопировать Recovery Code
   2. Поделиться с членами семьи
   3. Показать QR-код (создать из кода)
```
