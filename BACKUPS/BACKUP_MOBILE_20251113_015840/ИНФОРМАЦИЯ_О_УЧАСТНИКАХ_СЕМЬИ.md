# 👨‍👩‍👧‍👦 ИНФОРМАЦИЯ ОБ УЧАСТНИКАХ СЕМЬИ

## ✅ СОХРАНЕНИЕ УЧАСТНИКОВ:

### 1. **ГДЕ СОХРАНЯЮТСЯ:**

Все участники семьи сохраняются в **UserDefaults** с ключом `"family_members_list"`.

```swift
// Сохранение
UserDefaults.standard.set(encoded, forKey: "family_members_list")

// Загрузка
UserDefaults.standard.data(forKey: "family_members_list")
```

**Формат:** JSON (массив `FamilyMemberData`)

---

### 2. **КОГДА СОХРАНЯЮТСЯ:**

- ✅ Автоматически при каждом изменении списка участников
- ✅ При добавлении нового участника
- ✅ При загрузке экрана FamilyScreen
- ✅ После регистрации нового участника

**Функция:** `saveFamilyMembers()` вызывается автоматически

---

### 3. **СКОЛЬКО УЧАСТНИКОВ МОЖНО ДОБАВИТЬ:**

**Максимум: 10 участников** (до 10 человек)

```swift
// Кнопка "Добавить ещё" показывается только если:
if familyMembers.count < 10 && isUserParent {
    AddMoreMemberCard {
        showAddMemberModal = true
    }
}
```

**Ограничение:** `familyMembers.count < 10`

## 🎯 ОТВЕТЫ НА ВОПРОСЫ:

### ✅ **1. Будут ли сохраняться все добавленные участники?**

**ДА!** ✅ Все участники сохраняются автоматически в UserDefaults.

**Где:**
- UserDefaults ключ: `"family_members_list"`
- Формат: JSON массив
- Автоматическое сохранение при каждом изменении

---

### ✅ **2. Какие роли поддерживаются?**

**Все запрошенные роли поддерживаются:**

| Роль пользователя | Системная роль | Навигация |
|-------------------|---------------|-----------|
| Родитель | `.parent` | ParentalControlScreen |
| Мама | `.parent` | ParentalControlScreen |
| Папа | `.parent` | ParentalControlScreen |
| Дочь | `.child` или `.teenager` | ChildInterfaceScreen |
| Сын | `.child` или `.teenager` | ChildInterfaceScreen |
| Бабушка | `.elderly` | ElderlyInterfaceScreen |
| Дедушка | `.elderly` | ElderlyInterfaceScreen |

**Примечание:** 
- Мама и Папа = одна роль `.parent`
- Дочь и Сын = `.child` (маленькие) или `.teenager` (подростки)
- Бабушка и Дедушка = одна роль `.elderly`

---

### ✅ **3. Сколько членов семьи может сохранить?**

**Максимум: 10 участников** ✅

**Ограничение в коде:**
```swift
if familyMembers.count < 10 && isUserParent {
    // Кнопка "Добавить ещё" показывается
}
```

**Логика:**
- До 10 участников: можно добавлять
- 10 и больше: кнопка "Добавить ещё" скрывается
