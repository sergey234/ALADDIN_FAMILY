## 🚀 СЛЕДУЮЩИЕ ШАГИ

### **Для разработчика:**

1. **Установить зависимости:**
   ```bash
   cd /Users/sergejhlystov/ALADDIN_NEW/ALADDIN_NEW/mobile_apps/ALADDIN_iOS
   pod install
   ```

2. **Создать проект в Firebase:**
   - Открыть [Firebase Console](https://console.firebase.google.com/)
   - Создать проект "ALADDIN Family Security"
   - Добавить iOS приложение с Bundle ID: `com.aladdin.family`

3. **Добавить GoogleService-Info.plist:**
   - Скачать из Firebase Console
   - Добавить в Xcode проект
   - Убедиться, что добавлен в Target Membership

4. **Собрать проект:**
   - Открыть `.xcworkspace` (не `.xcodeproj`!)
   - Собрать проект (`Cmd + B`)
   - Проверить отсутствие ошибок

5. **Протестировать:**
   - Запустить приложение
   - Проверить логи Firebase в консоли
   - Отправить тестовый сбой (только для тестирования)

## 📝 ИСПОЛЬЗОВАНИЕ

### **Analytics:**

```swift
// Отслеживание экрана
AnalyticsManager.shared.trackScreen("Settings Screen")

// Отслеживание события
AnalyticsManager.shared.trackEvent("button_tapped", parameters: [
    "button_name": "subscribe"
])

// Установка User ID
AnalyticsManager.shared.setUserID("user123")
```

### **Crashlytics:**

```swift
// Логирование ошибки
do {
    try someOperation()
} catch {
    CrashReportingManager.shared.recordError(error)
}

// Логирование ошибки сети
CrashReportingManager.shared.recordNetworkError(
    error,
    endpoint: "/api/users",
    method: "GET"
)
```
