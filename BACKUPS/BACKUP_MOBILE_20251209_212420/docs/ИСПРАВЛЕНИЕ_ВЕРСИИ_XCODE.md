# ✅ ИСПРАВЛЕНИЕ ВЕРСИИ XCODE В WORKFLOW

**Дата:** 29 ноября 2025  
**Проблема:** Xcode 16.0 не найден на GitHub Actions  
**Решение:** ✅ Обновлено до Xcode 16.2.0

---

## 🐛 ПРОБЛЕМА

### Ошибка:

```
Error: Could not find Xcode version that satisfied version spec: '16.0'
```

### Доступные версии на GitHub Actions:

- ✅ **16.2.0** (GM) — `/Applications/Xcode_16.2.app`
- ✅ **16.1.0** (GM) — `/Applications/Xcode_16.1.app`
- ❌ **16.0** — не найдена

### Причина:

В workflow была указана версия `16.0`, которая не установлена на GitHub Actions runners.

---

## ✅ РЕШЕНИЕ

### Что исправлено:

1. **Обновлена версия Xcode** в `build-only.yml`:
   - Было: `'16.0'`
   - Стало: `'16.2.0'`

2. **Обновлена версия Xcode** в `appstore.yml`:
   - Было: `'16.0'`
   - Стало: `'16.2.0'`

### Изменения:

**Было:**
```yaml
- name: Setup Xcode
  uses: maxim-lobanov/setup-xcode@v1
  with:
    xcode-version: '16.0'  # Используем Xcode 16.0 для iOS 18 SDK
```

**Стало:**
```yaml
- name: Setup Xcode
  uses: maxim-lobanov/setup-xcode@v1
  with:
    xcode-version: '16.2.0'  # Используем Xcode 16.2.0 для iOS 18 SDK (доступна на GitHub Actions)
```
