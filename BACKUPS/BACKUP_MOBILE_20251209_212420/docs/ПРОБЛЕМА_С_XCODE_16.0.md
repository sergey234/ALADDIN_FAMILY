# ⚠️ ПРОБЛЕМА: Почему GitHub ругается на Xcode 16.0?

**Дата:** 30 ноября 2025  
**Вопрос:** Если мы работаем с appstore.yml, почему версия не та? Должна быть 16.2 и мы точно исправляли - почему GitHub ругается?

---

## ✅ ПОДТВЕРЖДЕНИЕ: appstore.yml правильный!

### Версия в appstore.yml: `16.2.0` ✅

```yaml
- name: Setup Xcode
  uses: maxim-lobanov/setup-xcode@v1
  with:
    xcode-version: '16.2.0'  # Используем Xcode 16.2.0 для iOS 18 SDK
```

**Статус:** ✅ Правильно, не менялась!

---

## ⚠️ ПРОБЛЕМА: Запустился НЕ appstore.yml!

### Что произошло:

**Запустился `build.yml` вместо `appstore.yml`!**

### Почему:

**appstore.yml** запускается только:
- ✅ При создании тега `v*`
- ✅ Вручную через GitHub UI
- ❌ **НЕ при push в master!**

**build.yml** запускался автоматически:
- ❌ При push в `main` или `master`
- ❌ С версией Xcode `16.0` (которая не существует)

---

## 📋 ТРИГГЕРЫ WORKFLOWS

### appstore.yml (правильный)

```yaml
on:
  workflow_dispatch:  # Вручную
  push:
    tags:
      - 'v*'  # Только при тегах
```

**Версия:** `16.2.0` ✅

---

### build.yml (старый, мешал)

**БЫЛО:**
```yaml
on:
  push:
    branches: [ main, master ]  # ← Автоматически при push!
  workflow_dispatch:
```

**СТАЛО:**
```yaml
on:
  # ОТКЛЮЧЕН автоматический запуск при push
  # push:
  #   branches: [ main, master ]
  workflow_dispatch:  # Только вручную
```

**Версия:** `16.0` → исправлено на `16.2.0`

---

## ✅ ЧТО ИСПРАВЛЕНО

1. **Отключен автоматический запуск build.yml**
   - Теперь не запускается при push в master
   - Не мешает appstore.yml

2. **Исправлена версия Xcode в build.yml**
   - Было: `16.0` (не существует)
   - Стало: `16.2.0` ✅

## 🎯 ВЫВОД

### appstore.yml НЕ менялся! ✅

- ✅ Версия всегда была `16.2.0`
- ✅ Правильный workflow
- ✅ Не запускается при push в master (только при тегах)

### Проблема была в build.yml

- ❌ Запускался автоматически при push в master

## ⚠️ ВАЖНО

**Если нужно загрузить в App Store:**

1. **Используйте ТОЛЬКО appstore.yml**
2. **Запускайте через тег:**
   ```bash
   git tag -a "v1.0.0" -m "Release"
   git push origin --tags
   ```
3. **Или вручную через GitHub UI**

**НЕ делайте просто `git push` - это запустит другие workflows!**
