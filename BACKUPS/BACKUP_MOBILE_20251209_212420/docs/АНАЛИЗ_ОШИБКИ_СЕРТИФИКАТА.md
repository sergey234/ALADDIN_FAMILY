# 🔍 АНАЛИЗ ОШИБКИ: Сертификат не найден в Provisioning Profile

**Дата:** 2 декабря 2024  
**Ошибка:** `Provisioning profile "ALADDIN App Store Distribution" doesn't include signing certificate "Apple Distribution: SERGEY KHLYSTOV (***)"`

---

## ✅ ПРОГРЕСС

**Старая ошибка:**
```
"ALADDIN" requires a provisioning profile. Select a provisioning profile in the Signing & Capabilities editor.
```

**Новая ошибка:**
```
Provisioning profile "ALADDIN App Store Distribution" doesn't include signing certificate "Apple Distribution: SERGEY KHLYSTOV (***)".
```

### Что это означает:

1. ✅ **Xcode теперь находит профили** - больше не "requires a provisioning profile"
2. ✅ **Manual signing работает** - Xcode видит профили и пытается их использовать
3. ✅ **Все настройки в project.pbxproj правильные** - CODE_SIGN_STYLE = Manual, CODE_SIGN_IDENTITY = Apple Distribution
4. ❌ **НО: Профили не содержат сертификат**, который мы пытаемся использовать

---

## 🔍 ПРОБЛЕМА

**Provisioning profiles не содержат сертификат "Apple Distribution: SERGEY KHLYSTOV (***)"**

Это означает, что:
- Либо профили были созданы с другим сертификатом
- Либо сертификат в keychain не совпадает с сертификатом в профилях
- Либо нужно проверить, какой сертификат действительно в профилях

---

## 🔍 ЧТО НУЖНО ПРОВЕРИТЬ

### 1. Какие сертификаты содержатся в профилях?

Нужно извлечь список сертификатов из профилей:
```bash
# Для App Profile
security cms -D -i "d2857d1f-a7a0-49b0-b803-c006d8ad053b.mobileprovision" | plutil -extract DeveloperCertificates raw -o - -

# Для Extension Profile
security cms -D -i "039a47c4-b057-4712-a90a-5bb21d9a500e.mobileprovision" | plutil -extract DeveloperCertificates raw -o - -
```

### 2. Какой сертификат установлен в keychain?

Нужно проверить, какой сертификат действительно установлен:
```bash
security find-identity -v -p codesigning
```

### 3. Совпадают ли они?

Если сертификаты не совпадают, нужно:
- Либо обновить профили с правильным сертификатом в Apple Developer Portal
- Либо использовать правильный сертификат (тот, который в профилях)

---

## ✅ РЕШЕНИЕ

### Вариант 1: Обновить профили (РЕКОМЕНДУЕТСЯ)

1. Зайдите в Apple Developer Portal: https://developer.apple.com/account/resources/profiles/list
2. Найдите профили:
   - "ALADDIN App Store Distribution" (UUID: d2857d1f-a7a0-49b0-b803-c006d8ad053b)
   - "ALADDINPacketTunnel App Store Distribution" (UUID: 039a47c4-b057-4712-a90a-5bb21d9a500e)
3. Убедитесь, что они связаны с сертификатом "Apple Distribution: SERGEY KHLYSTOV"
4. Если нет - отредактируйте профили и выберите правильный сертификат
5. Скачайте обновленные профили
6. Закодируйте в base64 и обновите GitHub Secrets

### Вариант 2: Использовать правильный сертификат

1. Проверьте, какой сертификат в профилях
2. Убедитесь, что этот сертификат установлен в keychain
3. Используйте этот сертификат вместо текущего
