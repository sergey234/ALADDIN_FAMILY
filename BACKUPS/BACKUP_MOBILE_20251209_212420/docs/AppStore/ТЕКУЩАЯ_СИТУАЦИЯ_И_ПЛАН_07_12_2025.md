## 📝 ПЛАН ДЕЙСТВИЙ

### ШАГ 1: Исправить уровни существующих подписок

1. Откройте подписку "ALADDIN Премиум"
2. Нажмите "Изменить уровень"
3. Измените уровень с 3 на **1** (самый высокий)
4. Сохраните

5. Откройте подписку "ALADDIN Семейный"
6. Уровень 2 оставьте как есть (это правильно)

### ШАГ 2: Создать подписку "Individual"

1. На странице группы нажмите **"+"** (плюс)
2. **Reference Name:** `Individual Subscription`
3. **Product ID:** `family.aladdin.ios.subscription.individual`
4. Нажмите **"Создать"**
5. **Уровень:** Выберите **3**
6. **Период:** 1 месяц
7. **Цена:** Установите цены
8. **Локализация:**
   - Русский: Display Name `Индивидуальный тариф`, Description `1 устройство, полная защита, AI помощник`
   - English: Display Name `Individual Plan`, Description `1 device, full protection, AI assistant`
9. Сохраните

### ШАГ 3: Создать подписку "Basic"

1. На странице группы нажмите **"+"** (плюс)
2. **Reference Name:** `Basic Subscription`
3. **Product ID:** `family.aladdin.ios.subscription.basic`
4. Нажмите **"Создать"**
5. **Уровень:** Выберите **4** (самый низкий)
6. **Период:** 1 месяц
7. **Цена:** Установите цены
8. **Локализация:**
   - Русский: Display Name `Базовый тариф`, Description `1 устройство, базовая защита`
   - English: Display Name `Basic Plan`, Description `1 device, basic protection`
9. Сохраните

### ШАГ 4: Заполнить метаданные для существующих подписок

После всех действий порядок должен быть:

1. **Уровень 1:** Premium (самый высокий)
2. **Уровень 2:** Family
3. **Уровень 3:** Individual
4. **Уровень 4:** Basic (самый низкий)

### ШАГ 6: Отправить первую подписку вместе с версией приложения

**ВАЖНО:** Первую подписку нужно отправить вместе с версией приложения!

1. Перейдите в раздел **"Версии приложения"** (App Versions)
2. Выберите текущую версию приложения
3. Найдите раздел **"In-App Purchases"** (Встроенные покупки)
4. Нажмите **"+"** (плюс)
5. Выберите подписку **"Premium"** (уровень 1 - самая высокая)
6. Сохраните
7. Заполните все обязательные поля версии (скриншоты, описание и т.д.)
8. Отправьте версию приложения на ревью

### ШАГ 7: После одобрения первой подписки

После того, как первая подписка (Premium) будет одобрена вместе с версией приложения:

1. Вернитесь в раздел подписок
2. Отправьте остальные 3 подписки на ревью отдельно:
   - Family
   - Individual
   - Basic

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### Порядок уровней критически важен!

Уровни определяют:
- Варианты обновления подписки (пользователь может перейти на более высокий уровень)
- Варианты отмены подписки (пользователь может перейти на более низкий уровень)

**Правильный порядок:**
- Уровень 1 = Premium (самый дорогой, больше всего функций)
- Уровень 2 = Family
- Уровень 3 = Individual
- Уровень 4 = Basic (самый дешевый, меньше всего функций)

### Метаданные обязательны!

Без метаданных (локализации) подписки не будут работать правильно. Обязательно заполните:
- Display Name (отображаемое имя)
- Description (описание)
- Минимум для русского и английского языков

### Первая подписка отправляется с версией!

Это важное требование Apple:
- Первую подписку нельзя отправить отдельно
- Она должна быть добавлена в версию приложения
- Версия приложения отправляется на ревью вместе с первой подпиской
