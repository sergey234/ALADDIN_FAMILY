## 5. ⚠️ UIBACKGROUNDMODES LOCATION

### 📝 ЗАПРОС APPLE:
"Приложение объявляет поддержку location в UIBackgroundModes, но мы не можем найти никаких функций, которые требуют постоянного местоположения. Apps that declare support for location in the UIBackgroundModes key must have features that require persistent location."

### 🔍 НА ЧТО КОНКРЕТНО РУГАЕТСЯ APPLE:

**Проблема Apple:**
- В `Info.plist` была строка `<string>location</string>` в секции `UIBackgroundModes`
- Это означает, что приложение хочет отслеживать местоположение **постоянно в фоне** (persistent location updates)
- Persistent location = обновления каждую секунду, даже когда приложение закрыто
- Apple требует, чтобы если вы заявляете о persistent location, у вас ДОЛЖНА быть функция, которая это использует

**Что такое persistent location:**
- Постоянное отслеживание GPS каждую секунду
- Работает даже когда приложение закрыто
- Сильно разряжает батарею
- Используется для навигации, фитнес-трекеров

**Что у нас есть:**
- Родительский контроль с отслеживанием местоположения детей
- Геозоны (дом, школа, секция)
- История перемещений
- SOS-кнопка

**НО:** Мы НЕ используем persistent location (постоянное отслеживание каждую секунду)!

### 🔧 ЧТО МЫ СДЕЛАЛИ:

**1. Удалили location из UIBackgroundModes:**
- Удалили строку `<string>location</string>` из `Info.plist`
