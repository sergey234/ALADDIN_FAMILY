## 🚀 КАК РАБОТАЕТ GITHUB ACTIONS ПРИ СБОРКЕ IPA:

### Процесс сборки:

1. **Git Checkout:**
   ```bash
   git checkout <commit>
   ```
   - GitHub Actions клонирует репозиторий из Git
   - Получает все файлы, которые в Git
   - Если файл не в Git → его не будет в сборке

2. **Xcode Build:**
   ```bash
   xcodebuild -workspace ALADDIN.xcworkspace -scheme ALADDIN archive
   ```
   - Компилирует все файлы из проекта
   - Использует `Info.plist` из Git
   - Использует все Swift файлы из Git
   - Если файл не в Git → ошибка компиляции

3. **Export IPA:**
   ```bash
   xcodebuild -exportArchive -archivePath ... -exportPath ...
   ```
   - Создаёт IPA файл
   - Включает все скомпилированные файлы
   - Использует настройки из `Info.plist`

### Что происходит с нашими исправлениями:

**✅ Автоматически применяются:**
- `Info.plist` изменения (UIBackgroundModes, HealthKit) → применяются автоматически
- `ShareSheet.swift` → компилируется автоматически
- Все Swift файлы → компилируются автоматически
- Privacy Policy в приложении → включается в IPA автоматически

**⚠️ НЕ применяются автоматически:**
- Ответы для Apple → нужно скопировать в App Store Connect вручную
- Демо QR-код → нужно загрузить в App Store Connect вручную
- Age Rating → нужно изменить в App Store Connect вручную
