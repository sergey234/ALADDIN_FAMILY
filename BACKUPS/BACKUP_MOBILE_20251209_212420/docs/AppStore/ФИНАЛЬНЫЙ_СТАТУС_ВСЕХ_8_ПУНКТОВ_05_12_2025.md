## 🔍 КАК РАБОТАЕТ GITHUB ACTIONS ПРИ СБОРКЕ IPA:

### Процесс сборки (как в коммите #179):

**1. Git Checkout:**
```bash
git checkout <commit>
```
- GitHub Actions клонирует репозиторий из Git
- Получает ВСЕ файлы, которые в Git
- Если файл не в Git → его НЕ будет в сборке ❌

**2. Xcode Build:**
```bash
xcodebuild -workspace ALADDIN.xcworkspace -scheme ALADDIN archive
```
- Компилирует все файлы из проекта
- Использует `Info.plist` из Git
- Использует все Swift файлы из Git
- Если файл не в Git → ошибка компиляции: `Cannot find 'ShareSheet' in scope` ❌

**3. Export IPA:**
```bash
xcodebuild -exportArchive -archivePath ... -exportPath ...
```
- Создаёт IPA файл
- Включает все скомпилированные файлы
- Использует настройки из `Info.plist`
