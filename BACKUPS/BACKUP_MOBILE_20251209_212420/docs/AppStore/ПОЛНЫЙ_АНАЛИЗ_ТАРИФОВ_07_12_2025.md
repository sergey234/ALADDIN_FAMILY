### 3. Маппинг в TariffsViewModel:

```swift
let mapping: [String: StoreManager.ProductID] = [
    "TariffsScreen.TariffType.free": .basic,
    "TariffsScreen.TariffType.personal": .individual,
    "TariffsScreen.TariffType.family": .family,
    "TariffsScreen.TariffType.premium": .premium,
]
```

**Важно:** `free` мапится на `basic`!

### 4. Как загружаются тарифы:

```swift
private func updateTariffs(from products: [Product]) {
    tariffs = StoreManager.ProductID.allCases.compactMap { productID in
        guard let product = products.first(where: { $0.id == productID.rawValue }) else {
            return nil
        }
        // Создает Tariff из Product
    }
}
```

**Критично:** Код использует `StoreManager.ProductID.allCases`, что означает:
- Все 4 ProductID (basic, individual, family, premium) должны существовать в App Store Connect
- Если какого-то ProductID нет - тариф не загрузится

## ⚠️ ВАЖНО: ПРО BASIC

### Почему Basic нужен:

1. **Код использует `StoreManager.ProductID.allCases`**
   - Это означает, что код пытается загрузить ВСЕ 4 подписки
   - Если Basic нет - будет ошибка или тариф не загрузится

2. **Маппинг `free` → `basic`**
   - В коде есть маппинг: `"free": .basic`
   - Это означает, что free тариф технически связан с basic подпиской

3. **Логика работы:**
   - Free тариф показывается в UI как бесплатный
   - Но в StoreManager есть basic ProductID
   - Если basic нет в App Store Connect - код может не работать

### Решение для Basic:

**Вариант 1 (рекомендуется):** Создать Basic с минимальной ценой
- Product ID: `family.aladdin.ios.subscription.basic`
- Цена: 1 рубль (или минимальная для вашей страны)
- Уровень: 4 (самый низкий)
- В UI free тариф остается бесплатным, но технически связан с basic подпиской

**Вариант 2:** Если Basic действительно должен быть бесплатным
- Все равно создать подписку с минимальной ценой (1 рубль)
- В приложении free тариф остается бесплатным для пользователя
- Технически это будет минимальная платная подписка
