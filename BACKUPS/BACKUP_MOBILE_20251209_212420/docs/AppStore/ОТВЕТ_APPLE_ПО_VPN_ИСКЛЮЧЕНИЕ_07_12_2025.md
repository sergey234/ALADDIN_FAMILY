---

## 🇬🇧 АНГЛИЙСКИЙ ВАРИАНТ (ОРИГИНАЛ)

```
Our app is primarily a parental control and family safety application. 

VPN functionality is a secondary security feature, not the main purpose 
of the app. The app's primary features are:

- Parental control (location tracking, app blocking, screen time)

- Family safety monitoring

- Threat detection and alerts

VPN is provided as an additional security layer, similar to how many 
parental control apps include VPN as a supplementary feature.

We request an exception to Guideline 5.4, as VPN is not the primary 
function of our application.
```

Мы просим исключение из Руководства 5.4, так как VPN не является 
основной функцией нашего приложения.

## 📊 АНАЛИЗ ВОЗМОЖНОСТИ ИСКЛЮЧЕНИЯ

### Результаты поиска информации:

**❌ Конкретных примеров успешных исключений не найдено:**
- На форумах Apple Developer нет публичных примеров успешных исключений из Guideline 5.4
- Apple обычно строго применяет правило 5.4 для VPN приложений
- Большинство разработчиков создают корпоративные аккаунты

**⚠️ Важные факты:**
- Apple удаляет VPN приложения, отправленные с личных аккаунтов
- Правило 5.4 применяется даже если VPN - не основная функция
- Исключения крайне редки

**✅ Положительные факторы для вашего случая:**
1. VPN действительно не основная функция (родительский контроль - основная)
2. Многие приложения родительского контроля включают VPN
3. Приложение соответствует другим требованиям Apple
