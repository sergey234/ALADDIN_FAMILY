Тема: Реализация In-App Purchase - Соответствие Guideline 3.1.1

Уважаемая команда App Review,

Мы реализовали In-App Purchase для полного соответствия Guideline 3.1.1, создав модель, которая сочетает требования App Store с гибкостью мультиплатформенных сервисов.

1. ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

Фреймворк и архитектура:

- StoreKit 2 (современный стандарт Apple)
- Файл реализации: StoreManager.swift
- Функциональность: Покупка, восстановление, проверка подписок полностью реализованы

Архитектура:

StoreManager (StoreKit 2)
├── Product Loading → Product.products(for: productIDs)
├── Purchase Flow → product.purchase()
├── Transaction Verification → checkVerified(verification)
└── Subscription Management → Transaction.currentEntitlements

Зарегистрированные Product IDs в App Store Connect:

- family.aladdin.ios.subscription.basic.v2 - Базовый тариф
- family.aladdin.ios.subscription.individual.v2 - Индивидуальный тариф
- family.aladdin.ios.subscription.family - Семейный тариф
- family.aladdin.ios.subscription.premium - Премиум тариф

Настройки подписок:

- Тип: Auto-Renewable Subscription
- Период: 1 месяц
- Цены: Настроены для всех стран
- Статус: Отправлены на ревью Apple

2. МОДЕЛЬ ОПЛАТЫ

Двухканальная система:

Основной канал - IAP в приложении:

- Все 4 подписки доступны для покупки через IAP
- Прямая интеграция с App Store
- Автоматическое управление подпиской
- Стандартный пользовательский опыт Apple

Дополнительный канал - Мультиплатформенная активация:

- Пользователи могут купить подписку на сайте
- Активировать в приложении через код активации
- Те же подписки доступны через IAP
- Одинаковый доступ к функциям

Преимущества модели:

- Полное соответствие Guideline 3.1.1 (все подписки доступны через IAP)
- Соответствие Guideline 3.1.3(b) (мультиплатформенные сервисы)
- Гибкость для пользователей (выбор способа оплаты)
- Масштабируемость (легко добавить новые платформы)

3. СООТВЕТСТВИЕ ТРЕБОВАНИЯМ

Guideline 3.1.1:

- Все подписки, доступные на сайте, доступны для покупки через IAP в приложении
- Пользователи могут приобретать подписки непосредственно в приложении через App Store
- IAP является основным способом оплаты в приложении

Guideline 3.1.3(b) - Мультиплатформенные сервисы:

- Приложение работает на нескольких платформах (iOS, веб-сайт)
- Пользователи могут купить подписку на сайте и активировать в приложении через код активации
- Те же подписки доступны для покупки через IAP в приложении
- Оба способа предоставляют одинаковый доступ к функциям

Код активации:

- Используется только для активации уже оплаченной подписки, купленной на сайте
- Не используется для совершения покупки через приложение
- Соответствует Guideline 3.1.3(b) для мультиплатформенных сервисов

4. РЕАЛИЗОВАННЫЕ СПОСОБЫ ОПЛАТЫ

Приложение поддерживает два способа активации подписки:

Способ 1: Покупка через IAP
- Выбор тарифа в приложении
- Оплата через App Store
- Автоматическая активация подписки после успешной транзакции

Способ 2: Активация подписки, купленной на сайте
- Покупка подписки на веб-сайте aladdin-ai.ru
- Получение кода активации после оплаты
- Ввод кода в приложении через экран активации
- Активация подписки после проверки кода на сервере

Технические детали:

- Оба способа предоставляют одинаковый доступ к функциям приложения
- Статус подписки синхронизируется между платформами
- Код активации используется только для активации уже оплаченной подписки

5. СООТВЕТСТВИЕ ТРЕБОВАНИЯМ APP STORE

- Все подписки доступны для покупки через IAP в приложении
- IAP является основным способом оплаты в приложении
- Код активации используется только для мультиплатформенных сервисов согласно Guideline 3.1.3(b)

6. ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

Обработка IAP транзакций:

- Использование StoreKit 2 для загрузки продуктов и обработки покупок
- Верификация транзакций через checkVerified(verification)
- Обработка состояний: success, cancelled, pending
- Автоматическое обновление статуса подписки через Transaction.currentEntitlements

Активация кода:

- Проверка кода активации через API endpoint /subscription/activate
- Верификация кода на сервере перед активацией
- Синхронизация статуса подписки между iOS и веб-платформой
