# 📱 ПОШАГОВАЯ ИНСТРУКЦИЯ: Создание подписок в App Store Connect

## ✅ ПРАВИЛЬНЫЙ ПУТЬ:

```
App Store Connect
  → Мои приложения
    → ALADDIN
      → Монетизация (в левом меню)
        → Подписки (Subscriptions)
```

**НЕ "Встроенные покупки", а именно "Подписки"!**

---

## 📍 Шаг 1: Зайти в раздел "Подписки"

1. Откройте: https://appstoreconnect.apple.com
2. Войдите с Apple ID разработчика
3. Нажмите **"Мои приложения"** (My Apps)
4. Выберите приложение **"ALADDIN"**
5. В левом меню найдите **"Монетизация"**
6. Нажмите на **"Монетизация"**
7. В списке нажмите **"Подписки"** (Subscriptions)

---

## 📍 Шаг 2: Создать Группу подписок

1. На странице "Подписки" найдите раздел **"Группы подписок"** (Subscription Groups)
2. Нажмите кнопку **"Создать"** (Create)
3. В поле **"Reference Name"** (Название группы) введите:
   ```
   ALADDIN Subscriptions
   ```
4. Нажмите **"Создать"** (Create)

**✅ Группа создана!** Теперь можно создавать подписки внутри этой группы.

---

## 📍 Шаг 3: Создать первую подписку (Basic)

1. После создания группы найдите раздел **"Подписки с автоматическим продлением"** (Auto-Renewable Subscriptions)
2. В созданной группе "ALADDIN Subscriptions" нажмите кнопку **"Создать"** (Create)
3. Заполните форму:

   **Product ID:** (вводите точно, без пробелов, с точками)
   ```
   family.aladdin.ios.subscription.basic
   ```

   **Reference Name:** (название для вас, можно на русском)
   ```
   ALADDIN Basic Subscription
   ```

4. Нажмите **"Создать"** (Create)

---

## 📍 Шаг 4: Настроить первую подписку (Basic)

### 4.1. Базовая информация:

1. **Subscription Duration (Длительность подписки):**
   - Выберите: **1 Month** (1 месяц)

2. **Price (Цена):**
   - Нажмите на кнопку **"Edit"** (Редактировать) рядом с ценой
   - Выберите цену для каждого региона
   - Или выберите **"Auto"** (автоматическая цена)
   - Нажмите **"Save"** (Сохранить)

### 4.2. Локализация (Display Name и Description):

1. Найдите раздел **"Localizations"** (Локализация)
2. Нажмите **"Add Localization"** (Добавить локализацию)

3. Выберите язык: **English (U.S.)** или **Russian**

4. Заполните:

   **Display Name:** (Отображаемое название)
   ```
   ALADDIN Basic
   ```

   **Description:** (Описание)
   ```
   1 устройство, базовая защита
   ```

5. Нажмите **"Save"** (Сохранить)

### 4.3. Сохранить подписку:

1. Прокрутите страницу вниз
2. Нажмите кнопку **"Save"** (Сохранить) вверху справа

**✅ Первая подписка создана!**

---

## 📍 Шаг 5: Создать вторую подписку (Individual)

1. Вернитесь к списку подписок (нажмите "Подписки" в левом меню)
2. В разделе "Подписки с автоматическим продлением" найдите группу "ALADDIN Subscriptions"
3. Внутри группы нажмите кнопку **"Создать"** (Create)

4. Заполните:

   **Product ID:**
   ```
   family.aladdin.ios.subscription.individual
   ```

   **Reference Name:**
   ```
   ALADDIN Individual Subscription
   ```

5. Настройте:
   - **Duration:** 1 Month
   - **Price:** Выберите цену
   - **Display Name:** `ALADDIN Individual`
   - **Description:** `1 устройство, полная защита, AI помощник`

6. Нажмите **"Save"**

---

## 📍 Шаг 6: Создать третью подписку (Family)

1. В той же группе "ALADDIN Subscriptions" нажмите **"Создать"**

2. Заполните:

   **Product ID:**
   ```
   family.aladdin.ios.subscription.family
   ```

   **Reference Name:**
   ```
   ALADDIN Family Subscription
   ```

3. Настройте:
   - **Duration:** 1 Month
   - **Price:** Выберите цену
   - **Display Name:** `ALADDIN Family`
   - **Description:** `До 5 устройств, родительский контроль`

4. Нажмите **"Save"**

---

## 📍 Шаг 7: Создать четвертую подписку (Premium)

1. В той же группе "ALADDIN Subscriptions" нажмите **"Создать"**

2. Заполните:

   **Product ID:**
   ```
   family.aladdin.ios.subscription.premium
   ```

   **Reference Name:**
   ```
   ALADDIN Premium Subscription
   ```

3. Настройте:
   - **Duration:** 1 Month
   - **Price:** Выберите цену
   - **Display Name:** `ALADDIN Premium`
   - **Description:** `До 10 устройств, все функции, приоритетная поддержка`

4. Нажмите **"Save"**

---

## 📍 Шаг 8: Настроить льготный период (опционально)

1. В разделе "Льготный платежный период" (Grace Period) нажмите **"Редактировать"** (Edit)
2. Установите:
   - **Продолжительность льготного периода:** 28 дней (рекомендуется)
   - **Правомочные подписчики:** Все продления

3. Нажмите **"Save"**

---

## 📍 Шаг 9: Включить оптимизированный интерфейс (рекомендуется)

1. В разделе "Оптимизированный интерфейс для покупок" убедитесь, что включено:
   - **Включено** (On)

Это позволит пользователям покупать подписки прямо в App Store.

---

## 📍 Шаг 10: Отправить подписки на проверку

**⚠️ ВАЖНО:** Первую подписку нужно отправить вместе с версией приложения!

1. Создайте новую версию приложения (1.0.1 или выше)
2. Загрузите бинарный файл (IPA)
3. В разделе версии приложения найдите **"Встроенные покупки и подписки"** (In-App Purchases and Subscriptions)
4. Выберите созданные подписки (все 4)
5. Отправьте версию приложения на проверку

**После одобрения первой версии:**
- Вы сможете отправлять дополнительные подписки отдельно из раздела "Подписки"
