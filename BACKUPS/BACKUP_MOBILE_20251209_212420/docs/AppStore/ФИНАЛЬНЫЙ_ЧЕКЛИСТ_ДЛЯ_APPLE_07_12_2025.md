## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### Порядок уровней критически важен!

Уровни определяют:
- Варианты обновления подписки (пользователь может перейти на более высокий уровень)
- Варианты отмены подписки (пользователь может перейти на более низкий уровень)

**Правильный порядок:**
- Уровень 1 = Premium (самый дорогой, больше всего функций)
- Уровень 2 = Family
- Уровень 3 = Individual
- Уровень 4 = Basic (самый дешевый, меньше всего функций)

### Метаданные обязательны!

Без метаданных (локализации) подписки не будут работать правильно. Обязательно заполните:
- Display Name (отображаемое имя)
- Description (описание)
- Минимум для русского и английского языков

### Первая подписка отправляется с версией!

Это важное требование Apple:
- Первую подписку нельзя отправить отдельно
- Она должна быть добавлена в версию приложения
- Версия приложения отправляется на ревью вместе с первой подпиской
