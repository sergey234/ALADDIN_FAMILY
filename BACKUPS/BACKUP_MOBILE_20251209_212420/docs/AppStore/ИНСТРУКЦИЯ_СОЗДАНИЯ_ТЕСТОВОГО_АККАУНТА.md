# 👤 ИНСТРУКЦИЯ: СОЗДАНИЕ ТЕСТОВОГО АККАУНТА ДЛЯ REVIEW NOTES

**Дата:** 02.12.2024  
**Время выполнения:** ~15 минут

---

## 🎯 ЦЕЛЬ

Создать тестовый аккаунт для Review Notes в App Store Connect, чтобы ревьюеры Apple могли протестировать приложение.

---

## 📱 ШАГИ

### Шаг 1: Запустить приложение

1. Открыть проект в Xcode
2. Выбрать устройство или симулятор (рекомендуется реальное устройство)
3. Нажать **Run** (⌘R) или **Product → Run**

### Шаг 2: Пройти онбординг (если требуется)

- Если приложение показывает онбординг, пройти его
- Если онбординг уже пройден, перейти к следующему шагу

### Шаг 3: Создать новую семью

1. Открыть **Family Screen** (экран семьи)
2. Нажать кнопку **"Добавить участника"** или **"Добавить члена семьи"**
3. В появившемся модальном окне выбрать **"Создать новую семью"**

### Шаг 4: Выбрать роль

1. В модальном окне **RoleSelectionModal** выбрать:
   - **Родитель** 👨‍👩‍👧 (Parent)
   - Это роль администратора семьи

### Шаг 5: Выбрать возраст

1. В модальном окне **AgeGroupModal** выбрать:
   - **Взрослый (18-64)** (Adult)

### Шаг 6: Выбрать букву

1. В модальном окне **LetterModal** выбрать любую букву (A-Z)
   - Это для идентификации в семье

### Шаг 7: Получить Recovery Code

1. После создания семьи появится модальное окно **RecoveryCodeModal**
2. **ВАЖНО:** Записать **Recovery Code** в формате:
   ```
   FAM-XXXX-XXXX-XXXX
   ```
3. Скопировать код или сделать скриншот

### Шаг 8: Сохранить данные для Review Notes

**Записать следующую информацию:**

```
Тестовый аккаунт для Review Notes:

1. Recovery Code: FAM-XXXX-XXXX-XXXX
   (заменить XXXX на реальный код)

2. Роль: Родитель (Parent)

3. Возраст: Взрослый (18-64)

4. Тестовый код активации: ALDN-TEST-1234
   (разблокирует Premium тариф для ревью)
```

## 📝 ТЕКСТ ДЛЯ REVIEW NOTES

После создания аккаунта, добавить в Review Notes:

```
Test Account for Review:

1. Recovery Code: FAM-XXXX-XXXX-XXXX
   (Use this code to join the family or recover access)

2. Role: Parent (Administrator)

3. Age Group: Adult (18-64)

4. Test Activation Code: ALDN-TEST-1234
   (Unlocks Premium plan for 24 hours for review purposes)

How to use:
- Open app → Family Screen → "Add Member" → "Join by Code"
- Enter Recovery Code to join the family
- Go to Tariffs → Enter Activation Code: ALDN-TEST-1234
- Premium features will be unlocked for testing
```

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Recovery Code** - это основной способ доступа к семье
2. **Activation Code** (ALDN-TEST-1234) - это код для активации Premium тарифа
3. Оба кода нужно указать в Review Notes
4. Если код потерян, можно создать новую семью
