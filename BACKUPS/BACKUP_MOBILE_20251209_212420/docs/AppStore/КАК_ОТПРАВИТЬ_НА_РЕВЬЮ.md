# 🚀 КАК ОТПРАВИТЬ ПРИЛОЖЕНИЕ НА РЕВЬЮ

**Проблема:** Нужно найти кнопку "Submit for Review" в App Store Connect.

**Решение:** Кнопка находится в разделе Version Information, в правом верхнем углу страницы.

---

## 📍 ШАГ 1: ПЕРЕЙТИ В VERSION INFORMATION

### Прямая ссылка:
```
https://appstoreconnect.apple.com/apps/6755897079/appstore/ios/version/info
```

### Или через меню:
1. **App Store Connect** → **My Apps**
2. Выберите приложение **ALADDIN X AI**
3. Вкладка **App Store**
4. Версия **1.0 Prepare for Submission**
5. Откроется страница **"Version Information"**

---

## 📍 ШАГ 2: НАЙТИ КНОПКУ "SUBMIT FOR REVIEW"

### Где находится кнопка:

1. **В правом верхнем углу страницы** (рядом с кнопкой "Сохранить")
2. **Или внизу страницы** (после всех разделов)
3. **Или в разделе "Подготовка к отправке"** (если есть)

### Как выглядит кнопка:

- **Текст:** "Submit for Review" (Отправить на проверку)
- **Цвет:** Синяя кнопка
- **Расположение:** Правая часть страницы

---

## 📍 ШАГ 3: ПРОВЕРИТЬ ПЕРЕД ОТПРАВКОЙ

### Перед нажатием "Submit for Review" убедитесь:

- [ ] **Билд выбран:** В разделе "Сборка" должен быть выбран билд 1.0.0 (3)
- [ ] **Права на контент указаны:** App Information → Права на контент
- [ ] **Политика конфиденциальности опубликована:** App Privacy → Published
- [ ] **Цена установлена:** Pricing and Availability → Price → Free
- [ ] **Доступность настроена:** Pricing and Availability → Availability → Все страны
- [ ] **Иконка загружена:** Version Information → Иконка приложения
- [ ] **Скриншоты загружены:** Version Information → Скриншоты (8 шт)
- [ ] **Описание заполнено:** Version Information → Описание
- [ ] **Review Notes заполнены:** Review Information → Review Notes
- [ ] **Контактная информация указана:** Review Information → Контакты

---

## 📍 ШАГ 4: ОТПРАВИТЬ НА РЕВЬЮ

### Действия:

1. **Прокрутите страницу вниз** (если кнопка не видна вверху)
2. **Найдите кнопку "Submit for Review"** (синяя кнопка справа)
3. **Нажмите на кнопку**
4. **Подтвердите отправку:**
   - Появится окно подтверждения
   - Проверьте все пункты
   - Нажмите "Submit" или "Отправить"
5. **Дождитесь подтверждения:**
   - Появится сообщение об успешной отправке
   - Статус изменится на "Waiting for Review" (Ожидает проверки)

## ⚠️ ЕСЛИ КНОПКА НЕ ВИДНА

### Проблема 1: Кнопка неактивна (серая)

**Причины:**
- Не все обязательные поля заполнены
- Билд не выбран
- Есть ошибки валидации

**Решение:**
1. Проверьте раздел "Подготовка к отправке" (Prepare for Submission)
2. Найдите красные предупреждения или ошибки
3. Исправьте все ошибки
4. Обновите страницу (F5 или Cmd+R)
5. Кнопка станет активной

### Проблема 2: Кнопка отсутствует

**Причины:**
- Версия уже отправлена на ревью
- Версия уже одобрена
- Нет прав для отправки

**Решение:**
1. Проверьте статус версии:
   - **"Waiting for Review"** - уже отправлена
   - **"In Review"** - на проверке
   - **"Ready to Submit"** - готова к отправке
2. Если версия уже отправлена, дождитесь результата ревью
3. Если нет прав, обратитесь к администратору аккаунта

### Проблема 3: Ошибки валидации

**Решение:**
1. Прокрутите страницу вверх
2. Найдите раздел "Подготовка к отправке" (Prepare for Submission)
3. Проверьте список ошибок:
   - **Красные предупреждения** - нужно исправить
   - **Желтые предупреждения** - можно игнорировать (но лучше исправить)
4. Исправьте все ошибки
5. Обновите страницу
6. Кнопка появится
