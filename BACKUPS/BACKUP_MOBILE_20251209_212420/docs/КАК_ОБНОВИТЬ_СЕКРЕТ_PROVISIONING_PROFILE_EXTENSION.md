## 🎯 ЧТО НУЖНО СДЕЛАТЬ

Обновить секрет `PROVISIONING_PROFILE_EXTENSION` в GitHub, чтобы сборка работала правильно.

---

## 📝 ПОШАГОВАЯ ИНСТРУКЦИЯ

### ШАГ 1: Откройте страницу с секретами

**Прямая ссылка:**
https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions

**Или:**
1. Откройте: https://github.com/sergey234/ALADDIN_FAMILY
2. Нажмите на вкладку **"Settings"** (вверху справа)
3. В левом меню найдите **"Secrets and variables"**
4. Нажмите на **"Actions"**
5. Откроется страница со всеми секретами

---

### ШАГ 2: Найдите секрет PROVISIONING_PROFILE_EXTENSION

**На странице со секретами:**

1. **Прокрутите страницу вниз** (если нужно)

2. **Найдите секрет с названием:**
   ```
   PROVISIONING_PROFILE_EXTENSION
   ```

3. **Рядом с названием будет кнопка:**
   - **"Update"** (если секрет уже существует)
   - Или просто пустое место (если секрета нет)

---

### ШАГ 3: Нажмите "Update" (или "New repository secret")

**Если секрет УЖЕ ЕСТЬ:**
- Нажмите на кнопку **"Update"** справа от названия секрета

**Если секрета НЕТ:**
- Нажмите на кнопку **"New repository secret"** (вверху справа)
- В поле "Name" введите: `PROVISIONING_PROFILE_EXTENSION`

---

### ШАГ 4: Скопируйте содержимое файла

**В терминале выполните команду:**
```bash
cat ~/Desktop/ALADDIN_Profiles/extension_profile_base64.txt | pbcopy
```

**Что происходит:**
- Команда читает файл с исправленным base64
- Копирует его содержимое в буфер обмена (как Cmd+C)
- Теперь содержимое готово для вставки

**Или вручную:**
1. Откройте файл: `~/Desktop/ALADDIN_Profiles/extension_profile_base64.txt`
2. Выделите всё (Cmd+A)
3. Скопируйте (Cmd+C)

---

### ШАГ 5: Вставьте в поле "Secret"

**В окне GitHub:**

1. **Найдите большое текстовое поле:**
   - Название: "Secret" или "Value"
   - Это поле для вставки содержимого

2. **Очистите поле** (если там что-то есть):
   - Выделите всё (Cmd+A)
   - Удалите (Delete)

3. **Вставьте содержимое:**
   - Нажмите **Cmd+V** (Mac) или **Ctrl+V** (Windows)
   - Вставится длинная строка base64 (без переносов)

4. **Проверьте:**
   - Должна быть одна длинная строка
   - Без переносов строк
   - Начинается с букв/цифр (например, "MII8YwYJ...")

---

### ШАГ 6: Сохраните

1. **Нажмите кнопку:**
   - **"Update secret"** (если обновляли)
   - **"Add secret"** (если создавали новый)

2. **Подтвердите** (если спросят)

3. **Готово!** Секрет обновлён

---

## ✅ ПРОВЕРКА

**После сохранения:**

1. **Вернитесь на страницу секретов**
2. **Найдите `PROVISIONING_PROFILE_EXTENSION`**

   - "Updated X minutes ago" (или "Created X minutes ago")
   - Кнопка "Update" доступна

**Если всё так** → ✅ Секрет обновлён правильно!
