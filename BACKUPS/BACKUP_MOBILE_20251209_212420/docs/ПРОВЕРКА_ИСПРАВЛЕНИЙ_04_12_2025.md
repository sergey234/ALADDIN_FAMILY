## 🔒 ИСПРАВЛЕНИЯ БЕЗОПАСНОСТИ

### **1. Исправлено логирование endpoint в NetworkManager**

**Проблема:**
- Раньше логировался полный URL с query параметрами: `request.url?.absoluteString`
- Это могло содержать токены или чувствительные данные в URL

**Исправление:**
- Теперь логируется только путь: `request.url?.path`
- Query параметры не логируются

**Файл:** `Core/Network/NetworkManager.swift`

**Строки:**
- 396: `let endpoint = request.url?.path ?? "unknown"` ✅
- 468: `let endpoint = request.url?.path ?? "unknown"` ✅
- 488: `let endpoint = request.url?.path ?? "unknown"` ✅
