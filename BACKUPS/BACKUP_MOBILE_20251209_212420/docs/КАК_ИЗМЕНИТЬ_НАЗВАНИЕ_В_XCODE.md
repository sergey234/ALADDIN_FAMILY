# 📝 КАК ИЗМЕНИТЬ НАЗВАНИЕ В XCODE ДЛЯ ВАЛИДАЦИИ

**Вопрос:** Как вставить новое название в Archive, чтобы пройти валидацию?

---

## 🎯 ОТВЕТ: ИЗМЕНИТЬ DISPLAY NAME В XCODE

**Важно понимать:**
- ✅ Название в App Store Connect — это отдельное поле
- ✅ Display Name в Xcode — это имя приложения на устройстве
- ✅ Для валидации нужно, чтобы Display Name совпадал с названием в App Store Connect (или был пустым)

---

## 📋 ШАГИ: КАК ИЗМЕНИТЬ НАЗВАНИЕ

### Шаг 1: Открыть проект в Xcode

1. Откройте **ALADDIN.xcworkspace** (не .xcodeproj!)
2. Дождитесь загрузки проекта

### Шаг 2: Найти настройки Display Name

1. В навигаторе слева найдите **проект** (самый верхний элемент)
2. Кликните на **проект** (синяя иконка)
3. В центральной части выберите **таргет "ALADDIN"** (не проект, а таргет!)
4. Перейдите на вкладку **"General"** (сверху)

### Шаг 3: Изменить Display Name

1. Найдите поле **"Display Name"**
2. Измените на: **"ALADDIN X AI"** (или оставьте пустым)
3. Если поля нет — нажмите **"+"** рядом с "Identity"
4. Добавьте: **Display Name** = **"ALADDIN X AI"**

**Альтернативный способ (через Info.plist):**

1. Найдите файл **Info.plist** в проекте
2. Добавьте или измените:
   - **Key:** `CFBundleDisplayName`
   - **Value:** `ALADDIN X AI`

---

## ✅ РЕКОМЕНДАЦИЯ: ОСТАВИТЬ ПУСТЫМ

**Лучший вариант:**
- ✅ Оставьте **Display Name пустым**
- ✅ Xcode будет использовать Bundle Name (ALADDIN)
- ✅ Название в App Store Connect ("ALADDIN X AI") будет использоваться в App Store
- ✅ Это стандартная практика

**Почему:**
- ✅ Не нужно менять код
- ✅ Название в App Store Connect важнее
- ✅ Display Name на устройстве может быть другим

---

## 🔄 СОЗДАТЬ НОВЫЙ ARCHIVE С НОВЫМ НАЗВАНИЕМ

### Если вы изменили Display Name:

1. **Сохраните изменения** в Xcode (Cmd+S)

2. **Создайте новый Archive:**
   - Меню: **Product → Clean Build Folder** (Cmd+Shift+K)
   - Меню: **Product → Archive**
   - Дождитесь завершения (5-10 минут)

3. **Проверьте новый Archive:**
   - Откроется окно Organizer
   - Проверьте, что версия и build number корректны

4. **Validate App:**
   - В Organizer выберите новый Archive
   - Нажмите **"Validate App"**
   - Выберите ваше приложение **"ALADDIN X AI"**
   - Дождитесь валидации

---

## ⚠️ ВАЖНО: НЕ НУЖНО МЕНЯТЬ DISPLAY NAME!

**Рекомендация:**
- ✅ **НЕ меняйте Display Name** в Xcode
- ✅ Оставьте его **пустым** или как есть
- ✅ Название в App Store Connect ("ALADDIN X AI") будет использоваться в App Store
- ✅ Display Name на устройстве может быть "ALADDIN" (это нормально)

**Почему:**
- ✅ Название в App Store Connect важнее
- ✅ Display Name на устройстве — это техническое имя
- ✅ Пользователи увидят "ALADDIN X AI" в App Store
- ✅ На устройстве может быть просто "ALADDIN" (это нормально)
