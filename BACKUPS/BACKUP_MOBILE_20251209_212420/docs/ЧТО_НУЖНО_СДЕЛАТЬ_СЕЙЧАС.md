## 🎯 ЧТО НУЖНО СДЕЛАТЬ

### ВАРИАНТ 1: Если у вас уже есть App Store Distribution профили

1. **Найти App Store Distribution профили:**
   - Откройте https://developer.apple.com/account
   - **Profiles** → найдите профили типа **App Store** (Distribution)
   - Для `family.aladdin.ios`
   - Для `family.aladdin.ios.packetTunnel`

2. **Скачать их:**
   - Скачайте оба профиля
   - Сохраните в Downloads

3. **Конвертировать в Base64:**
   ```bash
   base64 -i ~/Downloads/ALADDIN_App_Store.mobileprovision -o - | pbcopy
   base64 -i ~/Downloads/ALADDINPacketTunnel_App_Store.mobileprovision -o - | pbcopy
   ```

4. **Обновить GitHub Secrets:**
   - `PROVISIONING_PROFILE_APP` → base64 основного профиля
   - `PROVISIONING_PROFILE_EXTENSION` → base64 профиля расширения

---

### ВАРИАНТ 2: Если у вас только Development профили

**Нужно создать App Store Distribution профили:**

1. **Откройте https://developer.apple.com/account**
2. **Profiles** → **+** (создать новый)
3. **Выберите App Store** (Distribution) - **НЕ Development!**
4. **Для основного приложения:**
   - App ID: `family.aladdin.ios`
   - Certificate: iPhone Distribution
   - Name: `ALADDIN App Store Distribution`
   - Generate → Download

5. **Для расширения:**
   - App ID: `family.aladdin.ios.packetTunnel` (с Network Extensions и VPN)
   - Certificate: iPhone Distribution
   - Name: `ALADDINPacketTunnel App Store Distribution`
   - Generate → Download

6. **Конвертировать в Base64** (см. ВАРИАНТ 1, шаг 3)
7. **Обновить GitHub Secrets** (см. ВАРИАНТ 1, шаг 4)

## ⚠️ ВАЖНО

**Ошибка в логах говорит:**
```
Provisioning profile "iOS Team Store Provisioning Profile: family.aladdin.ios" is Xcode managed
```

Это значит что используется **Xcode managed профиль**, а нужен **manually managed профиль**!

**Решение:**
- Создайте профили **вручную** на developer.apple.com
- **НЕ используйте** автоматически созданные Xcode профили
- Выберите тип: **App Store** (Distribution)
