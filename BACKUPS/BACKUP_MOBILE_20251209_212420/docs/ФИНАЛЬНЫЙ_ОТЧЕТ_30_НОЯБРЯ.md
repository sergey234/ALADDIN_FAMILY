## 🚀 КАК ИСПОЛЬЗОВАТЬ

### Для сборки и загрузки в App Store:

1. **Создать тег:**
   ```bash
   git tag -a "v1.0.0" -m "Release version 1.0.0"
   git push origin --tags
   ```

2. **Или запустить вручную:**
   - Открыть: https://github.com/sergey234/ALADDIN_FAMILY/actions
   - Выбрать: "Build and Upload to App Store"
   - Нажать: "Run workflow"

3. **Проверить результат:**
   - Workflow автоматически соберет проект
   - Создаст архив с правильной подписью
   - Загрузит в App Store Connect (если настроены API ключи)
