# 📱 ИНСТРУКЦИЯ: Локальная сборка для App Store

**Дата:** 27 ноября 2025  
**Для:** Сборка iOS приложения ALADDIN для App Store  
**Требования:** Mac с Xcode и авторизованным Apple ID

---

## ✅ ЧТО НУЖНО

1. **Mac** с установленным Xcode (любая версия, поддерживающая iOS 15+)
2. **Apple ID** с оплаченным Apple Developer Program ($99/год)
3. **Авторизация в Xcode** (Xcode → Settings → Accounts → добавить Apple ID)
4. **Проект ALADDIN** (клонировать из GitHub или использовать локальный)

---

## 🚫 ЧТО НЕ НУЖНО

- ❌ **Физический iPhone** — НЕ нужен для сборки в App Store
- ❌ **Подключённое устройство** — НЕ нужно
- ❌ **Симулятор** — НЕ нужен для архива

**Примечание:** iPhone нужен только для тестирования на реальном устройстве, но не для сборки в App Store.

---

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ

### **ШАГ 1: Открыть проект в Xcode** (1 минута)

1. Откройте **Xcode**
2. **File → Open** (или ⌘+O)
3. Выберите файл `ALADDIN.xcodeproj`
4. Дождитесь, пока Xcode загрузит проект

---

### **ШАГ 2: Проверить авторизацию Apple ID** (1 минута)

1. **Xcode → Settings** (или ⌘+,)
2. Вкладка **Accounts**
3. Проверьте, что ваш Apple ID есть в списке
4. Если нет — нажмите **"+"** → **"Apple ID"** → введите email и пароль

---

### **ШАГ 3: Настроить подпись** (2 минуты)

1. В Xcode выберите проект **ALADDIN** (левый верхний угол)
2. Выберите target **ALADDIN** (под PROJECT)
3. Вкладка **Signing & Capabilities**
4. Убедитесь, что:
   - ✅ **"Automatically manage signing"** включено
   - ✅ **Team** выбран (ваш Apple ID с Team ID `6CJVBBUGSN`)
5. Повторите для target **ALADDINPacketTunnel** (если есть)

---

### **ШАГ 4: Выбрать устройство для сборки** (30 секунд)

1. В левом верхнем углу Xcode найдите выпадающий список устройств
2. Выберите **"Any iOS Device (arm64)"**
   - ⚠️ **НЕ выбирайте симулятор!**
   - ⚠️ **НЕ нужно подключать iPhone!**

---

### **ШАГ 5: Собрать архив** (5-15 минут)

1. В меню Xcode: **Product → Archive**
2. Дождитесь завершения сборки (5-15 минут)
3. Откроется окно **Organizer** с вашим архивом

---

### **ШАГ 6: Экспортировать IPA** (2 минуты)

1. В окне **Organizer** выберите ваш архив (самый свежий)
2. Нажмите **"Distribute App"**
3. Выберите **"App Store Connect"**
4. Нажмите **"Next"**
5. Выберите **"Upload"**
6. Нажмите **"Next"**
7. Выберите опции:
   - ✅ **"Upload your app's symbols"** (если есть)
   - ✅ **"Manage Version and Build Number"** (если нужно)
8. Нажмите **"Next"**
9. Проверьте информацию и нажмите **"Upload"**
10. Дождитесь завершения загрузки

---

### **ШАГ 7: Проверить в App Store Connect** (1 минута)

1. Откройте: https://appstoreconnect.apple.com
2. Войдите в ваш Apple ID
3. **My Apps → ALADDIN**
4. Перейдите на вкладку **"TestFlight"** (или **"App Store" → "Versions"**)
5. Проверьте, что билд появился в списке

---

## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### **Проблема 1: "No signing certificate"**

**Решение:**
1. Зайдите в **Apple Developer Center** → **Certificates, Identifiers & Profiles**
2. Убедитесь, что есть **Distribution Certificate**
3. Если нет — Xcode создаст автоматически при архиве

---

### **Проблема 2: "No provisioning profile"**

**Решение:**
1. В Xcode: **Signing & Capabilities**
2. Убедитесь, что **"Automatically manage signing"** включено
3. Выберите правильный **Team**
4. Xcode создаст профиль автоматически

---

### **Проблема 3: "Bundle ID not found"**

**Решение:**
1. Зайдите в **Apple Developer Center** → **Identifiers**
2. Убедитесь, что `family.aladdin.ios` зарегистрирован
3. Если нет — создайте новый App ID

---

### **Проблема 4: Архив не создаётся**

**Решение:**
1. Убедитесь, что выбрано **"Any iOS Device (arm64)"**, а не симулятор
2. Проверьте, что нет ошибок компиляции (красные крестики в коде)
3. Попробуйте **Product → Clean Build Folder** (⇧⌘K), затем снова **Archive**

```
1. Открыть проект в Xcode
```
