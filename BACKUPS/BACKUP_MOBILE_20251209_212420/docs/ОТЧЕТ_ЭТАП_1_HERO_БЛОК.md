### 1. ✅ Обновлен HTML структура hero-блока

**Изменения:**
- Убран правый блок с щитом 🛡️ и надписью "ALADDIN AI"


## 🔄 ИНТЕГРАЦИЯ С API

**Ожидаемый формат ответа API:**
```json
{
  "protected_devices": 8,
  "blocked_threats_total": 47,
  "active_users": 4,
  "uptime_days": 30,
  "threats_timeline": [
    {"timestamp": "...", "value": 5},
    {"timestamp": "...", "value": 8},
    ...
  ]
}
```

**Fallback значения:**
- Если API недоступен, используются статические значения из HTML
- Статистика слева: 4, 8, 47
- Карточки справа: 8, 47, 4, 30
