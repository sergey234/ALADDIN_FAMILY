## 🎨 Визуальные элементы:

1. **Карточка тарифа (свёрнутая)**:
   - Иконка тарифа (🆓 💎 👨‍👩‍👧‍👦 ⭐)
   - Название тарифа
   - Цена
   - Количество функций
   - Chevron вниз (▼)

2. **Карточка тарифа (развёрнутая)**:
   - Всё из свёрнутой версии
   - Chevron вверх (▲)
   - Список категорий (каждая категория - своя карточка)
   - Примечание "✅ Все из [предыдущего тарифа]"

3. **Карточка категории (свёрнутая)**:
   - Эмодзи категории
   - Название категории
   - Количество функций в скобках
   - Chevron вниз (▼)

4. **Карточка категории (развёрнутая)**:
   - Всё из свёрнутой версии
   - Chevron вверх (▲)
   - Список всех угроз (bullet points)
