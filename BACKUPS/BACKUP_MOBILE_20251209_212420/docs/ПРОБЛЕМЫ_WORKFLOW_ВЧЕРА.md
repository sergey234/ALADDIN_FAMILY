# 📋 ВСПОМИНАЮ: ПРОБЛЕМЫ С WORKFLOW ВЧЕРА

**Дата:** 30 ноября 2025  
**Цель:** Вспомнить все проблемы с workflow, которые были вчера

---

## 🔍 ГЛАВНАЯ ПРОБЛЕМА

### ❌ Запускался неправильный workflow!

**Что происходило:**
- При каждом `git push origin master` автоматически запускался `build-only.yml`
- Этот workflow собирал архив **БЕЗ подписи** и **БЕЗ загрузки** в App Store
- Пользователь несколько раз говорил: "Нафиг ты его отправляешь тогда-если мы его не сможем отправить!"

---

## ❌ ПРОБЛЕМА #1: Автоматический запуск build-only.yml

### Что было:

```yaml
# .github/workflows/build-only.yml
on:
  workflow_dispatch:
  push:
    branches: [ main, master ]  # ← ПРОБЛЕМА!
```

**Последствия:**
- Каждый push в master → запускался build-only.yml
- Архив собирался, но НЕ загружался в App Store
- Пустая трата времени и ресурсов

### Что делал build-only.yml:

```yaml
- name: Build Archive (without signing for CI)
  run: |
    xcodebuild archive \
      CODE_SIGN_IDENTITY="" \
      CODE_SIGNING_REQUIRED=NO \
      CODE_SIGNING_ALLOWED=NO
```

**Проблемы:**
- ❌ БЕЗ подписи
- ❌ БЕЗ provisioning profiles
- ❌ НЕ создает IPA файл
- ❌ НЕ загружает в App Store Connect

---

## ❌ ПРОБЛЕМА #2: Архив был не готов для App Store

### Что создавал build-only.yml:

1. **Архив БЕЗ подписи**
   - `CODE_SIGN_IDENTITY=""` - пустая подпись
   - Apple не примет неподписанное приложение

2. **БЕЗ provisioning profiles**
   - Собиралось без профилей
   - App Store требует правильные профили

3. **БЕЗ IPA файла**
   - Только .xcarchive (промежуточный файл)
   - Для App Store нужен .ipa

4. **Только для CI тестирования**
   - Для проверки компиляции
   - НЕ для публикации

---

## ❌ ПРОБЛЕМА #3: Пользователь несколько раз говорил

### Цитаты пользователя:

1. "Нафиг ты его отправляешь тогда-если мы его не сможем отправить!"
2. "Я тебе уже несколько раз про это говорил!"
3. "тот архив который мы сделали-он целый? Его можно отправлять в эпл сторе?"

**Суть проблемы:**
- Пользователь видел, что архив собирается
- Но он НЕ загружался в App Store
- Пользователь был расстроен, что время тратится впустую

---

## ✅ ЧТО МЫ ИСПРАВИЛИ

### 1. Отключили автоматический запуск build-only.yml

**Было:**
```yaml
on:
  workflow_dispatch:
  push:
    branches: [ main, master ]  # ← Автоматический запуск
```

**Стало:**
```yaml
on:
  workflow_dispatch:  # Только вручную
  # ОТКЛЮЧЕН автоматический запуск при push
  # push:
  #   branches: [ main, master ]
```

**Результат:**
- ✅ build-only.yml больше не запускается автоматически
- ✅ Не мешает правильному workflow
- ✅ Можно запустить вручную для тестирования

---

### 2. Объяснили разницу между workflows

**build-only.yml:**
- Только для CI тестирования
- БЕЗ подписи
- БЕЗ загрузки в App Store

**appstore.yml:**
- Для загрузки в App Store
- С подписью
- С provisioning profiles
- Создает IPA
- Загружает в App Store Connect

---

### 3. Запустили правильный workflow

**Действия:**
1. Создали тег v1.0.6
2. Отправили тег в GitHub
3. Должен запуститься appstore.yml

**Что должен сделать appstore.yml:**
1. ✅ Настроить сертификат подписи
2. ✅ Установить provisioning profiles
3. ✅ Собрать архив С подписью
4. ✅ Экспортировать IPA файл
5. ✅ Загрузить в App Store Connect
