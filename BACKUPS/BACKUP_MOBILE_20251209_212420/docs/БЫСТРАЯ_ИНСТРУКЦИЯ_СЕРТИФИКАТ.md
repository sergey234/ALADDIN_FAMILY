# ⚡ БЫСТРАЯ ИНСТРУКЦИЯ: Создание сертификата

**Проблема:** Нужен сертификат "Apple Distribution" для создания профилей

---

## 🎯 ЧТО ДЕЛАТЬ (4 ШАГА)

### 1️⃣ Создать CSR в Keychain Access

1. Откройте **Keychain Access** (Cmd+Space → "Keychain Access")
2. Меню: **Keychain Access → Certificate Assistant → Request a Certificate From a Certificate Authority...**
3. Заполните:
   - **Email:** `sergey21-02-84@list.ru`
   - **Common Name:** `Sergey Khlystov`
   - **Request is:** выбрать **"Saved to disk"** ✅
4. Нажмите "Continue"
5. Сохраните файл на Desktop: `CertificateSigningRequest.certSigningRequest`

---

### 2️⃣ Загрузить CSR в Developer Portal

1. Откройте: https://developer.apple.com/account/resources/certificates/list
2. Нажмите "+"
3. Выберите **"Apple Distribution"**
4. Нажмите "Continue"
5. Нажмите "Choose File"
6. Выберите файл `CertificateSigningRequest.certSigningRequest` (с Desktop)
7. Нажмите "Continue"

---

### 3️⃣ Скачать сертификат

1. После обработки нажмите **"Download"**
2. Сохраните файл (например, `distribution.cer`)

---

### 4️⃣ Установить сертификат

1. **Двойной клик** на файл `distribution.cer`
2. Сертификат установится автоматически в Keychain
