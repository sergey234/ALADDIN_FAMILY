**✅ ПРАВИЛЬНО:** Оплата происходит **на сайте** `https://aladdin-ai.ru`, а не через QR-код в приложении.

**Доказательства:**

**Методы оплаты на сайте:**

- ✅ Tinkoff Pay
- ✅ Банковские карты (Сбербанк, Тинькофф, Альфа-Банк, ВТБ и др.)

- ✅ Manual transfer (ручной перевод)

**Всего методов:** 20+ (согласно `PAYMENT_STRATEGY_ANALYSIS.md`)

**Важно:** В документах упоминается только "QR-оплата (СБП, SberPay)", но на самом деле на сайте доступны **все методы оплаты**, включая карты и другие способы.

### 2. IAP (In-App Purchase) - СТАТУС

#### ✅ Код готов (100%)
- `StoreManager.swift` полностью реализован (StoreKit 2)
- Логика определения региона работает
- Product IDs определены в `IAP_PRODUCT_IDS_COMPLETE.md`

#### ❌ НЕ зарегистрирован в App Store Connect (0%)
- **Проблема:** IAP продукты не зарегистрированы в App Store Connect
- **Следствие:** IAP не будет работать, даже если пользователь находится не в России
- **Документ:** `IAP_REGISTRATION_EXPLANATION.md` рекомендует НЕ регистрировать для первой версии

#### ⚠️ Логика в коде:
```swift
// Россия → сайт
static var useAlternativePayments: Bool {
    return isRussianRegion  // true для RU
}

// Не-Россия → IAP (но IAP не зарегистрирован!)
static var useIAP: Bool {
    return !isRussianRegion  // true для всех кроме RU
}
```

**Проблема:** Если пользователь не из России, код попытается использовать IAP, но он не зарегистрирован → покупка не сработает.

### 3. МОГУТ ЛИ ПОЛЬЗОВАТЕЛИ ИЗ РОССИИ ИСПОЛЬЗОВАТЬ IAP?

**Технически:** Да, если:
- У пользователя зарубежный Apple ID
- Пользователь находится за границей
- У пользователя есть доступ к App Store (не ограничен санкциями)

**Практически:** 
- ❌ IAP не зарегистрирован → не работает для всех
- ❌ В коде для России принудительно используется сайт
- ✅ Это правильно, т.к. IAP в России ограничен санкциями Apple

**Вывод:** Пользователи из России **должны** использовать сайт, даже если у них есть доступ к IAP.

### 2. Решить вопрос с IAP

**Вариант A: НЕ регистрировать IAP (текущий подход)**
- ✅ Все пользователи идут на сайт
- ✅ Проще поддерживать
- ❌ Зарубежные пользователи не могут оплатить через App Store
- ❌ Не соответствует ожиданиям зарубежных пользователей

**Вариант B: Зарегистрировать IAP**
- ✅ Зарубежные пользователи могут оплатить через App Store
- ✅ Соответствует App Store Guidelines
- ✅ Улучшает UX для международных пользователей
- ⏱️ Требует 1-2 часа на регистрацию в App Store Connect

**Рекомендация:** 
- Для первой версии (MVP): Вариант A (оставить как есть)
- Для международного расширения: Вариант B (зарегистрировать IAP)

### 3. Обновить логику в коде (если регистрируем IAP)

**Текущий код:**
```swift
static var useIAP: Bool {
    return !isRussianRegion  // Все кроме России
}
```

**Проблема:** Если IAP не зарегистрирован, код попытается использовать IAP, но он не сработает.

**Решение:** Добавить проверку доступности IAP:
```swift
static var useIAP: Bool {
    #if APP_STORE_BUILD
    // В App Store билде: проверяем регистрацию IAP
    return !isRussianRegion && isIAPRegistered
    #else
    // В других билдах: всегда сайт
    return false
    #endif
}
```
