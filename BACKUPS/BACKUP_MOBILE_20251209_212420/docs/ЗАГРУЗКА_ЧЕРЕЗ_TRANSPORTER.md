**Проблема:** Ошибка "Invalid response" при загрузке через Xcode

**Решение:** Использовать Transporter для загрузки билда

### Преимущества Transporter:
- ✅ Более надёжный при проблемах с сетью
- ✅ Не зависит от Xcode
- ✅ Работает даже при проблемах с серверами Apple
- ✅ Проще в использовании

---

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ

### Шаг 1: Экспортировать билд из Xcode

1. **Откройте Xcode → Organizer:**
   - Window → Organizer (или Cmd+Shift+O)
   - Выберите ваш Archive

2. **Нажмите "Distribute App":**
   - Выберите "App Store Connect"
   - Нажмите "Next"

3. **Выберите "Export":**
   - Выберите "Export" (не Upload!)
   - Нажмите "Next"

4. **Выберите приложение:**
   - Выберите "ALADDIN X AI"
   - Нажмите "Next"

5. **Проверьте опции:**
   - "Manager version" — можно включить
   - "Upload symbols" — можно включить
   - Нажмите "Next"

6. **Сохраните .ipa файл:**
   - Выберите место для сохранения (например, Desktop)
   - Нажмите "Export"
   - Дождитесь завершения (2-5 минут)
   - Будет создан .ipa файл

---

### Шаг 2: Установить Transporter (если нет)

1. **Откройте App Store на Mac**
2. **Найдите "Transporter"**
3. **Нажмите "Get" или "Install"**
4. **Дождитесь установки**

---

### Шаг 3: Загрузить билд через Transporter

1. **Откройте Transporter:**
   - Найдите в Applications
   - Или через Spotlight (Cmd+Space → "Transporter")

2. **Войдите в аккаунт:**
   - Если не вошли — войдите с `sergey21-02-84@list.ru`
   - Нажмите "Sign In"

3. **Загрузите .ipa файл:**
   - **Вариант A:** Перетащите .ipa файл в окно Transporter
   - **Вариант B:** Нажмите "+" → выберите .ipa файл

4. **Нажмите "Deliver":**
   - Нажмите кнопку "Deliver"
   - Начнётся загрузка

5. **Дождитесь завершения:**
   - ⏳ Загрузка займёт 10-20 минут
   - ⏳ Не закрывайте Transporter
   - ⏳ Не прерывайте процесс

---

## ⏳ ЧТО ПРОИЗОЙДЁТ ПОСЛЕ ЗАГРУЗКИ

1. **Билд загрузится в App Store Connect:**
   - Статус: "Processing"
   - Обычно занимает 30-60 минут

2. **Проверьте статус:**
   - Откройте https://appstoreconnect.apple.com
   - My Apps → ALADDIN X AI
   - Versions → Build
   - Дождитесь статуса "Ready to Submit"

3. **После обработки:**
   - Билд будет готов к отправке на ревью
   - Можно заполнять метаданные
