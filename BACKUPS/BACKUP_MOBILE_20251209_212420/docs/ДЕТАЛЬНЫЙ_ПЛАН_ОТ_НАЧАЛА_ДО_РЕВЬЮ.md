## 📋 ДЕТАЛЬНЫЙ ПЛАН ДЕЙСТВИЙ

### ЭТАП 1: ПОЛУЧИТЬ PROVISIONING PROFILES (ЛОКАЛЬНО)

**Где:** Ваш Mac, Xcode 13.2.1  
**Время:** 10-15 минут

#### Шаг 1.1: Открыть проект в Xcode

1. **Открыть Xcode:**
   - Найти Xcode в Applications
   - Или через Spotlight (Cmd+Space → "Xcode")

2. **Открыть проект:**
   - File → Open
   - Выбрать `ALADDIN.xcodeproj` или `ALADDIN.xcworkspace`
   - Нажать "Open"

**Результат:**
- ✅ Проект открыт в Xcode

---

#### Шаг 1.2: Настроить Signing для основного приложения

1. **Выбрать проект:**
   - В левой панели (Navigator) выбрать самый верхний элемент (проект "ALADDIN")
   - Или нажать на название проекта вверху

2. **Выбрать target "ALADDIN":**
   - В центральной панели выбрать вкладку "TARGETS"
   - Выбрать "ALADDIN" (основное приложение)

3. **Перейти на вкладку "Signing & Capabilities":**
   - Нажать на вкладку "Signing & Capabilities" вверху

4. **Настроить Signing:**
   - Найти раздел "Signing"
   - Поставить галочку "Automatically manage signing"
   - Выбрать Team: `6CJVBBUGSN` (или ваше имя)
   - Если Team не видно, нажать "Add Account..." и войти

5. **Проверить результат:**
   - Должно появиться: "Provisioning Profile: Xcode Managed Profile"
   - Должно появиться: "Signing Certificate: Apple Development"

**Результат:**
- ✅ Provisioning profile создан для основного приложения
- ✅ Профиль сохранён в `~/Library/MobileDevice/Provisioning Profiles/`

---

#### Шаг 1.3: Настроить Signing для Network Extension

1. **Выбрать target "ALADDINPacketTunnel":**
   - В центральной панели выбрать вкладку "TARGETS"
   - Выбрать "ALADDINPacketTunnel" (Network Extension)

2. **Перейти на вкладку "Signing & Capabilities":**
   - Нажать на вкладку "Signing & Capabilities" вверху

3. **Настроить Signing:**
   - Найти раздел "Signing"
   - Поставить галочку "Automatically manage signing"
   - Выбрать Team: `6CJVBBUGSN` (тот же, что и для основного приложения)

4. **Проверить результат:**
   - Должно появиться: "Provisioning Profile: Xcode Managed Profile"
   - Должно появиться: "Signing Certificate: Apple Development"

**Результат:**
- ✅ Provisioning profile создан для Network Extension
- ✅ Профиль сохранён в `~/Library/MobileDevice/Provisioning Profiles/`

---

#### Шаг 1.4: Найти и проверить provisioning profiles

1. **Открыть Finder:**
   - Нажать Cmd+Shift+G (Go to Folder)
   - Ввести: `~/Library/MobileDevice/Provisioning Profiles`
   - Нажать Enter

2. **Проверить файлы:**
   - Должны быть файлы `.mobileprovision`
   - Искать файлы с именами, содержащими:
     - `family.aladdin.ios` (основное приложение)
     - `family.aladdin.ios.packetTunnel` (Network Extension)

3. **Запомнить имена файлов:**
   - Записать полные имена файлов
   - Или скопировать их в отдельную папку

**Результат:**
- ✅ Provisioning profiles найдены
- ✅ Готовы к экспорту

### ЭТАП 2: ДОБАВИТЬ В GITHUB SECRETS

**Где:** GitHub.com  
**Время:** 15-20 минут

#### Шаг 2.1: Экспортировать provisioning profiles

1. **Скопировать файлы:**
   - Открыть `~/Library/MobileDevice/Provisioning Profiles`
   - Найти файлы с `family.aladdin.ios`
   - Скопировать их на Desktop (для удобства)

2. **Закодировать в base64:**
   - Открыть Terminal
   - Перейти в папку с файлами:
     ```bash
     cd ~/Desktop
     ```
   - Закодировать основной профиль:
     ```bash
     base64 -i "имя_файла.mobileprovision" > app_profile_base64.txt
     ```
   - Закодировать профиль для Network Extension:
     ```bash
     base64 -i "имя_файла_extension.mobileprovision" > extension_profile_base64.txt
     ```

3. **Скопировать содержимое:**
   - Открыть `app_profile_base64.txt`
   - Скопировать всё содержимое (Cmd+A, Cmd+C)
   - Сохранить в буфер обмена

**Результат:**
- ✅ Provisioning profiles закодированы в base64
- ✅ Готовы к добавлению в GitHub Secrets

---

#### Шаг 2.2: Добавить в GitHub Secrets

1. **Открыть GitHub:**
   - Перейти на: https://github.com/sergey234/ALADDIN_FAMILY

### ЭТАП 3: ОБНОВИТЬ WORKFLOW

**Где:** GitHub.com, файл `.github/workflows/appstore.yml`  
**Время:** 20-30 минут

#### Шаг 3.1: Обновить workflow для использования profiles

1. **Открыть файл workflow:**
   - Перейти на: https://github.com/sergey234/ALADDIN_FAMILY
   - Открыть `.github/workflows/appstore.yml`
   - Нажать "Edit" (карандаш)

2. **Добавить шаг для установки provisioning profiles:**
   - Добавить перед шагом "Build Archive":
     ```yaml
     - name: Setup Provisioning Profiles
       run: |
         mkdir -p ~/Library/MobileDevice/Provisioning\ Profiles/
         echo "${{ secrets.PROVISIONING_PROFILE_APP }}" | base64 -d > ~/Library/MobileDevice/Provisioning\ Profiles/app.mobileprovision
         echo "${{ secrets.PROVISIONING_PROFILE_EXTENSION }}" | base64 -d > ~/Library/MobileDevice/Provisioning\ Profiles/extension.mobileprovision
         ls -la ~/Library/MobileDevice/Provisioning\ Profiles/
     ```

3. **Обновить шаг "Build Archive":**
   - Изменить на Manual signing:
     ```yaml
     - name: Build Archive (with signing)
       env:
         APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}
       run: |
         xcodebuild archive \
           -project ALADDIN.xcodeproj \
           -scheme ALADDIN \
           -configuration Release \
           -archivePath ./build/ALADDIN.xcarchive \
           -destination 'generic/platform=iOS' \
           CODE_SIGN_STYLE=Manual \
           DEVELOPMENT_TEAM="$APPLE_TEAM_ID" \
           PROVISIONING_PROFILE_SPECIFIER="family.aladdin.ios"
     ```

4. **Сохранить изменения:**
   - Нажать "Commit changes"
   - Написать сообщение: "Add provisioning profiles support for signing"
   - Нажать "Commit changes"

**Результат:**
- ✅ Workflow обновлён для использования provisioning profiles
- ✅ Готов к сборке с подписью
