## 🎯 ОТВЕТ НА ВОПРОС О ПОИСКЕ ПОЛЬЗОВАТЕЛЯ

**Вопрос:** "А как мы если что будем искать пользователя если с платежом что то пойдет не так!?"

**Ответ:** ✅ **РЕШЕНО**

1. **Поиск платежей:** Используется `user_alias` в таблице `payments`
   - Endpoint: `POST /api/payments/recover`
   - Ищет платежи по `user_alias` напрямую в таблице `payments`
   - Не требует связи с таблицей `users`

2. **Восстановление кода активации:**
   - Пользователь вводит `user_alias` + `pin` на сайте
   - Сервер ищет оплаченные платежи по `user_alias`
   - Возвращает информацию о платеже и код активации

3. **Реферальная программа:**
   - Для анонимных платежей обрабатывается позже
   - Когда `user_id` станет известен (при регистрации или подтверждении)
   - Это нормально и не влияет на работу системы

**Подробное объяснение:** См. `docs/PAYMENT_USER_RECOVERY_EXPLANATION.md`
