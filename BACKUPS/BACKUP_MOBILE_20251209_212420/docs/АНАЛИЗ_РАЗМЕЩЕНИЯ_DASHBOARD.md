# 📊 АНАЛИЗ: ГДЕ РАЗМЕСТИТЬ ПУБЛИЧНЫЙ DASHBOARD

**Дата:** 3 декабря 2025  
**Вопрос:** Уместить dashboard в hero-блок или создать отдельную страницу?

---

## 🎯 ВАРИАНТЫ РАЗМЕЩЕНИЯ

### Вариант 1: Dashboard в hero-блоке (вместо щита)

**Что умещаем:**
- Карточки статистики (4 карточки)
- Мини-график угроз (компактный)
- Топ-5 угроз (список)

**Плюсы:**
- ✅ Всё на главной странице
- ✅ Сразу видно статистику
- ✅ Не нужно переходить на другую страницу
- ✅ Экономия места

**Минусы:**
- ❌ Может быть перегружено
- ❌ График будет маленьким
- ❌ На мобильных может быть тесно
- ❌ Может отвлекать от призыва к действию (кнопки оплаты)

---

### Вариант 2: Компактный dashboard в hero + полный на отдельной странице

**В hero-блоке:**
- Карточки статистики (4 карточки)
- Мини-график (компактный)
- Кнопка "Посмотреть подробную статистику" → `/dashboard`

**На отдельной странице `/dashboard`:**
- Полный dashboard
- Большие графики
- Детальная статистика
- Топ угроз с деталями

**Плюсы:**
- ✅ Hero-блок не перегружен
- ✅ Есть призыв к действию (кнопки оплаты)
- ✅ Полный dashboard на отдельной странице
- ✅ Лучше для мобильных
- ✅ Более профессионально

**Минусы:**
- ❌ Нужно создавать отдельную страницу
- ❌ Немного больше работы

---

## 📐 АНАЛИЗ РАЗМЕРОВ

### Hero-блок (текущий):

**Высота:** ~600-800px (viewport)
**Ширина:** 100% (адаптивная)

**Левая часть (контент):**
- Текст: ~200-300px
- Кнопки: ~100px
- Статистика: ~150px
- Итого: ~450-550px

**Правая часть (визуал):**
- Щит: ~300-400px
- Итого: ~300-400px

**Доступное место для dashboard:**
- Ширина: ~300-400px (правая часть)
- Высота: ~400-500px (можно расширить hero)

---

### Что нужно для полного dashboard:

**Карточки статистики:**
- 4 карточки × 150px = 600px (в ряд)
- Или 2×2 = 300px × 300px (в сетке)

**График угроз:**
- Минимум: 300px × 200px
- Комфортно: 400px × 250px

**Топ-5 угроз:**
- Минимум: 300px × 200px
- Комфортно: 400px × 250px

**Итого для полного dashboard:**
- Ширина: 400-500px
- Высота: 700-800px

## 📋 ПЛАН РЕАЛИЗАЦИИ

### Этап 1: Компактный dashboard в hero-блоке

**Что делаем:**
1. Убираем щит справа
2. Добавляем 4 карточки статистики (2×2)
3. Добавляем мини-график (компактный)
4. Добавляем кнопку "Посмотреть подробную статистику" → `/dashboard`
5. Подключаем статистику слева к API

**Размеры:**
- Карточки: 2×2, каждая ~140×140px
- График: 300×120px
- Кнопка: под графиком

---

### Этап 2: Полный dashboard на отдельной странице

**Что делаем:**
1. Создаем `/dashboard/index.html`
2. Полный dashboard с большими графиками
3. Детальная статистика
4. Топ угроз с деталями

**Размеры:**
- Карточки: 4 в ряд, каждая ~200×150px
- График: 800×400px (большой)
- Топ угроз: полный список
