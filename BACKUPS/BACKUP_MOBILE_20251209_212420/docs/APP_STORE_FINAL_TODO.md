### Этап 2: Загрузка в App Store Connect (15-30 минут)

- [ ] **2.1. Distribute App**
  - [ ] В окне Organizer выбрать созданный Archive
  - [ ] Нажать кнопку "Distribute App"
  - [ ] Выбрать "App Store Connect"
  - [ ] Нажать "Next"

- [ ] **2.2. Выбрать метод распространения**
  - [ ] Выбрать "Upload" (рекомендуется)
  - [ ] Нажать "Next"

- [ ] **2.3. Проверить опции**
  - [ ] Убедиться, что "Include bitcode" отключен (если не нужен)
  - [ ] Убедиться, что "Upload your app's symbols" включен (для crash reports)
  - [ ] Нажать "Next"

- [ ] **2.4. Проверить подпись**
  - [ ] Xcode автоматически проверит подпись
  - [ ] Если есть ошибки — исправить
  - [ ] Нажать "Upload"

- [ ] **2.5. Дождаться загрузки**
  - [ ] Процесс загрузки может занять 10-20 минут
  - [ ] Дождаться сообщения "Upload Successful"
