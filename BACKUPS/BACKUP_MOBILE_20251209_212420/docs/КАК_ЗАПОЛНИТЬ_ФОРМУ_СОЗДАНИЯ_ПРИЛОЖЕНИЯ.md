# 📝 КАК ЗАПОЛНИТЬ ФОРМУ СОЗДАНИЯ ПРИЛОЖЕНИЯ

**Форма создания нового приложения в App Store Connect**

---

## ✅ ПОЛЯ ДЛЯ ЗАПОЛНЕНИЯ

### 1. Платформы

**Что выбрать:**
- ✅ **iOS** (галочка только на iOS)

**Почему:**
- Ваше приложение для iOS
- Не нужно выбирать macOS, tvOS, visionOS

---

### 2. Название

**Что ввести:**
- ✅ **"ALADDIN AI Security"** (или другое свободное имя)

**Важно:**
- ❌ НЕ используйте "ALADDIN AI" — оно занято!
- ✅ Используйте "ALADDIN AI Security" или другой вариант
- ✅ Максимум 30 символов

**Почему изменить:**
- "ALADDIN AI" уже занято другим разработчиком
- Нужно использовать другое уникальное имя

---

### 3. Основной язык

**Что выбрать:**
- ✅ **Русский** (если есть в списке)
- ✅ Или **Английский (США)** — если русского нет

**Почему:**
- Это язык интерфейса App Store Connect
- Потом можно добавить другие языки
- Не влияет на язык приложения

---

### 4. ID пакета (Bundle ID)

**Что выбрать:**
- ✅ **"family.aladdin.ios"** (если он уже зарегистрирован)
- ❌ Если его нет в списке — нужно зарегистрировать

**Как зарегистрировать (если нет в списке):**

1. Нажмите на ссылку: **"Зарегистрируйте новый ID пакета в разделе Сертификаты, идентификаторы и профили"**
2. Или перейдите: https://developer.apple.com/account/resources/identifiers/list
3. Нажмите **"+"** → **"App IDs"**
4. Выберите **"App"**
5. Введите:
   - **Description:** ALADDIN iOS App
   - **Bundle ID:** `family.aladdin.ios` (Explicit)
6. Нажмите **"Continue"** → **"Register"**
7. Вернитесь в App Store Connect и выберите созданный Bundle ID

**Важно:**
- ✅ Bundle ID должен совпадать с тем, что в Xcode
- ✅ В вашем проекте: `family.aladdin.ios`
- ✅ Используйте именно этот Bundle ID

---

### 5. SKU

**Что ввести:**
- ✅ **"aladdin-ios-001"** (или любой уникальный код)

**Примеры:**
- `aladdin-ios-001`
- `aladdin-app-2025`
- `aladdin-ios-v1`

**Почему:**
- SKU — это внутренний идентификатор для вашего учёта
- Может быть любой уникальный код
- Не виден пользователям
- Нельзя изменить после создания

---

### 6. Пользовательский доступ

**Что выбрать:**
- ✅ **"Полный доступ"** (рекомендуется)

**Варианты:**
- **"Ограниченный доступ"** — только для тестирования внутри команды
- **"Полный доступ"** — для публикации в App Store

**Почему "Полный доступ":**
- ✅ Позволяет публиковать в App Store
- ✅ Позволяет использовать TestFlight
- ✅ Стандартный выбор для публичных приложений

## ⚠️ ВАЖНЫЕ МОМЕНТЫ

### Если Bundle ID не найден:

**Шаг 1: Зарегистрировать Bundle ID**
1. Перейдите: https://developer.apple.com/account/resources/identifiers/list
2. Нажмите **"+"** → **"App IDs"** → **"App"**
3. Введите:
   - Description: `ALADDIN iOS App`
   - Bundle ID: `family.aladdin.ios` (Explicit)
4. Нажмите **"Continue"** → **"Register"**

**Шаг 2: Вернуться в App Store Connect**
1. Обновите страницу
2. Bundle ID появится в списке
3. Выберите его
