# 🔐 ИНСТРУКЦИЯ: Как найти Accounts в Xcode 13.2.1

**Проблема:** Не могу найти "Settings → Accounts" в Xcode  
**Причина:** В Xcode 13.2.1 настройки называются "Preferences", а не "Settings"

---

## ✅ ПРАВИЛЬНЫЙ ПУТЬ ДЛЯ XCODE 13.2.1

### **СПОСОБ 1: Через меню Xcode**

1. **В верхнем меню Mac** найдите **"Xcode"**
2. **Кликните на "Xcode"**
3. **В выпадающем меню** найдите **"Preferences..."**
   - Или используйте горячую клавишу: `⌘ + ,` (Command + запятая)

4. **Откроется окно "Preferences"**

5. **В верхней панели окна** найдите вкладки:
   - General
   - **Accounts** ← **НАЖМИТЕ СЮДА**
   - Behaviors
   - Navigation
   - Fonts & Colors
   - Text Editing
   - Key Bindings
   - Source Control
   - Components
   - Locations
   - Downloads

6. **Кликните на вкладку "Accounts"**

---

### **СПОСОБ 2: Через горячую клавишу**

1. **Нажмите:** `⌘ + ,` (Command + запятая)
2. **Откроется окно Preferences**
3. **Кликните на вкладку "Accounts"**

---

## ✅ КАК ДОБАВИТЬ APPLE ID (если его нет)

1. **В окне Accounts** нажмите кнопку **"+"** (внизу слева)

2. **В выпадающем меню** выберите **"Apple ID"**

3. **Введите ваши данные:**
   - **Apple ID:** ваш email (например, `sergey@example.com`)
   - **Password:** ваш пароль Apple ID
   - Нажмите **"Sign In"**

4. **Дождитесь авторизации:**
   - Xcode подключится к Apple Developer
   - Появится ваш Apple ID в списке
   - Рядом будет написано **"Personal Team"** или **Team ID** (`6CJVBBUGSN`)

---

## ✅ КАК ПРОВЕРИТЬ TEAM ID

1. **В окне Accounts** выберите ваш Apple ID (кликните один раз)

2. **Нажмите "View Details..."**

3. **В открывшемся окне** вы увидите:
   - **Team ID:** `6CJVBBUGSN` (или другой)
   - **Team Name:** ваше имя или название команды
   - Список сертификатов и профилей

4. **Проверьте Team ID:**
   - Должно быть: `6CJVBBUGSN`
   - Если другое — это нормально, если у вас несколько команд

## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### **Проблема 1: "Preferences" неактивно (серая)**

**Причина:** Xcode не открыт или проект не загружен.

**Решение:**
1. Убедитесь, что Xcode открыт
2. Откройте проект ALADDIN
3. Попробуйте снова: `⌘ + ,`

---

### **Проблема 2: Вкладка "Accounts" не видна**

**Причина:** Окно Preferences слишком узкое.

**Решение:**
1. Растяните окно Preferences в ширину
2. Все вкладки должны быть видны

---

### **Проблема 3: "Sign In" не работает**

**Причина:** Проблема с интернетом или Apple ID.

**Решение:**
1. Проверьте интернет-соединение
2. Проверьте, что Apple ID правильный
3. Попробуйте войти на appleid.apple.com в браузере
4. Если не работает — используйте двухфакторную аутентификацию

---

## 📝 КРАТКАЯ ПАМЯТКА

```
1. Xcode → Preferences (или ⌘ + ,)
2. Вкладка "Accounts"
3. Если нет Apple ID → нажать "+" → "Apple ID"
4. Ввести email и пароль
5. Проверить Team ID (должно быть 6CJVBBUGSN)
```
