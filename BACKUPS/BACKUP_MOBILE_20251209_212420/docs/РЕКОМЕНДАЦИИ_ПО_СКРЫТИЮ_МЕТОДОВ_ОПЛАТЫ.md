## 🔧 ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

### Вариант 1: Флаг в настройках (РЕКОМЕНДУЕТСЯ) ⭐

**В backend (настройки/конфиг):**
```json
{
  "payment_methods": {
    "visible": [
      "sbp",
      "sberpay",
      "cards",
      "tinkoff_pay",
      "manual_transfer"
    ],
    "hidden": [
      "alpha_bank",
      "vtb",
      "yookassa",
      "cloudpayments",
      "yoomoney",
      "qiwi"
    ]
  }
}
```

**В коде сайта:**
```javascript
// Показываем только видимые методы
const visibleMethods = paymentMethods.filter(method => 
  config.payment_methods.visible.includes(method.id)
);

// Скрытые методы остаются в коде, но не отображаются
const hiddenMethods = paymentMethods.filter(method => 
  config.payment_methods.hidden.includes(method.id)
);
```

**Преимущества:**
- ✅ Легко управлять через админ-панель
- ✅ Можно быстро включить/выключить методы
- ✅ Не нужно менять код для изменения списка

---

### Вариант 2: CSS-класс (простой способ)

**В HTML:**
```html
<!-- Видимые методы -->
<div class="payment-method visible" data-method="sbp">СБП</div>
<div class="payment-method visible" data-method="sberpay">SberPay</div>
<div class="payment-method visible" data-method="cards">Банковские карты</div>
<div class="payment-method visible" data-method="tinkoff_pay">Tinkoff Pay</div>
<div class="payment-method visible" data-method="manual_transfer">Ручной перевод</div>

<!-- Скрытые методы -->
<div class="payment-method hidden" data-method="alpha_bank">Альфа-Банк</div>
<div class="payment-method hidden" data-method="vtb">ВТБ</div>
<div class="payment-method hidden" data-method="yookassa">ЮKassa</div>
<div class="payment-method hidden" data-method="cloudpayments">CloudPayments</div>
<div class="payment-method hidden" data-method="yoomoney">ЮMoney</div>
<div class="payment-method hidden" data-method="qiwi">QIWI</div>
```

**В CSS:**
```css
.payment-method.hidden {
  display: none; /* Скрыто, но код остается */
}

.payment-method.visible {
  display: block; /* Видимо */
}

/* Для быстрого развертывания - просто убрать класс hidden */
.payment-method.hidden.show-all {
  display: block; /* Показать все при необходимости */
}
```

**Преимущества:**
- ✅ Очень просто реализовать
- ✅ Не нужно менять backend
- ✅ Можно быстро показать все методы (убрать класс hidden)

### Вариант 3: Feature Flag (для продвинутых)

**В настройках:**
```javascript
const PAYMENT_METHODS_CONFIG = {
  showAllMethods: false, // Флаг для показа всех методов
  visibleMethods: [
    'sbp',
    'sberpay',
    'cards',
    'tinkoff_pay',
    'manual_transfer'
  ],
  hiddenMethods: [
    'alpha_bank',
    'vtb',
    'yookassa',
    'cloudpayments',
    'yoomoney',
    'qiwi'
  ]
};

// Функция для получения методов
function getPaymentMethods() {
  if (PAYMENT_METHODS_CONFIG.showAllMethods) {
    return [...PAYMENT_METHODS_CONFIG.visibleMethods, ...PAYMENT_METHODS_CONFIG.hiddenMethods];
  }
  return PAYMENT_METHODS_CONFIG.visibleMethods;
}
```

**Преимущества:**
- ✅ Гибкое управление
- ✅ Можно быстро включить все методы
- ✅ Можно A/B тестировать разные наборы методов
