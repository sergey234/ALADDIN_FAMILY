## 📝 ЧТО НУЖНО СДЕЛАТЬ

### ШАГ 1: Открыть Apple Developer Portal

1. Перейдите по ссылке: https://developer.apple.com/account/resources/profiles/list
2. Войдите в свой аккаунт Apple Developer
3. Убедитесь, что вы находитесь в разделе **Certificates, Identifiers & Profiles**

---

- Bundle ID: `family.aladdin.ios`
- Тип: **App Store**

**Профиль для расширения:**

- Bundle ID: `family.aladdin.ios.packetTunnel`

---

### ШАГ 3: Удалить старые профили

**⚠️ ВАЖНО:** Перед удалением убедитесь, что у вас есть доступ к Apple Developer Portal для создания новых профилей!

1. Найдите профиль `ALADDIN App Store Distribution`
2. Нажмите на него, чтобы открыть детали
3. Нажмите кнопку **"Edit"** (Редактировать) или **"Delete"** (Удалить)
4. Подтвердите удаление
5. Повторите для профиля `ALADDINPacketTunnel App Store Distribution`

**Альтернатива:** Если вы не хотите удалять старые профили, можно просто создать новые с другими именами (например, добавить суффикс `_v2`).

---

### ШАГ 4: Проверить сертификат

1. Перейдите в раздел **Certificates**: https://developer.apple.com/account/resources/certificates/list
2. Найдите сертификат **"Apple Distribution: SERGEY KHLYSTOV (***)"**
3. Убедитесь, что он активен и не истек
4. **ВАЖНО:** Запишите или запомните, что этот сертификат должен быть выбран при создании новых профилей

**Если сертификата нет:**
- Создайте новый сертификат типа **"Apple Distribution"**
- Скачайте его и установите в keychain
- Обновите GitHub Secret `IOS_DISTRIBUTION_CERTIFICATE`

---

### ШАГ 5: Создать новый профиль для основного приложения

1. Перейдите в раздел **Profiles**: https://developer.apple.com/account/resources/profiles/list
2. Нажмите кнопку **"+"** (плюс) в правом верхнем углу
3. Выберите тип профиля: **"App Store"** (для публикации в App Store)
4. Нажмите **"Continue"**

**Настройки профиля:**

**5.1. Выбор App ID:**
- Найдите и выберите: `family.aladdin.ios`
- Если его нет, создайте новый App ID с этим Bundle ID
- Нажмите **"Continue"**

**5.2. Выбор сертификата:**
- **КРИТИЧЕСКИ ВАЖНО:** Выберите сертификат **"Apple Distribution: SERGEY KHLYSTOV (***)"**
- Убедитесь, что выбран именно этот сертификат, а не другой с похожим именем
- Если видите несколько сертификатов с одинаковым именем, выберите тот, который активен и не истек
- Нажмите **"Continue"**

**5.3. Имя профиля:**
- Введите имя: `ALADDIN App Store Distribution`
- Или используйте другое имя (например, `ALADDIN App Store Distribution v2`)
- Нажмите **"Generate"** (Создать)

**5.4. Скачать профиль:**
- После создания профиль будет доступен для скачивания
- Нажмите кнопку **"Download"** (Скачать)
- Сохраните файл с именем `ALADDIN_App_Store_Distribution.mobileprovision`

---

### ШАГ 6: Создать новый профиль для расширения

1. Снова нажмите кнопку **"+"** (плюс)
2. Выберите тип профиля: **"App Store"**
3. Нажмите **"Continue"**

**Настройки профиля:**

**6.1. Выбор App ID:**
- Найдите и выберите: `family.aladdin.ios.packetTunnel`
- **ВАЖНО:** Этот App ID должен иметь включенные capabilities:
  - ✅ **Network Extensions**
  - ✅ **Personal VPN**
- Если этих capabilities нет, отредактируйте App ID и включите их
- Нажмите **"Continue"**

**6.2. Выбор сертификата:**
- **КРИТИЧЕСКИ ВАЖНО:** Выберите тот же сертификат **"Apple Distribution: SERGEY KHLYSTOV (***)"**
- Должен быть тот же сертификат, что и для основного приложения
- Нажмите **"Continue"**

**6.3. Имя профиля:**
- Введите имя: `ALADDINPacketTunnel App Store Distribution`
- Или используйте другое имя (например, `ALADDINPacketTunnel App Store Distribution v2`)
- Нажмите **"Generate"** (Создать)

**6.4. Скачать профиль:**
- Нажмите кнопку **"Download"** (Скачать)
- Сохраните файл с именем `ALADDINPacketTunnel_App_Store_Distribution.mobileprovision`

### ШАГ 7: Закодировать профили в base64

**Для macOS/Linux:**

```bash
# Для основного приложения
cat ALADDIN_App_Store_Distribution.mobileprovision | base64 > app_profile_base64.txt

# Для расширения
cat ALADDINPacketTunnel_App_Store_Distribution.mobileprovision | base64 > ext_profile_base64.txt
```

**Для Windows (PowerShell):**

```powershell
# Для основного приложения
[Convert]::ToBase64String([IO.File]::ReadAllBytes("ALADDIN_App_Store_Distribution.mobileprovision")) | Out-File -Encoding ASCII app_profile_base64.txt

# Для расширения
[Convert]::ToBase64String([IO.File]::ReadAllBytes("ALADDINPacketTunnel_App_Store_Distribution.mobileprovision")) | Out-File -Encoding ASCII ext_profile_base64.txt
```

**Проверка:**
- Откройте файлы `app_profile_base64.txt` и `ext_profile_base64.txt`
- Убедитесь, что они содержат длинную строку base64 (без переносов строк)
- Скопируйте содержимое каждого файла

### ШАГ 8: Обновить GitHub Secrets

1. Перейдите в ваш репозиторий на GitHub: https://github.com/sergey234/ALADDIN_FAMILY
2. Откройте **Settings** → **Secrets and variables** → **Actions**
3. Найдите секрет **`PROVISIONING_PROFILE_APP`**
4. Нажмите **"Update"** (Обновить)
5. Вставьте содержимое файла `app_profile_base64.txt` (весь base64 текст)
6. Нажмите **"Update secret"**
7. Повторите для секрета **`PROVISIONING_PROFILE_EXTENSION`** с содержимым `ext_profile_base64.txt`

**⚠️ ВАЖНО:**
- Не добавляйте переносы строк в base64
- Не добавляйте пробелы в начале или конце
- Скопируйте весь текст целиком

---

### ШАГ 9: Проверить результат

1. Запустите workflow: https://github.com/sergey234/ALADDIN_FAMILY/actions/workflows/check-secrets.yml
2. Проверьте логи на наличие ошибок
3. Если ошибка `Provisioning profile doesn't include signing certificate` исчезла, значит проблема решена!

## 🔍 ДИАГНОСТИКА

Если после обновления профилей проблема сохраняется:

1. **Проверьте fingerprint сертификата в профиле:**
   ```bash
   security cms -D -i ALADDIN_App_Store_Distribution.mobileprovision | plutil -extract DeveloperCertificates.0 raw -o - - | base64 -d > cert.der
   openssl x509 -inform DER -in cert.der -fingerprint -noout
   ```
   Должен быть: `SHA1 Fingerprint=88:C0:EF:8C:CC:E2:42:95:35:7F:B2:64:74:EB:76:E9:F5:F9:25:FB`

2. **Проверьте fingerprint сертификата в keychain:**
   ```bash
   security find-identity -v -p codesigning
   ```
   Найдите строку с `88C0EF8CCCE24295357FB26474EB76E9F5F925FB`

3. **Сравните:** Fingerprint должны совпадать!

## 📞 ЕСЛИ ВОЗНИКЛИ ПРОБЛЕМЫ

1. **Не могу найти сертификат в списке:**
   - Убедитесь, что сертификат активен и не истек
   - Проверьте, что вы используете правильный Apple Developer аккаунт

2. **Не могу найти App ID:**
   - Создайте новый App ID с нужным Bundle ID
   - Включите необходимые capabilities

3. **Профиль не скачивается:**
   - Попробуйте другой браузер
   - Очистите кеш браузера
   - Проверьте, что профиль создан успешно

4. **GitHub Secret не обновляется:**
   - Убедитесь, что у вас есть права на изменение secrets
   - Проверьте, что base64 текст скопирован полностью
