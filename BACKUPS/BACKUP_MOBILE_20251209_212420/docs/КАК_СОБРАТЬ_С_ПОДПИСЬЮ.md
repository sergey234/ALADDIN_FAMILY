## 🚀 ЗАПУСК СБОРКИ С ПОДПИСЬЮ

   - Расположение: справа вверху страницы

2. **Выберите ветку:**
   - Выберите: `master` (или `main`)

3. **Нажмите "Run workflow":**

   - Нажмите на неё

- Появится новый запуск в списке

## 📋 ЧТО ПРОИСХОДИТ В WORKFLOW

### Шаги сборки:

1. **Checkout code** - загрузка кода из репозитория
2. **Setup Xcode** - установка Xcode 16.2.0
3. **Cache dependencies** - использование кэша для ускорения
4. **Show Xcode version** - проверка версии Xcode
5. **Setup Provisioning Profiles** ← **ВАЖНО!**
   - Декодирует profiles из секретов
   - Устанавливает в `~/Library/MobileDevice/Provisioning Profiles/`
   - Проверяет, что profiles установлены
6. **Build Archive (with signing)** ← **ВАЖНО!**
   - Собирает Archive с Manual signing
   - Использует provisioning profiles
   - Подписывает билд сертификатом "iPhone Distribution"
7. **List Archive Contents** - проверка структуры Archive
8. **Export IPA** - экспорт IPA файла для App Store
9. **Upload to App Store Connect** - загрузка в App Store Connect (если API ключи настроены)
10. **Upload IPA as artifact** - сохранение IPA как артефакт для скачивания

## 🔍 ПРОВЕРКА ЛОГОВ

### Шаг "Setup Provisioning Profiles":

**✅ Должно быть:**
```
Setting up provisioning profiles...
✅ App provisioning profile installed
✅ Extension provisioning profile installed
📋 Installed provisioning profiles:
-rw-r--r--  1 runner  staff  XXXX app.mobileprovision
-rw-r--r--  1 runner  staff  XXXX extension.mobileprovision
```

**❌ Если ошибка:**
```
❌ PROVISIONING_PROFILE_APP secret is not set!
❌ PROVISIONING_PROFILE_EXTENSION secret is not set!
```
→ **Решение:** Добавить секреты в GitHub (см. ниже)

---

### Шаг "Build Archive (with signing)":

**✅ Должно быть:**
```
Building archive with manual signing...
Team ID: 6CJVBBUGSN
Bundle ID: family.aladdin.ios
** ARCHIVE SUCCEEDED **
```

**❌ Если ошибка:**
```
error: No profiles for 'family.aladdin.ios' were found
```
→ **Решение:** Проверить, что provisioning profiles правильно установлены

```
error: CODE_SIGN_STYLE=Manual requires provisioning profile
```
→ **Решение:** Проверить, что profiles установлены в правильную директорию

---

### Шаг "Export IPA":

**✅ Должно быть:**
```
Exporting IPA...
IPA file: ./build/export/ALADDIN.ipa
✅ IPA file found
```

**❌ Если ошибка:**
```
Error: IPA file not found!
```
→ **Решение:** Проверить логи предыдущих шагов, возможно проблема с подписью

## 📥 РЕЗУЛЬТАТ

### После успешной сборки:

1. **IPA файл будет доступен как артефакт:**
   - Откройте страницу запуска (🟢 Success)
   - Прокрутите вниз до раздела "Artifacts"
   - Нажмите на `ALADDIN-IPA`
   - Скачайте архив
   - Внутри будет `.ipa` файл

2. **Если API ключи настроены:**
   - IPA автоматически загрузится в App Store Connect
   - Проверьте статус в App Store Connect через 30-60 минут

3. **Если API ключи НЕ настроены:**
   - Скачайте IPA из артефактов
   - Загрузите вручную через Transporter (см. инструкцию ниже)

## 🔧 ЕСЛИ СЕКРЕТЫ НЕ НАСТРОЕНЫ

### Как добавить секреты:

1. **Откройте настройки секретов:**
   https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions

2. **Добавьте каждый секрет:**

   **APPLE_TEAM_ID:**
   - Name: `APPLE_TEAM_ID`
   - Secret: `6CJVBBUGSN`
   - Нажмите "Add secret"

   **PROVISIONING_PROFILE_APP:**
   - Name: `PROVISIONING_PROFILE_APP`
   - Secret: вставьте содержимое из `~/Desktop/ALADDIN_Profiles/app_profile_base64.txt`
   - Нажмите "Add secret"

   **PROVISIONING_PROFILE_EXTENSION:**
   - Name: `PROVISIONING_PROFILE_EXTENSION`
   - Secret: вставьте содержимое из `~/Desktop/ALADDIN_Profiles/extension_profile_base64.txt`
   - Нажмите "Add secret"

3. **Проверьте, что секреты добавлены:**
   - Должны быть видны в списке (но содержимое скрыто)

## 📤 АЛЬТЕРНАТИВА: ЗАГРУЗКА ВРУЧНУЮ

### Если API ключи не настроены:

1. **Скачайте IPA из артефактов:**
   - Откройте страницу успешного запуска
   - Скачайте `ALADDIN-IPA`
   - Распакуйте архив
   - Найдите файл `ALADDIN.ipa`

2. **Загрузите через Transporter:**
   - Откройте приложение Transporter (из App Store)
   - Перетащите `.ipa` файл в окно Transporter
   - Нажмите "Deliver"
   - Дождитесь загрузки

**Подробная инструкция:**
`docs/ЗАГРУЗКА_ЧЕРЕЗ_TRANSPORTER.md`
