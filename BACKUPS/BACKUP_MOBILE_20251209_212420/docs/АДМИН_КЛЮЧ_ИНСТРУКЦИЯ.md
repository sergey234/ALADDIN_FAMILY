## 📋 ЧТО ТАКОЕ АДМИН-КЛЮЧ?

**Админ-ключ** — это пароль для доступа к админ-панели `/admin/`.

- Используется для авторизации в админке
- Требуется для всех `/api/admin/*` endpoints
- Передается в заголовке `X-Admin-Key`

## ⚙️ КАК ИЗМЕНИТЬ АДМИН-КЛЮЧ

### Вариант 1: Через .env файл (рекомендуется)

1. **Создать/отредактировать `.env` файл на сервере:**
```bash
ssh root@149.154.65.180
cd /opt/aladdin-backend
nano .env
```

2. **Добавить строку:**
```
PAYMENT_ADMIN_KEY=ВАШ_СЕКРЕТНЫЙ_КЛЮЧ_ЗДЕСЬ
```

**Пример:**
```
PAYMENT_ADMIN_KEY=MySuperSecretAdminKey2025!
```

3. **Сохранить файл и перезапустить payment_service**

### Вариант 2: Через переменную окружения при запуске

При запуске payment_service добавить:
```bash
PAYMENT_ADMIN_KEY=ВАШ_КЛЮЧ uvicorn main:app --host 0.0.0.0 --port 8000
```

## 🔐 РЕКОМЕНДАЦИИ ДЛЯ КЛЮЧА

**Хороший ключ должен быть:**
- ✅ Длинным (минимум 20 символов)
- ✅ Случайным (не используйте простые слова)
- ✅ Содержать буквы, цифры и символы
- ✅ Уникальным (не используйте в других местах)

**Примеры хороших ключей:**
```
Aladdin2025!AdminSecretKey#Secure
MyAdminKey_2025_Production_Safe
SecureAdminAccess2025!@#$%^&*
```

**Плохие ключи (НЕ используйте):**
```
admin
password
123456
admin123
```

## 🛠️ БЫСТРАЯ УСТАНОВКА СВОЕГО КЛЮЧА

**Скрипт для установки ключа:**

1. Выберите свой ключ (например: `MySecureAdminKey2025!`)
2. Запустите команду на сервере:
```bash
echo "PAYMENT_ADMIN_KEY=MySecureAdminKey2025!" >> /opt/aladdin-backend/.env
```
3. Перезапустите payment_service
