## 🎯 ЧТО НУЖНО СДЕЛАТЬ СЕЙЧАС

### ШАГ 1: Проверить, какой сертификат в профиле

**На странице профиля:**

1. **Найдите раздел "Certificates"** (Сертификаты)
2. **Нажмите на сертификат**, чтобы увидеть его детали
3. **Проверьте имя сертификата:**
   - Должно быть: **"Apple Distribution: SERGEY KHLYSTOV (***)"**
   - Или похожее имя с вашим именем

**Если сертификат правильный:**
- ✅ Профиль уже содержит правильный сертификат
- ✅ Можно скачать профиль и обновить GitHub Secrets

**Если сертификат неправильный:**
- ❌ Нужно отредактировать профиль или создать новый
- ❌ Выбрать правильный сертификат

---

### ШАГ 2: Если сертификат правильный - скачать профиль

1. **На странице профиля нажмите кнопку "Download"** (Скачать)
2. **Сохраните файл** с именем: `ALADDIN_App_Store_Distribution.mobileprovision`
3. **Проверьте файл** - он должен быть в формате `.mobileprovision`

---

### ШАГ 3: Проверить сертификат в скачанном профиле (опционально)

**Для macOS/Linux:**

```bash
# Декодировать профиль и извлечь сертификат
security cms -D -i ALADDIN_App_Store_Distribution.mobileprovision | plutil -extract DeveloperCertificates.0 raw -o - - | base64 -d > cert.der

# Проверить fingerprint сертификата
openssl x509 -inform DER -in cert.der -fingerprint -noout

# Проверить имя сертификата
openssl x509 -inform DER -in cert.der -subject -noout
```

**Ожидаемый результат:**
- Fingerprint должен быть: `SHA1 Fingerprint=88:C0:EF:8C:CC:E2:42:95:35:7F:B2:64:74:EB:76:E9:F5:F9:25:FB`
- Subject должен содержать: `CN = Apple Distribution: SERGEY KHLYSTOV (***)`

---

### ШАГ 4: Если сертификат неправильный - отредактировать профиль

1. **На странице профиля нажмите кнопку "Edit"** (Редактировать)
2. **Найдите раздел "Certificates"** (Сертификаты)
3. **Снимите галочку** с неправильного сертификата
4. **Поставьте галочку** на правильный сертификат: **"Apple Distribution: SERGEY KHLYSTOV (***)"**
5. **Нажмите "Generate"** (Создать) или "Save" (Сохранить)
6. **Скачайте обновленный профиль**

---

## ⚠️ ВАЖНО

**Если в профиле несколько сертификатов:**
- Выберите тот, который активен и не истек
- Выберите тот, который соответствует сертификату в keychain (fingerprint `88C0EF8CCCE24295357FB26474EB76E9F5F925FB`)

**Если сертификата нет в списке:**
- Перейдите в раздел Certificates: https://developer.apple.com/account/resources/certificates/list
- Убедитесь, что сертификат существует и активен
- Если его нет, создайте новый сертификат типа "Apple Distribution"

## 🔍 КАК ПРОВЕРИТЬ СЕРТИФИКАТ В KEYCHAIN

**Для проверки, какой сертификат у вас в keychain:**

```bash
security find-identity -v -p codesigning
```

**Найдите строку:**
```
1) 88C0EF8CCCE24295357FB26474EB76E9F5F925FB "Apple Distribution: SERGEY KHLYSTOV (***)"
```

Этот fingerprint должен совпадать с fingerprint сертификата в профиле!
