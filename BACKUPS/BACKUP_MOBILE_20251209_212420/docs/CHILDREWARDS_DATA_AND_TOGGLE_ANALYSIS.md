## 1. 📊 ДАННЫЕ НА ЭКРАНЕ ВОЗНАГРАЖДЕНИЙ РЕБЁНКА

### Текущее состояние:

**Данные хранятся в `@AppStorage` (UserDefaults):**
- `child_unicorn_balance` = 245 (баланс единорогов)
- `child_weekly_earned` = 128 (заработано за неделю)
- `child_weekly_punished` = 45 (списано за неделю)
- `child_goal_title` = "Новая игра PS5" (название цели)
- `child_goal_cost` = 800 (стоимость цели)
- `child_goal_progress` = 0.306 (прогресс цели)

### Это настоящие данные?

**НЕТ, это мок-данные (тестовые значения):**

1. **Хранятся локально** в `UserDefaults` — не синхронизируются с сервером
2. **Имеют дефолтные значения** (245, 128, 45, "Новая игра PS5", 800)
3. **ViewModel пытается загрузить реальные данные** через API (`ChildRewardsViewModel.load()`), но:
   - Использует API endpoints: `getParentalControlStats`, `getReferralStats`, `getReferralRewards`
   - Если API не работает или нет данных — используются мок-значения

### Нужны ли актуальные данные?

**ДА, нужны!** Для продакшена необходимо:

1. **Интеграция с API:**
   - Загрузка баланса из `ChildRewardsService` API
   - Синхронизация с сервером при изменении баланса
   - Загрузка истории наград из API

2. **Реальные данные:**
   - Баланс единорогов должен браться из API
   - История наград должна загружаться из API
   - Цели должны синхронизироваться с родительским интерфейсом

3. **Текущая реализация:**
   - `ChildRewardsViewModel` имеет метод `load()`, но он не вызывается автоматически
   - Данные остаются мок-значениями до интеграции с реальным API

## 2. 🔄 ТУМБЛЕР СЕМЕЙНОЙ ЗАЩИТЫ

### Расположение:

**Главная страница → Жёлтая карточка "Семья" → Правый верхний угол**

### Как работает:

```swift
@AppStorage("family_protection_enabled") private var isFamilyProtectionEnabled: Bool = true

Button(action: {
    isFamilyProtectionEnabled.toggle()
}) {
    // UI тумблера
}
```

### Это реально работает?

**ДА, работает реально:**

1. **Сохраняет состояние** в `UserDefaults` через `@AppStorage`
2. **Мгновенно переключается** при нажатии
3. **Сохраняется между запусками** приложения

### Что делает тумблер?

**Включает/выключает семейную защиту:**
- **ON (включено):** Семейная защита активна — все члены семьи защищены
- **OFF (выключено):** Семейная защита отключена — защита не работает

### Нужна ли интеграция с API?

**ДА, для продакшена:**
- Текущая реализация только сохраняет локально
- Нужно отправлять состояние на сервер при изменении
- Нужно синхронизировать с другими устройствами семьи

## 3. ⚙️ КНОПКА НАСТРОЕК НА ЭКРАНЕ ВОЗНАГРАЖДЕНИЙ

### Расположение:

**Экран вознаграждений ребёнка → Правый верхний угол → Шестерёнка**

### Проблема:

**Кнопка не работала** — при нажатии ничего не происходило

### Причина:

- `showSettingsSheet = true` устанавливался, но `.sheet()` модальное окно не было добавлено в `body`

### Решение:

**✅ ИСПРАВЛЕНО:**

1. **Создан компонент:** `ChildRewardsSettingsModal.swift`
   - Модальное окно с настройками цели
   - Редактирование названия цели
   - Редактирование стоимости цели
   - Информационная карточка

2. **Добавлен `.sheet()` в `ChildRewardsScreen`:**
   ```swift
   .sheet(isPresented: $showSettingsSheet) {
       ChildRewardsSettingsModal(isPresented: $showSettingsSheet)
           .environmentObject(localizationManager)
   }
   ```

3. **Добавлена локализация** (RU + EN):
   - `child_rewards_settings_title`
   - `child_rewards_settings_goal_title`
   - `child_rewards_settings_edit_button`
   - И другие ключи

### Что теперь происходит при нажатии?

**Открывается модальное окно настроек:**
- Редактирование цели (название и стоимость)
- Сохранение изменений в `UserDefaults`
- Информационная карточка с объяснением
