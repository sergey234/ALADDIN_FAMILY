# 🧪 S4-06: НАГРУЗОЧНОЕ ТЕСТИРОВАНИЕ (5,000 ПОЛЬЗОВАТЕЛЕЙ)

**Статус:** Ожидает выполнения  
**Приоритет:** Высокий  
**Время:** 2-3 часа

---

## 🎯 ЦЕЛЬ

Проверить производительность системы под нагрузкой 5,000 одновременных пользователей.

---

## 📋 ЧТО НУЖНО СДЕЛАТЬ

### 1. Подготовка

**Проверить текущее состояние:**
```bash
# Проверить ресурсы сервера
free -h
df -h
nproc

# Проверить текущую нагрузку
systemctl status aladdin-api-gateway
systemctl status aladdin-backend
```

**Убедиться, что оптимизации применены:**
- Redis кэширование работает
- Connection pooling настроен
- Rate limiting активен

---

### 2. Выполнить нагрузочное тестирование

**wrk (5,000 соединений, 20 потоков, 60 секунд):**
```bash
wrk -t20 -c5000 -d60s --timeout 10s https://aladdin-ai.ru/api/health
```

**Locust (5,000 пользователей, скорость роста 50/сек):**
```bash
locust -f locustfile.py \
  --host=https://aladdin-ai.ru \
  --users 5000 \
  --spawn-rate 50 \
  --run-time 5m
```

**Apache Bench (10,000 запросов, 500 одновременных):**
```bash
ab -n 10000 -c 500 -k -s 10 https://aladdin-ai.ru/api/health
```

---

### 3. Мониторинг

**Создать скрипт мониторинга:**
```bash
#!/bin/bash
# monitor_load_test.sh

while true; do
    echo "=== $(date) ==="
    echo "CPU: $(top -bn1 | grep "Cpu(s)" | awk '{print $2}')"
    echo "RAM: $(free -h | grep Mem | awk '{print $3 "/" $2}')"
    echo "Connections: $(netstat -an | grep :8001 | wc -l)"
    echo "API Gateway status: $(systemctl is-active aladdin-api-gateway)"
    sleep 5
done
```

---

### 4. Анализ результатов

**Что проверить:**
- ✅ Время отклика (может быть до 500ms для 95% запросов)
- ✅ Успешность запросов (должно быть > 95%)
- ✅ Ошибки (допустимо до 5%)
- ✅ Использование CPU (может быть до 90%)
- ✅ Использование RAM (может быть до 90%)
- ✅ Очередь запросов
