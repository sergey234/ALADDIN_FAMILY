### 3. ThreatScenariosGallery ✅
**Файл:** `Components/ThreatScenariosGallery.swift`

**Функциональность:**
- Горизонтальный слайдер с 6 реальными сценариями угроз
- Каждый сценарий включает:
  - Иконку
  - Заголовок
  - Описание
  - Индикатор доступности
  - Кнопку действия ("Как защититься" / "Получить защиту")

**Сценарии:**
1. Угрозы мошенничества (Family+)
2. Фишинговые письма (Personal+)
3. Вредные приложения (Personal+)
4. Опасный контент для детей (Family+)
5. Угрозы IoT (Family+)
6. Deepfake атаки (Premium+)

**Особенности:**
- Горизонтальный ScrollView
- Карточки фиксированной ширины (280pt)
- Умная навигация в зависимости от доступности
