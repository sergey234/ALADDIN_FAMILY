## 🗑️ ШАГ 1: УДАЛЕНИЕ СТАРЫХ ПРОФИЛЕЙ И СЕКРЕТОВ

### 1.1. Удалить старые профили в Developer Portal

1. Откройте: https://developer.apple.com/account/resources/profiles/list
2. Найдите и **удалите**:
   - "ALADDIN App Store Distribution" (UUID: `de134a6b-7135-4f75-bc3b-4a68fd753f7c`)
   - "ALADDIN PacketTunnel App Store Distribution" (UUID: `c0a22622-4b23-4be3-b18d-b744dbf8e6ce`)
   - Любые другие профили с похожими именами

### 1.2. Удалить старые секреты в GitHub

1. Откройте: https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions
2. Найдите `PROVISIONING_PROFILE_APP`
3. Нажмите **"Delete"** (или "Удалить")
4. Подтвердите удаление
5. Повторите для `PROVISIONING_PROFILE_EXTENSION`

### 1.3. Удалить старые файлы локально

```bash
# Удалить старые файлы из Downloads
rm ~/Downloads/ALADDIN_App_Store_Distribution.mobileprovision
rm ~/Downloads/ALADDIN_PacketTunnel_App_Store_Distribution.mobileprovision

# Удалить старые base64 файлы
rm ~/Desktop/ALADDIN_Profiles/app_profile_appstore_base64_CORRECT.txt
rm ~/Desktop/ALADDIN_Profiles/extension_profile_appstore_base64_CORRECT.txt
```

## ✅ ШАГ 2: СОЗДАНИЕ НОВЫХ ПРОФИЛЕЙ

### 2.1. Создать новый профиль для App

1. Откройте: https://developer.apple.com/account/resources/profiles/list
2. Нажмите **"+ (Create a new profile)"**
3. Выберите тип: **"App Store"** (НЕ Development, НЕ Ad Hoc!)
4. Выберите App ID: **family.aladdin.ios**
5. Выберите сертификат: **Apple Distribution: SERGEY KHLYSTOV**
6. Назовите профиль: **"ALADDIN App Store Distribution"**
7. Нажмите **"Generate"**
8. **Скачайте профиль**

### 2.2. Проверить новый App профиль

После скачивания проверьте:

```bash
# Проверка типа профиля
security cms -D -i ~/Downloads/ALADDIN_App_Store_Distribution.mobileprovision 2>/dev/null | plutil -extract ProvisionedDevices raw -o - - 2>/dev/null || echo "✅ App Store Distribution (нет ProvisionedDevices)"

# Проверка UUID (должен быть ДРУГОЙ!)
strings ~/Downloads/ALADDIN_App_Store_Distribution.mobileprovision | grep -oE '[0-9A-F]{8}-[0-9A-F]{4}-[0-9A-F]{4}-[0-9A-F]{4}-[0-9A-F]{12}' | head -1
```

**ВАЖНО:** UUID должен быть **ДРУГОЙ** (не `de134a6b-7135-4f75-bc3b-4a68fd753f7c`)!

### 2.3. Закодировать App профиль в base64

```bash
base64 -i ~/Downloads/ALADDIN_App_Store_Distribution.mobileprovision > ~/Desktop/ALADDIN_Profiles/app_profile_appstore_base64_NEW.txt
```

### 2.4. Обновить GitHub Secret для App

1. Откройте файл: `~/Desktop/ALADDIN_Profiles/app_profile_appstore_base64_NEW.txt`
2. Выделите ВСЁ (Cmd+A)
3. Скопируйте (Cmd+C)
4. Откройте: https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions
5. Нажмите **"New repository secret"**
6. Name: `PROVISIONING_PROFILE_APP`
7. Secret: Вставьте содержимое (Cmd+V)
8. Нажмите **"Add secret"**

## ✅ ШАГ 3: СОЗДАНИЕ ПРОФИЛЯ ДЛЯ EXTENSION

### 3.1. Создать новый профиль для Extension

1. На той же странице: https://developer.apple.com/account/resources/profiles/list
2. Нажмите **"+ (Create a new profile)"**
3. Выберите тип: **"App Store"** (НЕ Development, НЕ Ad Hoc!)
4. Выберите App ID: **family.aladdin.ios.packetTunnel**
5. Выберите сертификат: **Apple Distribution: SERGEY KHLYSTOV**
6. Назовите профиль: **"ALADDIN PacketTunnel App Store Distribution"**
7. Нажмите **"Generate"**
8. **Скачайте профиль**

### 3.2. Проверить новый Extension профиль

```bash
# Проверка типа профиля
security cms -D -i ~/Downloads/ALADDIN_PacketTunnel_App_Store_Distribution.mobileprovision 2>/dev/null | plutil -extract ProvisionedDevices raw -o - - 2>/dev/null || echo "✅ App Store Distribution (нет ProvisionedDevices)"

# Проверка UUID (должен быть ДРУГОЙ!)
strings ~/Downloads/ALADDIN_PacketTunnel_App_Store_Distribution.mobileprovision | grep -oE '[0-9A-F]{8}-[0-9A-F]{4}-[0-9A-F]{4}-[0-9A-F]{4}-[0-9A-F]{12}' | head -1

# Проверка capabilities
security cms -D -i ~/Downloads/ALADDIN_PacketTunnel_App_Store_Distribution.mobileprovision 2>/dev/null | grep -q "com.apple.developer.networking.networkextension" && echo "✅ Network Extensions" || echo "❌ Нет Network Extensions"
security cms -D -i ~/Downloads/ALADDIN_PacketTunnel_App_Store_Distribution.mobileprovision 2>/dev/null | grep -q "com.apple.developer.networking.vpn.api" && echo "✅ Personal VPN" || echo "❌ Нет Personal VPN"
```

**ВАЖНО:** UUID должен быть **ДРУГОЙ** (не `c0a22622-4b23-4be3-b18d-b744dbf8e6ce`)!

### 3.3. Закодировать Extension профиль в base64

```bash

```

### 3.4. Обновить GitHub Secret для Extension

2. Выделите ВСЁ (Cmd+A)
3. Скопируйте (Cmd+C)
4. На той же странице GitHub Secrets
5. Нажмите **"New repository secret"**
