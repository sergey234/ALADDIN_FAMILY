# 🚨 КРИТИЧЕСКАЯ ОШИБКА: Неправильная структура YAML в appstore.yml

**Дата:** 1 декабря 2025  
**Проблема:** Workflow не запускался из-за неправильной структуры секции `on:`

---

## ❌ ПРОБЛЕМА

### Неправильная структура (БЫЛО):

```yaml
on:
  workflow_dispatch:
  push:
    branches:
      - master
    tags:  # ← ОШИБКА! tags находится ВНУТРИ push
      - 'v*'
```

**Почему это неправильно:**
- `tags:` находится внутри секции `push:`
- YAML парсер интерпретирует это как `push.tags`, а не как отдельный триггер
- GitHub Actions не видит триггер `tags` на верхнем уровне
- Результат: секция `on:` парсится как пустая `{}`

---

## ✅ РЕШЕНИЕ

### Правильная структура (СТАЛО):

```yaml
on:
  workflow_dispatch:
  push:
    branches:
      - master
  tags:  # ← ПРАВИЛЬНО! tags на том же уровне, что и push
    - 'v*'
```

**Почему это правильно:**
- `workflow_dispatch`, `push` и `tags` находятся на одном уровне
- Каждый из них - отдельный триггер
- GitHub Actions правильно распознает все триггеры

---

## 🔍 КАК БЫЛО ОБНАРУЖЕНО

1. **Python YAML парсер показал пустую секцию `on:`:**
   ```python
   on_section = {}  # Пустой словарь!
   ```

2. **Проверка структуры файла:**
   - Строки 3-9 содержали триггеры
   - Но YAML парсер не мог их правильно распарсить

3. **Причина:**
   - Неправильные отступы: `tags:` был внутри `push:`

---

## 📋 ПРАВИЛЬНАЯ СТРУКТУРА ДЛЯ GITHUB ACTIONS

### Вариант 1: Отдельные триггеры (рекомендуется)

```yaml
on:
  workflow_dispatch:
  push:
    branches:
      - master
  tags:
    - 'v*'
```

### Вариант 2: Комбинированный push

```yaml
on:
  workflow_dispatch:
  push:
    branches:
      - master
    tags:
      - 'v*'
```

**⚠️ ВАЖНО:** Вариант 2 работает только для `push`, но `tags` должен быть отдельным триггером!

## ✅ ПРОВЕРКА ИСПРАВЛЕНИЯ

После исправления:

```python
import yaml

with open('.github/workflows/appstore.yml', 'r') as f:
    data = yaml.safe_load(f)
    
on_section = data.get('on', {})
print(list(on_section.keys()))
# Должно вывести: ['workflow_dispatch', 'push', 'tags']
```

**Проблема:** Неправильная структура YAML - `tags` был внутри `push`  
**Решение:** Переместить `tags` на тот же уровень, что и `push`  
**Результат:** Workflow должен запускаться при push в master и при создании тегов v*
