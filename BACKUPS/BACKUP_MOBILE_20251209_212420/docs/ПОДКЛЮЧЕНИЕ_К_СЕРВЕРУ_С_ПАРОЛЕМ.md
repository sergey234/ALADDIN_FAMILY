## 🛠️ ИСПОЛЬЗОВАНИЕ EXPECT ДЛЯ АВТОМАТИЗАЦИИ

### Что такое expect?

`expect` — инструмент для автоматизации интерактивных команд. Позволяет автоматически вводить пароль при SSH подключении.

### Установка expect:

```bash
# macOS
brew install expect

# Linux (Ubuntu/Debian)
apt install expect

# Проверка
which expect
```
