## 📋 ПОШАГОВЫЙ ПЛАН

### **ШАГ 1: Проверка текущего состояния** ⏳
- Найти директорию payment_service на сервере
- Проверить текущую версию main.py
- Проверить наличие app/dashboard_stats.py
- Проверить статус payment_service

### **ШАГ 2: Создание бэкапа** ⏳
- Создать бэкап main.py
- Создать бэкап app/ (если есть)
- Сохранить список файлов

### **ШАГ 3: Загрузка dashboard_stats.py** ⏳
- Загрузить app/dashboard_stats.py на сервер
- Проверить права доступа
- Проверить синтаксис Python

### **ШАГ 4: Загрузка обновленного main.py** ⏳
- Загрузить main.py с dashboard endpoints
- Проверить синтаксис Python
- Проверить импорты

### **ШАГ 5: Перезапуск payment_service** ⏳
- Остановить service
- Проверить логи
- Запустить service
- Проверить статус

### **ШАГ 6: Проверка работы API** ⏳
- Проверить /api/dashboard/public/stats
- Проверить /api/dashboard/public/threats-timeline
- Проверить /api/dashboard/public/top-threats
- Проверить dashboard на сайте
