## 🔍 ЧТО ПРОИЗОШЛО

### Проблема 1: Команда `sed` создала дубликаты
- Команда `sed -i '/sleep_manager = None/a monitor_manager = None\nalert_manager = None'` создала более 1700 дубликатов `alert_manager = None`
- Причина: неправильный синтаксис команды `sed` в многострочном режиме

### Проблема 2: `expect` интерпретирует Python код
- Команда `expect` пытается интерпретировать `i+1` как команду TCL
- Причина: вложенные Python скрипты в `expect` конфликтуют

## ✅ РЕШЕНИЕ

### Вариант 1: Создать патч-файл локально и применить на сервере
1. Создать файл с изменениями локально
2. Загрузить на сервер через `scp`
3. Применить изменения через Python скрипт

### Вариант 2: Редактировать файл напрямую на сервере
1. Подключиться к серверу
2. Отредактировать файл вручную через `nano` или `vi`
3. Или использовать простой Python скрипт без вложенных конструкций

### Вариант 3: Использовать простые команды
1. Добавить импорты через `sed` (правильно)
2. Добавить переменные через `sed` (правильно)
3. Добавить код через `cat >>` (проще)
