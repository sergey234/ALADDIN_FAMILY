## 🎯 КАК ПРОВЕРИТЬ, ЧТО СЕКРЕТЫ РАБОТАЮТ

### Способ 1: Запустить workflow

1. **Открыть GitHub Actions:**
   https://github.com/sergey234/ALADDIN_FAMILY/actions

2. **Запустить workflow:**
   - Найти "Build and Upload to App Store"
   - Нажать "Run workflow"
   - Выбрать ветку: `master` или `main`
   - Нажать "Run workflow"

3. **Проверить логи:**
   - Если секреты работают, workflow использует их
   - Если нет - будет ошибка "secret not found"
