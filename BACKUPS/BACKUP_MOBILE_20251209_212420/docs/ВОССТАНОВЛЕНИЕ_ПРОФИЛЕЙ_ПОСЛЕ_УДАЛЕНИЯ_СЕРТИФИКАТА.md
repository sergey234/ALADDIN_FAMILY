## 📝 ПОШАГОВАЯ ИНСТРУКЦИЯ

### ШАГ 1: Удалить старые Invalid профили

1. **Откройте:** https://developer.apple.com/account/resources/profiles/list
2. **Найдите профиль:** `ALADDIN App Store Distribution` (Status: Invalid)
3. **Нажмите на профиль**, чтобы открыть детали
4. **Нажмите кнопку "Delete"** или "Remove"
5. **Подтвердите удаление**
6. **Повторите для:** `ALADDINPacketTunnel App Store Distribution`

**⚠️ ВАЖНО:** Development профиль `ALADDINPacketTunnel Dev New` НЕ удаляйте!

---

### ШАГ 2: Создать новый профиль для основного приложения

1. **На странице Profiles нажмите кнопку "+"** (плюс) в правом верхнем углу
2. **Выберите тип профиля:** **"App Store"**
3. **Нажмите "Continue"**

**Настройки профиля:**

**2.1. Выбор App ID:**
- Найдите и выберите: `family.aladdin.ios`
- Нажмите **"Continue"**

**2.2. Выбор сертификата:**
- **КРИТИЧЕСКИ ВАЖНО:** Выберите сертификат **"SERGEY KHLYSTOV - Distribution"** (тот, который остался после удаления)
- Это должен быть сертификат с fingerprint `88C0EF8CCCE24295357FB26474EB76E9F5F925FB`
- Нажмите **"Continue"**

**2.3. Имя профиля:**
- Введите имя: `ALADDIN App Store Distribution`
- Нажмите **"Generate"** (Создать)

**2.4. Скачать профиль:**
- После создания нажмите кнопку **"Download"** (Скачать)
- Сохраните файл: `ALADDIN_App_Store_Distribution.mobileprovision`

---

### ШАГ 3: Создать новый профиль для расширения

1. **Снова нажмите кнопку "+"** (плюс)
2. **Выберите тип профиля:** **"App Store"**
3. **Нажмите "Continue"**

**Настройки профиля:**

**3.1. Выбор App ID:**
- Найдите и выберите: `family.aladdin.ios.packetTunnel`
- **ВАЖНО:** Этот App ID должен иметь включенные capabilities:
  - ✅ **Network Extensions**
  - ✅ **Personal VPN**
- Если этих capabilities нет, отредактируйте App ID и включите их
- Нажмите **"Continue"**

**3.2. Выбор сертификата:**
- **КРИТИЧЕСКИ ВАЖНО:** Выберите тот же сертификат **"SERGEY KHLYSTOV - Distribution"**
- Должен быть тот же сертификат, что и для основного приложения
- Нажмите **"Continue"**

**3.3. Имя профиля:**
- Введите имя: `ALADDINPacketTunnel App Store Distribution`
- Нажмите **"Generate"** (Создать)

**3.4. Скачать профиль:**
- Нажмите кнопку **"Download"** (Скачать)
- Сохраните файл: `ALADDINPacketTunnel_App_Store_Distribution.mobileprovision`

---

### ШАГ 4: Закодировать профили в base64

**Для macOS/Linux:**

```bash
# Для основного приложения
cat ALADDIN_App_Store_Distribution.mobileprovision | base64 > app_profile_base64.txt

# Для расширения
cat ALADDINPacketTunnel_App_Store_Distribution.mobileprovision | base64 > ext_profile_base64.txt
```

**Проверка:**
- Откройте файлы `app_profile_base64.txt` и `ext_profile_base64.txt`
- Убедитесь, что они содержат длинную строку base64 (без переносов строк)
- Скопируйте содержимое каждого файла

---

### ШАГ 5: Обновить GitHub Secrets

1. **Перейдите:** https://github.com/sergey234/ALADDIN_FAMILY
2. **Откройте:** Settings → Secrets and variables → Actions
3. **Найдите секрет:** `PROVISIONING_PROFILE_APP`
4. **Нажмите "Update"**
5. **Вставьте содержимое** файла `app_profile_base64.txt` (весь base64 текст)
6. **Нажмите "Update secret"**
7. **Повторите для:** `PROVISIONING_PROFILE_EXTENSION` с содержимым `ext_profile_base64.txt`

**⚠️ ВАЖНО:**
- Не добавляйте переносы строк в base64
- Не добавляйте пробелы в начале или конце
- Скопируйте весь текст целиком

---

### ШАГ 6: Проверить результат

1. **Запустите workflow:** https://github.com/sergey234/ALADDIN_FAMILY/actions/workflows/check-secrets.yml
2. **Проверьте логи** на наличие ошибок
3. **Если ошибка исчезла** - проблема решена!
