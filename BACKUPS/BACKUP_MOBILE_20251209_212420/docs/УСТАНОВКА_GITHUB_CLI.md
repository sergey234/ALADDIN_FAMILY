# 🔧 УСТАНОВКА GITHUB CLI

**Дата:** 29 ноября 2025  
**Цель:** Установить GitHub CLI для автоматического добавления секретов

---

## 📋 ИНСТРУКЦИЯ ПО УСТАНОВКЕ

### Вариант 1: Через Homebrew (рекомендуется)

1. **Проверить Homebrew:**
   ```bash
   brew --version
   ```

2. **Если Homebrew не установлен:**
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

3. **Установить GitHub CLI:**
   ```bash
   brew install gh
   ```

4. **Проверить установку:**
   ```bash
   gh --version
   ```

---

### Вариант 2: Через официальный установщик

1. **Скачать установщик:**
   - Перейти: https://cli.github.com/
   - Скачать для macOS

2. **Установить:**
   - Открыть скачанный файл
   - Следовать инструкциям

---

## 🔐 АВТОРИЗАЦИЯ

После установки:

1. **Авторизоваться:**
   ```bash
   gh auth login
   ```

2. **Следовать инструкциям:**
   - Выбрать GitHub.com
   - Выбрать HTTPS
   - Выбрать "Login with a web browser"
   - Нажать Enter
   - В браузере авторизоваться
   - Вернуться в терминал

3. **Проверить авторизацию:**
   ```bash
   gh auth status
   ```

---

## ✅ ПРОВЕРКА

После установки и авторизации:

```bash
gh --version
gh auth status
```

Должно показать:
- ✅ Версию GitHub CLI
- ✅ Статус авторизации
