## 📋 APP STORE CONNECT

### Главная страница:
https://appstoreconnect.apple.com

### Как попасть на страницу API ключей:

**Способ 1 (через меню):**
1. Откройте: https://appstoreconnect.apple.com
2. Войдите в аккаунт
3. Нажмите на ваше имя (правый верхний угол)
4. Выберите **"Users and Access"**
5. Перейдите на вкладку **"Keys"**

**Способ 2 (прямая ссылка - может не работать, если не авторизованы):**
https://appstoreconnect.apple.com/access/users

Затем перейдите на вкладку **"Keys"**

## ✅ ПРОВЕРКА ССЫЛОК

1. **App Store Connect:**

2. **GitHub:**
   - Убедитесь, что вы авторизованы

## 🔍 АЛЬТЕРНАТИВНЫЕ СПОСОБЫ

### App Store Connect (если прямая ссылка не работает):

1. Откройте: https://appstoreconnect.apple.com
2. Войдите
3. В меню слева найдите **"Users and Access"**
4. Перейдите на вкладку **"Keys"**

### GitHub Secrets (если прямая ссылка не работает):

1. Откройте: https://github.com/sergey234/ALADDIN_FAMILY
2. Нажмите **"Settings"**
3. В левом меню: **"Secrets and variables"** → **"Actions"**
