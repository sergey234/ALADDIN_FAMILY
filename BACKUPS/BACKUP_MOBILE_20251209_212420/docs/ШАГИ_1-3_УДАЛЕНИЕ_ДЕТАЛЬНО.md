ls ~/Downloads/ALADDIN_App_Store_Distribution.mobileprovision 2>/dev/null && echo "❌ Файл все еще существует" || echo "✅ Файл удален"
ls ~/Downloads/ALADDIN_PacketTunnel_App_Store_Distribution.mobileprovision 2>/dev/null && echo "❌ Файл все еще существует" || echo "✅ Файл удален"

#### Вариант 2: Через Finder (визуально)

1. **Откройте Finder**

2. **Удалите файлы из Downloads:**
   - Откройте папку `Downloads`
   - Найдите файлы:
     - `ALADDIN_App_Store_Distribution.mobileprovision`
     - `ALADDIN_PacketTunnel_App_Store_Distribution.mobileprovision`
   - Перетащите их в Корзину (или Cmd+Delete)

3. **Удалите base64 файлы:**

   - Найдите файлы:
     - `app_profile_appstore_base64_CORRECT.txt`
     - `extension_profile_appstore_base64_CORRECT.txt`
   - Перетащите их в Корзину (или Cmd+Delete)

4. **Очистите Корзину** (опционально):
