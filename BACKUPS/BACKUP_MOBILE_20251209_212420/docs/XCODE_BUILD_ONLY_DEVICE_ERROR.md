# 🔧 ОШИБКА: "Build only device cannot be used to run this target"

## 📋 ЧТО ЭТО ЗНАЧИТ

**Ошибка:**
```
A build only device cannot be used to run this target.
No supported iOS devices are available.
Connect a device to run your application or choose a simulated device as the destination.
```

**Причина:**
- Вы выбрали **"Any iOS Device (arm64)"** как destination
- Это устройство подходит **только для архивации** (Archive)
- **Не подходит для запуска** (Run) приложения

---

## ✅ РЕШЕНИЕ: ВЫБРАТЬ СИМУЛЯТОР

### **ШАГ 1: Выберите симулятор**

1. **В верхней панели Xcode** (рядом с кнопкой ▶️):
   - Найдите выпадающий список устройств
   - Сейчас там написано: **"Any iOS Device (arm64)"**

2. **Нажмите на этот список**

3. **Выберите симулятор:**
   - **iPhone 13 Pro Max** (или любой другой симулятор)
   - Или: **iPhone 15 Pro**
   - Или: **iPhone 14 Pro**

4. **После выбора симулятора:**
   - Список изменится на выбранный симулятор
   - Например: **"iPhone 13 Pro Max"**

---

### **ШАГ 2: Запустите приложение**

1. **Нажмите ⌘ + R** (или кнопку ▶️ Play)
2. **Xcode автоматически:**
   - Запустит симулятор (если не запущен)
   - Соберёт приложение
   - Установит на симулятор
   - Запустит приложение

---

## 📱 РАЗНИЦА МЕЖДУ УСТРОЙСТВАМИ

### **"Any iOS Device (arm64)" — для архивации:**
- ✅ Подходит для: **Product → Archive**
- ❌ НЕ подходит для: **Product → Run** (⌘R)
- Используется для создания архива для App Store

### **Симулятор (iPhone 13 Pro Max и т.д.) — для запуска:**
- ✅ Подходит для: **Product → Run** (⌘R)
- ✅ Подходит для: **Product → Build** (⌘B)
- ❌ НЕ подходит для: **Product → Archive** (для App Store)

---

## 🎯 КОГДА ЧТО ИСПОЛЬЗОВАТЬ

### **Для тестирования (⌘R):**
- Выберите **симулятор** (iPhone 13 Pro Max, iPhone 15 Pro и т.д.)
- Нажмите ⌘R
- Приложение запустится на симуляторе

### **Для архивации (Archive):**
- Выберите **"Any iOS Device (arm64)"**
- Product → Archive
- Создастся архив для App Store

---

## 🔍 КАК ВЫБРАТЬ СИМУЛЯТОР

### **В Xcode:**

1. **В верхней панели** (рядом с кнопкой ▶️):
   - Найдите выпадающий список
   - Нажмите на него

2. **Вы увидите список:**
   ```
   > iPhone 13 Pro Max
   > iPhone 15 Pro
   > iPhone 14 Pro
   > ...
   > Any iOS Device (arm64)  ← НЕ выбирайте для запуска!
   ```

3. **Выберите любой симулятор** (например, iPhone 13 Pro Max)

4. **Если симулятора нет в списке:**
   - Xcode → Window → Devices and Simulators
   - Нажмите "+" (добавить симулятор)
   - Выберите устройство и iOS версию
   - Нажмите "Create"

---

## ✅ КРАТКАЯ ИНСТРУКЦИЯ

### **Чтобы запустить приложение:**

1. **Выберите симулятор** в верхней панели Xcode
2. **Нажмите ⌘R** (или кнопку ▶️)
3. **Приложение запустится на симуляторе**

### **Чтобы создать архив:**

1. **Выберите "Any iOS Device (arm64)"** в верхней панели
2. **Product → Archive**
3. **Архив будет создан**

---

## ⚠️ ВАЖНО

**"Any iOS Device (arm64)"** — это **не реальное устройство**!
- Это виртуальное устройство для архивации
- Нельзя запустить на нём приложение
- Используется только для создания архива

**Симулятор** — это **виртуальный iPhone**:
- Можно запустить приложение
- Можно тестировать
- Нельзя создать архив для App Store
