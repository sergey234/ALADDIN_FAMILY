# 🔧 Как убрать файл из таргета в Xcode

## Способ 1: Через File Inspector (самый простой)

1. **Откройте Xcode** с проектом `ALADDIN.xcodeproj`

2. **Найдите файл** `TariffsViewModel.swift` в навигаторе проекта (левая панель)
   - Он находится в папке `ViewModels/`

3. **Выберите файл** (кликните один раз на `TariffsViewModel.swift`)

4. **Откройте File Inspector** (правая панель):
   - Нажмите `⌘⌥1` (Command + Option + 1)
   - Или: View → Inspectors → File Inspector
   - Или: Кликните на иконку документа в правой панели

5. **Найдите раздел "Target Membership"** в File Inspector
   - Он находится внизу правой панели

6. **Снимите галочку** с `ALADDINPacketTunnel`
   - Оставьте галочку только на `ALADDIN`

7. **Сохраните** (⌘S)

## Способ 2: Через настройки таргета (если не видно File Inspector)

1. **Выберите проект** в навигаторе (самый верхний элемент `ALADDIN`)

2. **Выберите таргет** `ALADDINPacketTunnel` в центральной панели

3. **Перейдите на вкладку "Build Phases"**

4. **Раскройте раздел "Compile Sources"**

5. **Найдите** `TariffsViewModel.swift` в списке

6. **Удалите** его:
   - Выделите строку с `TariffsViewModel.swift`
   - Нажмите клавишу `Delete` или кнопку `-` (минус) внизу списка

7. **Сохраните** (⌘S)

## Проверка

После удаления:
1. Очистите проект: **Product → Clean Build Folder** (⇧⌘K)
2. Соберите проект: **Product → Build** (⌘B)
3. Ошибки должны исчезнуть!

## Если не видно правую панель

Если правая панель (File Inspector) не видна:
1. Нажмите `⌘⌥0` (Command + Option + 0) - откроется правая панель
2. Или: View → Inspectors → Show File Inspector

## Если не видно раздел "Target Membership"

Если раздел "Target Membership" не виден:
1. Убедитесь, что файл выбран (подсвечен синим)
2. Прокрутите правую панель вниз - раздел находится внизу
3. Или используйте Способ 2 (через Build Phases)
