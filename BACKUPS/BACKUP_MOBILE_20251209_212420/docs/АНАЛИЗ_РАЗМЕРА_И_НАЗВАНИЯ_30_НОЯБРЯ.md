### Почему так мало при таком большом коде?

#### 1. Компиляция Swift
- Swift код компилируется в бинарный формат
- Оптимизация компилятора (`-O`) удаляет неиспользуемый код
- Сжатие при компиляции
- **Результат:** 1.3M строк → ~2-3 MB бинарного кода

#### 2. Ресурсы
- **Assets.xcassets:** 21 MB (исходники)
- **После компиляции:** ~3-5 MB (оптимизированные изображения)
- Xcode автоматически оптимизирует изображения
- Используются системные шрифты

#### 3. Frameworks
- **Сторонние:** Alamofire, Moya, Lottie, SDWebImage (~3-4 MB)
- **Системные:** SwiftUI, Foundation, NetworkExtension (уже в iOS)
- Копируются только те, которых нет в системе

#### 4. Структура архива (12 MB):
```
• Скомпилированный код:     ~2-3 MB
• Ресурсы (оптимизированные): ~3-5 MB
• Frameworks:                ~3-4 MB
• dSYM (для отладки):        ~2-3 MB
• Метаданные:                ~1 MB
─────────────────────────────────────
• ВСЕГО:                     ~12 MB ✅
```
