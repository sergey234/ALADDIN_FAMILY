## 🔧 КАК ДИАГНОСТИРОВАТЬ

### Шаг 1: Откройте Xcode Console

1. Запустите приложение в Xcode
2. Откройте Console (View → Debug Area → Activate Console)
3. Посмотрите на последние сообщения перед крашем

### Шаг 2: Проверьте логи краша

В Xcode Console ищите:
- `Fatal error`
- `Thread`
- `EXC_`
- `Terminating app`

### Шаг 3: Проверьте конкретное место краша

**Если краш при открытии Тарифов:**
- Проверьте `TariffsViewModel.init()`
- Проверьте загрузку продуктов StoreKit

**Если краш при нажатии на кнопку:**
- Проверьте `navigationManager.navigateTo(.activationCode)`
- Проверьте `ActivationCodeScreen.init()`

**Если краш при запуске:**
- Проверьте `ALADDINApp.init()`
- Проверьте инициализацию менеджеров
