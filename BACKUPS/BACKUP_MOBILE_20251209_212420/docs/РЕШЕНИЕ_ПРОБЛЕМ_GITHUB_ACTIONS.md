# 🔧 РЕШЕНИЕ ПРОБЛЕМ С GITHUB ACTIONS

**Проблема:** Непонятные ошибки при сборке на GitHub  
**Решение:** Упрощённый workflow только для сборки (без загрузки)

---

## ❓ СЕКРЕТЫ - ОБЯЗАТЕЛЬНЫ ЛИ?

### Для сборки: НЕТ ❌
- ✅ Можно собрать билд БЕЗ секретов
- ✅ Секреты нужны только для загрузки в App Store Connect
- ✅ Можно собрать локально и загрузить вручную

### Для загрузки в App Store: ДА ✅
- ❌ Без секретов нельзя загрузить в App Store Connect
- ❌ Нужны: API ключ, Issuer ID, Key ID

---

## 🎯 ВАРИАНТЫ РЕШЕНИЯ

### Вариант 1: Только сборка (БЕЗ секретов) ⭐ РЕКОМЕНДУЕТСЯ

**Что делает:**
- ✅ Собирает билд с Xcode 16
- ✅ Создаёт Archive
- ✅ Сохраняет как артефакт
- ❌ НЕ загружает в App Store

**Преимущества:**
- ✅ Не нужны секреты
- ✅ Проверяет, что код компилируется
- ✅ Можно скачать Archive и загрузить вручную

**Как использовать:**
1. Откройте: https://github.com/sergey234/ALADDIN_FAMILY/actions
2. Выберите: "Build Only (No Upload)"
3. Нажмите: "Run workflow"
4. Дождитесь завершения
5. Скачайте Archive из артефактов
6. Загрузите вручную через Transporter

---

### Вариант 2: Полная сборка + загрузка (С секретами)

**Что делает:**
- ✅ Собирает билд
- ✅ Создаёт IPA
- ✅ Загружает в App Store Connect

**Требования:**
- ❌ Нужны секреты в GitHub
- ❌ Нужен API ключ App Store Connect

**Как использовать:**
1. Создать API ключ в App Store Connect
2. Добавить секреты в GitHub
3. Запустить workflow "Build and Upload to App Store"

---

### Вариант 3: Локальная сборка + ручная загрузка

**Что делает:**
- ✅ Собираете локально на Mac
- ✅ Загружаете через Transporter

**Преимущества:**
- ✅ Полный контроль
- ✅ Видите все ошибки
- ✅ Не зависит от GitHub

**Недостатки:**
- ❌ Нужен Mac с Xcode 16+ (у вас старый Mac)
- ❌ Не автоматизировано

## 🔍 ЧАСТЫЕ ОШИБКИ НА GITHUB

### Ошибка 1: "Signing requires a development team"

**Причина:** Нет Team ID в секретах

**Решение:**
- Использовать workflow "Build Only" (без подписи)
- Или добавить `APPLE_TEAM_ID` в секреты

### Ошибка 2: "No such file or directory: ALADDIN.xcodeproj"

**Причина:** Неправильный путь к проекту

**Решение:**
- Проверить структуру репозитория
- Убедиться, что проект в корне

### Ошибка 3: "SDK version issue"

**Причина:** Используется старая версия Xcode

**Решение:**
- Уже исправлено: используется Xcode 16.0

### Ошибка 4: "Code signing error"

**Причина:** Проблемы с подписью

**Решение:**
- Использовать "Build Only" workflow
- Или настроить Automatic signing
