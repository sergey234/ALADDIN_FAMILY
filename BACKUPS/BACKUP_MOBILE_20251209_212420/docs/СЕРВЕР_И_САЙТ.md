
### 3. Проверка сертификата SSL:

```bash
# Проверить SSL сертификат
openssl s_client -connect aladdin-ai.ru:443 -servername aladdin-ai.ru

# Проверить срок действия
echo | openssl s_client -connect aladdin-ai.ru:443 -servername aladdin-ai.ru 2>/dev/null | openssl x509 -noout -dates
```
