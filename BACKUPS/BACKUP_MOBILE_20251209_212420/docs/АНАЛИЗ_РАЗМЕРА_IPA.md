1. **IPA = ZIP архив**

   - Содержимое уже сжато алгоритмом ZIP

2. **После распаковки будет больше:**

   - Это нормально для приложения с ресурсами 21 MB

## 🔍 СТРУКТУРА IPA ФАЙЛА

IPA файл - это ZIP архив со следующей структурой:

```
ALADDIN.ipa (ZIP архив, 7.2 MB)
└── Payload/
    └── ALADDIN.app/              (после распаковки ~60-100 MB)
        ├── ALADDIN               (бинарник, сжатый)
        ├── Info.plist
        ├── Assets.car             (ресурсы, сжатые)
        ├── embedded.mobileprovision
        ├── _CodeSignature/
        └── PlugIns/
            └── ALADDINPacketTunnel.appex/  (extension, сжатый)
                ├── ALADDINPacketTunnel
                ├── Info.plist
                └── embedded.mobileprovision
```

**Все файлы внутри IPA уже сжаты алгоритмом ZIP!**
