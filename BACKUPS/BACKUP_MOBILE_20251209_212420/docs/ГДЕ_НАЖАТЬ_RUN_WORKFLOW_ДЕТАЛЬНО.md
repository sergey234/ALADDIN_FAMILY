# 🎯 ГДЕ НАЖАТЬ "RUN WORKFLOW" - ДЕТАЛЬНАЯ ИНСТРУКЦИЯ

**Дата:** 29 ноября 2025

---

## 📍 ТОЧНОЕ МЕСТО КНОПКИ

### Шаг 1: Откройте страницу

**Прямая ссылка:**
https://github.com/sergey234/ALADDIN_FAMILY/actions/workflows/appstore.yml

---

### Шаг 2: Найдите кнопку

**Где искать:**

1. **Откройте страницу** (ссылка выше)

2. **Посмотрите в ПРАВЫЙ ВЕРХНИЙ УГОЛ страницы**

3. **Там должна быть зелёная кнопка:**
   ```
   ┌─────────────────────────────────────┐
   │                                     │
   │  [Filter workflows] [Run workflow] │ ← ЗДЕСЬ!
   │                          ↑          │
   │                    Зелёная кнопка  │
   └─────────────────────────────────────┘
   ```

4. **Если кнопки нет:**
   - Прокрутите страницу ВВЕРХ
   - Или нажмите Cmd+↑ (Mac) / Ctrl+Home (Windows)
   - Кнопка всегда в ВЕРХНЕЙ части страницы

---

### Шаг 3: Нажмите на кнопку

1. **Найдите зелёную кнопку "Run workflow"**
   - Она справа вверху
   - Зелёного цвета
   - С текстом "Run workflow"

2. **Нажмите на неё ЛЕВОЙ кнопкой мыши**

3. **Откроется выпадающее меню:**
   ```
   ┌─────────────────────────────┐
   │  Run workflow               │
   │  ─────────────────────────  │
   │  Use workflow from:         │
   │  [master ▼]                 │
   │                             │
   │  [Run workflow] ← Нажмите! │
   └─────────────────────────────┘
   ```

---

### Шаг 4: Выберите ветку и запустите

1. **В выпадающем меню:**
   - Убедитесь, что выбрано: `master`
   - Если нет → выберите `master` из списка

2. **Нажмите зелёную кнопку "Run workflow"** (внизу меню)

3. **Меню закроется, страница обновится**

---

## ✅ ПРОВЕРКА: ЗАПУСК НАЧАЛСЯ?

3. **Если видите это** → ✅ **ВСЁ РАБОТАЕТ!**

## 🔍 ЕСЛИ КНОПКИ НЕТ

### Вариант 1: Прокрутите страницу вверх

- Кнопка всегда в ВЕРХНЕЙ части страницы
- Нажмите Cmd+↑ (Mac) или Ctrl+Home (Windows)

### Вариант 2: Обновите страницу

- Нажмите Cmd+R (Mac) или F5 (Windows)
- Кнопка должна появиться

### Вариант 3: Проверьте URL

**Должно быть:**
```
https://github.com/sergey234/ALADDIN_FAMILY/actions/workflows/appstore.yml
```

**Если другой URL** → откройте правильную ссылку
