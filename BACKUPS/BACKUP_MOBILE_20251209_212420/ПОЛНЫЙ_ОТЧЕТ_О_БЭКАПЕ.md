```bash

```

### Шаг 3: Установка зависимостей
```bash
pod install
```

### Шаг 4: Открытие проекта
```bash
open ALADDIN.xcodeproj
```

### Шаг 5: Настройка GitHub Secrets (для workflows)
В GitHub Settings > Secrets добавить:
- `APPLE_TEAM_ID`
- `IOS_DISTRIBUTION_CERTIFICATE`
- `IOS_DISTRIBUTION_CERTIFICATE_PASSWORD`
- `PROVISIONING_PROFILE_APP`
- `PROVISIONING_PROFILE_EXTENSION`
- `APP_STORE_CONNECT_API_KEY` (опционально)
- `APP_STORE_CONNECT_ISSUER_ID` (опционально)
- `APP_STORE_CONNECT_API_KEY_ID` (опционально)
