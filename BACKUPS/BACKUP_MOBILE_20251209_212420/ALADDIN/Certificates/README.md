# 🔐 SSL Certificates for ALADDIN iOS

**Папка для SSL сертификатов сервера**

## 📋 Описание

Эта папка содержит SSL сертификаты для SSL Pinning в мобильном приложении ALADDIN.

## 📁 Файлы сертификатов

### Основной сертификат
- **aladdin_cert.cer** - Основной SSL сертификат сервера
- **aladdin_cert_backup.cer** - Резервный SSL сертификат

## 🔒 Безопасность

- Сертификаты должны быть в формате .cer (DER)
- Не храните приватные ключи в этой папке
- Регулярно обновляйте сертификаты при их смене

## 🚀 Использование

Сертификаты автоматически загружаются в `NetworkManager.swift`:

```swift
private func loadPinnedCertificates() -> [Data] {
    // Загружает сертификаты из этой папки
}
```

## ⚠️ Важно

- В продакшене сертификаты должны быть реальными
- В разработке можно использовать тестовые сертификаты
- При отсутствии сертификатов SSL Pinning отключается
