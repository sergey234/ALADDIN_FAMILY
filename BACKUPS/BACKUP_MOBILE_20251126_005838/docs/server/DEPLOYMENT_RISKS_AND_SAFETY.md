## ⚠️ ПОТЕНЦИАЛЬНЫЕ РИСКИ

### 🔴 КРИТИЧЕСКИЕ РИСКИ

#### 1. **База данных: Перезапись существующих таблиц**
**Риск:** SQL скрипт может удалить существующие данные, если таблицы уже есть.

**Что может произойти:**
- Если таблицы `referral_codes` или `referrals` уже существуют, скрипт может их перезаписать
- Потеря данных о существующих реферальных кодах
- Потеря истории приглашений

**Защита:**
- ✅ Скрипт использует `CREATE TABLE IF NOT EXISTS` - не перезапишет существующие таблицы
- ✅ Используется `ON CONFLICT DO NOTHING` - не удалит существующие данные
- ⚠️ **НО:** Если таблицы уже есть с другой структурой, могут быть конфликты

#### 2. **Nginx: Перезапись конфигурации**
**Риск:** Скрипт может перезаписать существующую конфигурацию nginx.

**Что может произойти:**
- Потеря существующих настроек nginx
- Сайт может перестать работать
- SSL сертификаты могут быть потеряны

**Защита:**
- ⚠️ Скрипт копирует конфигурацию напрямую
- ✅ **РЕКОМЕНДУЕТСЯ:** Создать backup перед развертыванием

#### 3. **Python код: Конфликты с существующим кодом**
**Риск:** Копирование файлов может перезаписать существующие файлы.

**Что может произойти:**
- Потеря существующего кода
- Конфликты импортов
- Ошибки в приложении

**Защита:**
- ⚠️ Скрипт проверяет существование директорий
- ✅ **РЕКОМЕНДУЕТСЯ:** Использовать Git для контроля версий

## ✅ ЧТО СОХРАНИТЬ ПЕРЕД РАЗВЕРТЫВАНИЕМ

### 1. **База данных (КРИТИЧНО!)**
```bash
# Создать backup базы данных
pg_dump -h localhost -U your_user -d your_database > backup_before_referral_$(date +%Y%m%d_%H%M%S).sql

# Или для PostgreSQL
pg_dump -h localhost -U your_user your_database > backup.sql
```

### 2. **Nginx конфигурация (КРИТИЧНО!)**
```bash
# Сохранить текущую конфигурацию
sudo cp /etc/nginx/sites-available/aladdin-ai.ru /etc/nginx/sites-available/aladdin-ai.ru.backup_$(date +%Y%m%d_%H%M%S)
```

### 3. **Python проект (ВАЖНО!)**
```bash
# Использовать Git
cd /path/to/your/fastapi/project
git add .
git commit -m "Backup before referral program deployment"
git tag backup-before-referral-$(date +%Y%m%d)
```

### 4. **Текущие файлы проекта**
```bash
# Сохранить текущие файлы
cp -r /path/to/your/fastapi/project /path/to/backup/fastapi_project_$(date +%Y%m%d_%H%M%S)
```

## 🔄 ПЛАН ОТКАТА (ROLLBACK)

### Если что-то пошло не так:

#### 1. Откат базы данных:
```bash
# Восстановить из backup
psql -h localhost -U your_user -d your_database < backup_before_referral_YYYYMMDD_HHMMSS.sql
```

#### 2. Откат Nginx:
```bash
# Восстановить конфигурацию
sudo cp /etc/nginx/sites-available/aladdin-ai.ru.backup_YYYYMMDD /etc/nginx/sites-available/aladdin-ai.ru
sudo nginx -t
sudo systemctl reload nginx
```

#### 3. Откат Python кода:
```bash
# Использовать Git
cd /path/to/your/fastapi/project
git checkout backup-before-referral-YYYYMMDD
# Или восстановить из backup
cp -r /path/to/backup/fastapi_project_YYYYMMDD_HHMMSS/* /path/to/your/fastapi/project/
```
