**Вариант 2: Гибридный (баланс гибкости и простоты)**

**Описание:**
- Категории привязаны к минимальному тарифу
- Внутри категории показываем процент доступности
- Мотивирует апгрейд (видно, что можно улучшить)
- Понятная визуализация (процент доступности)
- Легко расширять

```
├─ Free: 6/10 доступно (60%) 🟡
├─ Personal: 8/10 доступно (80%) 🟡
└─ Premium: 10/10 доступно (100%) 🟢
```
