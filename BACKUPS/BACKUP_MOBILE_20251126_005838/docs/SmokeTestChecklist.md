# Smoke Test Checklist — ALADDIN iOS

> Использовать для ручного прогона на симуляторе `iPhone 13` (iOS 16/17).  
> Колонку «Факт / Комментарий» заполняем во время тестирования.

### Подготовка перед запуском
- Собрать debug-сборку с актуальными API-ключами и включённым `RemoteAnalyticsService`/`APIService.shared` (проверить `AppConfig.apiBaseURL`).
- Очистить данные приложения, перезапустить симулятор, залогиниться под тестовыми родительским и детским аккаунтами.
- Проверить, что `NetworkManager` использует валидные SSL сертификаты (папка `Resources/Certificates`) и включён VPN мок.
- Включить `NavigationManager.debugLogs` и Xcode Console для фиксации ошибок.
- Подготовить файл фиксации результатов `docs/SmokeTestRun_2025-11-11.md` (дублировать для новых прогонов при необходимости).

## Общие проверки

- Запуск/фон/возврат приложения.
- Переключение языка (RU → EN → RU).
- Проверка тёмной темы.
- Сетевые ошибки (отключить интернет, проверить обработку).
- Логи Xcode — отсутствие crash/exception.
- Запуск `python3 /Users/sergejhlystov/ALADDIN_NEW/scripts/advanced_quality_check.py` и сохранение отчёта в `docs/QAReports/`.

> После ручного прогона обновляем `task-qa-suite`: фиксируем результаты и замечания в `ProductionPrepPlan.md` или отдельном отчёте QA.
