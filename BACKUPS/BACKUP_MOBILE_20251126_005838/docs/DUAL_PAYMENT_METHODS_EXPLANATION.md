# 💳 Два варианта оплаты: IAP + Сайт — можно ли совместить?

**Дата:** 19 ноября 2025  
**Вопрос:** Можно ли сделать и IAP регистрацию, и оплату на сайте одновременно?

---

## ✅ КРАТКИЙ ОТВЕТ

**ДА, можно и даже рекомендуется!**

Оба варианта **НЕ противоречат** друг другу и могут работать одновременно для разных регионов.

---

## 🎯 КАК ЭТО РАБОТАЕТ

### Вариант 1: Оплата на сайте (для России)
- Пользователь в России
- Нажимает "Оформить на сайте"
- Переходит на `https://aladdin-ai.ru/`
- Оплачивает через QR/СБП/карты
- Получает код активации
- Активирует в приложении

### Вариант 2: IAP (для других регионов)
- Пользователь не в России
- Нажимает "Купить через App Store"
- Стандартный процесс IAP
- Подписка активируется автоматически
- Нет необходимости в коде активации

---

## 📋 ТЕКУЩАЯ РЕАЛИЗАЦИЯ

### Что у вас сейчас:

```swift
// AppConfig.swift
static var isRussianRegion: Bool {
    return Locale.current.regionCode == "RU"
}

static var useAlternativePayments: Bool {
    // ✅ ВСЕГДА true - используем только QR оплату
    return true
}

static var useIAP: Bool {
    return !isRussianRegion  // Для не-российских регионов
}
```

**Проблема:** `useAlternativePayments` всегда `true`, поэтому IAP никогда не используется.

## 🔧 КАК РЕАЛИЗОВАТЬ ОБА ВАРИАНТА

### Шаг 1: Обновить AppConfig.swift

```swift
// MARK: - Payment Configuration

/**
 * Проверка региона пользователя
 */
static var isRussianRegion: Bool {
    return Locale.current.regionCode == "RU"
}

/**
 * Включить альтернативные способы оплаты (QR-коды)
 * В России IAP недоступен → используем QR оплату
 * В других регионах → используем IAP
 */
static var useAlternativePayments: Bool {
    #if APP_STORE_BUILD
    // В App Store билде: Россия → сайт, остальные → IAP
    return isRussianRegion
    #else
    // В других билдах (TestFlight, Debug): всегда сайт
    return true
    #endif
}

/**
 * Использовать IAP (In-App Purchase через App Store)
 */
static var useIAP: Bool {
    #if APP_STORE_BUILD
    // В App Store билде: не-российские регионы → IAP
    return !isRussianRegion
    #else
    // В других билдах: IAP не используется
    return false
    #endif
}
```

### Шаг 2: Обновить TariffsScreen.swift

```swift
// В функции обработки кнопки оплаты
Button(action: {
    if AppConfig.useAlternativePayments {
        // Россия → переход на сайт
        URLHelper.openWebsite(
            urlString: AppConfig.subscriptionWebsiteURL,
            tariffId: selectedTariff.id
        )
    } else {
        // Не-российские регионы → IAP
        Task { @MainActor in
            await viewModel.purchaseSelectedTariff(tariff: tariffObj)
        }
    }
}) {
    Text(getButtonText(for: tariff))
        // ...
}

// Функция определения текста кнопки
private func getButtonText(for tariff: TariffType) -> String {
    if tariff == .free {
        return localizationManager.localized("tariffs_free_button")
    } else if selectedTariff == tariff {
        return localizationManager.localized("tariffs_selected")
    } else {
        // Разные тексты для разных регионов
        if AppConfig.useAlternativePayments {
            return localizationManager.localized("tariffs_pay_website")  // "Оформить на сайте"
        } else {
            return localizationManager.localized("tariffs_pay_iap")  // "Купить через App Store"
        }
    }
}
```

### Для пользователя не в России:

1. Открывает экран тарифов
2. Видит кнопку **"Купить через App Store"**
3. Нажимает → открывается стандартный диалог IAP
4. Выбирает тариф и период
5. Подтверждает покупку через Face ID/Touch ID
6. Подписка активируется автоматически
7. Нет необходимости в коде активации

### 2. Соответствие ожиданиям пользователей:

- Для других регионов: рекомендуется IAP (Guideline 3.1.1)

### 4. Готовность к расширению:
- Можно запускать в любых странах
- Автоматическая поддержка разных валют (через IAP)
