## 🔍 ДЕТАЛЬНАЯ СТРУКТУРА РАЗДЕЛА СОГЛАСИЯ

### Код раздела (строки 303-433):

```swift
// MARK: - Consent Section (152-ФЗ)
private var consentSection: some View {
    VStack(alignment: .leading, spacing: Spacing.s) {
        sectionTitle("Согласие на обработку персональных данных")
        
        VStack(spacing: Spacing.s) {
            // 1. Статус согласия
            HStack {
                [✓] Согласие предоставлено / [✗] Согласие не предоставлено
                Дата: (если есть)
            }
            
            // 2. Кнопки действий (если согласие есть)
            if consentAccepted {
                [📄] Просмотреть согласие → consent.html
                [🔒] Политика конфиденциальности → privacy.html
                [❌] Отозвать согласие (с подтверждением)
            } else {
                Информационное сообщение
            }
        }
    }
}
```

## 📱 ВИЗУАЛЬНОЕ РАСПОЛОЖЕНИЕ

### Порядок секций в Профиле (сверху вниз):

1. **Шапка профиля** (profileHeader)
   - Аватар, имя, роль

2. **Статистика** (profileStats)
   - Устройства, угрозы, защита

3. **Информация** (profileInfo)
   - Дата регистрации, статус

4. **Безопасность** (securitySection)
   - 2FA, активные сессии

5. **✅ СОГЛАСИЕ НА ОБРАБОТКУ ПДн** (consentSection) ← **ЗДЕСЬ!**
   - Статус, дата, кнопки управления

6. **Реферальная программа** (referralSection)
   - Код, награды

## 🎯 КАК НАЙТИ В ПРИЛОЖЕНИИ

### Шаги:
1. Откройте приложение
2. Нажмите на иконку **👤 Профиль** (правый верхний угол или нижняя навигация)
3. Прокрутите вниз до раздела **"Безопасность"**
4. Следующий раздел после "Безопасность" — это **"Согласие на обработку персональных данных"**

### Визуальные маркеры:
- ✅ Иконка: `checkmark.shield` или статус (✓/✗)
- 📄 Кнопки: "Просмотреть согласие", "Политика конфиденциальности"
- ❌ Кнопка: "Отозвать согласие" (красная)

## 🔗 СВЯЗЬ С ДРУГИМИ МЕСТАМИ

### Настройки → Дополнительно:
- Карточка "Согласие на обработку ПДн" (строка 515-522)
- При нажатии открывает **тот же раздел** в Профиле
- `navigationManager.navigateTo(.profile)`

### Активация кода:
- Блок согласия с чекбоксом (строки 193-272)
- Сохраняет согласие в `@AppStorage("personal_data_consent_accepted")`
- Профиль читает это же значение и показывает статус
