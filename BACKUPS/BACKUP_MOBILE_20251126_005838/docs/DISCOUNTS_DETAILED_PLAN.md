## 🔧 ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

### Backend (Python):

**1. Структура `SubscriptionPlan`:**
```python
@dataclass
class SubscriptionPlan:
    tier: SubscriptionTier
    name: str
    price: Decimal
    period_months: int = 1  # 1, 3, 6, 12
    discount_percent: Optional[int] = None  # 10, 15, 20
    original_price: Optional[Decimal] = None  # Цена без скидки
    # ...
    
    @property
    def monthly_price(self) -> Decimal:
        return self.price / Decimal(self.period_months)
    
    @property
    def savings(self) -> Optional[Decimal]:
        if self.original_price:
            return self.original_price - self.price
        return None
```

**2. Тарифы:**
- `BASIC_3M`: 783₽, period_months=3, discount_percent=10
- `BASIC_6M`: 1479₽, period_months=6, discount_percent=15
- `BASIC_12M`: 2784₽, period_months=12, discount_percent=20
- И аналогично для FAMILY и PREMIUM

**3. Метод `create_subscription()`:**
- Принимает `period_months` (1, 3, 6, 12)
- Рассчитывает `end_date = start_date + timedelta(days=30 * period_months)`

### iOS (Swift):

**1. Структура `Tariff`:**
```swift
struct Tariff: Identifiable {
    let id: String
    let title: String
    let price: String
    let period: String
    let periodMonths: Int  // 1, 3, 6, 12
    let originalPrice: String?  // Цена без скидки
    let discountPercent: Int?  // 10, 15, 20
    let monthlyPrice: String  // Цена за месяц
    let savings: String?  // Экономия
    // ...
}
```

**2. UI:**
- Сегментированный контрол для выбора периода
- Отображение скидки и экономии
- Отображение цены за месяц

**3. API:**
- При создании QR-платежа передается `period_months`
- Backend рассчитывает итоговую цену с учетом скидки
