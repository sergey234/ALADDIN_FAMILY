# 🔧 ИСПРАВЛЕНИЕ КНОПКИ "СОЗДАТЬ НОВУЮ СЕМЬЮ"

**Дата:** 2025-11-12  
**Проблема:** Кнопка "Создать новую семью" вылетает на главную страницу, работает только со второго раза  
**Статус:** ✅ Исправлено

---

## ❌ ПРОБЛЕМА

**Что было не так:**
1. При нажатии на "Создать новую семью" приложение вылетало на главную страницу
2. Регистрация открывалась только со второго раза
3. Логика закрытия модала была неправильной

**Причина:**
- Я изменил порядок операций: сначала закрывал модал (`isPresented = false`), потом открывал регистрацию
- Это приводило к тому, что состояние терялось, и регистрация не открывалась

---

## ✅ ИСПРАВЛЕНИЕ

### **Вернул оригинальную логику:**
1. ✅ Сначала открываем регистрацию (`showCreateFamily = true`)
2. ✅ Потом закрываем модал через 0.1 секунды (`isPresented = false`)
3. ✅ Добавил защиту от двойного клика через флаг `isProcessingCreateFamily`

### **Код исправления:**

```swift
@State private var isProcessingCreateFamily: Bool = false // ✅ Защита от двойного клика

// В action кнопки:
optionButton(...) {
    // ✅ ИСПРАВЛЕНИЕ: Предотвращаем двойной клик
    guard !isProcessingCreateFamily && !showCreateFamily else {
        print("⚠️ Попытка повторного открытия, игнорируем")
        return
    }
    
    isProcessingCreateFamily = true
    print("✅ Открываем регистрацию семьи")
    
    // Сначала открываем регистрацию
    showCreateFamily = true
    
    // Закрываем основной модал после открытия регистрации
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.1) {
        isPresented = false
        // Сбрасываем флаг через небольшую задержку
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.5) {
            isProcessingCreateFamily = false
        }
    }
}
```

### **Добавлен обработчик изменения состояния:**
```swift
.onChange(of: showCreateFamily) { newValue in
    // ✅ Сбрасываем флаг обработки при закрытии регистрации
    if !newValue {
        isProcessingCreateFamily = false
        print("✅ Регистрация закрыта, сбрасываем флаг обработки")
    }
}
```

## 📋 ЛОГИКА РАБОТЫ

1. **Пользователь нажимает "Создать новую семью"**
   - Проверяется флаг `isProcessingCreateFamily`
   - Если уже обрабатывается → игнорируем клик
   - Если нет → устанавливаем флаг и открываем регистрацию

2. **Регистрация открывается**
   - `showCreateFamily = true` → открывается `MainScreenWithRegistration`
   - Через 0.1 секунды закрывается модал `AddMemberOptionsModal`

3. **После завершения регистрации**
   - Вызывается `onComplete`
   - Закрываются оба модала
   - Происходит навигация на нужный экран по роли

4. **Сброс флагов**
   - При закрытии регистрации сбрасывается `isProcessingCreateFamily`
   - Можно снова открыть регистрацию
