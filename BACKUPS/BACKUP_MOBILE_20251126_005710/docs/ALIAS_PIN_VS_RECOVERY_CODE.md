# 🔐 Разница между Alias/PIN и кодом восстановления семьи

**Дата:** 17 ноября 2025  
**Статус:** ✅ Описано в документации и на лендинге

---

## 📋 Краткое описание

В системе ALADDIN используются **два разных типа кодов** для разных целей:

### 1. **Alias + PIN** (для подписки)

**Для чего:** Восстановление кода активации подписки (ALDN-XXXX-XXXX-XXXX)

**Когда нужны:**
- Если вы потеряли код активации после оплаты подписки
- Если нужно восстановить доступ к подписке

**Где указываются:**
- При оплате подписки на сайте `aladdin.family`
- Пользователь придумывает их самостоятельно

**Формат:**
- **Alias** — ваш псевдоним (минимум 6 символов, буквы и цифры)
- **PIN** — код из 4-6 цифр

**Пример:**
- Alias: `familySmith2024`
- PIN: `1234`
- Код активации: `ALDN-8K3Q-2PS5-9LM4`

---

### 2. **Код восстановления семьи** (FAM-XXXX-XXXX-XXXX)

**Для чего:** Восстановление доступа к семье в приложении

**Когда нужен:**
- Если вы потеряли устройство
- Если переустановили приложение
- Если нужно восстановить доступ к вашей семье

**Где выдаётся:**
- При создании семьи в приложении ALADDIN AI
- Показывается в `RecoveryCodeModal` после создания семьи

**Формат:**
- `FAM-XXXX-XXXX-XXXX` (например: `FAM-A1B2-C3D4-E5F6`)

**Пример:**
- Код восстановления: `FAM-A1B2-C3D4-E5F6`
- Используется для присоединения к семье или восстановления доступа

## 📝 Примеры использования

### Сценарий 1: Пользователь оплатил подписку, но потерял код активации

1. Пользователь идёт на сайт `aladdin.family`
2. Выбирает "Восстановить код"
3. Вводит **alias** и **PIN**, которые указал при оплате
4. Получает код активации `ALDN-XXXX-XXXX-XXXX`
5. Активирует код в приложении

### Сценарий 2: Пользователь потерял устройство и хочет восстановить доступ к семье

1. Пользователь устанавливает приложение на новое устройство
2. Выбирает "Восстановить доступ к семье"
3. Вводит **код восстановления семьи** `FAM-XXXX-XXXX-XXXX`
4. Восстанавливает доступ к своей семье

---

## ⚠️ Важные моменты

1. **Это два разных кода для разных целей:**
   - Alias + PIN → для подписки
   - Код восстановления семьи → для семьи

2. **Не путать:**
   - Код активации подписки (ALDN-XXXX-XXXX-XXXX) ≠ Код восстановления семьи (FAM-XXXX-XXXX-XXXX)

3. **Хранение:**
   - Alias и PIN нужно запомнить или сохранить в надёжном месте
   - Код восстановления семьи показывается один раз при создании семьи, его нужно сохранить
