## 3. Контент по блокам

### 3.1 Hero
- Заголовок: «ALADDIN AI — защита семьи 24/7».
- Подзаголовок: «Оплата на сайте → код активации → мгновенный доступ к 138 функциям».
- CTA `Оплатить подписку` (scroll к форме / `#pay`), `Ввести код` (ссылка `app://activate` или `/activate`).
- Счетчик: «4 семьи защищено», «8 устройств», «47 угроз заблокировано».
- Визуал: мокап iPhone с MainScreen, фон градиент.

### 3.2 Как это работает
1. **Оплатите** — выберите тариф, укажите alias+PIN, нажмите «Оплатить».
2. **Получите код** — код появляется на сайте, можно восстановить по alias+PIN.
3. **Активируйте** — откройте приложение → «Ввести код активации».

### 3.3 Тарифные карточки
- Free (0 ₽): базовые функции.
- Personal (290 ₽): 4 устройства, 50/100 защиты.
- Family (490 ₽): 6 устройств, 92/100 защиты (рекомендовать).
- Premium (990 ₽): 10 устройств, 100/100 защиты.

Каждая карточка содержит:
- Кол-во устройств, уровень защиты, основные функции.
- Кнопка `Оплатить на сайте` → заполняет alias/PIN форму с тарифом.

### 3.4 Alias + PIN форма
- Поля: `Alias (минимум 6 символов)`, `PIN (4-6 цифр)`, `Выбор тарифа`.
- Селектор «Метод оплаты»: данные из `cms/methods.json` (QR/СБП, карты конкретных банков, SberPay/Tinkoff Pay, прямой перевод).
- Чекбокс: «Нажимая “Перейти к оплате”, вы принимаете публичную оферту».
- Линки под формой: Privacy, Terms, FAQ, Telegram-бот.

### 3.5 FAQ / Поддержка
Взять вопросы из `docs/legal/help_faq.md`:
- «Как оплатить?»
- «Не получил код?»
- «Как вернуть деньги?»
- «Потерял alias/PIN?»
- «Оплата зависла?»

Контакты:
- Telegram: `https://t.me/aladdin_support`
- Форма: `https://aladdin.family/help-form`
- FAQ: `https://aladdin.family/help-faq`
