# 🌐 РЕКОМЕНДАЦИИ: ГДЕ РАЗМЕСТИТЬ PRIVACY POLICY И TERMS URL

**Дата:** 16 ноября 2025  
**Вопрос:** Где размещать Privacy Policy и Terms of Service - на сайте или на сервере?

---

## 🎯 КРАТКИЙ ОТВЕТ

**✅ РЕКОМЕНДАЦИЯ: Разместить на сервере (backend)**

**Почему:**
- Сайта пока нет
- Сервер скоро будет готов
- Apple требует публичный URL (не важно, где именно)
- Можно разместить на поддомене сервера

---

## 📋 ВАРИАНТЫ РАЗМЕЩЕНИЯ

### Вариант 1: На сервере (РЕКОМЕНДУЕТСЯ) ✅

**Структура:**
```
https://api.aladdin.ru/privacy-policy.html
https://api.aladdin.ru/terms-of-service.html
```

**Или на поддомене:**
```
https://legal.aladdin.ru/privacy-policy.html
https://legal.aladdin.ru/terms-of-service.html
```

**Преимущества:**
- ✅ Сервер скоро будет готов
- ✅ Полный контроль над файлами
- ✅ Можно обновлять без изменений в приложении
- ✅ HTTPS уже настроен
- ✅ Не нужно ждать создания сайта

**Недостатки:**
- ⚠️ Нужно настроить статическую раздачу файлов (nginx/apache)

## 🚀 РЕКОМЕНДУЕМЫЙ ПЛАН ДЕЙСТВИЙ

### Шаг 1: Разместить на сервере (СЕЙЧАС)

1. **Подготовить файлы:**
   - `20_full_privacy_policy.html` → `privacy-policy.html`
   - `20_terms_of_service.html` → `terms-of-service.html`

2. **Загрузить на сервер:**
   - В директорию `/var/www/html/` или `/usr/share/nginx/html/`
   - Или настроить статическую раздачу через nginx

3. **Проверить доступность:**
   - Открыть в браузере
   - Проверить, что HTTPS работает
   - Проверить, что файлы открываются корректно

4. **Получить публичные URL:**
   - `https://api.aladdin.ru/privacy-policy.html`
   - `https://api.aladdin.ru/terms-of-service.html`

### Шаг 2: Указать в App Store Connect

1. **Privacy Policy URL:**
   - Вставить URL в поле "Privacy Policy URL"
   - Проверить, что Apple может открыть URL

2. **Terms of Service URL:**
   - Вставить URL в поле "Terms of Service URL"
   - Проверить, что Apple может открыть URL

### Шаг 3: Обновить в приложении (опционально)

1. **Обновить ссылки в приложении:**
   - В настройках
   - В экране "О приложении"
   - В экране "Политика конфиденциальности"

## 📝 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Настройка nginx для статических файлов:

```nginx
server {
    listen 443 ssl;
    server_name api.aladdin.ru;

    location /privacy-policy.html {
        alias /var/www/html/privacy-policy.html;
    }

    location /terms-of-service.html {
        alias /var/www/html/terms-of-service.html;
    }
}
```

### Или просто положить в корень:

```bash
# На сервере
cd /var/www/html/
# Загрузить файлы
# Проверить права доступа
chmod 644 privacy-policy.html terms-of-service.html
```
