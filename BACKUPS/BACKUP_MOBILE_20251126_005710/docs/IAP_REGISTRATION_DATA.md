## 🧪 ТЕСТИРОВАНИЕ В SANDBOX

### Создать Sandbox тестовый аккаунт:

1. В App Store Connect → Users and Access → Sandbox Testers
2. Создать тестовый аккаунт
3. Использовать для тестирования IAP

### Тестирование:

1. Запустить приложение на устройстве
2. Войти в Sandbox аккаунт (Settings → App Store → Sandbox Account)
3. Попробовать купить подписку
4. ✅ Проверить, что подписка активируется
5. ✅ Проверить автоматическое продление
