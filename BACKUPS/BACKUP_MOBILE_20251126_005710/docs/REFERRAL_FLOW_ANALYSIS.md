## 🎩 МЕТОД 6 ШЛЯП МЫШЛЕНИЯ

### ⚪ БЕЛАЯ ШЛЯПА (Факты)

**Текущая ситуация:**
- ✅ Есть страница `invite.html` с реферальным кодом
- ✅ Есть страница `consent.html` для согласия на обработку ПДн
- ✅ Есть страница `index.html` с оплатой подписки
- ✅ Есть страница `success.html` для успешной оплаты
- ✅ Реферальный код сохраняется в `localStorage`

**Что нужно:**
- Реферальный код должен применяться при оплате
- Скидка -20% должна применяться автоматически
- Оба пользователя (реферер и приглашенный) получают скидку

---

### 🔴 КРАСНАЯ ШЛЯПА (Эмоции)

**Проблемы текущей логики:**
- ❌ Пользователь сразу попадает на согласие - это пугает
- ❌ Непонятно, что делать дальше после согласия
- ❌ Не видно, где применить скидку
- ❌ Непонятно, когда скидка активируется

**Что чувствует пользователь:**
- 😕 "Зачем мне согласие, я еще не решил покупать?"
- 😕 "Где оплата? Где скидка?"
- 😕 "Что делать дальше?"

4. ❌ Нет визуального подтверждения применения скидки
5. ❌ Реферальный код может потеряться между страницами

## 🎯 ВАРИАНТ 1: ПРЯМОЙ ПЕРЕХОД К ОПЛАТЕ (Рекомендуемый)

### Логика:
1. **invite.html** → Пользователь видит код и приглашение
2. **Кнопка "Получить скидку"** → Переход на `index.html#pay?ref=ABC123`
3. **index.html#pay** → Форма оплаты с примененной скидкой -20%
4. **При оплате** → Реферальный код передается на сервер
5. **success.html** → Подтверждение оплаты и скидки

### Плюсы:
- ✅ Прямой путь к оплате
- ✅ Скидка видна сразу
- ✅ Минимум шагов
- ✅ Понятно что делать

### Минусы:
- ⚠️ Согласие на обработку ПДн нужно добавить в форму оплаты

### Когда показывать согласие:
- В форме оплаты (чекбокс "Я даю согласие на обработку ПДн")

---

## 🎯 ВАРИАНТ 2: ИНФОРМАЦИОННАЯ СТРАНИЦА → ОПЛАТА

### Логика:
1. **invite.html** → Пользователь видит код и приглашение
2. **Кнопка "Узнать больше"** → Переход на `index.html?ref=ABC123`
3. **index.html** → Главная страница с информацией + баннер "У вас есть скидка -20%!"
4. **Кнопка "Оплатить со скидкой"** → Переход на `index.html#pay?ref=ABC123`
5. **Форма оплаты** → Скидка -20% применена, согласие в форме
6. **success.html** → Подтверждение

### Плюсы:
- ✅ Пользователь сначала знакомится с продуктом
- ✅ Скидка видна на главной странице
- ✅ Больше информации перед покупкой

### Минусы:
- ⚠️ Больше шагов
- ⚠️ Может потерять интерес

---

## 🎯 ВАРИАНТ 3: РЕГИСТРАЦИЯ → ОПЛАТА (Классический)

### Логика:
1. **invite.html** → Пользователь видит код и приглашение
2. **Кнопка "Зарегистрироваться"** → Переход на форму регистрации
3. **Форма регистрации** → Email, пароль, согласие на ПДн, реферальный код
4. **После регистрации** → Переход на `index.html#pay?ref=ABC123`
5. **Форма оплаты** → Скидка -20% применена
6. **success.html** → Подтверждение

### Плюсы:
- ✅ Классический поток регистрации
- ✅ Создается аккаунт до оплаты
- ✅ Можно сохранить данные пользователя

### Минусы:
- ⚠️ Больше шагов
- ⚠️ Нужна страница регистрации
- ⚠️ Пользователь может не дойти до оплаты

## 🎯 РЕКОМЕНДАЦИЯ: ВАРИАНТ 1 (Прямой переход к оплате)

### Почему:
1. ✅ **Минимум шагов** - меньше потерянных пользователей
2. ✅ **Понятно** - сразу видно скидку
3. ✅ **Быстро** - пользователь не теряет интерес
4. ✅ **Просто реализовать** - используем существующие страницы

### Детальный поток:

```
1. invite.html
   └─ Показывает: "Вы приглашены по коду ABC123"
   └─ Кнопка: "Получить скидку -20%"
   └─ Переход: index.html#pay?ref=ABC123

2. index.html#pay
   └─ Форма оплаты
   └─ Баннер: "🎁 У вас применена скидка -20% по реферальному коду ABC123"
   └─ Цена: показана со скидкой
   └─ Чекбокс: "Я даю согласие на обработку ПДн"
   └─ При оплате: передается referral_code=ABC123

3. success.html
   └─ Подтверждение оплаты
   └─ Сообщение: "Скидка -20% применена! Ваш друг тоже получит скидку."
   └─ Код активации
```

## 🔧 ЧТО НУЖНО ИСПРАВИТЬ

### 1. В invite.html:
- Изменить кнопку: "Получить скидку -20%" вместо "Зарегистрироваться"
- Ссылка: `index.html#pay?ref=ABC123`

### 2. В index.html:
- Добавить обработку параметра `?ref=CODE`
- Показать баннер со скидкой, если есть реферальный код
- Применить скидку -20% к цене
- Передать `referral_code` при оплате

### 3. В success.html:
- Показать сообщение о примененной скидке
- Упомянуть, что друг тоже получит скидку

## ✅ ИТОГОВАЯ ЛОГИКА (Вариант 1)

### Для приглашенного пользователя:
1. Получает ссылку `aladdin-ai.ru/invite/ABC123`
2. Видит приглашение и код
3. Нажимает "Получить скидку -20%"
4. Переходит на форму оплаты со скидкой
5. Оплачивает подписку
6. Получает код активации
7. **Скидка -20% применена автоматически**

### Для реферера (друга):
1. Приглашает друга по коду
2. Друг оплачивает подписку
3. **Автоматически получает скидку -20%** на следующий месяц
