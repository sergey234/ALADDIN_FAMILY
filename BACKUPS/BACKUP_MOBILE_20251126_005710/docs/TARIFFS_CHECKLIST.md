## ✅ Чеклист проверки тарифов

### 🆓 FREE (Бесплатный тариф)

#### Отображение
- [ ] Тариф отображается на экране тарифов
- [ ] Название "FREE" или "БАЗОВЫЙ" корректно
- [ ] Цена "0 ₽" отображается
- [ ] Период "Бесплатно" отображается
- [ ] Цвет тарифа корректный

#### Функции
- [ ] Список функций отображается
- [ ] Все функции FREE тарифа перечислены
- [ ] Функции локализованы (на русском)
- [ ] Нет функций платных тарифов

#### Активация
- [ ] Кнопка активации/выбора работает
- [ ] При выборе FREE тариф активируется
- [ ] Статус тарифа сохраняется в AppStorage
- [ ] После активации доступны только FREE функции

#### Ограничения
- [ ] Ограничения FREE тарифа применяются
- [ ] Платные функции недоступны
- [ ] Сообщения об ограничениях отображаются

## 📊 Сравнение тарифов

### Цены
- [ ] FREE: 0 ₽
- [ ] PERSONAL: 290 ₽/мес
- [ ] FAMILY: 490 ₽/мес
- [ ] PREMIUM: 990 ₽/мес

### Устройства
- [ ] FREE: ограничение (если есть)
- [ ] PERSONAL: 1 устройство
- [ ] FAMILY: до 6 устройств
- [ ] PREMIUM: без ограничений

### Функции по тарифам
- [ ] FREE: базовые функции
- [ ] PERSONAL: личные функции + базовые
- [ ] FAMILY: семейные функции + личные + базовые
- [ ] PREMIUM: все функции
