## 🎯 ОСНОВНАЯ ПРОБЛЕМА

**Страница "Вознаграждение ребенка" должна быть:**

**Одна и та же страница, но с разным функционалом!**

## ✅ ЧТО ДОЛЖНО БЫТЬ

### 👨‍👩‍👧 ДЛЯ РОДИТЕЛЕЙ (ParentalControlScreen → ChildRewardsScreen):

#### ✅ ОТКРЫТО (видно и доступно):

1. **Секция "Воспитание ребенка":**
   ```
   👨‍👩‍👧 Воспитание ребенка
   
   [✅ Вознаградить]  [❌ Наказать]
   ```
   - Кнопка "✅ Вознаградить" (зелёная, большая)
   - Кнопка "❌ Наказать" (красная, большая)
   - При нажатии открываются модальные окна

2. **Модальные окна:**
   - **RewardInputModal:** Ввод суммы и причины вознаграждения
   - **PunishInputModal:** Ввод суммы и причины наказания

3. **Настройки (шестерёнка):**
   - Настройка цели (название, стоимость)
   - Управление наградами магазина

4. **Полная история:**
   - Все награды и наказания
   - Детальная информация (дата, причина, сумма)
   - Возможность фильтрации

5. **Статистика:**
   - Баланс единорогов ребёнка
   - Заработано за неделю
   - Списано за неделю
   - Графики и аналитика

6. **Управление:**
   - Одобрение/отклонение запросов от детей
   - Просмотр всех достижений
   - Управление наградами магазина

#### 🔒 ЗАКРЫТО (не видно):
- Нет ограничений — родители видят всё

---

### 👶 ДЛЯ ДЕТЕЙ (ChildInterfaceScreen → ChildRewardsScreen):

#### ✅ ОТКРЫТО (видно и доступно):

1. **Баланс единорогов:**
   - Текущий баланс (большое число)
   - Статистика за неделю (заработано/списано)

2. **Прогресс к цели:**
   - Название цели
   - Прогресс-бар
   - Сколько осталось накопить
   - Сколько дней осталось

3. **Кнопка "Сообщить родителям":**
   - Отправка запроса на одобрение достижения
   - Шаблоны запросов
   - Кастомное сообщение

4. **История наград/наказаний:**
   - Последние 5 операций
   - Причина награды/наказания
   - Дата и сумма
   - Иконки для каждого типа операции

5. **Магазин наград:**
   - Список доступных наград
   - Покупка наград за единороги
   - Статус доступности ("Накопите ещё немного" или "Купить")

6. **Игровые карточки (2x3):**
   - 🛡️ Юный защитник
   - 🦄 Питомец
   - 🕵️ Я защитник
   - 🏆 Турнир
   - 🏪 Магазин
   - 📊 История

7. **Табы:**
   - Магазин (активен по умолчанию)
   - История
   - Достижения

#### 🔒 ЗАКРЫТО (не видно):

1. **Секция "Воспитание ребенка":**
   - Кнопки "Вознаградить" и "Наказать" — **НЕ ВИДНЫ**

2. **Настройки (шестерёнка):**
   - Настройка цели — **НЕ ВИДНЫ** (или ограниченный доступ)

3. **Полная история:**
   - Дети видят только последние 5 операций

4. **Управление:**
   - Дети не могут изменять баланс напрямую
   - Дети не могут одобрять/отклонять запросы

## 🔧 РЕАЛИЗОВАННЫЕ ИСПРАВЛЕНИЯ

### 1. ✅ Установка роли при входе в экраны

**ParentalControlScreen:**
```swift
.onAppear {
    UserDefaults.standard.set("parent", forKey: "current_user_role")
}
```

**ChildInterfaceScreen:**
```swift
.onAppear {
    UserDefaults.standard.set("child", forKey: "current_user_role")
}
```

### 2. ✅ Улучшена функция `isCurrentUserParent()`

**Добавлен fallback механизм:**
- Проверка через UserDefaults
- Fallback: проверка текущего экрана
- По умолчанию: ребёнок (безопаснее)

### 3. ✅ Улучшено обновление главной страницы

**Добавлены подписки на изменения:**
- `onReceive(mainViewModel.$familyMembers)`
- `onReceive(mainViewModel.$devicesProtected)`
- `onReceive(mainViewModel.$threatsBlocked)`

## 📋 ТЕКУЩИЙ СТАТУС КОДА

### ✅ РЕАЛИЗОВАНО:

1. **Разделение интерфейса по ролям:**
   - `parentQuickActions` — для родителей
   - `childRewardsHistoryView` — для детей

2. **Модальные окна:**
   - `RewardInputModal` — вознаграждение
   - `PunishInputModal` — наказание

3. **Функции вознаграждения/наказания:**
   - `rewardChild()` — вознаграждение
   - `punishChild()` — наказание
   - Проверка роли перед выполнением

4. **История:**
   - `getHistoryOperations()` — загрузка истории
   - `addToHistory()` — добавление в историю
   - Отображение для родителей и детей

### ❌ ПРОБЛЕМЫ:

1. **Роль не устанавливается автоматически:**
   - Решено: добавлена установка роли в `.onAppear`

2. **Родительские функции не видны:**
   - Решено: улучшена функция `isCurrentUserParent()`

3. **Главная страница не обновляется:**
   - Решено: добавлены подписки на изменения
