## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Product ID:** Должен быть уникальным и соответствовать Bundle ID
2. **Цены:** Устанавливаются для каждого региона отдельно
3. **Описания:** Нужны на всех поддерживаемых языках (минимум English и Russian)
4. **Sandbox:** Тестирование только в Sandbox окружении
5. **QR-оплата:** Для России используется QR, а не IAP (указать в Review Notes)
6. **Скидки:** Отображаются в приложении, но в App Store Connect регистрируются как отдельные продукты с разными ценами
