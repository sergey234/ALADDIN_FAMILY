## 🔘 Кнопки навигации

### Общие кнопки:
- **Пропустить (Skip):** В правом верхнем углу каждой страницы
- **Продолжить (Continue):** Основная кнопка для перехода между страницами 1-6
- **Начать (Get started):** Кнопка на последней странице (7-я)

### Кнопки на странице 7:
- **У МЕНЯ ЕСТЬ КОД (I HAVE A CODE):** Открывает QR-сканер
- **ВОССТАНОВИТЬ (RECOVER):** Открывает диалог восстановления с опциями:
  - Ввести код вручную
  - Сканировать QR-код
  - Восстановить из сохранения
