# ⚡ БЫСТРОЕ РЕШЕНИЕ: Тесты не запускаются

**Проблема:** Нажимаете Cmd + U, но ничего не происходит

**Причина:** Файл `MockAPIServiceTests.swift` не добавлен в проект Xcode

---

## ✅ РЕШЕНИЕ (2 минуты):

### Шаг 1: Открыть Xcode
```bash
open ALADDIN.xcodeproj
```

### Шаг 2: Добавить файл в проект

**Вариант A: Через меню (РЕКОМЕНДУЕТСЯ)**

1. В Xcode: Правой кнопкой на папку `Tests/UnitTests` (в левом навигаторе)
2. Выбрать: **"Add Files to ALADDIN..."**
3. Найти и выбрать файл: `Tests/UnitTests/MockAPIServiceTests.swift`
4. ✅ **ВАЖНО:** Убедиться, что стоит галочка **"Copy items if needed"**
5. ✅ **ВАЖНО:** Убедиться, что выбран **Target: ALADDINUnitTests**
6. Нажать **"Add"**

**Вариант B: Перетащить файл**

1. Открыть Finder
2. Найти файл: `Tests/UnitTests/MockAPIServiceTests.swift`
3. Перетащить файл в Xcode в папку `Tests/UnitTests`
4. ✅ **ВАЖНО:** В диалоге выбрать **Target: ALADDINUnitTests**
5. Нажать **"Finish"**

---

### Шаг 3: Проверить Target Membership

1. Выбрать файл `MockAPIServiceTests.swift` в Xcode
2. Открыть **File Inspector** (правая панель, ⌥⌘1)
3. В разделе **"Target Membership"**:
   - ✅ Должна быть галочка на **ALADDINUnitTests**
   - ❌ НЕ должно быть галочки на **ALADDIN** (основное приложение)

---

### Шаг 4: Запустить тесты

1. В Xcode: **Product → Test** (или **Cmd + U**)
2. Или: Нажать на иконку ▶️ рядом с тестами в Test Navigator (⌘6)

---

## ✅ ПРОВЕРКА

### После добавления файла:

1. **Файл виден в навигаторе?**
   - ✅ Да → Продолжить
   - ❌ Нет → Повторить Шаг 2

2. **Файл в правильном Target?**
   - ✅ ALADDINUnitTests → Продолжить
   - ❌ Нет → Исправить (Шаг 3)

3. **Проект компилируется?**
   - ✅ Да → Запустить тесты
   - ❌ Нет → Проверить ошибки
