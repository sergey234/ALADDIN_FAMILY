## 🎯 ЧТО ДЕЛАТЬ ДАЛЬШЕ

### Шаг 1: Release Build (1-2 часа)

**Следовать:** `docs/RELEASE_BUILD_CHECKLIST.md`

1. Проверить Release конфигурацию
2. Проверить Code Signing
3. Установить версию 1.0.0 (Build 1)
4. Создать Archive
5. Upload в App Store Connect

---

### Шаг 2: Review Notes (30 минут)

**Использовать:** `docs/REVIEW_NOTES_TEMPLATE.md`

1. Создать тестовый аккаунт
2. Заполнить Review Notes по шаблону
3. Загрузить в App Store Connect

---

### Шаг 3: App Privacy (30 минут)

**Использовать:** `docs/APP_PRIVACY_DATA.md`

1. Зайти в App Store Connect → App Privacy
2. Заполнить форму по данным из документа
3. Сохранить

---

### Шаг 4: Публичные URL (1-2 часа)

**Использовать:** `docs/PUBLIC_URLS_INFO.md`

1. Загрузить HTML файлы на сервер
2. Проверить доступность URL
3. Указать URL в App Store Connect

---

### Шаг 5: IAP Registration (1-2 часа)

**Использовать:** `docs/IAP_REGISTRATION_DATA.md`

1. Создать Subscription Group
2. Зарегистрировать тарифы
3. Установить цены
4. Протестировать в Sandbox

---

### Шаг 6: Category and Age Rating (15 минут)

**Использовать:** `docs/CATEGORY_AND_AGE_RATING.md`

1. Выбрать категории
2. Пройти анкету Age Rating
3. Сохранить
