## 🎯 ГДЕ РАЗМЕСТИТЬ КНОПКУ АКТИВАЦИИ КОДА?

### Вариант 1: На экране Тарифов (РЕКОМЕНДУЕТСЯ) ⭐

**Плюсы:**
- ✅ Логичный поток: Выбрал тариф → Оплатил → Активировал код
- ✅ Пользователь уже в контексте подписки
- ✅ Можно добавить после карточек тарифов или внизу экрана

**Где добавить:**
- После карточек тарифов (после строки 134)
- Или внизу экрана перед "Сравнение тарифов"

**Пример кода:**
```swift
// После карточек тарифов
VStack(spacing: Spacing.m) {
    Button(action: {
        navigationManager.navigateTo(.activationCode)
    }) {
        HStack(spacing: Spacing.m) {
            Image(systemName: "key.fill")
                .font(.system(size: 18))
                .foregroundColor(.primaryBlue)
            
            Text("Активировать код подписки")
                .font(.body)
                .foregroundColor(.textPrimary)
            
            Spacer()
            
            Image(systemName: "chevron.right")
                .font(.system(size: 14))
                .foregroundColor(.textSecondary)
        }
        .padding(Spacing.m)
        .background(
            RoundedRectangle(cornerRadius: CornerRadius.medium)
                .fill(Color.backgroundMedium.opacity(0.3))
        )
    }
}
.padding(.horizontal, Spacing.screenPadding)
```

### Вариант 2: На главном экране

**Плюсы:**
- ✅ Всегда доступно
- ✅ Можно добавить как отдельную карточку в сетке 2x2

**Минусы:**
- ⚠️ Может быть неочевидно для пользователя
- ⚠️ Занимает место на главном экране

**Где добавить:**
- В сетку карточек (после "Тарифы", строка 316)
- Или как отдельную секцию ниже

**Пример кода:**
```swift
// В сетке карточек
Button(action: {
    navigationManager.navigateTo(.activationCode)
}) {
    VStack(spacing: 8) {
        Text("🔑")
            .font(.system(size: 20))
        
        Text("Активировать код")
            .font(.system(size: 12, weight: .semibold))
            .foregroundColor(.white)
        
        Text("Активация подписки")
            .font(.system(size: 10))
            .foregroundColor(.white.opacity(0.8))
    }
    .frame(maxWidth: .infinity)
    .frame(height: 80)
    .background(
        RoundedRectangle(cornerRadius: 10)
            .fill(Color.white.opacity(0.1))
            .overlay(
                RoundedRectangle(cornerRadius: 10)
                    .stroke(Color.white.opacity(0.2), lineWidth: 1)
            )
    )
}
```
