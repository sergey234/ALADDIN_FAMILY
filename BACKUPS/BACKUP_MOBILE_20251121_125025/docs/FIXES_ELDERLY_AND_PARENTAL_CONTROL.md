**Проблема:** Слово "Здравствуйте" переносилось на две строки в интерфейсе для взрослых 60+.

**Файл:** `Screens/09_ElderlyInterfaceScreen.swift` (строки 225-237)

```swift
Text(localizationManager.localized("elderly_interface_hello"))
    .font(.system(size: 28, weight: .bold))
    .foregroundColor(.white)
    .lineLimit(1)
    .fixedSize(horizontal: false, vertical: true) // ✅ ИСПРАВЛЕНИЕ
    .minimumScaleFactor(0.6)
```

### 2. ✅ **Исправлены английские названия в интерфейсе для взрослых 60+**

  - `elderly_interface_health_journal`: "Журнал здоровья"

**Файл:** `Core/Localization/LocalizationManager.swift` (строки 1052-1054)

### 3. ✅ **Добавлен вызов loadChildren() в .onAppear модала**

**Проблема:** В модале "Настройки родительского контроля" список детей не загружался автоматически при открытии.

**Решение:**
- Добавлен вызов `loadChildren()` в `.onAppear` модала `FamilyParentalControlSettingsModal`
- Теперь список детей загружается автоматически при открытии модала

**Файл:** `Screens/02_FamilyScreen.swift` (строки 4852-4860)

```swift
.onAppear {
    // ✅ ЗАГРУЗКА ДЕТЕЙ: Загружаем список детей при открытии модала
    loadChildren()
    
    // Применяем правила при открытии модала (если уже включены)
    if isAutomatedRulesEnabled {
        applyAgeBasedRules()
    }
}
```

**Важно:** Это нужно для продакшн, чтобы список детей всегда был актуальным.

### 4. ✅ **Исправлена проблема с двойным кликом на "Создать новую семью"**

**Проблема:** При нажатии на "Создать новую семью" модал закрывался слишком быстро (0.1 секунды), что вызывало проблемы с навигацией и требовало двойного клика.

**Решение:**
- Убрана задержка закрытия модала
- Модал закрывается сразу при нажатии
- Регистрация открывается с небольшой задержкой (0.2 секунды) для плавности

**Файл:** `Shared/Components/Modals/AddMemberOptionsModal.swift` (строки 52-60)

```swift
) {
    // ✅ ИСПРАВЛЕНИЕ: Убираем задержку, закрываем модал сразу
    // Это предотвращает проблему с двойным кликом
    isPresented = false
    
    // Открываем регистрацию с небольшой задержкой для плавности
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.2) {
        showCreateFamily = true
    }
}
```
