# 💳 Прямой банковский перевод — способ оплаты без договора

## ✅ Ответ на вопрос: "Можно ли принимать платежи без договора?"

**Да, можно!** Есть **1 способ** — **прямой банковский перевод** (`manual_transfer`).

---

## 🔄 Как это работает

### 1. Пользователь на лендинге
- Выбирает тариф и способ оплаты "Прямой банковский перевод"
- Вводит alias и PIN
- Видит реквизиты для перевода:
  - ИНН организации
  - Расчётный счёт
  - БИК банка
  - Назначение платежа (с указанием alias для идентификации)
- Переводит деньги вручную через банк/приложение
- Опционально загружает чек/скриншот перевода

### 2. Поддержка
- Получает уведомление о новом платеже со статусом `awaiting_manual_payment`
- Проверяет поступление денег на счёт (по реквизитам и назначению платежа)
- Подтверждает платёж через админ-эндпоинт `/api/admin/payments/confirm-manual`
- Система автоматически генерирует код активации

### 3. Пользователь
- Получает код активации (через `/api/activation/retrieve` по alias+PIN)
- Активирует код в приложении

---

## 📋 Технические детали

### Статусы платежа
- `created` → `awaiting_manual_payment` (при создании)
- `awaiting_manual_payment` → `paid` (после подтверждения поддержкой)
- При `paid` → автоматически генерируется код активации

### API эндпоинты

#### Создание платежа (как обычно)
```http
POST /api/payments/create
{
  "tariffId": "family_12m",
  "userAlias": "familySmith",
  "pin": "1234",
  "paymentMethod": "manual_transfer"
}
```

**Ответ:**
```json
{
  "paymentId": "pay_123",
  "redirectUrl": null,  // Нет редиректа, показываем реквизиты
  "qrData": null,
  "expiresAt": "2025-11-24T12:00:00Z"  // 7 дней на перевод
}
```

#### Подтверждение поддержкой
```http
POST /api/admin/payments/confirm-manual
X-Admin-Key: ADMIN_SECRET_KEY_CHANGE_IN_PRODUCTION
{
  "paymentId": "pay_123",
  "pspTxnId": "optional_transaction_id_from_bank"
}
```

**Ответ:**
```json
{
  "success": true,
  "activationCode": "ALDN-8K3Q-2PS5-9LM4",
  "message": "Payment confirmed, activation code generated"
}
```

## ⚖️ Сравнение с другими способами

| Способ | Требует договор? | Автоматизация | Скорость обработки |
|--------|------------------|---------------|-------------------|
| **Прямой перевод** | ❌ **НЕТ** | Ручная (поддержка) | 1-24 часа |
| QR/СБП | ✅ Да | ✅ Автоматическая | Мгновенно |
| Банковские карты | ✅ Да | ✅ Автоматическая | Мгновенно |
| SberPay/Tinkoff Pay | ✅ Да | ✅ Автоматическая | Мгновенно |

## 🎯 Когда использовать

### ✅ Подходит для:
- Запуска без договоров (можно начать принимать платежи сразу)
- Резервного способа оплаты
- Небольшого объёма платежей (ручная обработка)

### ❌ Не подходит для:
- Большого объёма платежей (нужна автоматизация)
- Мгновенной активации (требуется проверка поддержкой)

---

## 📝 Что нужно на лендинге

1. **Блок с реквизитами** (показывается при выборе `manual_transfer`):
   ```
   ИНН: 1234567890
   Расчётный счёт: 40702810123456789012
   БИК: 044525225
   Назначение платежа: Оплата подписки ALADDIN, alias: familySmith
   ```

2. **Форма загрузки чека** (опционально):
   - Пользователь может загрузить скриншот/чек перевода
   - Это ускоряет проверку поддержкой

3. **Инструкция**:
   - "Переведите деньги на указанные реквизиты"
   - "После проверки (1-24 часа) вы получите код активации"
   - "Проверить статус можно по alias+PIN"

---

## 🔐 Безопасность

- Админ-эндпоинт защищён `X-Admin-Key`
- В продакшене использовать сильный секретный ключ
- Логировать все подтверждения платежей
- Проверять сумму и назначение платежа перед подтверждением

---

## ✅ Итог

**Прямой банковский перевод — единственный способ принимать платежи без договора.** Он уже реализован в коде и готов к использованию. Остальные способы (QR/СБП, карты, SberPay/Tinkoff Pay) требуют договоры с банками для API доступа.
