### 3. Backend обработка

**API Endpoint:** `POST /api/payment/create-qr`

**Request:**
```json
{
  "tariff_id": "basic",
  "period_months": 12,
  "amount": 2780.0,
  "currency": "RUB"
}
```

**Backend логика:**
1. Проверяет тариф и период
2. Рассчитывает цену с учетом скидки:
   - Если `period_months == 12` → скидка 20%
   - Если `period_months == 6` → скидка 15%
   - Если `period_months == 3` → скидка 10%
   - Если `period_months == 1` → без скидки
3. Создает QR-код на итоговую сумму
4. Возвращает QR-код и `payment_id`

**После оплаты (webhook):**
1. Backend получает подтверждение оплаты
2. Создает подписку:
   ```python
   subscription = await subscription_manager.create_subscription(
       family_id=family_id,
       tier=SubscriptionTier.BASIC_12M,  # или определяет по period_months
       period_months=12
   )
   ```
3. Устанавливает `end_date = now + timedelta(days=30 * 12)`
4. Активирует подписку

## 📱 ДЕТАЛЬНЫЙ UI ДИЗАЙН

### Карточка тарифа с выбором периода:

```swift
struct TariffCardWithPeriod: View {
    @State private var selectedPeriod: Int = 1
    let tariff: TariffType
    
    var body: some View {
        VStack(spacing: 16) {
            // Заголовок
            Text(tariff.title)
                .font(.title2)
                .bold()
            
            // Сегментированный контрол
            Picker("Период", selection: $selectedPeriod) {
                Text("1 мес").tag(1)
                Text("3 мес").tag(3)
                Text("6 мес").tag(6)
                Text("12 мес").tag(12)
            }
            .pickerStyle(.segmented)
            
            // Цены
            VStack(alignment: .leading, spacing: 8) {
                if selectedPeriod > 1 {
                    // Оригинальная цена (зачеркнутая)
                    Text("\(originalPrice)₽")
                        .strikethrough()
                        .foregroundColor(.gray)
                        .font(.subheadline)
                }
                
                // Итоговая цена
                Text("\(finalPrice)₽")
                    .font(.system(size: 32, weight: .bold))
                
                // Скидка
                if let discount = discountPercent, discount > 0 {
                    HStack {
                        Text("\(discount)%")
                            .foregroundColor(.red)
                            .font(.headline)
                        Text(String(repeating: "🔥", count: discount / 5))
                    }
                }
                
                // Цена за месяц
                Text("\(monthlyPrice)₽/месяц")
                    .foregroundColor(.secondary)
                    .font(.subheadline)
                
                // Экономия
                if let savings = savings, savings > 0 {
                    Text("Экономия \(savings)₽")
                        .foregroundColor(.green)
                        .font(.subheadline)
                        .bold()
                }
            }
            
            // Кнопка
            Button("Выбрать тариф") {
                // Переход к оплате
            }
            .buttonStyle(.borderedProminent)
        }
        .padding()
        .background(Color(.systemBackground))
        .cornerRadius(16)
        .shadow(radius: 4)
    }
}
```
