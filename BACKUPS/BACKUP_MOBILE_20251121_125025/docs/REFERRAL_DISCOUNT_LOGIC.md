## 📊 ОБЩАЯ ЛОГИКА

### Участники:
1. **Реферер (тот, кто пригласил)** — пользователь с реферальным кодом
2. **Приглашенный (тот, кого пригласили)** — новый пользователь, который перешел по ссылке

### Скидка для обеих сторон: **-20% на 1 месяц после тестового периода**

## ✅ ЧТО УЖЕ РЕАЛИЗОВАНО (Клиентская часть)

### 1. Приглашенный пользователь (тот, кого пригласили)

#### На лендинге (`index.html`):
- ✅ Реферальный код извлекается из URL (`?ref=CODE` или `#pay?ref=CODE`)
- ✅ Код сохраняется в `localStorage`
- ✅ Показывается баннер: "🎁 У вас применена скидка -20%!"
- ✅ **Цена автоматически уменьшается на 20%** при расчете
- ✅ Код передается на сервер при оплате: `referralCode: "ABC123"`

#### Пример расчета скидки:
```javascript
// Исходная цена: 1000 ₽
// Реферальная скидка: -20%
// Итоговая цена: 800 ₽ (1000 - 200)
```

#### В `index.html` (функция `getTariffPeriodInfo`):
```javascript
if (window.referralCode && window.referralDiscountPercent) {
  referralDiscount = 20; // -20%
  referralSavings = Math.round(finalTotal * (referralDiscount / 100));
  finalTotal = finalTotal - referralSavings; // Применяем скидку
```

## ⚠️ ЧТО НУЖНО РЕАЛИЗОВАТЬ (Серверная часть)

### 1. При оплате приглашенного пользователя

#### Шаг 1: При создании платежа (`/api/payments/create`)

**Текущий запрос (уже реализовано на клиенте):**
```json
{
  "tariffId": "family",
  "userAlias": "newUser",
  "pin": "1234",
  "paymentMethod": "qr_sbp",
  "periodMonths": 12,
  "amount": 800,  // ✅ Уже со скидкой -20%
  "referralCode": "ABC123"  // ✅ Передается на сервер
}
```

**Что нужно сделать на сервере:**
1. ✅ Принять `referralCode` из запроса
2. ✅ Найти реферера по коду в таблице `referral_codes`
3. ✅ Создать запись в таблице `referrals` со статусом `pending`
4. ✅ Сохранить оригинальную цену (до скидки) для учета
5. ✅ Применить скидку к платежу (если еще не применена)

#### Шаг 2: При подтверждении оплаты (`/api/payments/status/{paymentId}`)

**Когда платеж подтвержден (`status: 'paid'`):**
1. ✅ Найти запись в `referrals` для этого пользователя
2. ✅ Обновить статус на `completed`
3. ✅ Установить `converted_at = NOW()`
4. ✅ Записать `discount_applied = 200` (20% от 1000₽)
5. ✅ Записать `reward_amount = 200` (награда рефереру)

#### Шаг 3: Начислить награду рефереру

**Автоматически при подтверждении оплаты:**
1. ✅ Найти `referrer_id` из записи `referrals`
2. ✅ Добавить скидку -20% на следующий месяц для реферера
3. ✅ Сохранить в таблице пользователей или отдельной таблице скидок

## 📋 ДЕТАЛЬНАЯ ЛОГИКА ДЛЯ КАЖДОЙ СТОРОНЫ

### 👤 Приглашенный пользователь (тот, кого пригласили)

#### Когда получает скидку:
- ✅ **Сразу при оплате** — цена уменьшена на 20%
- ✅ Скидка применяется к первой оплате после регистрации

#### Как работает:
1. Переходит по ссылке `aladdin-ai.ru/invite/ABC123`
2. Видит приглашение и код
3. Нажимает "Получить скидку -20%"
4. Переходит на форму оплаты
5. **Цена уже со скидкой -20%** (применена автоматически)
6. Оплачивает подписку
7. Получает код активации

#### Пример:
```
Исходная цена: 1000 ₽
Скидка -20%: -200 ₽
К оплате: 800 ₽ ✅
```

---

### 👥 Реферер (тот, кто пригласил)

#### Когда получает скидку:
- ⚠️ **После того, как приглашенный оплатит подписку**
- ⚠️ Скидка применяется к **следующему месяцу** после тестового периода

#### Как работает:
1. Реферер приглашает друга по коду `ABC123`
2. Друг переходит по ссылке и оплачивает подписку
3. **Сервер автоматически:**
   - Находит реферера по коду `ABC123`
   - Создает запись в `referrals` со статусом `pending`
   - При подтверждении оплаты обновляет статус на `completed`
   - Начисляет скидку -20% рефереру на следующий месяц

#### Пример:
```
Реферер пригласил друга
Друг оплатил подписку: 800 ₽ (со скидкой -20%)
Сервер начисляет рефереру:
  - Скидка -20% на следующий месяц
  - Например: если следующий месяц стоит 1000 ₽, то реферер заплатит 800 ₽
```

### 3. Применение скидки рефереру при следующей оплате

**Нужно создать функцию:**
```python
def apply_referral_discount(user_id: int, original_price: float) -> float:
    """
    Применяет реферальную скидку -20% к цене для реферера
    """
    # Проверить, есть ли активная скидка от реферальной программы
    discount = db.get_active_referral_discount(user_id)
    
    if discount:
        discount_amount = original_price * (discount.percent / 100)
        final_price = original_price - discount_amount
        # Пометить скидку как использованную
        db.mark_discount_as_used(discount.id)
        return final_price
    
    return original_price
```
