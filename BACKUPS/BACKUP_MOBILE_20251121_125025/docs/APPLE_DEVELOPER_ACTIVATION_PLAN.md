## 🎯 ПОСЛЕ АКТИВАЦИИ АККАУНТА (день 3+)

### ШАГ 1: Вход в App Store Connect (5 минут)

1. Открыть https://appstoreconnect.apple.com/
2. Войти с Apple ID (который использовали для оплаты)
3. Принять условия использования (если потребуется)
4. Подтвердить email (если потребуется)

---

### ШАГ 2: Создание приложения в App Store Connect (15 минут)

1. Нажать **"Мои приложения"** → **"+"** → **"Новое приложение"**
2. Заполнить:
   - **Платформа:** iOS
   - **Название:** ALADDIN AI
   - **Основной язык:** Русский
   - **Bundle ID:** `family.aladdin.ios` (должен быть создан заранее)
   - **SKU:** `aladdin-ios-001` (уникальный идентификатор)
3. Нажать **"Создать"**

---

### ШАГ 3: Загрузка скриншотов (30 минут)

1. Перейти в раздел **"App Store"** → **"Скриншоты"**
2. Выбрать **iPhone 6.7" Display** (1290×2796)
3. Загрузить 7 скриншотов в правильном порядке:
   - Main Screen
   - VPN Screen
   - Family Screen
   - Profile Screen
   - Settings Screen
   - Tariffs Screen (12 месяцев)
   - Payment/QR Screen
4. Выбрать **iPhone 6.5" Display** (1242×2688)
5. Загрузить те же 7 скриншотов
6. Проверить отображение

---

### ШАГ 4: Заполнение App Information (20 минут)

1. Перейти в **"App Information"**
2. Заполнить:
   - **Категория:** Productivity (основная), Education (вторичная)
   - **Age Rating:** Пройти анкету → получить 5+ (целевой рейтинг)
   - **Copyright:** © 2025 ALADDIN AI
   - **Privacy Policy URL:** `https://aladdin-ai.ru/privacy.html`
   - **Support URL:** `https://aladdin-ai.ru/help-faq.html`
   - **Marketing URL:** (опционально) `https://aladdin-ai.ru/`
3. Сохранить

---

### ШАГ 5: Заполнение App Privacy (15 минут)

1. Перейти в **"App Privacy"**
2. Нажать **"Начать"**
3. Выбрать **"Нет, мы не собираем данные"** (или указать только технические данные)
4. Если собираем данные:
   - Device ID → Функциональность
   - Session ID → Функциональность
   - Агрегированная статистика → Аналитика
5. **Передача данных:** Нет
6. Сохранить

---

### ШАГ 6: Заполнение Pricing and Availability (10 минут)

1. Перейти в **"Pricing and Availability"**
2. Выбрать:
   - **Цена:** Бесплатно (Free)
   - **Доступность:** Все страны (или выбрать конкретные)
3. Сохранить

---

### ШАГ 7: Подготовка Version Information (30 минут)

1. Перейти в **"App Store"** → **"Версия 1.0"**
2. Заполнить:
   - **Что нового в этой версии:** (текст обновления)
   - **Описание:** (полное описание из подготовленного файла)
   - **Ключевые слова:** (из подготовленного файла)
   - **Поддержка:** (URL или email)
   - **Маркетинговый URL:** (опционально)
   - **Промо-текст:** (опционально)
3. Загрузить иконку приложения (1024×1024 PNG)
4. Сохранить

---

### ШАГ 8: Заполнение Review Information (10 минут)

1. Перейти в **"App Review Information"**
2. Вставить подготовленный текст Review Notes
3. Указать контактную информацию:
   - **First Name:** [Ваше имя]
   - **Last Name:** [Ваша фамилия]
   - **Phone:** [Ваш телефон]
   - **Email:** [Ваш email]
4. Сохранить

---

### ШАГ 9: Создание Archive и Upload (1 час)

**В Xcode:**

1. Выбрать схему **"ALADDIN"** → **"Any iOS Device"**
2. **Product** → **Clean Build Folder** (`Shift+Cmd+K`)
3. **Product** → **Archive** (дождаться завершения)
4. В **Organizer** выбрать архив
5. Нажать **"Distribute App"**
6. Выбрать **"App Store Connect"**
7. Следовать инструкциям:
   - Выбрать метод распространения
   - Выбрать опции подписывания (Automatic)
   - Загрузить
8. Дождаться завершения загрузки

**В App Store Connect:**

1. Перейти в **"TestFlight"** → **"iOS Builds"**
2. Дождаться обработки билда (10-30 минут)
3. Проверить, что билд появился в списке
4. Если есть ошибки — исправить и загрузить снова

---

### ШАГ 10: Регистрация In-App Purchases (1-2 часа)

**Примечание:** Для России IAP не используется (оплата на сайте), но для других регионов нужно зарегистрировать.

1. Перейти в **"In-App Purchases"**
2. Нажать **"+"** → **"Auto-Renewable Subscription"**
3. Создать продукты:
   - **Personal** (1 месяц, 3 месяца, 6 месяцев, 12 месяцев)
   - **Family** (1 месяц, 3 месяца, 6 месяцев, 12 месяцев)
   - **Premium** (1 месяц, 3 месяца, 6 месяцев, 12 месяцев)
4. Заполнить:
   - Product ID (например: `family.aladdin.ios.personal.1month`)
   - Reference Name
   - Price (для каждого региона)
   - Subscription Group (создать группу "ALADDIN Subscriptions")
   - Subscription Duration
5. Сохранить

---

### ШАГ 11: Отправка на Review (5 минут)

1. Перейти в **"App Store"** → **"Версия 1.0"**
2. Проверить все разделы (зелёные галочки):
   - ✅ Скриншоты загружены
   - ✅ Описание заполнено
   - ✅ App Privacy заполнена
   - ✅ Review Notes заполнены
   - ✅ Билд загружен
   - ✅ Публичные URL указаны
3. Нажать **"Отправить на проверку"** (Submit for Review)
4. Дождаться подтверждения
