## 🔍 Если приложение не запускается

### Возможные проблемы:

1. **Симулятор не запущен:**
   - Проверьте, что симулятор iPhone 13 запущен
   - Если нет — Xcode должен запустить его автоматически

2. **Ошибки выполнения:**
   - Проверьте консоль Xcode (⌘ + Shift + Y)
   - Ищите красные ошибки в логах

3. **Проблемы с подписями:**
   - Проверьте Signing & Capabilities в Xcode
   - Убедитесь, что выбран Development Team

4. **Проблемы с зависимостями:**
   - Проверьте, что все зависимости установлены
   - Попробуйте Clean Build Folder (⌘ + Shift + K)
