## ⚠️ КРИТИЧЕСКИЙ АНАЛИЗ: ЧТО ПЕРЕНЕСТИ И КОГДА

### 🔴 **НЕ ПЕРЕНОСИТЬ ПЕРЕД ПРОДАКШЕНОМ:**

#### 1. **Локальное сканирование (LocalThreatDatabase)** 🔴
**Текущее состояние:**
- ✅ Быстрая проверка метаданных (расширения, имена файлов)
- ✅ Работает офлайн
- ✅ Низкое потребление батареи

**Почему НЕ переносить:**
- ❌ **UX деградация:** Пользователь ждёт ответа сервера (1-3 секунды) вместо мгновенной проверки
- ❌ **Офлайн не работает:** Без интернета защита не работает
- ❌ **Нагрузка на сервер:** Миллионы запросов на проверку каждого файла
- ❌ **Задержки:** Даже с кэшем, первая проверка будет медленной

**Рекомендация:** ✅ **ОСТАВИТЬ НА iOS** (быстрая проверка метаданных), сервер для глубокого анализа

---

#### 2. **VPN клиент** 🔴
**Текущее состояние:**
- ✅ VPNManager работает локально
- ✅ Низкая задержка подключения
- ✅ Работает офлайн

**Почему НЕ переносить:**
- ❌ **Производительность:** VPN должен работать на устройстве (Network Extension)
- ❌ **Безопасность:** Трафик шифруется локально, не проходит через сервер
- ❌ **UX:** Задержки при каждом подключении

**Рекомендация:** ✅ **ОСТАВИТЬ НА iOS** (VPN клиент), сервер только для конфигурации
