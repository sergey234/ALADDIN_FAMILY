## 🔴 КРИТИЧЕСКИЕ ЗАДАЧИ (СЕЙЧАС)

### 1. Загрузка и настройка Backend на сервере ⚠️ СЛЕДУЮЩЕЕ

**Время:** 1-2 часа  
**Приоритет:** 🔴 Критический

#### Шаг 1.1: Загрузка backend на сервер
- [ ] Загрузить `payment_service/` на сервер (`/opt/aladdin-backend/`)
- [ ] Использовать скрипт `deploy_backend_to_server.sh` или rsync вручную

#### Шаг 1.2: Установка зависимостей на сервере
- [ ] Подключиться к серверу: `ssh root@149.154.65.180`
- [ ] Создать виртуальное окружение: `python3 -m venv .venv`
- [ ] Активировать: `source .venv/bin/activate`
- [ ] Установить зависимости: `pip install -r requirements.txt`

#### Шаг 1.3: Настройка .env на сервере
- [ ] Создать/обновить `.env` файл
- [ ] Добавить `PAYMENT_CARD_NUMBER` и `PAYMENT_CARD_HOLDER_NAME`
- [ ] Проверить другие настройки

#### Шаг 1.4: Запуск backend
- [ ] Протестировать запуск: `uvicorn main:app --host 127.0.0.1 --port 8000`
- [ ] Проверить доступность: `curl http://localhost:8000/api/payment-methods`
- [ ] Создать systemd сервис для автозапуска

#### Шаг 1.5: Настройка Nginx
- [ ] Добавить `location /api/` в конфигурацию Nginx
- [ ] Настроить proxy_pass на `http://127.0.0.1:8000`
- [ ] Перезагрузить Nginx: `systemctl reload nginx`

#### Шаг 1.6: Тестирование
- [ ] Проверить доступность API: `curl https://aladdin-ai.ru/api/payment-methods`
- [ ] Протестировать создание платежа через лендинг
- [ ] Проверить сохранение согласия ПДн в БД
