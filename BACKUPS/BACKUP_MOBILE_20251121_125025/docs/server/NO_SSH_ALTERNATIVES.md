# 🔧 АЛЬТЕРНАТИВЫ SSH: Как работать без SSH-доступа

**Проблема:** Нет SSH-доступа к серверу 149.154.65.180  
**Решение:** Используем альтернативные способы

---

## 🎯 ВАРИАНТЫ РАБОТЫ БЕЗ SSH

### ✅ Вариант 1: Настроить SSH-доступ (РЕКОМЕНДУЕТСЯ)

**Как получить SSH-доступ:**

1. **Связаться с администратором сервера**
   - Попросить создать SSH пользователя
   - Получить IP, порт, логин, пароль или ключ

2. **Если у вас есть доступ к панели управления**
   - cPanel, Plesk, ISPmanager - обычно есть функция "SSH Access"
   - Включите SSH доступ в настройках

3. **Если сервер ваш**
   - Установите SSH сервер: `sudo apt install openssh-server`
   - Настройте доступ в `/etc/ssh/sshd_config`

**После получения доступа:**
```bash
ssh user@149.154.65.180
```

---

### ✅ Вариант 2: Использовать SFTP/FTP клиент

**Если есть FTP/SFTP доступ:**

1. **Используйте FileZilla, WinSCP, или другой FTP клиент**
2. **Подключитесь к серверу:**
   - Хост: 149.154.65.180
   - Порт: 21 (FTP) или 22 (SFTP)
   - Логин/пароль: ваши учетные данные

3. **Загрузите файлы:**
   - Скопируйте скрипты на сервер
   - Загрузите SQL файлы
   - Загрузите HTML файлы

4. **Выполните команды через веб-интерфейс** (если есть)

---

### ✅ Вариант 3: Веб-интерфейс панели управления

**Если есть cPanel, Plesk, или другая панель:**

1. **Файловый менеджер:**
   - Загрузите файлы через веб-интерфейс
   - Создайте директории
   - Скопируйте файлы

2. **Терминал в браузере:**
   - Многие панели имеют встроенный терминал
   - Выполняйте команды прямо в браузере

3. **phpMyAdmin (для БД):**
   - Выполните SQL скрипты через веб-интерфейс
   - Импортируйте backup'ы

---

### ✅ Вариант 4: Использовать Python скрипт на сервере

**Если на сервере уже работает Python/FastAPI:**

1. **Создать endpoint для backup'а:**
   - Добавить специальный endpoint в FastAPI
   - Вызвать через браузер или API

2. **Или использовать существующие инструменты:**
   - Если есть админ-панель
   - Если есть API для управления

---

### ✅ Вариант 5: Попросить администратора выполнить

**Если нет доступа вообще:**

1. **Подготовьте все файлы:**
   - SQL скрипты
   - Python код
   - HTML файлы
   - Инструкции

2. **Отправьте администратору:**
   - Все файлы в архиве
   - Четкие инструкции что делать
   - Скрипты для выполнения

3. **Попросите выполнить:**
   - Создать backup'ы
   - Выполнить SQL скрипт
   - Разместить файлы
