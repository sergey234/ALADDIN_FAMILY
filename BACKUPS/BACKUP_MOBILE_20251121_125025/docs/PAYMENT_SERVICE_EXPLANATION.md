## 🎯 КТО ИСПОЛЬЗУЕТ `payment_service/`?

### 1. 🌐 ЛЕНДИНГ (index.html)

**Что делает:**
- Пользователь заполняет форму оплаты на лендинге
- Лендинг отправляет POST запрос на backend:
  ```
  POST https://aladdin-ai.ru/api/payments/create
  {
    "tariffId": "family",
    "userAlias": "test123",
    "pin": "1234",
    "paymentMethod": "qr_sbp",
    "personalDataConsent": true,
    ...
  }
  ```
- Backend создает платеж и возвращает `paymentId`, `redirectUrl`
- Пользователь переходит на оплату

**Использует эндпоинты:**
- `POST /api/payments/create` - создание платежа
- `GET /api/payment-methods` - список методов оплаты
- `GET /api/manual-transfer/info` - информация для ручного перевода

### 2. 📱 МОБИЛЬНОЕ ПРИЛОЖЕНИЕ (iOS)

**Что делает:**
- Пользователь вводит alias и PIN в приложении
- Приложение отправляет запрос на backend:
  ```
  POST https://api.aladdin.family/api/activation/retrieve
  {
    "alias": "test123",
    "pin": "1234"
  }
  ```
- Backend проверяет платеж и возвращает код активации
- Приложение активирует подписку

**Использует эндпоинты:**
- `POST /api/activation/retrieve` - получение кода активации
- `POST /api/activation/verify` - проверка кода
- `POST /api/activation/activate` - активация кода

## 🔄 ПОЛНЫЙ ПРОЦЕСС ОПЛАТЫ

### Шаг 1: Пользователь на лендинге
```
1. Открывает https://aladdin-ai.ru/#pay
2. Выбирает тариф (Family, Premium и т.д.)
3. Вводит alias и PIN
4. Отмечает согласие на обработку ПДн
5. Нажимает "Перейти к оплате"
```

### Шаг 2: Лендинг → Backend
```
Лендинг отправляет:
POST https://aladdin-ai.ru/api/payments/create
{
  "tariffId": "family",
  "userAlias": "test123",
  "pin": "1234",
  "paymentMethod": "qr_sbp",
  "personalDataConsent": true,
  "consentTimestamp": "2025-11-19T20:00:00Z",
  "consentIP": "94.231.135.14"
}

Backend сохраняет:
- Платеж в БД
- Согласие на обработку ПДн (152-ФЗ)
- Возвращает paymentId и redirectUrl
```

### Шаг 3: Оплата
```
Пользователь оплачивает через:
- QR код / СБП
- Банковскую карту
- Ручной перевод на карту
```

### Шаг 4: Backend получает подтверждение
```
Банк отправляет webhook:
POST https://aladdin-ai.ru/api/payments/confirm
{
  "payment_id": "pay_123",
  "status": "paid"
}

Backend:
- Обновляет статус платежа на "paid"
- Генерирует код активации: "ALDN-XXXX-XXXX"
- Сохраняет код в БД
```

### Шаг 5: Пользователь в мобильном приложении
```
1. Открывает приложение
2. Вводит alias и PIN
3. Приложение отправляет:
   POST /api/activation/retrieve
   {
     "alias": "test123",
     "pin": "1234"
   }

4. Backend возвращает:
   {
     "code": "ALDN-XXXX-XXXX",
     "expires_at": "2025-12-19T20:00:00Z"
   }

5. Приложение активирует подписку
```

## 📊 ЧТО ХРАНИТСЯ В `payment_service/`?

### База данных (payments.db):

**Таблица `payments`:**
- Информация о платежах
- Alias и PIN (хешированный)
- Тариф и сумма
- Статус платежа
- **Согласие на обработку ПДн** (152-ФЗ)
- IP адрес и время согласия

**Таблица `activation_codes`:**
- Коды активации (ALDN-XXXX-XXXX)
- Связь с платежом
- Статус (использован/не использован)
- Срок действия

## 📝 АНАЛОГИЯ

Представьте ресторан:

- **Лендинг** = Официант (принимает заказ от клиента)
