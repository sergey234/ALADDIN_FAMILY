### ✅ ЗАДАЧА 1: ОБНОВЛЕНИЕ TERMS OF SERVICE (РАЗДЕЛ 8)

#### 🔍 Что реально есть в системе:

**1. Система оплаты:**
- ✅ **QR-оплата для России:** Полностью реализована
  - `PaymentQRScreen.swift` - экран QR-оплаты
  - `PaymentQRViewModel.swift` - логика QR-оплаты
  - Поддержка: СБП, SberPay, Universal QR
  - `AppConfig.useAlternativePayments = true` (всегда для России)

- ✅ **IAP для других регионов:** Реализована
  - `StoreManager.swift` - менеджер IAP
  - `AppConfig.useIAP = !isRussianRegion`
  - `TariffsViewModel.purchaseTariff()` - логика покупки

**2. Определение региона:**
```swift
// Core/Config/AppConfig.swift
static var isRussianRegion: Bool {
    return Locale.current.regionCode == "RU"
}

static var useAlternativePayments: Bool {
    // ✅ ВСЕГДА true - используем только QR оплату (IAP в России недоступен)
    return true
}

static var useIAP: Bool {
    return !isRussianRegion
}
```

**3. Навигация к оплате:**
```swift
// Screens/10_TariffsScreen.swift (строка 333-348)
if AppConfig.useAlternativePayments {
    // Россия → QR оплата
    navigationManager.selectedTariffForPayment = tariffObj
    navigationManager.navigateTo(.paymentQR)
} else {
    // Не Россия → IAP
    await viewModel.purchaseSelectedTariff()
}
```

#### ✅ Соответствие правилам App Store:

**Apple App Store Guidelines 3.1.1 - In-App Purchase:**
- ✅ **Для России:** QR-оплата разрешена, так как IAP недоступен в России
- ✅ **Для других регионов:** Используется IAP (StoreKit)
- ✅ **Не противоречим правилам:** Используем альтернативные платежи только там, где IAP недоступен

**Вывод:** ✅ Система оплаты полностью соответствует правилам App Store.
