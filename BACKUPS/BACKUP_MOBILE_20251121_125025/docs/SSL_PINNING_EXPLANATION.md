## 🤔 ЧТО ТАКОЕ SSL PINNING? (Простым языком)

### 📖 Аналогия с Домом:

**Без SSL Pinning:**
- Вы приходите к дому (серверу)
- Сторож (iOS) спрашивает: "Вы хозяин?"
- Любой может показать поддельный паспорт (поддельный сертификат)
- Сторож проверяет только, что паспорт выглядит правильно
- **Проблема:** Мошенник может подделать паспорт и войти!

**С SSL Pinning:**
- Вы приходите к дому (серверу)
- Сторож (iOS) говорит: "Покажите паспорт!"
- У сторожа есть **ФОТОГРАФИЯ** настоящего хозяина (сертификат в приложении)
- Сторож сравнивает: "Этот паспорт совпадает с фотографией?"
- Если **ДА** → впускает ✅
- Если **НЕТ** → блокирует ❌
- **Безопасность:** Мошенник не может подделать, потому что у сторожа есть оригинальная фотография!

---

## 🔒 ДЛЯ ЧЕГО ЭТО НУЖНО?

### **Защита от атак "Man-in-the-Middle" (MITM):**

**Без SSL Pinning:**
```
📱 Ваш телефон → 🌐 Интернет → 🏢 Сервер
                    ⬇️
              👤 Хакер перехватывает!
              (подделывает сертификат)
```

**С SSL Pinning:**
```
📱 Ваш телефон → 🌐 Интернет → 🏢 Сервер
                    ⬇️
              👤 Хакер пытается перехватить
              ❌ БЛОКИРОВАНО! (сертификат не совпадает)
```

## ⚠️ ЧТО НУЖНО СДЕЛАТЬ?

### **Шаг 1: Получить сертификаты с сервера**

**Сервер:** `aladdin-ai.ru`

**Как получить:**
```bash
# Вариант 1: Через OpenSSL
openssl s_client -showcerts -connect aladdin-ai.ru:443 < /dev/null | openssl x509 -outform DER > aladdin_cert.cer

# Вариант 2: Через браузер
# 1. Откройте https://aladdin-ai.ru
# 2. Нажмите на замочек в адресной строке
# 3. Просмотр сертификата → Экспорт → Сохранить как .cer
```

---

### **Шаг 2: Добавить сертификаты в Xcode**

**Инструкция:**
1. Откройте Xcode проект
2. Перетащите файлы `aladdin_cert.cer` и `aladdin_cert_backup.cer` в папку `ALADDIN/Certificates/`
3. **ВАЖНО:** Убедитесь, что файлы добавлены в **Target Membership** (ALADDIN)
4. Проверьте, что файлы видны в навигаторе Xcode
