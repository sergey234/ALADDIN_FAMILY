# Краткая инструкция: сброс токена и проверка API

## 1. Сброс авторизации
1. Открой приложение в Xcode (Debug сборка).
2. При запуске `KeychainAutoRecoveryService` проверит и удалит повреждённые `auth_token` / `refresh_token`.
3. Если нужно вручную очистить токены, вызови `KeychainManager.shared.delete(forKey: .authToken)` и `.delete(forKey: .refreshToken)` в Debug Console или переустанови приложение.
4. Пройди авторизацию заново и убедись, что в Keychain появился валидный JSON (в логах пропадёт `Failed to decode auth_token`/`JWT: Access token не найден`).

## 2. Проверка API `/family/stats`
1. После успешного логина открой главный экран (MainScreen) — `MainViewModel` выполнит запрос к `/family/stats`.
2. В логах `NetworkManager` теперь логирует длительность каждого запроса (`⏱️ NetworkManager: запрос завершился за …`).
3. Если два запроса подряд заняли >5 секунд, таймауты автоматически увеличатся (в логах появится `таймауты увеличены …`). После стабилизации можно перезапустить приложение, чтобы вернуться к стандартным значениям.

## 3. Проверка локализации
1. Открой карточку «Вознаграждение ребёнка» → шестерёнка → убедись, что тексты отображаются на выбранном языке.
2. При необходимости переключи язык в настройках — `LocalizationDiagnostics` проверяет, что ключи `child_rewards_settings_*` присутствуют в RU/EN и логирует предупреждение, если чего-то не хватает.

## 4. Что отслеживаем в логах
- Ошибки Keychain: должны пропасть после очистки.
- Таймауты `NSURLErrorDomain Code=-1001`: теперь сопровождаются измерением времени; если видишь их постоянно, проверь сервер или увеличь таймауты на время диагностики.
- Информационные сообщения `ProfileImageManager` можно игнорировать (они появляются, пока пользователь не загрузил аватар).

Эти шаги добавлены в рабочий чеклист — перед релизом достаточно пройти точки 1–3, чтобы убедиться, что авторизация, сеть и локализация работают штатно.
