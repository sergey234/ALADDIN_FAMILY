## ❤️ КРАСНАЯ ШЛЯПА (Эмоции и чувства)

### Вариант 1: Экран Тарифов

**Положительные эмоции:**
- ✅ Логично: "Выбрал тариф → Оплатил → Активировал"
- ✅ Ожидаемо: пользователь уже в контексте подписки
- ✅ Удобно: все в одном месте

**Отрицательные эмоции:**
- ⚠️ Может быть неочевидно для пользователя, который уже оплатил
- ⚠️ Если пользователь вернулся в приложение после оплаты, он может не помнить, где искать

### Вариант 2: Главный экран (желтая карточка)

**Положительные эмоции:**
- ✅ Всегда видно: пользователь сразу видит кнопку
- ✅ Удобно: не нужно искать в других разделах
- ✅ Привычно: главный экран — первое, что видит пользователь

**Отрицательные эмоции:**
- ⚠️ Может быть перегружено: 3 кнопки в одной карточке
- ⚠️ Нелогично: активация кода не связана с управлением семьей
- ⚠️ Визуально тесно: карточка может стать слишком "забитой"

## ⚫ ЧЕРНАЯ ШЛЯПА (Критическое мышление, риски)

### Вариант 1: Экран Тарифов

**Риски:**
- ❌ Пользователь может не найти кнопку после оплаты
- ❌ Если пользователь уже выбрал тариф, он может не вернуться на экран тарифов
- ❌ Менее заметно для пользователей, которые уже имеют подписку

**Проблемы:**
- ⚠️ Нужно добавить отдельную карточку/кнопку
- ⚠️ Может быть неочевидно, что это для активации кода

### Вариант 2: Главный экран (желтая карточка)

**Риски:**
- ❌ **Визуальная перегрузка:** 3 кнопки в одной карточке — слишком много
- ❌ **Семантическая путаница:** активация кода не связана с управлением семьей
- ❌ **UX проблема:** пользователь может случайно нажать не ту кнопку
- ❌ **Нарушение принципа группировки:** кнопки должны быть логически связаны

**Проблемы:**
- ⚠️ Карточка станет слишком широкой или кнопки станут слишком узкими
- ⚠️ Нарушение визуальной иерархии
- ⚠️ Может быть неочевидно, что это для активации кода подписки

## 💚 ЗЕЛЕНАЯ ШЛЯПА (Креативность, альтернативы)

### Альтернатива 1: Отдельная карточка на главном экране

**Идея:** Добавить отдельную карточку "Активировать код" на главный экран
- После желтой карточки "Семья"
- Своя карточка с иконкой 🔑
- Не перегружает карточку "Семья"

**Плюсы:**
- ✅ Высокая видимость
- ✅ Не перегружает карточку "Семья"
- ✅ Семантически правильно

**Минусы:**
- ⚠️ Занимает место на главном экране
- ⚠️ Может быть не нужно для пользователей с активной подпиской

### Альтернатива 2: В настройках (уже есть)

**Идея:** Добавить в раздел "Дополнительно" в настройках
- Уже есть карточка согласия
- Можно добавить рядом карточку активации

**Плюсы:**
- ✅ Логично для административных функций
- ✅ Не перегружает главный экран

**Минусы:**
- ⚠️ Менее очевидно для пользователя
- ⚠️ Нужно искать в настройках

### Альтернатива 3: Умная карточка (показывать только при необходимости)

**Идея:** Показывать карточку "Активировать код" только если:
- Пользователь не имеет активной подписки
- ИЛИ пользователь недавно оплатил (в течение 24 часов)

**Плюсы:**
- ✅ Не перегружает UI для пользователей с активной подпиской
- ✅ Высокая видимость для тех, кому нужно

**Минусы:**
- ⚠️ Сложнее в реализации
- ⚠️ Нужна логика определения состояния

### Альтернатива 4: В карточке тарифа

**Идея:** Добавить кнопку "Активировать код" прямо в карточку тарифа
- После выбора тарифа показывать кнопку активации

**Плюсы:**
- ✅ Максимально логично
- ✅ В контексте выбора тарифа

**Минусы:**
- ⚠️ Может быть неочевидно для пользователей, которые уже оплатили

### ✅ РЕКОМЕНДУЕМЫЙ ВАРИАНТ: Экран Тарифов

**Где:** После карточек тарифов (после строки 134)

**Как:**
```swift
// После карточек тарифов
VStack(spacing: Spacing.m) {
    Button(action: {
        navigationManager.navigateTo(.activationCode)
    }) {
        HStack(spacing: Spacing.m) {
            Image(systemName: "key.fill")
                .font(.system(size: 18))
                .foregroundColor(.primaryBlue)
            
            Text("Активировать код подписки")
                .font(.body)
                .foregroundColor(.textPrimary)
            
            Spacer()
            
            Image(systemName: "chevron.right")
                .font(.system(size: 14))
                .foregroundColor(.textSecondary)
        }
        .padding(Spacing.m)
        .background(
            RoundedRectangle(cornerRadius: CornerRadius.medium)
                .fill(Color.backgroundMedium.opacity(0.3))
        )
    }
}
.padding(.horizontal, Spacing.screenPadding)
```

