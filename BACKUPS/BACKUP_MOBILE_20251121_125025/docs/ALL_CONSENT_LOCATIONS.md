### 4. 📝 **РЕГИСТРАЦИЯ (MainScreenWithRegistration)** — Модальное окно согласия

**Файл:** `Screens/MainScreenWithRegistration.swift`

**Местоположение:**
- Раздел: Экран регистрации семьи
- Позиция: Показывается **первым** при регистрации
- Строки: 50-61

**Что показывает:**
- ✅ Модальное окно `ConsentModal`
- ✅ Показывается через `registrationVM.showConsentModal`
- ✅ Полный текст согласия с возможностью развернуть

**Особенности:**
- Показывается **только при регистрации семьи**
- Не показывается при обычном использовании приложения
- Использует отдельный компонент `ConsentModal`

**Код:**
```swift
// Consent Modal (показывается первым)
if registrationVM.showConsentModal {
    ConsentModal(
        isPresented: Binding(
            get: { registrationVM.showConsentModal },
            set: { registrationVM.showConsentModal = $0 }
        ),
        onConsentGiven: {
            registrationVM.acceptConsent()
        }
    )
}
```
