# 🔗 Ссылки для оплаты Apple Developer Program через Gift Card

**Дата:** 16 ноября 2025

---

## 📱 АКТИВАЦИЯ GIFT CARD (Redeem Gift Card)

### 🌐 Онлайн (через браузер):

**Прямая ссылка:**
```
https://apps.apple.com/redeem
```

**Альтернативная ссылка:**
```
https://appleid.apple.com/account/manage
```
(Затем: Media & Purchases → Redeem Gift Card or Code)

---

### 📱 Через iPhone/iPad:

1. Откройте **App Store**
2. Нажмите на **ваш профиль** (иконка в правом верхнем углу)
3. Нажмите **"Redeem Gift Card or Code"** (Активировать подарочную карту или код)
4. Введите код с карты

**Или через настройки:**
1. Откройте **Настройки** (Settings)
2. Нажмите на ваше имя вверху
3. Выберите **Media & Purchases**
4. Нажмите **Redeem Gift Card or Code**

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ С ССЫЛКАМИ

### Шаг 1: Активировать Gift Card

**Ссылка:** https://apps.apple.com/redeem

1. Войдите в Apple ID
2. Введите код с Gift Card
3. Нажмите "Redeem" (Активировать)
4. Баланс пополнится на ваш Apple ID

---

### Шаг 2: Зарегистрировать Developer Program

**Ссылка:** https://developer.apple.com/programs/

1. Нажмите **"Enroll"** (Зарегистрироваться)
2. Войдите с Apple ID (у которого есть баланс)
3. Заполните форму регистрации
4. Выберите тип аккаунта (Individual или Company)

---

### Шаг 3: Оплата через баланс Apple ID

**В процессе регистрации:**

1. Дойдите до шага **"Purchase"** (Покупка)
2. Выберите способ оплаты
3. Если на балансе Apple ID достаточно средств ($99+), появится опция:
   - **"Use Apple ID Balance"** (Использовать баланс Apple ID)
4. Выберите эту опцию
5. Подтвердите оплату

---

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### Если опция "Use Apple ID Balance" не появляется:

**Возможные причины:**
1. **Недостаточно средств** - на балансе должно быть минимум $99
2. **Регион не совпадает** - Gift Card должен быть того же региона, что и Apple ID
3. **Баланс не активирован** - убедитесь, что Gift Card активирован

**Решение:**
- Проверьте баланс Apple ID: https://appleid.apple.com/account/manage
- Убедитесь, что Gift Card активирован
- Если баланс есть, но опция не появляется - попробуйте через несколько часов

## 🔍 ПРОВЕРКА БАЛАНСА APPLE ID

**Ссылка для проверки баланса:**
```
https://appleid.apple.com/account/manage
```

**Как проверить:**
1. Войдите в Apple ID
2. Перейдите в раздел **"Payment & Shipping"**
3. Там будет указан баланс Apple ID

## 📱 АЛЬТЕРНАТИВНЫЕ СПОСОБЫ ДОСТУПА

### Через App Store на iPhone:

1. Откройте **App Store**
2. Нажмите на **ваш профиль** (иконка в правом верхнем углу)
3. Там будет показан **баланс** (если есть)
4. Нажмите **"Redeem Gift Card or Code"** для активации

### Через iTunes (на компьютере):

1. Откройте **iTunes**
2. Войдите в Apple ID
3. **Account** → **Redeem**
4. Введите код Gift Card
