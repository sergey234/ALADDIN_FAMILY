3. **Главная страница не обновляется** — данные семьи не загружаются из API

## 🔧 ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: Родительские функции не видны

**Причина:**
- `isCurrentUserParent()` возвращает `false` потому что `current_user_role` не установлен в UserDefaults
- Роль должна устанавливаться при входе в систему или переключении интерфейса

**Решение:**
1. Установить роль при входе в ParentalControlScreen
2. Установить роль при переключении на детский интерфейс
3. Добавить проверку в `isCurrentUserParent()` с fallback на проверку текущего экрана

### Проблема 2: Главная страница не обновляется

**Причина:**
- `MainViewModel.loadDashboardData()` вызывается, но данные не отображаются
- Возможно, данные загружаются, но UI не обновляется

**Решение:**
1. Проверить, что `@Published` свойства обновляются на главном потоке
2. Добавить принудительное обновление UI после загрузки данных
3. Проверить, что `mainViewModel` правильно инжектирован в MainScreen

   ```swift
   private func isCurrentUserParent() -> Bool {
       // Проверка через UserDefaults
       if let roleString = UserDefaults.standard.string(forKey: "current_user_role"),
          let role = FamilyRole(storageValue: roleString) {
           return role == .parent
       }
       
       // Fallback: проверка текущего экрана
       if navigationManager.currentScreen == .parentalControl {
           return true
       }
       
       // По умолчанию - ребёнок (безопаснее)
       return false
   }
   ```
