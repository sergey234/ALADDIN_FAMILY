### 🔴 **ШАГ 1: ПЕРЕД ПРОДАКШЕНОМ (2-3 НЕДЕЛИ)**

#### **1.1 Увеличить долю проверок на сервере:**

**Текущее состояние:**
```swift
// AntivirusManager.swift
func performFullScan(fileURL: URL) async -> ScanResult {
    // 1. Быстрая локальная проверка
    let quickResult = await quickMetadataCheck(fileURL: fileURL)
    
    // 2. Если подозрительно → сервер
    if quickResult == .suspicious {
        // Отправка на сервер
        if let serverResult = await uploadForDeepScan(...) {
            return serverResult
        }
    }
}
```

**Что изменить:**
```swift
// Увеличить долю проверок на сервере
func performFullScan(fileURL: URL) async -> ScanResult {
    // 1. Быстрая локальная проверка (только для явно безопасных)
    let quickResult = await quickMetadataCheck(fileURL: fileURL)
    
    // 2. Если явно безопасно → возвращаем сразу
    if quickResult == .clean {
        return ScanResult(...)
    }
    
    // 3. ВСЕ остальные → сервер (80% проверок)
    if let serverResult = await uploadForDeepScan(...) {
        return serverResult
    }
    
    // 4. Fallback на локальную проверку
    return await scanOffline(fileURL: fileURL)
}
```
