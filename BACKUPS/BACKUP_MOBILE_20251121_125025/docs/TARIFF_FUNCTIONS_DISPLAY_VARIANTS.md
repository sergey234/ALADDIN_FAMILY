# 🎨 Варианты отображения 138 функций по тарифам на лендинге

## 📊 ВАРИАНТ 1: Аккордеон внутри карточек тарифов

### Концепция
В каждой карточке тарифа (FREE, PERSONAL, FAMILY, PREMIUM) добавляется раздвигающееся окно "Посмотреть все X функций защиты" с аккордеонами по категориям.

### Структура
```
┌─────────────────────────────────┐
│ FREE - 0₽/мес                  │
│ 26/138 функций (19%)           │
│                                 │
│ [Основные преимущества]        │
│                                 │
│ ▼ Посмотреть все 26 функций    │
│   ├─ 🛡️ Защита от угроз (16)   │
│   │  ├─ Киберугрозы (10)       │
│   │  └─ Интернет-угрозы (6)    │
│   ├─ 👨‍👩‍👧 Родительский контроль (8)│
│   └─ ⚙️ Дополнительные (2)     │
└─────────────────────────────────┘
```

### Преимущества
- ✅ Всё в одном месте — не нужно переходить на другую страницу
- ✅ Пользователь видит только нужный тариф
- ✅ Не перегружает страницу — аккордеон скрывает детали
- ✅ Мобильно-дружелюбно — легко сворачивается

### Недостатки
- ⚠️ Много скролла внутри карточки
- ⚠️ Сложно сравнивать тарифы (нужно открывать каждый)

### Оценка (1-5 баллов)
- **Читаемость:** ⭐⭐⭐⭐ (4/5) — хорошо структурировано
- **Удобство:** ⭐⭐⭐ (3/5) — нужно открывать каждый тариф отдельно
- **Визуал:** ⭐⭐⭐⭐ (4/5) — аккуратно, не перегружает
- **Реализация:** ⭐⭐⭐⭐⭐ (5/5) — просто, уже есть аккордеоны
- **Мобильность:** ⭐⭐⭐⭐⭐ (5/5) — отлично работает на телефоне

**ИТОГО: 21/25 баллов** 🏆

### Преимущества
- ✅ Легко сравнивать тарифы — всё в одной таблице

### Недостатки

### Оценка (1-5 баллов)

- **Мобильность:** ⭐⭐ (2/5) — горизонтальный скролл на телефоне

### Преимущества
