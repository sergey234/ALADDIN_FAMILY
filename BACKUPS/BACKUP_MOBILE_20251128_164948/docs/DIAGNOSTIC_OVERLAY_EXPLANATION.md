## 🎯 Что такое диагностический overlay?

**Диагностический overlay** — это **визуальное окно отладки**, которое показывается поверх экрана приложения и отображает техническую информацию в реальном времени.

### Пример того, что должно было показываться:

```
┌─────────────────────────────────────┐
│ 🔍 Диагностика PaymentQR            │
├─────────────────────────────────────┤
│ Статус: Создание платежа...         │
│ Payment ID: abc123                   │
│ Ошибка: Нет                          │
│ Таймер авто-проверки: Активен        │
│ Последняя проверка: 10:30:45         │
│ Создание платежа: 10:30:00           │
│ Retry: Нет                           │
└─────────────────────────────────────┘
```

**Цель:** Помочь разработчикам видеть, что происходит внутри `PaymentQRViewModel` без необходимости открывать консоль Xcode.

## ⚠️ Почему overlay был отложен?

### Проблема:

При попытке добавить `PaymentQRDiagnosticsView` в `25_PaymentQRScreen.swift` возникли **множественные ошибки компиляции**:

```
❌ Ошибка: Cannot find type 'PaymentQRDiagnosticsView' in scope
❌ Ошибка: Conflicting declarations of 'diagnosticOverlay'
❌ Ошибка: Nested struct conflicts with existing struct
❌ Ошибка: Function 'showDiagnostics()' already defined
```

### Причины ошибок:

1. **Конфликты вложенных структур:**
   - В SwiftUI нельзя иметь две структуры с одинаковым именем в одном файле
   - `PaymentQRDiagnosticsView` конфликтовал с существующими структурами

2. **Проблемы с областью видимости:**
   - ViewModel и Screen имеют разные области видимости
   - Доступ к диагностическим данным был сложным

3. **Сложность интеграции:**
   - Overlay должен был показывать данные из ViewModel
   - Требовалась сложная синхронизация состояния

### Решение:

- ✅ Файл `25_PaymentQRScreen.swift` восстановлен из стабильного бэкапа
- ✅ Диагностический overlay отложен до стабилизации основной функциональности
- ✅ Используется альтернативное решение (см. ниже)

### 1. Диагностические логи в консоль Xcode

**Где:** `ViewModels/PaymentQRViewModel.swift`

**Что показывается:**
```swift
print("🚨 ========== PaymentQRViewModel.init НАЧАЛО ==========")
```

**Примеры логов:**

- 🔍 Диагностическая информация (потоки, таймеры)
- ✅ Успешные операции
- ❌ Ошибки
- ⚠️ Предупреждения

**Преимущества:**
- ✅ Работает стабильно
- ✅ Не вызывает ошибок компиляции
- ✅ Показывает детальную информацию
- ✅ Можно фильтровать по эмодзи (🚨, 🔍, ✅, ❌)

**Недостатки:**
- ⚠️ Нужно открывать консоль Xcode
- ⚠️ Не видно на экране приложения

### 2. NavigationDebugOverlay (работает!)

**Где:** `Screens/25_PaymentQRScreen.swift` (строки 159-186)

**Что показывает:**
- Логи навигации (NavigationManager)
- Последние 200 записей
- Кнопка "Показать/Скрыть логи" (только в DEBUG режиме)

**Как использовать:**
1. Запустить приложение в DEBUG режиме
2. Открыть экран PaymentQR
3. Нажать кнопку "Показать логи" (в правом верхнем углу)
4. Увидеть логи навигации

**Код:**
```swift
#if DEBUG
.overlay(alignment: .topTrailing) {
    VStack(alignment: .trailing, spacing: 8) {
        Button(action: {
            showNavigationLogs.toggle()
        }) {
            Text(showNavigationLogs ? "Скрыть логи" : "Показать логи")
        }
        
        if showNavigationLogs {
            NavigationDebugOverlay(
                title: "PaymentQR Navigation",
                logEntries: latestLogs
            )
        }
    }
}
#endif
```
