- **AI Agents** - 76 файлов (ML модели)

- **Managers** - 24 файла
- **Microservices** - 17 файлов

### Поток данных:
```
iOS App → HTTPS → Nginx → API Gateway → SFM → Компоненты → Response
```

## 📈 ОЦЕНКА НАГРУЗКИ ПО УРОВНЯМ

### Базовые метрики (на 1 пользователя):
- **Средний запросов в минуту:** 2-5
- **Средний размер запроса:** 1-5 KB
- **Средний размер ответа:** 5-50 KB
- **Время обработки запроса:** 50-500ms (зависит от типа)
- **Пиковая нагрузка:** 10-20 запросов/минуту

### Ресурсы на запрос:
- **CPU:** 0.1-2% (зависит от типа запроса)
- **RAM:** 1-10 MB (включая кэш)
- **Диск I/O:** Минимальный (в основном кэш)

## 🔍 УЗКИЕ МЕСТА

### 1. CPU (2 ядра) ⚠️
- **Проблема:** Ограниченная производительность
- **Влияние:** Начинается с 5,000 пользователей
- **Решение:** Увеличение до 4+ ядер

### 2. RAM (4 Гб) ⚠️
- **Проблема:** Ограниченная память
- **Влияние:** Начинается с 5,000 пользователей
- **Решение:** Увеличение до 8+ Гб

### 3. AI Agents (ML модели) ⚠️⚠️
- **Проблема:** Высокое потребление CPU/RAM
- **Влияние:** Критично при любой нагрузке
- **Решение:** 
  - Оптимизация моделей
  - Кэширование результатов
  - Асинхронная обработка

### 4. База данных (PostgreSQL) ⚠️
- **Проблема:** Может стать узким местом
- **Влияние:** Начинается с 10,000 пользователей
- **Решение:**
  - Индексы
  - Connection pooling
  - Репликация

### 5. Redis ⚠️
- **Проблема:** Может стать узким местом
- **Влияние:** Начинается с 10,000 пользователей
- **Решение:**
  - Redis cluster
  - Оптимизация кэша
