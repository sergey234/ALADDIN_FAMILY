## ✅ ТРЕБОВАНИЯ ДЛЯ ЗАМЕНЫ PROMETHEUS ALERTMANAGER

### Что должно быть:

1. **Мониторинг метрик:**
   - ✅ CPU использование
   - ✅ RAM использование
   - ✅ Диск использование
   - ✅ Сетевая активность
   - ✅ Время ответа API

2. **Пороги и алерты:**
   - ✅ CPU > 80% → алерт
   - ✅ RAM > 90% → алерт
   - ✅ Диск > 90% → алерт
   - ✅ Ошибки API → алерт
   - ✅ Время ответа > 1s → алерт

3. **Уведомления:**
   - ✅ Email уведомления
   - ✅ Telegram уведомления (опционально)
   - ✅ Логирование алертов

4. **Хранение истории:**
   - ✅ История алертов
   - ✅ История метрик
   - ✅ Время возникновения алертов
