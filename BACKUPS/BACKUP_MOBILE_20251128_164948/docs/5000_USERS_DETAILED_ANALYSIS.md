## ⚠️ ПРОБЛЕМЫ

### 1. CPU (2 ядра) - 80-100% загрузка ⚠️
- **Проблема:** Оба ядра будут загружены на 100%
- **Последствия:**
  - Задержки при обработке запросов
  - Очередь запросов
  - Медленная работа AI моделей

### 2. RAM (4 Гб) - 2.5-3.5 Гб используется ⚠️
- **Проблема:** Остается только 0.5-1.5 Гб свободной памяти
- **Последствия:**
  - Возможен swap (использование диска вместо RAM)
  - Замедление работы
  - Риск нехватки памяти при пиковой нагрузке

### 3. AI запросы (ML модели) ⚠️⚠️
- **Проблема:** AI запросы очень ресурсоемкие
- **Последствия:**
  - Могут блокировать обработку обычных запросов
  - Высокое потребление CPU и RAM
  - Задержки до 2-5 секунд

### 4. Пиковая нагрузка ⚠️
- **Проблема:** При пиковой нагрузке (250-500 RPS) сервер может не справиться
- **Последствия:**
  - Таймауты запросов
  - Ошибки 503 (Service Unavailable)
  - Падения сервисов
