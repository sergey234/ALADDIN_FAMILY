# 🔒 АНАЛИЗ: ЧТО ПОКАЗЫВАТЬ ПОЛЬЗОВАТЕЛЯМ VS АДМИНИСТРАТОРУ

**Дата:** 2025-11-26  
**Цель:** Определить, какие данные безопасно показывать публично, а какие только администратору

---

## 🎯 ОСНОВНОЙ ПРИНЦИП

### ✅ МОЖНО показывать пользователям:
- Общая статистика защиты
- Общее количество заблокированных угроз
- Статистика работы системы (без деталей)
- Общее здоровье системы (healthy/warning/critical)
- Общая информация о защите

### ❌ НЕЛЬЗЯ показывать пользователям:
- Детали угроз (типы, источники, методы атак)
- Детали алертов (конкретные проблемы системы)
- Метрики сервера (CPU, RAM, Disk - это внутренняя информация)
- Логи и детальные данные
- Персональные данные других пользователей
- Внутренняя архитектура системы

---

## 📊 ДЕТАЛЬНЫЙ АНАЛИЗ ДАННЫХ

### 1. МЕТРИКИ СИСТЕМЫ (CPU, RAM, Disk)

**Для администратора:** ✅ **ДА**
- Детальные метрики CPU, RAM, Disk
- История метрик
- Графики использования ресурсов
- Детали производительности

**Для пользователей:** ❌ **НЕТ**
- **Почему:** Это внутренняя информация о сервере
- **Риск:** Раскрывает инфраструктуру, может помочь атакующим
- **Альтернатива:** Показывать только общий статус (healthy/warning/critical)

---

### 2. АЛЕРТЫ СИСТЕМЫ

**Для администратора:** ✅ **ДА**
- Все алерты (LOW, MEDIUM, HIGH, CRITICAL)
- Детали алертов (что именно произошло)
- История алертов
- Уровни серьезности

**Для пользователей:** ❌ **НЕТ**
- **Почему:** Раскрывает уязвимости и проблемы системы
- **Риск:** Атакующие могут использовать эту информацию
- **Альтернатива:** Показывать только общий статус защиты (активна/неактивна)

---

### 3. УГРОЗЫ И АТАКИ

**Для администратора:** ✅ **ДА**
- Детали всех угроз
- Типы атак
- Источники угроз
- Методы защиты
- История угроз

**Для пользователей:** ⚠️ **ЧАСТИЧНО**
- ✅ **МОЖНО:** Общее количество заблокированных угроз (без деталей)
- ✅ **МОЖНО:** Статистика защиты (сколько угроз заблокировано сегодня/неделя/месяц)
- ❌ **НЕЛЬЗЯ:** Детали угроз (типы, источники, методы)
- ❌ **НЕЛЬЗЯ:** Конкретные атаки

**Пример для пользователей:**
```json
{
  "protection_stats": {
    "threats_blocked_today": 42,
    "threats_blocked_week": 312,
    "threats_blocked_month": 1245,
    "protection_status": "active"
  }
}
```

---

### 4. СТАТИСТИКА ЗАЩИТЫ

**Для администратора:** ✅ **ДА**
- Детальная статистика по всем категориям
- Статистика по пользователям
- Статистика по типам угроз
- Временные графики

**Для пользователей:** ✅ **ДА (ОБЩАЯ)**
- ✅ Общее количество заблокированных угроз
- ✅ Статистика защиты (сегодня/неделя/месяц)
- ✅ Статус защиты (активна/неактивна)
- ✅ Общая информация о защите

**Пример для пользователей:**
```json
{
  "user_protection": {
    "threats_blocked": 42,
    "protection_active": true,
    "last_threat": "2 hours ago"
  }
}
```

---

### 5. ЗДОРОВЬЕ СИСТЕМЫ

**Для администратора:** ✅ **ДА**
- Детальное здоровье (CPU, RAM, Disk, Network)
- Метрики производительности
- Детали проблем

**Для пользователей:** ⚠️ **ТОЛЬКО ОБЩИЙ СТАТУС**
- ✅ Общий статус (healthy/warning/critical)
- ❌ Детали (CPU, RAM, Disk)

**Пример для пользователей:**
```json
{
  "system_status": "healthy",
  "message": "Система работает нормально"
}
```

---

### 6. ПЕРСОНАЛЬНЫЕ ДАННЫЕ

**Для администратора:** ✅ **ДА (С ПРАВАМИ ДОСТУПА)**
- Данные пользователей (с авторизацией)
- Логи активности
- История действий

**Для пользователей:** ❌ **НИКОГДА**
- ❌ Данные других пользователей
- ❌ Логи других пользователей
- ❌ Персональная информация

## 📋 ПЛАН РЕАЛИЗАЦИИ

### 1. ПУБЛИЧНЫЙ DASHBOARD

**URL:** `https://aladdin-ai.ru/dashboard` (публичный)

**Endpoints:**
- `GET /api/public/stats` - общая статистика защиты
- `GET /api/public/protection` - статус защиты
- `GET /api/public/threats` - общее количество угроз (без деталей)

**Что показывать:**
- Общее количество заблокированных угроз
- Статус защиты
- Общий статус системы

---

### 2. ПРИВАТНЫЙ DASHBOARD

**URL:** `https://aladdin-ai.ru/admin/dashboard` (только для администратора)

**Endpoints:**
- `GET /api/admin/metrics` - все метрики
- `GET /api/admin/alerts` - все алерты
- `GET /api/admin/threats` - детали всех угроз
- `GET /api/admin/stats` - детальная статистика

**Требования:**
- Авторизация (JWT токен администратора)
- Проверка прав доступа
