## 🔧 ФУНКЦИОНАЛЬНОСТЬ СКРИПТА

### Что делает скрипт:

1. **Проверяет аргументы**
   - Требует указать файл backup
   - Показывает доступные backup файлы

2. **Создает backup текущего состояния**
   - Перед восстановлением сохраняет текущее состояние
   - На случай, если что-то пойдет не так

3. **Останавливает сервисы**
   - `aladdin-api-gateway`
   - `aladdin-backend`

4. **Восстанавливает файлы**
   - `security/` - все Python модули
   - `data/` - данные и конфигурации
   - `logging_config.json` - конфигурация логирования
   - `requirements.txt` - зависимости

5. **Устанавливает зависимости**
   - Проверяет и устанавливает Python пакеты из `requirements.txt`

6. **Проверяет синтаксис**
   - Проверяет Python файлы на ошибки синтаксиса

7. **Запускает сервисы**
   - Перезапускает все сервисы после восстановления

## 📝 ИСПОЛЬЗОВАНИЕ (В БУДУЩЕМ)

**Когда понадобится восстановление:**

```bash
# 1. Посмотреть доступные backup файлы
ls -lh /opt/aladdin-backend/backups/

# 2. Запустить восстановление
/opt/aladdin-backend/scripts/restore_from_backup.sh /path/to/backup.tar.gz

# 3. Проверить результат
systemctl status aladdin-api-gateway
systemctl status aladdin-backend
```
