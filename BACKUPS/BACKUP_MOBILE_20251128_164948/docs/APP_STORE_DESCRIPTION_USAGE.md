## 📱 1. КРАТКОЕ ОПИСАНИЕ (Subtitle)

### Где находится:
**App Store Connect → App → App Information → Subtitle**

### Что это:
- Короткое описание приложения (до 30 символов)
- Отображается **под названием приложения** в App Store
- Видно в результатах поиска и на странице приложения

### Пример отображения:
```
ALADDIN AI
ALADDIN AI - защита семьи  ← Это краткое описание
⭐⭐⭐⭐⭐
```

### Текст из файла:
```
ALADDIN AI - защита семьи
```
**26 символов** ✅

## 🎨 2. ПРОМО-ТЕКСТ (Promotional Text)

### Где находится:
**App Store Connect → App → App Information → Promotional Text**

### Что это:
- Промо-текст (до 170 символов)
- Отображается **вверху страницы приложения** в App Store
- Можно обновлять **без новой версии приложения** (обновляется сразу)
- Используется для акций, новостей, обновлений

### Пример отображения:
```
🛡️ ALADDIN AI - ваш персональный агент безопасности! 
Защита всей семьи от киберугроз 24/7. VPN, родительский 
контроль, AI-аналитика. Военные технологии шифрования. 
Безопасность в кармане!

[Полное описание приложения...]
```

### Текст из файла:

## 🌍 ЛОКАЛИЗАЦИЯ

### Где указывается язык:
**App Store Connect → App → App Information → [Выбрать язык]**

### Доступные языки:
- 🇷🇺 **Russian (Russia)** - русский текст
- 🇬🇧 **English (U.S.)** - английский текст

### Как заполнить:
1. Выбрать язык (Russian или English)
2. Заполнить все три поля:
   - Subtitle (краткое описание)
   - Promotional Text (промо-текст)
   - Description (полное описание)
3. Повторить для каждого языка

---

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ

### Шаг 1: Войти в App Store Connect
1. Открыть https://appstoreconnect.apple.com
2. Войти в аккаунт
3. Выбрать приложение "ALADDIN AI"

### Шаг 2: Перейти в App Information
1. В левом меню выбрать **"App"**
2. Выбрать **"App Information"**

### Шаг 3: Заполнить для русского языка
1. В разделе **"Localizable Information"** выбрать **"Russian (Russia)"**
2. Найти поле **"Subtitle"** → вставить:
   ```
   ALADDIN AI - защита семьи
   ```
3. Найти поле **"Promotional Text"** → вставить:
   ```
   🛡️ ALADDIN AI - ваш персональный агент безопасности! Защита всей семьи от киберугроз 24/7. VPN, родительский контроль, AI-аналитика. Военные технологии шифрования. Безопасность в кармане!
   ```
4. Найти поле **"Description"** → вставить полное описание из файла

### Шаг 4: Заполнить для английского языка
1. Выбрать **"English (U.S.)"**
2. Повторить шаги 2-4 с английскими текстами

### Шаг 5: Сохранить
1. Нажать **"Save"** внизу страницы
2. Проверить, что все поля заполнены

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Subtitle (краткое описание):**
   - Максимум 30 символов
   - Отображается везде, где показывается название приложения
   - Должно быть кратким и информативным

2. **Promotional Text (промо-текст):**
   - Максимум 170 символов
   - Можно обновлять без новой версии приложения
   - Используйте для акций и новостей
   - Обновляется сразу после сохранения

3. **Description (полное описание):**
   - Максимум 4000 символов
   - Основной текст для пользователей
   - Можно использовать эмодзи и форматирование
   - Важно для SEO и поиска в App Store

4. **Локализация:**
   - Заполните для всех поддерживаемых языков
   - Минимум: English (U.S.)
   - Рекомендуется: Russian (Russia) + English (U.S.)
