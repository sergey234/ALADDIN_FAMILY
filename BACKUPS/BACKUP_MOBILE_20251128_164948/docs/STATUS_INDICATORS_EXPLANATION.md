## 🔴🟡🟢 ЧТО ОЗНАЧАЮТ ЦВЕТНЫЕ КРУГИ

### Текущая реализация (строки 23-31 в `ThreatProtectionCategoriesView.swift`):

```swift
let (statusIndicator, statusColor): (String, Color) = {
    if !isAvailable {
        return ("🔴", .dangerRed)      // КРАСНЫЙ
    } else if isEnabled {
        return ("🟢", .successGreen)   // ЗЕЛЁНЫЙ
    } else {
        return ("🟡", .warningOrange) // ЖЁЛТЫЙ
    }
}()
```

### Значение каждого цвета:

#### 🔴 **КРАСНЫЙ** (🔴 + красный кружок)
- **Условие:** `!isAvailable` — категория НЕ доступна
- **Значение:** Нужен более высокий тариф
- **Пример:** У пользователя тариф "БАЗОВЫЙ", а категория требует "СЕМЕЙНЫЙ"
- **Действие:** При нажатии → переход на экран Тарифов

#### 🟡 **ЖЁЛТЫЙ** (🟡 + оранжевый кружок)
- **Условие:** `isAvailable == true` И `isEnabled == false`
- **Значение:** Категория доступна для вашего тарифа, но НЕ включена
- **Пример:** У пользователя тариф "СЕМЕЙНЫЙ", категория доступна, но пользователь её не включил
- **Действие:** Можно включить в настройках

#### 🟢 **ЗЕЛЁНЫЙ** (🟢 + зелёный кружок)
- **Условие:** `isAvailable == true` И `isEnabled == true`
- **Значение:** Категория доступна И включена — защита активна
- **Пример:** У пользователя тариф "СЕМЕЙНЫЙ", категория включена и работает
- **Действие:** Защита работает, можно настроить
