## 📝 Формат файлов

Имя файла: `{номер}_{название}_Localized.swift`

## 🔧 Использование

Все локализованные версии используют `LocalizationManager` и автоматически поддерживают:
- 🇷🇺 Русский (RU)
- 🇬🇧 Английский (EN)
- 🇨🇳 Китайский (CN) - опционально
- 🇦🇪 Арабский (AR) - опционально

Переключение языка происходит автоматически через `LocalizationManager.currentLanguage`.
