# Система оплаты ALADDIN - Итоговая документация

**Дата создания:** 17 ноября 2025  
**Статус:** ✅ Готово к использованию (основная функциональность)

## 📁 Структура файлов

### Лендинг (`landing/`)

#### Основные страницы:
- **`index.html`** - Главная страница лендинга с формой оплаты
  - Выбор тарифа
  - Ввод alias + PIN
  - Выбор метода оплаты
  - Интеграция с бэкендом
  - Валидация данных
  - Обработка ошибок

- **`success.html`** - Страница успеха после оплаты
  - Автоматическая проверка статуса (каждые 3 секунды)
  - Отображение кода активации
  - Поддержка manual_transfer (показ реквизитов карты)
  - Форма для получения кода по alias+PIN
  - Обработка всех статусов платежа

- **`styles.css`** - Стили для всех страниц лендинга

#### Юридические страницы:
- **`privacy.html`** - Политика конфиденциальности
- **`terms.html`** - Условия использования / Публичная оферта
- **`help-faq.html`** - Помощь и FAQ
- **`help-form.html`** - Форма обратной связи

#### CMS данные (`cms/`):
- **`tariffs.json`** - Тарифы и цены
- **`methods.json`** - Методы оплаты
- **`banks.json`** - Список банков
- **`testimonials.json`** - Отзывы
- **`faq.json`** - Вопросы и ответы
- **`hero.json`** - Контент главного блока

#### Документация:
- **`README.md`** - Инструкции по запуску
- **`VIEW_INSTRUCTIONS.md`** - Инструкции по просмотру

### Backend (`payment_service/`)

#### Основные файлы:
- **`main.py`** - FastAPI приложение с эндпоинтами:
  - `POST /api/payments/create` - Создание платежа
  - `GET /api/payments/status/{payment_id}` - Проверка статуса
  - `POST /api/payments/confirm` - Webhook для подтверждения
  - `POST /api/activation/retrieve` - Получение кода по alias+PIN
  - `POST /api/activation/verify` - Проверка кода
  - `POST /api/activation/activate` - Активация кода
  - `POST /api/admin/payments/confirm-manual` - Админ-подтверждение
  - `GET /api/payment-methods` - Список методов оплаты

#### Модули (`app/`):
- **`config.py`** - Конфигурация (API ключи, настройки)
- **`database.py`** - Настройка базы данных (SQLite)
- **`models.py`** - SQLAlchemy модели (Payment, ActivationCode)
- **`schemas.py`** - Pydantic схемы для валидации
- **`utils.py`** - Утилиты (генерация кодов, хеширование PIN)
- **`payment_methods.py`** - Список методов оплаты и валидация
- **`rate_limit.py`** - Rate limiting для защиты от брутфорса
- **`providers/mock_psp.py`** - Mock провайдер платежей (для тестирования)

#### Документация:
- **`README.md`** - Инструкции по запуску и использованию
- **`requirements.txt`** - Python зависимости

## 🚀 Как запустить

### Backend:
```bash
cd payment_service
python3 -m pip install -r requirements.txt
python3 -m uvicorn main:app --reload --port 8000 --host 0.0.0.0
```

### Frontend (лендинг):
```bash
cd landing
python3 -m http.server 8080
```

Затем откройте: `http://localhost:8080`
