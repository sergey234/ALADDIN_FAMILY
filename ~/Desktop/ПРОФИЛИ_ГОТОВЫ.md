### Шаг 1: Открыть GitHub Secrets

---

### Шаг 2: Обновить PROVISIONING_PROFILE_APP

1. **Найти секрет:**
   - В списке найти `PROVISIONING_PROFILE_APP`
   - Нажать на него (или кнопку "Update" справа)

2. **Открыть файл:**
   - Открыть Finder
   - Перейти в `~/Desktop/ALADDIN_Profiles/`
   - Найти файл: `app_profile_appstore_base64.txt`
   - Двойной клик для открытия в TextEdit

3. **Скопировать содержимое:**
   - Cmd+A (выделить всё)
   - Cmd+C (скопировать)
   - Закрыть TextEdit

4. **Вставить в GitHub:**
   - Вернуться в браузер
   - В поле **"Secret"** нажать Cmd+V (вставить)
   - Нажать **"Update secret"**
