# 🤖 АВТОМАТИЧЕСКОЕ ОБНОВЛЕНИЕ GITHUB SECRETS

**Дата:** 29 ноября 2025

---

## ⚠️ ВАЖНО

GitHub Secrets **нельзя обновить напрямую через API** без специального шифрования. GitHub требует использования их публичного ключа для шифрования секретов.

---

## 🎯 РЕШЕНИЕ: Использовать GitHub CLI

### Вариант 1: GitHub CLI (рекомендуется)

1. **Установить GitHub CLI** (если не установлен):
   ```bash
   brew install gh
   ```

2. **Авторизоваться:**
   ```bash
   gh auth login
   ```

3. **Обновить секреты:**
   ```bash
   gh secret set PROVISIONING_PROFILE_APP < ~/Desktop/ALADDIN_Profiles/app_profile_appstore_base64.txt
   gh secret set PROVISIONING_PROFILE_EXTENSION < ~/Desktop/ALADDIN_Profiles/extension_profile_appstore_base64.txt
   ```

---

## 📋 РУЧНОЙ МЕТОД (если CLI не работает)

К сожалению, **я не могу напрямую обновить GitHub Secrets** через веб-интерфейс - это требует ручных действий в браузере.

Но я подготовил всё максимально удобно:

1. **Файлы готовы:**
   - `~/Desktop/ALADDIN_Profiles/app_profile_appstore_base64.txt`
   - `~/Desktop/ALADDIN_Profiles/extension_profile_appstore_base64.txt`

2. **Инструкция:**
   - Откройте файлы в TextEdit
   - Скопируйте содержимое (Cmd+A, Cmd+C)
   - Вставьте в GitHub Secrets
