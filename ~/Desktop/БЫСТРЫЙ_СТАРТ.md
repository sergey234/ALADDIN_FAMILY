## 1️⃣ СОЗДАТЬ ПРОФИЛИ (ВРУЧНУЮ)

1. Откройте: https://developer.apple.com/account/resources/profiles/list
2. Нажмите "+"
3. Выберите: **Distribution → App Store Connect**
4. Создайте 2 профиля:
   - `family.aladdin.ios` → `ALADDIN App Store Distribution`
   - `family.aladdin.ios.packetTunnel` → `ALADDIN PacketTunnel App Store Distribution`
5. Скачайте оба профиля

---

## 2️⃣ ЗАПУСТИТЬ СКРИПТ

```bash
~/Desktop/ALADDIN_Profiles/encode_profiles.sh
```

Скрипт автоматически закодирует профили в base64!

---

## 3️⃣ ОБНОВИТЬ GITHUB SECRETS

1. https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions
2. Обновите `PROVISIONING_PROFILE_APP`
3. Обновите `PROVISIONING_PROFILE_EXTENSION`
