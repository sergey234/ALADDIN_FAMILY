## 🎯 ВЫПОЛНИТЕ ЭТУ КОМАНДУ В TERMINAL

Откройте Terminal (Cmd+Space → "Terminal") и выполните:

```bash
mkdir -p ~/Desktop/ALADDIN_Profiles && base64 -i ~/Downloads/ALADDIN_App_Store_Distribution.mobileprovision | tr -d '\n' > ~/Desktop/ALADDIN_Profiles/app_profile_appstore_base64.txt && base64 -i ~/Downloads/ALADDIN_PacketTunnel_App_Store_Distribution.mobileprovision | tr -d '\n' > ~/Desktop/ALADDIN_Profiles/extension_profile_appstore_base64.txt && echo "✅ ГОТОВО!" && ls -lh ~/Desktop/ALADDIN_Profiles/*.txt
```

---

## ✅ ЧТО СДЕЛАЕТ КОМАНДА

1. ✅ Создаст папку `~/Desktop/ALADDIN_Profiles`
2. ✅ Закодирует основной профиль в base64
3. ✅ Закодирует профиль Extension в base64
4. ✅ Покажет размер файлов

## 📋 ПОСЛЕ ВЫПОЛНЕНИЯ КОМАНДЫ
