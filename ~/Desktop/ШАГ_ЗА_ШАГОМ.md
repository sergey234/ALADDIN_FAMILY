# 📋 ШАГ ЗА ШАГОМ: Обновление GitHub Secrets

**Дата:** 29 ноября 2025

---

## ⚠️ ВАЖНО

Я не могу напрямую обновить GitHub Secrets через веб-интерфейс - это требует ручных действий.

Но я подготовил **максимально простой способ**!

---

## 🎯 БЫСТРЫЙ СПОСОБ

### Шаг 1: Обновить PROVISIONING_PROFILE_APP

1. **Я скопировал основной профиль в буфер обмена** ✅

2. **Откройте браузер:**
   - https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions

3. **Найдите секрет:**
   - Найдите `PROVISIONING_PROFILE_APP`
   - Нажмите "Update" (или на сам секрет)

4. **Вставьте:**
   - В поле "Secret" нажмите **Cmd+V** (вставить)
   - Нажмите **"Update secret"**

---

### Шаг 2: Обновить PROVISIONING_PROFILE_EXTENSION

После обновления первого секрета, выполните эту команду в Terminal:

```bash
cat ~/Desktop/ALADDIN_Profiles/extension_profile_appstore_base64.txt | pbcopy
```

Эта команда скопирует Extension профиль в буфер обмена.

Затем:
1. В браузере найдите `PROVISIONING_PROFILE_EXTENSION`
2. Нажмите "Update"
3. В поле "Secret" нажмите **Cmd+V**
4. Нажмите **"Update secret"**

---

## ✅ ГОТОВО!

После обновления обоих секретов:
1. Запустить workflow "Build and Upload to App Store"
2. Билд должен собраться успешно!
