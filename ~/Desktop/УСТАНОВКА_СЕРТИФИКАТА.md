# 🔐 УСТАНОВКА СЕРТИФИКАТА

**Дата:** 29 ноября 2025

---

## 📋 ЧТО ДЕЛАТЬ

### Шаг 1: Найти скачанный сертификат

1. **Открыть папку Downloads:**
   - Finder → Downloads
   - Или Cmd+Option+L

2. **Найти файл:**
   - Ищите файл с расширением `.cer`
   - Или файл с названием типа `distribution.cer` или `AppleDistribution.cer`

---

### Шаг 2: Установить сертификат

1. **Двойной клик на файл `.cer`:**
   - Найти файл сертификата в Downloads
   - Двойной клик на файл
   - Откроется Keychain Access

2. **Выбрать keychain:**
   - В появившемся окне выбрать **"login"** (по умолчанию)
   - Нажать "Add"

3. **Сертификат установится автоматически**

---

### Шаг 3: Проверить установку

1. **Открыть Keychain Access:**
   - Cmd+Space → "Keychain Access"
   - Или Applications → Utilities → Keychain Access

2. **Проверить сертификат:**
   - В левом меню выбрать **"My Certificates"**
   - Найти **"Apple Distribution: ..."** (ваше имя)
   - Сертификат должен быть виден

3. **Проверить в Developer Portal:**
   - https://developer.apple.com/account/resources/certificates/list
   - Должен быть сертификат "Apple Distribution" со статусом "Active"
