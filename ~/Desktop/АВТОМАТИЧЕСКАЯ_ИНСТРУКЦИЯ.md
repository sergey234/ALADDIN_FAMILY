## ⚠️ ВАЖНО

**Я не могу автоматически создать профили в Developer Portal** - это требует ручных действий в веб-интерфейсе.

Но я подготовил **скрипт для автоматического кодирования** профилей после их скачивания!

---

## 📋 ЧТО НУЖНО СДЕЛАТЬ ВРУЧНУЮ

### Шаг 1: Создать профиль для основного приложения

1. **Откройте:** https://developer.apple.com/account/resources/profiles/list
2. **Нажмите "+"** (Create a new provisioning profile)
3. **Выберите:** Distribution → App Store Connect → Continue
4. **Выберите App ID:** `family.aladdin.ios` → Continue
5. **Выберите сертификат:** "Distribution" (2026/11/29) → Continue
6. **Название:** `ALADDIN App Store Distribution` → Generate
7. **Скачайте профиль** → Download

---

### Шаг 2: Создать профиль для Network Extension

1. **Нажмите "+"** (Create a new provisioning profile)
2. **Выберите:** Distribution → App Store Connect → Continue
3. **Выберите App ID:** `family.aladdin.ios.packetTunnel` → Continue
4. **Выберите сертификат:** "Distribution" (тот же) → Continue
5. **Название:** `ALADDIN PacketTunnel App Store Distribution` → Generate
6. **Скачайте профиль** → Download

---

## 🤖 АВТОМАТИЧЕСКАЯ ЧАСТЬ (СКРИПТ)

После скачивания профилей запустите скрипт:

```bash
~/Desktop/ALADDIN_Profiles/encode_profiles.sh
```

**Скрипт автоматически:**
- ✅ Найдет скачанные профили в Downloads
- ✅ Закодирует их в base64
- ✅ Сохранит в `~/Desktop/ALADDIN_Profiles/`

---

## 📋 ПОСЛЕ ЗАПУСКА СКРИПТА

### Шаг 3: Обновить GitHub Secrets

1. **Откройте:** https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions

2. **Обновить PROVISIONING_PROFILE_APP:**
   - Найти `PROVISIONING_PROFILE_APP`
   - Нажать "Update"
   - Открыть `~/Desktop/ALADDIN_Profiles/app_profile_appstore_base64.txt`
   - Скопировать всё (Cmd+A, Cmd+C)
   - Вставить в поле Secret (Cmd+V)
   - Нажать "Update secret"

3. **Обновить PROVISIONING_PROFILE_EXTENSION:**
   - Найти `PROVISIONING_PROFILE_EXTENSION`
   - Нажать "Update"
   - Открыть `~/Desktop/ALADDIN_Profiles/extension_profile_appstore_base64.txt`
   - Скопировать всё (Cmd+A, Cmd+C)
   - Вставить в поле Secret (Cmd+V)
   - Нажать "Update secret"
