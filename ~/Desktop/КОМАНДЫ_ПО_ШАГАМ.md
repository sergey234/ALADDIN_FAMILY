# 📋 КОМАНДЫ ПО ШАГАМ

**Если команда зависла, нажмите Ctrl+C и выполните по шагам:**

---

## Шаг 1: Создать папку

```bash
mkdir -p ~/Desktop/ALADDIN_Profiles
```

---

## Шаг 2: Закодировать основной профиль

```bash
base64 -i ~/Downloads/ALADDIN_App_Store_Distribution.mobileprovision | tr -d '\n' > ~/Desktop/ALADDIN_Profiles/app_profile_appstore_base64.txt
```

---

## Шаг 3: Закодировать профиль Extension

```bash
base64 -i ~/Downloads/ALADDIN_PacketTunnel_App_Store_Distribution.mobileprovision | tr -d '\n' > ~/Desktop/ALADDIN_Profiles/extension_profile_appstore_base64.txt
```

---

## Шаг 4: Проверить результат

```bash
ls -lh ~/Desktop/ALADDIN_Profiles/*.txt
```

---

**Выполняйте команды по одной!**
