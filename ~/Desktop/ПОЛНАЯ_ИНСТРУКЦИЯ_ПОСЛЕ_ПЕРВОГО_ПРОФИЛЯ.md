## 🎯 ШАГ 1: СОЗДАТЬ ВТОРОЙ ПРОФИЛЬ ДЛЯ EXTENSION

### Пошаговая инструкция:

1. **Открыть страницу Profiles:**
   - https://developer.apple.com/account/resources/profiles/list
   - Нажать **"+"** (Create a new provisioning profile)

2. **Выбрать тип:**
   - Выбрать **Distribution → App Store Connect**
   - Нажать **"Continue"**

3. **Выбрать App ID:**
   - В списке найти: **`XC family aladdin ios packetTunnel`**
   - Выбрать его
   - Нажать **"Continue"**

4. **Выбрать сертификат:**
   - Выбрать сертификат **"Distribution"** (тот же, что и для первого профиля)
   - Нажать **"Continue"**

5. **Ввести название:**
   - В поле **"Provisioning Profile Name"** ввести:
     ```
     ALADDIN PacketTunnel App Store Distribution
     ```

6. **Создать профиль:**
   - Нажать **"Generate"**
   - Дождаться создания
   - Нажать **"Download"**
   - Файл скачается в Downloads

## 🤖 ШАГ 2: ЗАПУСТИТЬ СКРИПТ ДЛЯ КОДИРОВАНИЯ

### После скачивания обоих профилей:

1. **Открыть Terminal:**
   - Cmd+Space → ввести "Terminal" → Enter

2. **Запустить скрипт:**
   ```bash
   ~/Desktop/ALADDIN_Profiles/encode_profiles.sh
   ```

3. **Что сделает скрипт:**
   - ✅ Автоматически найдет оба профиля в Downloads
   - ✅ Закодирует их в base64
   - ✅ Сохранит в `~/Desktop/ALADDIN_Profiles/`

4. **Если скрипт не найдет профили автоматически:**
   - Скрипт попросит указать пути вручную
   - Укажите полные пути к файлам `.mobileprovision`

## 📋 ШАГ 3: ОБНОВИТЬ GITHUB SECRETS

### Подробная инструкция:

#### 3.1: Открыть GitHub Secrets

1. **Открыть браузер:**
   - Перейти на: https://github.com/sergey234/ALADDIN_FAMILY/settings/secrets/actions
   - Войти в аккаунт (если не вошли)

2. **Проверить список секретов:**
   - Должны быть видны:
     - `PROVISIONING_PROFILE_APP`
     - `PROVISIONING_PROFILE_EXTENSION`
     - `APPLE_TEAM_ID`
     - `APP_STORE_CONNECT_API_KEY` (если добавлен)
     - И другие...

---

#### 3.2: Обновить PROVISIONING_PROFILE_APP

1. **Найти секрет:**
   - В списке найти `PROVISIONING_PROFILE_APP`
   - Нажать на него (или кнопку "Update" справа)

2. **Открыть файл с base64:**
   - Открыть Finder
   - Перейти в `~/Desktop/ALADDIN_Profiles/`
   - Найти файл: `app_profile_appstore_base64.txt`
   - Двойной клик для открытия в TextEdit

3. **Скопировать содержимое:**
   - Cmd+A (выделить всё)
   - Cmd+C (скопировать)
   - Закрыть TextEdit

4. **Вставить в GitHub:**
   - Вернуться в браузер на странице GitHub Secrets
   - В поле **"Secret"** нажать Cmd+V (вставить)
   - Нажать **"Update secret"**

5. **Проверить:**
   - Должно появиться сообщение об успешном обновлении
   - Секрет должен быть в списке

---

#### 3.3: Обновить PROVISIONING_PROFILE_EXTENSION

1. **Найти секрет:**
   - В списке найти `PROVISIONING_PROFILE_EXTENSION`
   - Нажать на него (или кнопку "Update" справа)

2. **Открыть файл с base64:**
   - Открыть Finder
   - Перейти в `~/Desktop/ALADDIN_Profiles/`
   - Найти файл: `extension_profile_appstore_base64.txt`
   - Двойной клик для открытия в TextEdit

3. **Скопировать содержимое:**
   - Cmd+A (выделить всё)
   - Cmd+C (скопировать)
   - Закрыть TextEdit

4. **Вставить в GitHub:**
   - Вернуться в браузер на странице GitHub Secrets
   - В поле **"Secret"** нажать Cmd+V (вставить)
   - Нажать **"Update secret"**

5. **Проверить:**
   - Должно появиться сообщение об успешном обновлении
   - Секрет должен быть в списке
