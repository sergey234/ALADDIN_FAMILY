### 1. GeometryReader

```swift
    // Использовать geometry.safeAreaInsets

```

### 2. VStack с правильными отступами
```swift
VStack(spacing: 0) {
    topSection        // Верх - логотип и профиль
    mainContent       // Середина - основной контент
    Spacer()          // Растягивает пространство
    bottomNavigation  // Низ - навигация
}
```

### 3. Правильные отступы
```swift
.padding(.top, 0)     // Верх - без отступов
.padding(.bottom, 0)  // Низ - без отступов
.padding(.horizontal, 20) // Боки - минимальные отступы
```
