## 🎯 ДЛЯ ЧЕГО ОН НУЖЕН?

### Основная цель: Предотвращение рекурсии

**Проблема, которую решает:**
- Старый код форматирования дат вызывал рекурсию через `Calendar.current` → `UserDefaults` → обновление View → снова форматирование
- Это вызывало краш приложения (BUILD 100)

**Решение:**
- `DateFormatterService` использует статический `Calendar` вместо `Calendar.current`
- Статический календарь создается один раз и не читает из `UserDefaults`
- Нет бесконечного цикла → нет рекурсии

---

## 📊 ЧТО ДЕЛАЕТ ЭТОТ ФАЙЛ?

### Основные функции:

1. **Форматирование дат:**
   - `formatExpirationDate(from:)` - форматирует дату окончания подписки
   - `formatDisplayDate(_:)` - форматирует дату для отображения
   - `formatDateTime(_:)` - форматирует дату и время

2. **Парсинг дат:**
   - `parseISO8601(_:)` - парсит ISO8601 строку в Date

3. **Работа с календарем:**
   - `isDateInToday(_:)` - проверяет, является ли дата сегодняшней
   - `isDateInYesterday(_:)` - проверяет, является ли дата вчерашней
   - Использует статический Calendar вместо `Calendar.current`
