## 🔍 **ДИАГНОСТИКА ПРОБЛЕМ**

### **Если что-то не работает:**

#### **Проблема: Геолокация не работает**
```
Решение:
1. Settings → Privacy → Location Services → ON
2. Найти ALADDIN → Allow Always
3. Перезапустить приложение
```

#### **Проблема: Звонки/SMS не работают**
```
Решение:
1. Проверить SIM-карту
2. Settings → Cellular → ON
3. Проверить разрешения Contacts и Messages
```

#### **Проблема: Приложение крашится**
```
Решение:
1. Проверить логи Xcode
2. Проверить версию iOS (минимум 15.0)
3. Очистить кэш: rm -rf ~/Library/Developer/Xcode/DerivedData/ALADDIN-*
```
