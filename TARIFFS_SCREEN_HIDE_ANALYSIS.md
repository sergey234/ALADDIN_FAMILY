# Анализ Способов Скрытия Страницы Тарифов

## 🎯 Проблема
Необходимо временно скрыть/заменить страницу тарифов с минимальными изменениями в коде для быстрого восстановления.

## 📊 Точки Входа в TariffsScreen (ФАКТЫ - Белая Шляпа)

### Основные точки доступа:
1. **ALADDINApp.swift** - главный роутер экранов
2. **SettingsScreen** - кнопка "Тарифы" в настройках
3. **MainScreen** - карточка тарифов на главной странице
4. **ThreatProtectionScreen** - кнопка "Сравнить все тарифы"
5. **ThreatScenariosGallery** - переход при недоступной функции
6. **MotivationBanner** - кнопка апгрейда
7. **ProtectionGroupSection** - переход при недоступной функции
8. **EnhancedThreatCategoryCard** - переход при недоступной функции

### Архитектурные факты:
- **NavigationManager** управляет всей навигацией
- **ALADDINScreen.tariffs** - enum case для идентификации экрана
- **SwiftUI Navigation** с environment objects
- **StoreKit 2** интеграция для IAP
- **Региональная логика** (Россия vs другие страны)

### 3. 🖤 ЧЕРНАЯ ШЛЯПА - РИСКИ, ПРОБЛЕМЫ

#### ВАРИАНТ 1: Feature Flag в AppConfig
**Риски:**
- ⚠️ Забыть выключить флаг перед релизом
- ⚠️ Может быть случайно изменен в коде
- ⚠️ Тестировщики могут не заметить

#### ВАРИАНТ 2: NavigationManager фильтр
**Риски:**
- 🚨 КРИТИЧНО: Может сломать всю навигационную логику
- 🚨 КРИТИЧНО: PaymentQR fallback использует `.tariffs`
- 🚨 КРИТИЧНО: goBack() логика зависит от `.tariffs`
- 💀 ПОТЕНЦИАЛЬНЫЙ КРАХ: Навигационный стек может сломаться

#### ВАРИАНТ 3: Conditional Compilation
**Риски:**
- 🚨 КРИТИЧНО: Забытые `#if` блоки останутся в коде
- 🚨 КРИТИЧНО: Разные сборки с разным поведением
- 💀 ПОТЕНЦИАЛЬНЫЙ КРАХ: Неправильная компиляция

#### ВАРИАНТ 4: Замена экрана в роутере
**Риски:**
- ⚠️ Пользователи увидят пустой экран при прямом переходе
- ⚠️ Навигационная логика может ожидать TariffsScreen
- ⚠️ goBack() из PaymentQR может сломаться

#### ВАРИАНТ 5: UI-level скрытие кнопок
**Риски:**
- 🚨 КРИТИЧНО: НЕ блокирует прямые URL переходы
- 🚨 КРИТИЧНО: НЕ блокирует навигацию через NavigationManager
- 🚨 КРИТИЧНО: НЕ блокирует deep linking
- 💀 ПОТЕНЦИАЛЬНЫЙ КРАХ: Неполная защита
