## 🎯 ЧТО ПОМОГУТ ПРОТОКОЛЫ?

### **1. Тестирование ViewModels БЕЗ реального API:**

**БЕЗ протокола (как сейчас):**
```swift
// ViewModel использует APIService.shared напрямую
class AnalyticsViewModel {
    private let apiService = APIService.shared  // ← Зависимость от реального API
    
    func loadData() {
        apiService.getAnalytics { ... }  // ← Нужен реальный сервер для теста
    }
}

// Тест НЕ МОЖЕТ работать без реального сервера
func testLoadData() {
    let viewModel = AnalyticsViewModel()
    // ❌ Проблема: Нужен реальный сервер
    // ❌ Тест упадет, если сервер недоступен
}
```

**С протоколом:**
```swift
// Протокол
protocol APIServiceProtocol {
    func getAnalytics(completion: @escaping (Result<AnalyticsResponse, Error>) -> Void)
}

// ViewModel использует протокол
class AnalyticsViewModel {
    private let apiService: APIServiceProtocol  // ← Протокол вместо класса
    
    init(apiService: APIServiceProtocol = APIService.shared) {
        self.apiService = apiService
    }
    
    func loadData() {
        apiService.getAnalytics { ... }
    }
}

// Тест МОЖЕТ работать БЕЗ реального сервера
func testLoadData() {
    let mockAPI = MockAPIService()  // ← Mock реализует протокол
    let viewModel = AnalyticsViewModel(apiService: mockAPI)
    // ✅ Тест работает БЕЗ реального сервера
    // ✅ Можно протестировать все сценарии
}
```
