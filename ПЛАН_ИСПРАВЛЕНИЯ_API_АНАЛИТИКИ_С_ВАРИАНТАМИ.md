```python
# app/routers/analytics_router.py
@router.get("/analytics")
async def get_analytics(
    period: str = Query("day", regex="^(day|week|month)$"),
    current_user: dict = Depends(get_current_user)
):
    user_id = current_user.get("sub")
    
    # Получаем реальные данные из базы данных
    threats_detected = await db.get_threats_detected(user_id, period)
    threats_blocked = await db.get_threats_blocked(user_id, period)
    items_scanned = await db.get_items_scanned(user_id, period)
    protection_level = calculate_protection_level(threats_blocked, threats_detected)
    
    # Получаем данные по типам угроз
    threats_by_type = await db.get_threats_by_type(user_id, period)
    
    return AnalyticsResponse(
        period=period,
        threatsDetected=threats_detected or 0,  # ✅ 0 если нет данных
        threatsBlocked=threats_blocked or 0,
        itemsScanned=items_scanned or 0,
        protectionLevel=protection_level or 0,
        topThreats=top_threats or [],
        threatsByType=threats_by_type or []
    )
```

## 🔧 ЛОГИКА ОТОБРАЖЕНИЯ ДАННЫХ

### **Когда показывать 0:**

1. ✅ **Нет данных в базе** - пользователь новый, нет истории
   - Это нормально для новых пользователей
   - Показываем 0 честно

2. ✅ **API не работает и нет кэша** - первая загрузка без интернета
   - Показываем 0 вместо ошибки
   - Лучше чем показывать MOCK данные

3. ✅ **Период без данных** - например, месяц назад не было активности
   - Показываем 0 для этого периода
   - Это реальные данные (просто их нет)

### **Когда показывать реальные данные:**

1. ✅ **API работает** - показываем данные из API
   - Это основной источник данных
   - Самые актуальные данные

2. ✅ **Есть кэш** - показываем кэшированные данные с индикатором
   - Данные могут быть устаревшими (5 минут)
   - Показываем индикатор "Данные из кэша"

3. ✅ **Есть данные в базе** - показываем реальные цифры
   - Даже если это 0 - это реальные данные
   - Честно показываем отсутствие данных

### **Когда показывать ошибку:**

1. ✅ **API не работает и нет кэша** - показываем ошибку или 0
   - Предпочтительно показывать 0
   - Ошибка только если критично

2. ✅ **Ошибка авторизации** - показываем ошибку 401
   - Требуется авторизация
   - Пользователь должен войти

3. ✅ **Ошибка сервера** - показываем ошибку 500
   - Проблема на сервере
   - Показываем ошибку с возможностью повтора
