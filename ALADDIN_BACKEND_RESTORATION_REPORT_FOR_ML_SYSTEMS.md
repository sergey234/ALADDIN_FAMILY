**Результат:** ✅ Gunicorn установлен в venv

### **Этап 2: Ручной запуск API для тестирования**
```bash
# Запуск через uvicorn
uvicorn main:app --host 0.0.0.0 --port 8002 --log-level info
```

**Результат:** ✅ API запустился, порт 8002 открыт

### **Этап 3: Тестирование функциональности**
```bash
# Тест health check
curl http://149.154.65.180:8002/api/health
# ✅ {"status":"ok"}

# Тест через домен
curl https://aladdin-ai.ru/api/health
# ✅ {"status":"ok"}

# Тест защищенного эндпоинта
curl https://aladdin-ai.ru/api/components/status/crash_detection_agent
# ✅ {"detail":"Not authenticated"} (корректная защита)
```

### **Этап 4: Настройка production systemd сервиса**
```bash
# Создание нового сервиса
sudo tee /etc/systemd/system/aladdin-production-api.service << 'EOF'
[Unit]
Description=ALADDIN Production API Gateway
After=network.target
Wants=network.target

[Service]
Type=simple
User=root
Group=root
WorkingDirectory=/opt/aladdin-backend
Environment=PATH=/opt/aladdin-backend/venv/bin
ExecStart=/opt/aladdin-backend/venv/bin/uvicorn main:app --host 0.0.0.0 --port 8002 --workers 4 --log-level info
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal
SyslogIdentifier=aladdin-prod-api

[Install]
WantedBy=multi-user.target
EOF

# Запуск сервиса
sudo systemctl daemon-reload
sudo systemctl enable aladdin-production-api
sudo systemctl start aladdin-production-api
```

**Результат:** ✅ Production сервис запущен с автозапуском
