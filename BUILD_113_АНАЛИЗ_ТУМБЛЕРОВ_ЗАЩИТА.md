### ❌ **ПРОБЛЕМА #1: ProtectionCategoryRow не вызывает аналитику**

**Файл:** `Components/ProtectionCategoryRow.swift`  
**Строки:** 33, 59-70

**Код:**
```swift
ALADDINToggle(isOn: $isEnabled)  // ❌ Нет аналитики!

.onTapGesture {
    if isAvailable {
        withAnimation {
            isEnabled.toggle()  // ❌ Прямое переключение без аналитики!
        }
        HapticFeedback.selection()
    }
}
```

**Проблема:**
- Тумблер переключается напрямую через `isEnabled.toggle()`
- Нет вызова `componentAnalytics.trackComponentToggle()` или `trackSettingToggle()`
- Но это может быть не проблема, если аналитика вызывается где-то еще
