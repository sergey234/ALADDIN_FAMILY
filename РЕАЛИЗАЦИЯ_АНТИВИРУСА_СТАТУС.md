**Причина:** Возможно, файл `MalwareSettingsViewModel.swift` не подключен к target проекта или есть проблема с модулями.

**Решение:** 
1. Проверить, что файл подключен к target в Xcode
2. Убедиться, что нет конфликтов имен
3. Возможно, нужно добавить явный import (хотя обычно не требуется для файлов в том же модуле)
