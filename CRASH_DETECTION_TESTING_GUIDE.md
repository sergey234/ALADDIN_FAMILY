## 🔧 ИСПРАВЛЕНИЕ ПРОБЛЕМ КОМПИЛЯЦИИ

### **Если в Xcode показываются ошибки:**

#### **Шаг 1: Очистка кэша Xcode**
```bash
# В терминале:
rm -rf ~/Library/Developer/Xcode/DerivedData/ALADDIN-*
rm -rf ~/Library/Caches/com.apple.dt.Xcode
```

#### **Шаг 2: Перезапуск Xcode**
1. Полностью закройте Xcode
2. Откройте проект заново
3. Выберите: `Product → Clean Build Folder`
4. Соберите проект: `Product → Build`

#### **Шаг 3: Проверка**
Проект должен компилироваться без ошибок: `** BUILD SUCCEEDED **`

## 📱 ПОДГОТОВКА К ТЕСТИРОВАНИЮ

### **Требования к устройству:**
- ✅ iPhone с iOS 15.0+
- ✅ Включена геолокация (`Settings → Privacy → Location Services`)
- ✅ Разрешение "Always" для приложения
- ✅ SIM-карта (для тестирования звонков)
- ✅ Включены уведомления

### **Установка приложения:**
1. Подключите iPhone к Mac
2. В Xcode выберите устройство в качестве target
3. Нажмите `Product → Run` (⌘R)
4. Приложение установится на устройство

### **ФАЗА 2: Тестирование обнаружения крашей (20 минут)**

#### **Тест 2.1: Симуляция краха**
1. Перейдите в `Network Protection → Emergency Help`
2. Включите Crash Detection (тумблер)
3. Нажмите кнопку `"🚨 ТЕСТ: Симулировать аварию"`
4. **Ожидаемый результат:**
   - ✅ Появляется красный модал "АВАРИЯ ОБНАРУЖЕНА!"
   - ✅ В логах: `"🧪 TEST: Simulating crash with G-force: 5.0"`
   - ✅ В логах: `"🚨 CrashDetectionManager: TEST CRASH DETECTED!"`

#### **Тест 2.2: Emergency Actions**
В красном модале нажмите:
- **"Отмена"** → Модал закрывается
- **"🚨 112"** → Должен открыться телефон (без реального звонка)
- **"📱 Уведомить контакты"** → Открывается SMS composer

## 🔍 ДИАГНОСТИКА ПРОБЛЕМ

### **Если что-то не работает:**

#### **Проблема: Нет геолокации**
```
Решение:
1. Settings → Privacy → Location Services → ON
2. Найти ALADDIN → Always Allow
3. Перезапустить приложение
```

#### **Проблема: Не работают звонки/SMS**
```
Решение:
1. Проверить SIM-карту
2. Settings → Cellular → Cellular Data → ON
3. Проверить разрешения для Contacts и Messages
```

#### **Проблема: Низкая производительность**
```
Решение:
1. Проверить уровень заряда батареи (>20%)
2. Закрыть другие приложения
3. Проверить температуру устройства
```
