## 🔴 ВОЗМОЖНЫЕ ПРИЧИНЫ (ПО ПРИОРИТЕТУ)

### 🔴 ПРИЧИНА #1: DateFormatter используется в computed property, который вызывается рекурсивно

**Вероятность:** 🔴 **90%**

**Где искать:**
- Computed properties с `DateFormatter.string(from:)`
- Computed properties, которые вызываются во время форматирования даты
- Computed properties в `MainScreen`, которые используют `displayFormatter`

**Проблема:**
- Если `displayFormatter.string(from:)` вызывается в computed property
- И этот computed property вызывается во время обновления View
- И обновление View вызывает форматирование даты
- Это может вызвать рекурсию
