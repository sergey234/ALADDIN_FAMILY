### Проблема:
- В выборе владельца показывается только "YOU" (Вы)
- Нет других членов семьи

### Анализ текущей реализации:

**Файл:** `Screens/20_DevicesScreen.swift` - `AddDeviceView`

**Текущая логика:**
```swift
private func loadFamilyMembers() {
    // Загружаем из UserDefaults
    let familyMembersKey = "family_members_list"
    if let savedData = UserDefaults.standard.data(forKey: familyMembersKey),
       let decoded = try? JSONDecoder().decode([FamilyMemberData].self, from: savedData) {
        familyMembers = decoded.map { $0.name }
    } else {
        // Если нет - используем текущего пользователя
        if let currentUserName = UserDefaults.standard.string(forKey: "current_user_name") {
            familyMembers = [currentUserName]
        } else {
            familyMembers = [localizationManager.localized("devices_owner_you")]
        }
    }
}
```

**Проблемы:**
- ❌ Загружает только из UserDefaults (может быть пусто)
- ❌ Нет загрузки из API
- ❌ Нет обновления списка при открытии формы

**План исправления:**
1. Добавить загрузку членов семьи из API
2. Обновлять список при открытии формы
3. Добавить обработку ошибок
