## 📚 ОБЪЯСНЕНИЕ ЛОГИКИ ТАРИФОВ (ПРОСТЫМ ЯЗЫКОМ)

### **🔑 ЧТО ТАКОЕ ТОКЕН?**

**Токен** - это как **пропуск** для входа в защищенную зону.

- ✅ **С токеном** - можешь заходить в защищенные части приложения (API)
- ❌ **Без токена** - не можешь заходить, нужно получить пропуск

---

### **📱 ЛОГИКА ПО ТАРИФАМ**

#### **1. FREE/TRIAL (Бесплатный/Пробный тариф)**

**Как получить токен:**
- 📱 При **первом запуске** приложения
- 📱 Приложение **автоматически регистрирует устройство** на сервере
- 📱 Сервер **выдает токен** (пропуск) для этого устройства
- ✅ **Токен получается БЕЗ авторизации** - просто регистрация устройства

**Простыми словами:**
> "Ты скачал приложение → приложение говорит серверу 'Вот мой телефон' → сервер дает пропуск → можешь пользоваться"

**Это правильно?** ✅ **ДА!**
- Пользователь может попробовать приложение без регистрации
- Токен привязан к устройству, а не к пользователю
- Можно использовать базовые функции

---

#### **2. BASIC/PREMIUM/FAMILY (Платные тарифы)**

**Как получить токен:**
- 🔐 При **авторизации** (входе в аккаунт)
- 📱 ИЛИ при **регистрации** нового аккаунта
- 📱 ИЛИ при **регистрации устройства** (если еще нет токена)
- ✅ **Токен получается при авторизации/регистрации** - привязывается к аккаунту

**Простыми словами:**
> "Ты создал аккаунт или вошел → сервер дает пропуск → можешь пользоваться всеми функциями"

**Это правильно?** ✅ **ДА!**
- Платные функции требуют авторизации
- Токен привязан к аккаунту пользователя
- Можно использовать все функции тарифа

---

#### **3. БЕЗ ТОКЕНА**

**Что происходит:**
- ❌ **Защищенные API недоступны** - нельзя загружать данные с сервера
- ❌ **Нельзя использовать функции** - которые требуют подключения к серверу
- ✅ **Можно использовать** - только локальные функции (без интернета)

**Простыми словами:**
> "Нет пропуска → не можешь зайти в защищенную зону → нужно получить пропуск"

**Это правильно?** ✅ **ДА!**
- Без токена нельзя использовать защищенные функции
- Это защита от несанкционированного доступа
- Пользователь должен авторизоваться или зарегистрировать устройство

---

3. ✅ **Без токена** - защита от несанкционированного доступа

**Это стандартная практика:**
- Большинство приложений работают так же
- Это безопасно и удобно для пользователей
