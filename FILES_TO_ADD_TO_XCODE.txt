## 🔧 КАК ДОБАВИТЬ ФАЙЛЫ В XCODE

### Способ 1: Через Finder + Xcode (Рекомендуется)
1. Открыть `ALADDIN.xcodeproj` в Xcode
2. В Project Navigator выбрать папку `ALADDIN`
3. Правой кнопкой → "Add Files to 'ALADDIN'..."
4. Выбрать нужный файл из списка выше
5. Убедиться что "Copy items if needed" отмечено
6. Нажать "Add"

### Способ 2: Через Terminal (Автоматический)
```bash
cd /Users/sergejhlystov/ALADDIN_NEW/ALADDIN_NEW/mobile_apps/ALADDIN_iOS

# Добавить все файлы через Ruby скрипт
ruby -e "
require 'xcodeproj'
project = Xcodeproj::Project.open('ALADDIN.xcodeproj')
target = project.targets.find { |t| t.name == 'ALADDIN' }

# Добавить файлы
files_to_add = [
  'Core/Utilities/APITestAnalyzer.swift',
  'IntegrationTestView.swift',
  'IntegrationTestViewModel.swift',
  'SimpleAPITester.swift'
]

files_to_add.each do |file_path|
  if File.exist?(file_path)
    file_ref = project.new_file(file_path)
    target.add_file_references([file_ref])
    puts \"✅ Добавлен: #{file_path}\"
  else
    puts \"❌ Файл не найден: #{file_path}\"
  end
end

project.save
puts 'Сохранено!'
"
```
